# 原生手牌相邻费用来源

`CostAuraSpec(CostSpec(delta=1), hand_adjacent=True)`表达黏弹的真实有限需求：原生普通法术在手牌中，令自己当前左右相邻的物理牌各增加一费。只允许friendly关系、完整普通可出手牌类型和+1，不接受种族、首张/周期、替代付款、筛选或动态授予组合。法术定义只能有这一条费用声明，秘密、任务和持续效果不作来源。印刷附件仍沿原安装、复制、移区、变形和保存管线。

## 原当前牌位与原接受牌位

`hand_neighbors.current_hand_neighbors`只读当前物理手牌列表，返回至多两个邻实体；无当前手牌驻留的对象没有当前邻位。原`submitted_hand_neighbors`仍读取出牌前捕获的邻位，语义保持独立。本次不改原提交历史，不以历史邻位冒充当前邻位。

普通`quote_input`将其实际物理对象交给原外层报价器。仅当实体的当前控制者、卡面和类型都对应报价输入时，当前左右邻牌可作为手牌来源；场上/武器来源仍按原范围执行，不把在手中的普通场上光环当成活跃来源。手牌来源与场上来源进入同一按附件ID排序的费用贡献序列，本地附魔、玩家修饰、支付账户、消耗及最低费用层继续共用。

生成报价没有物理手牌位置，不能凭将来的可能入手位置虚构相邻增费。实际生成到手后立即按真实位置重新报价。两个黏弹可共同影响中间一张牌；互相相邻时也会令对方增加一费。移除中间牌、换序、弃置、移库、转交、复制或变形后，下次报价直接读新位置，不维护可过期的邻位缓存，也不给相邻牌留下永久费用附件。

付款前捕获完整原手牌状态和原报价，实际支付与历史沿原`HandPlayCostReceipt`及Spell/非Spell接受证明。对象离手后，后续`quote_accepted_hand`不再有当前手牌邻位；已付款的原收据仍保存当时增加的费用。这一后续窗口政策以及精确来源层序待M6国服校准，不能从卡面文字认证。

## 实际卡与保存边界

`CATA_186`黏弹爆破手是4费4/4，战吼用普通`AddToHand`给当前对手`CATA_186t`。官网双语父卡childIds=123782、衍生物parentId=123783与完整原始记录相符；满手牌沿普通烧牌规则。黏弹是基础2费法术，手动出牌支付其实际当前费用并正常离手，没有主动主体；自动施法仍用原免费施放入口。普通召唤爆破手不执行战吼。`CATA_186te`只作完整附魔原始证据，不注册为可执行卡。

只有原生普通法术可携带这类印刷附件；载体、完整声明、唯一附件及印刷可移除来源相互校验。普通费用光环动态授予接口明确拒绝此范围。篡改原生手牌范围为场上范围不能绕过载体验证。玩家观察只显示本人必要的当前费用，不暴露私有手牌引用、邻位来源或接受证明。
