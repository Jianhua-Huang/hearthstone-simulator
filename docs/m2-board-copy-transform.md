# 保留原本体的战场复制变形

原CopyMinion现在可显式接受[实际成功复制体续接](m3-copy-followups-hidden-pairs.md)，仍使用既有冻结本地材料和物理交付。这不改变本页TransformMinionIntoCopy的接收者重置、驻留及复制政策。

`TransformMinionIntoCopy(target, card, source_id=None, stats=None)` 以两个既有 `MinionReference` 指明战场接收者和材料来源。二者实际执行时都须保持原卡面、控制者、区域修订、入场身份及活跃存活资格；已离场、转控、换形、休眠或死亡则跳过。未知卡面、错误类型和不支持的材料仍明确报错。

原接收者保留实体 ID、owner/controller、战场位置、原 presence/入场序号、召唤回合和已用攻击次数；区域修订递增以使旧引用失效。它不分配新实体、不死亡、不触发被复制者的战吼，不将复制来源转控。自我复制先捕获本地材料，再重置原实体。

执行复用 `transform_minion` 的重置、光环刷新、`transformed` 事件和既有入场处理。材料沿 `copy_current_stored_state` / `copy_attachments`，包括本地基值、伤害、费用、沉默和能力消费状态，附件分配独立 ID；外部光环由当前位置与控制者重算。被复制来源的冻结按接收者的攻击机会重绑期限；接收者原冻结及原增益被替换，已用攻击次数不会从来源复制或清零。上述伤害、冻结、层序及准确国服窗口为待校准政策。

可选 `stats` 复用严格 `SummonStats`，在第一个变形事件及入场前安装；指定生命按原规则清除伤害。无独立关键词、战吼授予或组合矩阵，普通印刷变形保持原路径。复制后的沉默、回手、死亡与费用复用各自内核。

仅完整隔离适配 EX1_564 无面操纵者，5费3/3中立史诗，战吼选择随从成为其当前复制。ETC_110 封面艺人的完整原始行只证明固定3/3需求，不适配该真实来源。正式池和国服认证保持开放。

新增效果由既有注册表和 `FrameCodec` 编解码，恢复边界检查两端的定义和物理实体；合法但已失效引用按执行时跳过，缺失实体的存档拒绝。沿原等待、事务回滚、快照、clone、回放及玩家信息隔离，无新 State/Entity/Player 字段或模块。规则/解释器身份为 prototype-v301/core-effects-v303，schema264和观察84/命令12/replay1保持。

实际执行、验证结果、已知差异和下一项仅在[项目状态](project-status.md)与[机制清单](mechanism-backlog.md)维护。
