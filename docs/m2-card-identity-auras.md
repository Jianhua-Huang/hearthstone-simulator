# 原生光环的当前卡牌身份筛选

场上原生属性光环和关键词光环可使用 `card_ids` 选择受益者，复用玩家长期属性光环已使用的当前物理卡牌ID比较。实际执行与验收结果见[项目状态](project-status.md)及[机制清单](mechanism-backlog.md)，精确国服身份和时序仍待 M6。

```python
AuraSpec(attack=2, card_ids=('CS2_101t', 'CS2_101t2'))
KeywordAuraSpec(
    Keyword.TAUNT, 'friendly_minions',
    card_ids=('CS2_101t', 'CS2_101t2'),
)
```

## 原声明与筛选

AuraSpec、KeywordAuraSpec末尾新增默认空 `card_ids`；空元组不筛选，保持旧非空光环声明。非空时必须唯一、不可变、非空字符串ID元组，使用普通场上友方随从、always、非相邻范围。来源是否纳入仍由原include_self决定；不叠加种族或任意条件选择器，不引入名称匹配或隐式别名。

原扁平属性附件保存 `aura_card_ids`，由原 `aura_spec` 重建完整属性声明；关键词沿原 KeywordAuraSpec 保存。完整原生声明、附件数量和来源资格复用现有校验，拒绝删空/缩短/冒充选择器、非印刷/有期限/消费/不可沉默/融合来源。注册表冻结时所有选择器ID必须已有完整随从定义，未知或非随从明确报错，不能默默从池或筛选中删去。GrantAura API保持；GrantKeywordAura拒绝非空ID选择器，不扩展特殊授予。

原数值和关键词刷新管线调用同一纯 `matches_card_identity`，只比较受益实体当前 `card_id`。不读名称、种族、原来卡面或源实体的来源ID。变形改变匹配，当前/基础复制重新计算；来源沉默、死亡、回手或转控，受益者沉默、转控、进入/离开战场或休眠均复用原光环生命周期。外部光环不是受益者固有附魔，不被当前复制重复算入本体，不被受益者沉默移除。

不会建立第二个属性或关键词执行器、派生缓存、事件、动作或机制模块；玩家长期属性光环的原比较结果保持。选择恢复、即时/等待回滚、JSON/完整帧、死亡记录与当前载体验证复用原管线。当前规则prototype-v203、效果core-effects-v197、schema191拒绝旧1～190；观察74/命令11/replay1保持。没有新CardDefinition、Entity/Player/GameState字段；AbilityInstance仅加一个默认空扁平选择器，JSON恢复显式校验并转换为元组，旧wire字段缺失不能默认补齐。
