# 控制者回合内的英雄免疫光环

KAR_712 紫罗兰幻术师要求“在你的回合中，你的英雄免疫”。原永久英雄免疫、自身受伤风怒和装备武器冲锋无法直接表达这项持续条件。现在扩展既有 `KeywordAuraSpec`，复用原免疫、防伤与来源生命周期；实际执行、验证和下一项只在[项目状态](project-status.md)与[机制清单](mechanism-backlog.md)维护。

## 原生声明

```python
KeywordAuraSpec(Keyword.IMMUNE, condition='controller_turn')
```

本条件只支持 `friendly_hero` 和 `IMMUNE`，无包含自身、相邻、种族或卡牌 ID 筛选。来源必须是注册的普通非融合随从，附件按原生声明校验，保持印刷来源、可沉默、未消费、无期限。条件光环不能任意授予，不展开额外关键词或条件组合。

常驻光环和既有自身条件保持。条件来源的印刷声明即使被改成 `always`，仍进入原生载体验证，不能通过移除条件逃过原声明校验。

## 时钟与生命周期

生效条件为活跃来源的当前控制者等于 `GameState.active_player`。只使用现有实际回合调度结果，无独立计时器、预算或永久免疫附件。来源进入时立即按当前玩家判断；沉默、死亡、回手、变形和休眠停止贡献，唤醒重新判断。复制得到独立物理来源；转控后保护新控制者的英雄，仅在新控制者当前行动时生效。英雄替换由原光环重算覆盖新英雄。

真正切换实际回合时，`refresh_turn_keywords` 先更新现有关键词贡献和缓存，再进入新回合的事件捕获。没有本条件来源时不改变旧刷新路径。它不触发新的事件，不增加回合，也不修改生命或属性光环层。原自然开始仍经过普通光环刷新、开始反应和抽牌。

结束效果仍在结束方的当前回合，直到实际开始后继回合才失去旧玩家的条件。额外本人回合保持条件成立；跳过的槽位不改变当前实际行动玩家，也不创造一次条件失效/生效窗口。这些是明确的内部时序政策，尚未国服校准。

## 伤害、恢复与玩家边界

本项只贡献既有免疫关键词，伤害和疲劳沿原防伤管线处理；疲劳次数仍按真实空牌库抽取推进。它不把其他生命损失或支付自动改写为伤害。原命中、目标资格及资源规则继续由相关内核模块负责。

快照保存原声明和已有贡献缓存，独立注册表恢复、clone、回放、选择暂停以及动作/选择失败回滚复用原解释器。玩家可以看到公开英雄免疫和合法操作，不获得完整光环声明、物理来源内部字段或全知状态。

没有新增模块、状态字段、关键词枚举、动作、事件或序列化字段；schema236、观察76、命令12和replay1保持。语义版本为 prototype-v270 / core-effects-v264，旧版本状态应使用其原引擎，不能把相同结构编号当作规则互换许可。默认306定义生产注册表指纹保持。
