# 每回合首张当前种族的原提交费用

本页记录公共表达和保存契约；实际进度、验证和下一项仅在[项目状态](project-status.md)及[机制清单](mechanism-backlog.md)维护。必要真实来源是[纳拉雷克斯，龙群先锋的完整原行及双语主面](../data/cards/native-first-dragon-cost-v1.json)。这些内部窗口尚未完成国服校准。

```python
CostAuraSpec(CostSpec(set_to=1, card_types=(CardType.MINION,)),
             first_per_turn=True, tribes_any=('dragon',))
```

这是已有首张类型费用光环的真实种族筛选扩展。普通存活随从提供原生印刷光环；仍拒绝任意授予、非友方、混合卡牌类型、其他额外筛选、融合载体、支付改写和周期条件组合。带种族的设置费用仅由已声明的首张筛选使用；普通持续种族光环仍只接受原有减法。费用设置为1沿原设置语义，即使原费用为0也设为1；原局部费用层、外部附件顺序和最低费用规则保持。

## 资格与原材料

当前报价对象按原 `tribe_state_for` 读取当前种族。已经提交的牌按其付款前冻结的印刷元数据与有序种族附魔判断，使用原 `normalized` / `apply_change` / `TribeState.matches_any` 处理Dragon、ALL、排除和重设。未知合格种族明确拒绝，不能默认为非龙；已知不匹配的当前对象不要求计算无关的首张龙历史。

原 `PlayRecord.submitted_cost.quote.quote_input` 已保存完整付款前附件，无需新增PlayRecord字段、事件扫描或可变玩家计数。`FirstPlayCostFact` 继续保存完整有序手牌提交前缀，仅在声明种族时增加同长度的完整 `CostQuoteInput` 元组及对应筛选。输入身份、玩家、卡面、类型和原前缀逐行一致；来源后来变形、失去种族、死亡或转控不会重写原提交。只有付款者当前实际回合、原提交时匹配的随从占据资格；非龙、其他类型、其他玩家和此前回合均不占据。

来源进入或复制不产生独立用途预算。已使用龙后再召唤来源，不能重获本回合优惠；沉默、死亡、回手、变形和休眠停止当前光环；唤醒、转控和复制按现时受益方的原历史重新判断。纳拉雷克斯自身不是龙，普通从手牌使用它不占据首张龙资格。

## 原起源边界

本批扩展沿[已有付费手牌首张契约](m2-first-play-turn-cost-auras.md)的接受窗口。原全卡生成物有独立 `GeneratedActivationReceipt` 和安装/主体进度，没有伪造付费手牌提交。它们不是该付费历史中的记录；本批没有从这项结构事实推定它们在国服是否消耗“首张”资格。真实标准间接来源接入时，仍须按该来源的实际出牌/生成政策补齐或校准，不能以本批的手牌计数证明所有起源完整。普通召唤及纯报价不制造手牌出牌。

## 报价、保存与信息

物理报价、生成报价、合法动作枚举和真实付款复用原管线。生成报价只判断假设新牌，不分配实体、移动牌、耗RNG或消耗资格；实际付款保留当时完整贡献。待选择的已提交首张龙仍占据资格；其来源随后离场不会改写已经支付的金额。动作失败及后续选择失败沿原完整事务边界回滚。

`CostContribution.first_play` 必须绑定原生光环的完整类型及种族筛选；普通未过滤贡献不能注入种族输入。紧凑事实重新计算资格，状态恢复另与保留的实际原提交输入前缀逐字比较，允许后续合法推进；修改某个旧输入但保持表面价格合理也不能通过。全部字段经过严格状态及帧编解码，不提供未签名来源认证。

玩家只取得允许看见的最终费用及普通公开信息，不获得原前缀、完整输入、贡献或分配边界。统一格式提高至schema356/core438，旧schema1～355须原引擎；观察90、命令12和replay1保持。没有新增Effect或payload类型，也没有新的持久状态账户。
