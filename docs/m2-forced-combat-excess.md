# 强制攻击中的过量分流

棘嗣幼龙EDR_453使用[完整固定卡面](../data/cards/briarspawn-drake-v1.json)及普通本人结束触发。主体交给已有`AttackRandomEnemyMinion`，保存原攻击者驻留，在执行时从当前活跃敌方普通随从抽一次；空池不抽样，不改为攻击英雄。选中的防守者也捕获原驻留，回手或重入场不会被同ID的新身体替代。

## 原攻击的明确政策

`AttackRandomEnemyMinion.excess_to_hero=True`传给`ForceAttack`，再进入原`ActionWindow`、`CombatDamage`和`CombatExchange`。默认值为false，普通手动攻击及其他既有强制攻击继续使用原完整伤害。真值只适用于有原窗口的敌方随从强制攻击，不能给无窗口裸战斗、英雄来源或友方战斗借用。

原宣告与交付保存同一布尔政策；原攻击事件、当前窗口、完成历史和待执行尾部共同核验。改目标只替换目标及其驻留，不能改变政策。已接受攻击在原沉默、变形、冻结、控制及离场规则下执行；攻击次数、潜行、攻击中免疫、取消和完成仍交原战斗流程，不为幼龙复制结算器。

## 一个同时健康批次

公共攻击先构造原互伤及已有相邻伤害请求。普通`damage_batch`验证并接受原攻击后，`excess_damage.prepare_combat_partition`只展开第一份攻击者伤害；反击与其他既有包保持在同一批次。

攻击者先按原实际攻击值和SOURCE规则报价一次，将`min(预算, 原防守者当前正生命)`分给原随从，剩余量分给其当前控制者的英雄。两份分别走TARGET修正、改道、圣盾、免疫、护甲和生命下限；第一份实际造成0或额外伤害都不重分余量。英雄余量为0时不创建第二份，零攻击沿原零战斗伤害规则，不凭空放大或消耗圣盾。改打英雄时直接结算一次完整原伤害，不再分出重复英雄包。

这与旧法术/地标分流共用`prepare_parts`及同批临时`PreparedHealth`，不把预算或私有包放进可挂起状态。SOURCE规则与法伤不会在两份交付时重复运行，COMBAT也不计入法术伤害。整批反击、分流及固有吸血完成后才进入事件反应和死亡检查；原攻击者在反击中死亡不丢失已接受英雄伤害或固有吸血。

一次性治疗转换若要求重新准备健康包，仍从原未分流请求重新报价整组，不能把已经分配的量再当作新的SOURCE预算。
