# 复生：满血并保留附魔

原生罪孽战马新增可空CardDefinition.reborn_policy，安装为可沉默的印刷复生行，当前实体与冻结死亡材料核对本体来源和政策；动态授予仍沿下方原入口。死亡/保留附魔/消费共用本页原执行器，印刷与动态重置差异见[后续契约](m3-native-reborn-fire-draw.md)。

这是原复生流程的一种真实返回规则。国服资料片说明列出满血并保留附加效果的复生赐福；本地 `EDR_100t9` 描述和 `EDR_100t9e` 附魔原行也表达这一差异。[国服说明](https://hs.blizzard.cn/news/24179067/)。32.4修复说明另确认：带此赐福的休眠随从，唤醒本身不应触发复生。[国服32.4说明](https://hs.blizzard.cn/news/24205006/index.html)。这些资料不代替当前完整结果池或精确国服校准。

实际执行、验证结果和下一项仅在 [项目状态](project-status.md) 与 [机制清单](mechanism-backlog.md) 维护。

## 声明与载体

原 [GrantKeyword](../hs_sim/engine/effects.py) 和 [GrantStoredKeyword](../hs_sim/engine/hand_keywords.py) 增加末尾可选参数 `reborn_policy`。默认 `None` 是普通复生；唯一特殊值为 `full_health_enchantments`，只允许与 `Keyword.REBORN` 一同声明。

同名字段存于原 [AbilityInstance](../hs_sim/engine/model.py)。动态授予必须是可沉默的非印刷关键词附件；原生声明则由印刷行承载，两者载体均须为随从；不能赋予英雄、武器、法术，不能作为其他能力的隐藏数据或未经支持的计时关键词。原来源、到期回合、消费和附件身份管理沿用。场上与存储效果、当前实体和冻结死亡材料均检查载体及字段类型，未知值明确报错。

必要隔离配方以 [完整原行证据](../data/support/full-health-reborn-basics.json) 固定回荡恐怖描述、附魔及淡水鳄。描述不是可出牌法术；专项通过普通诊断载体调用原存储关键词效果验证配方，没有把有限随从池或单一赐福包装成完整黑暗之赐发现。

## 原死亡流程中的差异

1. 原死亡检查点冻结 `DeathRecord`，包括当时的能力和附魔。是否满血保留附魔只从这份材料中的未消费复生附件确定；不读取后来改变的墓地实体。
2. 原亡语与复生队列、控制者、位置、容量失败和入场事件顺序保持。新实体从原卡牌定义及组件创建，并分配新身份。
3. 满血规则通过 [restore_reborn_enchantments](../hs_sim/engine/lifecycle.py) 重建新印刷本体，再调用原附件复制入口保留普通附魔和授予能力，重新分配附件ID。来源、顺序、授予能力消费状态和原期限保留；临时控制返回仍绑定旧驻留，沿原复制政策不转移。印刷攻击许可只在冻结原限制确实存在时映射到新印刷限制；原限制已移除的许可保持惰性，不能重新匹配后激活。
4. 原关键词消费入口消费新实体所有复生附件。外部光环重算后，满血规则设伤害为0；普通复生仍设为最大生命减1，不继承额外附魔。返回不是再次出牌或战吼，不再付款，不触发额外随机抽选。

沉默、移除和到期将特殊规则随整条附件撤销。当前复制携带规则，基础复制和原区域重置不携带动态附件。选择恢复、事务回滚、clone和回放沿用原解释器；没有另设返回调度器、关键词、持久账户、玩家动作或事件。

## 内部政策和待校准边界

新印刷本体按新实体初始化原生能力用途；授予能力按冻结消费状态继承。例如原印刷圣盾重新可用，已经消费的授予圣盾仍消费。已有期限不续期，外部光环不固化为附魔，复生能力自身不会因保留附魔而无限重复。这些是明确的内部继承政策，精确国服的印刷/授予用途、控制返回、准备与特殊卡面材料、休眠返回及到期检查点仍需校准。

本入口只由实际死亡调度，唤醒不走复生。没有扩大休眠期间死亡资格，也没有建立“休眠＋复生”独立组合模块。未注册主体、完整成对发现、其他赐福、当前正式结果池和完整来源仍按原未完成范围处理。

## 序列化边界

本字段由原结构序列化和效果帧编码保存。引入时为 `prototype-v256` / `core-effects-v250` / snapshot schema226，拒绝1～225；玩家观察76、命令12、replay1保持。新字段缺失或类型不符的快照不能静默取默认，重新计算哈希也不能绕过声明和载体检查。未签名快照仍不提供来源认证。生产代表包64和合成包3保持；此隔离配方不宣称最新炉石完整实现。
