# 印刷费用的支付账户

卡牌固有的生命值或残骸费用需要进入正常报价、合法性与支付流程。赤红汲取的卡文明确使用生命值；重生的翼手龙的完整本地卡文使用残骸，必要原行见[来源包](../data/support/native-cost-payment-basics.json)。[官方赤红汲取卡库](https://hearthstone.blizzard.com/cards/121011-blood-draw)的索引文本支持前者，当前直接页面渲染不完整，不能据此宣称精确国服支付窗口已校准。

本页描述声明与实现契约。实际执行、证据和下一项仅在[项目状态](project-status.md)和[机制清单](mechanism-backlog.md)维护。

## 不可变印刷声明

[CardDefinition](../hs_sim/engine/model.py)末尾`cost_payment`使用原`PaymentType`，默认`MANA`。声明只适用于可正常出牌的卡牌或可付费主动英雄技能；字符串、布尔、未知账户、选择专用选项、被动技能与普通初始英雄明确拒绝。它不是新资源、动态授予程序或卡牌关键词。

原[费用账户](m2-resources.md)负责`MANA/HEALTH/ARMOR/CORPSES`。报价在原固有数值层之后，以印刷声明作为局部附魔层的初始账户；未声明支付方式的减费/设费保持当前账户，显式`CostSpec.payment`沿既有附魔、光环、玩家修正顺序覆盖它。移除覆盖后回到印刷账户，不把替代支付伪装成手牌附魔、扣血或扣资源回调。

实体只保存原卡面ID和原局部附魔，没有增加币种缓存或附件。起始手牌、直接手牌/牌库创建、正常抽取、当前/基础复制、沉默与回手重置均通过同一印刷声明查询。变化卡面使用新卡面的声明。原生命周期负责清除或继承可移除修正，印刷支付账户不依赖这些修正存在。

## 同一报价与证明

[物理与生成报价](../hs_sim/engine/costs.py)均从固定注册卡面读取初始账户；合法操作、玩家手牌/技能显示、实际付款仍共享原报价。付款资格及扣款、支付事件、生命规则、残骸实际消耗事实、一次修正用途和事务均由原执行层负责；不引入另一个付款入口。

[冻结物理与法术费用](../hs_sim/engine/repeat_matching.py)及[生成费用证明](../hs_sim/engine/intrinsic_costs.py)也读取同一固定声明，重演完整局部和外部费用操作。伪造初始账户不能仅靠同时改写局部/最终账户通过校验。接受收据、待选前后恢复、克隆、回放和异常回滚使用原历史与帧。

支付声明进入注册表身份。默认法力声明不改变旧注册表指纹，普通卡牌和模块卡面都保持旧序列化形状；非默认声明参与指纹，不能用不同支付卡面恢复同一存档。`prototype-v260/core-effects-v254/schema230`拒绝旧1～229；观察76、命令12、replay1保持。

玩家正常看到自己已可见卡牌的报价账户，对手隐藏手牌不会因此泄漏印刷账户或私有付款事实。全知卡面声明、原费用证明、收据和执行帧不进入玩家DTO。

## 必要代表与范围

原行包保留全部三个本地`CARD_ALTERNATE_COST`来源，不能将三个标签数量当作全部机制分母。两种必要构筑实验为：5残骸、4/3、突袭/吸血的重生的翼手龙，以及3生命值发现法术的赤红汲取。后者只使用一个明确登记的寒冬号角实验库存，沿原职业/可收藏/来源排除查询，不称为完整标准或狂野发现池。寒冬号角复用原复原两水晶效果；原DB缺失`COST`使用零数值默认，不解释为新机制。

`JAIL_446hp`是完整保留的不可收藏技能原行，其当前模式和来源尚未确认，也没有完整实验适配；诊断技能只验证公共主动技能报价入口，不能冒称该原行已接入。原标签值1/3只在受审查代表中分别映射生命值/残骸，未知值明确拒绝。

生命付款沿原护甲、免疫/圣盾、濒死资格等本地政策；这些政策的精确国服行为仍需M6校准。完整正式来源、卡池和全部特殊费用优先级保持开放，没有开发组合机制或增加批量卡牌接入。
