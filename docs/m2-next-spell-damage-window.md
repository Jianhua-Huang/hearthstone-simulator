# 下一次实际法术的限定法伤窗口

BAR_064 天才奥术师和 BOT_531 星界密使要求“本回合你的下一个法术获得法术伤害+2”。这是玩家获得的一次待用加成，不能用永久全局法伤再提前删除来替代。实际执行与下一项仅在[项目状态](project-status.md)和[机制清单](mechanism-backlog.md)维护。

## 声明与领取

```python
PlayerEffectSpec(
    'spell.next.damage.two',
    'BAR_064',
    kind='next_spell_damage',
    spell_damage=2,
)
```

使用原 `AddPlayerEffect` 与完整玩家效果实例；加成为正整数。不接受倒计时、到期主体、触发、其他光环、重复或目标限制声明，不扩展跨机制组合。来源离场、死亡或沉默不会撤回已建立的玩家效果。

`spell_casts.note_payload` 是原手牌、重复、效果施放、抽到时施放和历史施放的公共主体接受入口。成功接受时，当前施法者全部待用实例原子移入该物理 `SpellCastRecord.spell_damage_effects`，并从玩家待用列表移除。先完成全部移交，再发布原玩家效果到期事件和施法接受事件；后续新的物理施法不能重复领取。失败动作沿原事务回滚。

反制与没有合法目标的尝试不接受主体，也不领取，这是显式的本地原型政策；精确国服消费时点尚未校准，不能以历史官方补丁说明代替此项证据。

## 结算期间查询

公共 `spell_damage_sources` / `spell_bonus` 保留普通法伤查询，另接受可选的 `cast_id`。无施法身份的全局查询不包含待用加成。匹配玩家且尚在结算中的施法可以读取自己的已领取实例；其他施法、已经完成或中断的施法不能读取它。

普通法术伤害按其实际来源查找活跃物理施法，随机分配伤害在既有整次预算报价时传递同一个施法身份。两条管线复用原法伤贡献，无新的伤害执行器或数值缓存。一张法术的多个伤害步骤均可读取；整次随机分配仍沿原规则只给总预算加成一次。

非伤害法术可以显式查询 `spell_bonus(state, player_id, registry, cast_id=cast.id)`，因此抽牌数量等既有行为可读取同一个窗口。新产生的独立施法和原施法结束后的延迟效果不能借用原加成。

## 生命周期与保存

尚未领取的效果必须属于当前实际回合，复用已有真实回合清理；不使用己方下一次回合倒计时。结束主体之后、后继实际回合之前退休未用效果，包含结束反应新增的当回合效果。领取后的完整实例留在私有施法记录中，供恢复和历史核对，已不占玩家活跃列表。

实例身份与获得顺序唯一递增，创建回合匹配原施法，规范状态拒绝同时活跃或跨施法重复领取。旧来源卡牌与实例配置必须已注册。完整施法记录使用共同反序列化函数，既覆盖主历史，也覆盖随机分配预算内的嵌套记录。

选择等待、独立注册表恢复、clone、动作回放和失败回滚沿原解释器。全知快照和内部领取收据不提供给玩家；玩家仅见原四字段效果 DTO，待用没有倒计时，到期事件为0。
