# 过载状态持续增加武器攻击力

B231 扩展原连续属性关系，读取现有过载账户，复用属性缓存、事件规范化和装备贡献。实际进度、验收和下一项仅维护在 [项目状态](project-status.md) 与 [机制清单](mechanism-backlog.md)。

```python
StatRelationSpec(
    operand=StatRelationOperand.CONTROLLER_OVERLOADED_MANA,
    layer=StatRelationLayer.CONDITIONAL_ATTACK,
    amount=2,
)
```

新操作数仅允许一个原生普通武器声明、条件攻击层和严格正整数加成。阈值、比较符和种族字段必须为空；非法载体、混关系、重复附件、期限、消费及动态授予拒绝。普通随从资格函数保持原语义，未扩展任意资源表达式或关键词授予。

纯查询读取武器当前控制者的 `overload_owed` 与 `overload_locked`。任一为正便给予固定加成，水晶数量不会倍增攻击；对手状态不替代当前控制者。转控和原允许的手牌当前复制重新读取新控制者账户，原来源ID仅保留身份用途。

这采用明确的本地 pending-or-locked 政策，完整本地 TRL_352 卡文支持“有过载水晶时+2攻击”方向，但不能独自证明两个账户的精确国服解释及所有显示窗口。本轮官方卡库入口没有返回规则文本，不宣称官方或国服口径已认证。

## 属性与刷新

贡献保存在已有 `conditional_attack`。最终攻击为普通印刷/有序附魔/光环数值加条件贡献后执行零下限；它不同于原护甲武器的最终赋值层。加成不写回印刷攻击或永久附魔，反复过载和解锁不会累积。原普通数值修改在条件消失后仍保留。

原资源事件前规范化同步更新武器和行动玩家英雄的 `weapon_attack`，然后捕获监听。非行动玩家武器仍可查询当前攻击，但没有该回合的英雄攻击贡献。法力事件、实际过载历史、待结算转锁定及解锁仍由原资源模块处理，没有第二个记账器。

## 生命周期与原战斗

出牌付款、装备、替换、物理转移、销毁和最后耐久磨损继续使用原流程。原区域复制接口仅验证其已支持的 HAND/DECK范围，本项没有增加已装备武器复制接口。冻结死亡记录保存原攻击；之后解锁不重算历史。

攻击声明待选完成后、伤害准备之前使用当时攻击。已经接受的伤害保持原数值，之后伤害监听解锁不会修改该次伤害或重新消耗攻击机会。原上下文保留它自己的过载账户和派生攻击，不用今天的状态覆盖过去。

JSON、模型和 FrameCodec 验证原生声明与当前缓存，选择恢复、clone、独立注册表回放和异常回滚沿原解释器。玩家只有可见攻击和合法操作，不返回公式、附件、缓存或全知工作帧；保存校验不承担未签名来源认证。

无新增 State/Player/Entity/CardDefinition字段或保存布局，仅有限枚举及机制语义改变。core-effects-v299更新机制指纹；prototype-v298、schema262、观察84、命令12和replay1保持，旧引擎不能解释新增操作数。

唯一必要实验适配为 TRL_352 舔舔魔杖，2费1攻击3耐久、萨满稀有；完整原始证据与pin见 [支持文件](../data/support/overload-weapon-attack-basics.json)。实际范围、证据和精确CN差异以两份台账为准，不能据此宣布完整正式池或最新版本支持。


## 普通随从的原生过载关系

电涌风暴的实际需求将同一个CONTROLLER_OVERLOADED_MANA操作数扩展至普通非融合随从：仅一个原生StatRelationSpec、CONDITIONAL_ATTACK及严格正整数amount。原纯conditional_attack继续读取当前控制者的owed或locked账户，最终攻击为普通数值加已有条件贡献并执行零下限；固定加成不随水晶数量或重复刷新叠加。已有武器路径、其声明和英雄武器贡献保持。

只在载体资格与纯攻击求值增加这一有限普通随从入口。原生附件、移除/复制/转控/回手/复生/沉默和异常回滚仍沿原生命周期；动态授予、融合/磁力载体、混关系和重复声明继续拒绝。没有新增账户、字段、公共Effect或保存布局，不能从该入口推导任意资源表达式与组合。普通随从与原Likkim可读取同一账户并分别获得自己的固定加成。

当前机制版本core-effects-v689，schema548/观察117及原命令/回放布局保持；原完整默认快照仅机制指纹及对应hash变化，旧存档需匹配原机制。pending-or-locked及精确数值显示窗口仍为待国服校准政策，新增完整卡面与内部测试不代替官方一致性或正式池认证。实际执行与下一项仍只在原两份台账登记。
