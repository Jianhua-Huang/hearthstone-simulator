# 每回合每第 N 个实际法术的费用光环

BT_255 凯尔萨斯·逐日者的本地原文要求每回合每第三个法术消耗1点法力。[官方23.0.3补丁](https://hearthstone.blizzard.com/en-us/news/23797160/23-0-3-patch-notes)也将旧0费改为1费，不能沿用早期数值。执行结果与下一项只在[项目状态](project-status.md)和[机制清单](mechanism-backlog.md)维护。

## 独立声明

```python
CostAuraSpec(
    CostSpec(set_to=1, card_types=(CardType.SPELL,)),
    every_nth_per_turn=3,
)
```

扩展已有周期费用声明，单一法术受益类型。间隔为至少2的整数，排除布尔值；与首张、种族、卡牌身份、能力筛选或支付账户不组合。来源继续为原生普通随从；动态授予、复合载体和混合谓词保持原拒绝政策。没有新费用处理器或玩家计数账户。

## 计数对象与暂定政策

原周期随从和首张费用继续使用付费手牌前缀。周期法术额外冻结原施法历史的完整 `PlayerSpellCountCostRow` 投影，不把一次付费手牌根当作全部物理施法。

本地政策为：同一玩家、当前实际回合、已经接受主体且未失败的物理施法各计一次，包含现有手牌、重复、效果、抽到时施放和历史起源。不等待主体全部完成；选择等待中的已接受施法也已计数。未接受主体、反制及没有目标的尝试不计数。候选法术尚未进入原前缀，序号为已计数量加1。

这是依据“施放”原文与既有物理历史作出的显式原型政策，官方上述公告只确认周期与费用值，**没有证明反制和各自动起源的准确国服计数窗口**。这些政策继续待M6校准；本契约不把暂定选择说成官方规则。

当序号能被N整除，原费用贡献执行声明的减费或设费。多个物理来源共同读取玩家序号，不能各获得下一张免费用途。来源进入不重置序号；普通随从出牌不增加法术序号；双方玩家与每个实际回合分别查询原历史。无需额外回合预算或独立时钟。

## 冻结费用与保存

`FirstPlayCostFact` 保留原完整付费手牌前缀，追加可空 `cast_rows` / `cast_history_length` 两个原始操作数字段，仅周期法术要求存在。序号从完整投影重算，不能外部填写。普通首张和周期随从必须保持空值，防止篡改计数依据。

所有原施法行连续、类型完整、时序和实体分配有界；已注册的法术卡面与学派逐行核对。恢复时与当前保留物理前缀绑定，不接受改写身份或撤回原已接受主体。原先尚未接受的尝试可以在后续合法接受或失败；当时冻结的费用仍按原窗口计算，不追溯改价。完整付款和接受状态继续认证报价窗口，不提供未签名存档的来源认证。

共同报价覆盖真实手牌、生成卡报价、合法操作和实际付款；后续施法、来源沉默、死亡、回手或转控不会改变已接受价格。来源当前生命周期继续走原能力层，没有来源本地用途计数。

选择等待、独立注册表JSON恢复、clone、动作回放和异常回滚复用原解释器。玩家取得可见的最终费用，不取得完整物理投影、付款证明或全知状态。
