# 玩家本回合的法术目标限制

RLK_218 银月城奥术师需要来源无关的玩家规则：“在本回合中，你的法术不能以英雄为目标”。这项规则进入原公共目标管线，不给英雄添加魔免，不在每张法术中补条件。实际执行、验收及下一项仅在[项目状态](project-status.md)和[机制清单](mechanism-backlog.md)维护。

## 定义与实例

```python
PlayerEffectSpec(
    'target.current.spells.no.heroes',
    'RLK_218',
    kind='turn_rule',
    target_policy='spells_no_heroes',
)
```

复用原 `AddPlayerEffect`、实例身份、来源、获得顺序和 `created_turn`，没有新增运行时模块、玩家账户或状态缓存。本目标策略必须指定该命名值；不接受倒计时、到期主体、触发、法伤、其他光环或重复声明，不开发组合。未知策略明确报错。独立的[手动出牌类型规则](m2-player-turn-play-types.md)复用同一种类和时钟，以互斥字段声明，不让类型规则误禁英雄目标。

`turn_rule` 没有己方回合倒计时，也不占奥秘、任务或持续目标区域。多个实际实例可以并存，共同限制同一玩家；显式移除使用既有接口。来源沉默、死亡、回手、变形或转控不会移动或撤除已经建立的玩家规则。

## 公共目标资格

`targeting.accepts_target` 调用原玩家效果模块的 `target_allowed`。规则按来源的实际行动控制者查询，只排除法术选择英雄，双方英雄都在排除范围。随从、英雄技能及其他牌型保持其原目标域；无目标伤害不会因此被禁止。实际目标查询、合法操作枚举、接受前验证与共享自动目标选择使用同一条件。

自动选择也采用这项排除，这是明确的内部政策；精确国服自动起源、随机和重定向窗口仍未校准。普通法术产生的随机或范围伤害仍是伤害处理，不把它误当成一次法术目标选择。

## 真实到期与恢复

普通回合清理在自然结束主体之后统一退休双方玩家当回合创建的规则，结束反应中建立的规则也在同一次真实清理中退休。到期反应建立的同回合规则沿原稳定循环继续退休，由原解释器步数预算限制；进入实际后继或跳过槽前再确认没有剩余规则。不会借来源寿命、玩家自己的下一次回合或新的额外回合延长限制。

状态中的活跃规则必须属于当前实际回合，不能伪造为旧回合存活。结束时发布原 `player_effect_expired` 事件，不新增事件类型。

普通法术已有完整的原付款和接受状态，包含当时的玩家效果，继续用它们恢复已接受目标。后来建立或退休的规则不会改写旧接受事实；只在实际重新选择目标时按原选择窗口查询。非**法术**出牌目标契约保持原实现。

选择等待、独立注册表恢复、clone、动作回放和错误回滚复用原解释器。失败的新动作不会留下规则；已经提交动作的规则在后续选择失败时保留。

## 玩家信息和版本

沿原四字段玩家效果 DTO 展示规则键、公开卡牌、`effect_kind='turn_rule'` 与 `remaining_turns`。存续时没有己方倒计时，字段为 `None`；到期事件使用 0，拒绝虚构的倒计时 tick。内部来源身份、获得顺序、注册策略和全知状态不提供给玩家。

注册定义新增 `target_policy`，默认空值不改变生产注册表指纹。结构/语义为 prototype-v271 / core-effects-v265 / schema237，旧 schema1～236 使用其原引擎；观察76、命令12和replay1保持。没有新 GameState/Entity/Player 字段。

## 必要代表与限制

只隔离适配 RLK_218，原卡面与完整来源见[固定 raw 和 pin](../data/support/player-spell-target-restriction-basics.json)。原文本为法术伤害+2；`SPELLPOWER=1` 是存在标签，不能把它当作实际法伤数值。必要适配明确设置法伤2并建立上述战吼规则。

正式卡池、其他策略和期限、特殊来源及精确国服窗口继续开放。本契约不宣称所有目标限制、全部基础机制或最新版本完整支持。
