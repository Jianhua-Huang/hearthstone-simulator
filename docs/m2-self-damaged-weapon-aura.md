# 受伤来源对当前武器的持续攻击力光环

独立基础契约 B34/U22。扩展原 `AuraSpec` 和 `aura` 附件，用[属性光环模块](../hs_sim/engine/stat_auras.py)计算当前武器贡献；原[属性刷新](../hs_sim/engine/resolver.py)、[事件前规范化](../hs_sim/engine/event_normalization.py)及[装备模块](../hs_sim/engine/equipment.py)共享结果。实际执行、验证证据和下一项只维护在[项目状态](project-status.md)及[机制清单](mechanism-backlog.md)。

## 声明与来源

```python
from hs_sim.engine import AuraSpec

while_damaged = AuraSpec(
    attack=2,
    target='friendly_weapon',
    condition='self_damaged',
)
# 普通随从 CardDefinition(..., auras=(while_damaged,))
```

原四个位置参数保持，新增 `target='friendly_minions' / condition='always'` 默认值，原友方随从攻击/生命、相邻和包含自身政策继续执行。新增形状只允许 `friendly_weapon / self_damaged`、正整数攻击、零生命与无位置选项；错误类型、其他条件或目标明确拒绝。没有通用条件表达式图。

新形状仅用于普通非融合随从的印刷声明。原扁平 `AbilityInstance` 保存 `aura_target`、`aura_condition`；`aura_spec` 属性由原数值与范围重建声明，没有重复持久化数值。新原生附件必须有来源、可沉默、未消费、无期限、无磁力归属；注册及恢复核对完整原生声明与数量，不能删去新范围字段使其变成旧随从光环。原 `GrantAura` API 保持无条件随从范围，没有增加条件授予入口。

来源条件读取物理载体自身 `damage > 0`。其原 `source_id` 只记录来源身份，复制体读取自身伤害；受益方取载体当前控制者的当前武器槽。来源须是活跃场上随从，休眠和非活跃建造状态按原能力政策排除。存在多个物理来源时各自贡献一次，不按卡牌名合并。

## 属性、健康与结算

贡献写入原武器 `aura_attack` 派生层，在原印刷与附魔数值之后、攻击零下限之前参与计算。没有永久 `Enchantment`、反复伤害叠加或玩家累计量。无武器时不存入未来武器；之后装备、替换或失去武器重新选择当前槽。旧武器离场前仍由原死亡记录冻结最后攻击和耐久，墓地实体随后清除外部贡献。

重复受伤不会增添层；部分治疗保持、满血撤销、再伤恢复。零伤害、伤害防止和过量治疗不激活。最大生命设值/增益、光环撤销的伤害钳制仍用原健康政策。通用光环刷新先完成原生命光环与钳制，再计算武器条件，避免来源被钳制为满血后仍残留贡献。

伤害/治疗结果及属性事件冻结上下文前，只重新计算武器贡献，及时更新活动方英雄的原武器攻击分量；没有事件、效果执行、附件分配或随机消耗。原随从属性光环和关键词外部来源不提前重新选择。该窗口沿用 `include_dying=True`，将死来源贡献保留到原死亡检查点；实际移出后撤销。这个细节是待国服校准的本地政策。

武器自身在非控制者回合仍显示有效攻击，英雄是否获得攻击和武器关键词继续由原装备回合政策决定。攻击次数、磨损、武器耐久消耗和准备后的战斗伤害包不另立规则。原攻击宣告待选后重新读取交付攻击；已经准备的主要伤害包保持原冻结政策。

## 生命周期、保存与玩家信息

沉默移除新附件；回手与变形使用原重置。当前复制保留伤害与印刷来源，重新分配附件身份；基础复制从健康卡面开始，沉默当前复制不恢复附件。转控立即改用新控制者武器，休眠抑制、唤醒按保留伤害重算。普通手动出牌与召唤安装同一印刷声明。

范围字段进入原附件的完整解码、快照、工作帧及回放。声明字段缺失、错误类型、非原生范围/数量、非法生命周期或陈旧武器/英雄派生缓存明确拒绝；恢复不重新授予或抽样。本武器攻击profile不增加 GameState、Entity 或 Player 字段。玩家接口显示当前攻击和合法操作，不返回内部光环声明、附件或全知工作帧。

当前 `prototype-v201 / core-effects-v195 / schema189` 拒绝旧 schema1～188，观察74、命令11、回放1保持。无属性光环的普通定义完整指纹保持；非空 `AuraSpec` 新增默认范围/条件字段，其指纹及附件格式发生版本化变化。

## 代表与证据边界

只接入 `CS2_221` 恶毒铁匠的完整本地 raw/pin [证据包](../data/support/self-damaged-weapon-aura-basics.json)，pin 为 `c3a29cb63a112723aed1c52182a6b343519c806060c7f75770559a5c7ee8f405`。5费4/6、中立普通亡灵，单一受伤时武器+2攻击声明；武器使用已有实验夹具。适配仅在隔离验证注册表中，生产代表包未改；`VAN_CS2_221` 仅保留历史资料。

[官方激怒调整说明](https://hearthstone.blizzard.com/en-gb/news/21614307)说明删除关键词时保留受伤期间的持续效果。[官方铁匠卡库入口](https://hearthstone.blizzard.com/en-us/cards/61-spiteful-smith/)可读取入口，但本次网页正文没有提取到动态卡牌内容；+2及当前完整卡面取自本地 raw，不能据入口认证当前国服补丁。精确来源/事件/死亡/攻击窗口、健康钳制与数值层顺序仍待 M6；其他条件、特殊授予/融合来源、U22整族、M0正式池和M7批量接卡继续开放。

装备武器时自身冲锋由[独立武器条件契约](m2-weapon-presence-keyword.md)表达；其GameState依赖另用Entity.conditional_keywords派生集合。此扩展不改变本页受伤profile的本地条件与生命周期政策，未登记的条件或新条件授予仍拒绝。

装备期间自身持续加攻击由[独立武器数值契约](m2-weapon-presence-attack.md)表达，Entity.conditional_attack只保存自身状态依赖。此扩展不改变本页既有profile的数值/关键词/生命周期政策，条件授予仍按原支持范围拒绝。

原生种族受益筛选见[独立冲锋光环契约](m2-tribal-keyword-aura.md)；本页既有自身条件和数值政策保持，新选择器不扩展本页条件授予范围。
