# 法术伤害存在条件的持续武器加攻

复用原 `StatRelationSpec`、`spell_bonus`、派生缓存、事件规范化和装备贡献。执行进度、实际验证和下一项仅维护在 [项目状态](project-status.md) 与 [机制清单](mechanism-backlog.md)。

```python
StatRelationSpec(
    operand=StatRelationOperand.CONTROLLER_HAS_SPELL_DAMAGE,
    layer=StatRelationLayer.CONDITIONAL_ATTACK,
    amount=2,
)
```

仅一个原生普通武器声明，严格正整数加成及条件攻击层；不接受阈值、种族、期限、消费、重复关系或动态授予。普通随从声明资格保持。没有新增状态字段、伤害执行器或条件表达式系统。

纯条件读取当前控制者的 `spell_bonus(state, controller, registry)`。默认聚合包括通用及学派限定法伤；合格总量为正便给固定加成，多个来源和较大法伤不倍增加成。现有来源金额非负。来源仍按原己方英雄/战场、active、存活、非待死亡及未消费政策筛选，普通玩家效果复用原查询。没有传入 cast_id，因此某次已接受施法专属的 next_spell_damage 不是当前通用持有条件。

[官方 31.6 更新说明](https://hearthstone.blizzard.com/en-us/news/24179332/patchnotes-zu-31-6)明确修复过学派法伤未使幽灵之爪加攻的问题，支持纳入学派来源。该历史证据不认证最新国服的全部显示、生命周期和战斗窗口。只新增本地完整 KAR_063 幽灵之爪的隔离实验适配；CORE_KAR_063 仅保留完整原始材料。

普通属性与光环层加固定条件值后再应用零底，不修改基础攻击或永久附魔。原护甲武器最终赋值层保持独立。原规范化在事件捕获前更新条件缓存及行动英雄武器贡献；装备、替换、销毁、来源沉默/离场/休眠/控制变化和现有手牌当前复制继续使用原生命周期。

攻击声明待选结束后，尚未准备的伤害读取新状态；已经准备的伤害保持原值。武器最后磨损和死亡历史保存原冻结材料，后来来源变化不改写死亡记录。JSON/typed 帧校验分别重算当前及冻结状态，重摘要不能绕过缓存、原生声明或重复关系守卫；未签名文件来源认证不在此接口内。玩家接口不暴露私有条件缓存、附件公式或恢复帧。

此项仅更新机制语义与枚举，保存布局、原型版本、schema 和玩家接口版本保持。完整正式池、国服校准与阶段整体验收仍开放。
