# 指定当前种族的持续冲锋光环

本契约扩展原关键词光环的受益者筛选，公共接口仍在 `keyword_auras.py`；冲锋资格、攻击次数和生命周期沿用原内核。实际执行、验证和下一项只在[项目状态](project-status.md)与[机制清单](mechanism-backlog.md)维护。当前为内部政策，尚未国服校准。

## 声明

```python
KeywordAuraSpec(
    Keyword.CHARGE,
    'friendly_minions',
    include_self=True,
    tribes_any=('beast',),
)
```

`tribes_any` 是唯一、不可变、非空字符串元组；默认空元组不筛选，保持旧英雄、场上和手牌光环。非空选择器当前只接受普通场上友方随从、`CHARGE`、`condition='always'`、非相邻范围。包含自身仍由原 `include_self` 决定，自身也必须满足种族条件。没有新增任意谓词、种族缓存、效果指令或冲锋执行器。

选择器表达必要原生声明：载体必须是普通、非融合随从，能力为印刷、可沉默、有来源、未消费、无期限、非磁力。完整原生声明、数量和附件校验复用原生命周期；保留来源卡面与复制附件的不同身份。`GrantKeywordAura` 不接受非空种族选择器，其他来源和关键词按真实需要后续处理，不预造关键词与种族组合矩阵。

## 受益者和窗口

每次原场上光环重算，在来源的当前控制者场面筛选。先沿原范围排除休眠、建造中星舰与地标，再调用 `has_any_tribe(registry, target, tribes_any, basis='current')`。双种族任一匹配；`all` 和排除使用原种族查询，不从已接入样本枚举种族。完整种族未知明确报错，不把未知对象当作非野兽，也不从匹配中悄悄删掉。

受益者获得的仍是派生 `aura_keywords`，与自身、永久和其他光环来源取并集，不创建永久关键词附件。种族改变通过原刷新点重新判断，改变印刷依据的池或历史消费者不受影响；来源自身失去野兽身份时仅失去对自身的贡献，仍可让其他野兽获冲锋。来源转控指向新的友方场面，受益者转控按目的方来源重新判断。

来源沉默、离场、变形、休眠等撤销贡献。沉默受益者保留外部光环，但移除可沉默的种族修改后重新判断资格。当前复制保留已有种族修改并分配新附件身份，基础复制与重置使用印刷身份；外部冲锋不会被复制成固有能力。唤醒、回手、重新出牌、死亡冻结沿用原政策，不新增死亡检查点。

普通手动出牌和召唤的野兽可以立即用原冲锋管线攻击；非野兽保留原召唤限制。获取、失去、重新获取贡献均不返还已消费攻击；成熟随从失去冲锋后仍可正常攻击。声明后等待选择的已接受攻击及准备后的伤害保持原交付政策，不新增攻击窗口。

## 保存与玩家信息

附件完整保存选择器；snapshot schema189 拒绝旧1～188、缺失字段、非法类型和重复选择器。原生范围的改变、重复实例与陈旧根光环缓存由原声明和稳定边界检查拒绝。捕获上下文按各自原状态校验声明；不据此声称所有历史外部光环缓存都新增了独立认证，也不认证未签名存档来源。

玩家只看到公共关键词、当前种族和合法攻击，不能获得选择器、附件身份、注册表指纹或全知结算帧。普通查询不改状态，异常和待选失败沿原事务回滚。当前 prototype-v201 / core-effects-v195；观察74、命令11、replay1 保持。旧非空关键词声明的指纹增加默认 `tribes_any=[]`，普通空声明保持。
