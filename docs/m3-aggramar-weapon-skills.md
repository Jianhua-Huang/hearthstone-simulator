# 阿格拉玛：当前武器与原攻击后的授予

[完整源记录](../data/cards/aggramar-weapon-skills-v1.json)保留复仇者阿格拉玛、泰沙拉克、维库执行者、三个技能和三个附魔证据，共九条原行。六个可执行卡面有十二个完整中英文官网观察；三条附魔仅保存完整原始证据，不注册物理卡、法术描述或独立附魔适配。技能的原 COST 缺省保留，描述费用零只按完整双语主面归一。

[适配器](../hs_sim/cards/aggramar_weapon_skills.py)只组合既有公共效果。战吼使用 EquipWeapon 装备真正的3/3泰沙拉克，普通召唤或场景放置不补战吼。维库执行者为完整3/3嘲讽随从，沿普通召唤、容量和生命周期执行；不为新泰坦增加标准构筑根资格。

## 三个技能

守护秩序向当前武器授予攻击完成后的抽牌触发；统帅风范授予攻击完成后的执行者召唤；迅疾挥剑增加武器两点攻击并授予原生“攻击时免疫”关键词。原卡面明确写“你的武器”，不按泰沙拉克名字筛选，也不将效果挂到阿格拉玛或玩家的未来武器上。

普通技能回调收到的是原接受快照，因此适配器以现有 InvokeBehavior 续接读取实际主体窗口中的当前武器，再交给 GrantTrigger、ModifyWeapon、GrantKeyword。迅疾挥剑的数值修改保存 EquippedWeaponReference；无当前武器时技能正常结束，不创建装备或未来授予。这个主体取值窗口及细粒度反应顺序属于已记录的本地政策，尚未当前国服校准。

三技能继续使用原泰坦行动和消费记录，不另收法力、不产生 CAST、不消费英雄攻击次数，也不重复执行战吼。物理武器上的永久附魔不会因泰坦沉默或离场而被移除；武器销毁和替换沿原生命周期退役，后来的新武器不继承旧授予。

## 原攻击、最后耐久与转控

攻击后回调使用 completed_attack 读取实际声明、接受和完成记录，要求原攻击者是该玩家的英雄，原战斗武器为承载触发的物理武器。回调不读取后来替换的装备槽，不响应随从攻击或对手英雄的攻击。实际使用了哪个武器与哪些主体已接受由原战斗记录、事件捕获和分离的 RuleContext 保留。

原执行器先提交攻击磨损，再捕获 attack_finished，随后进入普通死亡检查点，因此最后一点耐久也能捕获已授予的抽牌和召唤。已接受的主体可跨等待、武器退役及后续替换继续完成；复制、恢复、失败回滚和回放不再次消耗耐久或重复奖励。

物理转控使用既有 TransferWeapon，保留原实体和附魔，触发按承载武器的实际新控制者执行。迅疾挥剑的关键词沿现有武器对当前英雄的贡献生效，只保护真正攻击中的英雄，不保护普通效果伤害或防守；武器退役后移除贡献。历史曾出现的转控问题不作为复刻旧缺陷的依据，这里按完整卡面和现有公共生命周期实现。

## 范围

迅疾挥剑仍是两个普通公共效果的顺序组合，不另写附魔、伤害或攻击结算器。武器中途替换与技能/攻击反应的精确国服窗口、来源日志等继续记录待验证，不以内部一致性代替正式证据。完整十二泰坦参考的身份、权重和角色保持，尚未安装鹰泰坦池、完整职业奖励域、真实发掘 profile 或 WW_009。
