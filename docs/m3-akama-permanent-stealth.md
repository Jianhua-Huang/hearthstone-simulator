# 阿卡玛的原生永久潜行

[完整资料](../data/cards/akama-prime-v1.json)保留阿卡玛、终极阿卡玛和一条原来源证据，共三完整固定客户端原行及六完整双语主站面。原本体的 COLLECTION_RELATED_CARD_DATABASE_ID 精确绑定非收藏终极体；MIS_701只原始证据，不注册。原过去732成员与其他来源保持，具名物理依赖不是普通构筑或随机生成资格证明。

阿卡玛原体仍是普通可消耗潜行，亡语通过原 `shuffled`/`AddToDeck` 洗入确切终极卡面，按实际亡语控制者接受。终极阿卡玛在普通潜行标记之外拥有一个印刷 `KeywordAuraSpec(STEALTH, target='self')`，仅限 `always`、无位置/种族/身份筛选的独立自身来源。原关键词并集、活跃状态、附件身份和生命周期负责它的存在；不是攻击后再授予潜行。

core842/schema660为这个真实需求扩展有限原生声明。自身永久潜行进入原 `native_scope` 及声明/载体校验，额外 `GrantKeywordAura` 仍拒绝该来源；其他消费型关键词及默认范围保持原拒绝政策。`local_keywords` 合并这项原自身贡献，沉默/变形移除、回手重装、当前复制独立附件、转控和休眠/唤醒沿原执行器。

`consume_stealth` 仍调用原 `consume_keyword` 消耗普通潜行标记，只在实际词条消失时返回成功。普通攻击、强制攻击、随从能力伤害三个原入口据此发布已有 `stealth_lost`；未造成实际伤害的原分支保持跳过。普通潜行与永久来源可同时存在，普通标记被消耗后持续来源仍提供潜行。没有新增关键词枚举、GameState字段、玩家命令、事件、Effect/载荷或第二套战斗/伤害调度。

从其他来源获得的普通潜行仍按原生命周期消耗；明确去潜行/照明弹与罕见同窗源变化暂按上述连续原生来源的本地政策，精确国服交互待验证。固定补丁/热修和国服规则边缘继续暂缓，不能用这一有限适配宣称完整过去池或正式最新版本支持。实际进展、验收及下一项只维护[项目状态](project-status.md)和[机制台账](mechanism-backlog.md)。
