# 辛达苟萨奇闻家族与当前巨龙条件

TIME_852碧蓝女王辛达苟萨、TIME_852t1碧蓝之王玛里苟斯及TIME_852t3碧蓝誓言石的完整源和六个严格双语主面固定在`data/cards/arcane-dragon-fabled-v1.json`。官网原父子关系支持女王对应国王与誓言石；使用原FabledSpec/expand_fabled_cards，在30个物理原始名额内登记完整家族，普通原实体、洗牌、换牌与开局继续由既有管线负责。生成或召唤女王不追加原始伴生牌。誓言石已在P62接入，本族复用它，不重复注册。

## 共享原生条件及奥术费用

`repeat.witness.current_tribes`为现有纯控制者见证查询增加明确的当前种族依据，复用原tribes模块及完整有序面板遍历。`other_dragons`排除原来源实体，保留多种族、all及种族修改；未知必要种族明确报错。控制中的休眠/待清理占位计入，星舰建造物不计，是待国服校准的本地presence政策。旧current_face_printed配置保持原语义。

女王使用有限`NativeSourceCondition('controller_other_dragon')`和`CostAuraSpec(..., relation='friendly_arcane_spells')`，后者只允许普通友方奥术法术减2，无其他数值、种族、首次/周期或相邻组合。报价、生成报价、冻结费用贡献与真实付款共用原费用器；筛选依据实际卡面的奥术学派，最低费用0，非奥术和技能不借用此范围。原生资格沿普通附件安装、沉默、控制和当前复制生命周期。

## 国王的两次施法

付费手牌复用原SpellRepeatSpec及受控见证接受。自动effect/draw/history在原接受窗捕获相同当前巨龙条件；`NativeRepeatPlan`记录原物理法术、提供者、见证分配和完整种族修改，只有实际存在尼利费用来源时才附带原1费报价，不为国王制造无关费用查询。

原one_cost_casts继续器复用为RepeatAutomaticSpell，沿原payload和Finish执行唯一额外native_repeat。多个“两次”来源共享max2，已接受见证后来死亡不撤回额外义务；原目标、分支、条件、实际动作时钟、选择、回滚和回放仍交原施法解释器。私有计划与原接受、实际子施法和欠付尾部连接；结构核验不认证未签名存档来源。

## 誓言石与历史材料

复用P62原行为身份，先在原友方随从死亡库存按死亡时完整种族修改筛选，再以原有精确death_ids/原SummonCause交普通Resurrect。一次物理死亡是一个候选，按原死亡顺序尝试，新身体用普通复活材料；不读取后来活体种族、不召唤对方死亡或保留原已过期附魔。空库、容量和通知继续沿原机制。旧定义和源行保持，仅修正旧行为中印刷种族替代当前死亡种族的问题。

精确国服presence、费用/重复接受、自动施法和历史召唤顺序仍待M6；新私有计划及配置语义由schema415拒绝旧存档，没有新增持久模型字段。正式合法/生成池、雷鸫依赖闭合及全部标准可达支持仍独立。实际版本、验证和下一项仅见[项目状态](project-status.md)与[机制台账](mechanism-backlog.md)。
