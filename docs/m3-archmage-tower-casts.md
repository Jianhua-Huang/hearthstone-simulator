# 原法师预算与冰血哨塔的牌库施法

AV_283「大法师的符文」和 AV_290「冰血哨塔」沿固定本地过去法师名单接入。[完整原行与四份官网主面](../data/cards/archmage-tower-v1.json)由共享准备器核对固定目录、完整官网响应及缓存收据；本批不增加标准合法根，不把历史依赖注册等同于完整生成来源闭合。实际执行、差异和下一项只维护在 [项目状态](project-status.md) 与 [机制清单](mechanism-backlog.md)。

| 原牌 | 运行入口 |
| --- | --- |
| 大法师的符文 | 九费无学派法师法术，沿既有 `CastManaWorth` 连续施放印刷费用合计二十的法师法术，复用敌方优先自动目标。 |
| 冰血哨塔 | 十费无学派法师法术，沿既有三本人结束 `PlayerEffectSpec(kind='objective')`，每次实际结束主体从本人当前牌库施放另一张原物理法术。 |

## 资料和本地边界

[官网符文卡面](https://hearthstone.blizzard.com/en-us/cards/70011-rune-of-the-archmage/)说明二十费法师法术与敌方目标。[官方 22.0 已知问题记录](https://us.forums.blizzard.com/en/hearthstone/t/220-known-issues/76017)在 2021-12-10 更新中说明哨塔的发现应自动随机选择。[玩家原始目标报告](https://us.forums.blizzard.com/en/hearthstone/t/iceblood-tower-self-casting-face/90701)描述哨塔的炎爆术可能命中自己；这与普通自动随机目标相符，但不是当前国服完整规则证明。

[社区措辞解释](https://us.forums.blizzard.com/en/hearthstone/t/major-bug-just-cost-me-a-match/106067)把哨塔列入 “another” 排除同名卡的例子。本地据此排除当前卡面 ID 等于原程序来源 ID 的全部牌库实体，不按随机目标、实现数量或费用裁候选。重印别名、国服精确窗口与来源替换等仍未校准。符文的敌方优先在敌方合法目标为空时沿既有回退政策，零费循环沿原工程步数限制报错回滚，不伪造官方施法次数上限。

## 符文复用连续预算

已有学派预算与随从来源保持。`SpellManaBudgetLink` 仅新增可空 `mage_cast_id`：非空时是二十费、无学派过滤的法师法术域，查询使用 `class_mode='specified'` 与法师职业，不读取当前英雄职业。该字段绑定实际原法术 CAST、原来源实体、原卡面与玩家；原生适配仍由完整来源记录固定为 AV_283。

第一次接受及后续实际抽选必须处于原活跃法术中。每个子 CAST 保存原预算、剩余量、上一实际子 CAST 和原法术 CAST。印刷费用决定扣减；普通局部费用、临时费用与额外独立施法不另计预算。完整候选、身份、权重、来源排除及随机仍交给原池解析和原 `sample_candidates`，实际执行仍交给原 `CastSpell`；没有另一套施法器。

历史验证允许原法术完成或因终局中断，但每个子 CAST 必须晚于原接受、属于原玩家和回合，并早于该原法术的实际完成事件。原实体回手后再次施放形成新窗口，不能把后来子 CAST 重新挂到旧已完成来源。原完成收据、预算链与待执行续接共同保护剩余义务；实际重试按有效事件时间线核对，不提供未签名存档的外部来源认证。

## 哨塔复用持续效果与原牌库实体

卡牌的 `ongoing_effect_id` 接原目标区容量检查及实际法术载荷安装。时钟、独立实例、结束主体接受、重复主体及最后一次清理均沿既有 Objective 机制，与已有拉卡利故事同路；不另建计数器。当前本人尚未接受的自然结束计为第一次，对手结束不推进，精确官方时序仍独立待验证。

`CastRandomDeckSpell` 只为该实际三本人结束 Objective 增加无费用上限的分支，保存原完整 `PlayerEffect` 和原 `turn_ended` 事件。恢复核对原注册声明、原实例、来源、剩余次数与真实本人结束区间，实际执行须仍处于结束结算。已捕获主体的持续来源政策沿公共玩家效果约定；不借后来同名新实例。原普通有费用上限的随从偏好路径保持。

每次执行重新查询当前本人牌库：每张物理法术一个权重，排除原哨塔卡面，其余不按目标或价格筛选。选中的完整 `CardReference` 直接交给 `CastStoredSpell`；原实体离开牌库施放，不产生抽牌、手牌使用或生成复制。没有敌方优先，发现和其他选择沿普通自动随机策略。空候选不抽随机，持续时钟仍正常推进。

## 保存与范围

core808/schema629 保护新增预算链接字段和原牌库请求字段；Effect/payload 类型集合及 Entity、PlayerState、GameState 顶层布局保持。内容包 v712 接两张真实法术和一个 Objective 声明，不改变原标准根、合成部件或其他池的完整有序成员。等待中的原预算、原结束主体和原物理 CAST 继续由原解释器恢复、clone、回放和回滚；原预算、帧、完整实例和私有材料不得进入玩家 DTO。过去法师完整来源及其他专用池仍须逐项闭合。
