# 阿沙隆：两轮进化及后续出牌授予

本契约对应固定37.0原行中的`TLC_229t14`。父任务`TLC_229`双语官网主面均直接引用该奖励；父任务本身需独立接入。完整原行和严格双语观察见[来源前审](../outputs/card-integration-20261014/k151-source-preaudit-01/source-review.json)。实际进度和验收只在[项目状态](project-status.md)及[机制台账](mechanism-backlog.md)维护。

## 表达与选择

`AdaptAndRemember`捕获原战吼的玩家、`SourceAllocationFact`及原场上`MinionReference`，通过既有`RequestChoice(sample_size=3)`执行两轮三选一。十个选项始终来自原固定进化库存，未采到的选项也先核对完整定义；不按已有关键词裁池。两轮可选同一项，顺序和重复都保留。

每个选择奖励仍委托普通属性、关键词和亡语能力。已有`BuffCapturedMinion`、`GrantCapturedKeyword`及新增薄包装`GrantCapturedDeathrattle`在实际执行时守原驻留，再内联调用原附件执行器；它们不会追随离场重入、变形或转控后的同ID对象。原受益者失效时，其自身奖励跳过，已接受两轮选择和永久承诺仍继续。这些精确窗口为本地政策，尚需国服校准。

两轮选择及所选奖励反应完成后，普通玩家效果安装器一次提交一个完整程序。`PlayerEffectSpec(kind='adaptations')`只表示这一独立永久能力；`PlayerEffect.adaptations`为严格两项固定ID的不可变元组。普通玩家效果必须为空，程序不能借用期限、健康来源或费用绑定。原实例没有可复用的动态已选材料字段，新增此有限值避免创建一百种选择对声明，也不把ID塞进费用或健康来源中。

每次实际战吼独立生成程序，重复战吼逐次选择。安装前不暴露半个程序；新程序不会再次给已完成入场的阿沙隆自身授予。程序保留原物理来源卡面，后续来源死亡、沉默、回手、变形或转控不撤销、不转移它。

## 后续入场

付费手牌入口在反制和实际容量检查通过后、原随从处于`PLAY`时安装。随后沿原正常入场或磁力合并执行。磁力材料首先属于原组件，原`merge`负责将身材和可转交能力带到宿主；不在融合后向宿主补一遍。

现有全卡历史自动入口使用真实`PhysicalReplayEntryMaterial`及原召唤root，在原primary入场通知前安装。该origin有自己的接受证明，不伪造付费`PlayRecord`。数量额外体按既有独立打印材料进入，不被当作另一张打出；这项primary/extra政策及间接来源范围仍需国服校准。普通召唤、招募、复生、复活、复制和巨型肢体不新增出牌授予；当前复制若已携带原附件，则沿原复制规则保留。

入场属性与能力共用普通附件安装函数。默认公开效果的资格、通知和检查点保持；只有已验证原出牌入口以内部调用安装原材料，再交原入场公告。没有额外的效果解释器、回合计数器、伪造动作或影子出牌记录。临时潜行的截止按原授予玩家通过公共owner时钟捕获，来源或受益者后续转控不重绑。

## 活性孢子、保存与信息

活性孢子为原受益者安装普通可移除亡语；每次实际亡语以原死亡位置、玩家及实际来源建立含两个植物成员的`SummonOrderedGroup`。实际数量、每个成员入场、容量、等待、死亡及回放沿原公共管线，植物不因普通召唤重新获得永久程序。

新实例材料由严格状态解码器核对，实例种类须匹配注册表；续接还核原来源分配和完整选项。快照schema357拒绝旧1～356；core439保护新效果及入口语义。玩家观察v91只为这一公开程序增加有序固定选项ID，保留原DTO隔离；不输出全局附件ID、宿主实体ID或私有来源证明。

这些是内部表示与执行契约，不能代替M0正式标准池、完整可达内容、M6国服实测或阶段/发布验收。旧进化配方的历史来源和数据保持，旧原型结果不据此变成当前正式支持证据。
