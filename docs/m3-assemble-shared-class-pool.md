# 拼装职业共用参考池

本地共用池取自已保存的 [HearthPwn 职业名单](https://www.hearthpwn.com/news/12750-assemble-pools-try-assembling-a-minion)。只解析各职业共用池的图片身份，跳过逐卡演示脚本；12 个栏目声明数合计 218，对重复的多职业身份去重后为 214。逐卡演示的 212 个身份是这个集合的子集，不将演示程序当作正式服规则。完整来源响应及提取结果留在 K543/K547，运行清单为 [assemble-shared-classes-v1.json](../data/cards/assemble-shared-classes-v1.json)。

每个成员绑定完整原行、原生定义、池元数据及原拼装模板或投影摘要。214 个身份均已有执行定义，含 199 个随从模板和 15 个其他卡种的投影；没有重新实现卡牌主体。职业栏目与实际印刷职业加中立的筛选结果完全一致，因此共用一个完整成员池，沿既有职业、费用、种族和效果限定查询。每个物理身份使用本地单位权重，不重复累计多职业栏目中的同一成员。

原来源池使用独立实验目标且 complete=false；[宿主绑定 v3](../data/cards/local-special-pool-bindings-v3.json)核完整来源摘要后复制到统一本地目标。complete=true只表示这份声明的本地库存完整，不代表官方穷尽、逐生产者精选差异或精确权重已确认。拉夏的被动技能池仍为独立未确认域，不能借普通拼装池替代。没有新增狂野构筑资格。

接入完整名单时，实际生成暴露了旧片段只逐批声明部分效果体触发范围的问题。[效果体上下文清单](../data/cards/assemble-shared-body-contexts-v1.json)对 175 个已有无手选目标的效果体，按这 12 个真实生产者实际可达的窗口补接声明；173 个原已支持战吼，另两个是直接状态操作的延后调用。前文本仍负责全部事件、条件、次数及生命周期，后文本仍组合原公共效果。没有新增 175 个机制，也没有开发任意假想卡牌组合。双事件前缀保留全部原生事件，不能只审核显示的首个事件。武器等投影沿用同一个严格摘要保护的扩展入口。

读取本随从攻击力或位置的效果，只能在本随从自己的死亡中使用该死亡记录；其他随从的死亡不能替换当前来源的数值。原生条件、无变化结果消除、手选目标规则和本地争议配方限制继续保留。BE_734 的待确认亡语范围没有被本批扩展解除。

当前依据仍有边界：具体生产者可能使用更窄的精选名单；官方非均匀权重、特定无意义配对排除及版本对应未核定。另已取得一份自述约 259 条的[中文社区参考](https://www.iyingdi.com/tz/post/5758699)，尚未逐条对齐身份和角色，不能将 214 宣称为全池。标准内容能够生成的过去卡牌等后续候选域仍需接入；本池可用不表示所有跨系列生成链已经闭合。

本地运行只读取仓库中的固定数据。三个按原始字节核验的来源 JSON 在 `.gitattributes` 中禁用换行转换，避免 Git 检出改变来源摘要。实际验收及下一项仅在[项目状态](project-status.md)和[机制台账](mechanism-backlog.md)维护。


## 扩展社区参考与真实身份

本地宿主现另取[旅法师营地的公开组件名单](https://www.iyingdi.com/tz/post/5758699)，12个职业/中立栏目合计264条，按实际卡牌身份去重为259，包含旧214个身份。新[完整库存](../data/cards/assemble-extended-reference-v1.json)逐条保留栏目、图源系列、名称/卡种/印刷数值、候选别名和完整固定原行。Core图库有独立Core身份时使用该身份；统一Core图库下没有独立别名的保留实际原ID。BAR_551与WON_317由图源系列区分，没有按现有适配选择别名。缺失的零攻击字段仍记录为原源省略，不冒充原行明确给出0；英雄图面护甲与英雄生命值分开处理。

259条包含239个随从模板、19个其他卡种投影和泽奥图BE_790。泽奥图完整留在源库存，执行时由既有用户授权限制排除，不通过缺适配推断不合格。新身份WON_317使用其实际物理ID；完整双语主面互认copyOfCardId后沿用OG_330的原生亡语和卡组身份，没有重写随机生成器。新池使用独立来源目标；[宿主清单v4](../data/cards/local-special-pool-bindings-v4.json)选择该259条来源，原214条来源及旧清单保持。

效果体接线按12个真实请求在11种英雄职业下的职业、费用、种族及角色资格查询。允许其他职业获得这些来源时继续按真实当前职业筛选，法师指定首件的例外保持。222个旧效果体补接所需的2013条时机声明，全部无手选目标；已有事件条件、原生用途、实体生命周期、公共结算和BE_734待确认亡语范围不变。包含在普通战吼/亡语/开始窗口缺少声明、原先可能仅被视为不匹配的效果体。这里是实际成员和实际请求的接线，不新增独立组合机制，也不以无异常构造代替效果执行。

此来源仍为社区参考：逐生产者精选范围、正式穷尽性及非均匀权重未确认，本地按每个物理身份一份权重。作者另列拉夏14项并明确仍缺1项；[证据名单](../data/support/rajh-published-members-v1.json)独立保存，尚未绑定成被动技能池，也不由普通随从模板推断技能上下文兼容。过去内容、卡包和僵尸兽等域继续独立处理；本地complete只表示声明库存闭合。版本对齐和待验证规则边界按用户要求暂缓。


拉夏已知14项现另接[独立被动技能参考池](m3-rajh-known-passive-pool.md)，报告未知第15及原费用窗口的高费首件限制仍保留。旧普通组件名单与演示不代替该域，原3兼容源不额外混入14成员；正式穷尽性、角色和权重仍未确认。
