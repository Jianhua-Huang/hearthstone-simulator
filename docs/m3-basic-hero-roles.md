# 基础英雄、默认技能与指定衍生物

本契约描述规范默认角色的接入方式。实际批次、验证结果、差异和下一项只在[项目状态](project-status.md)和[机制台账](mechanism-backlog.md)维护。

基础角色不是正常手牌英雄牌。完整源行的HERO_POWER引用决定initial_hero_power，职业保持一致；构筑仍须校验所选英雄、技能、职业、符文及完整套牌。显式Scenario可以配置技能，但不能据此认证默认角色的合法构筑开局。默认头像之外的皮肤、强化及替换技能须分别核实来源和实际需求。

构筑内容装配器可以向历史代表注册表传入有限initial_hero_power_bindings，并显式defer_validation=True延后跨包引用检查。仅允许给未绑定的基础英雄添加初始技能，不覆盖已有绑定或其他卡面字段。外层完成依赖注册后必须registry.validate()；未链接注册表仍不能freeze或生成有效指纹。默认代表工厂不传这些参数，维持其原内容与指纹。此选项不是运行时或存档开关。

卡牌配方见[完整固定源](../data/cards/basic-hero-roles-v1.json)和[适配模块](../hs_sim/cards/basic_hero_roles.py)。稳固射击使用无目标的HERO_POWER伤害；次级治疗术使用普通角色目标和HERO_POWER治疗；恶魔之爪使用已有当前回合到期的英雄攻击附魔。英雄技能伤害及治疗不借用法术伤害加成，特殊目标许可仍由其真实来源单独处理。

图腾召唤从灼热、石爪、空气之怒、治疗四种基本图腾中排除本方当前控制的同身份，再通过SummonByCard随机交付；对手图腾和其他图腾种族不排除候选，同身份被沉默仍占该身份，变形后按当前身份判断。完整四种均在本方时，玩家可见的使用规则拒绝手动激活；满场沿原技能容量检查，在付款前拒绝。候选由公开战场决定，不读取对方私有信息。实际召唤cause、完整原候选和随机仍归公共生产者及恢复证明管理。

空气之怒的法强、石爪的嘲讽及灼热身材直接声明；治疗图腾只在控制者结束回合时，用普通治疗批次治疗全部友方存活随从，包括自身，不治疗英雄。力量图腾作为历史池证据保留，不冒充当前基本图腾。此身份依据[官方29.0池变更](https://hearthstone.blizzard.com/en-gb/news/24064735/29-0-patch-notes)，不据这条历史新闻认证后续国服全部热修。

食尸鬼冲锋通过原归因召唤接通已有完整食尸鬼卡面：冲锋及控制者结束时消灭属于原印刷能力，沉默和转控沿原生命周期执行，不另加不可移除的延迟消灭标记。原死亡管线结算尸体。[官方职业说明](https://news.blizzard.com/en-gb/article/23852696/death-knight-deep-dive)佐证基础技能及衍生物；具体特殊激活、复制/换面及精确国服时点仍须对应来源和校准。

公共目标、支付、攻击、召唤、死亡、区域、时钟与玩家DTO均复用原内核。不得为显示动态文本虚构默认目标权限，也不得将未实现技能或衍生物注册为白板。正式标准池、皮肤/强化映射、全部实际可达内容及国服执行证据不能由本契约的有限角色范围推导为完整。
