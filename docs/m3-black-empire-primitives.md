# 黑暗帝国阶段的基础效果接入

本契约只说明真实卡牌如何复用现有机制。实际执行、证据和下一项仍在[项目状态](project-status.md)与[机制台账](mechanism-backlog.md)维护。预载卡面、内部接入、正式生效和国服时序分别记录，不能互相代替。

`data/cards/black-empire-primitives-v1.json`保留完整原行及双语主面。官网整页响应只作为逐卡主面证据，不认证完整正式池；卡牌运行不读取提取outputs或联网。旧来源绑定候选阶段保持固定，不按日期悄悄换池。

## 支付与普通主体

重塑之砧通过原`cost_payment=ARMOR`报价和支付，再用普通本回合英雄攻击增益。不手动扣护甲、不以生命或法力补余额，不另造费用账户。

冰冷异常保留敌方角色目标，顺序交付原冻结、护甲和抽牌；前一步及其反应完成后才推进下一步。螳螂妖先驱在战吼主体读取当前有效装备，再交普通属性与突袭授予。祖拉玛特的仆从复用普通可用时随从目标和沉默，空域仍可使用随从本体。

## 印刷关键词和亡语

膨水鳐、拼接骑士声明普通剧毒和吸血。托维尔先锋的战吼与亡语分别调用原护甲获得；不把两种实际激活合成一个次数。

不稳定的原型机明确保留原缺失ATK字段；两份官方零攻击主面验证后，以显式零声明建立本体。其复生及亡语分别由原生命周期与手牌随从批量增益处理，不为该牌造复生副本或专用计数器。

晶石魔像使用原嘲讽、复生和普通英雄治疗亡语。复生后的实际新体、已消费的复生和每次真实亡语都沿既有执行器。

## 来源触发与费用光环

始生浮龙与OC91战车绑定原完整出牌记录，只响应本人另一个已使用随从；自身使用和仅召唤随从不替代该事实。属性增益与抽牌仍交公共效果。钢铁活化者只响应本人英雄实际正护甲获得，一次获得通知抽一张，不按护甲点数多抽。

喉魔异教徒仅声明`CostAuraSpec`的双方普通法术加费。报价、支付、叠加、沉默、离场和恢复复用原来源层，不逐张改写手牌基础费用。

这些表达没有新增公共Effect、payload或对局字段。精确国服窗口、完整新阶段合法/生成池、热修集合、实际可达内容和阶段发布验收继续独立闭合。

## 物理属性、费用与原生命值结果

`data/cards/black-empire-stats-v1.json`继续保留十三个完整原行与二十六份双语主面。暗影之舞原行缺少COST，零费用由两份完整官方零值主面和显式声明确认；石头穴居人只规范已核对的代理显示标记，原规则及数字保持。

型如泰坦先沿原物理随从检索，再给此时手牌中的当前野兽加属性，因此实际抽到的原野兽也进入增益。不可知者只将本人手牌中当前带连击的随从设为6/6；弗蕾亚捕获本人手牌和牌库的当前野兽引用及现有属性，再由普通存储增益翻倍，已有增益也参与。两个属性操作均保留原实体、原费用及各自区域范围。

腐蚀者扎卡兹捕获本人手牌/牌库中的原随从与法术，逐项交付普通永久费用附件；当前场上、武器及对手不在范围内。飞翼影魔通过原自动抽样选择一个原手牌暗影法术引用，再交普通减费；候选为空时不创建抽样。恢复沿原队列与区域驻留证明，不重新扩大候选或重复修改。

泰坦猛击者直接声明现有敌方场上随从计价，正常验证、支付及突袭/风怒由公共机制负责。指虎乱斗打手在战吼主体读取当前护甲并使用普通增益；始生怪熊读取本体当前攻击力交给本回合英雄增益；觅食的狐龙在自然亡语读取原死亡攻击力，主动亡语读取原载体当前攻击力，再沿普通抽牌执行。

暗影之舞同窗捕获未受伤敌方角色并交原伤害批次。星界坠雨为五次有序续接，每次从新局面提供敌方随从候选和法术伤害；死亡及复生完成后，新体可以成为下一次目标，空域仍沿原跳过政策。虚渺延火先造成原法术伤害，再从独立宿主提供的完整`constructed.minions`域召唤三费随从；不触发其战吼，不从已实现子集拼池，未知合格成员仍明确失败并回滚。

石头穴居人的六点伤害使用原`on_result`生命值结果窗口接受存活奖励。原目标存活（包括护盾挡伤）时接受普通生命增益和嘲讽；原目标致死后的新复生体不改写结果，较晚普通反应移除原存活目标也不撤销已接受奖励。卡牌层不增加生命、死亡或支付执行器。
