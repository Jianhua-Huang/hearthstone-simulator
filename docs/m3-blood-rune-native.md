# 上一张牌的符文与原召唤组攻击

本契约说明畸怪符文剑、紧急手术和通灵护士的真实表达。[完整源包](../data/cards/blood-rune-native-v1.json)保留两根、一张固定衍生物及两条附魔证据。实际进度、验证、差异和下一项只在[项目状态](project-status.md)和[机制台账](mechanism-backlog.md)维护。

## 原印刷符文

畸怪符文剑使用真实 `BattlecryRecord` 和公共 `played_cards`。普通手牌战吼以其自身 `play_id` 为排他上界，防止新武器自己的鲜血/邪恶符文使条件永远成立；没有新手牌使用的触发读取当时实际最新使用历史。

上一条本人手牌使用的 `FrozenPlayedFaceFact.metadata.runes` 是依据，独立检查邪恶和鲜血是否至少一枚，分别通过原 `ModifyWeapon` 增加一点攻击或耐久。符文枚数不重复增益。没有上张使用时无奖励；被反制的使用仍计数，召唤、英雄技能和效果施法不伪造新的手牌使用。跨回合不清除“上一张”的历史，后来实体变形不重写原卡面。缺失元数据明确报错，不猜无符文。

## 固定原召唤请求

紧急手术原生法术主体捕获接受的敌方随从 `BoardPresenceReference`，依次发出四个已有 `SummonByCard` 固定请求。每个请求保留实际法术归因、数量、容量、交付和普通反应，再执行有限 `AttackSummonedGroup` 续行。

`SummonAttackProfile(card_id, token_id, count)` 冻结真实法术、真实衍生物和请求数量，进入注册表只读视图与指纹。没有声明时显式拒绝。续行保存原 `RuleContext` 与目标驻留，校验活跃原施法、接受目标和状态前缀，通过已有 `original_summon_groups.recipients` 精确连接完整原请求及成功记录。

来自原四个请求的数量额外交付属于该原组；早已在场、嵌套召唤或后来重新入场的同名物不能仅凭名字加入。全满时的真实失败请求也保留，不能裁掉失败请求而声称原组完整。该有限续行不启用历史预留的通用整组选择/producer控制器，也不建立另一个可变账户。

## 普通强制战斗

续行把每个成功原入场的连续驻留和原敌方目标交给已有 `ForceAttack`。受击者同驻留变形仍跟随；转控后由当前战斗关系决定是否可执行；死亡、离开或再入场不重绑旧攻击，也不随机换一个新敌人。未执行攻击的真实护士继续留在场上。

通灵护士是官网固定 `JAIL_454t`，二费3/1亡灵、吸血，没有额外突袭。强制攻击按原战斗、声明、拦截、伤害、死亡和吸血流程执行，法伤不会增加战斗伤害，不额外伪造治疗。

当前明确本地政策是四次召唤及其普通反应先完成，再接受原组攻击。因此只有一个空位时只产生原先可交付的身体，后来战斗腾出空位不追补失败请求；原数量额外成员亦参与。确切召唤/攻击先后、容量及数量窗口仍待国服对应证据。卡面的“四个”不能独自认证这些时序。
