# 失火：原抽牌组的手牌销毁期限

WORK_026「失火」复用原物理抽牌组与手牌截止机制。它是三费火焰法术：抽三张牌，三回合后销毁其中仍在手中的牌。完整原行、三份附魔证据和两份官网主面见 [源记录](../data/cards/burndown-card-v1.json)。资料以共享 `tools/card_batch.py prepare` 核对固定完整目录及官网完整响应缓存，附魔只作证据，不注册成可独立使用的牌。实际执行、差异和下一项仅在 [项目状态](project-status.md) 与 [机制清单](mechanism-backlog.md) 维护。

原 `DrawPhysicalGroup` 接收三个普通 `DrawGroupSlot()`；每次抽牌、疲劳、满手烧毁、抽到即施放与额外补抽，均沿已有 `draw_one`。新增有限奖励 `destroy_drawn_after_ends` 仅接受这三个普通槽和三次本人结束，不能附加检索、延系或重复奖励。原已支持的费用、复制、类型奖励不变。

原三次根抽牌全部完成后，将各自 `DrawGroupArrival.hand` 的有序非空原引用交给一次 `ScheduleHandRemoval(..., retirement='destroy', cards=...)`。它使用原 `DrawRecord`、实际原入手及 K646 转换结果，不按当前手牌名称或全局最新抽牌寻找目标。原 `arrival_reference` 沿该根唯一的 `replacement_id` 链取最终实际入手，抽到即施放的原墓地牌不成为目标；补抽并不新增根槽，其最终手牌承接这一根的结果。已有同名卡与普通反应中的额外抽牌仍排除。原抽牌变成香蕉时，期限绑定实际香蕉；原链最终满手或疲劳时没有手牌目标。

原手牌截止执行器保存完整目标清单，计算真实本人自然结束次数；销毁沿 `DestroyStoredCard` 的非死亡路径与逐张结果，不制造弃牌、死亡或亡语。来源离开墓地不取消已接受期限。使用、离手重入、转交与换面仍沿原严格 `CardReference` 驻留政策，不能用同名新体替换原目标。两个施放各自保存自己的原抽牌和期限。

本地时间政策复用 FIR_928：三次本人自然结束包含施放当回合尚未接受的结束，对手结束不推进。`WORK_026e3` 的原计数字段为三，但这不单独证明全部国服时序。先完成原组再统一点燃、原替代链最终入手承接期限、同手换面解除旧严格引用，以及结束监听期间才接受期限的精确先后，仍是待国服校准边缘；本轮按这些明确政策执行，不宣称官方完全一致，也不阻塞其余卡牌。

等待期间使用原 `CapturePhysicalDrawGroup`、`ContinuePhysicalDrawGroup`、`HandDeadlineRecord` 和销毁续接。恢复核对原根抽牌、实际入手、原手持引用和完整剩余义务，失败沿既有事务与 RNG 回滚。原内部帧、原抽牌材料与私有截止证明不进入玩家 DTO；仅已有公开计时字段按原政策展示。

core807 保护新奖励语义；schema628、Effect/payload 集合及实体/玩家/游戏状态布局保持。内容包 v711 仅新增这张实际可达法术和生成元数据，没有新增标准根或改变任何既有候选身份、角色和权重。过去法师完整生成来源及其他专用池仍须独立闭合，不能从一张真实入口成功推断整个卡池已完成。
