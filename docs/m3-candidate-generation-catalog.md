# 固定候选的独立生成元数据

[完整来源包](../data/cards/candidate-generation-catalog-v1.json)保存固定37.0数据和原候选政策的1188张完整原行。它覆盖现有PoolQuery需要的类型、印刷费用、职业、稀有度、种族、符文、阵营、子类型、学派、已知印刷关键词及战吼声明。实际执行、验证及下一项只在[项目状态](project-status.md)与[机制台账](mechanism-backlog.md)登记；候选范围不是已认证的正式标准范围。

`candidate_pool_rows()`不读取Registry.cards，不解析文本执行行为。主种族和已审附加种族仍由原解码器处理。原费用缺省的8张卡仅使用[逐张零费证据](../data/cards/candidate-printed-cost-evidence-v1.json)，核对完整原行及各自EN/CN官网卡面；其他缺值明确拒绝，不把None通用变成0。

已审具名布尔关键词使用固定映射。JAIL_890被俘的纳斯雷兹姆没有原TAUNT标签，但完整原文和两官网卡面明确有嘲讽，故仅此卡显式补充。FIR_959的“免疫火焰法术”是有条件的具体效果，不授予无条件IMMUNE；不能从被引用的加粗词推导自身关键词。准备等没有表示为Keyword枚举的机制不强行加入此表。

`register_candidate_pool_metadata`先核对全部候选，再登记缺失行。已实现卡的全部印刷查询字段须与独立来源相符，已有池行仍须与完整可执行定义严格相符；矛盾明确失败，不覆盖。构筑数量限制使用的deck_identity不参与生成筛选：已有Core别名和历史未指定身份保持，生成身份继续是原卡ID，不随意合并权重。

未实现卡只登记PoolCard，不创建CardDefinition、空效果或主体占位。宿主仍须提供显式GenerationContext和匹配PoolDefinition；本包不登记生产constructed.cards或正式standard池，不把候选目录包装成正式合法池。共享查询先检查全部合资格实现，再消费RNG；未知成员导致事务失败，不能从候选中删去。根卡目录外但标准对局实际可达的跨系列内容仍须按真实依赖接入。

疯狂的药剂师CORE_BOT_576只通过原生combo执行，不再占用战吼入口、历史或筛选。原目标条件、付款及连击接受交给公共执行器，原完整来源只修改一处配方entry。暮光神坛CATA_492保留印刷HERALD标记，原on_use仍是唯一主动入口，不因标记自动再执行兆示。原动态文本{0}和官网具体古加尔/Cho'gall卡面均保留。

地标定义和实体校验只为印刷HERALD标记开放有限例外；攻击、生命、受伤、冻结、战斗关键词和随从沉默等仍被拒绝。耐久、冷却、占位及使用结算保持。没有新增Effect、载荷、实体/状态字段或执行器；机制版本提升core400，快照结构schema322保持，旧core399快照需要原引擎。默认311定义及注册表指纹保持，构筑指纹绑定完整目录。

目录完整仅表示这1188候选在上述既有查询字段上有独立元数据。正式成员、禁限、热修、特殊生成政策、完整可达内容和精确国服规则仍需分别核实；现有特殊关键词门禁不是全部正式生成排除已穷尽的证明。

## 已核定的原生随机排除

固定原库中26个候选根具有`DONT_PICK_FROM_SUBSETS=1`。普通随机请求由原奇闻声明、任务等关键词门禁及三条原生身份声明共同处理：`CATA_EVENT_110`破碎的巨龙之魂、`JAIL_500`快刀乱斩、`JAIL_831`下水道之王。三条身份均在原完整目录中核对实际标记，通过已有`register_generation_exclusion`声明，不新增关键词或把这三张改为奇闻。巨龙之魂的适配器原本已经声明同一禁令；目录层也声明它，使未注册可执行代码时的资格判断仍独立于覆盖率。原集合幂等，完整注册表实际只新增后两张的排除。

该接口复用历史命名的`fabled_generation_exclusions`集合及已有指纹承诺，不修改公共内核。生成/发现使用完整宿主库存并在查找可执行定义、抽样之前应用禁令，不把禁用成员从原库存抹去。其它合资格但没有实现的牌仍报错。原任务特殊来源政策保持；这些声明不是对所有系列、载体和生成例外的穷尽证明。

固定`AddToHand`、原牌库抽取、正常打出、历史重施和原合法构筑不走普通随机候选门禁。实际光明之翼的生成、两张受限原牌的正常使用与相关保存/回放按各自原公共路径处理。这里的资格声明不创建生产`constructed.cards`池，也不认证正式国服合法池或完整实际可达；实际来源、验证及下一项只在原两份台账维护。
