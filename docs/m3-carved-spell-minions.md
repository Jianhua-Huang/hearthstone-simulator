# 树人保存的原法术与战吼施放

巴珊娜MEND_046及MEND_046t使用一个明确注册的CarvedSpellProfile。原始树人卡文保留完整`Cast {0}.`，官网仅省略动态法术名；tools/card_batch.py只允许完整记录指纹匹配的该树人显式省略此槽，不允许删正文、改数字或借用其他卡。原始数据、完整官网响应及归一化声明全部保留。

CreateCarvedTreants先通过原GenerationContext与版本化池查询全部合格自然法术。所有定义和目标表达在随机前验证，不能按实现范围裁池。按印刷费用，在三个固定槽位中逐次选取仍可补足剩余总额的候选，允许重复，合计12；零费候选保留且槽位减少保证终止。此条件抽样分布是明确的本地政策；无法组成完整三项的实验池显式报未支持，不伪造补差法术。

三个原法术ID先冻结，再分别交普通AddToHand创建三个1费2/2树人。carved_spell_id在首次创建/获取通知前绑定原独立战吼附件，满手仍走原逐卡溢出，不根据之后的手牌容量重新分配预算。树人不是发现结果，也没有额外法术手牌或虚构的付费出牌。

AbilityInstance与BattlecryPayload各只增加一个可选字符串参数。实际接受时冻结原法术，重复、另一次触发及历史重放复用原战吼载荷；其他载体重放时仍用原保存法术的目标声明。参数随current复制保留，base复制及普通定义重置清空；沉默移除当前主体，已接受的载荷保持。已知未刻印的印刷基础树人有明确空槽并产生空槽诊断，不执行未知法术。未知定义、错误学派或错误主体明确失败。

保存法术的目标域通过原共享目标查询投影到树人，作为可在空域打出的IF_AVAILABLE战吼；不把随从改造成法术，也不增加抉择关键词。当前抉择法术的非空目标声明须一致，分支仍按普通效果施法政策随机选择，无目标分支清除先前转交的目标。只有真实接受的战吼记录可发起CastCarvedSpell；付款、实体、法术历史、抉择正文、反应和回放全部走原CastSpell。

所有者通过已授权可见实体的body.cast_card_id了解保存的法术；对方隐藏手牌仍不获得此信息。参数原字段、宿主profile、全知状态和等待帧不进入玩家DTO。[官方36.0公告](https://hearthstone.blizzard.com/en-us/news/24287396/36-0-patch-notes)明确修复过向对手泄露巴珊娜法术的问题。玩家观察版本随可选公开body字段升级，命令保持原PlayCard协议。

[完整配方](../data/cards/carved-treant-v1.json)保留45原行、双语完整主面和43自然法术依赖。精确分配概率、抉择/目标接受顺序、空域、溢出、复制与重置等国服窗口仍待M6；内部收据不认证无签名存档的来源真实性。实际执行、验证和下一项只登记原两份台账。
