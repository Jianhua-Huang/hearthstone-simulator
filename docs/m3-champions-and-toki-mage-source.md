# 阵营勇士与托奇的完整已知法师来源

`data/cards/champions-of-azeroth-v1.json` 保存 WON_113、两个原始选择面及十三个必要既有依赖的完整原行，另保留二十二个官网主面观察。十张勇士各有精确原生定义；灰烬使者、贝恩和火球术使用原身份。LOE_077 只补由既有完整定义得到的生成元数据，不改变原战吼重复声明。

四费中立法术 WON_113 先经普通支付和 CAST，再提出一个普通选择。WON_113a、WON_113b 只作选择展示，不是德鲁伊抉择，也不作为物理生成卡登记。所选分支直接调用原 `GenerateFromPool` 两次生成，原费用附魔在发布入手通知前应用，每张减二、最低零费；满手沿普通生成爆牌，不重新抽取。

两个原始阵营库存均保留五项、权重一和父资料中的顺序：

| 阵营 | 原始成员顺序 |
| --- | --- |
| 联盟 | AT_072、EX1_383、EX1_559、LOE_077、EX1_350 |
| 部落 | EX1_414、EX1_016、EX1_110、RLK_593、BAR_080 |

公共查询按原有卡牌身份规范化顺序返回候选，原始库存顺序与实际候选顺序分别保存，不把排序差异当作缺牌。两个来源 scope 分别绑定原来源、查询、完整库存摘要及本地目标；未知来源、查询、缺成员或不同原生材料明确拒绝，不按可执行程度裁池。

父卡完整官网响应列出了原 childIds，但没有直接取得可独立认证的两个阵营子池。五/五角色采用这些原身份和角色资料的本地推断；两个选择面的单卡接口 404 只作为已记录的资料缺口。每张独立放回抽样、允许同名两张也是明确的本地政策，不能表述为官方唯一抽样规则。原数据、权重、角色依据和这些差异均保存在上述数据文档中，仍未国服校准。

`data/cards/toki-mage-past-source-v1.json` 保存固定完整原卡库、原过去系列政策、181 项法师或中立可收集法术的完整原行与 pin。这个范围是在原 179 项法师参考中加入 RLK_590 太阳之井和 WON_113 艾泽拉斯的勇士；所有实际可达依赖保留原定义与生成元数据。与原教师 44 项库存有序合并后共 201 项，原 44 项仍是完整前缀，每身份只保留一次，权重一。

本地 v15 宿主按实际来源开放 TIME_861 当前法师视图。普通生成资格排除 SW_450、ULD_433、UNG_028 三个主任务，实际 178 项；三个身份仍保留在 181 项原调查和 201 项共享库存中，没有删掉或隐藏。原法师 179 项独立来源、完整奥术 84 项域、其他库存及原教师德鲁伊 21 / 法师 24 实际视图保持。

托奇的三费 3/3 原生定义和独立返回程序不变。战吼沿原 `CreateIssuedSpellSet` 在接受窗口保存完整候选、三次实际选中及前后 RNG，再逐张生成物理原牌。原来源离场不会移除玩家程序；原三张实际法术均使用后沿原奖励交付返回一张托奇。WON_113 真正使用时仍提出自己的两阵营选择，并实际生成勇士，不用白板替代。等待、失败回滚、JSON 恢复、clone、回放及玩家隔离继续使用既有解释器和投影。
