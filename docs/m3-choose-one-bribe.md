# 腐毒贿赂的组合卡与原始版复制

固定37.0.0.255026完整源为JAIL_861腐毒贿赂及JAIL_861e附魔证据，见`data/cards/choose-one-bribe-v1.json`。两个严格双语主面对应根卡；附魔只保留原文，不注册可执行卡牌。

## 有限交付配方

根卡是普通2费法术，使用原宿主池和`PoolQuery(collectible=True, choose_one=True)`发现抉择牌。查询跨职业，正式标准资格和完整池仍由M0单独确定；未实现的合格候选在抽样前明确报错。

`DiscoverFromPool.paired_choose_one=True`只接受一次普通三选一手牌发现、无其他费用/赠礼/召唤配方。实际候选必须具有已登记的物理抉择声明。选中后，原完整发现结果生成两个固定请求：

1. 为本人创建新的印刷实体，携带现有`ChooseBranchSelection`的组合分支。
2. 按同一次原选中卡ID，为对手创建独立的普通印刷实体。

两个请求在首次获取反应前固定。本人沿原首要发现交付、真实收件与完成通知执行，然后交付对手的派生复制；双方分别使用实际手牌容量和普通烧牌规则。本人烧牌仍保留实际墓地收件，对手仍取得其普通交付，不改找已有同名卡。获取反应修改本人的费用或材料不会写入对手的固定原始版请求。

## 组合绑定

组合分支在新体首次`card_created`通知前安装。沿现有分支协议，法术允许hand/cast_effect/cast_draw/cast_history，随从允许hand/physical，武器允许hand；这里只复用已存在的类型范围，不新增武器代表或组合矩阵。

本人新体的合法动作受原组合分支约束，目标、费用、主体及接受证明仍由原抉择与支付流程执行。对手新体没有这份绑定，其他既有全局组合来源仍按原规则独立生效。当前复制继承原绑定，原始版复制及普通重置清除它；已有卡和定义不改变。没有额外法术重施放、独立数值附件、玩家计数器或第二套卡牌主体。

## 保存与边界

新增的是发现请求字段，core521/schema419明确拒绝旧执行格式；实体仍使用已有choose_branch字段。普通选择、完整原结果、交付配方、创建通知、恢复/clone/回放、错误选择回滚及玩家信息投影共用原解释器。历史普通发现、黑暗之赐复制、余项与延迟交付保留原入口。

内部使用真实标准版愤怒核对4点伤害/抽牌与单独支付，使用既有战争古树代表核对随从组合；实验小池不作正式标准池证明。精确双向交付窗口、跨职业发现资格、分支预选与字面附魔的边界，以及跨区/历史来源的国服交互仍待M6校准。执行结果和下一项仅维护在原两份台账。
