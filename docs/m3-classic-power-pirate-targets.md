# 英雄技能抽牌零费、海盗费用与真实条件目标

本批接入AT_027威尔弗雷德·菲兹班、AT_070天空上尉库拉格、BRM_029雷德·黑手、AT_122穿刺者戈莫克、EX1_573塞纳留斯，以及真实EX1_573t嘲讽树人。[完整资料](../data/cards/classic-power-pirate-targets-v1.json)保留十二条完整原行、十六个完整官网双语面、源响应与角色；[资料准备](../outputs/card-integration-20261014/k693-classic-power-pirate-targets/source-preparation-03.json)使用原共享工具。过去传说732个原候选的身份与顺序保持，不因本批覆盖程度裁池。

HERO_07bp生命分流复用原完整固定资料及实际技能定义、行为，不另造技能，也不将没有生成元数据的英雄技能塞入随从生成池。塞纳留斯的EX1_573a、EX1_573b两个选择与EX1_573ae附魔行只作完整原始证据；可执行依赖是具名树人，没有将选项伪装成普通可生成法术。

威尔弗雷德从原card_drawn通知读取实际DrawRecord，核对原来源、物理接收对象和玩家，再匹配同一来源、玩家、回合及动作的原已接受HeroPowerRecord。仅对原到手引用提交普通ModifyStoredCost set0；不追随离开原区域后重新入手的同一实体。疲劳、烧牌、没有到手的抽取不附加费用；自然抽牌、普通法术和其他来源不套用。一次实际技能的每次独立抽取各按原收据处理。原技能支付、自伤、选择和回放仍由公共执行器负责；来源退休不撤销已到达的零费附魔，沉默后的新抽牌不再授予。

来源明确的抽取替代链沿既有原抽取与到手引用连接。与其他抽牌监听器、变换到手及先前反应的精确国服排序仍记录为本地政策；不据来源猜测未记录的抽牌，也不将数据存在冒称官方校准。

库拉格只为原BoardMinionCostSpec增加有限cost.board-friendly-pirates-v1 profile，要求friendly范围。原序列化字段仍为scope和profile_id；实际完整战场、当前种族及all排除、数量、固有费用层、零费下限、提交前报价和原支付事实全部复用既有路径。手中本体尚未入场，不计入已付费用的海盗数量；后续反应移走海盗不重付或追溯改价。印刷冲锋走普通攻击入口。休眠普通随从的占位计数沿既有本地政策。

雷德·黑手复用PlayerTargetRuleSpec：只读本人当前手牌中的龙条件和公开目标的已知印刷传说稀有度，使用IF_AVAILABLE随从箭头。条件不成立时无箭头；成立且有目标时必须选择可用目标，允许己方传说随从。执行时再核实际当前持龙与存活目标，提交普通捕获引用销毁。未知稀有度或所需种族显式报错，不当作白板或从池里删去。对手隐藏手牌不参与判定。

戈莫克的同一审计目标接口读取本人普通随从占位，排除实际来源自身、地标和被动对象，按既有政策计入休眠随从。使用前的四个其他随从门槛控制IF_AVAILABLE角色箭头，执行时重核实际其他随从数量；满足后提交原4点MINION_ABILITY伤害，不取得法术伤害加成。没有新增另一套目标或伤害结算器。

塞纳留斯使用真实两个ChooseOneSpec分支。增益捕获实际活跃友方其他随从引用并提交普通+2/+2；树人分支通过两个有原SummonCause的SummonByCard，使用本地固定的原来源右侧、左侧位置和普通容量。来源已不在原战场时沿普通追加政策。选择合法性、原出牌一次支付、满场一棵或零棵、召唤通知与恢复沿既有内核。

在真实范达尔提供两项效果时，本地实现先召唤，再通过保留原play_id的普通InvokeBehavior重新捕获增益对象，使新树人也获得+2/+2。该顺序依据暴雪社区论坛的[玩家实际报告和讨论](https://eu.forums.blizzard.com/en/hearthstone/t/choose-both-effects/1822)，属于社区证据；不是当前国服工作人员规则确认。已检查的本地旧Fireplace实现存在先增益再召唤的冲突，因此没有照搬其顺序或代码。左右位置、分次接受窗口及中间来源变化继续明确为待校准本地差异。

这次公共形状变化只包含一个有限费用profile，core830/schema650拒绝旧schema，不新增Effect或帧载荷。测试小夹具直接使用原生命分流注册器与真实CORE_OG_044静态范达尔声明，比较新面、依赖完整定义和元数据，不复制技能或抉择执行器。实际验收、保全证据和下一项只维护在[项目状态](project-status.md)及[机制台账](mechanism-backlog.md)。完整过去池、MIS_701及其余专用域仍按原目标推进。
