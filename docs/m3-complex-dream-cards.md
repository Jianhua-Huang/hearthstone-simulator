# 复杂梦境依赖

`DREAM_02`伊瑟拉苏醒与`DREAM_05`梦魇使用完整固定37.0原行和原Dream职业；前者为自然，后者为暗影。梦魇原行没有COST，保持原数据并省略运行时cost参数，使用既有默认0，不伪造印刷标签。父来源的完整五项随机池见[固定来源契约](m3-fixed-dream-source.md)。

`BuffCapturedMinionWithStartTrigger`只表达真实数值授予及一次性的`turn_started`回调。保存原`MinionReference`、数值、原授予来源和已注册回调/条件；拒绝未知或未来分配、未知来源和未注册回调/条件。原对象已离场、换面或换控制方时请求失效，不重绑后来进入的对象。

同一个解释器步骤先安装普通一次性触发附件，再调用原`Buff`执行器应用数值与发布`stats_changed`，最后通知`ability_granted`。反应捕获时两部分均已存在；没有新属性计算器、全局计时器、状态字段或磁力分组。沉默、回手、变形和基础复制按原生命周期清除；当前复制带走当时的两个普通附件及原触发预算。`RemoveEnchantment`仍只承诺移除所选数值附件，不把普通附件假装成磁力组。

梦魇在实际施法时选择原施法者1或2的静态条件。原有限触发器捕获、重核及消费一次用途，原回调接收其完整已消费附件，从`trigger.source_id`取得销毁归属，再提交原随从引用给公共销毁执行器。其他玩家开始不消费，实际额外回合开始会消费，被跳过的机会没有开始事件。控制方改变不改写原施法者条件。接受后到销毁执行之间的驻留/控制变化遵循既有严格引用政策，精确国服窗口仍待校准。

伊瑟拉苏醒把两方现存角色放入一个普通法术伤害批次，法术伤害增益、圣盾、死亡均由原执行器处理。排除项为固定完整raw4392族的八个当前卡面ID，不按中英文名字判断，也不将八个卡面注册为未完成白板。4392标签含义及这八个排除对象是尚未国服校准的本地政策，不能用原行或官方简短卡面认证精确规则。

保存格式更新为schema317/core394，拒绝旧存档。专项覆盖共同安装时的反应复制/选择、原施法者时钟、额外/跳过回合、附件生命周期、独立注册表恢复/回放、异常回滚、严格待选形状和信息边界。实际结果、失败记录、未执行检查及下一项只在原两份台账维护；没有执行全量或正式国服验收。
