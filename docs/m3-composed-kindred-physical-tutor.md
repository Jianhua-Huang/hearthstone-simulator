# 托加检索原生延系合成体

原生延系正文可执行与物理牌库能够识别该资格是两个入口。本契约补托加 TLC_102 的真实依赖：完整规范合成体若包含已审的原生延系部件，原两次检索应将其识别为首张延系牌，再按第一次原抽牌的完整类型找激活牌。原牌、拼装和普通非延系牌的既有政策保持。

## 一处资格查询

`hs_sim.engine.kindred.has_native_kindred(registry, card_id)`先保留既有 `kindred_profiles` 的原牌/拼装识别；对规范合成 ID，先解析整个实际卡面，核蓝图、两个部件身份、原声明及捐赠许可，再检查其原部件是否具有原生延系 profile。资格是原生印刷声明，不根据正文文字、一次临时授予或可调用的行为名猜测。

它只查询，不添加虚拟原生 profile、独立卡牌或生成池，也不修改登记或消耗随机。未知或未审部件在完整解析时显式报错，不能被当作没有延系而从候选中悄悄删去。普通印刷资格和移除正文/稀有改面来源的待校准边界继续沿原本地政策，不借此扩大为所有授予机制。

## 原两次物理抽牌

`physical_draw_groups`的首张候选筛选、第二次执行前原首件资格核验、恢复时原根验证共用同一查询。所有交付仍交原 `draw_one`，不另造抽牌、牌库、费用、爆牌、随机或续接系统。

第二次选择继续以第一次原 `DrawRecord.card_id` 提供完整类型，不改读当前手牌、最后一次抽牌或同名另一实体。合成女王/三纪暴龙的野兽与亡灵均参与；原全种族部件仍用相同的完整类型关系。第一张爆牌、变形或离开手牌，不删除或改写原选择；嵌套抽牌不成为原首件。无延系候选不回退普通抽牌，无匹配激活牌只保留第一张，不伪造疲劳。

来源在第一次抽牌反应中死亡，仍沿原请求的玩家和两槽完成。独立注册表恢复、clone、回放、坏分支及晚第二次失败的事务边界继续由公共解释器验证；重哈希的错误原首件不能绕过资格核验。玩家只得到既有实际抽牌信息，不得到候选、原匹配材料或内部队列。
