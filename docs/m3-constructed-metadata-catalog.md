# 构筑元数据投影与独立生成目录

固定37.0源中，复活的奥妮克希亚CATA_155同时具有龙和亡灵：主种族CARDRACE24，加已审客户端2534亡灵标记。历史代表包仅保留了主种族。[来源包](../data/cards/constructed-metadata-catalog-v1.json)固定完整24原行、元数据摘要和历史定义摘要，不从名字或效果文本猜种族。实际执行、验收和下一项只在[项目状态](project-status.md)及[机制台账](mechanism-backlog.md)维护。

`representative.build_registry(metadata_overrides=...)`接受显式不可变的卡ID/完整CardMetadata配对，检查类型、重复及实际编译使用；未知或未经过原卡面工厂的ID明确拒绝。默认空配对保持原历史包。构筑组装器在原定义创建时提供已审元数据，因此无需运行时替换卡面、添加族群附魔或修改旧实体状态。当前仅覆盖CATA_155的印刷元数据，其他定义字段、主体和支付不变。

`register_reviewed_pool_metadata`为24张已有可执行候选补齐缺失PoolCard。完整来源和期望元数据全部检查后才登记新行，存在不一致时不留下部分目录。每行来自现有完整定义，已有相同目录可重复核对；不覆盖矛盾条目，不生成占位CardDefinition，也不新增PoolDefinition。可执行卡、独立资格元数据和格式池成员仍是三个不同层次。

修正后的印刷种族用于公共当前种族求值及纯生成筛选。动态种族替换仍单独存在；沉默、基础复制、正常回手和同卡变形恢复正确印刷种族，当前复制保留原动态材料。真实巨型附属物及其原实验池依赖继续沿既有入场流程，不为元数据测试简化卡牌主体。克隆、存档及回放绑定完整注册表指纹，不能用旧印刷目录加载新目录快照。

本批没有新增卡牌、Effect/载荷类型或状态字段，core399/schema322与观察89/命令12/replay1保持；构筑内容版本和指纹更新，默认311历史包及其完整存档保持。现有已注册候选的生成元数据补齐不等于全部1188候选已接入，也不证明正式标准成员、生成排除或精确国服规则已闭合。M0/M6与后续卡牌效果继续独立处理。
