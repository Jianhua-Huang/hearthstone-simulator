# 实际复制体续接与隐藏受伤即死

实际执行、验证证据、差异及下一项仅在[项目状态](project-status.md)与[机制清单](mechanism-backlog.md)维护。本页描述实际卡牌所需的有限表达，不将内部政策当作国服官方校准。

## 原始复制交付

`CopyMinion(..., cause=SummonCause.capture(context), on_summon=behavior_id)`可在每个真正成功的战场复制体完成入场反应后继续主体。非空续接必须有原始归因，行为在请求及材料接受时验证；未声明时保留原复制行为。手牌、弃牌和物理招募材料不借用此入口。

原`CopyEntryMaterial`增加可选`on_summon`，其余当前/基础复制、原本地材料、召唤数量及入场流程继续由公共内核执行。`ContinueCopiedMinion`保存原`CardSummonRecord`、交付序号及`MinionReference`，不会读取“场上最后一个随从”。只有该原始材料、真实成功交付、卡面、接收者、epoch和入场身份全部一致，才可接受一次续接。

`CardSummonDelivery.followup_started`复用既有一次接受字段，不增加状态账本。尚未开始的续接、下一份交付和Finish必须完整有序保存在解释器队列。续接接受后的私有事件绑定实际来源、接收者、复制体及原控制指令，历史和原始选择边界分别验证；不能删去尚欠续接、给另一实体借用，或凭空添加接受事件。复制和招募的接受收据按各自原材料验证，互不冒用。

入场反应让复制体死亡、变形、转控或离区时，原续接标记为已接受后按失效引用跳过；不会给替代卡面或同ID的新驻留继续效果。数量修正造成的额外成功复制各有独立交付及续接，失败份数没有续接。晚错误仍完整回滚原付款、实体、材料、附魔、知识及RNG。

`original_copy_reference(context)`仅从实际复制续接收据查询原被复制者，不将当前施法者、后续召唤或来源的新卡面当作材料。查询校验原交付引用和上下文头；公开动作和玩家DTO不获得这份内部引用。

## 血蓟幻术师

[完整原行/PIN](../data/cards/hand-mirror-demons-v1.json)固定EDR_780的3费2/4恶魔及原战吼。原EDR_780e、EDR_780e1完整附魔文字只作证据保存，没有注册为可执行白板卡牌。

战吼请求原本体的当前复制，成功续接再交付`MarkHiddenDamagePair`。它只接受两个不同、同接收者的原随从驻留，本地政策为等概率选择一个受伤即死；两份附加能力在同一检查点安装，授予反应不能在两者之间重绑目标。两者都获得普通触发能力，具体行为分别为受伤即死与无额外效果，执行身份不进入双方DTO或玩家事件。

脆弱主体只消费本体实际正量`damage_dealt`，使用原`DestroyCapturedMinion`绑定受伤时的驻留；不以当前损伤值轮询，也不把非伤害失血当作受到伤害。0伤害、治疗、圣盾和完全免疫不满足条件，普通死亡仍有真实`DeathRecord`、残骸和原亡语。捕获后不追杀离区再返回的新驻留。

隐藏标记沿普通能力的复制、沉默、变形、回手重置和控制变更生命周期处理。当前复制继承各自实际标记，基础复制不继承；新的复制来源信用仍由公共复制器维护。完整满场失败不安装新标记或消费标记抽选RNG。已存在标记、重复战吼、额外数量和反应窗口按上述原执行器组合，不额外发明单卡计数或穷举组合。

两种标记、选择结果、复制续接事件及原实体分配不进入玩家观察；全知快照仅供宿主保存和测试。结构和接受证明不认证未签名存档的来源。

## 影蔽袭击者

EDR_524固定4费3/5恶魔战吼。`ShuffleSharedHandCard`在执行时读取完整本方手牌卡面集合和敌方物理手牌；已提交的本体不再算作手持。相同卡面使用真实卡牌ID，不比较名称、费用或当前身材，也不将构筑复制上限的`deck_identity`自动当作同一实际卡面。

本地政策是对所有匹配敌手实体等概率选一张，同名重复牌各一个权重；一次仅洗入一张。空匹配不消费RNG。选中的`CardReference`交原`MoveCard(destination=DECK, position='random')`，保持原实体和区域生命周期，随机插入不打乱其他牌的相对顺序。移入牌库退休玩家追踪句柄，不展示完整敌手牌、候选或插入位置；不制造弃牌、销毁或死亡事实。

现有手牌移区政策保留本地状态；匹配数量、印刷ID别名、移动状态保留、等概率与国服精确窗口仍需M6核对。牌面数据和内部测试不认证这些边界。两张根卡的定义和配方在[hand_mirror_cards.py](../hs_sim/cards/hand_mirror_cards.py)，真实命令示例为`python -B -X utf8 -m examples.card_hand_mirrors`。

本批结构及语义由core-effects-v341/schema274保护，旧schema1～273拒绝；观察85、命令12和replay1保持。默认代表包与旧卡定义保持，正式卡池、全部可达效果和国服校准仍分别验收。

迷醉召唤者新增对多个完整当前场上复制材料的等概率选择，候选身份为物理来源而非印刷卡名；同一物理来源不得重复。其余单个确定性复制、确切交付回调和原对象驻留校验保持；同名敌人、满场随机政策及原对象失效见[真实消费者契约](m3-native-consumer-followups.md)。没有以自造选择替代原召唤执行器。
