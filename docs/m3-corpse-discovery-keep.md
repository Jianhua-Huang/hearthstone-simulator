# 原发现菜单的残骸保留分支

TLC_434古生物秘术为3费、单邪恶符文的暗影法术，发现亡灵并消耗5份残骸保留原三张。完整原行及严格中英主面直接复用P89资料，见[数据包](../data/cards/native-corpse-keep-discovery-v1.json)。准确标准生成资格仍取决于宿主constructed.cards，不从可执行定义反推候选。

DiscoverFromPool.keep_all_corpse_cost声明一次原菜单的真实残骸门槛，默认None。只允许带原来源、三个选项、一次普通可收藏随从手牌发现；不和赠礼、费用、临时、复制或入场配方混用。会丢失此语义的手牌使用后续包装器明确拒绝。原完整候选、职业/种族筛选、去重和一次无放回报价保持；未知合格内容仍先于RNG报错。

本轮内部政策沿一个实际发现选择，在原选择执行窗检查残骸，先支付再交付。足够时保留所选牌及原有序菜单中的余项，不足时只保留所选；空池没有选择或支出，不足三项只处理实际报价。所选先创建，余项按原顺序逐张创建，各次原获取反应可正常暂停。保留余项不伪造额外选择和发现历史；所选原发现完成通知仍使用原公共交付收据。**付款与选择的精确国服先后、足够残骸时的客户端选择行为，以及保留余项的发现计数/通知窗口尚待M6校准；本地政策不作官方一致性声明。**

直接将两个AddToHand放在通用等待队列不能证明交付义务完整，本次实测可从存档删掉其中一项而恢复仍接受。新增唯一KeepPoolDiscovery控制只持有原ResolvePoolDiscovery、上下文、付款阶段/原余额/真实支出ID和实际创建前缀；无新增GameState、Entity或Player字段。

控制调用原resources.resource_effect执行SpendResource，再冻结其真实成功/不足结果；不另扣银行、不重算已接受分支。每次交付调用原create_hand_card，所选沿finish_for_entity发布原发现完成，其他仍是普通获取。满手烧毁、来源、属性、死亡与所有反应沿已有管线。即使首张牌的获取反应后来改变残骸，剩余交付也不重新支付或改变原分支。

私有接受/进度/完成证明绑定原实际ChoiceResult和OriginalDiscoveryOffer、原唯一残骸支出及有序实际创建分配。每次进度在反应可等待前记录，唯一应有控制须保留在原队列与选择边界，不能删除、重复、缩短、换菜单、借用另一组支出或实体。嵌套组分别保留各自choice_id；验证从有效提交时间线读取证明，真实Retry的旧诊断不能冒充当前义务。终局保留实际已完成前缀并沿原解释器停止；异常回滚仍由原事务负责。
