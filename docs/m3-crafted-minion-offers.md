# 原生自定义随从的两阶段选择

维克多`CATA_470`复用[不可变造物卡面](m3-crafted-minion-faces.md)，以`CraftMinion`接受一次实际战吼，再依次选择龙与亡灵。只有最后一步创建一个合成实体，不先获取、使用或召唤两个部件；入手、溢出和费用附件继续使用普通`AddToHand`，不另写交付结算器。

开发者确认它使用[专门筛选的子集](https://www.reddit.com/r/hearthstone/comments/1rs1yau/comment/oas2h2h/)，不能按所有龙/亡灵或当前已接入卡反推。`crafted.nefarian.dragons`和`crafted.nefarian.undead`是两个独立、按目标版本和模式绑定的宿主池，必须显式声明完整。裸构筑注册表不安装猜测池；专项的有限实验池仅验证算法。原生捐赠能力声明与生成资格分开，原系列版不能静默用同名Core版替代。

专属部件选择不直接套用“生成一张完整卡”的职业、标准系列或奇闻等资格过滤。资格由独立专属池和显式排除声明负责；类型、种族、印刷费用及完整元数据仍严格核对。所有费用内合格部件都必须有确切执行定义和受审捐赠适配，未知内容明确报错，不能跳过。第一次抽选前还检查所有可能到达的第二类部件及实际原生目标/学派兼容性；这属于执行能力验证，不用兼容性删去合格候选。

本地有限政策为：印刷合计费用最多10，先选龙，其印刷费用从第二次预算扣除；每次至多三个不同选项，小池提供已有项且仍需选择，空池报错。独立权重沿原声明，不追加Core同名去重或卡面行数规则。[玩家原记录](https://www.reddit.com/r/hearthstone/comments/1s403bb/victor_nefarius_has_very_limited_access_to_which/)支持10费总上限及大于5费的第一部件；精确资格、权重、数量和当前国服规则尚待M0/M6，不能把早期每部件最多5费的推测作为约束。

持龙条件在这次实际`CraftMinion`首次接受时读取原玩家当前手牌种族，包含All类型和已有种族更改，冻结0或3的减费。两次选择共用这个值；选项期间新增/移走龙不重新判定，造物本身不能给自己触发减费。减费只作为普通当前费用附件，不改变配方的印刷费用，也不放宽10费原预算。重复战吼各有新的接受窗口，后一次可看见前一次已经入手的造物。上述窗口及特殊重放继承仍待国服校准。

`CraftOffer`保存原接受状态、完整有序候选、实际选项、MT19937前后、原来源/玩家与冻结减费。第二段还携带原第一段及真实`ChoiceResult`。私有接受事件绑定这些内容与原状态摘要，实际选择事件关闭相应阶段；恢复重新查询原窗口、局部复演抽样，核完整菜单、所选部件与继续项。已接受但尚未选择的阶段必须保留实际待选或排队工作，不能在其他反应等待时裁掉整段。原回溯重置后的诊断事件用既有effective_events退役，不另建对局账户。

允许两段之间的其他实际反应推进随机，不用父段结束RNG覆盖新的真实RNG。原来源死亡不取消已接受的工作，归属不跟随后来的控制权改变。校验防止内部不一致，不提供未签名存档的来源认证。

选择使用有限`CRAFT`用途，第二次菜单显示合成卡面及原窗口费用预览。它不自动等同普通发现事件；发现奖励、精确客户端菜单及正式资格仍须依据真实证据核定。玩家只看到自己的实际选项和入手后可见造物，不得到完整池、原接受状态、随机状态或对手暗牌配方。

新增两种效果和一个明确注册的不可变payload，不新增对局账户或第二份入手/死亡/复制系统。协议core579/schema473、观察105；旧命令与回放入口保持。实际验收、差异和下一项仅记录于[项目状态](project-status.md)及[机制台账](mechanism-backlog.md)。


## 天灾驯兽师的普通战吼入口

`RLK_821`沿原`CraftMinion`调用，使用同一`ICC_828t`僵尸兽模板和两个独立来源池。每个部件的印刷费用上限为5、合计上限10，不附加支线奖励的减三费；最终实体仍经过普通费用层和入手交付。真实1费1/2猎人亡灵的完整原行和双语主面保留在[来源数据](../data/cards/past-scourge-tamer-v1.json)。

来源保留实际出牌者与物理源，两段接受、三个以内真实选项、原随机证明和选择恢复沿原公共流程。第一段不提前交付部件，第二段才创建一个完整造物；已接受的工作继续遵守原来源死亡、容量、回滚和玩家信息边界。合成体的原生战吼、亡语和关键词由既有不可变卡面及附件安装执行。

已有四个受审捐赠体属于执行能力声明，不能当作任一正式部件池。本入口保留显式宿主完整池要求，未知合格部件会报错并回滚。印刷费用、职业和种族的本地调查只给出待核外界，不证明两阶段资格、例外、版本或权重；正式名单与精确国服窗口继续独立核对。本批没有增加公共效果、模型、帧或第二套拼装执行器。
