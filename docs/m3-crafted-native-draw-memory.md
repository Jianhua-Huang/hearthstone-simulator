# 合成栉龙的原抽牌亡语记忆

栉龙 `TLC_603` 原本已有完整的战吼抽牌与亡语弃牌正文。本次只补它作为原生合成部件时的声明与载体验证，固定 [完整原行和双语主面](../data/cards/zombeast-native-draw-memory-v1.json)，不新增卡牌定义或另一套抽牌、弃牌、复制结算器。

原 [亡语记忆](m3-native-deathrattle-memory.md) 的 `draw_link` 仍装在该部件的印刷亡语附件上。合成面保留原部件身份，`deathrattle_card_id` 与正文仍指向栉龙；实际来源、属性和付款属于合成后的物理实体。合成面的单个 `native_deathrattle` 字段保持为空，避免与原附件保存两份材料。一次合成最多接受一个原生记忆部件，目前只审 `draw_link`；其它记忆族或多个记忆部件明确未支持，这属于能力边界，不是候选资格规则。

公共载体检查核对完整有序配方、蓝图、两部件许可、当前随从类型，以及原印刷亡语的部件身份、正文和 `NativeDeathrattleSpec`。它重新解析完整卡面，不以有相似行为 ID 或任意授予替代原部件。普通载体、已有复制/继承来源及它们的材料校验保留原路径；结构伪造仍须拒绝。这些检查不提供未签名快照的原始来源认证。

真正战吼继续通过原 `DrawForDeathrattle` 调用普通抽牌。在真实牌进入手牌并取得本次获取身份后、抽牌通知前，将原 `DrawRecord`、实体、手牌驻留和抽牌来源链接装入原附件。抽牌通知即使导致合成体死亡，也已具备正确亡语材料；疲劳、爆牌或抽到时施放仍沿原规则，不制造成功手牌链接。

亡语使用原接受时冻结的材料，通过原 `DiscardRememberedDraw` 核对物理获取身份后弃牌。相同卡名的另一张牌不匹配；原牌离手后重新获取不能重绑。当前复制保留已有链接，真实再次出牌的战吼可增加新的抽牌；基础复制、回手重置、沉默和变形沿原生命周期。载体转控不重写原抽牌者。死亡记录、当前复制材料及等待恢复复用已有载体校验入口，不新增对局账户或保存字段。

天灾驯兽师及标准围攻城门使用同一制造入口，任务原减三费只改变当前付款，原配方费用/身体不变。本次有限实验池只证明真实入口与后续记忆执行；`crafted.zombeast.first/second` 没有因此成为正式或完整的候选域。完整记忆和抽牌/获取 ID 不出现在玩家观察中。
