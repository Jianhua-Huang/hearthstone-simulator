# 经典克苏恩的独立成长

对应B08a及B08b-02/U31。这里补玩家仪式成长、实体永久数值及真实地卜师嘲讽，复用原附魔、能力、出牌、死亡、区域、复制、解释器和事务。没有新建组合结算器或任意效果授予接口。当前prototype-v164/core-effects-v164，schema159，玩家观察70；命令10、回放1保持。实际执行结果和下一项只在[项目状态](project-status.md)及[机制清单](mechanism-backlog.md)维护。

## 公共入口和归属

注册`CthunProfile(version, card_ids, base_attack=6, base_health=6)`；`card_ids`是可以携带经典成长的真实物理身份，OG_279不作为可执行实体。profile冻结并进入注册表指纹；缺少命名实体适配时，成长可以在没有实体的局面累计，实际创建仍明确报错。

卡牌返回`GrowCthun(player_id, attack, health, source_id=None, taunt=False)`，数值仅接受准确非负整数，taunt仅接受准确bool。地卜师声明+1/+1及taunt=True；只支持这一真实仪式关键词，不推广成任意关键词授予。纯嘲讽也是非空增长；数值为零且taunt=False才不生成历史或收据。没有profile或来源无效时报错。每次增长写入一个`CthunGrowthRecord`，两个玩家分别累计数值及是否已授予嘲讽；牌不在手牌、牌库或战场也不能丢失记录。成长不消耗随机数。

`cthun_ritual_stats(state, registry, player_id)`返回印刷6/6加该玩家所有仪式增量。普通局部附魔、当前伤害和光环不改变这个累计量。真实“克苏恩至少10攻击”的查询`cthun_attack_at_least`允许仪式总量满足，或者本人手牌/战场的实际克苏恩攻击力满足；不要求必须有实体，也不读取对手实体来替本人达标。必要经典战吼读取自身实际攻击力并复用原逐发`SplitDamage`，采用最多100发的调查政策，精确上限待国服校准。

## 永久附件与普通生命周期

每个实体增量仍是原有序`Enchantment`中的独立加法行。`CthunRitualStamp`冻结玩家、原历史范围和profile版本；相应数值必须与原范围内该玩家的实际增长一致。它不能混入费用、定值、寿命、种族或其他授予。普通buff仍按自己的生命周期移除。

嘲讽复用`AbilityInstance(kind='keyword', keyword=TAUNT)`，独立的cthun_ritual戳使用同一原历史范围，仅允许不可沉默的granted嘲讽，不能携带来源引用、消费、期限或其他能力状态。数值与嘲讽分别核对原贡献和重置补齐，不在重建缓存或恢复时重放增长；各通道禁止重复使用同一原贡献。原数值查询及玩家DTO继续只返回两个数值，不公开全知关键词累计。

- 对已经存在且受该玩家控制的手牌/牌库/战场/待出牌实体，仅追加这次增量；即使被沉默也继续成长。先设为1/1再增长+2/+2，得到3/3，不能重置为理想累计身材。
- 新建普通实体以当前控制者累计成长初始化一次。普通base复制使用接收者累计量；current复制保留原捕获局部材料，覆盖初始化附件而不重复累计。冻结复制材料显式校验原仪式行。
- 沉默不移除仪式数值与嘲讽；地卜师自己的印刷嘲讽沿普通沉默移除。回手及本人牌库重置保留仪式数值/能力行并分别补足尚未应用的本人记录，其他普通附件按原重置政策处理。跨玩家重置入牌库使用接收者数值与嘲讽累计量。当前控制权转移保留实体局部身材/能力，后续只接收新控制者的新增量。
- 变形成克苏恩不追加此前数值或嘲讽，先用6/6，再获得后来的增量；变形离开克苏恩清除仪式数值/能力材料。若后来重置回手则按普通存储实体补齐累计。该精确窗口为本地政策，待国服校准。
- 死亡实体和原死亡记录不随未来成长改写；新复活实体通过原创建入口获得当前玩家累计量，不把原死亡附魔重复贴回。没有新增特殊死亡来源适配。

牌库中的累计数值采取提前物化政策，使普通抽牌不再次添加；这一内部表示及隐藏区域/重置/复制的精确时点仍待M6核对。以上是基础自身生命周期，未建立来源与其他机制的组合矩阵。

## 恢复与玩家信息

历史、永久数值/能力行、冻结材料和私有实际收据都进入原快照及解释器。当前schema159严格拒绝旧1～158，旧存档需原引擎；不静默迁移。原事务负责异常时回滚实体、增长、支付、事件和随机状态。选择中途恢复和动作回放不重复执行已完成的增长。

无效历史、错误版本、未来/重复增长行、永久数值与原范围不符、嘲讽戳指向无原授予范围、将仪式行改成可沉默/任意能力或放到其他卡面、丢失/改写实际收据均拒绝恢复。当前与冻结复制材料使用相同原范围校验。哈希和结构检查不提供未签名存档的来源认证。

本人玩家DTO仅可选显示`cthun_ritual={attack, health}`；对手字段、全知历史、永久行身份和私有收据不进入玩家投影。双方公开实体继续使用原投影。公开动画/仪式展示的精确内容未以本批保守信息政策冒充国服实测。
