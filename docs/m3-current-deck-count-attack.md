# 当前牌库数量条件持续自身攻击

本契约扩展既有 `StatRelationSpec`，复用 [牌库数量条件](m3-current-deck-count.md)、[原属性层](m2-stats.md)和[生命周期](m1-lifecycle.md)。实际验收、差异与下一项只在 [项目状态](project-status.md)和[机制清单](mechanism-backlog.md)维护。

```python
StatRelationSpec(
    operand=StatRelationOperand.CONTROLLER_DECK_COUNT,
    layer=StatRelationLayer.CONDITIONAL_ATTACK,
    amount=5,
    card_count=25,
    comparison='at_least',
)
```

原四字段保留，新添 `card_count/comparison` 两个可选字段。新操作数只允许自身 ATTACK、原 CONDITIONAL_ATTACK 层和严格正整数加成；阈值为严格非负整数，`at_most/at_least` 均含等号。原自身生命、受伤、武器存在和弃牌数量四种操作数必须保持两新字段 `None`。未知操作数、错误层、布尔/浮点、缺失比较和未经审查的声明明确拒绝。

这是一项印刷普通非融合随从能力。查询在原已验证状态上读当前控制者全部物理 DECK 槽位，所有牌型、同卡面重复与0费均计数；不读取原构筑数量、开局事实、职业元信息或其他区域。已有 `DeckCountCondition` 执行比较，不新增查询语言或表达式图。未知卡面仍由原注册表和状态校验拒绝。

原 `conditional_attack` 纯计算和已有实体派生整数承载自身贡献，原事件规范化及完整属性刷新更新它。贡献加在普通有序数值附魔与外部属性光环后、零下限前；原最终自身生命关系保持。反复抽牌或洗入不会产生永久叠加，不改变基础攻击、伤害或普通附魔。没有新模块、Entity/Player/GameState 字段、资源、效果、执行器、事件、外部动作或组合族。
