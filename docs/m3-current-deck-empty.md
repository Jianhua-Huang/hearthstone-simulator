# 当前牌库为空

`DeckCondition('current', 'empty')` 是原声明的有限结构条件，供宿主或规则对已验证的状态使用。原 `matches_deck_condition` 返回指定玩家此刻物理 `DECK` 列表是否为空；原 `CheckDeckCondition` 执行选中的分支。

空牌库与没有随从、没有中立牌、没有重复牌分别判断。非空职业法术牌库可以同时满足无随从和无中立，却不满足空牌库。牌型、职业、种族、收藏、费用、身份别名与卡面变化不会改变物理数量；手牌、战场和墓地不进入计数。查询无需无关的卡牌元信息，不使用 RNG、资源或事件，也不从当前空牌库推断构筑起点。普通恢复仍严格验证所有卡牌定义，结构查询没有放宽存档或执行未知内容的规则。

只开放 current/empty；starting/empty 和其他未审阅谓词明确拒绝。原 scope/predicate 两字段保持，其他谓词各自的所需事实与完整元信息守卫保持，见 [原牌库契约](m5-deck-conditions.md)、[无中立条件](m3-current-deck-no-neutral.md)和[无随从条件](m3-current-deck-no-minions.md)。

原分支在轮到执行时读取状态并选择一次。之前抽走、销毁或洗入的牌已影响这次检查；选中的分支之后暂停或改变牌库，不反向改选。待执行条件、已选效果、选择恢复、克隆、独立回放、动作及选择失败回滚继续由公共解释器和 typed 帧负责。没有新模块、模型类型、持久字段、动作、事件或执行器。

必要代表仅为 DAL_554「大厨诺米」与 `COLLECTION_RELATED_CARD_DATABASE_ID` 精确关联的 DAL_554t「猛火元素」。冻结本地原行是 7 费 6/6 中立传说、无种族的战吼随从：如果牌库为空，召唤**六个** 6/6 元素。Token 原 6 费 6/6、非收藏、元素且无关键词。不得用同名战棋英雄皮肤代替原卡，也不凭历史记忆改成七个。

适配只在隔离注册表，战吼返回一个原 `CheckDeckCondition`，命中分支包含六次原单次 `Summon`。战吼随从本体先占用一个场位，召唤沿原容量、实体分配、检查点与一次付款；没有批次计数参数或新召唤执行器。完整 raw/PIN 位于 `data/support/current-deck-empty-basics.json`，没有扩大生产代表或正式卡池。
