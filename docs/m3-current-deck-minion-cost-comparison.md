# 当前牌库随从费用严格比较

```python
DeckMinionCostCondition(cost=4, comparison='less', cost_basis='local')
DeckMinionCostCondition(cost=4, comparison='greater', cost_basis='local')
```

冻结声明有 `cost`、`comparison`、`cost_basis`、`scope` 四字段。阈值必须是非负整数，不能是布尔、浮点或字符串；只接受严格 `less` / `greater`、显式 `local` 和 `current` 范围。等号不满足任一比较。任意表达式、手牌外部费用、起始范围等未审阅政策明确拒绝。

## 条件事实

只遍历指定玩家当前物理牌库，完整查验每个实体的当前卡牌定义，然后仅对 `CardType.MINION` 读取原 `local_cost(entity)`，与明确阈值比较。法术、武器、地标和英雄牌不参与；仍须查验它们的定义，不能因较早随从已不符而跳过后面的未知条目。类型和本地费用查询不要求无关职业或构筑别名元信息。

重复实体分别参与。零费和101等合法大费用都可比较，不按法力上限截断。空牌库或没有随从的牌库按全称条件为真，这是明确的内部政策，精确国服空子集规则待校准。

本地费用指实体基础费用及保存附件的原操作结果，使用原费用模块。后续实际改费、抽牌、洗入、清空和变形会影响下一次查询；原构筑卡组、手牌、场上、历史费用及假设手牌报价不会代替当前牌库事实。此条件可用于已验证场景状态，不要求原构筑开局。查询不会消费费用用途、随机数或修改事件与历史，全知牌库和条件帧不提供给玩家。

## 分支与必要代表

条件仍交给原 `matches_deck_condition`、`CheckDeckCondition`。在该效果轮到执行时读取当前牌库，选定一次分支，然后沿用公共解释器、检查点、等待、保存恢复、克隆、回放和回滚。选定后的牌库变化不重新选择分支；后续新的执行重新查询。没有新条件执行器、费用执行器或招募执行器。

必要隔离代表只 `AV_100`「德雷克塔尔」：完整冻结原行4费4/4、中立传说，无种族标签。战吼行为派发时捕获来源物理实体的 `local_cost` 作为标量阈值，声明所有当前牌库随从都小于该值；命中后返回原 `SummonFromZone(count=1)`。阈值没有假定永远是印刷4费，也没有读取实际付款金额；捕获窗与牌库求值窗分别明确，不在选择恢复时随意改写阈值。

招募沿用原物理迁移、随机选择、容量与检查点；不会额外支付被招募牌的费用、抽牌或执行其战吼。空候选和满场不移动牌、不消耗随机数。已招募的牌有独立实体和原生命周期，来源沉默、回手或离场不会撤销招募；重新打出来源时按新的当前牌库重新判断。

完整原始行及 PIN 在 `data/support/current-deck-minion-cost-comparison-basics.json`。`AV_223` 范达尔·雷矛只作原始证据，没有可执行适配。实验30槽构筑、背景牌、英雄与技能明确隔离，不扩展正式池或生产代表包。官方[23.2.2补丁说明](https://hearthstone.blizzard.com/en-us/news/23797162)将德雷克塔尔的召唤数改为一个，与冻结原行一致；该说明未证明精确当前国服费用层、空子集或来源求值窗口。
