# 当前牌库没有中立牌

`DeckCondition('current', 'no_neutral')` 扩展原有限牌库声明。宿主纯查询仍调用 `matches_deck_condition(state, registry, player_id, condition)`，卡牌仍使用原 `CheckDeckCondition`、效果 tuple 和公共解释器，无新条件执行器。

## 范围与依据

取指定玩家此刻 DECK 中每个物理实体的当前卡面，使用原 `PoolQuery(include_neutral=False)` 和 `matches_metadata` 的职业元信息判断。只要有一张中立牌，条件就不成立；空牌库成立。重复职业牌、构筑身份别名、其他职业或多职业牌不等于中立牌，不能套用“没有重复牌”或“全为本职业”条件。

手牌、战场、墓地和原起始卡组不参与当前查询。抽走或销毁最后一张中立牌后重新查询为真；洗入中立牌后为假；牌库实体变形以新卡面为依据。牌库中的非收藏衍生牌、法术等同样判断职业，不以可收藏性或随从种族代替它。

每个实体都检查审阅后的元信息，再聚合结果；即使前面已发现中立牌，后面的未知记录也不能被短路跳过。缺少元信息抛出原 `UnknownDeckFacts`，错误消息不披露隐藏卡 ID。查询不使用随机、不移区、不支付或推进动作。

该有限谓词只开放 current。`DeckCondition('starting', 'no_duplicates')` 及原 current 无重复政策保持；starting 的 no_neutral 和其他未审核谓词明确拒绝，不由当前剩余牌库推断起始事实。原起始与无重复契约见 [既有接口](m5-deck-conditions.md)。

## 分支、恢复与生命周期

`CheckDeckCondition` 轮到执行时读取当前状态，选定一次分支；此前的抽牌、洗入、移区与换面已生效。分支选中以后暂停或改变牌库，不会反向改选；下一个条件执行重新查询。条件自身没有持续光环、缓存或玩家累计值。

未决条件、已选中分支和其剩余效果使用原 typed 帧。声明仍只有 scope/predicate 两个字段；未知 scope/predicate、缺失/多余字段、非法玩家或非 tuple 分支按原严格解码拒绝。未暂停的失败回到操作前，待选继续失败回到原等待点。恢复、克隆和动作回放沿用原私有状态和解释器，不新增存档格式。

必要实验代表为 DMF_241「大主教伊瑞尔」：完整本地原行 8 费 7/5 圣骑士传说德莱尼。成功战吼只返回原突袭、吸血、嘲讽、圣盾四次 `GrantKeyword`，不增加身材；未命中仍是正常付费随从。之后牌库变化不会撤销已授予能力；沉默、回手和重新使用按原能力生命周期处理，重新使用时再次检查条件。

完整 raw/PIN 位于 `data/support/current-deck-no-neutral-basics.json`，可执行适配只在隔离测试注册表，未扩大生产代表或正式生成池。私有牌库和条件工作不会进入玩家观察、事件流或命令目录。
