# 随机存储随从的种族依据

TLC_822「恐龙保育师」需要在本人实际结束时从当前手牌野兽中随机减费。其已有随机存储随从效果只按印刷元数据筛选，不能表达经过种族变更的当前野兽。[完整来源包](../data/cards/current-stored-tribe-v1.json)保留真实正文及完整中英官网卡面。

`RandomBuffStoredMinion` 增加有限 `tribe_basis`，只允许 `printed` 或 `current`。既有调用默认仍为 `printed`，原参数顺序和其他筛选条件保持。当前模式先使用原 `zone_candidates` 筛选物理存储随从及其他元数据，再用公共 `has_any_tribe` 核对当前完整种族，不用卡名或新有限种族全集替代。

已移除的印刷野兽不再匹配当前模式；当前设置为野兽、双种族、全部种族和显式排除沿原种族声明。未知当前信息明确报错；完整当前设置可以使未知印刷种族变为已知。没有所需种族条件时不强行要求无关的种族信息。

候选仍为原物理手牌/牌库引用，同名实体各保留一个权重，一次原随机选择后由 `BuffStoredCard` 统一处理减费、费用下限、区域/生命周期和通知。没有新随机器、种族状态、账本、支付或属性执行器。

恐龙保育师只在本人自然结束时读取本人当前手牌，沉默、转控、选择暂停、失败回滚、克隆和回放使用原管线。effect声明字段变化明确升级core382/schema305并拒旧1～304；模型字段不变，观察87/命令12/replay1保持。精确国服资格、候选/通知及随机窗口仍待M6。

实际验证、差异及下一项只在[项目状态](project-status.md)与[机制台账](mechanism-backlog.md)维护。
