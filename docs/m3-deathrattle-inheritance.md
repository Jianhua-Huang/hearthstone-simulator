# 本回合死亡随从的完整亡语继承

EDR_491荆棘大德鲁伊是2费3/2术士随从；名称不代表职业，印刷只有战吼，没有亡语或种族。[完整来源包](../data/cards/deathrattle-inheritance-v1.json)保留37.0原行、两个完整官方卡面及既有代表的完整定义摘要。实际验收、差异和下一项仍只在[项目状态](project-status.md)和[机制台账](mechanism-backlog.md)维护。

## 查询与授予

`GainDeathrattlesFromDeathsThisTurn(player_id, beneficiary)`复用`DeathQuery`。`player_id`来自原主体玩家，与接收者的控制者分开保存；“本回合”是当前全局回合，“你的随从”按死亡时控制者判断。只读取真实场上随从死亡记录；普通离场不算死亡，其他回合和对手死亡不混入。

按既有死亡顺序及记录内物理能力顺序，复制每个未消费的`deathrattle`声明。保留重复死亡和同一随从上的独立重复授予，不以behavior ID去重。不执行亡语主体条件，也不按全局亡语禁止源删去结构声明；是否触发仍由之后的真实亡语接受窗决定。沉默或实际移除后死亡的随从只提供死亡记录中真正剩余的声明。

接收者使用原`MinionReference`和存活驻留守卫，不能给尸体或同ID的新驻留授予。一次处理完整收集材料、分配所有新附件，再沿原`ability_granted`通知发布；普通死亡、重复、反应、选择和队列仍由原解释器执行。

## 材料和生命周期

不能用当前墓地实体或印刷卡名重建。复制原`DeathRecord.abilities`中的完整能力，包含原生声明、成长数值、物理抽牌关联及实际弃牌记录。召唤、生成、弃牌和数值正文继续通过原亡语回调及公共执行器处理，回调的实际载体和死亡材料是新接收者。

新附件具有新ID、可移除的`granted`身份和本次授予来源，不借用原载体的临时期限或磁力组。`deathrattle_inherited_from=(death_id, ability_id)`连接原完整物理声明；原打印或授予来源仍完整留在该死亡记录。边界校验核对真实原死亡、原未消费声明、单调附件身份及完整规范化材料，拒绝凭空指向、偷换behavior或改写记忆。不扩大普通`GrantDeathrattle`的材料形状。

原生记忆只额外接受有上述原声明证明的继承附件，不开放任意跨卡伪造。当前复制保留材料和证明并分配新附件ID；基础复制恢复印刷体；沉默、正常回手、变形与普通移除沿现有生命周期。全知指针和记忆不进入玩家DTO。

## 范围

新增一个Effect和一个可序列化能力字段；无新增GameState或Entity字段、玩家字段、回放动作或私有亡语解释器。格式切换到core397/schema320，旧schema必须使用原引擎，不能静默补空证明。

当前使用内部政策：本次继承保留死亡时记忆、忽略原到期时间/磁力组，以新载体执行正文。精确国服继承顺序、记忆和控制窗口仍须M6校准，简短官方卡面不证明这些时序。完整正式标准池、通用生成资格和其他尚未接入的真实特殊亡语仍独立登记，未知能力明确报错。
