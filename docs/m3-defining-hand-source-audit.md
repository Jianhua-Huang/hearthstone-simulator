# M3：手牌定义来源前审

本地 `DEFINING_ENCHANTMENT` 有22条附魔原行。20条使用原卡面 DBF 引用且全部在本地找到；另两条战棋附魔使用值1作标记，不能把它们当成缺失的 DBF 卡面。完整原行、数值种类与20个完整来源见[固定调查](../data/support/defining-hand-sources-audit.json)。这不是最新国服合法池清单。

该标签关联了多种真实规则：随机卡面反复变形、复制手牌或牌库中的物理牌、最近打出/施放的牌、牌库顶镜像、生成法术后继续变化等。标签能指出原始来源，不能独自确定触发窗口、复制继承、离手再入手或外部变形后的生命周期。不能据此提供任意保留附魔或手牌授予组合。

泽鲁斯、熔岩之刃和变形卷轴有独立来源附魔，支持“当前卡面与连续来源需要分别识别”的设计线索。暴雪[12.0机制说明](https://hearthstone.blizzard.com/en-gb/news/21965466)和[12.0更新](https://hearthstone.blizzard.com/en-us/news/21964710/update-12-0-august-2-the-boomsday-project)证明历史普通变形清除附魔的基本方向。后来的[27.6更新](https://hearthstone.blizzard.com/en-gb/news/23989479/27-6)明确把泽鲁斯保留附魔的更改标为战棋；这不能反推构筑也采用同样政策。

当前内核已有重复手牌事件、普通存储变形和新实体复制。普通变形清除旧监听；`CopyCard` 新建实体；`CopyEntryMaterial` 是随从复制入场材料。这些能力不能因为参数齐全就宣称已完成所有定义来源。还需核对保持接收者实体身份、变为来源当前物理复制的公共操作，以及连续来源如何绑定和退役。

本批不修改运行规则、不新增卡牌或测试，不将调查写成机制验收。来源生命周期继续作为真实缺口保留；基础复制依赖的核对顺序和实际执行只在[项目状态](project-status.md)及[机制清单](mechanism-backlog.md)维护。M0正式池、M6国服校准、M7批量接卡和整个基础目标仍未完成。

后续独立原生来源表示见[来源契约](m3-native-defining-hand-source.md)；带来源的当前复制/转手政策仍需具体真实来源证据。实际结果与下一项只在两台账维护。
