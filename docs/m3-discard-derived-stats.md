# 真实弃牌数派生双属性

CATA_493「地狱公爵」4费2/2、突袭，拥有每张本人已弃牌带来的+2/+2。[完整来源包](../data/cards/discard-derived-stats-v1.json)保留固定原行及完整中英官网响应。攻击和生命均是原生连续关系，不把历史重放成永久增益。

## 有限声明与状态

既有 `StatRelationSpec` 增加的唯一生命形状是 `target=HEALTH`、`operand=CONTROLLER_DISCARD_COUNT`、`layer=CONDITIONAL_HEALTH` 和正整数倍率。攻击仍用原关系。没有开放任意生命表达式、跨实体循环或动态生命关系授予。

原 `discarded_cards` 查询当前控制者的已提交弃牌账本，无新计数器。普通活跃载体在手牌、牌库及场上均重新派生；沉默移除原声明，重置清除缓存，复制/转控按接收者当前事实计算。休眠资格沿原活跃能力政策。原始死亡记录继续冻结发生时的属性，不按后续历史重算。

`Entity.conditional_health` 是与既有conditional_attack平行的可校验派生缓存，默认零；最大生命从原基础/本地/光环层加此贡献。增长保留伤害，贡献减少采用原剩余生命钳制。完整光环刷新先捕获原健康事实，计算新光环和原生生命后一次比较总贡献，避免先失去光环再增长原生生命造成额外治疗。无需贡献的实体不执行生命重算。

## 保存与执行

缓存纳入原严格解码与派生值比较；未知、过期或重签错误缓存不能静默恢复。transform/reset统一清零；普通生命增减、毁灭、伤害、亡语、区域和复制仍由原执行器处理，没有新健康执行器、账本、effect或payload类型。
