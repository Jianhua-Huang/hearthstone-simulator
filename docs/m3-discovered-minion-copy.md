# 发现手牌与实际创建材料的复制召唤

生命仪式当前为2费牧师神圣法术：发现3费随从，召唤2/3复制体。完整原行、中英官网卡面及[33.4.2官方修改](https://hearthstone.blizzard.com/en-us/news/24223779)共同确定当前2/3数值；原DINO_426e仅作附魔数据证据，不建立占位可执行定义。

本实现保留普通发现手牌，再召唤复制体。该交付解释由卡面与[玩家的第一手对局描述](https://us.forums.blizzard.com/en/hearthstone/t/they-didnt-ban-questlock/153622)相互印证：其描述生命仪式在第二回合产生随从，并接续第三回合使用3费随从。这属于有证据的实施判断，没有代替国服正式校准。

使用有限的 `DiscoverFromPool.summon_copy_stats=SummonStats(2,3)`，要求一次普通手牌随从发现、原来源和 `SummonCause`；不允许费用/临时声明、黑暗之赐、冻结或发现费用治疗续接。带原因的场上发现继续使用原生产者，手牌复制请求不借用场上发现身份。

实际完整 `ChoiceResult` 经候选/职业/来源及选项收据核对后，排入 `DeliverAndSummonDiscoveredMinion`。该Effect调用原 `create_hand_card` 并直接取得真实创建对象，不搜索同名手牌或猜实体号。手牌成功交付时，以该对象捕获普通 `stored_copy/current` 材料及2/3设值，并在同一创建窗口接受原带归因 `SummonByCard`。获取通知和后续交付仍由公共解释器处理，原已接受材料/数量不被后来的通知变更重写。

满手烧牌时保留普通烧牌行为，采用原选中印刷随从的2/3召唤材料；不会把墓地对象伪装成合法stored-copy来源。满战场仍能获得发现手牌，召唤沿已有失败路径。原手牌和成功复制体是独立实体，召唤不触发战吼，数量额外体复用同一已接受材料。

创建窗口相对获取反应的顺序、后来手牌变更是否应反映在复制体、满手分支的复制材料/来源继承，以及隐式职业资格均待精确国服校准。上述政策须与实际代码一起记录，不能由绿色内部测试升级为正式规则认证。

新增一个请求字段、一个Effect，复用既有SummonStats/复制材料载荷、实际手牌创建和召唤执行器；无新状态/实体/能力字段。core404/schema325拒绝旧1～324，观察89/命令12/replay1保持。普通发现默认None，既有默认代表内容保持。实际测试、已知差异与下一项仅在原两份台账维护。
