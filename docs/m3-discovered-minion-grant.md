# 普通发现的固定随从属性增益

盛气凌人当前为1费战士法术：发现一个嘲讽随从，使其获得+1/+2。CORE_WON_350的构筑同卡身份为WON_350；WON_350和CFM_940完整旧行仅作证据，不据版本前缀推断身份。完整原行和中英官网卡面确定当前效果。

`DiscoverFromPool.minion_grant`使用已有`CreatedMinionGrant`，仅允许非负固定攻击/生命增益的普通手牌随从发现：一个选中结果、三个普通选项、逐次交付、可收藏随从、明确原来源。不能携带关键词、复生、特殊主体、身份、费用、临时声明、重复法术、黑暗之赐、复制召唤、冻结或治疗续接。未接通该声明的手牌发现包装器明确拒绝，避免静默丢失增益。

普通发现仍由完整选择收据、资格池和来源版本排除核验。选中交付只把声明转交已有`AddToHand`和创建层；创建层在真实新实体首次获取或烧牌通知前安装增益。不会查找同名旧手牌，也不新增属性执行器。满手的真实烧牌实体同样带有增益；满战场不影响入手。正常打出、沉默、等待恢复、回放、克隆、玩家视图与异常回滚继续共用原管线。

隐式职业资格采用当前英雄职业加中立，属性在首次创建通知前生效。这些细部为内部实施政策，仍待精确国服校准。生成必须具有宿主明确提供的资格池，未知合格内容在取随机数之前明确报错；本实现没有认证正式标准池。
