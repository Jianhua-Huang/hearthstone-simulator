# 发现奥秘并直接施放

[完整原始记录](../data/cards/ring-toss-secret-casts-v1.json)保存套圈圈DMF_105及其腐蚀面DMF_105t，两条完整原行和四份中英文主面。它们是标准过去来源的跨系列可达依赖，不增加标准组牌根；完整过去法师源仍按原台账补齐。这两个形态分别发现一个、两个奥秘并直接施放，腐蚀资格继续使用已有真实支付报价及手牌升级。

## 有限声明

DiscoverFromPool增加destination='cast'这一交付值，仍用原菜单、抽样、完整选项、选择历史、生产者与续接。仅接受原source_id、一次或两次、每次三选一、after_each及允许重复的普通当前职业可收藏奥秘查询。费用/临时寿命/附魔、手牌奖励、召唤、刷新、额外保留等参数不进入该路径；随机GenerateFromPool不能借用这个目的地，非默认字段的值及类型均明确拒绝。

查询仍读取完整constructed.cards和当前职业，保留原身份、去重与权重。剩余法力、已有同名奥秘及奥秘容量不会删除候选；先接受完整发现结果，再让原自动施法与奥秘部署规则处理实际结果。空完整域不造菜单、不消耗随机；未知合格内容仍沿原候选验证报错。当前宿主的法师奥秘域是完整普通域内六个合格身份，此数值不是所有职业、历史版本或官方线上全奥秘池的认证。

## 物理施法和原结果证明

选中结果由原MaterializeDiscoveredCard交给已有CastSpell。spell_casts.materialize_generated_cast仅提取原公共生成施法器的分配与接受操作，返回实际物理实体及原施法工作；原cast_generated继续返回同一工作队列。该路径不会先进入手牌，不触发入手、不受手牌烧毁处理，也不再次支付所选奥秘的印刷费用。SpellCastRecord沿原origin=effect、caster_id=原发现来源、from_zone=None记录，目标与自动选择保持普通策略。

DiscoveryCompletion保存的recipient是实际生成接受时、主体尚未执行的墓地分配事实；后续实体部署至奥秘区不改写该原事实。原完成通知排在整次子CAST工作之后，普通接受事件监听的等待窗口遵循既有语义：奥秘激活属于同步主体步骤，监听等待发生时奥秘可已部署。两次发现沿after_each，第一次施法及其反应完成后才产生第二菜单，父法术只支付一次。

原私有交付日志与完成收据继续由FrameCodec保存和重核。生成施法不冒充AddToHand的card_created证明，而在原同步窗口核验唯一spell_cast_started：原物理ID、卡面、玩家、发起者和来源区域必须对应原所选结果，另核origin=effect及完整分配界限。物理牌库CastStoredSpell保留自己的原卡引用和区域；不能互相冒充、丢掉原受益实体或用另一同名实体替换。类型入口只允许普通、无自选目标/分支/预算等附加策略的真实Secret定义。

游侠斥候GDB_841沿原发现资格与CopyDiscoveredCard处理结果。直接施放的普通奥秘使用已有打印材料创建一张独立手牌复制，不再施放这张复制，不按已经部署的奥秘局部状态猜测材料；原资格冻结、创建、容量和信息边界继续共用。发现减费等原手牌消费者保留自己的实际区域政策。

## 差异和验证范围

重复奥秘或五奥秘容量仍保留普通CAST尝试，部署是否成功由既有奥秘机制决定。完整主面没有说明所有细时序，本地选用逐次发现、逐次完整施放；国服精确窗口及版本/热修对齐按用户授权暂缓并明确记录，未冒称官方校准。

本增量无新Effect、payload或状态字段，core785→786，schema611及玩家观察/命令/replay接口保持。专项需从真实套圈圈与腐蚀入口核验付款、两个菜单、原结果收据、免费CAST、容量/重复/空域、恢复/回放、失败原子性、隐藏身份以及既有斥候复制。相关验证覆盖原生成/物理施法、发现交付、选项与收据、复制、奥秘及宿主；实际结果和下一项只在[项目状态](project-status.md)和[机制清单](mechanism-backlog.md)登记。
