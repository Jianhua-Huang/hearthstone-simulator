# 发现后原召唤对象的冻结

冰川急冻当前为6费萨满冰霜法术。它复用普通发现、带原施法原因的场上发现生产者和现有 `Freeze`，只新增有限的 `DiscoverFromPool.freeze_summoned=True`。该声明仅允许一次、普通三个选项、交付后续接的可收藏随从场上发现；需要原来源与 `SummonCause`，不能附手牌费用、黑暗之赐或象牙骑士治疗。

选择仍沿完整 `DiscoverySummonOffer` 和实际 `ChoiceResult`。原选中卡的 `SummonByCard` 完成后，`FreezeDiscoveredMinion(producer_id,index)` 核对原父生产者、实际子请求、原原因和完成状态，读取该请求的第0次交付。只在原物理驻留仍存活时调用公共冻结，不扫描后来战场、不根据卡牌ID找替身、不预测实体号。失败或离场的原对象仍接受空续接，不能转而冻结额外召唤体。

内部政策是等该选中请求全部交付及其反应完成后，冻结原第0次交付；数量额外随从独立，不因为同卡面成为后继目标。控制、变形或离场导致原连续驻留失效时跳过。官方卡面确定发现、召唤、冻结这三个动作，但没有单独认证这些细部时序和额外数量政策；精确国服校准仍开放。

`DiscoverySummonRecord.freeze_acceptances` 保存已接受续接的有序索引前缀；完整收据事件只允许在实际子请求完成后追加一次。完成生产者必须保留全部应有接受，等待队列及原付款选择边界必须保留精确的冻结/完成控制；选项不能注入这些控制。冻结继续委托既有免疫、不能冻结、解冻时钟、死亡、回滚和终局管线。

没有新增玩家命令、观察字段、GameState字段或实体/能力字段。请求与既有记录各加一字段、一个Effect，使用core403/schema324并拒绝旧1～323。默认False保留普通发现行为；默认311定义和指纹保持，存档机制签名及schema变化独立登记。
