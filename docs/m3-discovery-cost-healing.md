# 发现原选择与印刷费用治疗

象牙骑士CORE_KAR_057的当前卡面为4费4/4圣骑士随从，战吼发现法术并按其费用为英雄恢复生命。[来源包](../data/cards/discovery-cost-heal-v1.json)保留完整Core及旧别名原行、两张EN/CN官网卡面。实际进度、验证和下一项只在[项目状态](project-status.md)与[机制台账](mechanism-backlog.md)维护，国服精确规则校准独立登记。

`DiscoverFromPool.heal_hero_by_printed_cost`是显式布尔声明，默认False。当前仅支持一次、三个候选上限、普通可收藏法术发现、手牌逐次交付、原来源存在的有限形状；额外发现轮次、牌库/战场交付、附加减费、礼物及其他特殊创建声明均明确拒绝，没有为它们预做组合。候选资格、抽样、职业捕获、玩家选择和牌的交付仍由原发现管线负责。

真正选择时，原`choices.choice_effects`把完整ChoiceResult交给原ResolvePoolDiscovery。接受原选项、玩家、来源、提示和选中ID的一致性校验后，普通手牌交付之后排入`HealHeroFromDiscoveredSpell`，保存原ResolvePoolDiscovery与原GenerationContext。该有限Effect只在实际选择之后成立；没有选择或空候选池就没有治疗续接。

续接执行时再次校验完整选择及上下文，读取所选定义的印刷费用，并交给既有Heal。目标是原玩家当前英雄，来源仍用原来源ID。生成入手及其反应完成后才治疗；反应中退役或转控来源不更换原玩家，反应中的英雄替换也不重做已接受的发现选项。满手爆牌仍保留原选择，因此可以继续治疗；终局中断照原执行器处理。

FrameCodec对该Effect验证完整收据和池资格，边界校验还递归核对实际排队上下文与来源，包括其他反应造成的等待，不只检查当前发现选项。原GameState不递归遍历，沿用既有队列深度上限。非法收据、异地上下文、未声明治疗或未知合资格内容明确失败，不从后来手牌、日志或同名卡推断结果。这里复用现有存档自洽检查，不提供未签名来源认证。

真实适配器使用显式constructed.cards宿主池、可收藏SPELL与当前英雄职业查询，沿原中立政策，不硬编码印刷圣骑士职业。根卡依旧复用原生战吼；自然召唤不执行它。Core构筑同卡身份为KAR_057，原别名不注册占位。没有正式池或已注册卡回退名单，未实现合资格效果仍在抽样前失败。

当前内部政策采用所选法术印刷费用、交付及其反应之后治疗、原玩家当前英雄。费用光环/创建减费、隐式发现职业资格、具体反应窗口及特殊来源归因的精确国服规则仍待校准，不能以测试认证官方结论。此声明没有增加新的治疗结算器、GameState/Entity/Ability字段或玩家字段；新增一个有限Effect和发现请求布尔字段，core401/schema323拒旧1～322，观察89/命令12/replay1保持。
