# 原发现未选结果与传奇商贩

TLC_514的完整原行和两张严格双语官网主面保存在[data包](../data/cards/native-discovery-remainders-v1.json)。真实战吼发现一张传说随从牌，获得原所选牌并将其余原选项洗入本人牌库；职业资格沿已有当前英雄职业加中立政策。生成资格仍来自完整宿主constructed.cards，未知合格效果先于抽样明确报错，不删池、不把未知内容变白板。

有限新增声明是DiscoverFromPool.shuffle_unselected_into_deck=True，默认False。仅接受一次、三个选项、after_each、带原来源的普通可收藏传说随从手牌发现；不与费用、赠礼、属性、临时或场上交付等配方混用。丢失该语义的原手牌使用奖励包装器显式拒绝此声明，原普通请求保持默认行为。

原ResolvePoolDiscovery得到实际完整ChoiceResult，并校验原有序报价、选中身份、当前职业输入、来源、提示和选择结构。普通创建器直接交付所选基础配方并捕获实际创建分配；原获取通知及全部反应结束后，ShuffleDiscoveryRemainder才从原offered_card_ids减去实际选中身份。它不重新查找/抽样余项，不扫描后来手牌或同名实体；选中牌随后移区、重入或来源死亡不改变余项。

余项按原报价顺序交给一次已有ShuffleDeckCards语义操作；所有AddToDeck实际创建与随机置入均由原执行器完成，两个余项是一条declared_count=2的洗牌操作。该原执行器同步完成整组置入，随后才处理置入反应，不在本批另写洗牌或随机算法。原选中牌满手烧毁仍洗入余项；完整空池无选择，无收据或洗牌；不足三个选项只处理实际剩余项，空余项不造洗牌、不消耗额外随机。

私有discovery_remainder_accepted记录完整原选择、上下文和实际创建分配。唯一应有的ShuffleDiscoveryRemainder必须保留在等待队列及原选择边界证明，选择不能注入此控制；嵌套发现按各自choice_id保留独立义务，允许内层先执行。完成收据绑定同一完整原结果、实际语义洗牌ID、有序实际新牌库分配及原插入事件。解释器在同一步调用原洗牌执行器并记录完成，不留下可裁剪的第二层洗牌队列。

验证只从原effective_events读取当前提交时间线；真实Retry保留的旧尝试日志是诊断材料，不冒充当前义务或洗牌历史。当前帧不能丢弃、重复、换序冒充或借用已关闭的控制。获取反应终局时保留已创建牌与接受诊断，不执行未到达的洗牌；异常仍回滚当前动作。独立reader恢复、clone、回放、原随机流和信息投影沿公共解释器；完整原选项、内部收据和物理分配不进入玩家DTO。此为内部一致性证明，不提供未签名存档来源认证。

所选基础创建、获取反应后接受洗牌、整组置入反应和当前职业资格是明确本地政策，仍待M6国服精确时序校准；官网卡面不证明这些窗口或CN37.0热修集合。新增一个请求布尔字段和一个Effect，复用已有SourceAllocationFact/GenerationContext等payload，不新增GameState/Entity字段。core446/schema364拒绝旧1～363；观察92、命令12、replay1保持。实际验收与下一项仅维护在原两份台账，M0正式池、全部标准可达及阶段发布独立开放。
