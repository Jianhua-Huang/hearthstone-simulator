# 原牌库法术移顶与每回合牌库端点选择

诺甘农的圆盘 BE_250 是2费奥术法术。实际主体只构造原 `ReorderZone` 与 `AddPlayerEffect`：在主体原窗口读取当前物理牌库，分为法术和其他牌，两组内部保持原顺序，再把法术组放到前面。没有创建、销毁、重置或洗牌；原实体、附魔、费用、牌库容量及随机状态保持。稳定分区是内部政策，原正文只确认所有法术移到顶部，内部相对顺序仍待国服校准。

原 `TurnDrawReplacementProfile` 只把来源资格从原随从扩展到有实际 `on_play` 的普通法术，不开放 choice-only 控制面。玩家永久程序仍由原玩家效果管理；来源法术进入墓地不删除程序。原正常回合抽牌入口先看已有活体来源抑制，再按最新安装的适用替换执行。重复圆盘和迦顿等程序保留各实例，一个正常抽牌位置接受一份最新替换；此优先政策继续待M6。

圆盘的程序主体在本人回合开始的正常抽牌位置给出 `EFFECT` 普通菜单。两槽使用实际 BE_250t“保留圆盘”和 BE_250t2“翻转圆盘”描述符；不把隐藏的牌库顶或底实体、卡面、预览及完整顺序交给玩家。菜单不是发现，不添加发现记录或发现完成事件。手动额外抽牌、检索及抽到时施放的补抽不经过这个永久程序。

新增有限 `DrawDeckEdge(player_id, edge, source_id=None)` 只接受 top/bottom。top 委托原 `Draw`；bottom 在实际执行时捕获当前最后一个物理 `CardReference`，交原 `draw_one`。不是反转牌库，也不按卡名重找目标。原抽牌记录、手牌容量/烧牌、疲劳、抽到时施放、补抽、死亡/反应检查点与完成义务仍由旧抽牌器处理。正常回合的实际 Draw 保持无来源，原菜单保留永久程序来源。底部抽到需补抽的法术后，补抽沿原普通顶部管线；这个窗口政策仍待国服校准。

程序遇空牌库时直接普通疲劳，不产生无意义菜单；只剩一张时保留两个方向槽，但实际只抽一次。这些菜单边界、稳定分区、替换优先及精确反应顺序都是明确的内部执行政策，不由单卡正文自动证明为国服正式行为。
