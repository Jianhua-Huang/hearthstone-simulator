# 四张龙牌的普通公共效果

完整固定37.0原行和两个附魔证据行在[卡牌包](../data/cards/dragon-native-effects-v1.json)，行为在`hs_sim/cards/dragon_native_effect_cards.py`。实际进度、测试、差异和下一项只在[项目状态](project-status.md)及[机制台账](mechanism-backlog.md)维护。本契约限定内部表达，正式标准池和国服校准分别登记。

| 真实卡 | 执行表达 |
| --- | --- |
| 鲜花商贩 | 原`turn_ended/EndTurnSpec`捕获本人结束，当前其他友方龙中一次`RandomBuff(+1/+1)` |
| 龙龟 | 原手牌仍持有真实黑暗之赐随从时，给当前己方英雄本回合+3攻击、获得6护甲 |
| 碎裂扫荡者 | 普通随机消灭随从、有限随机消灭地标、普通消灭当前装备武器三个实际阶段 |
| 时光流汇扫荡者 | 原生回溯一次与7点随从技能随机伤害，每次真实战吼重取当前敌人 |

鲜花商贩使用原完整当前种族查询，包含额外龙族和all种族的实际匹配；排除自身物理实体、休眠体、地标和不活跃占位。未知当前种族明确失败，不能悄悄当作非龙。控制改变后的新触发按新控制者的真实本人结束捕获，已接受主体仍遵循原结束批次的窗口。空池不消耗RNG，沉默和离场沿原能力生命周期。

龙龟的原始主种族为野兽，完整额外标签同时声明龙族。条件复用已有黑暗之赐身份查询，只读实际本人手牌中的随从；龙龟出手后的自身赐福、普通印刷关键词和对手手牌不作为持有条件。重复战吼重新读取当前手牌、分别奖励，整次出牌付款一次。加攻使用原Buff属性层和当前回合到期，护甲使用普通GainArmor并继续保留。本批按英文正文先加攻再获得护甲，通知顺序及英雄替换等精确官方政策仍待M6。

`locations.RandomDestroyLocation(candidate_ids, source_id=None)`只增加有限地标随机入口。请求校验唯一不可变整数ID及来源，实际执行再次筛选仍在BOARD、活跃、耐久为正、未等待销毁的LOCATION；冷却地标仍可被消灭。按排序后的实际物理候选抽一次，空池沿原跳过事件且不耗RNG；来源即使在空池时也须合法。真正移除由已有DestroyLocation和共同死亡协调器执行，区域、空位、亡语、暂停及回滚继续共用原实现。

碎裂扫荡者的随从随机移除沿原RandomDestroy；地标阶段委托上述有限入口；武器阶段读取敌方当前唯一装备武器并调用普通Destroy。三个阶段按随从、地标、武器顺序独立结算，后一个阶段读取其实际执行时的当前局面，因此前一亡语造成的等待、来源死亡或武器替换都沿原队列继续。此分阶段顺序是明确内部政策，仍需国服时序证据；没有扩展原RandomDestroy的随从作用域或另写死亡循环。

时光流汇扫荡者声明原Keyword.REWIND与RewindSpec的一次重试，官网没有额外child卡面，未猜测耗尽形态。伤害种类为MINION_ABILITY，法术伤害不放大它；当前敌方英雄及活跃存活普通随从进入原随机伤害流程。每次实际战吼重取当前候选，死亡后的旧目标不会被后一次主体再次选中。[国服36.2公告](https://hs.blizzard.cn/news/24290432/)与[全球公告](https://hearthstone.blizzard.com/en-us/news/24290432/36-2-patch-notes)均有对应死亡目标修复说明；这条有限依据不认证全部随机分布和回溯时序。

回溯继续由原完整出牌检查点、资源/历史恢复、前进的随机流和单次最终支付负责。重试可以得到相同结果；有效致命结局直接完成。真实待选、恢复、克隆、回放和玩家可见句柄沿原协议，玩家不能读取全知检查点或RNG。真实卡CLI为`python -B -X utf8 -m examples.card_dragon_native_effects`，其中龙龟的赐福前提来自真实萨维斯和原牌库实体，四段均没有实验卡定义；跨职业、短牌库和显式法力仍是内部Scenario。

新增一个effect、无新payload、模型或GameState字段；core378/schema303拒绝旧1～302。观察87、命令12、replay1结构保持，默认311指纹与旧1085完整卡定义保持。两个附魔原行仅作来源证据；实际可达/生成资格、正式标准合法性、热修和M6国服精确行为继续独立核对。
