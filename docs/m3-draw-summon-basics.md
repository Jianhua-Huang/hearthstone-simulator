# 抽到时召唤与补抽：独立物理来源

成功抽到的随从可以复用既有手牌进度、原抽牌事实、揭示、原实体召唤和抽牌指令表达。没有新增关键词枚举、效果处理器、快照字段或组合模块。实际执行、验收与下一项仅在[项目状态](project-status.md)及[机制清单](mechanism-backlog.md)维护。

## 真实需求与原始证据

霍迪尔之子 `TTN_083` 洗入四张冰霜霸主 `TTN_083t`；这些 8/8 随从抽到时召唤。暗金教密谋者 `CAP_400` 的亡语将两张卧底小鬼 `CAP_400t2t` 洗入敌方牌库；小鬼抽到时为抽牌者的对手召唤，具有吸血。[霍迪尔之子官方卡页](https://hearthstone.blizzard.com/en-gb/cards/97099-son-of-hodir/)和[卧底小鬼官方卡页](https://hearthstone.blizzard.com/en-us/cards/127024-imp-formant)支持这两个召唤方向，未证明当前国服的满手、满场或精确监听优先级。

[完整 raw](../data/support/draw-summon-basics.json)保存四张真实牌及鱼人袭击者 `CS2_168` 的完整原始行和逐行指纹。冰霜霸主的主标签原样为 `CASTS_WHEN_DRAWN`，原始类型仍是 `MINION`，卡文和引用标签明确为 `SUMMONED_WHEN_DRAWN`。不能因标签命名将实体转换为法术、制造法术 CAST 或修改原始证据。这里只作隔离表达验证，没有将实验注册表并入生产代表包或正式候选池。

## 现有能力如何表达

随从定义声明 `HandProgressSpec('event', event='card_drawn', condition_id=..., on_complete=..., repeat=True)`。纯资格条件核对事件目标、原抽牌玩家、`draw_id` 及原 `DrawRecord`，只接受本实体真实成功进入手牌的 `outcome='hand'`。不以同名卡、当前手牌数量、生成／普通移动事件代替原事实。证明缺失或冲突明确报错。

完成回调按顺序返回：

1. `RevealHandCard(source_id)`。
2. `SummonStoredCard(CardReference.capture(source), recipient)`。
3. `Draw(drawer, source_id=source_id)`。

普通来源的 recipient 是原抽牌者；卧底小鬼是其对手。补抽仍属于原抽牌者。召唤移动原物理实体，保留 owner，controller 变为实际接收方；不通过 `Summon(card_id)` 新建替身。它没有支付、出牌记录、法术施放记录或战吼。来源本身的真实战吼／亡语仅使用既有 `AddToDeck`。

原抽牌记录保留真实手牌进入事实，随后的召唤是区域迁移，补抽是来源为该随从的新 `DrawRecord`。不凭空新增专用 outcome 或法术替代抽牌的 `parent_id` 关系。抽牌主体、事件捕获和继续工作由既有解释器处理。

`repeat=True` 让每次新的真实抽牌都能激活：同一随从因满场未入场，普通回牌库后再次抽到，仍须执行自身规则。不能用一次消费的手牌进度永久关闭这个印刷行为。普通复制、生成、回手或移动本身不产生成功抽牌资格；显式 `MoveCard(draw=True)` 沿原抽牌事实通路处理。

## 当前内部政策与待校准边界

| 情形 | 当前处理 |
| --- | --- |
| 连续抽到此类随从 | 每张原随从先召唤再补抽；补抽也可以抽到同类，完整收尾后继续原多抽指令 |
| 牌库已空的补抽 | 正常产生一次疲劳 |
| 原手牌已满 | 原抽牌烧掉，不建立成功手牌进度，不召唤、不补抽 |
| 指定接收方场面已满 | 沿 `SummonStoredCard` 既有失败政策，原实体留在手牌并揭示，仍补抽；不改投另一侧 |
| 抽牌者满场但对手有空位 | 对手定向来源仍可入场 |
| 同名旧随从已在手牌 | 不参与另一物理牌的原抽牌事件 |
| 手动打出此随从 | 按正常费用入场，不补抽 |
| 召唤反应导致对局结束 | 公共终局检查停止后续补抽，原未完成抽牌记录中断 |

当前场上监听先于手牌进度监听；接受的手牌工作复用既有原引用与继续帧。满手烧牌、满场失败后的留手／揭示／补抽、精确优先级均是明确的内部政策，须在 M6 以国服证据校准。官方卡文和内部测试不能替代这些边界的官方证据。

## 恢复、错误与信息边界

手牌进度、揭示、实际召唤、补抽待选均沿公共选择解释器保存原工作。独立注册表恢复、克隆和动作回放保留相同实体、历史与顺序；恢复不重复召唤或再次抽牌。回调稍后遇到未知定义时，整个动作回滚原实体、区域、历史、可见性和 RNG。

玩家看到公开入场的随从及原揭示卡，补抽的普通隐藏牌继续按原手牌规则隔离。全知抽牌／手牌进入历史、隐藏实体身份、内部工作与 RNG 不进入玩家观察。接口读取不会推进工作或消耗随机数。

## 保留范围

完整来源调查、特殊抽取／起始来源、精确国服政策及正式合法／可达池仍开放。本地卡文线索只是调查入口，不能当作穷尽范围。其他抽到时行为应先核对现有原事实和效果能否表达；缺少一个专用名称或记录 outcome 不构成新模块依据。当前不展开特殊授予、组合矩阵或批量接卡。
