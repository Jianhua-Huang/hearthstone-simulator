# 好奇的恐惧山猫与反向身材野兽

[完整原记录及四份主面](../data/cards/dreadlynx-v1.json)同时保留BE_850t好奇的恐惧山猫（5费2/5德鲁伊史诗野兽、嘲讽及战吼）和必要BE_850扭曲的恐惧山猫（非收集5费5/2德鲁伊野兽、突袭）。API全文保留战吼、突袭和相反身材说明，仅把两个动态数值显示成空的斜线两端；它没有将运行时身材定义成0/0。

`tools/card_batch.check_face`只允许这份完整原行pin配合显式`{'{0}':'','{1}':''}`省略这两个显示槽。保留全部规则正文、印刷费用/攻击/生命、类型/职业/种族等主面核验；原行、主面数字或额外规则变更不能借此匹配，其他源和任意宏不放宽。完整目录/单卡响应与字节收据仍按原工具保存，原未匹配观察保持。

卡牌主体仅在原生战吼callback窗口读取当前来源攻击力和剩余生命，以非负剩余生命作为野兽攻击力、当前攻击力作为野兽生命，构造普通`SummonEntryMaterial`并交给原`SummonByCard`。入场和接收者光环、突袭、数量额外体、反应、死亡、支付、选择恢复、回滚和回放均复用原内核。数量额外体保留本次原接受材料；后一次真实重复战吼在自己的body窗口读取新身材。来源被后续入场反应改变或死亡不会重写已接受材料。0生命实际入场后由普通死亡流程处理；沉默按原管线去掉入场设值并回到野兽印刷基值。

这里的callback窗口、剩余或最大生命、同窗光环、原材料冻结和默认放置仍属于待M6国服核定的内部政策，卡面与内部验证不证明全部细节。数据中的`behavior_verified/formal_pool_complete/cn_calibrated`未改为True。没有新公共效果、状态字段或玩家接口，core632/schema520和默认代表保持；正式池与实际可达域仍由M0闭合。实际执行、证据、差异和下一项只维护在[项目状态](project-status.md)与[机制清单](mechanism-backlog.md)。
