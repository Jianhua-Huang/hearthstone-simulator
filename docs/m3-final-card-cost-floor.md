# 原生双方法力值费用下限

TTN_924锋鳞使用`CostAuraSpec(CostSpec(minimum=2), relation="all_cards_minimum")`。这是所有可出牌卡种的连续约束，双方共享；英雄技能不在该CostSpec的卡种内。此声明只接受原生、可沉默、未消费的印刷附件，不能用一般授予光环仿造。

报价按原内在公式、本地附魔和其他外部操作结算；最后取全部生效下限的最大值。下限不是一次增费，既不能被后分配的减费穿透，也不能先把0提到2、再被+1错误算成3。多个来源不相加。附件编号和完整CostContribution仍按原顺序保存，物理付款与生成预览共同使用此规则；两类冻结报价校验都跳过下限的中间数值操作，在最终重新验证约束。

移除、沉默、控制方、休眠及死亡沿用公共光环生命周期。当前验收为固定本地规则，未声称完成国服边界校准；没有新增费用账户、存档字段或组合目录。core-effects-v734区分本次数值语义，schema587及观察/命令/回放协议保持。
