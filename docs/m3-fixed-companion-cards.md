# 固定动物伙伴与按实际容量填手

真实具名亡语循环召唤新的基础实体，伤害后的固定入手复用普通批次和交付；已有静电震击定义保持，未知虚空灵魂来源继续显式未支持。完整依赖、保存与目录/生效补丁边界见[契约](m3-fixed-named-followups.md)。

本契约覆盖动物伙伴、兽群呼唤、哈尔拉兹和完整霍弗/雷欧克/米莎/山猫。固定37.0完整原行和审核配方在[卡牌数据](../data/cards/fixed-companion-effects-v1.json)，行为在`hs_sim/cards/fixed_companion_cards.py`。[来源](../outputs/card-integration-20261014/k34-source-evidence.json)保留明确身份及证据限制。实际进度、执行验证、差异和下一项只在[项目状态](project-status.md)与[机制台账](mechanism-backlog.md)维护。

## 具名身份与公共声明

动物伙伴的官方目录`childIds=[100,226,959]`明确对应普通完整`NEW1_034`霍弗、`NEW1_033`雷欧克、`NEW1_032`米莎，不猜测Core衍生别名。三张根卡的构筑等价由具名`copyOfCardId`及完整原行核对。哈尔拉兹的等价原`TRL_900`保存明确`COLLECTION_RELATED_CARD_DATABASE_ID=50213`，指向完整`TRL_348t`山猫；根目录没有childIds不等于可以按命名拼接token。

霍弗声明冲锋，米莎声明嘲讽，雷欧克沿既有`AuraSpec(attack=1)`只给其他友方普通随从持续加攻；移除、沉默和复制继续使用原光环生命周期。山猫为1费1/1突袭；当前哈尔拉兹为4费4/2，自己同样具有印刷突袭。所有依赖保留不可收藏及原种族、职业和完整费用，不进入可收藏根分母。

## 固定候选与有序召唤

动物伙伴返回一个`SummonByCard`，材料是这三项完整`SummonEntryMaterial`，声明`selection='random'`并携带实际`SummonCause.capture(context)`。这是已命名固定家族，不是任意野兽生成池，也不依据已注册子集临时筛候选。原producer统一处理抽样、完整接受、额外数量、场位、入场和待选；额外数量复制沿原选中伙伴，不各自换抽。满场是否抽样继续遵守原容量政策。

兽群呼唤返回三个依次执行的确定性请求，顺序为霍弗、雷欧克、米莎，每个请求只有一个材料和实际cause。`materials`是候选集，不能把三个材料放进一个first请求来代表三次召唤。各次容量和反应分别结算，后面的请求不会顶掉前面已成功入场者；当前只有一个空位时先召唤霍弗。

该固定顺序有历史玩家说明作为第一手调查线索；找到的两个官方旧帖地址读取均为HTTP403，未取得原帖内容。转载页只用于定位地址，不作为直接官方规则依据，顺序仍需目标补丁国服校准。不能把历史出处或目录关系当作当前国服验收。

## 一次接受实际空位的填手请求

`zones.FillHandWithCard(player_id, card_id, source_id=None)`负责真实规则容量。执行时验证来源与完整可入手定义，即使没有空位也不忽略未知卡牌；沿既有`hand_capacity(player, rules)`取得玩家显式上限或规则默认值，计算`max(0, capacity-len(hand))`。数量超过结算预算则在分配前报错。

请求一次返回该数量的普通`AddToHand`，由原生成、入手、满手烧毁及反应管线执行；每张都是独立基础实体，不移动牌库，不抽牌或制造场上死亡、弃牌和额外RNG。哈尔拉兹离手入场后才执行填手，因此初始满手打出它通常补一个空位。非默认规则容量和玩家单独扩手均沿同一入口，不在卡牌脚本里固定写10。

空位数量在本次请求实际执行时接受一次。后来入手反应扩容不追加新的填手循环，缩容沿既有后续AddToHand烧牌政策处理。已接受尾项可跨真实待选保存，选择失败保留该边界，后续整次动作失败仍事务回滚。该有限接受/容量反应政策为明确内部契约，精确国服行为仍待校准。

## 保存与边界

新增请求注册在原区域模块，内核`core-effects-v337`及内容包`constructed-cn37-preview-v40`标识新语义；schema271布局保持，没有新持久字段、GameState账本或内核模块。原召唤材料、规则容量和AddToHand序列共用typed codec、快照、独立恢复、clone与回放；旧签名不能因schema相同被当作当前语义恢复。

默认历史代表包不追加这七项定义。玩家观察85、命令12和replay1结构保持，玩家只取得原公开场面/根卡事件和本人可见手牌，不返回完整候选材料、内部帧或RNG状态。内部保存一致性不认证未签名外部存档来源。

`python -B -X utf8 -m examples.card_fixed_companions`通过真实玩家命令展示随机伙伴、固定顺序与霍弗攻击，以及哈尔拉兹填手后本体/山猫的突袭。跨职业场景、短牌库和显式法力仅用于内部实验，不认证完整标准套牌、合法/可达池或精确国服时序。
