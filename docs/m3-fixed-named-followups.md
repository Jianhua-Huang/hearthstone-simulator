# 固定亡语循环与具名法术后续

本契约描述永生血瓣花、永生花芽、雷霆动地及已有静电震击的接法。完整固定37.0原行、已注册静电震击定义指纹及未接入虚空灵魂来源保存在[数据包](../data/cards/fixed-named-followups-v1.json)，行为位于`hs_sim/cards/fixed_named_followup_cards.py`。实际进度、验证、差异和下一项只在[项目状态](project-status.md)与[机制台账](mechanism-backlog.md)维护。

永生血瓣花为4费5/1，永生花芽为4费0/1不可收藏衍生物。花芽原始数据省略零攻击，官网中英文卡面明确为0；仅这一已核实字段显式归零，不据此把任意未知属性填零。血瓣花亡语通过普通`SummonByCard`创建花芽，花芽亡语通过同一入口创建基础血瓣花，均携带原`SummonCause.capture(context)`。这是具名新实体召唤；旧实体、受伤和属性附魔不带到新体。沉默、变形、非死亡离场、当前死亡控制者、主动触发亡语、额外召唤及实际容量继续由原生命周期负责。

雷霆动地为2费自然法术，在主体执行时从双方当前活跃存活普通随从捕获目标，提交一个1点`DamageBatch`，再用原`AddToHand`获得静电震击。伤害沿既有法伤、保护、通知和死亡解释器处理，死亡后出现的新随从不加入原批次；待选恢复保留后续入手。满手沿原烧牌流程，不删除奖励、不制造抽牌记录；反制阻断整个主体，自动施放共用同一行为。静电震击采用完整既有`TIME_218`定义，保留0费、自然学派、随从目标、1伤和本回合英雄加攻，既不重注册也不覆盖旧定义。

本批只注册两个根卡和一个新衍生物，没有内核、模型、effect、payload或协议变化。构筑内容身份采用`constructed-cn37-preview-v92`，旧内容存档不能因布局相同冒充新注册表；默认代表包保持。普通选择、回滚、快照、克隆、回放和玩家投影继续共用原接口。玩家不取得召唤材料、内部队列、完整历史或随机状态。

原四根卡前审中的邪恶的虚鳞纳迦、星尘之镰均具名获得虚空灵魂。完整官网child已核为`JAIL_732`，不是按前缀推测的衍生物。虚空灵魂的实际成长窗、未来同族状态和完整合格恶魔召唤池尚未闭合，三个根卡都保持显式未支持，仍留在目标内；不能只实现获取入口而把必要子效果当白板，也不能仅选已注册恶魔。

真实卡命令示例为`python -B -X utf8 -m examples.card_fixed_named_followups`。跨职业、短牌库和显式法力的Scenario用于内部验证；未认证正式标准构筑、完整生成资格或国服精确时序。伤害通知、死亡与入手窗口及额外召唤的精确官方政策仍须按M6校准。

国服官网目录与生效规则必须独立核对。[国服36.6.3公告](https://hs.blizzard.cn/news/24303864/)已将乘风浮龙延系减费从3改为2，而本次读取的国服及全球卡牌库仍显示3。保留固定37.0源和既有减2实现，目录用于身份与显示对照，不能覆盖有日期的平衡性公告。全部正式热修、禁限与实际可达清单仍需独立闭合。
