# 究极边境参考随从的公共效果接线

[完整数据](../data/cards/frontier-common-natives-v1.json)保留13个参考随从、两个真实亡语召唤物、两个库恩内部抉择面和三个Core原版证据，共20完整原行、30份完整双语官网主面。三个Core面与库恩两个内部选项本次官网API未匹配，[完整响应和逐项缺口](../outputs/card-integration-20261014/k554-frontier-common-natives/primary-availability-01.json)保留；三原版主面明确copyOfCardId包含对应Core身份，原行类型、费用和完整英文文本一致。Core物理ID与原版构筑去重身份分别保存，不因主面缺失删掉候选。

活化纪念碑、月亮巨人守护者、摩天龙和泰拉图斯按真实完整身材、种族和嘲讽/圣盾/复生/扰魔声明。冰霜巨人使用原PlayerHeroPowerCountCostSpec，海巨人使用BoardMinionCostSpec('all')，闪金镇豺狼人使用原HandCountCostSpec和突袭。原英雄技能历史、双侧场面、本人其他手牌及冻结支付/生成报价继续沿公共计价，不在卡牌层修改费用或伪造激活记录。

废料场巨像与石裔干将的真实亡语分别召唤BT_155t邪爆巨像7/7嘲讽、REV_375t墓翼蝠8/8突袭。归因及数量交给SummonByCard，位置复用既有deathrattle_position，天然死亡取原槽，额外主动触发取来源右侧。强音雷象的亡语使用原DamageBatch对敌方随从造成3点伤害；不包含地标，不把随从伤害当成可受法术伤害加成的法术。

遗忘之王库恩使用真实ChooseOneSpec与两个内部choice_only面。获得10护甲或刷新本人已有永久水晶的两种主体由原GainArmor/RefreshMana执行，兼得明确组合两者；不增加水晶上限或另造法力账户。真实范达尔资格、一次支付、分支及恢复继续由原抉择解释器负责，内部选项不进入生成库存。

典狱长通过DestroyDeckBatch一次移除原本人牌库，再将原捕获随从驻留交给GrantCapturedKeyword授予自身免疫。没有给其他随从安装免疫，也没有把“不能死亡”附魔当成本体规则；沉默仍可移除授予。销毁不是抽牌、弃牌、场上死亡或触发牌库牌的亡语。原销毁反应完成前不先授予免疫；来源在反应中离开原驻留时沿原引用失效政策处理。当前原牌库身份不公开，精确国服揭示窗口未校准，已在数据中明确记录。

黑龙领主死亡之翼在真实亡语主体接受时捕获本人手牌中当前龙的完整CardReference，按原手牌次序组合普通SummonStoredCard请求，原槽位置依次推进。原实体及其当前存储修改保留，没有手牌支付或战吼；非龙不移动，之后新获得的龙不加入已捕获组。后续引用失效、满场、额外召唤及全部生命周期继续委托原招募管线。这一组接受窗口沿本地公共政策，未另作国服校准。

这些定义只注册实际已知依赖，未修改公共内核、存档或观察协议。究极边境的参考34身份、原始来源模式/版本冲突保持，不能据本批完成度裁出生产池。真实发现与1费打出专项使用独立13成员实验过去域，公共能力在批内集中验证，不为每张简单卡重复整局回放；实际验收和剩余项只在[项目状态](project-status.md)与[机制台账](mechanism-backlog.md)维护。
