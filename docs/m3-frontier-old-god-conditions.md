# 过去古神的空区域条件与腐蚀历史副本

[完整固定数据](../data/cards/frontier-old-god-conditions-v1.json)保留BOT_424机械克苏恩、DMF_188亚煞极，污染之源两完整根及四份完整双语官网主面；另保留已实现DMF_064/DMF_064t的完整原行，不重复注册或覆盖旧原生卡及其腐蚀形态。两根来自既有究极边境34身份参考，没有把该表或测试中的两成员库存当成全职业正式过去池。

机械克苏恩的捕获主体只提交原InvokeBehavior，沿普通队列延后到实际执行时再检查原控制者的物理牌库、手牌及整个board列表。原亡语上下文的状态快照早于先前反应/主体实际完成，不能拿该快照作这个实时条件。任一非空即无效果，包含普通/休眠随从、地标及本人仍在场的主动亡语触发来源；对方场面不妨碍条件，武器、技能、奥秘和任务各自的独立区域不算board。自然死亡先由原死亡协调器移出整批身体，再按既有顺序执行主体；先前亡语或等待中的反应新加牌可以改变实际条件。不新增死亡检查点，也不缓存一个永不重核的空场布尔值。

条件成立只提交原Destroy，目标为实际敌方英雄，来源为原亡语身体。没有用巨大伤害代替摧毁，没有扣护甲或合成伤害事件；免疫、英雄致死协调、真实救援来源、终局及待执行工作仍由原执行器处理。这里不新增一套英雄死亡机制，也不替代其尚待国服校准的边界。

友方地标阻止条件有[玩家实际失败贴及讨论](https://www.reddit.com/r/hearthstone/comments/y2vz99/)交叉支持。该资料是玩家观察，不是开发者规则说明；精确极端窗口仍按本地政策记录。主体查的是本人完整物理board，不以是否是普通随从、是否活动或是否可成为目标裁掉占位。

污染之源亚煞极在真实战吼主体接受时，从原play_history逐条冻结本人已打出的Corrupted卡面。资格核对原记录card_id所绑定定义的Keyword.CORRUPTED，不读原实体后来变形后的卡面，不按中文/英文名字含“腐蚀”判断，也不计仅生成、持有、召唤或对方打出的牌。同名的每次实际出牌分别保留，不按身份去重；当前本地政策也保留已经计为打出的被反制记录。

每条记录组合原AddToHand，以该Corrupted卡面的基础定义创建独立副本，附原CostSpec(set_to=0)并在当前turn到期。普通区域执行器负责容量、溢出烧牌、交付通知、附魔及到期，副本自身不因减费到期而消失。战吼接受后剩余交付保持已捕获原组，后续手牌变化不加入新的历史成员。等待、独立注册表恢复、clone、回放和异常回滚仍复用原解释器。

“名称里的Corrupted不等于Corrupted关键词”有[官方论坛的玩家复现与讨论](https://us.forums.blizzard.com/en/hearthstone/t/corrupted-cards-generated-by-shaladrassil-dont-interact-wit/166543)交叉支持；不是官方开发者确认。已接入的腐蚀之血和莎拉达希尔梦境不能因此获得资格。无凭据的永久材料/无尽腐蚀属性如何返回、不同历史成员返回顺序、被反制与精确窗口仍未国服确认。当前明确使用基础卡面复制政策；[恐怖增生的早期讨论](https://us.forums.blizzard.com/en/hearthstone/t/new-neutral-epic-minion-horrendous-growth/43998)只是预发布猜测，不能拿来认证保留属性。三份Wiki页面读取返回403，未声称已读取或核实其规则。

本批不修改公共内核、状态字段或存档schema。两个真实根的主效果接入和内部验证，不等于所有可能历史材料与后续生成链闭合；原完整名单、来源模式/版本疑点、其它专用域及上述本地差异保持。实际验收与下一项仍仅在[项目状态](project-status.md)及[机制台账](mechanism-backlog.md)维护。
