# 过去随从的回合、区域、死亡与补抽消费者

[固定数据](../data/cards/frontier-zone-and-end-v1.json)保存DAL_553恶狼大法师、OG_042亚煞极、OG_133恩佐斯、NEW1_030死亡之翼、ULD_304法奥瑞斯国王、TRL_541夺灵者哈卡及TRL_541t堕落之血，共七完整原行和14份完整双语官网主面。哈卡原行COLLECTION_RELATED_CARD_DATABASE_ID明确指向真实堕落之血DBF，不用近似诅咒或白板代替。根均来自既有究极边境参考，血为实际必要衍生物，不因此开放独立狂野构筑范围。

恶狼大法师与亚煞极使用已有EndTurnSpec('controller')的真实结束声明，不套用任意时机的无条件触发。前者提交普通六费可收藏随从池请求，不加职业过滤、不裁掉未知候选；后者沿SummonFromZone移动本人原牌库随从实体，不复制、不抽牌或执行战吼。原控制者时钟、额外结束触发、归因、空池及容量全部由公共机制负责。

恩佐斯使用原DeathQuery(has_deathrattle=True, deathrattle_basis='printed')和Resurrect，计本人实际死亡记录中的原生亡语牌，按不同死亡发生而非不同牌名选择。原生亡语即使死亡时已被沉默，仍按印刷定义参与；临时授予给非原生亡语牌的内容不因此变成印刷亡语。原接受窗冻结完整死亡库存，后续反应中新死亡不加入；实际身体、基础重建、数量与满场继续交给原复活管线。这里沿已声明的本地印刷资格政策，未另行国服校准。

死亡之翼先用DestroyBatch标记双方其他当前普通随从，排除本人、休眠/失效对象及地标；死亡检查点和全部亡语由原解释器处理。随后延后InvokeBehavior重新读取本人当时手牌，再组合原DiscardCard请求，因此先前死亡抽到的牌也会弃掉。弃牌组捕获后新取得的牌不自动混入，原弃牌奖励与实体生命周期仍委托已有区域机制。没有把销毁数量误当本体亡语或重建一套弃牌器。

法奥瑞斯在真实战吼主体接受时，为当时手牌中的每张法术捕获quote_unselected_cost纯报价，并按原手牌次序提交对应费用的普通随机随从请求。非手牌法术、随从及之后新取得的法术不加入；原法术不离手、不施放或付款。后续场面反应重新定价不会改变已经捕获的后续费用。每次候选查询、随机、额外数量及入场依旧由SummonFromPool执行；不是每档固定一个样例，也不删除未知合格候选。

哈卡的真实亡语分别向两玩家牌库各随机插入一个新堕落之血，原牌保留。血声明真实CastsWhenDrawn、暗影派系、标准法术来源的本人英雄伤害及CastWhenDrawnSpec(after_draw=...)。主体只造成3伤；原补抽和补抽的全部反应完成后，after_draw才向该玩家牌库插入两个新基础血。回调校验原实体、原玩家、原血牌和真实after_draw阶段；手动打出血没有这次补抽或洗入。

连续血的补抽链先向下完成，回调再从内向外执行，空牌库的补抽正常疲劳；不能在原血施放时立即加入新血，否则会改变本次补抽和随机。满手/烧牌、异常回滚、死亡中止与等待恢复继续使用原draw_casts。真实版本下的极端复制材料、资格和精确窗口依旧按本地政策留档，不把内部通过冒充国服校准。

本批只增加真实原生定义与必需的血，没有修改公共内核或存档字段。专项中有限费用随从库存及六成员过去库存使用独立实验目标，不能据此绑定通用生产过去域；原34参考、模式/版本冲突和其它未完成依赖保持。实际验收、差异与下一项只在[项目状态](project-status.md)及[机制台账](mechanism-backlog.md)维护。
