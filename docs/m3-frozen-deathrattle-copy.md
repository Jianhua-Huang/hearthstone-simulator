# 原生亡语保存的随从复制材料

真实升腾还将同一copy_summon材料沿普通GrantDeathrattle绑定变形后的身体，使用独立有限授予来源校验，不伪装成目的随从的印刷声明；见[变形召回契约](m3-transform-original-deathrattle.md)。本页原生蛋的接受和重置政策保持，当前格式以新契约及两份台账为准。

腐蚀之巢EDR_454及恐怖的龙蛋EDR_454t使用[完整固定材料](../data/cards/corrupted-roost-v1.json)。地标为2费2耐久，蛋为1费0/2非收藏随从。完整原行的攻击值省略，两个完整官网主面明确为0；原文和标签均不改写。动态龙名的`{0}`只允许在固定原行PIN和显式声明下省略，不放宽其他正文、数字或元数据比较，见[有限显示证据](../data/support/card-source-egg-name-display-v1.json)。

## 接受、入场与亡语

地标沿原玩家目标规则选择当前友方龙；使用主体再次核对原目标仍为活跃、存活的友方龙，然后捕获其完整当前局部材料。`CopyEntryMaterial.profile='remembered_copy'`只允许原战场随从、current模式、无属性覆盖；它保存原分配事实、当前基础值、伤害、能力与附魔，继续排除派生光环缓存。后续原龙死亡、变形或新获增益不重写这份材料。

`NativeDeathrattleSpec('copy_summon')`使用`DeathrattleMemory.summon_copy`，不能混入其他原生记忆载荷。原`SummonEntryMaterial`可携带一份与目标印刷亡语声明一致的记忆，只接受无其他入场授予的普通材料。原召唤器在首次刷新及入场通知前把记忆安装到新蛋的原生亡语附件；即时入场死亡也能捕获完整材料。数量额外体各有新的附件身份，仍使用同一不可变复制材料。

真实亡语只读原`DeathrattleCapture`中的附件，交回既有`SummonByCard`、复制入场、死亡、数量与事件管线，不执行原龙战吼。原生亡语被普通效果提前触发时复用同一入口，蛋不因此自行死亡。现有当前复制保留蛋的记忆，基础复制及回手重置后为已知空记忆；这项空值表示明确的重置政策，不是未知卡牌的白板回退。未知定义、错误印刷声明与无效复制材料继续拒绝。

## 原时钟与恢复

延迟孵化不重新捕获原龙，也不重启已过期附件。`remembered_copy`入场沿原附件移除入口丢弃已失效的全局期限和本人区间期限，包括有限的下次开始触发；使用原实际本人区间及开始发布状态，不用全局回合奇偶猜测。永久层仍保留，接收方光环重新计算。完整组合部件继续由已有当前材料及普通入场器处理。

活动实体、死亡冻结材料、待选请求及嵌套复制材料核对原分配、捕获上界和原生声明；反序列化复用严格原生记忆解码。没有新GameState账本、Effect类型或独立结算器。core542/schema437识别新字段，旧1～436使用原引擎；观察99、命令12、replay1保持，玩家投影不输出完整材料和内部身份。
