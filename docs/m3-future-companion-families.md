# 未来动物伙伴的共同家族

MEND_300驯服宠物、MEND_303迁徙的雷象、MEND_307自由漫步的完整原行和六个严格双语主面固定在`data/cards/native-companion-replacement-v1.json`。它们分别请求印刷费用档+1并抽一张、战吼费用档+1，以及费用档+2后选择新伙伴召唤。自由漫步的后续调用仍连接同一次实际CAST，不额外付款、施法或执行战吼。

`MinionFamilyProfile`由卡牌层注册原有霍弗、雷欧克、米莎三个位置、固定规则版本及`constructed.cards`野兽池。内核不写卡牌ID。每位玩家从共同初始位置开始，`UpgradeMinionFamily`把每个位置替换成该位置当前伙伴**印刷费用**加指定值的随机可收藏野兽；手牌减费、场上费用修改和实物属性不作为费用档。已有实物、其他玩家家族与既有卡牌定义不受替换影响。三次位置抽选相互独立，可以得到相同卡牌，位置仍保留三份概率。

所有位置先完成完整宿主池查询和执行定义核验，再开始第一次抽样。资格使用既有`resolve_candidates`，保留规范身份、权重、正常特殊关键词排除和来源排除。完整池未安装、上下文不匹配或存在未知合格定义时明确失败，不裁成已实现子池；本次支付、原家族和RNG由普通事务一起恢复。实验测试池不认证正式标准合法池。

每个替换生成不可变`FamilyReplacementRecord`，保存在唯一新增的私有`GameState.minion_family_history`。记录保留原请求与来源、玩家、上一家族修订、规则/宿主池版本、原三位置、完整有序候选、新三位置以及MT19937前后状态。恢复时从上一修订和固定池重算候选并局部重演随机。原提交事件和实际宿主上下文也须匹配；回溯事件核对使用共同`effective_events`，不把已撤销尝试算成当前提交。它是执行一致性证据，不认证未签名外部存档的来源。

`companion_effects`在每次实际主体接受时冻结同一玩家家族修订与[塔雅逻辑数量](m3-companion-quantity.md)。原随机伙伴、兽群呼唤、MEND_301和EDR_853全都使用这一入口，没有第二套基础伙伴。未升级玩家保持原请求、三位置顺序、选项ID和随机政策；不因另一位玩家升级而要求其使用生成池。升级后的`SummonFamilyMember`按位置抽选或执行指定位置，再交普通`SummonByCard`完成实物、入场、属性、普通倍率和生命周期。三个位置相同也不去重；普通倍率复制本次已选体，塔雅额外逻辑单位各自选择。

候选家族修订在主体接受时冻结，各逻辑单位的随机位置在前次入场反应结束后才抽选。反应消耗RNG可影响下一抽，但反应中新升级的家族不改写已接受主体的尾部，之后新主体重新读取家族。菜单保留三个原位置的不同ID，预览显示该位置实际的新卡；重复卡面仍是不同位置。满场沿原不抽选政策；实体召唤失败和普通倍率继续由原执行器处理。

空费用档使用显式空位置，保留所请求的费用档，不为该替换消耗RNG、不借用别的费用或伪造白板。后续随机位置仍在三个位置间选择，选到空位置不召唤；后续升级继续推进该位置费用档，可以重新获得有候选的新伙伴。选择菜单也保留空位置。这些空档、费用上界、组内先后与家族冻结窗口是**本地政策，待M6国服校准**；完整卡面与[官网职业系列介绍](https://hearthstone.blizzard.com/en-us/news/24267730)没有证明这些精确边界，不将内部通过写成官方规则证据。

MEND_303的无条件嘲讽在原正文和双语主面均明确，但原运行标签未列`TAUNT`，仅保留在引用节点。候选查询目录只给这一个具名原行增加印刷嘲讽覆核，保留1188份原行、原哈希和完整主面；不把所有引用标签当成印刷关键词，不放宽执行定义与候选目录的一致性检查。

内核478、快照schema395拒绝旧1～394，构筑身份由对应内容版本固定。新增两个Effect和两个私有冻结载荷，一个GameState历史字段；实体、玩家、观察/命令/回放接口形状保持。默认代表注册表不登记此家族，空注册字段不改变其指纹。完整家族、候选、来源和RNG不出现在玩家投影或玩家事件中；原正常选择仅向对应玩家显示实际选项。
