# 固定对战面板与印刷形态

本契约是B15/U38的独立基础子集。它保存会影响规则的面板编号，并让明确注册的卡牌族选择完整印刷形态。实际测试和下一项只登记在[项目状态](project-status.md)及[机制清单](mechanism-backlog.md)。完整面板池、完整形态映射及国服校准仍开放。

## 依据与范围

[官方17.6公告](https://hearthstone.blizzard.com/en-us/news/23469099/17-6)说明转校生的效果取决于对战面板；当时的25种效果是历史信息，不是当前覆盖分母。[官方21.2公告](https://hearthstone.blizzard.com/en-us/news/23712592/21-2-patch-notes)记录了暗月马戏团面板效果的修复，说明映射也需要补丁依据。两者均不证明当前国服的完整对应表。

[已有客户端静态节点](../outputs/board-environment-basics-20261010/client-board-evidence.json)保留完整BoardDdId、BoardDbfRecord和GetBoardIdFromAssetName，证明正整数数据库身份及资源名查询方向。枚举中STW=1、ORG=2；节点没有转校生执行映射。本批没有重新反编译或启动客户端。[实际网页观察](../outputs/board-environment-basics-20261010/official-search-observations.json)保留检索结果，社区结果没有用来认证对应表。

[三个完整本地原始记录](../data/support/board-environment-basics.json)分别是SCH_199基础牌、SCH_199t圣盾形态、SCH_199t2战吼造成2点伤害形态；canonical pin为c45083b379872d7eeb4d5c97402c352f85e3178da00ddcb0727f2bfa187c0ca3。只在隔离专项中接入这三条定义，不扩充生产代表包或正式生成池。

**本地实验对应表：STW1→SCH_199t，ORG2→SCH_199t2。** 这是显式、待国服校准的政策；不能从枚举顺序或卡牌原始记录推断其已获得官方验证。其用途是验证公共环境事实及印刷形态选择。

## 公共声明

Scenario与MatchSetup接收可选board_id，GameState保存同一事实。None明确表示尚未指定；其他值必须是正整数，拒绝布尔、0、负数和字符串。不对面板随机抽样；宿主负责指定，编号存在不意味着属于当前正式合法池。

```python
from hs_sim.engine import BoardCardFamily, BoardCardForm

registry.register_board_card_family(BoardCardFamily(
    'transfer-student', 'experimental-stw-org-v1', 'SCH_199',
    (BoardCardForm(1, 'SCH_199t'), BoardCardForm(2, 'SCH_199t2'))))
```

注册表检查基础牌为普通可打出随从，基础牌没有可执行主体；结果必须为完整可打出随从，印刷费用、攻击和生命一致，声明元数据时结果不可收藏。族和成员不能交叉共享；编号不能重复，多个编号可以指向同一结果。表为不可变有限声明，政策版本、完整映射进入注册表指纹。未注册任何族时不新增指纹字段。

调用者应先注册所有完整定义及其主体，再注册族。不接受未知定义、任意计算公式或未解析基础牌作结果。这里只提供本基础需求的印刷随从族；其他特殊卡需求待接卡时判断。

## 选择与生命周期

公共game_boards模块在实体创建、普通场上Transform以及存储upgrade_face入口解析卡牌ID；后续沿原内核安装所选形态的印刷能力。没有第二套战斗结算器或新的效果类型。

| 入口或状态 | 本地行为 |
| --- | --- |
| 初始手牌、牌库、战场；之后获取、召唤 | 实体创建前确定形态，两席共用同一面板；不执行战吼，不消耗随机数 |
| 构筑与换牌 | 原卡组继续保存SCH_199，物理实体使用所选形态；抽取、换牌复用原流程 |
| 普通打出 | 按形态原费用、目标和能力执行；圣盾和伤害直接复用已有模块 |
| 普通复制、回手 | 沿原复制材料及回手重置政策；所选卡面不因复制或回手改变 |
| 沉默或已消费印刷能力 | 保留形态身份，遵循原生命周期；查询面板不会重新安装被移除或消费的能力 |
| 变形、存储换面 | 目标ID属于已声明族时，先解析完整形态，再沿原身份／附件／区域政策执行 |
| 选择等待、克隆、保存恢复、回放 | 原状态和起点保存面板，不重新抽样或重选；晚错误整体回滚 |
| 未指定或该族没有当前编号 | 明确ResolutionError，禁止静默生成白板或删除候选 |

传入任何该族成员都会按当前面板重新解析，这也是待校准的实验政策。当前实现没有面板切换动作；普通动作和返回的状态／观察副本不能改变面板。构筑存档额外检查当前board_id与原MatchSetup一致。未签名存档的一致性检查不认证其历史来源。

## 玩家与保存契约

面板是公开事实，两席观察根均含board_id。它不公开对手手牌、牌库顺序、宿主实体ID或随机状态。新公开字段进入观察revision和原玩家目标输入的严格canonical header；普通PlayerRuleContext可读取其公开副本。未知字段仍拒绝。没有新增玩家动作或命令字段。

当前规则prototype-v173、效果core-effects-v173、schema168严格拒旧1～167，观察74、命令11及replay1保持。当前状态存档必须显式保存board_id；构筑存档的match_setup也必须有该字段。未版本化的宿主配置JSON可省略可选编号，但不自动迁移旧存档。

## 已知边界

固定整局身份、上述两项映射、族成员重新解析及各入口选择时点均需M6国服校准。其他模式可能切换面板，不能套用本传统对战原型政策。完整当前可用面板、概率分布、全部转校生形态及其生成资格尚未锁定，分别保留M0/M6/M7。历史45条前缀记录含多种形态／附魔，不能直接当作45个合法面板或45种已执行效果。

本批不开发界面、动画、推荐策略、特殊授予或跨机制组合，也不宣布U38整族或整体基础目标完成。
