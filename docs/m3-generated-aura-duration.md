# 格尔宾的胜利与生成光环的额外期限

CATA_621的完整效果是随机获取一张圣骑士光环，并使该牌持续时间增加一回合。完整原行、两份官方主面和全部16条PALADIN_AURA原始标签保存在[data/cards/generated-aura-duration-v1.json](../data/cards/generated-aura-duration-v1.json)。官网未提供固定childIds；标签索引须与当前格式的完整生成池相交，不能按名称、当前已实现卡或固定五张标准候选构造结果。

PoolQuery.card_ids是纯身份白名单，空元组保持原语义；它与原牌型、职业、收藏性和其他查询条件共同生效。格尔宾使用全部明确标签ID、可收藏圣骑士法术和constructed.cards当前上下文。当前候选池的五张光环均有完整定义，但候选清单不认证M0正式合法性。完整合格池若包含未实现光环，必须明确失败，不能裁去它再抽选。

GenerateAuraWithExtraTurn只包装一张普通、原来源绑定的池生成，不接受费用、额外施放或随从创建授予等复合参数。所有合格成员先核原生光环定义，抽样仍由原生成器执行一次；create_hand_card在创建/获取事件前装入一个纯aura_duration_bonus附件。一个物理光环目前只支持一个此类附件，没有新增AbilityInstance字段，也没有用攻血或费用字段寄存期限。

当前材料复制通过原复制管线取得独立附件；base复制不继承。普通物理移库、抽回和转交保留它，实际施放玩家取得光环。存储卡面变化清除此类原生期限附件。上述复制/变形/转交政策是内部明确契约，仍待M6国服证据。

实际接受施法时，把原附件冻结进SpellCastRecord.aura_duration_grants；手牌额外施放沿同一原手牌施法材料，真实CastStoredSpell沿实际物理材料，普通全新自动施放不借用旧牌。私人aura_duration_accepted事件绑定实际cast_id和完整材料摘要。验证按实际ID关联，不假设自动嵌套施法按创建顺序接受；回溯采用原有效时间线。

AddPlayerEffect和PlayerEffect的aura_duration_cast_id只指向实际原施法，核同一来源、玩家、卡面和原生定义后，按原duration加一安装。本人/对手、开始/结束事件、首次接受窗、容量和普通倒数均继续沿原实现；不增加第二个时钟。来源进墓不撤销实例，同名再次施放各有期限，不能改写现有同名实例或全局规范定义。

私人aura_duration_bound把实际实例ID、原cast_id和原公开安装事件位置连接起来；全部增强安装事件须有且仅有一份收据，存活实例须保留其原关联。倒数降低到印刷范围后也不能删掉关联冒充普通期限。通用主体、重复/随机结束来源、生产数量与等待上下文统一核同一原期限；缺少State的纯生产声明仅核有限结构上限，其接受状态继续承担完整来源验证。

玩家仍只收到原公开光环类型和剩余期限；现有公开倒数范围为原期限或本次有限额外一回合。真实状态严格核原施法和最大期限，私人施法材料/摘要及关联ID不进入玩家DTO。损坏、遗漏或错绑材料会被拒绝，这不是未签名存档的外部来源认证。

实际源标签也确认CATA_480、END_011、TIME_700是原生光环。其既有主体和时钟保持，PlayerEffectSpec.kind由objective纠正为aura，因此真实TIME_019不再漏判。其他历史objective不自动转换。默认代表包311条完整定义保持；唯一默认身份变化是m5.sandfury_aura.kind，已有完整指纹重建审计，不能宣称旧指纹保持。两个时间光环在构筑包作同样分类修正。
