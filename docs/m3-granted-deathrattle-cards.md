# 法术授予亡语：增益、伤害与手牌招募

固定37.0完整原行和审核配方在[数据包](../data/cards/granted-deathrattle-effects-v1.json)，显式适配在`hs_sim/cards/granted_deathrattle_cards.py`。本契约描述行为与限制；实际执行、验收证据、差异和下一项只在[项目状态](project-status.md)与[机制台账](mechanism-backlog.md)维护。

## 身份与卡面

`CORE_UNG_952`使用当前5费卡面。官方目录的`copyOfCardId=[41864]`与原始行对应`UNG_952`构筑身份；`COLLECTION_RELATED_CARD_DATABASE_ID=41324`明确指向`UNG_810`剑龙。国服目录的`child_ids`为空，不能据此拼接一个衍生物ID。

剑龙是完整4费2/6、嘲讽、野兽、中立可收藏卡，不能标作不可收藏token或白板。它不属于当前标准根候选，却由标准卡直接召唤，因此仍在本轮必需依赖范围。注册它的完整元数据不等于允许它作为标准套牌根卡，也不把部分注册表认证为完整生成池。

## 公共授予与结算

剑龙骑术通过原必选战场随从目标规则接受、支付并结算，允许友方或敌方随从；英雄不是合法目标。主体依次返回公共`Buff(+2,+6)`、`GrantKeyword(TAUNT)`和`GrantDeathrattle`，三者都保存实际施法实体来源，没有新执行器或持续光环。已有嘲讽按公共关键词并集处理，多次施放保留独立属性附件与亡语附件。

亡语主体返回单一、确定性的`SummonByCard`，材料为完整`UNG_810`，`SummonCause.capture(context)`记录实际亡语载体，而不是把原法术施法者误当作本次召唤者。当前接受控制者获得新剑龙；新剑龙重建自己的印刷卡面，不继承原载体的增益或获得的亡语。

自然死亡使用原`DeathRecord.position`；主动触发时，有效载体仍在接受场面则插在其右侧，否则采用普通末端插入。这个主动位置与来源离场回退、同批死亡位置和逐步授予窗口是明确内部政策，尚未目标补丁国服校准。容量、数量贡献、入场反应、死亡检查点和已接受计划继续沿原公共召唤与亡语管线执行，满场不驱逐已有随从或另行抽样。

## 生命周期、恢复与信息

沉默移除本次属性和授予能力；回手后重打恢复印刷卡面；当前状态复制保留授予附件并分配新附件身份，基础复制不继承。转控后按当前控制者接受亡语，原所有者/授予者不是固定召唤接收者。所有行为复用既有附件、死亡历史、事务、等待选择及完整回放。不能把全知历史、随机状态或结算帧提供给玩家。

内容包以独立版本标识新增配方；`core-effects-v337`、schema271、观察85、命令12和replay1结构保持，无新内核模块或持久字段。默认历史代表包不追加这些定义；旧内容身份不能当作同一批新卡恢复。

`python -B -X utf8 -m examples.card_granted_deathrattles`通过真实玩家命令演示施放剑龙骑术、对手两次火球消灭载体及原位置召唤剑龙。短牌库、显式法力和跨职业场景只供内部实验；来源目录、内部验证和官方对局校准分别登记。

## 绵羊面具与洛戈什的奋战

绵羊面具DINO_429通过原`SetStats(1,1)`和`GrantDeathrattle`设定随从，不变形、不移除原生关键词；原生命设值清除累计damage，持续光环仍沿公共层。获得的亡语先通过命名回调取得实际执行局面，再对双方当前活跃、存活、普通随从提交同一`DamageBatch`，固定每项2点、`DamageKind.MINION_ABILITY`，来源为载体。它不借原法术的法伤，也不伤害英雄；载体自身的既有伤害规则沿原健康结算。主动触发时载体可能在该批死亡并再接受一次自然亡语，不能将它省略。

洛戈什的奋战CATA_610只授予一个命名亡语。主体使用`SummonFromZone(zone=HAND, cause=SummonCause.capture(context))`，从当前接受控制者的手牌随机召唤一个随从；位置声明与上文一致。原区域producer负责完整物理候选、保留选中实体及手牌附魔、入场、场位与数量额外材料，不抽牌、不支付随从费用、不执行战吼。多次授予的各个亡语重新查询届时手牌，数量额外副本保持各自已接受的材料。空池/满场和选择恢复继续沿公共招募政策，精确窗口仍待国服校准。
