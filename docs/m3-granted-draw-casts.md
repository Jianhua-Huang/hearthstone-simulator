# 阿米图特的原牌库复制与抽到时施放授予

[完整根记录及双语官网主面](../data/cards/amitut-v1.json)固定BE_143阿米图特，阿米图斯的守护者：七费5/8圣骑士传说、嘲讽战吼，为本人牌库中的每张神圣法术洗入一张具有抽到时施放的复制。没有具名衍生卡依赖；实际可达的神圣法术实现和正式合法性仍须M0/M7闭合，不能仅据数据主面认证。

战吼在主体窗口按当前牌库物理顺序接受全部神圣法术，包含同名的不同原实体。各项用`CapturedCardCopyMaterial`冻结当前卡面、局部费用及完整附件，交`CopyCard`和原语义`shuffled`。原牌不移动、不授予新能力；同一次主体不递归纳入刚生成的复制，后一次真实重复战吼重新接受新牌库。一次主体的成功插入是一组语义洗牌，空组不抽RNG/不获洗入信用，容量拒绝不分配失败复制；部分成功仍保留原声明数量和真实成员。

`CopyCard.cast_when_drawn=True`是有限声明，只接受当前本人原牌库的完整法术复制材料、随机放回本人牌库及明确来源。副本创建、当前材料安装和费用处理完成后，在原创建/插入通知之前安装一个具有默认`CastWhenDrawnSpec`的独立keyword附件。`AbilityInstance.draw_cast`仅允许这种持久授予，仍不开放通用`GrantKeyword`裸授予该关键词，也不允许附带自定义抽后回调或临时期效。原当前复制保留该附件并分配新附件ID；基础复制、物理重置与变形沿原生命周期清除授予，不把来源离场当作取消条件。

普通法术实际抽到时，原`draw_one`读取有效授予，冻结`GrantedDrawCastBasis`：原牌库物理分配、当时未消费的完整声明和原附件上界。它保存于`DrawRecord.cast_grant`；原私有`card_drawn`见证携完整不可变依据。行、原实体、卡面、声明、实际抽牌玩家/动作和事件逐项核对，拒绝缺凭证、未来分配、改借声明和改写私有见证。实际抽牌者可以与原牌库控制者/所有者不同，凭证仍保留原归属；施放、补抽和疲劳由真实抽取者承担。未签名保存不因此获得外部来源认证。

有印刷`cast_when_drawn`的法术继续使用原声明及抽后行为，新增通用授予不覆盖其策略。满手烧牌不启用授予，也不补抽。普通手动使用、生成、移牌和复制不冒充抽取；真正抽到的复制仍是原实体，沿[原抽牌施法链](m5-draw-casts.md)执行无支付自动施放、目标/选择、失效、替代补抽、原生反应和终局，不增加手牌使用记录或另建施法器。

授予、抽牌依据和续接均可恢复、克隆和回放；独立触发的等待选择保留原声明，选择失败和后续异常回滚原支付、牌库、附件、历史、RNG和玩家知识。完整依据、附件分配和牌库内容保持宿主私有，玩家沿已有关键词及受限事件投影观察。精确国服复制材料、完成/插入通知、满手与补抽及重复接受等窗口仍待M6核定。
