# 原死亡武器的洗回与自身成长

`ShuffleGrowingWeapon(weapon, death, player_id, attack_growth, source_id)`接受原`SourceAllocationFact`和完整`DeathRecord`，仅处理刚从WEAPON进入原控制者墓地的物理武器。卡面、owner/controller、epoch和装备顺序必须对应同一次真实死亡；记录必须仍在实际死亡历史中。后续该实体已移区或换面时跳过，不重绑新驻留、不另造一张武器。活武器主动亡语不在此入口范围，既有TriggerDeathrattles的随从范围保持。

操作复用普通印刷重置、属性附件安装、物理移区、随机插入和洗牌历史。重置普通费用/附魔和磨损，恢复印刷耐久；只保留本接口的`weapon_self_shuffle_growth`自身增长材料，再增加本次原生攻击成长。外部增益不冒充自身永久成长。此材料保留和准确死亡窗口为待M6的明确内部政策，不能从“永久”二字认证全部官方边界。

高山之王的战锤`TIME_209t`实际6费3攻4耐久、风怒，亡语通过原`ShuffleDeckCards`声明一次由实际控制者发起的洗牌，再调用此原死亡武器入口。来源取原武器，普通洗牌消费者得到完整发布者收据；原请求已移区后的重复执行不会生成新体、再次插入或额外推进RNG。仅实际发布的插入有洗牌记录，沿既有一位置随机政策，包括空牌库。

解释器和FrameCodec共同校验原分配及死亡；等待、选择恢复、回滚、clone和回放使用原管线。没有新增持久模型字段，schema417保持，core515保护新效果/语义；旧mechanics身份不能当当前运行时继续。原成长标签、物理材料、死亡和随机证明不进入玩家DTO，玩家仍见原普通武器数值及允许的洗牌事件。结构校验不认证未签名存档来源。

完整来源、原卡面和家族关系固定于`data/cards/muradin-fabled-hammer-v1.json`。当前仅适配战锤依赖；TIME_209穆拉丁仍未注册，TIME_209t2天神下凡复用既有实现，两附魔只作证据。原[设计说明](https://x.com/mynty_phresh/status/1977789937279016993)确认从己方手牌/牌库/英雄装备取锤，获得属性和风怒、不继承武器亡语；它不证明复制、沉默、归还材料或国服37.0时序。实际进度、验证和下一项只见[项目状态](project-status.md)与[机制台账](mechanism-backlog.md)。
