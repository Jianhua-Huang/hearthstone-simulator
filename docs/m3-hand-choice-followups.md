# 原发现选项与当回合出牌跟随

本契约规定地图真实卡文所需的独立公共能力：第一次发现获得一张牌后，保存原选项；当回合打出实际收到的牌，再从原未选项选择一次。它不是新关键词，也不提供任意“机制＋机制”或特殊授予接口。实际验证和下一项只见[项目状态](project-status.md)与[机制清单](mechanism-backlog.md)。

## 声明与既有能力

`DiscoverForPlayFollowup(request)`来自`hs_sim.engine`。`request`必须是以下之一：

- `DiscoverFromPool`：一次普通手牌交付，明确`source_id`；复用既有生成上下文、职业、查询、政策、完整候选和权重抽样。不能附带重复发现、场上交付、附加费用、法术重复或临时授予。
- `ChooseFromZone`：本人的`Zone.DECK`，明确`source_id`以及`copy_base`、`copy_current`、`take`或`draw`操作；复用原查询、去重、物理引用和抽样。`take/draw`必须保留独立物理选项。

卡牌回调只返回效果。例如隔离实验中的淹没的地图：

```python
DiscoverForPlayFollowup(DiscoverFromPool(
    ctx.player_id, "supported_murlocs",
    PoolQuery(tribes_any=("murloc",), class_mode="current"),
    source_id=ctx.source_id,
))
```

`supported_murlocs`须由注册表明确声明。该示例不能代表国服完整可生成鱼人池；未适配的合法候选仍明确报错，不能偷偷删除。

私有记录由`hand_choice_followups.py`维护，保存在`GameState.hand_choice_followups`。卡牌不能改写记录、RNG、选择帧或完成标记，不借用公开玩家持续效果保存私有候选。普通发现、选择恢复、出牌历史和区域操作继续沿原入口。

## 原选项和物理身份

原记录保存来源卡面、玩家、实际全局回合/所属回合区间、完整有序候选、原抽样前后RNG、第一次选择及结果、实际交付实体和成功手牌驻留。候选不会在之后打出或领取奖励时重新抽池。

生成与`copy_base`创建新实体；`copy_current`沿原当前复制；`take`移动原实体；`draw`走真实抽牌管线。记录在成功手牌交付事件前完成身份绑定，普通交付反应能够看到已经绑定的私有状态。满手烧毁没有成功手牌驻留，不武装后续奖励。

后续匹配使用实体ID、原`HandEntryRecord`及实际`PlayRecord`，不能用卡名、最近一次发现或当前牌库替代。已在手里的同名牌、普通base/current复制均不继承此跟随；原牌离开手牌或转交另一玩家后失效，返回不会恢复旧驻留。原地图法术离开执行区不删除已建立的跟随。

## 消费和到期窗口

当前内部政策在原回合完成`card_played`时消费一次。完成的实际付费出牌绑定原记录；非法操作不消费。已被反制但仍完成的出牌也会触发奖励，这是明确待国服校准的政策，不能当作官方一致性结论。

消费在捕获普通出牌反应前固定，奖励排在那些普通反应之后。期间等待会保存已经消费的记录和唯一待发奖励；继续时不会重复付款、消费或抽样。奖励选择仅排除原先选中的选项身份：按物理实体区分的牌库选项中，另一张同名牌仍是原未选项。

奖励沿第一次声明的交付操作处理。原物理引用已失效时明确记录`zone_target_skipped`，不重抽或偷偷换一张；base复制仍使用已冻结印刷选项。奖励烧毁仍完成一次消费。空池保存空记录且不消耗RNG；只有一个原选项时完成出牌后无剩余选择。

未消费记录在原`ExpireTurn`到期，即原结束主体与反应完成之后、下个实际回合开始之前。对局结束将尚在等待/交付/武装的记录标为结束，并放弃未完成工作。额外回合仍是新的真实全局回合，不延续旧“本回合”。这些精确窗口与迁移/复制/反制政策均待M6国服校准。

## 存档、回放与玩家信息

完整状态与帧codec保留原选择、物理引用、RNG和唯一交付完成/奖励工作。恢复重演原局部抽样并检查候选、原结果、驻留、实际消费出牌、活动选择分支与完成标记；不使用后来局面的牌库重判原发现。结构校验不能认证未签名存档的外部来源。

普通选择仍使用`ChoicePurpose.EFFECT`；此模块独立验证原选择结构，原`POOL_DISCOVERY`的即时交付格式保持。解释器的奖励请求与交付完成标记只作控制工作，不增加自身的伤害/死亡检查点。

玩家观察版本为72。仅持牌本人获得`play_followups`中的来源卡面、到期全局回合和原剩余牌名/ID；没有内部根ID、候选池、物理引用、历史或RNG。对方即便知道该手牌身份，也不能看到私有剩余项。等待中的选择继续遵循原玩家隔离。

开发身份为`prototype-v168` / `core-effects-v168`，snapshot schema163，旧1～162需原引擎，命令10/replay1保持。旧格式不被重新标号当作兼容。
