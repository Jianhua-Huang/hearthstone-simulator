# 按手牌数量持续减费

后续真实幸运币武器的有限筛选声明见[独立契约](m3-coin-hand-costs.md)：复用本数量阶段，另存完整当前卡面，不改变下文旧声明及事实形状，也不把旧载体资格一并放开。

本契约补齐两个真实独立费用输入：自己的其他手牌数量，以及对手的全部手牌数量。实际执行结果和下一项只在[项目状态](project-status.md)及[机制清单](mechanism-backlog.md)维护；不建立任意费用表达式或跨机制组合矩阵。

## 固定依据与有限声明

[三条完整原始记录](../data/support/hand-count-cost-basics.json)保存山岭巨人`EX1_105`、核心山岭巨人`CORE_EX1_105`及发条巨人`GVG_121`。canonical pin为`a55951de85fa213a7046d60c5c0501b88a042166d9e1d7d700eee1b8992b60e4`；固定本地原文和12费8/8数值不是最新正式合法池认证。核心记录仅作证据，两张必要普通随从仅隔离适配，生产代表包保持。

`CardDefinition.hand_count_cost`默认`None`，可声明`HandCountCostSpec(scope='friendly_other')`或`HandCountCostSpec(scope='enemy')`。政策固定`cost.hand-count-v1`，只允许普通可从手牌打出的随从，每张合格手牌减一费、最低零；其他scope、表达式、非普通载体及无真实审核来源的多个数量公式明确拒绝。

```python
CardDefinition(
    'EX1_105', '山岭巨人', CardType.MINION,
    cost=12, attack=8, health=8,
    hand_count_cost=HandCountCostSpec('friendly_other'),
    # 另需审核过的普通构筑元信息。
)
```

## 实际数量与物理来源

每次报价读取双方完整有序HAND驻留物理ID。所有手牌类型计数，不按费用、稀有度或卡名过滤；场上、牌库、虚空等区域不计入。捕获时核对每行的当前区域、控制方及已支持定义，包括另一侧、最终零费和当前不参与计数的行；未知内容不能通过零费或范围短路隐藏。

`friendly_other`统计实际payer手牌，只有真正仍在这副手牌里的报价物理ID才减去一个自身名额。同名的第二张山岭巨人是另一张手牌，照常计数。物理来源在场上或牌库时不占HAND槽，不减去不存在的自身名额。`enemy`统计另一玩家当前全部手牌，自己的手牌数量与卡牌身份不影响此数量。

纯生成报价没有物理ID。本地合同沿原“额外获得一张新手牌”的假设：新增的自身不计入其他牌，当前实际手牌全是它的其他牌。已有一张山岭巨人和一张其他牌时，实体山岭巨人为11费，新生成山岭巨人的假设报价为10费；不按卡名借用已有实体。满手时仍可查询这个假设，报价不执行获取或绕过满手烧牌规则，也不分配虚拟槽/实体。

抽牌、获取、弃牌、出牌、回手及满手烧牌沿原区域处理器，下一报价自然读取新驻留目录。不写基础费用、永久减费、附魔或缓存，不分配ID、不消费RNG和有限用途。

## 共享报价及冻结付款

`costs.quote_input`向原`capture_intrinsic_stage`传递明确物理`source_id`；生成入口保持`None`。数量操作在当前base之后、既有历史条件/本地附魔/外部层之前，最终最低费用仍由调用方处理。原枚举、玩家价格、支付验证和实际付款共用这些入口。

`HandCountCostFact`保存原声明、payer、原实体分配上界、双方完整有序物理ID、物理来源或生成None、数量及before/after。手牌身份和文字不是数量输入，原目录不保存对手卡面。`IntrinsicCostStageFact.hand_cards`必须显式保存该事实或None，完整重算数量、排除和金额。物理来源必须在原分配上界内且不是对手手牌；物理报价绑定相同来源，生成事实拒绝借用物理来源。

真实手牌接受收据还要求自身存在于原本人HAND目录，即便删去自身并重新计算“全部手牌”恰巧得到同一数量，也不能冒作原手牌依据。完整原付款证明沿既有解释器重算实际付款前状态；后续card_played待选、抽牌或弃牌不改写已接受费用，也不重复扣款。

紧凑历史验证检查原分配前缀与保留实体，并重算保存的原数量操作数，不用今天的手牌替换旧目录。它不认证未签名存档外部来源或协同重写的完整历史真实性。挂起恢复、clone、独立注册表回放和失败回滚沿原公共框架，没有另一套支付或区域流程。

## 生命周期、格式与玩家边界

声明属于固定印刷定义，普通印刷复制、沉默、回手及重新获取复用原生命周期；再获取后按当前手牌重新报价。不会将上一次看到的减费写成永久费用。特殊复制保留沉默/费用的精确国服政策仍待具体来源和M6核查。

首次落地为`prototype-v183`、`core-effects-v177`、schema172，明确拒绝旧1～171；观察74、命令11及replay1保持。所有定义新增默认`hand_count_cost=None`，所有固有阶段新增显式`hand_cards`，所以普通注册表指纹和费用保存格式变化；不填补旧字段。没有新Entity/Player字段、玩法事件或外部动作。

对手手牌数量本来公开，玩家可以看到本人卡牌由该数量计算出的价格；不提供对手隐藏手牌身份或其当前费用。原物理目录、subject_id、分配上界、完整付款证明和宿主快照不输出到玩家接口。不同对手卡面但相同数量应得到相同本人价格。
