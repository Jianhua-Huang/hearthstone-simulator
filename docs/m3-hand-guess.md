# 对手手牌猜牌与原接受答案

未来主义先祖TIME_041使用有限`GuessOpponentHandCard`，猜中后沿现有`BuffCapturedMinion`增加原随从4点生命。它与只展示真实手牌的`InspectHandCards`分开；不绑定展示卡面与真实手牌位置，也不生成或抽取展示的牌。

## 来源与待校准范围

[完整原行与双语官网主面](../data/cards/futuristic-forefather-v1.json)支持4费4/4、嘲讽、三张猜牌及猜中增加4生命。[官网卡面](https://hearthstone.blizzard.com/en-us/cards/120784-futuristic-forefather)没有说明干扰项的精确来源和抽样。

[历史拉祖尔的信使玩家讨论](https://us.forums.blizzard.com/en/hearthstone/t/is-priest-card-envoy-of-lazuf-really-showing-me-1-card-from-opponent-s-hand-and-2-from-his-deck/20391)报告一张实际手牌及两张原牌库内但不在当前手牌的干扰项。这是另一张同类牌的玩家记录，不能视为开发者确认未来主义先祖的规则。[来源收据](../outputs/card-integration-20261014/k268-futuristic-forefather/rule-sources-01.json)保留完整HTTP正文、SHA和推断边界。

以下均为明确的本地政策，精确抽样、重复身份、不足候选和通知窗口保留M6国服校准；内部通过不等于官方规则已经确认。

## 有限候选

从原对手当前物理手牌等概率选择一张真实卡面，每张实体一个权重。干扰项来自该玩家原始牌库，排除捕获手牌内全部生成身份；按生成身份去重，每个身份由原牌库首次出现的卡面代表。最多等概率无放回抽取两个不同干扰项，再打乱完整展示顺序。原始牌库与当前剩余牌库不能混用，当前手牌中的生成牌仍可成为真答案。

空手时不请求选择、不消耗RNG，即使场景没有原牌库材料。非空手牌却没有可靠原始构筑库存时明确报错；已知的小型或空原牌库显示实际完整的1～3张候选，不补造全局或职业干扰项。全部可能候选必须已支持，执行预算不足不能缩减规则数量；检查在随机前完成。

## 原答案、奖励及信息

私有选项材料保存原玩家/来源、完整原手牌引用及获取ID、选中实体、原牌库、干扰项和有序展示卡面。通用选择负责等待、恢复和回放，不在恢复后重新抽样。领取时核对原获取、完整选项及原来源；后续原手牌离开或换面不重算已接受答案。

展示选项的`entity_id`全部为空，不将真实手牌位置写入玩家知识。玩家只得到普通选择编号及预览卡面，不能通过实体链接、选项标识或事件读出正确答案；对手也看不到选择者的私密选项。完整快照仍只用于引擎内部。

奖励捕获原随从的`MinionReference`，由公共属性层增加最大及当前生命，保留已受伤害，不产生治疗事件。原本体离场、重新入场或失去原引用资格后，不将奖励转给新身体。支付、选择回滚、生命周期和重放继续沿既有执行器。

本次只新增一种Effect，未增加GameState账本、卡牌定义字段或独立载荷类型。core547/schema441拒绝旧1～440；观察99、命令12、回放1保持。实际进度、验证和下一项仍只在[项目状态](project-status.md)及[机制台账](mechanism-backlog.md)维护。


## K488 猜测原发现选项

可疑的炼金师/侍应使用[原发现来源记忆](m3-card-discovery-facts.md#k488-原发现的来源记忆与延后猜牌)，与本页前述GuessOpponentHandCard的当前手牌及原牌库干扰项分开。它们展示原发现实际给出的完整1～3项；完整池不足三项时不补造选项，空池没有问题，未知合格内容仍在原采样前报错。原选择者可以在自己的回合使用取得的牌，后续猜牌仍比较原选择，不按现在持有哪些牌重新决定答案。

猜牌者只得到普通私密菜单和卡面，不取得原选择ID、实体位置、谜题附件、来源分配或正确标记。猜中沿共享原发现复制器交付：同一原手牌驻留复制当前材料，否则使用原配方；猜错不交付。满手、复制来源、等待和回滚共用既有执行器，不能把所有奖励当作基础副本，也不能给未实际取得的同名实体补发效果。

历史问答和原REV_000e说明支持对手开始时的猜牌方向，精确CN37窗口、原来源生命周期、原备选显示顺序及特殊复制材料继续单独校准，来源和暂定政策见[原始说明](../outputs/card-integration-20261014/k488-past-suspicious-guess/source-design-02.json)。本页旧手牌猜牌政策保持；实际执行证据与下一项仅在两份主台账维护。
