# M3：原手牌随从的标本罐与延迟释放

昆虫学家托鲁TLC_841及标本罐TLC_841t使用[完整原始材料](../data/cards/hand-jars-v1.json)。原标本罐省略攻击标签，两个完整官网主面明确为0；空罐和已装随从的两段完整正文均保留，只在精确原行PIN及显式声明下省略分隔符和动态随从名，见[显示证据](../data/support/card-source-jar-name-display-v1.json)。这不放宽其他数字、正文或身份的比较。

## 原手牌与变形

EncloseHandMinions在实际战吼主体接受时冻结本人手牌中所有随从的有序CardReference；非随从、敌方牌和后来获得的随从不进入这份批次。每份EncloseHandMinion到达时重新检查原引用，已经离区、换面或转手的对象跳过；不会找另一张同名牌。仍有效时才捕获其当时完整当前材料，然后调用公共transform_stored_entity，沿原实体重置、手牌位置、隐藏身份和变形通知，不制造弃牌、抽牌、烧牌、入手或战场死亡。

remembered_hand_copy只接受原HAND随从的current完整材料，无属性覆盖或额外授予。它与场上remembered_copy分开：释放手牌来源时执行印刷入场休眠，不能继承场上已经唤醒的政策。当前基础值、附件、原生记忆和组合材料冻结，派生光环由接收方重算；既有原时钟到期检查沿原复制执行器，延迟释放不会重新开始已经过期的附魔。

公共存储变形仅增加可空内部播种参数，要求原手牌物理身份、完整复制材料和目标印刷原生声明一致，在第一次变形通知前安装到唯一的印刷亡语附件。旧调用默认空，仍走原路径。没有新GameState、AbilityInstance或DeathrattleMemory字段，也没有独立区域/死亡结算器。

## 释放、复制与信息

标本罐的真实亡语读取原DeathrattleCapture中的记忆，交原SummonByCard和复制入场；不执行释放随从的战吼。已知空罐有明确空记忆，正常亡语释放为空，不是未知卡回退为白板。原非死亡亡语触发、重复次数、召唤数量、满场、自然死亡位置、支付和异常回滚沿旧执行器。当前复制保留冻结材料，基础复制、普通回手重置、沉默和外部变形沿原生命周期；重复托鲁战吼可形成有限的嵌套罐子。

玩家观察仅在既有公开区域或本人手牌授权之后输出可选deathrattle_copies列表，每项仅含将释放随从的card_id，供显示名字。完整复制材料、原实体/附件身份、捕获时钟和对手隐藏手牌均不输出。已有恐怖龙蛋也能显示相同的原生复制名称。观察版本101；命令12和replay1保持。core562/schema456拒绝旧1～455，原引擎可读取旧档。

## 证据边界

卡面证明封装手牌、1费0/1、空罐和亡语释放的方向。逐份实际变形时捕获当前材料、附件/费用保留、临时期限、当前/基础复制、回手、控制转移、重复嵌套及精确反应窗口仍为本地政策，待国服M6；官网主面不能证明完整服务器时序。正式合法/生成池、全部可达内容和阶段发布验收保持独立。实际进度和下一项只在[项目状态](project-status.md)和[机制台账](mechanism-backlog.md)维护。
