# M3：原手牌随从拆分为两份当前材料

`SplitRandomHandMinion(player_id, source_id=None)` 仅从该玩家当前手牌中的随从实体随机选择一个。空池不消耗随机数；其他类型、牌库和对手手牌不参与。它先冻结原物理复制材料及当时费用、攻击力、最大生命值，再通过原私有 `temporary_hands.hide` 移出原实体，返回两个普通 `CopyCard`。没有新历史账本、模型字段或自定义复制结算器。

两份保留普通当前复制允许保留的原附魔、能力与来源，各自分配附件 ID，再由既有 `SummonStats` 和 `CostSpec(set_to=...)` 追加属性及费用设值。原基础材料和此前附魔仍可供普通基础复制、沉默与重置流程使用；存储统计缓存不替代材料。费用用原只读 `quote_unselected_cost` 取得，不支付或消费优惠次数；各新手牌随后仍应用普通外部费用层。

本地拆分政策是三个数值独立处理：偶数均分，奇数随机分配余下的 1；费用和攻击可为 0，生命至少为 1。当前随机调用顺序为选择原牌、费用余量、攻击余量、生命余量；无余量或生命下限令两份相同的维度不抽随机。所有数值在第一次获取反应前冻结，后续选择恢复不会再次抽取或读取原牌；第一份的反应仍可以影响后续正常入手的容量。

原实体私有移至 SETASIDE，退出原手牌连续驻留；不伪造抽牌、弃牌、销毁、烧牌、战场死亡、亡语或残骸。两份沿普通创建/入手通知顺序交付，满手由原容量和烧牌执行器处理。实际手动使用裂解术本身空出一个槽；满手自动施法仍可能烧掉第二份。这些物理复制、通知、异常回滚、待选、克隆、回放与玩家隐藏规则均复用原实现。

真实接入仅 `TIME_030` 裂解术（Divergence），完整 `TIME_030e1/e2` 为独立原始附魔证据，并未注册成新卡牌主体。双语官网卡面和完整原附魔证明费用、攻血的拆分方向；奇数独立分配、1 生命下限、精确随机调用顺序、原实体移出及各获取反应窗口仍是明确本地政策，待 M6 国服校准，不能以内部测试通过冒充官方验证。特殊临时来源、无限数值及完整可达范围仍须随实际来源核验，不宣称此批已穷尽。

没有新增显式载荷；公共解释器自动登记新 Effect，旧 `CapturedCardCopyMaterial`、`CopyCard` 和待选帧保存两份已冻结工作。引入时 core559/schema453，玩家观察100与命令12保持。实际结果及下一项仅在[项目状态](project-status.md)与[机制清单](mechanism-backlog.md)维护。
