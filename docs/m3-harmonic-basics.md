# 谐振/失谐的独立持牌轮换

[官方音乐节介绍](https://hearthstone.blizzard.com/en-us/news/23921497)说明这类法术在手牌中每回合切换两个模式。原手牌进度已支持换面后的下一阶段、连续身份与见证；两个完整形态相互声明为下一阶段，就能表达轮换，不新增谐振内核、事件、账户或存档字段。

本契约只核对独立持牌行为，不扩展组合机制、任意授予或更多载体。当前内部政策采用本人真实回合结束事实；官方介绍没有写出精确窗口，这一时序与完整生命周期仍待M6国服校准。执行进度与下一项只在[项目状态](project-status.md)和[机制清单](mechanism-backlog.md)维护。

## 既有声明

在两个有完整主体的CardDefinition上分别配置：

```python
HandProgressSpec('event', goal=1, upgrade_card_id=other_form,
    event='turn_ended', condition_id='harmonic.owner.end')
```

条件为原事件player_id等于当前持牌者player_id。这里不使用repeat=True：每个形态本身有一个新阶段，原公共解释器换面时保留进度链身份、历史见证与完成数，并用下一印刷阶段的空进度继续。各实体独立，实际事件见证去重；没有按全局回合奇偶推算形态。

## 执行与区域

只有实际手牌监听本人结束事实，牌库、已打出的牌与其他区域不轮换；对方回合不算本人结束。初始形态和本回合新获取保持其当前印刷形态，到下一个本人结束才切换。换牌/首回合开始不产生结束见证，因此不提前切换。

沿原事件解释器的捕获顺序：场上普通反应先于已捕获的手牌监听。结束反应后来新创建的手牌不能补吃旧窗口；离开/返回导致进度能力身份更新，不能复用旧捕获资格。这里沿用公共政策，没有另立特殊时序。

普通不重置移区暂停并保留已获进度，重新进入后等待新结束。current复制保存当前形态与进度，同时分配新实体/能力ID；base复制从当前印刷形态的空进度开始，不倒回历史上的悦耳牌名。本地费用修正沿原换面保留，base复制清修正；转交后使用新持牌者的结束事实。这些复制、移区、费用、转交及精确首次窗口仍待国服校准，不宣称全部特殊来源已覆盖。

## 恢复与信息

卡面、不可变进度与原见证随既有快照/挂起解释器保存。普通结束反应待选时尚未轮换，换面后反应待选时已保存新形态；独立注册表恢复、克隆和回放都只继续一次。条件异常沿原事务回滚先前普通反应的随机变化、卡面、回合、区域和玩家知识。

玩家仅见自己的形态与原公开进度摘要；对手隐藏手牌保持牌背，内部见证、能力身份、随机状态与区域历史不送给玩家。换面隐藏旧已揭示身份，沿原信息政策；结构验证不认证未签名存档来源。
