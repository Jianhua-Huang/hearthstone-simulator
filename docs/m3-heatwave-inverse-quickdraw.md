# 热浪来袭与原快枪事实的反向目标条件

本增量接入完整过去Mage179域中WW_377热浪来袭的实际效果。它仍是标准来源的可达依赖，不新增标准合法根；完整179运行源和NX2_001/TIME_857生产scope保持原边界。实际验收与下一项以[项目状态](project-status.md)和[机制清单](mechanism-backlog.md)为准。

[完整原记录与两份官网双语主面](../data/cards/heatwave-inverse-quickdraw-v1.json)与前批[证据行](../data/cards/past-mage-summon-draw-chains-v1.json)一致：2费火焰法术，印刷快枪，原效果对一个敌方随从及相邻随从造成2点伤害，快枪改为对所有敌人。复用已核完整响应，不新增网络请求、衍生物或候选池。

## 真实入口

| 原接受事实 | 目标与主体 |
| --- | --- |
| 快枪未生效 | 必须选择敌方普通随从；原主体开始时捕获该随从及物理紧邻的存活普通随从，交既有DamageCapturedMinionGroup |
| 快枪生效 | 无目标，不接受额外选择目标；原主体开始时捕获当前敌方英雄和普通随从，交既有DamageBatch |
| 初始场景手牌 | 保留既有旧手牌语义，不能当作本回合新入手 |
| 真正生成或抽到手牌 | 原手牌进入事实决定本回合快枪，不刷新同名旧实体 |
| 免费自动CAST | 保留既有quickdraw=false政策，按普通敌方随从域选择目标；空域不伪造快枪或伤害英雄 |

两种主体均使用普通SPELL伤害及法强。普通模式不跨过休眠或其它占位向外补邻居；原目标在付款接受后、正文前死亡或离场时结束空主体，保留原付款，不重选。是否快枪只读原physical/cast条件，不依据当前手牌、同名新牌或正文后的局面重新判断。

## 最小公共范围

`CardDefinition.target_condition`仅增加有限值`unless_quickdraw`；印刷关键词仍必须是QUICKDRAW，没有新关键词或通用反向条件语言。既有五种正向目标条件保持。新纯模块`engine/target_conditions.py`集中从原五个布尔事实读取条件；反向声明只对原quickdraw取反，缺失、未知或非bool事实显式失败。

普通手牌接受、玩家动作枚举、自动施法的有效声明、主体预检及普通根目标证明使用同一判断。原目标绑定和主体契约允许该同一有限声明，恢复时继续从完整原条件重算，不增加`unless_quickdraw`保存字段或把派生值当成另一事实。普通根/主体的原候选、原目标、原付款与信息权限保持各自既有证明。

没有增加状态、卡面或Effect/payload字段，也没有新的伤害、区域、支付、选择或恢复执行器。内核版本标识变化用于区分新的目标语义；保存格式仍沿原字段，旧内核存档继续服从既有严格兼容校验。玩家自己的play_conditions仍只有原布尔事实，对方手牌、原手牌进入历史和恢复证明不公开。

## 保留边界

源资料证明卡文和印刷身份；快枪的获取/到手/过期、自动施法false政策、物理邻位、正文前离场与精确伤害通知顺序仍沿本地已实现规则。正式国服的特殊替代、重定向和极端区域变化边界未据内部测试升级为已校准。版本/热修对齐与国服规则边界依用户指示暂缓；其它专用域和未实现卡牌继续保持完整活动目标范围。
