# 手牌更高费用条件与莎拉达希尔

`HandProgressSpec("higher_cost_play")`只表达真实法术的单次手牌条件：持有期间使用过费用严格更高的一张牌。无升级卡面、回调或额外关键词，不把莎拉达希尔标为普通腐蚀牌。

## 判定与持久事实

复用`hand_progress.corrupt_candidates`在原手牌提交时的完整比较：实际打出牌的冻结报价与另一张原手牌的当前报价。相等不满足，后来取得或复制出来的牌不追认原接受资格。原整次出牌完成后才推进；反制仍属于完成的出牌，自动施法没有手牌提交，不能用它伪造更高费用出牌。

原候选保留物理来源、附件和玩家身份。进展键同时保留原出牌ID及该完整候选，验证必须找到原完成出牌的实际候选；不扫描诊断事件，也不增加第二套出牌账本。

`HeldHigherCostProgress`冻结有限声明、至多一个原见证和出牌前缀。原手牌提交保存于`PlayRecord.held_higher_cost`，每次实际施法保存于`SpellCastRecord.held_higher_cost`，包括反制记录。根卡正文只读取实际施法的冻结条件；后来同一物理来源被回收、重新取得或改变进展，不能改写旧施法。

新物理手牌取得重置此条件；显式当前复制沿原复制管线继承已获得的见证，基础复制从零开始。手牌整卡历史重放取原`PlayRecord`，法术历史重施取原`SpellCastRecord`，将原条件安装在新执行实体上。其他牌和现有腐蚀/注能规则保持原政策。

## 梦境交付

正常与腐蚀梦境各为五张既有、完整且逐定义固定的牌。根卡选择原条件对应的一组，以既有`RequestChoice(sample_size=5, min_count=0, max_count=0)`捕获完整随机排列，再按该顺序调用`AddToHand`。没有玩家选择或发现语义；第一张交付前已确定完整组和顺序，通知反应或暂停不会重抽。满手按实际排列的前缀入手，其余走普通烧牌。

五张腐蚀梦境已有P55/P58实现，本入口仅固定十张已有定义，不能重复注册、替换其效果或将已有衍生物计作本批新增。

## 证据与边界

[暴雪32.0已知问题](https://us.forums.blizzard.com/en/hearthstone/t/320-known-issues/143315)说明比较莎拉达希尔显示费用与打出牌支付费用，并将梦境牌非随机顺序列为已修复问题。完整原行和双语主面保留在本批源包中。

该证据不等于固定国服37.0全部交互已校准。费用比较的精确接受窗口、重入/复制/历史继承、重复来源和通知反应政策仍须M6核对；本地内部测试不能替代国服实测。此有限能力不声明支持任意卡牌类型、任意授予或更多跨机制组合。

新增持久字段由schema423保存，旧422及更早存档拒绝；玩家接口继续仅投影原手牌进度字段，不暴露见证、私有历史或全知状态。
