# 持有期间的实际法力支出

CATA_131、CATA_132、CATA_140分别要求持有期间支出4/8/25法力。以既有HandProgressSpec新增有限mana_spent种类，按实际支付与明确消耗金额推进；不读取印刷费用或当前剩余法力，不运行任意进度回调或条件。

付款复用原CostUseReceipt，只有payment来源的MANA才进入；免费effect_launch、其他资源和零量不进入。明确SpendMana复用ManaConsumptionRecord的actual金额。原子推进发生在各真实写入后、通知捕获前；付款的独立投影走同一纯函数，原支付证明仍逐字段比较。正常手牌出牌冻结条件后支付，其自身支付从持续进度中排除；其他支付入口沿原支付函数处理。

原手牌驻留复用AbilityInstance的有序键、单位和完成值。每一类原收据ID单调，接受量按goal截断，一次完成后停止。重新进入手牌归零；显式current复制沿既有复制规则继承已赚取材料。PlayRecord新增HeldManaProgress，保存原spec、键/单位及两个账本前缀上界；战吼及历史重演读取原提交条件，不能从后来同ID实体、后续法力变化或当前持牌重建。

原fact验证连接完整现有账本，核对实际资源、金额、截断、前缀、原卡声明与时间；这是内部一致性证明，不为未签名快照认证来源。解释器和存档codec复用已有模型通道，无新Effect、实体或玩家字段。新PlayRecord字段通过schema身份拒绝旧存档，玩家只见已有hand_progress投影，不暴露内部账本键和前缀。

树人使用原临时法力/永久水晶；护巢龙的两张3/3嘲讽雏龙按原条件入手或沿普通有归因召唤；麦琳瑟拉使用宿主完整constructed.cards、龙查询与实际手牌容量填充，在创建时设置一费。未知合格生成内容显式失败，不裁池。完整三态原文及8严格主面保持。

支出类别、自身费用时点、复制继承和重演窗口为当前内部政策，仍需国服校准；实验生成池不认证正式池。实际验收与下一项仅在原两份台账记录。
