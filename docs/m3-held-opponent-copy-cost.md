# 持牌期间使用对手卡牌复制与无拘之魂

JAIL_433无拘之魂（Unshackle Soul）的完整原行与严格双语主面保存在`data/cards/native-held-opponent-copy-v1.json`。真实卡面是5费牧师暗影史诗法术，消灭一个随从；持有本牌期间使用过对手卡牌的复制后，本牌费用为1。[官方卡面](https://hearthstone.blizzard.com/en-us/cards/126124)支持这项需求，不证明全部来源与微观时序。早期派工文字误称Unbound Soul，原始资料和运行时名称没有随之修改。

## 原复制来源与当前卡面

`CardCopyOrigin(entity_id, card_id, owner, controller)`保存执行实际物理复制时的直接来源，而不是以后再查源实体的控制者或职业。`Entity.copy_origin`保存这份不可变事实，`PlayRecord.copy_origin`冻结实际提交载体的事实。它与既有`origin_entity_id`分开：后者也被召唤、历史重演和衍生物用于诊断，不能单凭其非空认定发生过复制。

普通存储复制、战场复制、存储召唤复制及已接受数量复制材料，共用此事实。选项执行中的真实物理、死亡或弃牌复制也保存原材料的来源；单纯按卡名生成、普通召唤和移动对手原实体不因此变成复制。当前/基础复制都冻结直接来源，当来源本来就是自己的复制时，新副本记录当前自己的直接来源，不沿祖先追溯为对手。这个复制的复制政策仍需M6核对。

同一物理卡的普通变形保留复制来源，故当前牌名/职业变化不丢原信用；裂变衍生物另保留这份信用，诊断来源仍可指向自己的父实体。[官方36.0.1历史修复](https://us.forums.blizzard.com/en/hearthstone/t/3601-hotfix-patch/162668)专门修正无拘之魂与心灵清扫者对复制变形卡的处理，支持保留这项来源。它不证明国服37.0的所有复制、裂变或变形窗口。把原牌变形成另一张牌不会自动产生一次出牌。

恢复检查原来源类型、玩家、已登记原卡面、源实体和不可变owner、分配先后，以及实际出牌与物理载体的复制来源一致性。来源以后移区、转控或换面不能重写旧事实；这些检查不提供未签名存档的外部来源认证。

## 原提交与连续持牌

`HandProgressSpec('opponent_copy_play')`只记录一份原始手牌使用见证，不带回调、升级、重复或任意筛选器。新`commit_play`共用原有一次付费出牌append；普通执行、法术付款投影及非施法付款尾部都调用同一入口。成功append后，在提交反应之前原子更新该玩家仍持有的其他监听卡，保存`play:N`。不新增出牌账本、事件系统、付款系统或逐卡闭包状态。

资格读取原PlayRecord的直接复制来源controller与本次出牌玩家的关系。同职业复制可以满足；同名牌、异职业生成牌、对手原实体移动到本人手牌都不能替代复制事实。已支付且提交的反制牌仍是一次使用；自动施法、召唤、获取、变形及手牌替代动作不另计一次手牌使用。本次主体或提交反应中后来取得的无拘之魂不追溯本次提交。

普通重新进入手牌清零这项持牌条件，回手、重新抽到及跨玩家移动共用原入口。显式当前复制继承已经取得的进度，基础复制不继承；所有新能力ID独立。达到条件后保持第一份见证，不因后续使用累加。连续驻留和显式复制的精确国服政策仍待M6。

## 原费用阶段与保存

`IntrinsicCostSpec(set_to=1, condition='held_opponent_copy', history_profile_id='hand.held-opponent-copy-play-v1')`只允许带上述原生持牌声明的独立普通法术。`HeldOpponentCopyMatch`保存实际payer、物理来源或生成None、原手牌进入、原play上界和第一份见证。只生成一张新牌的假设报价没有已赚取的物理进度，不能借用手中同名牌。

条件设值在原固有费用阶段，随后仍走本地费用编辑、外部光环/玩家政策和普通付款。实际报价、玩家合法动作及提交价格使用同一入口；物理费用事实与原CostQuoteInput的来源/能力见证一致，提交还绑定原手牌进入，SpellCostFacts亦绑定原物理操作数。保存后的费用事实按原历史前缀重算，不以今天的手牌条件替换旧付款。

内核481、schema398拒绝旧1～397。新增两项Entity/PlayRecord可选复制来源字段、两个冻结事实类型及有限声明枚举；没有新的GameState或PlayerState字段，没有新Effect/指令。等待恢复保留已支付提交及原进度，不重复扣款或重新记见证；异常按原动作或选择边界回滚，普通回溯重试重新执行原根，保留结果也不虚构新的出牌记录。

玩家投影只提供原本可见的手牌、价格和进度摘要。原来源物理ID、隐藏牌库、完整复制事实、见证play IDs、付款证明、RNG及等待帧不返回玩家接口。内部一致性验证、正式标准池、国服校准与全部实际可达内容分别验收，执行状态只维护在原两份台账。
