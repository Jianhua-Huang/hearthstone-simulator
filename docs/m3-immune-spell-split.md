# 免疫法强的原法术分裂预算

`RandomSplitDamage.spell_bonus_multiplier`只开放两个明确值：默认1沿原法术预算报价；0表示免疫Spell Damage。0仍要求原活跃CAST与SPELL来源，不得借非施法profile代替法术。非施法profile保持原默认值，不接收额外免疫声明。

免疫请求不把法强贡献加入预算，报价中的`spell_bonus`为0、贡献列表为空；真实CAST本身和原接受状态仍保留其施法材料。接受证明在原状态重算，根收据拒绝免疫请求夹带法强贡献。普通下一次法术材料的接受/消费由原CAST管线处理，不在卡层补偿或减掉当前法强。

两种法术政策共用原候选、逐点RNG、单位`DamageKind.SPELL`、生命/死亡/反应、等待、唯一完成尾和回放。内部单位仍为原1点请求，法强已经在外层预算处理，不给每个单位重复叠加。普通伤害规则、来源/目标倍率、预防、转移和其他既有单位语义继续执行，免疫法强不代表免疫所有伤害修正。

该字段进入原请求、状态历史、接受证明及完整关闭事件；结构变更为core427/schema345，旧schema344及更早须用原引擎。没有新增GameState、实体或能力字段、效果类型、载荷类型、计数器或第二执行器。结构核验不提供未签名存档来源认证。

## 骨刃乱舞

JAIL_445的[完整原行和双语主卡面](../data/cards/native-immune-split-v1.json)保留原349标签及`ImmuneToSpellpower=1`节点。真实2费、单邪恶符文法术先请求一个免疫法强的3点根；完整结算后，原续接读取当前全局回合中实际`DeathRecord.controller`属于施法玩家的死亡，成立才接受另一个3点根。原付款和CAST各一次，两个根各自接受新局面；不改写成提前决定的6点根。

首轮的真实反应可能新造成友方死亡，所以条件没有在出牌前固定。自动施法按其原施法玩家查询，不把当前行动玩家或死亡对象原所有者代替实际阵营。条件接受的精确国服窗口及其与单位伤害倍率、转换、一次法强材料的政策仍待M6；原始卡面不能单独证明服务器时序。

玩家只接收原公共伤害信息，内部预算、候选、RNG与政策证明不进入DTO。实际验证、差异和下一项仅在[项目状态](project-status.md)和[机制台账](mechanism-backlog.md)登记。
