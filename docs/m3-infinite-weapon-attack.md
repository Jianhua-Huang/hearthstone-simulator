# 无穷之手的本回合攻击设值

END_012无穷之手是3费4/2武器，印刷不能攻击英雄，真实战吼将本武器攻击力在本回合设为无穷。两条完整原行和两份严格双语官网主面保存在`data/cards/infinite-weapon-attack-v1.json`；END_012e只有一回合附魔的原始证据，不额外注册为可执行卡面。

不能攻击英雄复用既有`AttackPolicySpec('cannot_attack_heroes')`及英雄对当前装备的派生查询。限制随原印刷武器存在，不仅限于战吼回合；自动EquipWeapon和场景已有装备仍有4攻击及限制，均不执行战吼。普通主动攻击、攻击次数、反击、磨损和武器移除继续用原管线，本项不新增攻击规则分支。

## 原装备实例与普通属性层

`equipment.SetWeaponAttackForTurn(weapon, attack, expires_turn, source_id)`使用既有EquippedWeaponReference，原卡面、控制者、区域epoch、安装顺序和当前装备槽必须仍匹配。支持非负整数设值，期限必须是当前实际全局回合；无效来源/期限明确失败，原装备已失效则跳过，不扫描当前最新同名武器。

真实战吼主体执行时只接受自身仍为本玩家当前有效装备的END_012，捕获该次原物理引用。主体开始前已经被替换/转出时不改另一把装备；请求接受后再因选择反应被替换或转交，引用也不能追到新安装。新效果仅增加一个带`set_attack`及原`expires_turn`的普通Enchantment，刷新和通知沿装备原路径，没有另改base_attack、持久英雄增益或第二套倒计时。

设值遵循既有附件顺序：之前的增益在设值生效期间被覆盖，之后的普通增益保留其原行为；临时层结束后，既有永久增益仍存在。物理转交不重绑原全局回合，非本人回合不向英雄贡献武器攻击；实际当前装备者获得原武器的印刷攻击限制。正常替换退役旧限制，墓地中的临时层也由原全局清理。保存、继续、克隆、回放、异常回滚和玩家视图复用现有协议，没有模型/附件字段或保存布局变化。

## 明确的内部数值表示

本轮以既有内部正int32最大值2147483647作为“无穷”的一次设值，政策标识`int32-max-set-attack-v1`。只复用已有无穷伤害模块的数值常量，不把其伤害包饱和政策移植为全局攻击算法，也不将显示阈值作为逻辑值。后续普通属性运算保持原行为。

官网主面和本地原行只确认无穷文案，未证明此整数就是国服正式实现；精确无穷标记、上限/溢出及全部属性传播仍待M6。当前是可执行的显式内部表示，不能据设值、击杀或内部测试宣称完整无穷族已正式校准。

本卡是现场播报员完整标准武器池的必要依赖，仍有其他未知合格武器时须显式报错。具体版本、实际测试、进度和下一项仅在[项目状态](project-status.md)及[机制台账](mechanism-backlog.md)维护；M0正式池、M6、全部标准可达及发布门槛继续独立开放。
