# 双方原手牌混洗

私运之王托瓦格尔JAIL_852的战吼只返回`ShuffleHandsTogether(player_id, source_id)`。公共入口读取执行时双方完整物理手牌，保留各自当前张数，随机重分配并改变顺序；不会创建副本、抽牌、弃牌或进行牌库洗牌。数据、执行、内部验证和国服校准分别记录。

## 来源与明确边界

[完整源](../data/cards/joint-hand-shuffle-v1.json)保留固定37.0.0.255026本体与完整双语官网响应的核验材料，原8费5/5中立传说、无种族标签保持。[HearthstoneTeam公开答疑](https://www.reddit.com/r/hearthstone/comments/1tux9zu/escape_from_violet_hold_how_does_this_work/)明确保留手牌数量，牌可以换位或交换。网络工具取得的答疑摘录与直接HTTP读取403分别保留，不能把摘录标为完整HTML/API响应。

[营地机制汇总](https://iyingdi.com/tz/post/5665243)已撤除设计师早期“脏鼠偷取全部”的说法，转述工程师更正为只偷回实际进入对手手牌的己方牌；原本与后来都在对手手里的牌不能取得。该页还说明可行时至少交换一张、尽可能不与原手牌完全相同。完整HTML及SHA已保存；嵌入的两张卡图只是卡面材料，不能作为工程师原话截图或国服实测。

当前抽样政策是对物理实体作均匀排列，拒绝双方非空却没有交换任何实体的结果，并在可改变顺序时拒绝完全相同的排列。保留每张实体的权重，不在抽样后强塞一对交换而改变分布。双方合计不到两张不消耗RNG；只有一方有多张牌时仅打乱那方。精确官方算法、同名副本的“不同”判定、随机序列与接受窗口仍待M6，不能据此声明官方概率分布一致。

## 原实体与原驻留

公共入口先计算完整分配，再一次性安装双方手牌；所有通知捕获的都是完成分配后的局面。固定配额使用原已占槽位，双方满手不会因处理顺序烧掉对方换入牌。容量已经降低而仍持有超额牌时也暂保留原配额，此项待国服校准。

实际更换控制者的牌保留物理ID、owner和当前材料，推进epoch，复用`renew_hand_progress`及`enter_hand`建立新持有者来源和获取记录。留在原持有者手里的牌不离手，不更新epoch、获取记录或原生来源身份。真实神秘变形者的转手与米尔雷斯的新对手同步沿[原转手管线](m3-original-hand-entry-theft.md)，没有为具体卡牌另造结算器。

原生TIME_876的随机选面另修复同名随从产生相同选项ID的问题：每个原物理候选在既有私有选择材料中带独立candidate_id，保留重复卡面的各自权重；仍按原接受卡面变形，不从稍后局面重新抽选。

## 随机、通知与信息

混洗为不可中断的一次原分配，不把手牌搬到临时区域，也不发布虚假的空手。完成后只为实际转手牌发布原card_moved_to_hand，再发布双方原hand_reordered；普通触发、任务与镜像仍沿原通知管线接受。镜像同步在首次获取通知的触发捕获前完成。后续反应可以等待选择，但不能重新运行已经完成的混洗；下一次真实重复战吼则重新读取当前双手和RNG。

所有参与卡牌的旧跟踪句柄在随机换位后退役，新持有者只通过既有玩家投影看到应知材料。原完整分配、获取、物理候选和RNG不新增到玩家DTO。零张或一张的无变化请求不伪造隐藏信息失效。复制、恢复、回滚和回放复用原解释器；没有新增GameState账本或payload。

core538/schema433拒绝旧1～432，新增一个Effect类型；观察99、命令12、回放1保持。实际进度、验证结果、已知差异和下一项仅在[项目状态](project-status.md)及[机制台账](mechanism-backlog.md)维护，M0正式池、M6国服和全部可达内容继续独立开放。
