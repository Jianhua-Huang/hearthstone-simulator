# 艾雅所需的一费卡扎库斯药水

本增量只处理JAIL_504升级暗金幸运币实际可达的一费药水依赖。艾雅根、后手声明、三种硬币和永久替换仍待后续整卡接通；不接入狂野CFM_621根或其五费/十费药水。

完整原始目录固定为37.0.0.255026，来源及双语主面见[准备收据](../outputs/card-integration-20261014/k308-kazakus-potion-forms/prepared-03/source-review.json)。JAIL_504t3p是无流派的一费实体模板；九个CFM_621一费成分只作真实选项展示，通过显式组件声明调用公共效果，不能单独产生物理实体。CFM_621_m4是原2/2恶魔。JAIL_504t5仅为原始调查线索，官网未返回主面，本批不注册或依赖它；没有删去任何已知实际药水成分。

`ComposedSpellProfile`保存完整九成分、对应行为和有限目标声明。`ComposedSpellRecipe`把原模板和两个不同的有序成分编码进规范、有限长度的`potion:`身份；未知、递归、重复、非规范或逆序内容明确拒绝。解析卡面不增加静态定义、可变缓存或注册表指纹，也不改写原模板。只有包含火焰之心的药水要求一个普通角色目标。未初始化模板不可手动使用，自动调用也显式报错，不当白板。

`CreateRandomComposedSpell`从完整九成分抽两个不同成分，再按原脚本序号规范化。实际实体交付共用普通生成/满手燃烧，在普通发布前保存私有完整候选、原抽样、配方和MT19937前后状态。恢复局部重演抽样，不要求之后的全局RNG仍停在当时状态；这不是未签名存档的外部来源认证。

原脚本序号1～9提供真实成分身份，不足以单独证明官方执行优先级。两个不同成分、等概率抽样及规范执行次序是本地限定政策，均待国服M6校准；不能由36种可表达配方宣称已确认服务端权重。

`ResolveComposedSpell`绑定一个原CAST，逐次在新局面调用原组件行为。伤害/法伤、冻结、抽牌/疲劳、护甲、复活、召唤和属性修改仍交原内核，第二成分不会使用第一个效果之前的旧场面；不制造第二次出牌、额外支付或组件CAST。私有组件/结束证明和唯一后续游标进入原事件及待选帧，异常沿原事务回滚，终局沿原中断。随机恶魔使用完整宿主`constructed.minions`及普通collectible/demon谓词；缺失的合格定义不能从池中裁掉，正式标准域继续归M0。

整个配方属于实际卡面身份，所以原当前/印刷复制、存储施放及暗影之死能够保留两个效果。官方[36.6修复](https://hearthstone.blizzard.com/en-us/news/24294373/36-6-patch-notes)明确提到艾雅药水与暗影之死，故该真实入口在专项验证中单列。公开`spell_recipe`只在玩家可见实体中出现；对手隐藏手牌、完整候选、抽样与恢复证明仍保持私有。

不新增模型类/字段、GameState账户或明确帧负载；只新增两个Effect及非空时进入指纹的静态profile。快照483拒绝旧1～482，观察110，命令12/replay1保持。实际通过范围和下一项仅在原两份台账登记。
