# 卡扎库斯的自定义黑幕庭审

`CAP_405`的战吼先选择两个不同效果，再决定长度；选择不是施法、任务进度或发现获得。三段提供沿普通`RequestChoice`，每次效果从完整九项、随后排除第一选中项的八项中提供三项；第三段提供全部0/4/7费长度。接受窗口保存完整域、顺序、先前选择、原物理来源与MT19937前后状态，恢复重演而不重抽。只有最后一段完成才创建一张配方法术，满手沿普通燃烧，不补造替身。

## 原始材料与顺序

`data/cards/kazakus-sham-trial-v1.json`保留19条完整原行：根卡、三个未初始化模板、九个效果和三个长度选项、两个附魔证据及已实现的`CORE_LOOT_368`。32份完整双语官网响应经过原工具核对。虚空领主的完整定义逐字段固定，不重新实现其亡语。

冻结`CAP_405t1`的中文名称与正文为空；官网两个语言主面均返回完整英文卡面。这个确切原行使用已核过的英文名称，保留原空中文字段，不删掉该效果或把它执行为空。模板的两成分文本槽、四回合计数槽只作确切原行的显示规范化，数字和其它规则仍须匹配。`CAP_405tb1b`没有准确官网API主面，其完整原行与[官方效果展示](https://hearthstone.blizzard.com/en-us/news/24293282)的7费立即选项对应；不把缺失响应写成核验成功。

原生`TAG_SCRIPT_DATA_NUM_1`给出九个效果的1～9顺序：偷牌、抽牌、互攻、虚空领主、夺取控制、三个三费随从、+3/+3、减费、治疗。[同页官方演示](https://hearthstone.blizzard.com/en-us/news/24293282)先选+3/+3、后选控制，最终卡面和实际结算仍先控制、后增益，被控制的随从也获得+3/+3。这支持该组的固定顺序；其余配对及当前国服精确窗口仍须M6核对，不据一段演示认证全部配对。

## 不可变配方与原倒计时

`ShamTrialRecipe`用原模板和两个原成分构成规范身份，按原生顺序归一，共108种卡面。注册表纯解析卡面，不保存运行时定义缓存。原模板禁止手动使用，选项保持`choice_only`；不把展示选项增加为可执行法术。

7费配方使用一次正常CAST执行两成分。4费和0费配方安装普通`PlayerEffect(kind='objective')`，分别在一个或四个未来本人回合开始边界到期。不是四个全局回合，也不靠回合奇偶近似。区域准入、共享容量、原安装顺序、边界前捕获、倒计时和到期释放仍由既有玩家效果管线负责。边界反应中新安装的程序不消费已经捕获的同一边界，这是既有本地政策。

倒计时声明也从规范配方纯解析；安装保存原CAST、原实例、原玩家和原来源的私有收据。到期主体绑定这份原程序和实际到期事件，来源离场后仍按保存配方执行。到期不再支付或新建CAST，原程序在主体前释放区域。没有新增对局账户、计时器或模型字段。

两个成分分别交普通效果解释器，原成分游标跨获取、抽牌或其它反应中的选择等待保存。完成前一个成分及其反应后，再从新局面执行下一个。恢复不跳步、不重新抽样；失败回滚复用原命令事务。保存证明只保证内部一致性，不认证未签名存档的外部来源。

## 九个普通主体

偷牌用原自动抽选和物理`MoveCard`，不是复制、弃牌或对手打出；保留原当前材料，满手处理仍沿区域交付。随机控制只接受原连续战场驻留。抽牌、手牌/战场增益、当前手牌随从减费、治疗和虚空领主召唤共用现有效果。三个三费随从通过原完整宿主池、原生成组与实际召唤原因执行，不从已实现卡牌列表拼池，未知合格内容继续报错。

`ForceEachMinionAttack`只安排各原始存活战场驻留的一次强制攻击。每步从尚未执行的存活原始驻留中随机选攻击者，再从当前其它存活随从中选防御者；新召唤物可以成为防御者，不加入原始攻击者队列。没有有效对手时不抽随机数。实际攻击、死亡、亡语和原驻留失效仍交`ForceAttack`，不另写伤害或死亡结算器。具体随机次序、新召唤参与和准确窗口为明确本地政策，待当前国服校准。

## 玩家与保存边界

制造中的完整域、随机状态和内部身份只属于可信宿主。手牌配方只对其可见玩家提供`trial_recipe`，隐藏对手手牌不附带配方。激活后的普通公开玩家效果向双方提供配方及剩余本人回合数，完整实例和工作帧仍不公开。
