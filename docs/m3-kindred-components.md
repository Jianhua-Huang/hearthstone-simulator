# 原生延系部分与下一次延系

真实抽牌条件只读原两次物理抽牌，来源奖励绑定原连续驻留；按实际消灭奖励保存原目标与死亡原因，继续委托普通死亡、抽牌和法力执行器。有限请求及待国服边界见[五费随从契约](m3-five-cost-native.md)。

真实原生法术参数绑定原亡语执行与物理材料，当前费用/亡语抽取连接原手牌奖励；首回合和后续正常抽牌共用可移除来源门禁。有限字段、公共执行及未覆盖继承边界见[亡灵资源契约](m3-undead-resource-native.md)。

实际进度、验收结果和下一项只在[项目状态](project-status.md)及[机制台账](mechanism-backlog.md)登记。本文描述蛮鱼挑战者及其实际依赖的表达，未认证国服规则校准。

[完整固定配方](../data/cards/kindred-component-effects-v1.json)保留TLC_251及17张已有延系消费者的完整原行、摘要和明确角色。注册表通过不可变KindredProfile指定实际原生入口、成立部分、必要普通准备和不成立分支；不解析正文执行，也不为任意授予发明规则。原有卡牌定义保持，包装已有注册行为，内容版本随实际实现改变。

## 接受和重复

蛮鱼挑战者的真实战吼安装独立next_kindred玩家效果；来源离场、沉默或转控不撤销原玩家效果。实际延系入口在当前窗口捕获最近已关闭的本人回合关系、完整有序来源及次数。复用[本人回合历史](m3-kindred-basics.md)，不能拿本回合、对手或仅召唤历史代替。每个真实战吼调用独立接受，额外战吼不能沿用已消费的下一次来源。

当前本地政策为存在一个或多个待用来源时总共两次，各原实例一并消费；延系条件不成立也消费。普通非延系效果、对手的延系和单纯召唤不消费。失败条件消费、多个来源及特殊入口的精确国服政策仍须M6校准，历史玩家报告不能升级为官方结论。

普通文本、付款和整段战吼不因卡含有延系而复制：

| 原生形状 | 执行边界 |
| --- | --- |
| 纯成立部分 | 每次运行具名active主体，重读实际场面；自体奖励仍绑定原连续驻留 |
| 改为另一个效果 | 成立时重复active，不成立只运行一次inactive；不能另加普通分支 |
| 原抽牌或单次奖励上的延系修饰 | 原准备只执行一次，同一批原物理接收对象得到两次延系奖励 |
| 普通移除后延系伤害 | 原目标移除一次，接受的两次伤害分别在实际执行时读取场面 |
| 原生延系费用 | 报价冻结完整来源，成立时内在减费操作执行两次；实际付款时消费一次 |

火山长尾蜥只抽一张火焰法术，在抽到时施放接受前给原牌两份局部法术伤害；杂交育种只抽原四费用组，原组按完整一轮、完整第二轮获得减费；温泉踏浪鱼人的下一鱼人价格仍只减一，两份圣盾奖励绑定原实际付款，原圣盾消耗规则不变；封冻沉眠造成一次4伤，普通抽一张及延系额外抽牌分别表达。烧蚀毒雾只消灭一次，后续两波伤害独立执行。鳞皮科多兽每次重选当前最高攻击随从，雷兹迪尔每次重读对方当前手牌。

## 付款、恢复与终局

TLC_366、TLC_600、TLC_816通过原IntrinsicCostStageFact保存原next_kindred实例。普通报价、合法动作和生成报价查询不消费；实际付款的原投影与CostUseReceipt共享同一完整材料，零价也消费。后续历史验证使用原报价的来源，不能拿已经消费或后来新增的当前来源重算旧报价。没有实际付款的静态估价不消费该价格来源；实际自动施法的正文延系另走原生主体入口。

KindredActivation只在待执行帧携带原完整RuleContext。GameState中的KindredRecord保存紧凑原来源分配、历史边界、成立关系、完整角色计划与开始/结束身份，不保存递归全状态。每个执行身份和整根都有具名完成标记；准备中的内层主体保持嵌套次序。待选存档核对剩余计划和唯一完成标记，拒绝漏掉第二次、重复身份或替换成立角色。实际英雄死亡可以中断余下工作，记录真实game_ended事件/动作，不伪装完成。异常回滚仍由原事务处理。

这些材料是内部一致性证明，不给未签名存档提供外部来源认证。原状态和帧是受信引擎输入，不投影给玩家；玩家仍只获得原DTO、合法动作及可见事件。存档schema变更拒绝旧schema，默认卡牌指纹不变不承诺旧完整存档兼容。

## 来源边界

官方API卡面和国服公告只证明身份、数值、正文及发布时间。官方论坛的玩家发帖与其他社区报告均只作历史行为线索，不能据此宣称国服37.0的全部接受窗、来源叠加、费用消费或特殊授予已校准。当前只适配明确登记的17张原生消费者，其他实际标准延系牌仍按真实缺口继续接入；不宣称整族或完整标准池已经完成。
