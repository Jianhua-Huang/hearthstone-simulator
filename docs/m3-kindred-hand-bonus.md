# 原延系检索与原生手牌额外效果

[完整来源包](../data/cards/kindred-hand-bonus-native-v1.json)只接入托加和扭曲畸怪。四张前审来源与两个实际子卡的中英文卡面均保留，但活体疫病、尼珊德拉及其重组规则不因此成为已实现内容。执行、验证、差异和下一项只在[项目状态](project-status.md)及[机制台账](mechanism-backlog.md)维护。

## 托加的两次物理检索

`DrawPhysicalGroup(kindred_pair=True)`是明确的两次随从/法术牌库检索。它要求两个原宽域slot，普通抽牌组的默认False保持原行为；字段只通过关键字传入，旧的slot/index/arrival位置参数不移动。

第一次在当前物理牌库筛选当前卡面具有原生Kindred profile的牌，然后交给原`draw_one`。第二次在第一根抽牌及其反应结束后，从执行时的物理牌库筛选能激活第一次原卡面的牌：同类随从的任一种族相交，或同类法术的非空法术派系相同。匹配直接复用原延系的`query_for_definition`与`share_tribes`；完整副种族和“全部”参与，未知必要元数据明确报错。

第一次原`DrawRecord.card_id`固定条件主体，不能改读最终手牌、最新同名卡或抽牌反应里的其他Draw。爆牌仍有原选中卡面；离手或手牌变形不删除/改写第二次条件。无首次匹配就没有第二次条件，无第二次匹配就跳过该检索；两者不伪造疲劳或随机普通牌回退。每次仍是普通物理抽牌，可入手、爆牌、等待或结束，不使用生成池，也不打出任意一张牌来预先激活延系。

原续接保存同一明确pair政策，并在恢复时核对实际原抽牌的Kindred资格/类型关系。当前卡面profile与被移除正文的特殊资格、抽到时施放/重新进入等稀有来源，仍遵循已登记的本地M6窗口，不以本批正常路径证明完整官方行为。

## 扭曲畸怪的两个原生关键词槽

原始`TAUNT`、`ELUSIVE`、`DYNAMIC_KEYWORD1/2`声明提供初始嘲讽/魔免。当前入手沿原卡面初始化，不另外假定入手即时抽样。真实本人`turn_started`通过已有重复手牌进度监听，只有仍在原手牌的实例才执行`RotatePrintedHandBonuses`。

该有限请求保存`CardReference`，原卡面必须是有两个印刷额外效果的随从，当前两条原生printed关键词槽必须完整。它只替换这两个槽，不删除独立授予的手牌关键词/黑暗之赐。候选采用完整八项`BONUS_EFFECTS`，无放回抽两项；手牌原生槽允许突袭，不套用场上“现在能否攻击”的授予过滤。两项先全部安装、刷新，再发出内部通知，不暴露半次替换状态。

仍使用普通关键词能力、附件分配、消耗、当前复制、沉默和区域重置，没有额外可变关键词集合、来源计数器或CardDefinition字段。当前复制保留已选原槽，两个物理副本后续分别抽样；正常出牌保留当前槽，原回手重置恢复印刷卡面。牌库、场上、对方开始不作为“仍持有的本人开始”监听者。

初始时点、本人开始限定和重新入手政策是明确的本地M6政策，尚未国服校准；卡面比对不认证这些窗口。内部日志不自动加入玩家事件，玩家只获得既有当前卡牌投影，不获得候选、原引用或生产请求。
