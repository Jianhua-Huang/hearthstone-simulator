# 延系出牌主体与真实鱼人依赖

本文描述七张真实卡的原生主体及固定依赖；下一次延系来源、条件部分派发与原奖励承接见[原生延系部分契约](m3-kindred-components.md)。实际进度、验证结果和下一项只在[项目状态](project-status.md)与[机制台账](mechanism-backlog.md)登记。

## 声明与条件

[完整配方](../data/cards/kindred-murloc-effects-v1.json)保留固定37.0源中的七张根卡、两张必要衍生物和一份仅供证据的附魔原行。卡牌模块验证整个配方及每条完整原行的PIN；运行时不解释正文或根据未知标签猜效果。

火鳃鱼人、蒸鳍偷蛋贼、涡流风暴幼龙、异种虫女王和咒术图书管理员都使用随从`on_play`，不声明战吼。条件通过[原延系契约](m3-kindred-basics.md)读取最近已关闭的本人真实回合，查询使用各原生定义的完整印刷种族。同回合使用、对手使用和直接召唤不充当此前自身回合提交；空的最近回合取代更早的匹配。成立后只返回公共效果，不新增可变成立标志或跨局计数器。

## 依赖与生命周期

抛石鱼人的官网child 98738明确对应旧系列WW_001t“石头”，不是根据中文名称选取LOE_016t“岩石”随从。石头为1费、无学派法术，必须指定一个普通合法角色，造成3点法术伤害并正常接受法术伤害加成。蒸鳍偷蛋贼的官网child 118184及固定原行对应TLC_429t“幼年蒸鳍鱼人”：1费1/1鱼人、突袭。两张均为实际依赖，不能因所属系列不同而省略。

TLC_243e“风暴积云”只保留完整原始证据；免疫与到期使用已有能力附件，不注册可执行白板附魔。异种虫女王的官网child还列出已有TLC_903t；当前印刷正文不召唤该随从，不据child关系虚构召唤行为，也不重复注册旧定义。

随从奖励绑定原`MinionReference`，复制绑定原`BoardPresenceReference`；离场、变形、沉默、附魔复制及到期均使用各原公共契约。生成、复制和抽牌仍产生原事实，原生主体不直接修改实体、牌库、手牌或全局历史。独立恢复、选择、异常回滚、克隆、回放和玩家隐藏信息继续经过原解释器。

## 证据边界

原始七卡接入本身没有增加公共内核字段；下一次来源适配涉及的执行状态及存档边界另见原生延系部分契约。注册表内容版本改变仍会影响完整快照身份，不能用schema未变承诺跨内容版本兼容。

官方卡库的身份、数值、正文和child关系只证明卡面及关联，不能代替国服服务器的精确接受窗、反应顺序、复制继承或随机权重证据。鱼人候选必须采用完整种族元数据，不能只检查主`CARDRACE`漏掉双种族；候选池未完整时，EDR_999等随机生成入口保持明确未接入，不删除缺失卡后宣称支持。正式M0卡池、构筑热修集合与M6国服校准仍分别验收。
