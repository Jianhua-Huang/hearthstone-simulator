# 延系的原随机组续接

冰脊剑龙的普通部分只随机选取至多两个当前敌方随从并造成一次伤害；成立的延系冻结同一原组，下一次延系来源只增加冻结部分的次数。原付款、历史条件、来源消费、伤害、死亡和冻结时钟仍由公共层执行。

`RequestChoice.kindred` 是有限的自动准备回调：只允许零次人工选择、普通效果目的、无分支主体、无重复选择键，且原来源/玩家与不可变延系接受材料一致。抽样仍用原选择器；空池不抽样。它不能作为通用人工选择上下文。`ResolveChoiceResult` 显式携带同一接受材料，回调获得当前状态与原调用归因。

`RunKindredComponent.prepared_choice` 把同一原选择带给成立部分。它只属于有 prepare 的真实 active 角色，不改原接受条件或重做普通部分。原计划校验识别唯一的待执行自动回调，要求它位于原 prepare 完成之前，仍拒绝重复、替换、截断或重排。实际等待、恢复及回放保留原选择身份和完整接受材料。

冻结使用公共 `FreezeCapturedMinion`，以原实体、控制者、卡面及驻留核对后同步委托原 Freeze。死亡、转控、换面、离场重入或休眠不把原冻结转给新对象；前一个冻结的反应也不能误伤后来驻留。没有新的 GameState、Entity、Ability 字段或冻结执行器。

本地抽样/伤害与冻结检查点、双延系及条件失败消费仍待国服 M6 校准；内部保存一致性不提供未签名存档的来源认证。实际执行和证据仅在[项目状态](project-status.md)及[机制台账](mechanism-backlog.md)。
