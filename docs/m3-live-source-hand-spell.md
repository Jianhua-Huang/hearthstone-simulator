# M3：存活来源提供的原手牌法术

蛇颈龙群的伊度TLC_241及呼叫蛇颈龙群TLC_241t使用[完整固定材料](../data/cards/live-source-hand-spell-v1.json)。4完整原行及4严格双语主面保留两条原生附魔。伊度是4费2/7随从，没有虚构战吼或每回合触发；法术为2费神圣，主体仅组合普通+2/+2和授予圣盾。持续提供与回手由内核负责。

## 静态来源与唯一原牌

LiveHandSpellProfile只登记真实随从和2费神圣法术的对应关系，非空时进入Registry指纹。GameState.live_hand_spells保存有序LiveHandSpellLease：原MinionReference、所提供法术的完整原SourceAllocationFact、创建窗口、最后已处理出牌和退役标志。原分配事实保存当时卡面、持有者、区域及分配器上界，后来合法变形不重写该事实；没有新增CardDefinition、Entity或AbilityInstance字段。

同一实际、活跃、未沉默的场上驻留只提供一次原牌。原卡后来进入手牌以外区域，或手牌暂时没有它，均不会重新创建；源码、原实体和取得窗口不能借同名牌代替。初始场景、召唤、当前/基础复制、变形和控制转移都经同一来源核对。不同伊度各有独立记录；新驻留取得新记录，不能重新启用旧记录。

公共create_hand_card增加默认关闭的内部绑定与延后发布参数，先完成本批所有新来源及原卡记录，再沿同一announce_hand_card发布原创建/入手或烧牌通知。默认普通生成仍是原逐牌行为。既有光环刷新仅在真实结算时维护来源，场景初始化显式维护；普通查询、恢复和观察不补造卡。内部重入标志仅包围同步刷新，所有语义状态仍在上述可序列化记录中。

## 实际施法与退出

原物理法术的整次手牌出牌完成后，记录本次真实PlayRecord，并调用原ReturnSpentSpell重置、回手和取得；支付、实际CAST、圣盾、属性、满手烧牌及事件保持普通执行。整次出牌最多处理一次，反制也不把来源提供改为法术主体。自动施放的新法术实体、独立复制或其他来源生成的同名法术不继承这张原牌的记录。

原来源失效时记录退役，属于原玩家、仍为原法术卡面的手牌私有移出到SETASIDE，不制造弃牌、烧牌或死亡；已经施加的增益/圣盾保留。牌库中或被转交/变形的牌不被这份有限手牌清理删除。来源转控为新驻留，新控制者得到自己的原牌；普通回手再出、休眠恢复等视为新有效提供区间。

记录校验覆盖完整当前来源集合、唯一原牌、原分配上界、创建窗口、原已完成出牌及退役状态；稳定边界不能遗失应完成的原出牌处理。FrameCodec和状态解析使用有限冻结类型，没有任意回调、隐藏可变闭包或第二套支付/区域执行器。玩家投影不输出记录、原实体身份、捕获窗口或对手未知法术。core563/schema457拒绝旧1～456；观察101、命令12、replay1保持。

## 证据和待校准政策

官方[33.2补丁](https://hearthstone.blizzard.com/en-us/news/24223019/33-2-patch-notes)明确修复将呼叫蛇颈龙群洗入牌库时生成多个复制的问题，完整HTTP响应及哈希保留在本批outputs。实现以一份原牌记录避免此循环，不能靠“手牌无此牌”重新生成。该修复和卡面不证明全部国服时序：原物理回手与费用重置、完成/反制窗口、初次满手只尝试一次、弃牌/独立复制/转交、来源失效对牌库的影响及休眠区间仍是明确本地政策，待M6。正式卡池、完整可达内容和阶段发布验收保持独立，实际结果和下一项仅在[项目状态](project-status.md)与[机制台账](mechanism-backlog.md)登记。
