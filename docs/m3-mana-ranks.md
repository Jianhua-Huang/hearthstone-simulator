# 等级法术的自动阈值驱动

[官方贫瘠之地公告](https://news.blizzard.com/en-us/article/23622608/announcing-forged-in-the-barrens-hearthstones-newest-expansion)明确说明等级法术达到5、10法力水晶时增强，并且适用于手牌和牌库。原UpgradeHandCard只提供显式手牌操作；普通手牌进度也不能处理牌库中的自动阈值和高法力时的新获取。这个真实缺口由[独立模块](../hs_sim/engine/mana_ranks.py)补齐，换面继续使用原upgrade_face。

本契约只描述独立等级法术。未鉴定与谐振/失谐另行核对，不引入组合机制、任意成长公式或新的手牌能力授予。实际执行和下一项只在[项目状态](project-status.md)及[机制清单](mechanism-backlog.md)维护。

## 声明与身份

先注册三个具有完整主体的物理法术定义，再声明固定5/10阈值的族：

```python
from hs_sim.engine import ManaRankFamily

registry.register_mana_rank_family(ManaRankFamily(
    'wicked-stab-ranks-v1', ('BAR_319', 'BAR_319t', 'BAR_319t2')))
```

三个形态必须不同且完整，保持印刷费用、职业和学派；缺失或不兼容定义明确拒绝。族不能共享形态，声明不可变，注册表冻结后不能增改。当前等级由物理卡面表达，不另造玩家计数、附件或实体字段，也不从名称猜测资格。

新机制政策版本`mana-ranks-v1`进入可选族声明与注册表指纹。没有声明时不扫描或改动牌，原opening/生产代表注册表指纹实核保持。现有`prototype-v167` / `core-effects-v167`、schema162（拒旧1～161）、观察71/命令10/replay1保持；没有修改快照结构、动作/效果codec或默认既有规则。带族声明的注册表由不同指纹固定，不能借同一全局版本把它当作旧无声明规则。

## 实际更新窗口

真实变更事件在捕获普通反应之前同步两名玩家手牌和牌库，用各自当前最大水晶，使用原物理卡面与换面生命周期。场景初始化在信息对象建立后、首次信息同步前处理；自然回合增长在turn_started前处理，因此正常抽牌取得已经升阶的物理牌。

使用最大水晶，已花费、临时法力或过载不会代替它。小于5为第一阶，5至9为第二阶，达到10为第三阶；一次4→10直接换到第三阶，不人为要求第二个事件。当前内部政策只向高阶变化：降水晶/降上限、转给法力较低玩家不把已有高阶卡面降回；具体国服降阶/归属政策仍待M6。

新手牌/牌库获取，以及普通移动、复制完成后的第一个真实事件都同步。先完成复制材料化再换面，避免高阶身份携带旧低阶主体；当前持牌者控制资格，物理owner不被冒改。PLAY/墓地等区域不自动变化，已接受出牌的原卡面和主体保持。烧牌或所有特殊自动CAST来源没有据此获得全来源认证。

换面保留物理身份与普通费用/附加状态，提升区域修订使先前捕获的引用失效；费用修正不使用法术石的clear_local政策。新卡面即完成程度，不对无关事件重复换面。未新增独立升级事件或额外行动窗口，行为由原事实窗口表达。

## 验证代表与边界

[三条完整raw/pin](../data/support/mana-ranks.json)固定邪恶挥刺的2费三形态与2/4/6真实伤害。PIN为`6867d77c0b413778273c5f756bb99cd029d6ea41847b24ea0b7444a5350876cb`。适配仅在隔离专项注册表存在，生产代表64/合成3保持；场景不证明混合职业合法卡组。名称前审包含冒险武器/技能，不能以名称盘点宣称完整正式等级法术范围。

等待发生在普通选择探针，选择恢复后才真实改变水晶；独立注册表恢复、clone与回放一致。坏后续效果回滚水晶、卡面、区域修订和信息；导入的未结算低阶快照被拒绝，不由恢复代码自动修复。墓地用实际弃牌/已出牌路径验证，新获取是新的实体，未使用不存在的墓地MoveCard入口。

玩家只见既有手牌卡面与合法操作，牌库身份及对手手牌不泄漏。原换面会隐藏此前已揭示的手牌身份；精确可推断知识政策待M6，结构测试不认证未签名存档来源。正式来源/生成池、精确国服窗口、U33其他独立规则、H2及M0/M6/M7仍开放，不能以必要代表验证宣布整族或完整目标完成。
