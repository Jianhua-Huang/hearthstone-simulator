# 单次物理检索的空匹配续接

德雷阿佳丝 BE_703 的真实4费6/4亡语要求抽取一张古神；无法抽取时随机获取古神。本接法使用原 `DrawMatching` 的单次物理匹配，在实际查询窗口决定是否有候选，不在卡牌行为中预先扫描并猜测后来的检索结果。

`DrawMatching.on_empty` 默认为空的不可变 Effect 元组，只有 `count=1` 且 `empty_deck='skip'` 可携带非空续接。原执行器实际无匹配时返回该元组；有匹配时仍按原物理权重选择，并沿原 `MoveCard(draw=True)`、抽牌记录、烧牌和反应完成。已经选择到原牌后不再保留空匹配分支，不会因为烧毁、后来离手或抽牌反应重查并生成第二张。普通无续接检索、多次检索及疲劳政策保持原实现。

新字段只连接既有公共效果，没有新抽牌、生成、死亡执行器或状态账户。队列、待选恢复、错误回滚、FrameCodec 与玩家隔离沿原解释器；嵌套请求仍需通过自身完整参数核验。只能说明本地执行一致性，不能认证未签名存档来源。

德雷阿佳丝的物理查询使用印刷 `OLD_GOD` 关键词，所有职业均可匹配；不使用当前临时授予或普通随机生成禁令来过滤牌库。实际空匹配续接为 `GenerateFromPool`，显式允许 Old God 这一特殊关键词，其他生成资格和完整候选检查保持公共规则。满手时实际抽到匹配古神并烧毁仍不生成；空牌库或非空牌库无匹配均进入生成，不触发普通疲劳。此“无法抽取”的解释及精确相对窗口仍待国服校准。

[固定完整源包](../data/cards/drestagath-v1.json)包括根、三份已实现古神和一份未实现尤格的五行原始记录，根两份完整官网主面严格通过。固定源全部 `OLD_GOD=1` 行恰为 BE_009、BE_013、BE_017、BE_784；四者进入独立实验候选，既有三古神完整定义摘要固定。BE_009 仅有真实独立元数据，**没有注册白板可执行替身**。本源调查不能认证正式部署、热修或完整国服合法池。

**完整原生随机获取分支仍缺 BE_009 古神主谋尤格-萨隆。** 原生成器会在抽样前检查全部四候选，遇缺失明确失败并回滚，不能缩成已实现的三张或依靠特定随机种子绕过。当前只交付原生物理检索、完整候选声明和公共空匹配能力，不能声称德雷阿佳丝整卡完整支持。成功生成、生成前后等待等通用能力使用明确的 fixture 身份验证，不作为真实四古神生成成功的证据。待真实尤格接入后仍须补这张牌的原生完整分支验收。

接口格式起点为 core649/schema535，旧存档由对应旧内核读取；没有新增 Effect、payload 类型或公共模块。默认无该卡声明的代表包注册表身份保持，实际进度、验证及下一项仅在原两份台账维护，M0/M6/M7分别验收。
