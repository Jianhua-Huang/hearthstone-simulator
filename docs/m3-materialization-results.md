# 原实际创建与移动结果

真实发现的后续消费者需要原实体，不能按同名牌或实体游标重建。现有 opening.create_hand_card 和 zones.copy_physical_card 已返回真实对象；zones.create_deck_card 与 move_physical_card 补齐相同内部返回契约。实际进度、验证和下一项只在原两份台账维护。

create_deck_card(r, AddToDeck(...)) 直接执行原唯一牌库创建路径并返回 Entity：原费用/附加材料验证、插入位置和随机、创建/入库事件完全保留。注册的 AddToDeck handler 调用该函数并丢弃返回值，Entity 不作为解释器工作返回。

move_physical_card(r, MoveCard(...)) 执行原物理移动，成功时返回原同一 Entity；zone/controller/zone_epoch、手牌进入、原抽牌编号、移库/烧牌和信息处理保持。过期引用或已在同玩家手牌的空操作返回 None；满手烧毁返回实际墓地对象，不伪装为成功入手。注册的 MoveCard 非抽牌分支丢弃实体返回值；抽牌仍交 draw_one 的原完整抽牌/自动施法/替换抽牌流程，draw_one 原来就不把移动返回值排入队列。不要用物理移动 helper 冒充完整抽牌。

这些返回发生在原同步实体操作及通知之后、已捕获反应执行之前。内部执行器可立即捕获现有 CardReference 或复制材料，跨待选/反应使用原驻留守卫；同名牌后来创建、原对象离区重入或控制者变化不能让新对象继承旧引用。Entity 本身既不能作为 Effect 续接，也不能保存或直接传给玩家。

无新创建/交付执行器、生产Effect、实体/玩家/状态字段、随机抽选、事件或结算检查点。旧注册效果的结果与 wire 不变，core459/schema376/观察93/命令12/replay1及内容v255保持；默认完整快照精确保持是该有限兼容声明的证据之一，不代表未运行的全量已通过。

这只是原实际结果接口，尚未把普通卡池after_each/after_all、物理/地图/黑暗之赐、场上发现、余项和手牌复制等全部源连接到统一发现交付收据。TLC_483 宝库闯入者的真正原收件/发现后通知，以及TLC_460/460t完整生命周期仍待接通；不能据接口或绿测宣称这些整卡已完成。精确发现/获取反应时序及正式池仍分别归M6/M0。
