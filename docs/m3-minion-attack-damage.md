# 原友方随从逐来源攻击力伤害

真实来源为BE_732穿刺者克洛恩（Kronn the Impaler），10费猎人元素传说6/6。完整原行和两语言完整官网主面保存在[源包](../data/cards/kronn-impaler-v1.json)，卡牌层只有[普通公共效果调用](../hs_sim/cards/kronn_impaler_card.py)。实际进展和下一项仅在[项目状态](project-status.md)与[机制台账](mechanism-backlog.md)维护；本页定义有限内部契约，不认证国服规则。

`EachMinionDealsAttackDamage(player_id, source_id, remaining=None)`首次执行时，按当前物理场位顺序保存原玩家活跃、存活、非交互物体随从的完整`BoardPresenceReference`组，包括仍符合条件的战吼本体。后续只处理原组；新入场随从不加入，离场再入的同实体ID不重绑。`None`表示尚未接受组，空元组表示原组已结束，不能将两者混同。

每一步检查原驻留是否仍为活跃、存活的当前友方随从，读取其当前攻击力及原玩家当前敌方角色域，组合原`RandomDamage`与剩余续接。每次普通随机选择、伤害、死亡及反应完整执行后才进入下一步。变形保留连续驻留并使用当前材料，转控后不再符合当前友方条件；新敌方随从进入后续候选。战吼载体离场不取消其他原参与者。原生额外战吼是新的主体接受窗，重新接受整组。

每击的`source_id`是实际参与随从，`DamageKind`为`MINION_ABILITY`；不借用战吼载体作为全部伤害来源。攻击力数值、剧毒、吸血、潜行消费、圣盾/免疫、伤害事实和所有生命结算均交原公共管线。它不是强制战斗，不消耗攻击次数，不要求冲锋/突袭、解冻或攻击准备，也不产生普通反击。法术伤害不增加该类伤害。目标使用普通随机角色域，潜行/魔免不是手动箭头保护门槛，休眠/地标/交互物体不进入。

零攻击力保留`RandomDamage`原抽样及零伤害语义；不为减少RNG而裁掉原参与者。原组为空不抽样，陈旧参与者在抽样前跳过，终局沿原解释器截断剩余工作。随机目标已经接受后，攻击力或来源的后续变化不改写已排定的普通伤害，剩余来源仍在自己的后续窗口读取当前局面。

效果为单一不可变公共指令，没有新随机、伤害、战斗、资源或状态账户。`FrameCodec`恢复原组，检查唯一实体引用、原实体存在和驻留分配上界；每次正常执行也校验，空尾不绕过未知来源校验。整动作与失败选择回滚、独立注册表快照、克隆、回放和玩家投影共用现有解释器，内部剩余组、驻留编号及RNG不能进入玩家DTO。

上述组接受顺序、逐步而非同窗的数值/候选时序、当前友方条件、零攻击抽样与已接受伤害政策均为明确本地参数，仍待M6国服校准；不能仅凭卡文或内部测试宣称官方全部细节一致。core629/schema517拒绝旧1～516快照，原命令/观察/replay协议保持。机制签名按原规范排序，只有新增指令进入效果类型列表，全部旧类型及顺序保持。
