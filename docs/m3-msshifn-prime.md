# 姆希菲的真实抉择与具名真菌身体

[完整资料](../data/cards/msshifn-prime-v1.json)保留孢子首领姆希菲、终极姆希菲、两个抉择展示面和真菌守卫/打手/巨怪三种实际身体，共七个定义。其中五个是物理随从，两个是没有普通生成元数据的 `choice_only` 显示面；MIS_701 仅作原来源证据，不注册。八条完整固定客户端原行和十二个完整双语主站面经共享工具核对。原本体没有 COLLECTION_RELATED_CARD_DATABASE_ID，具名终极关系由两种语言的完整主站 root-child/prime-parent 面明确绑定，不猜造客户端标签。

本体的真实亡语复用 `shuffled` 与 `AddToDeck`，按本次亡语控制者和原语义发起者洗入确切终极身体。提前触发、真实重复、控制和沉默仍由既有生命周期管理；终极身体没有另一项升级亡语。

终极姆希菲是有印刷嘲讽的随从抉择。`ChooseOneSpec` 在正常出牌接受前选择姆希菲防护或姆希菲出击，分别由普通、来源归属的 `SummonByCard` 召唤一个9/9真菌守卫或真菌打手。守卫有嘲讽，打手有突袭；费用、放置、容量、数量额外体和通知继续委托公共执行器。终极随从本身可以占最后一个场位，之后的衍生物按原容量规则失败。

真实两者兼得选择的是一个具名真菌巨怪，同时具有嘲讽与突袭。这是固定资料中已存在的真实结果面，不解释成分别召唤两个身体。所有分支都没有战吼或额外 CAST；普通直接召唤或当前复制终极身体不会执行出牌抉择。回手再正常使用重新按当时真实抉择政策接受，旧已接受召唤数量及原来源材料继续沿原公共队列恢复。

两个显示面的完整客户端记录保留，现有主站直接API查询没有可用面；原空响应及来源审计仍可追溯，不能据此冒称官网已核。原过去732名单、未接的其他终极族、完整宿主生成域和其余目标均保留，不能用这七个定义宣称整个过去来源已完成。召唤反应、数量、同时死亡及控制边缘沿现有明确本地政策，精确国服窗口与版本/热修继续暂缓。实际进度、检查和下一项仅在[项目状态](project-status.md)及[机制台账](mechanism-backlog.md)维护。
