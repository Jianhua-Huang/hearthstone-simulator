## 指定开始与截止

新可选`GrantLimitedTrigger.deadline`和`AbilityInstance.limited_trigger_deadline`只表达一次性的`turn_started`附件，类型复用原OwnerTurnExpiry。原战吼玩家与实际本人区间固定，原创建区间和下一开始序号须一致；没有新全局时钟、PlayerEffect或卡牌私设计数。空值继续使用旧有限触发语义。

捕获只接受原玩家的指定真实开始。额外本人回合是有效开始，被跳过的机会没有开始事件。休眠等原因错过这次窗口后，不能在更晚的开始补发；附件在该实际区间结束时沿原统一过期流程退役，覆盖非活跃、转控及墓地实体。保留到区间结束不表示允许再次触发：原一次预算在主体前消费，截止又禁止后续开始。

原有限触发器重核驻留、控制者与能力身份；沉默、回手和变形清除旧附件。当前复制保留原截止与剩余预算并分配新能力身份，基础复制没有战吼授予。复制后的原玩家条件不随控制者改写，这是复用既有原施法者附件政策，精确国服行为仍待M6。原开始消费前/后的等待、失败回滚和恢复仍由公共解释器处理；已接受主体使用原随从引用，不把同实体ID的新卡面当旧本体。
