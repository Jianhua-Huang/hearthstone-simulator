# 塔兰吉、邦桑迪与永久恩泽

本文维护有限实现契约；进展、证据和下一项仍只在[项目状态](project-status.md)和[机制台账](mechanism-backlog.md)维护。

## 完整家族与原实体

TIME_619墓地尊主塔兰吉是4费4/5死亡骑士亡灵奇闻随从。TIME_619t邦桑迪为6费6/6，TIME_619t2赞达拉往事为3费法术；后二者的原行具有IS_FABLED_BUNDLE_CARD，原FabledSpec/expand_fabled_cards将这两张实体加入原始物理套牌。三个HIDE_COST恩泽卡面仅作选择展示，不占原始牌库名额，不作为0费物理法术使用。六个完整原附魔行保留为证据。

`data/cards/talanji-bwonsamdi-v1.json`保存12条完整原行与六个可展示卡面的12份完整双语官网响应。官网保留邦桑迪完整亡语但省略费用显示槽，原TAG_SCRIPT_DATA_NUM_1明确给出初值4；比较只允许该显示槽为空，没有丢弃规则主体。原始数据明确职业为death_knight，旧前审文字中的priest不作为实现依据。

塔兰吉执行时先在本人真实友方死亡库存按BWON卡面匹配。已有死亡时，以最近匹配记录调用原ResurrectMinion重建新实体；否则调用原DrawMatching抽取实际牌库里的BWON。现存同名牌、对方死亡和烧牌不替代友方死亡记录。检索为空跳过、不疲劳；具名对象获取及其反应完成后再选择恩泽。满手烧掉、无匹配或满场复活失败时仍可保存恩泽，这是当前本地顺序政策，待国服窗口校准。

赞达拉往事沿原DamageBatch对全部敌方角色造成2点法术伤害，随后普通RequestChoice选择恩泽。选择不计发现，不支付或施放三个展示卡面。正常伤害、反应、死亡及终局中断继续由原解释器负责。

## 原玩家永久程序

每次实际恩泽选择安装一个独立、永久的普通PlayerEffectSpec/PlayerEffect。NamedMinionBoonsProfile将三个固定程序关联到邦桑迪、真实战吼/法术入口，以及嘲讽、吸血、突袭。程序的展示牌为物理邦桑迪，选择展示牌独立保留。没有新增GameState账户、模型字段、效果类型或另一套附魔/召唤执行器。

本地按原文字允许重复选择同一恩泽，每次使亡语召唤费用增加2；当前费用为4加上实际程序数的两倍，关键词按三类去重。确切重复资格和费用上限仍待M6，内部实现不把该政策冒充正式国服裁定。未来匹配按精确印刷费用查询宿主随从池；确认的空池不召唤、不抽样，缺失或未知合格内容明确报错，正式池须声明完整。既有实验模式允许局部池，专项使用显式完整的实验池；二者均不认证正式生成范围。

程序作用于本玩家当前HAND/DECK/PLAY/BOARD中的具名邦桑迪，以及以后创建、普通重置和复活得到的同名身体。邦桑迪自身获得永久关键词附件，本地设置remove_on_silence=False；原印刷亡语仍按普通沉默移除。当前复制保留物理附件，转控不会把玩家的永久程序转交给对手；亡语实际执行时读取当时控制者自己的程序。因此被偷走的身体可以保留已有关键词，亡语召唤物不借用原玩家恩泽。精确沉默、复制和永久层序仍待国服证据。

每个永久程序通过私有接受记录连接真实活动战吼或CAST、原玩家/来源、完整PlayerEffect及关键词。保存时核原入口、原实例完整覆盖和永久程序未被裁除；来源死亡或回手不退役这些程序。该结构不为未签名存档提供外部来源认证。

## 亡语交付、休眠与巨型

邦桑迪亡语从原玩家程序冻结费用及关键词，交给原SummonFromPool、PoolSummonBasis和SummonEntryMaterial。实际空位、完整候选、权重、随机和召唤数量继续由原管线接受；普通多个新身体共享原条目的冻结关键词。新随从继承普通可沉默关键词，保留自己的原生文本，不额外取得邦桑迪亡语。

入场关键词只扩展为按嘲讽/吸血/突袭顺序排列的八种实际子集，继续拒绝重复、错误顺序和无关关键词。关键词在首次入场通知前装好，打印休眠身体也保留附件；巨型主身体沿相同入口授予，附肢继续走原巨型流程。手动指定休眠等其它入口限制保持。

暴雪论坛的[34.0.3历史热修说明](https://us.forums.blizzard.com/en/hearthstone/t/3403-hotfix-patch/154571)记载休眠继承修复，并将偷取后不把对方恩泽传给召唤物列为非Bug；这是历史来源，不能替代37.0国服热修核定。

## 玩家信息

恩泽程序与常规公开光环分别投影：持有者可见自己的程序摘要，对手看不到隐藏的恩泽选择或内部程序事件。可见邦桑迪的boon_summon_cost显示实际亡语费用，对手隐藏手牌不显示该字段；关键词只有在原实体可见时按普通规则公开。原实例ID、接受来源和完整程序材料不进入玩家DTO。

观察版本为player-view-v109，相关支付输入承认可见随从的非负召唤费用字段。恢复、克隆、回放和错误选择/交付回滚沿原协议执行。固定M0正式池、实际可达内容、M6国服时序和阶段发布验收仍独立开放。
