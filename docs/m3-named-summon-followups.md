# 具名召唤的原交付续接

时空旅行者TIME_434的真实亡语召唤TIME_434t影子，并由影子攻击随机敌方随从。影子本身是无突袭的4/1白板；强制攻击属于这次亡语的后续效果，不能写成影子的永久能力。完整原行、双语主卡面及既有影子定义固定在[配方](../data/cards/native-named-summon-attack-v1.json)。

`SummonEntryMaterial.on_summon`只向现有具名召唤声明一个注册行为。原`SummonByCard`、完整材料、`SummonCause`、数量计划、实际入场及原`CardSummonDelivery.followup_started`继续负责请求和执行；未知行为在接受前报错。强制休眠材料仍只允许原印刷白板，不借此扩张组合。

成功入场及其反应完成后，`ContinueNamedMinion(root_id, index, beneficiary, behavior_id)`核对原选中材料和实际delivery，先消费一次续接并写入私有完整收据，再调用原注册行为。失败交付不续接。数量额外体逐个完成自己的后续效果后才推进下一交付；原接受的材料和数量计划不重新推测。

接收者使用实际入场捕获的`BoardPresenceReference`。连续在场的变形仍由同一驻留接收；死亡、休眠、转控或离场重入导致原接收者无效时跳过，不寻找同名随从或最近召唤。`original_named_reference`同时核对原来源、玩家、目标、材料、行为和已消费标记，供卡牌行为将原引用转交已有`AttackRandomEnemyMinion`。敌方候选在攻击执行时查询，随机、强制攻击、防守者引用、战斗与死亡继续交给普通管线。

原控制尾必须保留唯一待处理续接、必要的下一交付及Finish；删改、重复、错序、替换行为/接收驻留、向玩家选项注入控制工作都拒绝。继续帧中的实际行为调用也要核对原收据。私有事件与所有实际续接标记逐项守恒，含回溯后退役的根；这证明内部一致性，不认证未签名存档的外部来源。等待恢复、clone、回放、失败继续和事务回滚共用原解释器。

此处入场反应之后续接、每数量交付后立即攻击、连续变形接收和转控跳过是明确的内部时序政策，仍待M6国服校准。正文或本地测试不能独立认证这些细部。来源是原亡语实体、执行玩家是原召唤接收者，不能从死亡后的当前场面重建。

仅新增一个既有材料字段和一个Effect，无新payload类型、GameState/Entity/Ability字段或第二执行器。私有材料、历史、收据和继续工作不进入玩家DTO。版本、实际验证、差异和下一项仅在两份主台账维护。
