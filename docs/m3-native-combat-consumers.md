# 原生伤害、治疗与完成动作奖励

BE_284冷暗虚空捕获原目标和该场面槽位的两个相邻活跃随从，用同一DamageBatch分别造成4/2/2法术伤害；边缘不补目标，圣盾与法伤交给原管线。BE_325凶煞降临在消灭前保存当前生命值和当时控制者的英雄，先Destroy及其反应，再Heal；当前“拥有者”按控制者解释，精确国服窗口仍待M6。

BE_552喷火器是2攻击、2耐久武器。原attack_finished事实必须来自本人的真实英雄攻击，奖励通过AddToHand交付既有BE_553t；该依赖的完整定义和原行固定，不复制其机械突袭/结束消灭主体。普通随从攻击与对方英雄攻击不奖励，末次耐久及满手沿原攻击和交付语义。

BE_723游荡巡逻者读取完成的实际PlayRecord及其原card_id定义，按原生Combo主体或COMBO标记识别连击牌，不以本次连击是否激活作条件。普通使用、召唤和自动施法区分；随机伤害沿原RandomDamage和随从能力种类，不获得法伤。动态额外授予Combo槽的资格没有在本批另建规则。

BE_749萨恩诺斯巨兽的每次亡语返回两个独立的一费SummonFromPool请求，再以原InvokeBehavior读取当前友方随从并给予+3攻击。每次请求按实际空位抽样，入场无战吼，原选择恢复不重复第一份交付；空池仍执行后续增益，未知合格内容明确回滚。完整候选池由宿主提供，不从已实现列表推定。
