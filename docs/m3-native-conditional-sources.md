## 法强和费用的原生资格

`CardDefinition.native_condition` 是可空 `NativeSourceCondition`，当前只支持两个有限分支：

```python
# 时光扭曲先知：既有法强来源仅在物理载体受伤时供给。
spell_damage=2
native_condition=NativeSourceCondition('self_damaged')

# 奎尔多雷造箭师：一个原友方英雄技能设0费用光环。
cost_auras=(CostAuraSpec(CostSpec(set_to=0, card_types=(CardType.HERO_POWER,))),)
native_condition=NativeSourceCondition('controller_hand_at_most', 3)
```

第一分支要求普通随从的正数原生法强，不能借同一条件共享费用光环；第二分支要求恰好一个既有友方英雄技能设0光环，不扩展到任意费用表达。阈值必须是非负整数，受伤分支不能带手牌阈值。声明安装到原 `spell_damage` 或 `cost_aura` 能力的同名字段，沿普通复制、区域、沉默和恢复流转，不增加单卡计数器或GameState历史。

条件读取实际物理载体及其当前控制者；`ability.source_id` 仍是既有来源归因，不能拿它读取原副本的伤势或手牌。当前复制保留来源归因，但分别判断各自伤势/控制者，转控立即采用新控制者。提供者是否有效、休眠、存活、沉默及是否位于实际来源区域，继续沿原来源遍历政策。

[法强查询](../hs_sim/engine/health_rules.py)在原包准备窗口筛选提供者，保留批次开始预算与后续新窗口的区别；治疗后不保留旧全局法强。英雄技能伤害不改成法术伤害。[费用查询](../hs_sim/engine/costs.py)在权威报价时判断手牌数量，再沿既有有序外部修正及付款证明执行；不把条件写成永久减费。普通卡和对方技能不匹配，实际附加英雄技能槽仍按原HERO_POWER类型资格处理。

已接受的原零费付款不会因随后抽牌、来源离场或选择等待而重算成当前价格。完整原状态、能力和报价收据继续由原恢复器验证，不能从当前手牌数量猜过去条件。报价、玩家观察和合法动作查询保持纯函数。

## 本人回合英雄攻击光环

小蜘蛛使用原 `AuraSpec(attack=1, target='friendly_hero', condition='controller_turn')`。这个新增有限配对只允许正攻击、零生命及无相邻/自身/种族/卡名选择；不开放任意英雄属性光环。能力保留原可沉默的印刷来源，普通当前复制和转控共享旧生命周期。

`stat_auras.hero_bonuses` 读取当前行动方的实际战场来源，将攻击贡献交给现有 `aura_attack` 与装备/战斗层；多个物理来源相加，不写入永久攻击附魔。转控、死亡、沉默和换面沿原光环刷新清除旧贡献。真实行动方变更后、开始窗口捕获之前先规范化英雄值；结束主体仍使用原结束阶段的行动方。跳过/额外回合、濒死来源和精确移除窗口沿原内核政策，正式一致性仍须国服校准。

## 真实生命分流依赖

HERO_07bp使用完整的2费英雄技能定义：先执行原 `Draw`，然后经原 `InvokeBehavior` 对当时本人的当前英雄造成2点HERO_POWER伤害。它不是只有抽牌的测试替代，也不是法术或生命支付；爆牌/疲劳走普通抽牌，伤害仍走原护甲、防护及英雄技能数值规则。延后读取当前英雄避免把抽牌之前的旧英雄ID固定成最终受伤账户。

这项定义不等于全部术士默认开局、基础英雄、皮肤/强化技能或生成池已接通。显式Scenario可以配置已有头像与当前技能以验证可执行状态；不能据此认证合法初始套牌或完整职业。英雄替换、终局/自动抽牌链及特殊技能伤害修正的精确国服窗口仍开放。

## 严格恢复与边界

原生条件只能属于可移除、未消费且无外部到期的印刷提供者；动态授予明确拒绝。实体/捕获状态/死亡材料核对原声明、金额、学派或费用规格，拒绝丢失资格、借用其他声明及重复原生提供者；类型解码拒绝未知分支和多余字段。完整来源真实性仍需可信宿主，未签名存档只检内部一致性。

CardDefinition与AbilityInstance各新增一个可空 `native_condition`，schema282拒旧1～281，解释器core-effects-v357；没有新GameState或独立历史字段。旧定义asdict增加None，旧摘要只有移除这一新增空字段后才保持；注册表与既有PIN视图仅在空声明时省略它，非空条件参与签名。观察85/命令12/replay1保持，玩家不接收条件对象、私有来源材料或完整快照。官方身份页和固定源记录不单独证明正式合法池或精确国服时序。
