# 原使用、抽牌与召唤对象的真实消费者

BE_008魔古将领读取实际已完成PlayRecord的冻结印刷职业，当前场上外观或来源变形不改中立资格。当前内部政策计入自身中立使用，该首次触发窗口仍待国服核对，不能仅据文字认证；召唤和自动施法没有普通使用事实。每次合格使用安装一个独立的一次性本回合法术-1费用层，仍沿普通支付与到期流程，零费下一法术也消耗原层；来源随后死亡不撤回已获得层。

BE_150线圈携载机沿原当前英雄/中立、可收藏法术发现域，将选中卡以-2费用直接创建于本人牌库顶。没有手牌中转和随机插入；实际新实体、费用附件、首个获取通知和后续正常抽牌均由原发现/牌库入口负责。缺完整宿主池或未知合格内容明确回滚。

BE_154谦恭审判使用三个普通DrawGroupSlot。新增有限DrawGroupReward(kind='set_drawn_minion_stats', amount=2)，整组完成后对仍在原连续手牌驻留的实际随从入手对象调用SetStoredMinionStats，不改费用、法术或旧手牌。沿原替代抽牌链找到最终入手者，额外反应抽牌不加入本组三个槽；疲劳和烧毁仍保留普通事实，烧毁结果没有手牌奖励。这是复用既有整组窗口的内部政策，精确国服相对时序仍待校准。

BE_196迷醉召唤者按当前活跃敌方随从捕获完整CopyEntryMaterial，每个物理实体一个候选。同名不同实体保留独立权重；同一实体重复登记或混合非复制材料明确拒绝。SummonByCard(selection='random')仅增加全为board_copy/current材料的普通选择形状，仍沿原容量检查、一次均匀抽选、数量计划、当前复制和普通入场；没有新随机执行器。实际每份复制交付通过original_copy_reference绑定原敌手，再由ForceAttack攻击原连续场上对象。原对象不再存在时不换目标，复制不执行战吼；原续接对存活、驻留和控制者的限制保持。

BE_201冰冷恶兆先冻结原敌人，再从完整宿主随从域随机召唤五费随从。SummonFromPool.on_summon只接受具来源和SummonCause的普通材料，进入PoolSummonBasis及每份确切SummonEntryMaterial；候选、权重、来源和回调声明均受原证明约束。通过既有named续接，实际召唤通知与反应完成后冻结原交付者；原对象失效不另找对象。空/满场仍处理第一份冻结，不消费召唤随机；未知合格候选在容量判断前报错并回滚整次动作。

core609/schema502拒旧1～501，增加SummonFromPool和PoolSummonBasis的两个可选回调字段；无新Effect、payload类型、状态或历史字段。其余旧请求和十一拼装片段保持。上述源时机、对象失效/控制变化、复制与反应窗口仍需M6；正式资格池、全部可达内容与国服校准分别验收。进度和下一项只在原两份台账维护。
