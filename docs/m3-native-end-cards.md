# 原生结束主体与来源身材召唤

本页是扩展契约，实际结果和下一项仅在[项目状态](project-status.md)与[机制清单](mechanism-backlog.md)维护。完整卡面、配方及既有依赖证据见[native-end数据](../data/cards/native-end-effects-v1.json)。

卡牌声明原`TriggerSpec('turn_ended', body, EndTurnSpec(...))`，结束窗口、顺序、有限用途、额外执行和时钟仍由原内核处理。本包除魔像/艇长为either，其他结束声明为controller；火炮长只有真正battlecry，获取已接入完整CAP_107t。结束主体要读取前一主体后的局面时，返回命名InvokeBehavior再执行，不在最早接受窗冻结后段目标或条件。

CORE_TTN_866神秘恐魔使用固定37.0的7费4/10、吸血及野兽/恶魔；其构筑等价由原DECK_RULE_COUNT_AS_COPY_OF_CARD_ID98469明确对应TTN_866，不按CORE前缀猜身份。结束主体真正执行时确认原来源仍是本人活跃存活随从，捕获完整当前敌随从的有序BoardPresenceReference以及本体原驻留引用，逐一交ForceAttack。每次沿原战斗窗口结算伤害、反击、吸血和死亡；来源死亡/离区后旧受击引用失效，后续请求不会攻击新同名体。反应新生的敌方随从不塞入已捕获队列。冻结、普通攻击次数、潜行/嘲讽与迫攻资格继续依赖原ForceAttack政策，准确顺序与服务器边界待M6。

DINO_132绝息剑龙声明8费6/12、嘲讽及野兽/恶魔，结束主体以原RandomDamage对完整当前敌方普通活跃存活随从抽一次，造成5点MINION_ABILITY伤害。英雄不进入候选，不叠法伤，空池不消费随机，盾免/死亡由原伤害层处理。两张都只声明controller结束；多个/额外结束主体各自执行时重查局面，不借此增加新时钟或结束规则。

- 彩翼灵龙给其他当前友方普通随从+1/+1，魔蚊只给+1攻击，均排除自身和休眠/交互载体。盛怒主母执行时读当前是否满血，满足才给自身+3生命。
- 破鳞盾卫用DamageBatch同时伤害全部当前敌角色2，土石幼龙对敌英雄4，标注MINION_ABILITY且不叠加法伤。小动物看护者以HealBatch给双方当前英雄3，使用原普通HealingKind.EFFECT，不添加不存在的治疗类型。
- 护卫者召唤完整CATA_476t：6/6、圣盾、龙/元素；救赎者使用完整普通龙CATA_478t并覆盖身材，不复制来源关键词、附魔或触发。
- 积云给当前本人英雄圣盾。魔像在双方结束获得复生，消耗/死亡新体及再次获得仍走原关键词生命周期；不是印刷自带复生。艇长给当前实际结束玩家硬币，原结算内active_player仍是结束玩家，controller不作为收牌者。额外激活及跨时钟精确语义继续随原激活profile和M6核对。

`hs_sim.engine.source_stat_summons.SummonBySourceStats(player_id, card_id, source, accepted_stats, cause)`只补真实来源身材召唤。source必须原普通MinionReference，accepted_stats必须同时有非负攻击和正生命，cause必须原SummonCause并与来源实体、控制者、卡面、epoch/入场顺序一致。来源分配实体必须保留。

该请求仅查询和转接材料，归入现有透明控制通道，避免在原主体和SummonByCard之间增加死亡/触发检查点。所有旧控制项保持原通道。

原生救赎者在其原已接受主体中保存来源引用、正数身材及因果。请求执行时，原引用仍是存活同一驻留则取当前攻击/剩余生命；失效则使用接受时身材，保留已接受主体，不读取后来返回、换控制或变形的新体。随后只生成原SummonByCard和单一SummonEntryMaterial，由原数量、容量、入场/区域、属性和回放机制执行；没有独立召唤器或新GameState账本。新效果/core322及内容包v22标识该语义，schema268、观察85/命令12/replay1保持。

该口径修复了“先前结束伤害杀死救赎者后以非正生命创建材料，整次操作回滚”的实际缺陷。当前仍有效时的身材可包含同一结束批次前段产生的增益；来源失效后回退的是**原接受时**身材，不宣称取得服务器最后已知状态。若来源在接受后多次改变身材再离开，精确应使用哪个窗口、剩余/最大生命、光环层、归属与额外激活规则仍待国服证据校准。不能以内部断言或原型默认值认证官方一致性。
