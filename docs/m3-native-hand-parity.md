# 吉恩的手牌奇偶变形与初始技能事实

本契约描述CATA_615/CATA_615t的内部执行政策。官方双语父子卡面确认身份和文字；当前费用依据、检查窗口、初始技能适配、材料继承和费用层序尚未获得国服完整校准。十一职业升级技能的原行/官网缺口仍按[基础角色契约](m3-basic-hero-roles.md#吉恩所需的十一职业升级技能)登记。

## 有限原生手牌检查

`HandParityTransformProfile(card_id, transformed_id)`只连接两个不同、同印刷费用的普通随从卡面，不支持链式声明、动态授予或任意条件表达式。声明进入注册表指纹；未使用该能力的旧注册表不增加指纹字段。吉恩在手牌中且未沉默时，仅在本人的实际手牌身份、卡面、驻留或顺序变化后检查；完整Scenario初始化也检查一次。纯费用变化及仅对手手牌变化不会自行创建检查窗口。这是明确的本地窗口政策，早期玩家费用变化报告不能证明CN37的最终依据。

条件读取其他本人实际手牌的当前完整未选分支报价，不支付、不消费次数或随机。自身费用不参与条件；0是偶数，没有其他手牌时成立。未知必需价格明确报错，不改为零或静默排除。每个窗口先接受全部合格原实体，再通过原`upgrade_face`变换印刷卡面，保留实体ID、手牌槽、本地属性/费用及原既有授予政策；全部变换完成后才发布第一条私有通知。狼人形态不反向变化。牌库、场上来源不以手牌条件变形。

变化检测仅是当前Resolution内的临时签名，不进入存档，也不作为玩法事实或跨动作缓存。等待恢复以当前手牌重新开始检测；变形本身已经完整提交，不留半个接受组。失败反应仍回滚原整个动作。信息发布复用原私有stored_card_transformed，不给玩家报价输入或对手手牌。

构筑发起完整起手牌后再出现第一次检查和换牌菜单，原实体ID及原牌库事实保持；替换后的起手牌与后续自然抽牌继续共用检测。Scenario初始化可以完成同步通知和非等待反应；其暂停仍受既有“仅构筑开局允许setup resolution暂停”的约束，没有放宽场景存档协议。真实构筑开局的换牌等待、恢复及回放按原协议执行。

## 初始技能与狼人战吼

新增私有`PlayerState.starting_hero_power_card_id`，只在初始化实际安装主技能时记录，未安装则为None。额外槽不填主位事实。替换/移除、英雄变更、clone、恢复及回放保留它，不使用会在恢复后重置的Game.origin推断开局。字段校验已知英雄技能类型，普通玩家DTO不输出该字段；它是存档中的一致性事实，不提供未签名存档的外部开局来源认证。

狼人战吼通过普通InvokeBehavior在实际执行时读当前主位。初始规范基础类型或其规范升级类型确定唯一职业家族；当前主位仍为该基础类型时，用原HeroPowerReference绑定的ReplaceHeroPower安装升级技能，并在首次通知前按原费用附件设为1。初次新安装沿既有规则获得新实体及使用计数；已经是该升级形态时只对同一实体ModifyCost为1，不刷新使用次数。额外槽保持独立。没有初始技能、已换成非基础技能或其他职业基础类型时，不伪造初始升级；重新获得相同初始基础类型可再次适配。规范之外的皮肤映射及这些资格/刷新/费用政策均待M6。

新增的是一项实际初始事实和一个有限注册表声明，没有新Effect、CardDefinition或Entity/AbilityInstance字段。core498/schema411拒绝旧1～410存档；玩家观察95、命令12和回放1保持。实际进度、执行证据与下一项仅在两份原台账维护，不能据内部通过认证正式标准池或国服完整支持。
