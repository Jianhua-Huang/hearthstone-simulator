# 原生伤害、嘲讽绕过与条件免疫提供者

[完整来源包](../data/cards/native-health-attack-providers-v1.json)与[执行装配](../hs_sim/cards/native_health_attack_provider_cards.py)包含五张真实根卡。克洛玛图斯及四个头仅保留来源，不作为已实现内容。实际进度、验证、差异与下一项只在[项目状态](project-status.md)及[机制台账](mechanism-backlog.md)维护，正式卡池与国服规则校准仍独立登记。

## 来源及目标侧伤害

量子反稳定机直接使用既有 `HealthRule(DAMAGE, SCALE, 2, layer=TARGET, target_relation='self')`。它改变实际受到的伤害，攻击与最大生命不翻倍，治疗不翻倍；圣盾、免疫与其他防护仍交原结算。

布拉玛·灼石和戈德林只增加两个有限的 `HealthRule.source_relation` 形状：

- `friendly_elemental_minions`：普通SOURCE侧伤害+1。
- `friendly_beast_minions`：普通SOURCE侧伤害×2。

这两个形状限定完整原生配方，不提供目标关系、派系、伤害类别或任意数值组合。原字段声明、数值层序和同批接受规则保持；没有新增伤害执行器或伤害账本。匹配使用原包的来源控制者和物理随从当前种族，调用已有完整种族查询，支持副种族、全部种族及真实种族修正。戈德林本身是野兽，其冲锋替代仍为原生突袭，9攻显示值不会变成18攻。

普通随从技能和死亡后原随从来源伤害按相同归因处理，法术或英雄并不因同属某职业就成为随从。未知当前种族明确报错并沿原事务回滚；退休逻辑随从来源缺少当前种族事实时也不假定为非匹配。精确当前/印刷依据、退休来源和修正层序保持M6边界，完整实际来源仍须按真实卡接通。

## 无视嘲讽

凯恩·日怒采用当前Core的4费3/5及原生冲锋，完整858原身份映射到BT_187作为构筑身份；旧版卡面不因此注册为可执行根卡。

`AttackPolicySpec('friendly_ignore_taunt')` 是无条件的原生随从提供者。共享普通攻击目标检查在判断嘲讽时，纯查询当前控制者面板上活跃、存活、未标记消灭的来源；不向每个攻击者安装永久附件。英雄与友方随从均可受益，沉默、离场、休眠与控制变化随原能力生命周期生效。动态授予和武器提供者暂不由此形状表达。

这项规则只绕过嘲讽。冻结、攻击次数、新随从准备度、突袭不能攻击英雄、潜行与免疫目标等原规则保持。已声明并接受的攻击继续沿原攻击窗口执行，来源后来离场不重新选择目标或撤回已接受的原攻击；后续新攻击重新查询当前来源。强制攻击沿其原有目标政策，不另造强制攻击管线。

## 没有其他随从时的自身免疫

生存专家使用 `KeywordAuraSpec(IMMUNE, 'self', condition='controller_no_other_minions')`。该形状限定本体IMMUNE，不接受其他关键词、任意目标筛选或动态授予。

只有其真实场上随从参与派生。其他友方普通随从的物理占位会关闭免疫，包含休眠和等待死亡清理的占位；地标、交互对象及未发射的星舰建造物不当作另一个随从。当前控制者和现有面板是真值，手牌不会获得此运行时免疫。入场、离场、实际建造、控制、沉默、复制和区域重置都沿原刷新；不按每个事件反复授予或消费IMMUNE。

占位、临死与窗口的精确国服政策待校准。内部示例和专项只证明本文声明的范围，不代替官方对局证据。
