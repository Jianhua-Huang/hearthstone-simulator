# 原生囚禁与亡语释放

TIME_442 时间流守望者使用真实四费2/6战吼和亡语；TIME_442e 完整原行只作10000回合等原始证据，不另造可执行实体。目标声明为 IF_AVAILABLE 的敌方场上随从，空敌方场仍可正常打出。

复用 NativeDeathrattleSpec / DeathrattleMemory，新增有限 dormancy_link 及原附件中的 dormancies。RememberedDormancy 保存原 BattlecryRecord ID、目标物理ID、控制者、卡面、zone_epoch、entered_order 及该次 DormancyState ID。没有另建全局关联表，也不扫描诊断事件、卡名或当前场位猜目标。

ImprisonForDeathrattle 绑定实际仍在执行的战吼、原目标引用及原记忆能力ID。共享 MakeDormant 创建10000回合的普通休眠后，在光环刷新和 minion_dormant 通知前，把实际分配的休眠身份写入仍属于同一原驻留的亡语附件；后续倒计时、反应、死亡和唤醒仍交原模块。通知中杀死来源时，原死亡捕获已含关联；来源在此之前离场时，不给后来的同ID驻留补写记忆，也不改写已接受的旧死亡。

亡语只读实际 DeathrattleCapture 冻结的原附件，返回 AwakenRememberedDormancy。它要求实际已开始且未完成/中断的亡语、原载荷中的同一关联，再调用 AwakenCapturedMinion。原目标离场、驻留改变或已结束原休眠后进入新的休眠，旧关联过期；不因名称相同改绑目标。当前复制保留原关联，基础复制和回手重置恢复空记忆；沉默沿普通能力移除，不留下额外释放监听器。单独授予行为名而无原生记忆的来源仍明确未支持。

保存/恢复严格解码完整关联；原目标不符、未知战吼、未来休眠分配、缺少字段或无关记忆混合均拒绝。普通原生召唤成长、抽牌/弃牌记忆和继承继续共享原格式与原执行器。schema421拒绝旧420及以前；原 CardDefinition 结构没有新字段，新增的是既有原生记忆的嵌套载荷。玩家观察不输出完整记忆、原战吼或内部休眠分配身份。

当前本地政策依原 MinionReference 和单次休眠身份匹配，多个成功实际囚禁按原顺序记忆；精确重复战吼、控制/换面、来源提前死亡、特殊继承及通知窗口仍待M6国服校准。结构校验不提供未签名存档的来源认证。实际接受结果、剩余标准内容、M0/M6与发布门槛只在两份原台账维护。
