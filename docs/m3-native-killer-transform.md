# 原致死随从与原驻留变形

CATA_185无面复制者是3费3/3中立随从，印刷扰魔及亡语：“将消灭本随从的随从变形成为无面复制者”。[完整来源包](../data/cards/native-killer-transform-v1.json)保留冻结37.0原行及两完整官方卡面。没有额外衍生卡，变形结果使用同一完整定义；实际进度、验证和下一项只在[项目状态](project-status.md)与[机制台账](mechanism-backlog.md)维护。

主体只读取其真实`DeathRecord.cause`的首次原致死来源，按原来源卡面类型、来源ID、控制者、zone_epoch和entered_order构造`MinionReference`。没有来源、来源不是随从、从未具有有效场上驻留或只有存活载体主动亡语而没有实际死亡时，不制造凶手。不扫描最近伤害，也不把执行时的同名实体当作原来源。

`TransformCapturedMinion(beneficiary, card_id, source_id)`在实际执行时核对原物理驻留及当前存活、活跃、未将死。随后直接调用公共`transform_minion`，不在旧上下文检查后另排一个裸ID变形。凶手已经死亡、回手、重入、换面或转控时，旧引用失效，不救尸体，也不重新绑定。同卡面变形同样更新epoch。变形沿原生命周期重置完整卡面、附件与数值，保留目标的原控制/所有权、场上位置及原执行器规定的攻击时钟。

首次亡语回调保留原接受局面，而额外执行可获得新执行视图；各次仍使用原死亡原因。因此第一次成功变形后，额外亡语不把新驻留当作同一原凶手再变一次。选择恢复、克隆、回放和失败回滚继续使用原解释器。新Effect在续接解码时拒绝未知或未来分配、未知来源以及非随从结果；原引用和致死材料不进入玩家DTO。

新增一个Effect，无新增状态/实体/能力字段或载荷类型。core398/schema321拒绝旧存档；观察89、命令12和replay1保持。当前内部政策将伤害、剧毒及随从直接消灭的真实随从来源纳入，严格保留原控制和驻留条件。官方简短卡面只证明身份和文本，精确国服来源资格、控制及变形窗口仍待M6校准，完整标准资格和生成池继续独立登记。
