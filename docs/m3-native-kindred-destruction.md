# 普通消灭与延系原属性奖励

TLC_829饥饿的魔暴龙复用原KindredProfile的prepare/active分段：普通战吼无论延系是否成立都尝试消灭一个原目标，prepare尾部必须调用既有repeat_components接续完整已接受计划。目标域始终为普通IF_AVAILABLE场上随从域，不套用纯延系条件目标profile。
