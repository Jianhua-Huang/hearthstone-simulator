# 原生延系的条件目标

`KindredTargetProfile(card_id)`限定纯延系随从的原生出牌主体：已有KindredProfile必须使用同一个on_play包装器、只有成立主体，没有普通准备或不成立主体；要求原生IF_AVAILABLE敌方BOARD随从域及内建结构目标规则。它不放开任意全知谓词，不增加`target_condition="kindred"`这一通用字符串接口，也不将延系改成战吼。

目标入口复用原上一本人真实已关闭回合关系查询；主体仍由原KindredProfile捕获条件、消费下一次延系来源及执行次数。未成立时目标域为空；成立且有合法敌方随从时必须选目标，域空时仍可出牌。普通出牌、重定向检查和自动物理重放共用effective_target_spec，没有第二套合法性判定或新的付款执行器。

玩家自己的原生条件目标手牌在play_conditions中只获得一个kindred布尔值；对手手牌不获得它，也不输出历史、匹配行或内部查询材料。player-view-v89及原目标观察输入检查限定该事实只能出现在本人手牌且类型精确为bool。命令协议保持原revision/action封装。

旧的独立目标收据只保存原物理宇宙。对实际声明本profile的原牌，目标重建从已经保留的原play前缀和冻结owner_turn_id恢复当时回合前缀，清除该回合后来的结束/关闭字段，再使用原查询验证。当原牌的回合在以后关闭，不能把它误作当时的上一本人回合。材料只在宿主临时重建中使用；没有新增持久状态、嵌套完整GameState或玩家历史。

暴掠龙女王TLC_825完整原行/元数据、两个完整官方卡面与原Kindred声明一起固定。成立主体以真实组件执行时的当前Attack提交普通MINION_ABILITY伤害；手牌增益和入场等待中的增益生效，法术伤害不参与。普通召唤不执行on_play，下一次延系只重复成立主体并按原政策消费。精确国服的接受、离场最后已知值及目标移动窗口仍待M6校准，本实现不认证这些边界或完整正式卡池。
