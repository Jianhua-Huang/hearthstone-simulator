# 魔网数值、额外效果及真实消费者

原MEND_500/502/504是三张基础魔网，原脚本基础值分别4伤害、6费随从档、减费1；MEND_500原349=1免法伤。MEND_501战吼使三者整局减费1、亡语从完整固定三牌取得一张；MEND_503增加一个效果执行单位，MEND_506提高主要数值1。MEND_505取得完整三牌，再选择额外效果一次、减费2或数值+2。三升级定义只作choice_only预览，不能实体化、独立施法或加入普通生成池；长期效果显示归属实际地图，原物理显示卡校验保持。

PlayerEffectSpec只新增默认空spell_effects，承载一个不可变SpellEffectModifierSpec：明确物理法术ID列表、主要数值加法或一个额外效果单位。声明彼此独立、永久、不可混入其他玩家程序；现有程序默认空字段不参与指纹，旧身份保持。注册时目标必须是已登记的物理法术。原AddPlayerEffect负责实例与归属，费用继续使用已有Card-ID CostSpec和AddCostModifier，不新建支付或玩家账本。

spell_effect_values只为实际活动CAST报价，原生主体接受时确定主要数值与效果单位数；它们属于一次施法和一次付款，不能用整牌重复施法代替。已接受数值/次数不因执行中的新升级而追改，后一次实际施法重新报价。原玩家长期程序独立叠加并在源死亡后保留。自动及非当前回合施法同样读实际施法者。该接受窗是明确内部政策，精确国服窗口继续校准。

迸发魔网每单位重新查询当前活跃、存活敌方随从，空池无RNG；引入的RandomEnemyMinionExcessDamage只是原随机选择与DamageExcessToHero连接。后者只追加普通/免法伤系数，默认1保持、SPELL允许0、地标EFFECT仍只能1。每次源预算先报价一次，再沿原承受端保护/路由分配随从与英雄，不重复法伤或来源倍率。随机一次即保存原目标引用，亡语新随从可进入下一单位。目标唯一时的RNG沿原RandomDamage，不额外简化。

晶化魔网每单位使用一个GenerateFromPool请求，保留完整宿主可收藏随从池/权重与原SummonCause，前单位反应结束后才接受下一抽样，不能提前抽完所有额外效果。满场仍沿原池批先选择后检查空间的政策，不擅自省略RNG。魔网枢纽每单位使用原DrawWithCostReduction，目标仅实际原手牌到达；回调、自动施法、满手、疲劳和失效仍由原抽牌管线处理。

地图先按两主面childIds显示顺序取得枢纽/迸发/晶化三张，再进行原选择；该顺序、数值/重复的精确接受窗、空池/满场及转换/保护相互窗口仍为M6事项。完整生成池未知成员必须在抽样前明确失败，不裁为已实现子集。

来源工具仅允许三条完整原记录固定pin以显式声明省略@、{0}、{1}；两个完整规则体仍全部比较，原脚本基础值/元数据/原始行保持，不能删除重复体或改变隐藏数值。20主面覆盖七根、三隐藏费用选择，地图两主面分别关联全部六孩子；未知4285标签仅作成员旁证，不据数字标签独立解码规则。
