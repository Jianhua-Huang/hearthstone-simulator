# 团本首领奥妮克希亚与真实雏龙条件

[固定数据](../data/cards/native-onyxia-whelp-v1.json)保存ONY_004完整根、既有ONY_001t完整依赖和四份完整双语官网主面。根的COLLECTION_RELATED_CARD_DATABASE_ID与原雏龙DBF71299一致，雏龙仍复用过去法术已接入的1费2/1突袭定义及WHELP标记，不创建同名白板替代或覆盖旧定义。此根来自既有究极边境34身份参考，不作为独立狂野构筑或完整正式过去池认证。

真实原生根声明突袭、一个有限自身免疫光环及六次普通单成员SummonByCard请求，各使用SummonEntryMaterial(ONY_001t)。原SummonByCard的materials是不同候选库存，不能把六个同名身体塞入一个候选库存。SummonCause及原解释器负责归因、各次数量、容量、入场、暂停及后续主体；实际只交付能容纳的身体。没有空位且没有其他雏龙时不凭召唤计划授予免疫，没有把六条尝试变成保证六条在场。

KeywordAuraSpec只增加condition='controller_controls_whelp'，必须为target='self'和Keyword.IMMUNE，不能附加选择器/相邻/包含自己政策或任意授予。原生定义/附件核验沿既有native_scope和ordinary-face守卫。公共刷新在原自身光环分支枚举当前控制者完整战场，用原has_any_subtype读取各随从当前卡面的印刷whelp分类，并把免疫作为来源自身的派生贡献；没有新的计数缓存、状态字段或关键词授予器。

当前候选政策是普通、活动、正生命、非待消灭的友方随从，排除地标、interactable和building对象。休眠、对方、手牌/牌库及正在消灭的雏龙不满足；精确待死窗口仍未国服校准。完整候选逐行核分类，即使前面已有真匹配，后面未知分类也明确失败，实际动作按原事务回滚。不能凭名字、普通龙族或“全部种族”推断雏龙。

沉默雏龙、改变其普通种族不改变印刷分类，仍可维持条件；变形读取新卡面，转控读新场面。最后一条合格雏龙死亡、休眠或离开，来源沉默、变形、回手、死亡或休眠，都会沿普通刷新撤回相应贡献。该免疫只保护原生来源自身；已产生的雏龙没有因此免疫。实际突袭攻击和反击伤害继续交给原战斗、免疫与死亡管线。

内部语义为core741；schema591布局、观察117、命令13及replay1保持。没有新字段或effect类型，旧规则语义由mechanics_version拒绝，不补默认值兼容旧核心。默认代表与旧卡定义的运行保全独立核验，不从完整原行存在推导已验收。

专项有限单成员过去库存使用独立实验目标；生产过去域仍未绑定，原34完整参考、模式备注/版本疑点及其他生成依赖保持。实际结果、差异及下一项只在[项目状态](project-status.md)和[机制台账](mechanism-backlog.md)维护，版本对齐与国服规则边界继续暂缓。
