# 原生圣骑士光环

`PlayerEffectSpec.kind="aura"` 表示原生圣骑士法术建立的公开持续实例。注册时要求展示卡是明确带圣骑士职业的法术，且其 `ongoing_effect_id` 指回本定义；安装时核对实际原法术和控制者。历史 `objective` 或随从属性光环不因此变成原生光环。TIME_019仅检查本人当前仍在持续区的此类实例，伤害委托普通 `DamageBatch`，属于随从能力。

原实例继续使用公共附件身份、顺序、容量、安装、移除和倒数。`tick_player` 默认 `controller`，原生光环可显式选择 `opponent`；事件先捕获待计时实例，之后的反应中新建实例不能被旧计时消费。来源法术进墓不撤销已建立实例，同名再次施放有独立身份和期限。具体敌方结束窗口及与其他结束反应的顺序仍是待国服校准政策。

抗性光环的完整固定源为2费神圣法术，持续2个敌方回合，`PALADIN_AURA`、`OBJECTIVE_AURA`均为1，两个脚本持续字段均为2。官网动态显示缺失不改写原行。`opponent_spell_cost=1` 仅表达独立、非消费的敌方法术费用加法，不混合其他主体、奖励或支付规则。

安装复用普通 `AddCostModifier` / `CostModifier` 和现有报价、付款执行器。实例与修正分别保存 `cost_modifier_id` / `player_effect_id`，在第一个费用通知前完成双向连接；恢复时逐向验证原定义、付款方、来源、完整修正和唯一身份。移除或到期只退役该实例自己的修正，不能撤销同来源的其他实例。已接受的付款保留原报价，不因等待期间光环被移除而重算。结构校验不提供未签名存档的来源认证。

默认玩家效果的新字段均保留原语义和注册表指纹；没有新状态账本、区域执行器、效果请求或私有信息投影。快照格式变更按当前内核版本拒绝旧格式。对手时钟、混合持续区容量、费用层顺序和精确国服行为仍须M6证据；完整正式标准池与可达内容仍须各自闭合。实际验收与下一项只在[项目状态](project-status.md)和[机制清单](mechanism-backlog.md)维护。
