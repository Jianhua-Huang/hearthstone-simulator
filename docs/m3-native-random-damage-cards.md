# 随从的逐点分配与随机单次伤害

本契约覆盖疯狂投弹者、愤怒的女祭司、窜逃的黑翼龙和萨萨里安。固定37.0完整原行与审核配方在[卡牌数据](../data/cards/native-random-damage-effects-v1.json)，行为在`hs_sim/cards/native_random_damage_cards.py`；[冻结目录关系](../outputs/card-integration-20261014/k32-source-evidence.json)记录具名官方身份依据。实际进度、验证、差异和下一项只在[项目状态](project-status.md)及[机制台账](mechanism-backlog.md)维护。

## 逐点分配与单次打击

疯狂投弹者的战吼一次接受三个有序命名`InvokeBehavior`；每项执行时重新取得双方当前英雄与普通随从，排除原来源物理ID，再交给原`RandomDamage`造成1点`MINION_ABILITY`伤害。每个物理候选一个权重，原随机通知、伤害、死亡检查及反应完成后才执行下一项。首项反应新召唤的随从可进入下一项候选，原来源随后死亡也不取消已接受的尾项。

愤怒的女祭司声明已有`TriggerSpec('turn_ended', body, EndTurnSpec())`，在原控制者结束主体中返回命名续接，再调用`SplitDamage(3-player_id, 6, source_id, kind=MINION_ABILITY)`。原执行器把6点分成六次1点，每次重查该方当前角色，保留各次随机、死亡和等待；不额外创建SPELL预算，不叠加法术伤害。来源在已接受分配中死亡不让剩余点数丢失。

窜逃的黑翼龙使用相同的原控制者结束声明，执行主体时重新查询当前敌方普通随从，排除休眠、非存活和交互载体。它只调用一次`RandomDamage(..., amount=10, kind=MINION_ABILITY)`，英雄不在候选中；潜行不妨碍随机命中，圣盾吸收整个单次打击。没有目标时沿原跳过通知结束，不消耗RNG。多个结束主体依次执行时，后一个重查前一主体及其亡语之后的局面，不沿用最早的目标列表。

以上分配允许同一个目标重复命中；`RandomDamageBatch`表示一次选择不同目标再结算，不能用它替代这些单位导弹或单次打击。现有SPELL专用`RandomSplitDamage`需要真实施法记录和一次法伤报价，也不用于随从主体。

## 萨萨里安与生命周期

萨萨里安声明印刷`REBORN`，战吼、亡语指向同一个命名主体。每次实际执行重新取得敌方当前角色，原`RandomDamage`选择一次并造成一个2点`MINION_ABILITY`包。原死亡收据提供亡语来源与执行玩家，来源已在墓地仍可造成该次伤害；不把当前同名随从或复生的新实体当作原来源。

普通复生创建新实体、保留印刷亡语并使已消费的复生不再可用，不执行战吼。原体的战吼、原体死亡的亡语与复生体后来死亡的亡语是独立真实执行。沉默在死亡前移除原未来亡语及复生。队列、死亡清理、伤害归因、异常回滚和恢复均沿已有模块，不添加卡牌专属次数或死亡账本。

## 保存与证据边界

三个Core别名的构筑身份分别由官方目录具名`copyOfCardId`与完整`EX1_082`、`BT_493`和`YOP_034`核对；普通`RLK_223`保持自身身份。整包及逐原行pin变化明确拒绝，不从未知858等标签猜行为。

没有新增内核效果、模块、持久字段或账本，`core-effects-v335`与schema271保持；内容签名推进到`constructed-cn37-preview-v38`。玩家观察85、命令12和replay1结构保持。原随机与公开伤害事件继续由玩家信息投影提供，内部帧、原结束材料、死亡材料和RNG状态不返回玩家。

候选重查、原接受主体在来源死亡后的保留、随机通知与伤害之间的反应窗均沿现有内部政策，仍需精确国服校准。严格保存和回放验证不认证未签名外部存档来源。

`python -B -X utf8 -m examples.card_native_random_damage`通过真实玩家命令展示双方英雄分配、六点分配、十点单次打击，以及萨萨里安被真实火球两次消灭的亡语和复生。跨职业场景、短牌库和显式法力仅为内部实验，不认证正式标准套牌或全部可达内容。
