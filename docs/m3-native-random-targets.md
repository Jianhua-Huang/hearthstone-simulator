# 原生随机目标的来源和候选域

当前只实现候选准备和显式抽样，实际激活消费者尚未完成。CORE_CFM_670的完整9费5/4原行与两种语言的完整官网主面保存在数据包；标准注册表继续将这张根卡视作未实现，不能把宿主计划当作整卡支持。代表来源仅由专项测试的私有夹具注册，没有生产卡牌适配器或标准装配入口。

`register_random_target_card`登记原生随从声明。普通初始化添加纯印刷`random_targets`附件，复制、沉默和重置沿已有生命周期；没有增加CardDefinition字段、AbilityInstance字段或GameState账户。`current_sources`只读取场上活跃、未沉默、未濒死且有有效原声明的实际随从，保存物理来源和完整附件身份。双方来源均有效，同一物理载体只登记一次。

## 两种候选域

`manual_partition`接收实际物理来源、有效目标定义和原提交目标，复用手动目标谓词。卡牌类型、区域、敌我范围和结构/玩家谓词保持；敌方潜行、免疫、魔免等手动选中限制仍有效。它不调用普通自动施法的宽松候选查询。实际效果玩家可以与当前物理来源控制者分开，原事实与效果玩家分别保存。

`attack_partition`必须绑定真实、仍开启的攻击窗口。在原攻击已合法声明后，才准备敌方角色的替换域；嘲讽、潜行及攻击者自带的手动目标限制不作本替换域过滤。它不能让冻结随从、未就绪随从或没有合法起始目标的攻击凭空发生。原窗口或原驻留失效时不准备替换。当前攻击替换政策继承既有重定向执行器的边界，更多确切国服规则仍待校准。

两者都返回私有的不可变`NativeTargetPartition`，包括有效定义摘要、原物理来源、效果玩家、原目标、全部原生载体以及完整有序候选事实；不生成事件、不支付、不接受一次出牌或战斗。

`sample`仅接受显式`random.Random`操作数，返回`NativeTargetSelection`及MT19937前后状态。没有适用来源、没有提交箭头目标或没有目标声明时保留原值且不抽RNG；有替换域时等权抽选，单候选也按普通随机抽样消费RNG；空替换域返回显式no_target。构造时局部重演校验抽样和状态，不能将此当作原候选完整性或未签名外部来源的认证。

## 限定来源与边界

[2020年玩家原始实战报告](https://us.forums.blizzard.com/en/hearthstone/t/mayor-noggenfogger-interaction-with-deathwing-mad-aspect/37893)记录市长将死亡之翼的强制攻击转向英雄；[2021年另一原始报告](https://us.forums.blizzard.com/en/hearthstone/t/mayor-noggenfogger-the-mayor-who-doesnt-work/65583)及其讨论说明攻击并不会击中己方角色。这些是历史玩家证据，不是当前国服37.0的官方结算轨迹。

手动可选中限制的精确分类、强制攻击关系切换、重复来源数量与顺序、各类主体何时重新抽选、反应先后及当前国服行为均保留待校准；本地当前候选政策没有被宣称为官方完整规则。生产消费者必须将选中目标连接真实施法、战吼/连击、英雄技能、地标/主动能力及攻击的原接受记录，保留原手动提交和付款事实，并完成待选/回溯/回放及玩家边界后才能装配整卡。这里没有绕过这些接受证明或在回调里偷偷改目标。
