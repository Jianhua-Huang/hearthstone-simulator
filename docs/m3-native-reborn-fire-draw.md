# 原生保留附魔复生与原火焰抽牌的局部法强

本契约对应罪孽战马`CAP_800`和火山长尾蜥`TLC_223`。完整固定原行、附魔证据与配方见[数据包](../data/cards/native-reborn-fire-draw-v1.json)，适配见[卡牌实现](../hs_sim/cards/native_reborn_fire_draw_cards.py)。实际进度、验证与下一项仅在[项目状态](project-status.md)及[机制台账](mechanism-backlog.md)维护。

## 原生复生声明

`CardDefinition.reborn_policy`是末尾可选字段，默认`None`。唯一非空值仍为`full_health_enchantments`，必须与普通随从的原生`Keyword.REBORN`一同声明；不能用于法术、选项、星舰模板或计时复生。原`install_printed`把政策安装到同一条可沉默的印刷复生附件，来源绑定自身，没有“打出后再补授予”的替代实现。

既有授予入口、普通复生与死亡流程保持。实际死亡记录中的未消费复生决定返回政策；原创建、保留附魔复制、容量、入场事件和复生消费继续共用原执行器。新印刷本体和授予附魔均分配新身份，返回后所有复生消费，因此不会自行无限复生。当前复制保留原材料；基础复制、回手重置仍具有卡面自身声明，动态附件沿原重置政策处理。

当前实体与冻结死亡材料都核对原生政策、印刷卡面、自身来源和唯一原生政策行。沉默可以移除印刷行，不能以另一个实体来源、另一卡面政策或重复行冒充原生复生。

新增空字段不改变旧声明含义。注册表签名在字段为`None`时省略它；两个早期冻结依赖检查使用`reviewed_definition_digest`的同一空字段视图。非空政策始终进入签名，不能省略。旧完整原行、配方PIN和历史定义摘要文件不重写；旧定义比对明确区分新增空字段与原字段变化，不宣称原`asdict`字节未变。

## 实际抽牌之前授予局部法术伤害

火山长尾蜥以自身完整印刷种族查询上一段已关闭本人回合的实际出牌；元素或野兽匹配均可，当前回合出牌、仅在场或直接召唤不能替代上一自身回合事实。资格在原战吼接受状态固定。

无资格时复用普通`DrawMatching`，只从本人实际牌库查询FIRE法术，空匹配跳过。资格成立时交`DrawMatchingSpellDamage(player_id, query, source_id, amount)`。此有限入口要求显式SPELL查询、原存在来源和正数加成，按原匹配抽牌的一次随机选择政策捕获一张实际牌库牌；空池不取随机数、不疲劳。

选中后在同一抽牌窗口，先通过`GrantStoredSpellDamage(CardReference, amount, source_id)`向原DECK法术安装局部附件，再委托既有`draw_one`。普通入手、爆牌、抽到时施放、选择和补抽都沿原管线。补抽得到的牌不会继承最初那张牌的奖励；不从完成后的手牌重新找同名牌，也不把局部奖励改成玩家的“下一个法术”光环。

这个窗口来自真实需求：[国服33.2说明](https://hs.blizzard.cn/news/24223019/)及[官方英文33.2说明](https://hearthstone.blizzard.com/en-us/news/24223019/33-2-patch-notes)修复了爆发未受火山长尾蜥法强增益的问题。它证明抽到时施放也必须受益；精确37.0国服内部顺序仍需对应校准。`VAC_321t`爆发尚未注册，本次自动施放边界使用明确命名的实验夹具验证公共能力，不以白板或固定伤害占位实现真实爆发。

`GrantStoredSpellDamage`只作用于原引用仍匹配的HAND/DECK SPELL，永久正数、可复制、可随普通重置清除；不接受原生、临时、学派筛选或无关附件状态。来源和未来分配在带`origin_state`的FrameCodec中核对，旧引用移区失效。没有扩成任意授予或组合机制。

## 同一个实际施法与伤害预算

`SpellCastRecord.local_spell_damage`保存实际主体接受时的完整不可变能力tuple。统一`note_payload`入口覆盖本人手牌、重复、效果、抽到时和历史施法；反制、失败和未接受的主体不能声称获得这份材料。每个实例保留原能力ID、授予来源和数值，不能从另一张物理法术借用、跨卡迁移或使用未来分配。当前复制重分配附件身份，基础复制不继承动态加成。

健康层只在对应实际活动CAST中把这份局部材料加入已有法强来源。普通分段伤害沿各段原规则；随机分配伤害沿原整次预算，只把法强加入总量一次，后续单位交付不再重复加成。分配预算的紧凑证据只允许本CAST、原物理SPELL分配和已冻结的完整局部能力，不能借另一张法术伪装场上来源。治疗、非伤害法术和后续其他法术不会拿到这张牌的局部奖励。

没有新伤害执行器、抽牌历史或GameState字段。core354/schema280保护新增请求、原生声明和CAST材料；真实旧schema279存档明确拒绝。观察、命令和回放格式保持，不能据默认卡包签名保持宣称旧机制兼容。

## 玩家信息与限制

`stored_spell_damage_granted`按既有私有卡牌事件投影，只给实际持有者；原牌库候选、隐藏身份、能力ID、CAST材料及解释器工作帧不会给对手。公开战场仍使用既有属性和关键词，玩家不取得全知快照。

准确国服抽牌内窗口、复制或重复例外、复生附魔顺序及当前热修仍未逐项认证。上述声明不证明完整标准池、全部可达爆发/升级形态或甲龙生成池已完成；未知内容继续明确报错。
