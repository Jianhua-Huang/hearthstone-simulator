# 冰封猛犸的原生火焰冻结门禁

AV_128 的[完整固定原行与两个双语官方主面](../data/cards/frozen-mammoth-v1.json)明确为四费6/7中立野兽，“被冻结，直到你施放火焰法术”。它是标准来源可达的跨系列部件依赖，不作为新增标准合法根；[卡牌适配](../hs_sim/cards/frozen_mammoth_card.py)保留原身份、完整元数据和真实火焰施法监听，并核独立次选参考身份。候选资格仍见[角色参考](m3-zombeast-local-reference.md)，不从能力已实现倒推正式卡池。

## 有限声明与原生标记

`SchoolFreezeProfile(card_id, behavior_id, school=FIRE)`只审一个静态物理随从及其真正的 `spell_cast_finished` 原印刷监听，不是任意条件表达式。声明需有完整类型、真实行为和唯一原卡/行为关联；当前只支持精确类型的火焰学派。

公共[模块](../hs_sim/engine/school_freeze.py)通过原 `install_printed` 安装一个纯 `school_freeze` 原生附件。它只用已有字段 id、kind、source_id、origin、behavior_id、consumed；没有新增卡牌、实体或效果字段。未消费表示本次入场门禁仍关闭，消费后不再阻止普通自然解冻；真实原监听保留，所以后续被普通冻结后仍可再次响应本人火焰法术。

标记必须来自原完整声明，具有本物理随从的自来源和原印刷身份，不接受额外时钟、数值或伪造行为。合成体核完整规范配方、两部件许可、components及真正提供该声明的原部件。当前只审一个门禁部件；多个原生冻结部件明确未审，不能据此裁掉候选。

## 共用冻结和生命周期

实际状态使用既有 `frozen_until_owner_turn`。真正进入战场时，在原物理材料安装后建立新门禁和普通冻结；未满足条件的原生附件使普通 `ThawCharacters` 暂不自然解冻。刷新只维护原门禁，不重复创建账户、计数器、冻结效果或主体。

普通入场、自然召唤、重新进入、复活及复制沿原创建/移动/入场管线。复制材料仍保留原生正文时，新物理入场重开其原生门禁；原物理来源已解除的门禁不会被重新关闭。当前沉默副本沿原文本移除政策，清掉接收者创建时的原生冻结；基础复制恢复印刷门禁。若当前材料本身带有普通冻结，仍由原复制调用者施加。这沿已有条件冻结的每次入场政策，也是本地明确的猛犸复制政策，尚未取得相应当前国服校准。普通复制的原生自来源重绑只为该标记增加有限例外，其他附件的既有来源政策保持。

源在手牌/牌库时不通过原战场监听预先解除门禁。控制变更保留同一门禁，施法归属使用当前控制者；普通冻结时钟仍由原控制移动代码重绑。原沉默、明确解除冻结、不能被冻结及回手重置继续使用公共管线；不能被冻结解除门禁后不因保护来源消失而重新关闭，沿既有条件冻结的本地政策。

## 真实施法及恢复

原监听读取事件的真实 CastRecord，核来源/玩家/目标关联、成功完成、主体已执行且无失败或中断。只对当前控制者的火焰学派施法返回已有 `Unfreeze`，不按消耗多少法力解除，也不把任意学派算作火焰。零费火焰有效；本地成功完成政策下，被反制的火焰不解除。该接受时点沿既有成功火焰消费者，不宣称所有当前国服边缘均已校准。

解除动作沿原共享执行器先消费原生门禁，再清普通冻结并发出既有通知。正文内等待尚未完成时门禁保持，通知内等待则已经解除；原队列恢复、clone、回放及异常事务维持这两个不同边界。普通冻结和旧施法法力冻结继续各用自己的原条件，只有普通自然解冻时统一检查它们是否仍关闭。

实体及原复制材料均验证完整来源标记。对手只获得既有公开冻结状态，不获得内部标记或声明；重哈希的错误原行为、自来源和缺失冻结位不能绕过一致性检查。此处验证本地状态和已接受材料，不认证未签名存档的来源。
