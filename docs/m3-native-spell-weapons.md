# 原发现法术与真实武器载体

阿扎达斯 BE_055 为4费4/3，战吼发现法术并变为同费3/3武器。官网父面的 childIds 明确给出132338，与本地 BE_055t“阿扎达斯之锤”对应；该真实武器模板印刷1费3/3，正文是在英雄攻击后随机施放所保存的法术。没有合成卡ID、逐法术生成武器定义或新的战斗执行器。

[完整源包](../data/cards/archaedas-v1.json)保存两个完整原始行及四份完整官网主响应。武器的运行时法术名槽 `{0}` 在两语言官网中留空；初次严格失败及原始响应保留。公共核验只为这一份完整原行摘要允许省略该名称，卡名、类型、职业、费用、身材和正文其余部分仍严格比较，不放开通用标记替换。完整原行或正文有任何变化，不能借用这一例外。

原 `DiscoverFromPool` 通过有限 `spell_weapon_card_id` 声明真实模板，仅支持一次普通本职业可收藏法术发现。原候选、随机、完整 offer、实际 ChoiceResult 与发现历史继续共用；未知合格法术明确报错，不能从池里删去。`DeliverDiscoveredSpellWeapon` 绑定原 ResolvePoolDiscovery，交同一 MaterializeDiscoveredCard 和发现完成管线；发现记录的选中卡仍为法术，实际物理交付是带原法术材料的真实武器，满手则烧毁该武器。武器材料和费用在普通 card_created/card_added_to_hand 前安装，不给玩家一张临时白板或未初始化载体。

武器复用 `carved_spells` 的印刷能力参数和原 `carved_spell_id` 保存格式。`CarvedSpellProfile.weapon_attack` 只开放真实非收藏武器、唯一 attack_finished 触发和真实战吼创造者；原树人和学生的战吼载体分支保持。武器以原选中法术的印刷费用作为本体费用，印刷模板定义仍为1费；后来的普通费用附件继续独立作用。源法术当前报价与印刷费用的选择、发现完成和实际交付相对窗口仍是待国服校准的本地政策。

现有复制材料已经保存完整能力，当前复制沿原机制保留；基础复制补上同卡原生武器材料继承。普通存储移动及显式 reset 保留原法术和本体费用；替换变形重建本体，清除旧材料。印刷费用查询沿已有物理本体查询入口读取该原费用，不在支付器再特判卡ID。没有新增 Entity、PlayerState 或顶层历史字段。

攻击完成查询从既有真实卡适配中原样下沉到 character_attacks，旧适配保留同名导入；它只定位原完成记录，裸 CombatDamage 不冒充一次声明攻击。武器触发读取普通 BehaviorCall 已保存的原来源状态，核对原英雄攻击及原实际武器，再返回已有 CastSpell。施法使用独立物理法术、原武器作为 caster，随机目标和法术自身选择由既有施法器负责；不是手牌使用，不重复付款或添加手牌出牌事实。最后一点耐久及已接受反应中的武器销毁沿原磨损、死亡和队列政策，不另写攻击循环。精确反应时序仍待M6。

玩家观察版本116只对获准查看的载体增加 `cast_card_id`：本人手牌和公开已装备武器可见，对方隐藏手牌不可见。私有 recipe、完整发现 offer、能力字段及宿主队列不进入玩家 DTO；动作13、回放1保持。core650/schema536识别新发现字段和一类交付请求，旧版本存档使用对应旧内核。原生卡行为、保存、克隆、回放和异常回滚复用公共实现；实际执行、差异与下一项仅在原两份台账维护，M0正式池、M6国服校准和M7完整内容继续分别验收。
