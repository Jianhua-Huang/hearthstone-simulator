# M3：原生获得属性后的额外奖励

达拉然魔像勇士JAIL_330使用[完整固定材料](../data/cards/native-stat-gain-v1.json)：4费3/3、圣盾、嘲讽；JAIL_330e仅保留为原始附魔证据，不登记可执行卡。NativeStatGainProfile声明一个可被沉默和重置移除的印刷来源，非空声明进入注册表指纹。

## 共用属性操作

每个普通Effect执行前捕获实际载体的原生能力和已有属性附件；执行后按原有顺序比较新附件的局部属性。一次附件增加攻击或生命中的任一项，只接受一次额外+1/+1；两项同时增加不算两次。奖励仍调用普通属性安装器，既有属性、死亡、费用、区域及反应由原管线处理。

检查覆盖实际物理随从的场上、手牌、牌库与保留材料；场上休眠来源不生效。普通创建先安装印刷来源，再接受后续明确授予。当前复制先恢复冻结材料，再重新捕获已有附件，因此不会把继承的增益算作新获得；明确的后续属性覆盖单独判断。光环的派生重算、属性下降、费用变化和额外奖励自身均不创建新奖励。

原效果窗口内的捕获仅存活到同步处理器返回。接受后使用有限RewardNativeStatGain工作项，携带原物理分配、原生能力、新附件及原局部数值；等待选择、恢复、clone和回放沿同一解释器，不依靠隐藏的可变回调。现有事件保存每个原附件/原能力的奖励收据，稳定边界拒绝重复、未来附件及未声明载体；不提供未签名存档的来源认证。玩家接口不输出这些内部材料。

AbilityInstance仅新增native_stat_gain_card_id，无GameState、Entity或CardDefinition字段。core564/schema458拒绝旧1～457；观察101、命令12、replay1保持。

## 官方证据与本地政策

完整双语官网主面保留在批次证据。官方[问题讨论](https://us.forums.blizzard.com/en/hearthstone/t/dalaran-champion-gained-stats-but-not-its-extra-11/163604)中，玩家报告只增加生命没有获得额外奖励，工作人员表示将调查；这支持不能忽略生命增益，但不证明国服37.0已修复或给出精确时序。完整论坛响应及哈希另行保存。

按新局部附件计次、设值和显式复制覆盖的判断、奖励先于普通已捕获反应、场上休眠排除、临时原增益的额外奖励永久保留，以及保留材料范围，均为待M6核对的本地政策。正式合法池、全部可达内容及发布验收继续独立登记；实际验证和下一项只在[项目状态](project-status.md)与[机制台账](mechanism-backlog.md)维护。
