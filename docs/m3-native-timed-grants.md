# 原实体关键词授予与既有期限

`GrantCapturedKeyword` 增加末尾可选 `duration: TimedKeywordSpec | None`，默认行为保持。请求构造和实际授予都交给原 `GrantKeyword` 校验；禁止关键词不匹配、非期限对象和同时指定两种到期方式。原 `MinionReference` 仍先核对存活、当前定义、控制者、区域驻留及入场身份，过期引用不安装附件，也不替后来重入的同 ID 随从绑定时钟。

没有新的计时器、实体字段或期限执行器。匹配原随从后，由原关键词执行器在实际安装时绑定玩家及真实自身回合序号。待选请求中的期限沿原帧白名单保存。新增可序列化参数使用 core384/schema307，旧 schema306 及更早格式须使用原引擎。

## 实际来源

固定 37.0 完整源中的 `TLC_246` 远古翼手龙是 4 费 4/4 野兽。其战吼发出普通单选，选项连接同一原随从：

| 官方关联选项 | 实际授予 |
| --- | --- |
| UNG_999t10 / 41054 氤氲迷雾 | 潜行，直到安装时控制者下次实际回合开始 |
| UNG_999t5 / 41060 液态外膜 | 扰魔，无期限 |
| UNG_999t7 / 41062 闪电之速 | 风怒，无期限 |

三个选项来自真实官方关联，作为不可物理打出的 `choice_only` 定义保留；没有独立法术主体、生成池资格或费用支付。原始隐藏费用为空，选择描述面显式采用 0。根卡只有战吼，普通召唤不会执行。这里没有新增德鲁伊抉择声明。

完整原记录和八份中英文官网完整卡面由 [固定数据包](../data/cards/native-timed-grants-v1.json) 绑定。选项中保留真实卡面 ID。根卡付款、普通待选、原引用、附件、控制、复制、沉默、回手、恢复与回放仍沿公共管线。
