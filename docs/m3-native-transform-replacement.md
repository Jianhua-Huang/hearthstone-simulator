# 原生随从的变形目的替代

胆大的魔荚人EDR_529使用[完整固定材料](../data/cards/plucky-podling-v1.json)：1费1/2萨满史诗，完整原行及两个完整双语官网主面保持。它声明有限`NativeSourceCondition('transform_destination_plus_two')`，安装纯印刷`transform_replacement`附件；没有新增CardDefinition或AbilityInstance字段、伪造关键词或任意条件表达式。

## 一个实际变形

公共`transform_minion`先取得原本要变成的随从，再按该目的定义的印刷费用加2查询`constructed.cards`。当前身体必须仍有有效的原生附件；原先的随机变形照常完成原目的抽选，替代池再抽一次。全部合格候选先核验，未知定义不从池中删掉。当前政策仅让活跃存活战场随从提供替代；手牌、牌库及休眠实例沿普通变形政策，精确区域行为仍待M6。

替代在原身体重置之前完成，直接交已有变形器安装最终身体，只有一次transformed通知，没有中间随从、召唤或战吼。原位置、owner/controller、本回合攻击次数与召唤回合继续保留；光环、印刷休眠、巨型与原入场逻辑共享。原请求若是当前复制变形，替代不借用该复制来源的局部材料或固定复制属性；原效果独立的保留费用及升腾式实际亡语授予仍安装到最终身体。

当前复制保留印刷附件并分配新附件身份。其历史source_id可以仍指原复制来源，实际承载者另用SourceAllocationFact捕获，不能强制两者相同；转控后按当前承载者处理。沉默移除附件后普通变形不需要替代池。空替代费用档目前保持原身体、无替代RNG且不安装原变形的后续授予，这是待国服确认的明确内部政策。

## 保存、证明与信息

`TransformReplacementDraw`保存原承载者、完整附件、原目的卡面、上下文/池版本、完整有序加权候选、实际选择、MT19937前后状态及实际变形事件序号。保存时重算完整费用档并局部重演抽选，核对真正的一次变形；空池保存空结果。只新增这个类型载荷和私有诊断事件，没有新GameState账本或执行器。

待选恢复、clone、回放和异常回滚复用原解释器；事件白名单不向任一玩家输出候选、RNG或完整证明。冻结卡牌/随从复制材料沿原生来源条件校验，不能借复制载荷夹带另一卡面的声明。证明检查结构和执行一致性，不提供未签名历史的外部来源认证。

core544/schema439识别新有限种类及载荷，旧1～438使用原引擎；观察99、命令12、replay1保持。全部旧定义字段布局保持，原指纹和完整数据另按原两份台账的证据核对。

## 证据边界

完整官网主面支持从“原目的随从”费用再加2；来源不是魔荚人自身的费用。现有材料未确认全部区域、原目的/替代抽样、空高费用档、固定复制属性、控制和通知细节，这些保留M6。正式池、国服校准和完整可达内容不因接入这张牌而完成。实际执行、测试结果及下一项仅在[项目状态](project-status.md)及[机制台账](mechanism-backlog.md)维护。
