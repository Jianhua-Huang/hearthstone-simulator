# 真实武器的普通抉择入口

EDR_525「倒刺荆棘」是3费1/3武器，官方两个分支分别给予本回合剧毒、给予对所有敌人造成2伤的亡语。[完整来源包](../data/cards/native-weapon-choice-v1.json)保留原武器及两个非物理选项；P03原跳过记录继续作为当时证据，不代表K88后的执行状态。

## 入口与范围

普通 `ChooseOneSpec` 允许武器，通过原手牌动作接受分支、检查目标和支付，沿原装备管线安装原实体，再执行捕获的 `on_play` 分支。不会产生额外法术施放或战吼。直接 `EquipWeapon`、Scenario已有武器不执行手牌分支。

已有物理预选对武器只允许 `hand` 来源，拒绝把武器声明成法术施放、英雄技能或生成随从。没有扩展自动装备/历史重放的分支协议，也没有新增玩家兼得修正器的种类范围。旧入口的复合声明限制保持；现有场上兼得来源使用原显式combined主体，不另建组合机制。

## 原有公共生命周期

剧毒使用 `GrantKeyword` 及当前回合 `expires_turn`，原装备投影赋予当前行动英雄相同关键词，普通结束到期统一移除。亡语使用 `GrantDeathrattle`，跟随原武器，替换、磨损和主动消灭交原死亡协调器；转移后的亡语使用死亡时控制者。亡语一次普通 `EFFECT` 伤害批次读取当前敌方角色，不增加法术伤害，也不重扫该批死亡中新出现的对象。

分支以原武器ID为接收者，不改投新装备。原装备反应已将来源移除时，既有授予器按其区域资格跳过。保存、待选恢复、失败回滚、克隆和回放使用原解释器，无新状态字段、payload或执行器；core380/schema303，旧执行身份明确拒绝。

精确装备/分支/通知顺序、剧毒亡语归因、转移和到期的国服规则仍待M6。官网卡面支持身份、数值与正文，内部验证不能代替官方校准。实际结果及后续只在[项目状态](project-status.md)和[机制台账](mechanism-backlog.md)登记。
