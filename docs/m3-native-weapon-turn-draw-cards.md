# 武器吸血、对手回合攻击力与最高费用抽牌

真实条件消费者继续使用既有属性、攻击、施法和物理库存事实；跨冻结反应的原邻位组仅增加有限法术续接，冻结/死亡仍由公共执行器负责。保存、末次武器奖励及初始资格的边界见[契约](m3-conditional-consumers.md)，当前执行版本以原两份台账为准。

本契约覆盖奥达奇战刃、堕落的灰烬使者、焦油爬行者与泰兰·弗丁。固定37.0完整原行和审核配方在[卡牌数据](../data/cards/native-weapon-turn-draw-effects-v1.json)，行为在`hs_sim/cards/native_weapon_turn_draw_cards.py`。[冻结来源](../outputs/card-integration-20261014/k33-source-evidence.json)保留官方目录关系及成本调查线索。实际进度、执行验证、差异与下一项仅在[项目状态](project-status.md)和[机制台账](mechanism-backlog.md)维护。

## 原生武器

两把武器声明印刷`LIFESTEAL`，完整原行中的`HEALTH`映射为耐久而非随从生命。装备、英雄攻击、真实伤害、吸血、磨损与最后耐久消失均沿原装备和战斗层；卡牌不额外给英雄永久吸血，也不单独调用治疗。圣盾阻止的零伤害不产生吸血，最后一次实际打击仍按原战斗捕获的武器规则处理。堕落的灰烬使者保留原双鲜血符文元数据。

## 对手回合的持续攻击力

焦油爬行者声明原`TAUNT`与一个印刷的闭合关系：

```python
StatRelationSpec(
    operand=StatRelationOperand.CONTROLLER_OPPONENT_TURN,
    layer=StatRelationLayer.CONDITIONAL_ATTACK,
    amount=2,
)
```

该关系只支持普通非融合随从自身攻击力、严格正整数数值及原条件层；不开放动态授予、任意条件图或跨载体表达式。原生附件必须可沉默、有原来源、无期限、未消费，并与本卡印刷声明及数量相符。未知/错误层、布尔数值、重复原生附件或借用授予来源均拒绝。

当前载体实际在`BOARD`、按原规则活跃且`active_player != controller`时贡献数值；使用当前控制者，不读取原拥有者或复制来源的控制关系。贡献进入既有`conditional_attack`派生缓存，位于原印刷/有序附魔与外部光环之后的条件层，原最终自身生命关系仍沿原政策；不会写成永久Buff或反复累加。

真实开始后继回合、更新`active_player`和全局回合号后，`refresh_turn_attacks`仅重算带该操作数的载体，再创建新本人回合和开始工作。没有这类来源时不刷新其他属性关系，也不改变原关键词刷新路径。额外本人回合仍按实际行动玩家判断，跳过的槽位不制造一次假生效窗口。结束反应尚未真正切换玩家时仍属于结束方的回合。

沉默、休眠、离场或变形撤销该贡献，唤醒重新计算；当前复制与转控按接收者当前控制关系重算。回手不把条件贡献复制为手牌永久攻击，死亡材料保存原死亡窗口攻击，不用后续回合重写历史。完整刷新和事件前规范化继续共用原属性关系模块。

## 最高实际牌库费用的定向抽牌

原`DrawMatching`增加显式`selection='highest_cost'`，保持原六个字段。先沿原`PoolQuery`筛选当前物理牌库，再比较`max(0, local_cost(entity)[0])`：这表示牌库实体的基础费用与其当前实际保存的费用附魔，不是它将来进入手牌后的报价。唯一最高项直接选中且不耗RNG，并列按各物理实体一个权重随机选择一次。

泰兰的亡语提交`DrawMatching(player_id, PoolQuery(kinds=(MINION,)), 'skip', selection='highest_cost', source_id=source_id)`。实际抽牌继续走原`MoveCard(draw=True)`及抽牌管线，保留原实体、真实抽牌历史、满手烧毁、抽到时效果和选择恢复。没有随从或空牌库只跳过，不造成疲劳；多个独立亡语各自在实际执行时查询剩余牌库。

原牌库减费附魔会改变最高项；手牌才应用的内在减费或外部支付报价不提前改变它。历史玩家报告分别记录了牌库实际减费后抽取变化、缝合巨人仍按牌库费用被抽到的现象，只作为这项内部政策的第一手调查线索，不是开发者确认或目标补丁国服校准。

原`DiscardMatching`的最高/最低费用仍比较当前手牌完整报价，和本项牌库口径分别声明；其原代码分支、支付无消费和续接政策保持。`DrawMatching`没有开放最低费用，牌库匹配销毁也没有借本项开放费用极值。普通`random/first`抽牌保持原政策。未知内容不从候选中静默删除。

## 保存、版本及边界

没有新增效果类型、内核模块或持久字段，schema271布局保持，`core-effects-v336`和内容包`constructed-cn37-preview-v39`签名标识新语义。原严格typed codec可保存新增枚举值与显式选择政策，旧语义签名不能因布局相同被当作当前存档。默认历史代表包不增这四张根卡。

原缓存校验在每个冻结状态自身的控制者/实际行动玩家域重算，陈旧条件攻击与伪造原生声明拒绝；这些检查只证明内部一致性，不认证未签名外部存档来源。玩家看到当前攻击、公开武器和合法操作，不看到内部条件缓存、属性附件、完整费用材料或工作帧。观察85、命令12和replay1结构保持。

精确国服回合切换截面、牌库费用层例外、并列随机以及非活动显示政策仍须M6校准。正式标准合法/可达内容与构筑热修继续独立处理。

`python -B -X utf8 -m examples.card_weapon_turn_draw`通过真实玩家命令展示两把武器的普通及最后耐久吸血、焦油的原死亡攻击，以及泰兰的物理定向抽牌。跨职业场景、短牌库与显式法力仅用于内部实验，不认证正式标准套牌。
