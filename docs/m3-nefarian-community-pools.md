# 奈法里奥斯本地参考池

维克多·奈法里奥斯的本地候选来自已保存的 [Wiki 玩家实测整理](https://hearthstone.wiki.gg/wiki/Victor_Nefarius)。完整原响应及提取收据留在 K543；运行数据为 [nefarian-community-pools-v1.json](../data/cards/nefarian-community-pools-v1.json)，含 19 条龙、20 条亡灵原始条目，合计 38 个身份，以及每个完整原行和原生执行定义摘要。社区反复观察不构成官方穷尽性证明。

亡灵表中的 CATA_898 鳞甲长矛手，与固定数据的“只有龙种族”冲突。本地保留原始成员，在亡灵阶段明确登记排除，因此当前可提供 19 个龙、19 个亡灵身份；没有改写原卡种族。这个排除来自角色冲突，不是执行覆盖过滤。官方是否使用其他身份或名单存在笔误，仍未确认。成员均使用本地单位权重；官方非均匀权重和热修归属未确认。

原始两个来源池保持独立目标及 complete=false；[本地宿主绑定 v2](../data/cards/local-special-pool-bindings-v2.json)保存完整成员、排除、来源文件及原池摘要，审核后复制到统一的新本地目标。complete=true只指该声明的本地名单闭合，不表示正式国服池完整。原标准构筑根和资格仍由原上线候选策略决定，专用池没有新增狂野构筑资格。

所有可选原料必须有原生执行定义、完整池元数据和明确的捐赠适配。注册时核每个完整定义，并校验当前十费预算内的合格配对；没有实现的原料须报错，不能删候选。实际战吼仍通过公共 CraftMinion 执行，两个接受窗口、完整候选、随机状态、选择、折扣与最终物理造物沿用既有保存契约。

合成安装保留每个原料的独立主体和附件。END_022 的受伤法伤保留自己的条件，不与另一原料的无条件法伤混为一个条件；ULD_185 的受伤攻击使用原关系，按合成后的当前实体判断。BRM_025 与 ICC_700 的实际配对沿用既有“死亡数量价格阶段，再英雄治疗归零”顺序，随后处理局部折扣和外部约束。这里只补这些真实原料所需的桥接，不扩展任意条件组合。锋鳞仍使用[最终费用下限](m3-final-card-cost-floor.md)。

存档中的原始材料、条件数值和附件重数须与声明相符；借用其他材料、移除条件或重复原生属性附件必须拒绝。观察给玩家的仅是既有公开预览和自己的最终造物，原始候选、随机状态、内部接受收据不能泄露。

实际执行结果及下一项仅在[项目状态](project-status.md)和[机制台账](mechanism-backlog.md)维护。版本同步和待验证规则边界沿用户要求暂缓。
