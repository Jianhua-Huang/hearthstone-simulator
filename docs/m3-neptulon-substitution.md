# 耐普图隆的原攻击替代

TID_712接入固定候选快照，保留10费7/7、巨型+2、突袭和风怒。既有TID_712t与TID_712t2仍各为4费4/2独立随从，攻击时免疫继续使用原关键词和普通伤害执行器；本次不覆盖或重新定义两只手。完整根/手原行、双语主面和旧手定义摘要在[data/cards/neptulon-substitution-v1.json](../data/cards/neptulon-substitution-v1.json)。这是标准宿主究极边境实际能够发现的跨系列依赖，不是另起完整狂野接卡。

## 接受与执行

卡牌仅声明印刷attack_declared触发和有限AttackSubstitutionProfile，回调交CheckAttackSubstitutes。原攻击入口仍负责合法目标、突袭/嘲讽/冻结检查、一次本体攻击消耗、潜行移除和原ActionWindow分配。普通强制本体攻击也走同一触发入口，但保留原强制入口不消耗手动攻击次数的规则。

Check在原监听位置执行，重核原身体、控制者、驻留、活动存活状态以及可移除的原印刷触发附件。此前沉默或离场使本次检查不接受替代；没有合格手则继续原7攻战斗。接受时保存原选中窗口和完整本人随从候选，按当前原生手身份、活动存活条件筛选，按当时场上顺序冻结每只手的独立BoardPresenceReference和原身体epoch。所有友方手均可入选，不按最初召唤它的本体分组，也不只取两只。

原本体窗口保持在栈底；每个成员依次交既有ForceAttack，仍使用原窗口、互相伤害、免疫、反应、死亡与检查点。冻结、刚召唤和用过普通攻击次数的手仍可接受原强制攻击；不另支付它的手动攻击次数。沉默的手保留原身份，可以被选中，但其攻击时免疫依正常生命周期消失。

每次强制交付前重核原手身体与原目标驻留；变形、离场、控制改变、休眠、死亡或原目标失效时记录跳过，不另找成员或目标。接受后新来的手不加入；本体后来死亡或沉默不撤回已接受序列。原手的实际伤害使用交付时的正常属性，不把卡面4点当成固定伤害。

所有成员尝试结束后，原ResolveAttack交付本体窗口并记replaced终态。本体不再造成战斗伤害或承受反击，不伪造attack_finished或completed战斗记录；每只实际攻击的手有自己的forced声明、接受与完成历史。本体已消耗的手动机会保持，风怒可以再次声明并重新接受当时名单。

## 恢复与完整性

原CharacterAttackRecord增加可空substitution计划，包含来源分配事实、触发附件身份、接受时钟、原目标、完整候选、选中驻留、实际尝试前缀和有限状态；未替代的旧攻击仍走原流程。ForceAttack增加可空producer_link，只对替代成员绑定父窗口与原索引，普通强制请求保持默认形状和行为。

每个活动计划只有一个原Continue尾及必要的下一成员请求，不能跳过未完成子攻击、交换成员/尾顺序、裁去或复制尾。原攻击尾校验同时覆盖实际等待与PaidHandChoiceBoundaryProof中保存的队列。成员原声明、父窗口、目标、控制者、身体epoch与独立收据互相核对；替代控制不能作为新的ChoiceOption效果提供。终局保存实际尝试前缀并中断未完成计划，由原清理过程退役窗口和队列。失败仍整次回滚。

新增收据用于内部一致性检查，不宣称无签名外部存档的来源认证。其私有接受、尝试、完成和本体replaced事件不加入玩家事件公开名单，计划不进入玩家DTO。原手正常攻击及伤害继续使用原公开投影。原命令、回放协议和玩家观察版本保持，core748/schema598拒旧1～597；空默认注册表不因空profile改变指纹。

## 证据与保留差异

[官网完整卡面](https://hearthstone.blizzard.com/en-us/cards/75583-neptulon-the-tidehunter/)支持印刷关键词和友方手替代攻击，完整双语响应已缓存。论坛[多只手讨论](https://us.forums.blizzard.com/en/hearthstone/t/theres-a-bug-with-neptulon-the-tidehunter/93353)及[单独攻击讨论](https://us.forums.blizzard.com/en/hearthstone/t/multiple-neptulon-fix/102479)是玩家报告，不是开发者裁定，也没有被当成国服全规则认证。

左右手ID映射、精确接受监听时点、场上顺序、冻结物理名单、原目标失效跳过、后续来源离场继续均是本地明确政策。秘密重定向、被迫攻击友方/自身手的特殊目标，以及历史沉默缺陷报告保留为待验证规则边缘，不据报告发明新的异常执行器。版本与国服校准继续按用户要求暂缓，不阻塞已知名单实际效果接入。

实际测试与执行结果、剩余专用域及下一项只维护在[项目状态](project-status.md)和[机制台账](mechanism-backlog.md)。参考根全部有定义不代表递归生成依赖闭合，也不代表过去卡牌/法术生产域已完整绑定。
