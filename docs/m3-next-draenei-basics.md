# 下一张德莱尼：独立匹配与有限消费

这是两条必要真实来源的基础表达契约。现有玩家效果、冻结出牌事实和普通增益／复制已经足够，无需新增“下一张”模块、可变回调计数或组合接口。实际执行、验收与下一项仅在[项目状态](project-status.md)及[机制清单](mechanism-backlog.md)维护。

## 需求与依据

星光漫游者 `GDB_720` 的战吼使下一张打出的德莱尼获得 +2/+1。阿斯卡拉 `GDB_455` 的当前完整本地记录是 4 费 4/4，使下两张打出的德莱尼各召唤自身复制。[官方资料片介绍](https://hearthstone.blizzard.com/en-us/expansions-adventures/the-great-dark-beyond)支持未来德莱尼的共同方向；[34.6 官方补丁](https://hearthstone.blizzard.com/en-us/news/24242740)及[阿斯卡拉卡页](https://hearthstone.blizzard.com/en-us/cards/111020-askara/)支持从下一张改为下两张。它们没有证明当前国服的反制、入场失败、匹配依据或奖励时序。

[完整 raw](../data/support/next-draenei-basics.json)保存两张来源、两条附魔证据及鱼人袭击者 `CS2_168` 的原始行和指纹。附魔行仅作原始证据，不作为可执行卡牌。鱼人袭击者是必要非匹配对照，其他观察、区域及选择探针明确为合成定义；没有接入生产代表包或正式生成池。

## 表达方式

- 一次效果：战吼返回 `AddPlayerEffect`，定义监听 `minion_play_accepted`。纯回调检查原出牌玩家、实际提交卡面和种族，匹配后返回 `RemovePlayerEffect`，再返回 `Buff`。
- 两次效果：两个命名 `PlayerEffectSpec` 阶段。首次匹配移除第一阶段、安装第二阶段，再 `CopyMinion`；第二次匹配移除第二阶段、再复制。新阶段不参与已经捕获的原事件，召唤的复制不产生新的付费出牌接受事实。
- 实例与未来阶段保存在既有 `PlayerState.player_effects`；卡牌代码不改状态、分配器、历史或 RNG。注册定义与回调沿既有冻结指纹及选择帧保存。

资格检查复用 `matches_metadata(PoolQuery(kinds=(MINION,), tribes_any=("draenei",)), ...)`，传入原 `played_face` 的卡面及元数据。全种族按原匹配规则处理；需要但未知的种族元数据明确报错，不能静默当作非匹配。

## 当前本地窗口与生命周期

本实验只验证实际付费手牌随从的成功物理入场。奖励在 `minion_play_accepted` 的捕获反应中执行，早于该随从战吼主体；当前采用冻结提交卡面的印刷种族。反制及支付后的满场入场失败没有此接受事件，因此保留未来效果。开始时已满场的非法出牌则保留整个动作前状态。这些政策须由 M6 国服证据校准，不能由内部通过推断为官方规则。

创作者的新效果由战吼安装，晚于它自己的接受事件，所以不消费自己刚创建的效果。**不能永久排除原来源实体**：同一个创作者回手后再次打出，可以消费此前留下的效果，然后战吼再创建新实例。

未来效果属于原受益玩家；来源死亡、沉默、回手或转控不撤销或转移它。普通自然回合没有期限。来源的召唤／复制不执行战吼，也不复制已建立的玩家实例。普通生成、抽牌、召唤和复制不是付费打出，不消费未来效果。

先消费匹配实例，再交付奖励。复制时场面已满仍消费该次，但按原 `CopyMinion` 记录失败，不额外插入实体。原外部动作失败会整体回滚实例、阶段、属性、区域、付款、历史与 RNG。

## 恢复与玩家边界

实例移除后、第二阶段安装后、属性交付后的待选，复用公共选择解释器和冻结回调工作。独立注册表加载快照、克隆和动作回放保存原工作；继续选择不再次消费、换阶段或交付。同一普通场景的两次消费中间也可恢复。

两方只看到既有公开玩家效果 DTO：`effect_key`、`card_id`、`effect_kind`、`remaining_turns`。全局实例 ID、原来源实体 ID、提交事实、区域驻留和 RNG 不进入该 DTO。读取玩家接口不消费实例或随机数。本表达无新的快照字段、效果处理器或协议版本。

## 保留范围

完整来源、正式合法与生成池、动态种族、自动／整牌来源、精确国服政策仍开放。行星领航员的支付前资格及一次减费／额外过载消费、王牌探路者保留原两个额外效果，分别需要核对既有费用和结果保存能力；接口没有一个字段不等于已经证明缺少公共机制。不展开特殊授予、组合矩阵或批量接卡。
