# 下一张已使用法术的原生额外主体

古言术三张真实来源共用一个有限程序，主效果继续使用普通抽牌组、召唤及随机伤害。BE_221抽一张并为原交付减2费；BE_222召唤原BE_222t的5/5吸血虚翼龙鹰；BE_223随机对一个敌人造成3点SPELL伤害。完整三根、一个已知本地衍生物和三附魔证据保存在data/cards/ancient-word-cards-v1.json。根卡六个双语主面已核验；官网没有返回130406衍生物主面，不能宣称其官网或国服核验完成。完整本地记录的唯一双语名字/5/5吸血、同系列职业和BE_222t身份，与双语父牌明确命名相吻合，作为内部接入依据，原缺页响应保留。

## 注册与执行

先注册来源SPELL、普通PlayerEffectSpec及纯额外主体，再注册`NextSpellBodyProfile(program_id, card_id, behavior_id, school)`。程序必须是独立、无数值/光环/计时的普通persistent实例；当前仅三张真实古言术注册Shadow来源。默认代表注册表没有这些声明，其指纹保持。不能把已有费用加法伤程序或整张存储法术Aura当任意额外效果。

主牌执行普通效果后安装程序，只在该来源真实且已接受的CAST中允许安装。初始来源可以是正常重复或自动施法；程序的下一接收者仅为原hand且符合派系的物理CAST。沿共享note_payload接受窗，在目标/反制之后、公布接受和执行主效果之前，一次捕获全部匹配实例，按原附件ID顺序转交给当前CAST。转交提交后发普通player_effect_removed；persistent不是计时到期，不伪造expired或零剩余回合。Countered未接受主体不消费，这是当前内部窗口政策。

完整实例存入`SpellCastRecord.next_spell_body_effects`，从玩家的待用区移除。当前主效果全部完成后、原spell_cast_finished之前，由共享解释器逐项调用额外主体；不产生新CAST、不再次付款、不重复安装原古言术程序。额外主体使用当前施法者、当前CAST和普通法术伤害/召唤来源；每次实际调用读取新局面，不预先冻结一整组目标。主效果或反应刚安装的程序不补入已接受计划，保留给后续法术。

## 挂起与恢复

`next_spell_body_cursor`的2i表示第i项尚未开始，2i+1表示已接受并运行，2i+2表示已完整完成。ContinueNextSpellBodies/FinishNextSpellBody只推进既有原计划，拒绝错父CAST、重复开始、跳槽或跨过运行中主体；原FinishSpellCast必须等整组完成。队列保存普通效果与剩余完成续接，额外抽牌、选择或嵌套施法等待时不重新认领。终局中断沿原内核，不把未完成主体标为完成。

私有installed/claimed/removed/started/finished证明保留原源CAST、完整有序实例、实际槽及执行身份。Game恢复按有效事件线性重建待用区和原计划/游标，核对全部当前玩家实例和CAST；原回溯撤销的事件不混入。FrameCodec检查原未完成CAST及当前/紧随完成后的合法队列位置。已接受实例不能裁掉、重复或换源，重哈希也不能绕过内部一致性检查；这不为未签名存档提供外部来源认证。

新增两个既有CAST字段和两个薄解释器续接Effect；无新GameState/Entity/PlayerState字段、费用账户或卡牌层结算器。core614/schema505拒旧1～504，观察114/命令12/replay1保持。实际执行版本和验收只在两份原台账维护。
