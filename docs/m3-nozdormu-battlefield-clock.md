# 原版诺兹多姆的在场计时

真实来源是EX1_560诺兹多姆，九费8/8龙，双方回合只有15秒。完整原行、八个官网语言面及完整732过去传说域保存在[资料文件](../data/cards/past-nozdormu-battlefield-clock-v1.json)。CS3_035永恒者诺兹多姆是独立原始牌库开局来源；两者不互相替代。

## 公共来源与生命周期

`BattlefieldTurnClockProfile`只接受这张已核对真实来源的15000毫秒声明。注册通过已有turn-clock注册表，原`TurnClockProfile`、开局钩子与唯一安装证明保持。新公共模块不改CardDefinition或AbilityInstance的字段，也不迁写历史卡牌定义和资料指纹。

在场声明使用普通可复制的trigger能力载体，标记事件是不会捕获触发的宿主扣时事件。卡牌回调为空；实际查询、累计时间、选择到期及自然结束都在公共引擎。这个声明没有另造每回合开始的卡牌动作或卡牌层定时器。

每次查询从双方实际战场读取活跃、存活、未注定死亡的普通随从及当前未消费的标记能力。原沉默移除能力；回手、死亡、变形和休眠沿普通生命周期退出。当前材料复制保留能力，沉默后的材料复制不恢复印刷文本；控制改变保留全局规则。多个独立来源只共同给出一个15秒上限，不叠成更短时间。

已有永恒者开局安装继续独立生效。所有在场来源退役时，它仍提供原上限；没有该开局安装时，最后一个在场来源退役就撤销上限。

## 确定性时间与本地政策

继续使用可信宿主`AdvanceTurnTime(owner_turn_id, elapsed_ms)`，不读墙钟，不从动画长度推断时间，也不增加玩家指令。上限绑定已有owner-turn区间，场景模式首回合使用原概念开始边界，不伪造构筑开局或turn_started事件；额外回合获得自己的新预算，被跳过的机会不制造实际计时回合。溢出只扣到当前回合剩余时间，不带入下一回合。

中途首次出现来源且此前没有扣时，本地给当前实际回合完整15秒可计费预算；只在存在计时来源时接受宿主扣时。这个回合以前已扣除的时间跨沉默、离场、复制、转控及重新入场保存，因此来源反复进出不重置预算。无来源期间不接受计时输入，不虚构那段时间的服务端流逝。这个起点和暂停政策明确待国服校准。

到期继续复用原选择恢复器：主动方选择保存完整候选、基数、答案和MT19937前后状态，超时自动选择后完成原付费工作，再走普通自然结束；不重复支付、CAST或提交玩家动作。原工作等待对手选择时暂停主动方钟；对手真实答复后再继续。当到期的原工作恰好移除最后一个在场来源、又没有永恒者开局安装时，本地政策在该实际工作后解除上限；以后同回合再次入场仍保留已扣时间。

`Rewind`保留完整宿主计时事件，不退还已经扣除的时间。终局不再启动新回合，正常结束阶段自己的选择也不借用已经关闭的旧计时区间。

## 保存、边界与信息

每个在场扣时收据保存有序的全部原来源：注册profile、完整物理分配事实、完整普通能力和原附件分配上界。恢复检查来源类型、注册声明、完整字段、分配边界、原能力身份和顺序、重复来源、实际owner区间、累计扣时前缀、上限及到期选择的随机重演。原永恒者安装和旧格式扣时事件继续按原契约验证；两类收据可以在同一实际区间顺序共存。

这些检查保证保存材料的结构与界限一致，不提供未签名历史的外部来源认证，也不宣称从后来局面重建了每个旧时点的全部战场。实际回放重新执行真实卡牌动作与宿主时间输入核对局面。

计时承诺使用原可选`turn_clock`字段；有活跃在场来源时，即使尚未扣时也必须保留该承诺。全部来源和历史时间都不存在的对局不增加字段。玩家只看到公开上限、已用、剩余、当前玩家和暂停状态；原区间token、分配事实、能力载荷、宿主私有事件和RNG不进入玩家观察或事件。

公共行为版本为core829、schema649，拒绝旧1～648存档；Effect/Frame载荷类型不增加。旧完整定义、候选身份/顺序/权重、标准1322根及114部件范围保持；实际验收与下一项只在[项目状态](project-status.md)和[机制台账](mechanism-backlog.md)维护。

动画、断线、服务端实际起算、到期工作改变来源的精确国服窗口仍是本地差异。资料存在及此单个真实来源可执行，不代表完整过去池或整轮标准目标已交付。
