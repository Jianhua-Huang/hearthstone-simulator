# 尼珊德拉分裂与甲虫重组

实际接入数量、执行结果和下一项只在[项目状态](project-status.md)及[机制清单](mechanism-backlog.md)维护。本页定义有限真实来源的内部契约，未认证国服精确时序。

完整原始记录固定于[data包](../data/cards/nythendra-beetles-v1.json)：EDR_818为7费7/7、嘲讽和亡语，死亡骑士2邪恶符文、亡灵/龙；EDR_818t为1费1/1甲虫及本人回合开始重组。两个完整原行、四份严格双语主面及未解数字标签均保留。代码只执行审阅后的规则，不解析卡文。

卡文没有直接解释分裂属性、较小形态及合并处理。[原始玩家攻击力报告](https://us.forums.blizzard.com/en/hearthstone/t/done-with-hs-until-ursol-renewing-flames-is-nerfed/146647/11)、[较小基础形态报告](https://us.forums.blizzard.com/en/hearthstone/t/carnivorous-cubicle-nythandra/144454)、[重组增益及新体报告](https://www.reddit.com/r/hearthstone/comments/1jpnrpp/)与[不触发授予亡语的报告](https://www.reddit.com/r/hearthstone/comments/1rhfhe0/)只作为暂定实现依据，不当作官方技术答复或CN37校准。矛盾的玩家属性叠加解释没有升级为通用规则。

## 亡语分裂

`SplitNythendra`绑定原DeathrattleCapture身份、实际执行时已有的`DeathrattleRecord.source_attack`及原SummonCause。数量按该非负攻击力，不读取尸体后来变化的属性或按最大生命猜测。自然死亡使用原死亡位置；效果触发沿原存活载体右侧位置。重复亡语各自使用自己的实际执行记录。

每个基础甲虫依次调用原`SummonByCard`，并从该接受操作返回的`FinishCardSummon`取得实际根ID，不搜索同名新随从。原召唤倍率、入场、反应、死亡检查及等待均由既有解释器执行。下一单位在上一完整入场后继续，反应释放的空位可继续使用；遇当前满场结束基础单位序列。私有接受记录保留原总量，不能将int32最大攻击力展开成巨大列表。容量停步、插入位置及倍率时序仍待M6。

## 本人开始与非死亡重组

普通触发器只在本人`turn_started`返回重组请求，绑定原事件和源甲虫的物理ID、controller、区域修订和入场顺序。实际执行时源仍须是该活跃、存活、非将死的原甲虫；离区重入、改面、转控和休眠不能追随。原窗口中已经捕获的触发不因后来的沉默自动撤销。

接受时按当前本人战场顺序捕获全部活跃、存活、非将死的EDR_818t；没有按原尼珊德拉分组。其他被沉默的甲虫仍是该物理族；休眠、对方和已改面载体不参与。原组先通过公共`RemoveFromGame`整批进入SETASIDE，不死亡、复生、执行亡语或产生残骸。其通知及反应沿公共调度继续，然后在原最左位置通过普通归因召唤生成新体。这里没有宣称“移除与入场在所有反应前原子完成”。后续排队的原甲虫触发因引用失效跳过。

重组数量是原甲虫个数N，不累加甲虫的当前攻击力或生命增益。新体遵循普通召唤疲劳、入场及召唤倍率。

## 有限原生形态

N=7使用原EDR_818。N=1至6由`nythendra.reformed.N`六个内部编译定义表达，基础费用/攻击/生命均为N，保留本体名称、种族、符文、嘲讽和亡语。它们明确不是额外XML或官方卡牌ID；数据包单独记录来源与配方。

较小形态不是7/7上的临时减益：基础复制、沉默、回手、再次出牌、死亡与复活都自然沿现有定义和生命周期保持N费N/N。当前复制仍保留普通附加材料。内部形态不可收藏且不新增随机池行；原提交构筑身份归本体，不允许用内部形态伪造合法构筑。实验战场一次超过七只活跃甲虫时明确拒绝，未编造第八种官方形态。

## 保存、回滚与信息

三种有限Effect通过原白名单帧编码器保存，未新增实体或GameState字段。分裂的原接受、每个实际子召唤ID及结束原因，重组的完整原组、原事件、非死亡移除及实际子召唤ID进入私有收据。恢复检查已接受尾部和完整原选择边界，拒绝裁剪、借用、重复或改写原数量/形态。原Rewind有效事件视图退役被放弃的尝试；终局保留实际执行前缀，不强迫剩余效果继续。

这些检查证明宿主材料的内部一致性，不认证未签名存档来源。玩家只取得既有公开区域及普通召唤/移除投影，私有尾部、SETASIDE列表和全知状态不进入玩家DTO。精确CN窗口、属性及形态政策仍独立列入M6，不能由内部测试替代。
