# 发现菜单的原卡材料

`OriginalDiscoveryOffer.materials` 按原菜单顺序保存每个 `OfferedCardMaterial`，身份同时绑定 option ID 与 card ID；同名物理牌不会合并。共享选择入口在实际抽样和原生产者绑定之后、手动/自动选择之前只读取一次材料。普通池、板上生成及临时生成保留原印刷配方，物理移动/复制/弃牌、从牌库授予黑暗之赐和地图首次发现则保存完整 `CapturedCardCopyMaterial`；实际原复制材料、死亡与弃牌记录分别保留自己的类型，不从后来尸体或同名牌反推。

物理材料复用既有来源分配事实和完整当前局部状态，包括原基础值、附件、能力、组件、耐久、临时寿命、抉择预选、准备及数值来源。原选项仍保存全部实际交付请求、黑暗之赐配对、费用与附魔声明；“只给选中结果”的奖励没有因此自动授予未选项。菜单上已经失效的引用明确记录 unavailable，不能改找后来同名实体；未知生产者显式失败。

等待时材料保存在私有 `ResolutionFrame.original_discovery_offer`，自动选择使用本次解释器的瞬时原接受对象。两种入口提交时都直接使用原对象，不在提交时重新捕获物理属性、不扫描诊断事件寻找游戏对象。恢复核对原发布、提交及完整帧；真实等待还从既有支付选择边界的原状态重新计算材料，以拒绝重写发布和帧后冒充原窗口。闭合材料允许原实体合法移动、变形、死亡和重入，但保留原身份与分配范围。真正回溯及异常回滚继续沿公共事务；检查证明内部一致性，不认证未签名存档的外部来源。

core463/schema380 引入一个不可变材料 payload、原 offer 的材料字段与私有等待帧字段；没有新增实体、玩家、GameState 字段或生产效果。旧1～379存档显式拒绝，观察93、命令12及replay1保持。完整材料及原配方继续禁止进入玩家投影。

`unselected_materials` 与 `unselected_options` 使用同一原结果，按菜单顺序排除实际选中项。此层只准备原材料，尚未执行其余选项；TLC_460/TLC_460t 仍未注册。后续须将该独立真实来源连接现有整卡执行器，覆盖法术、随从、武器、地标及英雄牌，并完成原武器驻留和耐久续接；不能伪造历史 play ID 或把材料保存当作源生之石完成。实际进度、验证与下一项仍只在原两份台账维护，M0正式池和M6国服校准独立开放。
