# M3：真实1费随从的现有机制配方

[固定材料](../data/cards/one-cost-basic-effects-v1.json)保留炫晶小熊、火炭变色龙、伪装的侦探、林地生态学者及纯净藤蔓的五条完整原行。[适配](../hs_sim/cards/one_cost_basic_cards.py)只组合已有机制，没有新内核、状态、存档字段或公共接口；本配方不注册部分END_013生成池。实际进度、验证和下一项仍只在[项目状态](project-status.md)与[机制台账](mechanism-backlog.md)维护。

## 真实扣款与原生监听

炫晶小熊分别监听普通费用的 `mana_spent` 和[直接消耗](m2-mana-consumption.md)的 `mana_consumed`。只响应本人正数实际扣款且原通知局面剩余法力为0；自身必须是仍存活、有效的战场来源。两条路径是不同扣款事实，不凭请求金额或回合计数推导。零费、零直接消耗及对方扣款不奖励；自身从手牌支付最后法力时还没有战场监听，不给新入场本体奖励。每个既有物理来源各用原 `BuffCapturedMinion` 加1/1，没有单卡可变计数器。

## 当前回合技能与公开目标

火炭变色龙以原公开 `hero_power_uses_this_turn` 作为目标资格：注册[玩家目标规则](m5-player-target-inputs.md)，谓词只读分离DTO中自己的次数，没有访问全知GameState。有效时沿原IF_AVAILABLE友方战场随从域选目标；无技能事实或无合格目标时可无目标打出，不能凭空指定目标。主体检查同一当前回合条件，对原随从引用依次执行+1/+2及突袭；若增益反应令原驻留离开，突袭不会绑定后来重入的实体。

技能次数的接受、付款、回合重置和选择/回滚仍由原内核管理。特殊自动激活、打断与精确判定窗是否与目标国服版本一致，仍须M6核对。

## 伪装落位与过载归属

伪装的侦探使用原 `disguised=True` 和独立 `on_play`，没有伪造战吼。`PlayRecord.player_id` 保留使用者及其付款，原 `board_player_id` 决定文本“该玩家”的2点过载接收者；不从后来当前控制者猜原落位。原区域、容量、入场、过载账目与下一真实回合锁定均复用公共机制。直接召唤不执行出牌主体，战吼重复不会把本牌的固有效果变成战吼。基础入口见[伪装契约](m3-disguised.md)，反制及晚场满等特殊窗口仍待国服校准。

## 指定亡语交付和正负属性

林地生态学者的亡语使用原 `AddToHand` 交付确切的TLC_813纯净藤蔓；完整不可收藏的1费神圣法术一起注册，不生成白板或改成随机其他法术。归属、沉默、手牌容量和隐藏知识沿原交付/死亡管线。

纯净藤蔓只选战场随从：友方以原受益引用增加2点生命；敌方以一条立即执行的原 `Buff(health=-2)` 削减属性。负数不能塞进只允许正数奖励的 `BuffCapturedMinion`，也不能以伤害代替：属性削减不消耗圣盾、不结算法强，但可能使随从死亡。本配方没有在负属性效果之前引入等待或额外反应窗口；未来真实需求若要跨窗口保存原目标，应另核对原驻留守卫，不能推广成任意延迟负奖励。

## 支持与证据边界

这些配方绑定固定37.0原行，身份网页与内部执行分别记录。官方身份页HTTP成功不证明完整动态文本、正式构筑/生成资格或精确国服时序。新增定义不改变旧定义和公共内核，原快照、回放、玩家投影及费用证明继续共享；内容包版本变更仍拒绝旧内容快照。全部候选和实际可达池未闭合前，不据这几张已接入卡宣称生成源或标准模式完整支持。
