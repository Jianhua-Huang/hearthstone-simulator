# 闪回的一费过去池与迦拉克隆的信徒

本地v6为TIME_711闪回安装独立的`constructed.past.one_cost_minions`来源域，完整保留先前取得的282个一费随从候选，不把教师21法术或究极边境34随从混入这份视图。旧两个来源域和清单仍保留；闪回的原支付、连击、两次随机召唤、进入前相对+1攻击及额外数量继续交原执行器。固定完整名单、303原行、四份双语主面、原集合政策和未确认项见[data/cards/one-cost-past-pool-v1.json](../data/cards/one-cost-past-pool-v1.json)。

## 候选与来源

原名单来自官网可见Wild集合减Standard集合及明确aliasSetIds，作为固定本地“过去”候选政策，不认证官方隐藏精选名单、重印权重或国服穷尽性。全部282原ID/顺序保留，每ID本地权重1，原独立生成身份去重、起始卡组限制和未知内容报错保持。缺少的DRG_303接原祈求；九张既有牌缺少的生成元数据在本地绑定时补入，先核完整旧定义摘要及与独立原行一致的CardMetadata，不改变这些牌的行为或按是否实现筛选名单。

GenerationScope的`current_class=None`只用于原本不依赖当前职业的查询，不代表未知职业可以通过当前职业查询。闪回的原查询是可收藏随从、恰好1费、class_mode=any；任何收受职业共用这个原视图。仍核真实TIME_711来源、原完整查询/策略、pool/target/mode和库存摘要；陌生来源或相近查询不能借用。其余两个德鲁伊scope保持职业限定。

[官方31.0说明](https://hearthstone.blizzard.com/en-us/news/24149389/31-0-patch-notes)要求克苏恩/迦拉克隆相关随机生成、发现和变形有相应起始组牌。既有starting_generation继续独立应用这条规则：无相关原始牌组时282库存中281条合格，DRG_303仍在库存；本人相关原始牌组实验中282条合格，对手原始牌组或后来获得相关牌不代替本人原始事实。独立Scenario中的相关起始牌实验不认证其为合法标准卡组。没有为了让名单容易执行而取消这项规则。

## 祈求入口与真实支持范围

DRG_303保留1费1/2、牧师、战吼和祈求关键词。主体只发原`Invoke(player_id, source_id)`，不手工生成牧师奖励、支付技能法力或写升级数。无主迦拉克隆时记录原无效尝试，成功计数不增加且不消费随机。正常召唤不会执行战吼；回手后实际打出才沿战吼入口祈求。

构筑注册实际五族/十五形态的InvokeProfile声明，家族/职业/技能关联由20条原始英雄及技能证据核对。英雄形态和五个未接收益没有注册白板或空回调，遇到这些未接内容仍明确错误。宿主已有完整显式profile时保留其声明；隔离实验用既有真实萨满代表验证本牌依主迦拉克隆家族路由、两次升级和正常奖励，不把另外四族合成探针当真实卡。

当前固定标准入口不含可起始的迦拉克隆组牌；完整一费域仍保留受限制候选，未因此扩展为完整狂野迦拉克隆接卡。真实英雄/技能/收益适配的缺口独立记录，不能据此宣称全部历史祈求卡已完成。2019主迦拉克隆说明与31.0生成规则分别留证，未将旧一律禁止随机生成的描述沿用到当前规则。
