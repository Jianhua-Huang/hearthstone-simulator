# 梦魇供能的原对手牌库副本与连击赐福

EDR_528梦魇供能是1费盗贼连击法术：从对手牌库发现一张随从的复制，连击时附带黑暗之赐。完整原行与严格双语主面固定在`data/cards/opponent-deck-gift-copy-v1.json`。卡牌直接消费原施法的`spell_conditions.combo`，等待期间不重新统计已出牌数。

## 原物理候选和复制材料

`DiscoverOpponentDeckCopy`复用`zones.sample_zone_choices`。该函数只是抽出已有`ChooseFromZone`的原候选/抽样段，原区域选择的顺序、RNG和空池行为保持：只查询对手完整物理牌库中的随从，复制发现先按卡面去重，抽中卡面再选一个原物理代表。同名牌不放大卡面的发现权重，不按职业或外部生成池过滤。

每个选项以已有`CapturedCardCopyMaterial`接受当前存储材料，再用`DeckCopyOffer`绑定可见预览和可选gift ID。两个分支都从这一原材料创建副本；不移动或修改对手原牌，也不在选择后寻找同名牌。后续原牌修改、移动或新同名对象不会改写已接受材料。该当前材料/接受时点和去重政策是明确的内部政策，精确国服行为待M6。

真实连击分支使用完整十种构筑赐福及原`sample_eligible_gifts`。资格来自当前接受的数值、关键词和战吼能力；选项分别配对不同可行赐福，不能通过删除不合格牌缩小对手牌库。普通分支不抽赐福。整份原有序选项、材料、配对和索引进入真正`CARD_DISCOVERY`及统一交付收据。

## 原子复制与交付

`CopyOpponentDeckOffer`将原材料交给既有`CopyCard`材料化路径。公共CopyCard请求形状保持；共享内部helper仅增加可选创建授予参数，限定为当前存储随从的捕获材料。复制原本地属性、费用、能力和对手复制来源后，叠加该次赐福与费用差，再发布第一次创建/获取通知。没有先入手再补赐福的可观察中间态。

短小利爪复用普通费用层，甜美梦境在发现者的牌库顶创建新的副本，普通入手和溢出烧牌沿原创建管线。源对手实体与其牌库相对顺序保持。原副本的实际分配、同步创建窗口、发现完成通知、失败回滚及玩家信息仍由`MaterializeDiscoveredCard`和`DiscoveryCompletion`负责。

原发现菜单材料另外认识这一明确生产者；已有“执行未选发现项”继续读取原物理复制材料和每一项固有赐福，不丢失当前修改，不把仅选中后的交付位置当作自动整卡使用位置。源生之石等已有消费者仍用原整卡执行器。

## 恢复和范围

完整待选菜单及材料、原来源/玩家、赐福资格与实际收件事实继续核对；原材料提供结构一致性，不认证未签名存档来源。新增两个效果和一个冻结选项payload，没有模型或保存布局新字段，也没有第二套复制、赐福、发现、费用或创建执行器。

精确国服材料继承、来源离开、重复卡权重、赐福/通知窗口、随机序列及可见复制细节仍待M6。此处为物理牌库选择，不认证正式合法或生成池。实际版本、验证、进度及下一项仅在[项目状态](project-status.md)与[机制台账](mechanism-backlog.md)维护。
