# 永恒者诺兹多姆与宿主回合计时

CS3_035的原始7费8/8龙牌通过原`before_deal`开局钩子安装15,000毫秒回合限制，完整原行和双语官网响应固定在[data包](../data/cards/nozdormu-turn-clock-v1.json)。这是有限内部契约；官网牌面证明双方套牌条件和15秒文字，不证明所有计时窗口或超时选择政策。

## 开局与生命周期

`TurnClockProfile`声明实际来源、原行为和15秒限制。`ActivateOriginalDeckClock`由原开局解释器执行；双方完整`original_deck`及原实体对应由既有构筑开局验证，不从当前牌库、手牌、名称或场上实体反推。当前政策只接受双方原提交牌表都有CS3_035，首位玩家的首个原始实体安装一次，重复副本和另一个玩家的同名钩子不重复安装。

安装后的规则不依赖随从当前的区域、存活、卡面或沉默；没有可被移除的玩家效果附件。`Scenario`没有真实构筑开局，因此不会仅凭双方牌库含此牌伪造已触发规则。普通7费出牌仍使用原付款、随从入场和8/8身体。

开局换牌不运行回合钟。原实际`turn_started`公布后才有可推进的钟；原`turn_ended`发生即停止旧钟，即使结束反应仍等待选择。每个真实本人区间使用唯一`owner_turn_id`，额外本人回合也获得新标记及完整15秒。一次输入的多余毫秒不会转扣下一回合。

## 宿主输入、选择与正常结束

可信宿主读取`hs_sim.engine.turn_clocks.current(game)`，将其`owner_turn_id`连同正整数毫秒提交给`Game.apply(AdvanceTurnTime(token, delta_ms))`。内核不读取墙钟，不睡眠；实时宿主负责计算实际经过时间。本批不改浏览器Demo或代替宿主调度时钟。

纯计时输入只记录时间，不增加玩家动作编号，不改变未完成付费选择的原证明。接受到剩余时间为零时，内核继续原解释器中已付费的工作。仍需主动方选择时，当前本地政策从原完整选项按合法基数随机选择，保存原选项、基数、答案和MT19937前后状态；每个后续主动方选择也独立续接，沿用原累计解释预算。没有伪造玩家提交、重复CAST、重新支付或从卡牌层另写发现结算。

若原工作要求对手决策，当前本地政策暂停主动方钟并拒绝继续扣时；过期工作产生对手决策时保留零剩余时间，待真实对手选择恢复原工作，再完成旧回合。对手决策不会被冒充主动方的随机选择。

原工作全部完成后，由新的正常结束动作身份运行原`EndTurnPhase`一次；结束反应、到期、死亡、下一位玩家和额外回合仍交既有执行器。终局不再结束或开始回合。正常结束阶段自己的选择不再属于已停止的旧钟。

## 保存、回放与信息

完整事件记录保留开局安装、每次宿主请求/实际扣除量/原区间和每次超时抽样。`Rewind`恢复卡牌尝试，完整事件仍追加保存，因此不会退还宿主已扣时间。纯计时输入不推进RNG，只有实际超时抽样推进它。

计时事实通过可选`turn_clock`承诺进入全知快照和状态哈希；无计时对局不增加该字段。恢复重核原提交牌表、唯一开局钩子、完整扣时前缀、真实区间及停止窗口、原待选请求、随机重演和紧接的真实选择事件，并比较完整承诺。省略承诺或重算哈希后裁改事实也不能绕过这些验证。该验证不提供未签名存档的来源认证。

宿主历史采用版本1的独立`advance_turn_time`记录，普通玩家动作编解码器及座位绑定接口拒绝这一类型；回放重新执行宿主时间输入和玩家动作，不把呈现事件当命令。普通玩家命令版本12和回放外壳schema1保持。

玩家观察只提供当前玩家、上限、已用、剩余及暂停状态，不包含内部区间标记、完整原牌表、宿主私有事件、超时完整候选或RNG。已有公开选择结果仍由原信息过滤器处理。初次引入为观察版本114、内核603、快照497；当前执行版本以原两份台账为准，旧存档需要原引擎。

仅持纯State的合法性投影可由原开局牌表证明不存在计时来源，此时不需要伪造事件宿主。存在符合条件的原来源时，投影必须携带真实安装/推进事件；缺失则显式拒绝，不冒充无时钟对局。真实Game宿主继续沿原事件记录核验。

## 证据边界

本地政策名`original-decks-turn-time-v1`。完整来源、实际验证和下一项仅在[项目状态](project-status.md)及[机制台账](mechanism-backlog.md)登记。

以下未认证当前国服一致性：15秒的服务端起算/动画/断线窗口、对手决策暂停、超时随机基数与分布、重复选择和回溯的精确处理，以及开局替换/复制牌库时原提交牌表与后来组成的适用关系。本批不以历史动画Bug或其它模式的观察替代构筑国服证据，也不据内部计时验证认证M0正式卡池、M6或整轮标准完整支持。
