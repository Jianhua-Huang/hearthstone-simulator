# 自动施法优先原随从

本文描述紫色珍鳃鱼人和圣窟生物确实需要的最小公共能力。实际进度、验证与下一项仅在[项目状态](project-status.md)和[机制台账](mechanism-backlog.md)登记；不是新的组合机制矩阵。

## 原引用与目标窗口

`PreferredMinionTarget(BoardPresenceReference(...))`保存发起随从的原连续战场驻留。请求必须将同一物理随从声明为`source_id`，拒绝未知实体、未分配驻留和其他发起者冒充。它只扩展共享自动法术目标策略，其他仅允许原枚举的非施法来源不因此开放。

`CastSpell`、`CastStoredSpell`和`RecastSpell`在原自动CAST窗口继续完成条件、抉择分支和完整合法目标查询，然后应用偏好：

- 原随从仍处于原驻留，且属于该法术当前完整合法域时，确定选择它；这次目标确定不使用RNG。
- 原引用过期、离场或不是合法目标时，在完整合法域按既有规则随机选择。普通随机选择保留原单候选也取一次RNG的政策。
- 无目标正文保持无目标；必需目标的法术在空域记录原`no_target`失败。空目标域不取RNG。

同一驻留内变形或转控不自动改绑对象，也不豁免当前合法性。离场重入产生新驻留，不取得原偏好；新实体仍可能作为普通随机候选被选中。没有使用手动目标预检代替CAST窗口查询，也不在选择恢复后重新抽目标。

`AutomaticTargetPartition`增加`preferred_id`，保存完整合法域、敌方域、实际选择域及原偏好引用。`AutomaticTargetSelection`保存该窗口的RNG前后状态；有合法偏好时证明RNG未推进，回退时局部重演原随机。原`AutomaticTargetProof`和Finish在原状态重算完整域、驻留和条件，仍验证实际施法与发起者。上述引用、候选、内部状态和证明不进入玩家投影，也不提供未签名存档的来源认证。

## 物理牌库法术

`CastRandomDeckSpell(player_id,max_cost,source_id,target_preference=None)`只筛当前本方物理牌库中的法术，费用采用`max(0,local_cost(entity)[0])`。实际区域附魔降费/升费影响资格，手牌固有报价或只对手牌生效的玩家费用光环不决定牌库资格。每个物理实体占一个候选；同名两张保留两个权重，完整空池不取RNG。

选中后仅返回原`CastStoredSpell`，绑定原实体与区域版本。实际移区、施法历史、目标、主体、完成和反应仍由原自动施法执行器负责；不生成新副本、不付款、不造手牌出牌或抽牌事实，也不触发抽牌替换。未知定义仍明确失败，不按实现状态删候选。该入口没有建立第二套施法或牌库账本。

## 历史重施与真实配方

`RecastFromHistory`仅增加可选`target_preference`，完整原spec随现有批次保存并转交`RecastSpell`。已有友方/回合/学派/结果查询、按实际施法次数区分、冻结候选与边界、采样、剩余计划和请求一致性继续使用原历史执行器。

[完整固定配方](../data/cards/self-target-spell-effects-v1.json)只接两张根卡：

| 卡牌 | 表达 |
| --- | --- |
| TLC_438 紫色珍鳃鱼人 | 原战吼返回费用上限2的物理牌库施法，偏好原使用随从；重复战吼逐次查询剩余牌库 |
| TLC_430 圣窟生物 | 本方结束主体请求一次本回合成功的友方神圣施法历史重施，随机按原实际次数取候选，偏好原结束来源 |

普通随从效果召唤不执行战吼。对手期间不启动圣窟生物的普通本人结束主体；转控后的主体按原当前控制者查询。额外结束主体仍沿原重复执行窗重新接受历史，可能包含此前本回合真正完成的重施。

卡牌适配不捕获已经离场的来源，也不将新驻留当成原来源。普通使用来源通过原首条实际入场事实约束；结束来源按原接受顺序与单调分配驻留约束。此前来源已离场的后续实际主体使用普通随机回退，不因此取消施法或制造原随从。

## 保存与边界

增加一个有限效果、一个偏好载荷、目标分区的一个字段以及历史批次spec的一个可选字段；没有GameState、玩家、实体或卡牌定义新字段。公共core360/schema285严格拒旧1～284，当前卡牌定义及默认代表注册表指纹不因这组公共请求增加字段而改变。观察86、命令12、外层replay1保持。

卡面依据为固定37.0完整源及官网身份/正文。精确牌库费用资格、原驻留继承、自动选择保护、偏好是否消耗RNG、历史次数权重与反应窗仍是明确的内部政策，待国服M6校准；不能据官网文字与内部测试宣布这些边界已官方验证。正式标准根池、构筑热修及所有实际可达内容继续分别验收。
