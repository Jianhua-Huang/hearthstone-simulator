# 原手牌法术的回手与替换

本批接入冰霜陷阱 `AV_226` 与古神在上 `DMF_236`。[固定数据包](../data/cards/original-spell-secret-effects-v1.json)包含两张完整主卡、一条霜冻附魔只读记录及四份已校验的完整中英文官网主面。不增加标准组牌根，不因实现程度修改[72 张过去奥秘参考名单](../data/cards/past-secrets-local-reference-v1.json)，也不据两张效果开放完整过去来源或 `WON_040`。

## 原提交窗口

两张牌沿原奥秘安装、付款、隐藏、去重、对手回合和揭示流程；只接受 `card_committed` 对应的活跃手牌法术窗口。事件的 `source_id`、玩家、`play_id` 和窗口必须一致；已被反制、并非手牌法术或已完成的提交不再消费另一个奥秘。自动施法仍按已有管线执行，不伪造新的手动出牌窗口。

新增有限效果 `CounterReturnSpell` 和 `CounterReplaceSpell`，都保存原窗口 ID、原出牌 ID、完整原法术和已揭示来源的 `SourceAllocationFact`。已有 `HandPlayCostReceipt.zone_epoch` 加一就是原提交后的墓地驻留；用它校验原实体，不从后来手牌或同名牌推断。这样也能处理回手后在手牌中变过卡面的实体，而不错误地使用最早入手记录的区域代数。

待执行效果恢复时重新校验实际窗口、不可变出牌、来源分配、原卡面和原驻留。合法等待中的新实体分配不改变原凭据；原实体离开捕获驻留后跳过，不找替代牌。反制仍委托原 `mark_counter` / `announce_counter`，原 CAST 尝试、出牌、支付和关闭证明由原管线继续完成。

## 冰霜陷阱

反制原尝试，不退款；把同一原实体交回其物理拥有者，区域控制者随实际交付更新。它使用从原付款收据锁定的墓地驻留，不新建同名卡、不制造一次死亡。拥有者与施法者不同的行为是本地对“拥有者”的明确解释，仍待国服校准。

公共 `hand_returns.deliver` 负责已捕获墓地牌的容量、移动、回手重置、费用和进手发布；原战术撤离/诈死也复用这段交付，其目标校验、原死亡、默认接收控制者与驻留失效政策保持。冰霜陷阱仅显式指定物理拥有者和 `cost_delta=1`。

普通手牌费用和临时状态先按既有重置流程清除，再安装加一，最后发布进手监听，因此监听可见最终价格。重复触发不会把上次回手附加费继续叠入新的印刷基础。原本仍有效的玩家费用来源继续按现有报价生效。原实体上的原生法术数值、光环额外时长来源和刻印武器材料经既有校验/安装/保留接口恢复；这些参数属于本地原生实例材料，不作为普通手牌费用抹掉。

揭示后接收手牌才满，沿已存在的 `graveyard_delivery_overflow` 明确交付失败并使原驻留失效，不延期补发、换同名牌或增加死亡/残骸。所有费用与实例值在首次进手通知前完成。

## 古神在上

原出牌的不可变 `PlayRecord.cost` 决定查询费用，包含实际提交时的折扣；不用印刷基础费用或后来剩余法力替代。只反制原尝试，再委托已有 `CastFromPool` 为原施法者施放一个替代法术；不额外支付候选的常规施法费用，候选自身真实支付效果仍正常执行。

来源是明确绑定到本地固定标准候选快照的完整 `constructed.cards`，查询为可收藏法术、印刷费用等于原提交费用，覆盖所有职业。现有成员、角色、别名去重、权重和排除保持；不按可执行覆盖或当前目标是否存在裁候选。没有明确 `GenerationContext` 的注册表直接报错并回滚，不猜默认来源、不退到代表池。

替代法术使用既有自动随机目标和随机选择政策，不保留原目标。没有合法目标时保留普通失败尝试，不重抽候选。原法术若仍是该完整域的合法成员，仍可被选中；不臆造“必须另一张”排除。空同费用域沿现有空池政策结束，原反制不撤销；这项以及同名资格的精确正式行为仍是记录在案的本地边界。

原替代 CAST 的反应、额外施法、伤害预算、选择、终局、失败和回放由现有解释器负责，不在卡牌层复制施法器。替代法术不生成第二次手牌提交，也不会让保留的另一奥秘错误地处理一次新的手动窗口。

## 冻结死亡记录与后来的卡面

实际验证原实体回手时发现：原随从死亡并回手后，可以通过已有存储变形成为法术；历史校验却把它当前的卡牌类型当作死亡时类型。现改为：原记录仍按冻结 `card_id` 与死亡区域核对类型；当前类型不同，只允许完整 `copy_source` 仍证明原类型、且实体已离开原死亡墓地驻留的记录。没有冻结事实或仍在原死亡驻留的类型不符继续拒绝。

此修改保持死亡、残骸和旧亡语材料，不把后来卡面写回原死亡；没有新增历史字段或放宽普通区域引用。保存恢复后删除原冻结事实仍会被拒绝。非随从记录没有因为本批推断出新的变形支持。

## 公开依据与本地差异

[2022 年玩家本人报告](https://us.forums.blizzard.com/en/hearthstone/t/another-bad-interaction/93234)描述冰霜陷阱后法力仍已消耗；[2021 年重复触发报告](https://us.forums.blizzard.com/en/hearthstone/t/three-consistency-issues/76706)描述同一法术再次回手后仍只比基础费用多一。[2021 年费用观察](https://us.forums.blizzard.com/en/hearthstone/t/oh-my-yogg-and-the-cost-of-cards/59003)描述折至一费的原法术被替换为一费法术；[2021 年目标观察](https://us.forums.blizzard.com/en/hearthstone/t/if-i-get-oh-my-yogged-then/71053)描述目标被重新随机。[2024 年抽到时施法讨论](https://us.forums.blizzard.com/en/hearthstone/t/ice-trap-dont-trigger/135445)支持区分手牌窗口与自动施法。

这些是有日期的社区观察；回复中的解释不等于官方裁定，也不认证当前国服热修。原卡文依据保存的完整官网响应，精确拥有者解释、反应先后、空池/同名边界和国服版本继续待验证，不等待实测、不裁域。

被反制的回溯法术没有有效载荷结果，继续沿 [R-091 既有本地契约](m5-rewind.md)直接提交，不制造一次结果选择；实际已执行载荷的原死亡回手回溯仍由旧公共路径验收。本批不把这项旧未校准契约升级为正式规则认证。
