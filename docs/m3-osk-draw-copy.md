# 欧斯克的原随从抽取与当前复制

本文描述两个真实战吼形态的有限表达，执行进展仍只在[项目状态](project-status.md)和[机制台账](mechanism-backlog.md)维护。根卡的手牌换面、实际分支资格与权重另行处理，不能从形态注册推定整卡已支持。

`TLC_452t18`使用两个明确MINION匹配槽的`DrawPhysicalGroup`，继续委托原`draw_one`、当前物理牌库候选和随机。空匹配跳过，不产生普通疲劳；烧掉的对象不获得手牌奖励。原两次抽牌及反应完成后，`set_stats_cost_all`只处理本组仍匹配原HAND驻留的到手实体。额外抽牌、同名其他牌、离手后重新抽回的实体不替代原到达。

`SetStoredMinionStats`只接受原手牌随从引用。普通有序`Enchantment`安装攻击/生命设值，普通费用附件安装设定费用，三项都在首次通知前提交；不把印刷基础身材改成2/2，也不通过临时计算增益来模拟绝对设值。后续普通属性和费用规则仍可改变结果。未知原定义明确报错，陈旧驻留按原引用管线跳过。`stored_card_stats_set`属于持有者私有事件。

`TLC_452t19`的玩家目标规则只读取玩家DTO中的当前Titan关键词，仍使用普通战吼目标保护、双方BOARD/MINION和无合法目标可空过的规则。并非施放指向法术，Elusive不因此阻止目标。沉默/用尽技能后是否应按印刷Titan排除仍须当前国服证据，不把本地当前关键词规则当已校准结论。

复制返回有原`SummonCause`的`CopyMinion`及纯数值`CreatedMinionGrant(2,2)`。原`CopyEntryMaterial`冻结当前本地身材、附魔、能力与组成；普通复制交付先安装原材料，再在首次入场通知前安装相对+2/+2，沿原召唤数量、容量、入场、死亡和恢复管线继续。不能用入场后回调补增益，也不重放被复制随从的战吼。当前复制既有受伤材料保持，本地+2生命同时提高上限与当前生命；精确当前国服复制政策待校准。

有归因的当前BOARD复制复用已有组成槽保存制造随从/星舰等原组成，仍检查实际卡面与有序组件匹配。不因目标特殊而把合法非Titan目标从菜单中删去。新BOARD入场授予仅接受有原来源的非负纯属性增长，不泛化关键词、黑暗之赐或额外行为；原stored_copy授予范围保持。

新增请求沿原mechanics和FrameCodec保存，复制沿原召唤历史保存原材料及来源。模型文件和GameState账户不变。原资料的三完整记录与六份完整双语官网主面保存在`data/cards/titanographer-draw-copy-v1.json`，与已核整族资料复用；这只证明卡面数据，不证明实际技能池、抽样权重、手牌时钟或正式生成池。

整组后设值窗口、当前Titan判断、受伤复制、数量与容量等当前具体国服边界保持M6开放；M0正式补丁/热修与合法生成池也独立开放。内部专项不能替代这些证据。
