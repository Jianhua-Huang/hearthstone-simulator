# 原召唤组的流放回合奖励

盛宴之角以三个普通`SummonByCard`请求召唤已确认的贪婪的迅猛龙，然后运行一个有限`GrantOutcastSummonedGroup`续行。`OutcastSummonProfile(card_id, token_id, count)`记录真实法术、物理衍生物和完整请求数，进入注册表只读视图、验证和指纹。仅普通原生流放法术可以声明此配方，不提供表达式或任意关键词组合。

续行保存原`RuleContext`，沿原活跃施法和接受前缀校验。既有`original_summon_groups.recipients`连接全部完成/失败请求与成功入场，包含原数量额外交付，排除已有、嵌套和后来同名召唤。随后使用原`successful_summons.original_recipient`驻留守卫；同驻留转控/变形跟随，死亡、离开或相同ID重新入场不取得旧奖励。

活跃原施法必须保留完整待执行请求与唯一组尾，已接受请求加剩余请求数须等于配方且保持次序。完成时发布一个宿主私有组证明，连接完整成功入场、原激活条件及真实关键词授予事件；空组和非流放也发布完成事实。恢复核对真实施法、原请求、完整成员、授予和收尾，拒绝删去请求/组尾、重复或改序，以及删掉已完成证明。证明沿既有有效时间线事件过滤，回溯废弃尝试不获完成信用；它不充当未签名外部存档的来源认证，也不进入玩家事件投影。

只有原接受条件激活流放时，才在原三次召唤及普通反应完成后，执行一个原子组奖励。每个仍有效的原成员交给普通`GrantKeyword(IMMUNE_WHILE_ATTACKING, expires_turn=currentTurn)`；普通战斗和全局本回合结束清理负责实际免疫与退役。没有预装到入场材料、改写衍生物本体、寻找后来同名物或新增计时器。首次授予反应执行前，原子组内全部有效成员已安装；确切国服召唤/数量/反应、组原子性、转控变形及期限窗口仍待M6，不能用卡面文字代替服务器证据。

根为4费恶魔猎手流放法术；衍生物是2费2/1恶魔猎手野兽、原生突袭，没有免疫。双语根官网`childIds`明确118502；DINO_136e为完整附魔证据，不建立物理定义或生成池行。完整记录和四份主卡面见[数据](../data/cards/native-outcast-summon-v1.json)。普通召唤衍生物不获得这项奖励，自动施法不伪造流放激活，普通共享施法重复各自保留原组。
