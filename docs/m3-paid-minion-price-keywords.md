# 原付款附带的随从关键词与下一实际回合加费

实际进度、验证、差异和下一项仅在[项目状态](project-status.md)和[机制台账](mechanism-backlog.md)登记。本页说明三张真实费用卡的有限表达，不扩展任意“机制＋机制”声明。

## 付款与入场使用同一份接受材料

温泉踏浪鱼人需要“下一鱼人减1费；延系成立再获得圣盾”。价格筛选沿原当前种族规则，而不是单独建立一个按印刷种族触发的奖励监听。`AddCostModifier`及持久`CostModifier`只增加`minion_keyword`，目前仅允许有明确来源、一次用途、随从种族减费附带`DIVINE_SHIELD`；其余旧声明保持显式`None`。

原报价、付款和`CostUseReceipt`完整保存该修正。预览和合法动作查询不消费，0费的实际匹配使用仍消费；来源死亡、沉默、转控或普通回合结束不撤销没有期限的价格。全种族及手牌中的真实种族附魔继续沿公共匹配层，后来改变卡面不重算已经接受的付款资格。

`costs.install_paid_minion_keywords`只读取原`PlayRecord.submitted_cost.quote`的完整有序贡献，核对同一玩家、物理来源、原卡面、回合、动作、金额、支付类型及修正/消费ID的实际付款使用收据。只有其中真实消费的关键词来源能交付，不从当前手牌、当前种族、来源名字或未界定的全局历史推断“下一张”。

在普通成功入场前安装原关键词附件；磁力路径在原普通合并前安装到原被使用载体，后续转移仍由既有磁力执行器负责。反制或支付后入场失败没有成功入场交付，但已消费的价格不退款；开始时非法满场出牌则沿原事务保留价格。关键词不通过`live_character`授予，避免休眠载体丢失应有的原入场材料。附件在首次入场通知前已经存在，休眠时随原能力保存，正常唤醒后生效。

使用既有附件分配器、普通关键词和生命周期，没有第二份未来奖励计数、玩家账本、事件或执行器。多个实际减费可以累加，各自关键词附件仍按原圣盾消费规则处理，不创造多层圣盾次数。当前复制继承材料，基础复制/沉默/离手重置继续交原公共契约。

该表达绑定原实际付费手牌随从入口，沿既有普通费用修正的消费范围。自动施法、普通召唤和没有该原付款接受的整牌执行不伪造价格使用。其他真实整牌来源若要求消费价格或交付奖励，须在接入该来源时核对其实际接受、用途和入场关系，本页不认证这些尚未核实的来源，也不因此宣布整个未来关键词来源族完成。

## 下一次真实本人开始与本回合到期

慢动作和焦油狂潮的未来加费不使用`turn+1`。卡牌只给对手安装既有普通、无倒计时的`PlayerEffectSpec`实例，监听其下一次`turn_started`；回调确认实际事件玩家，先移除原实例，再添加当前真实回合到期的普通`AddCostModifier`。来源的生命周期不改变已安装的受益玩家。

这类实例不是奥秘、印记或有限计时目标，不占用这些区域容量。对手额外真实开始可以激活，施放者的额外回合不激活；被跳过且没有实际开始的槽位不激活。实际加费的到期仍由原自然结束清理负责，普通手牌出牌、英雄技能、交易和其他费用作用域保持原区分。精确国服跳过槽、开始反应和到期窗口仍待校准。
