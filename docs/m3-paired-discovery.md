# 发现随从的赐福绑定

当前十种配方、有限特殊主体与版本见[黑暗之赐公共接口](m3-dark-gifts.md)。下方历史实验保留引入时范围，实际结果以最新台账为准。

黑暗之赐要求发现选项中的随从分别绑定不同赐福；短小利爪仅能赋予减去2攻击力后仍至少为1的随从。[国服资料片说明](https://hs.blizzard.cn/news/24179067/)。这是同一个真实关键词的候选、选择和交付规则。实际验证、执行位置与下一项仅由[项目状态](project-status.md)和[机制清单](mechanism-backlog.md)维护。

## 声明与候选

原[DiscoverFromPool](../hs_sim/engine/pools.py)的末尾可选`gift_pool`接受不可变`DiscoveryGiftPool`。它声明自己的ID、版本、`generation_target`、模式、完整性标记和完整配方元组，须与对局的生成上下文一致。正式模式要求显式完整声明；该声明本身不构成M0正式池或国服认证。

`DiscoveryMinionGift`保存赐福ID、显示名称、[CreatedMinionGrant](m3-created-minion-grants.md)、费用减值、最低印刷攻击力和有限目的地（默认hand或deck_top，见[直接牌库创建契约](m3-deck-creation-grants.md)）。配方表达普通属性/关键词及两种有依据的有限特殊授予；不接受未知主体、任意战吼/亡语或可执行回调。黑暗之赐描述和附魔证据行不因此注册为可使用法术。

当前外层入口接受一次、三个选项、入手形状、逐次交付的普通发现及火化所需的普通减费；所选赐福可声明有限hand/deck_top目的地。其他费用、多次发现、普通牌库/场上交付等形状仍明确拒绝，待真实来源需要时核对。原发现卡池、印刷资格、职业、来源与别名去重继续由原候选查询负责；所有合格卡牌都须有可执行定义，不能因未实现而从随机池删去。赐福配方同样先完整验证。

随从沿原加权无放回采样。随后从满足每个随从资格的不同赐福有序绑定中等概率取一个；该随机分布是本地政策，官方说明只证明不同绑定，没有证明服务端抽样算法。没有可行绑定时明确报错并由原事务回滚，不重抽随从或裁剪卡池。空随从池不请求选择、不消耗两种采样的随机数。

## 冻结选择与交付

原[DiscoveryPick / ResolvePoolDiscovery](../hs_sim/engine/discovery.py)保存所选赐福和完整有序绑定。每个选项包含相同的整组绑定，并保留自己的随从/赐福、来源和原职业依据；不能把另一项的赐福接到所选随从。原`POOL_DISCOVERY`用途保留，普通`EFFECT`选择不能代替本流程。

选项名称展示随从与赐福。预览是冻结的印刷本体加该配方的局部费用、属性和关键词，不声明为最终支付报价或含后续局面变化的预览。恢复时对全部选项核对卡池、资格、配方、名称、预览和整组绑定。选择解释器注入实际`ChoiceResult`；交付须匹配完整原选项与实际所选ID，没有真实结果的分支不能直接交付。

内核私有`pool_discovery_picked`事件保存完整编码收据，包括原请求、整组绑定、所选材料和实际结果。它不捕获卡牌触发、不进入玩家事件日志。所选结果按配方目的地沿原`AddToHand`或`AddToDeck(position=top)`创建一次，使用原来源、费用及原子授予；不额外支付或再次抽取赐福。手牌交付沿原满手烧毁，牌库交付直接创建且不经过手牌；异常回滚与挂起工作队列共用。

`CreatedMinionGrant.identity`是可选创建授予身份。配方交付时填写赐福ID，原附魔层保存`created_minion_grant:<ID>`及原来源；只有关键词的赐福也获得零数值身份附魔。它没有新实体账户或执行器，当前复制保留并重分附件ID、基础复制清除、沉默和回手复用原生命周期，满血保附魔复生复用[原返回规则](m2-full-health-reborn.md)。该身份不是酒馆`HAS_DARK_GIFT`标签或完整构筑消费者适配的证明。

## 范围与可复现性

[完整原行pin](../data/support/paired-discovery-basics.json)保留疯狂生物、必要的三个真实3费随从、两个资格外对照和全部27条EDR_100原行，其中包含12个本地赐福描述。引入时的受限实验明确只使用四个可执行配方：+3攻击力/吸血、减费/-2攻击力、+4生命值/嘲讽、满血保附魔复生；其余八个主体保留并明确拒绝，不能把四配方实验池冒充正式池或完整黑暗之赐。

疯狂生物的实验适配沿真实2费1/1与战吼，查询印刷3费、当前职业或中立的可收藏随从。实验随从库存有明确受限声明，不能称为完整标准/狂野发现池；狡诈拷问者的传说范围不借用该小池。其他来源、全部真实赐福主体、当前正式结果池与精确国服资格/抽样/预览/时序仍需要核实。

全部声明和待选分支使用原帧编码器；存档、独立注册表恢复、克隆及回放复用同一请求和随机状态。玩家只获得自己的选项名称/预览和原有可见牌面，不得到内部绑定、收据、附件ID、全知快照或对方手牌。目的地扩展见[直接牌库创建契约](m3-deck-creation-grants.md)。引入时为`prototype-v258` / `core-effects-v252` / schema228，拒绝旧1～227；观察76、命令12、replay1保持。
