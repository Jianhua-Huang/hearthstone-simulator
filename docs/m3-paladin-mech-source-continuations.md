# 恶火存放切面与海床救生员探底续接

[固定原生资料](../data/cards/paladin-mech-source-continuations-v1.json)保留SC_412恶火、TSC_083海床救生员及其四份完整双语主面，固定旧SC_412t恶蝠完整定义/生成元数据，TSC_083e只作原附魔证据。两根仍属于[完整27项参考](../data/cards/past-paladin-mech-local-reference-v1.json)，不按实现程度删成员。本模块不安装正式过去来源scope，不改变普通池或标准合法根。

## 发射后的存放形态

StoredLaunchFormProfile声明唯一原面和终态。注册表验证两者都是可打出的普通随从、原费用/印刷身材/职业/种族相同，不允许星舰本体、循环或推测变形链。非空声明参与注册表指纹；空声明不改变旧默认指纹。它没有给Entity、快照或玩家视图加字段。

同步器读取该当前控制者的实际StarshipLaunchRecord，在原发射以及完整入手、入库、抽牌、回手、存放变形等通知边界处理HAND/DECK中的原面。先完成全部符合项，再逐项发已有私有stored_card_transformed通知，首个观察者不会看到只切了一部分的库存。复用upgrade_face保留普通已有数值/设值/费用附件，只替换印刷面并退役旧驻留引用；已有终态不因更换控制者而反向变回原面。标准沉默和回手继续走原生命周期。

恶火在未发射时提供其它随从+1攻击光环；切面复用原恶蝠的+2攻击/突袭光环。[官方卡面](https://hearthstone.blizzard.com/en-gb/cards/113855/)只写发射条件；[玩家直接报告](https://www.reddit.com/r/hearthstone/comments/1imzuw0/)指出手牌/牌库切面，已在战场上的原面保持。因而这里不把BOARD中的恶火改成恶蝠，回手进入存放区后再满足条件。该报告不是当前国服官方校准；跨通知、特殊复制、沉默等精确边缘保留为本地政策。

Game校验不允许当前符合原发射条件的未沉默存放原面遗留；它不要求从别处获得的终态必须有本人的发射历史。事务负责发射付款、历史、全部面替换、RNG和信息状态的整体回滚。保存恢复及回放复用实际声明/原历史，不保存另一个可失真的“已发射”布尔账户。

## 探底的原属性窗口

DredgeWithSourceStats只接受原已开始、无失败的随从战吼RuleContext。它保留该正文接受窗口的实际攻击和非负剩余生命；包括当前普通附魔/光环，生命不是最大生命。选择前后的源增益、离场和死亡不会重读成另一组数值。这一冻结窗口及非负政策明确作为本地待CN校准边缘。

原Dredge规格/原SelectDredgedCard字段保持。公共选项构造和重排仍共用同一底部三张、原抽样、预览、私有选择及zone_epoch退役逻辑；只有真实属性请求使用新的SelectDredgedCardWithSourceStats分支。整组必须同一种分支、相同原请求，不能混入另一战吼窗口或改主人/来源/查询。新分支复用普通重排后，为当时选中的随从捕获新牌库驻留并排入BuffStoredCard；选中法术不授予。

card_dredged反应在原顺序执行，已捕获奖励不扫描后来牌库顶。如果原牌被移走或同ID离场再进入，旧驻留奖励跳过，不能借给新的驻留；重新触发战吼则按新的实际源窗口另捕获。空库无伪造选择、入手、抽牌或RNG。已有普通Dredge及其回调路径保持。

原RuleContext属于内部冻结材料，玩家选项不带完整状态、效果、RNG或原施法/战吼账本。内部类型、原请求/驻留和整组一致性校验不提供未签名存档的外部来源认证；不能从“重算哈希仍能载入”推导其来自真实客户端。

core762标记两种新探底效果及存放切面。原Dredge线格式、游戏状态/命令/观察字段不变，schema600/观察119/命令13/replay1保持；新增Effect类型与非空注册表声明独立进入恢复身份。

调查还发现[星际阵营生成条件的社区汇总](https://hearthstone.wiki.gg/wiki/Hellion)及[官方论坛玩家讨论](https://us.forums.blizzard.com/en/hearthstone/t/herald-card-an-colossi-are-not-discoverable/158759)。现有starting_generation明确支持克苏恩/迦拉克隆条件，尚未据这些报告冒造完整阵营隐藏资格表。27原名单保持，完整来源接入必须独立处理/记录这项资格政策，不能为了绕开而删除SC_401/405/412，亦不能用原生存在认证正式生成。
