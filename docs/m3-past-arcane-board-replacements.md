# 原手牌弃置与原战场替换

[完整源包](../data/cards/past-arcane-board-replacements-v1.json)包含星界沟通、群体变形、咒术师的召唤，以及法力过剩、该群体变形专属绵羊、双生法术副本的六条完整原行和十二份双语官网主面。群体变形关联的真实`AV_218t`不能替换为同名`CS2_tk1`。法力过剩隐藏的零费有显式规范，不改原数据的空值；这批不增加标准合法根。

`TransformMinionsToCard`只表达一组完整`MinionReference`到一个已注册随从面的转换。源、唯一物理目标、旧驻留与预算先核；执行开始接受全部仍存活的原目标，统一使用原`transform_minion`写入面、重置材料及刷新光环，全部完成后再发布普通变形通知和入场后续。先处理目标移除生命光环时，已接受的后续原目标仍会得到其新面，不会被中间死亡检查提前拿走。普通单体路径保持原发布顺序；变形替换、冻结初始化、原复制材料和普通入场继续共用，卡牌层不复制写入器。

群体变形按本次真实施法正文捕获双方当前存活、非休眠随从；地标和休眠体保持，潜行、扰魔不把群体效果变成单体目标检查。两板原顺序、实体、控制权和既有使用次数沿原转换保留；原亡语不因变形触发。动作失败交原事务整体回滚，待选恢复保存正常队列，没有专用影子状态。

星界沟通组合原物理`DiscardCard`和普通资源效果。正文一次捕获当前原手牌，逐张沿已有弃牌/反应管线执行；后来获得的牌不被临时加入原组，已离开原驻留的旧牌不重绑定。弃手后检查当前永久或可用法力是否已达实际水晶上限：达上限给真实法力过剩，否则获得十个装满水晶，并只按超出新增容量的数量刷新已花费法力。这个弃手优先与法力过剩分支参考[独立公开实现](https://raw.githubusercontent.com/jleclanche/fireplace/master/fireplace/cards/tgt/druid.py)，不冒充本次国服规则校准。可用临时法力条件、过载/临时账户替换和精确通知窗仍是显式本地政策与待验证边界。法力过剩复用普通抽一张，保持疲劳、满手和真实抽牌记录。

咒术师的召唤捕获原目标控制方及当前战场局部费用，不用历史手动付款数值，也不把大于十的费用截成十。原消灭/死亡和亡语之后，两次普通`SummonFromPool`分别从完整当前宿主的同费随从域抽选、接受自己的当前数量和容量；第一根接受后，后来的数量变化只影响第二根。原目标方作为接收方是本地明确政策，不能把独立开源示例的施法者接收写法当作权威依据。精确失败、位置与死亡反应窗口留待国服验证，不能按实现覆盖裁池。

原版使用既有`HandDerivativeSpec(TWINSPELL)`，副本是完整真实`DAL_177ts`，保留同正文而没有双生声明。自动施法、反制、重复、满手和失败恢复沿既有衍生物协议执行，不在正文手动发一张替代品。

新增一个有限效果类型，内容版本和内核版本随实际收据记录；`schema603`拒绝旧1～602。没有新增游戏状态账本、payload类型或玩家字段。完整过去奥术库存与可执行覆盖独立，原生产scope在实际依赖未闭合前保持关闭。实际检查、差异和下一项只在原两份台账登记。
