# 原牌库发现的选中牌奖励

[固定原资料](../data/cards/past-arcane-deck-rewards-v1.json)包含奥术箭袋`RLK_817`和无底玩具箱`TOY_851`的完整原行及四份官网双语主面。它们是完整过去奥术名单的可达依赖，不增加标准合法根；完整来源未闭合时继续拒绝实际生成，不能只提供已实现成员。

`ChooseFromZone.selected_reward`只接受两个有限声明，默认`None`保持已有路径：

- `arcane_spell_damage`要求本人牌库、原实体take、真正发现、三个最多选项及仅限法术的原查询。
- `copy_with_spell_damage`要求同一原实体发现形状，原查询为全部牌库卡。

声明必须有原来源，不能与原费用奖励、销毁未选牌、不同操作或其它查询混合。卡牌层仅声明真实请求，不抽样、不写区域或自行分配复制实体。原`SelectDeckTake`保留完整有序实体引用、当前预览、原请求、索引和实际选择结果；选中时同时核对已捕获的完整原选项程序，不能替换奖励而沿用旧选择事实。独立原手牌后续计划目前不接受这两项奖励，避免默默丢失其交付义务。

奥术箭袋使用现有`GrantStoredSpellDamage`给选中的奥术法术原驻留追加独立`+1`，随后交由普通非抽牌移入手牌。原费用及修改保留；加成只在此物理法术的实际CAST中捕获，不为玩家提供全局法强。非奥术法术照常交付但不加成。授予反应若使原牌离开并重新进入牌库，后续旧引用不会重新拉取同实体的新驻留或同名另一张牌。

无底玩具箱使用现有玩家持续法强查询，在提交选择、原交付之前核条件。满足时同时捕获选中原牌的当前复制材料，先完成原发现交付，再以普通`CopyCard(current)`分配独立复制体和附件。原牌移区、修改或烧毁不使已接受的材料改指其它牌；复制与原牌分别受实际手牌容量限制。额外复制不另制造一次发现、抽牌或手动使用记录；自动施法复用同一选择和交付入口。

以上选中时条件/材料捕获、同名实体权重、先授予后交付、复制与原发现通知的精确先后，是沿当前公共模块采用的本地政策。完整官网主面证明两张牌的文字和印刷字段，不证明这些精确窗口。国服边界校准依用户要求暂缓；本契约不宣称与官方所有特殊交互完全一致。下一次性法强或另一张存放法术自身的局部法强，不等于玩家当前拥有持续法强。

请求新增一个可空字符串字段，线格式升为`schema602`，旧1～601需用原引擎读取。没有新增游戏状态账本、效果类型、选择目的或玩家DTO字段。现有序列化、原预览与发现完成收据、普通区域/复制、事务回滚和信息投影继续共用。执行结果与下一项只登记原两份台账。

相关验证暴露旧原生触发值校验器把`DiscardRecord`误当作附魔快照，普通弃牌即读取不存在的字段。弃牌记录按原契约只保留基础分配事实；校验器继续验证所有实际物理载体及真正带附魔快照的死亡记录，移除对弃牌不存在字段的读取，不给弃牌历史新增虚构材料。原区域选择恢复/回放及真实希拉格标记/复制边界用于验证此修正。
