# 原牌库复制的使用奖励与原抽牌组发现

[固定原资料](../data/cards/past-arcane-physical-discovery-v1.json)包含月光指引`DED_002`、加大音量`ETC_205`的完整原行及四份双语官网主面，复用完整缓存响应，不增加标准合法根或衍生物。完整过去池与这两张可执行适配分别记录；未知合格内容不能按当前覆盖裁掉。

`DiscoverForPlayFollowup.reward_mode`默认`remaining_offer`保持原地图契约。新增`draw_original`只接受本人牌库的普通当前复制发现，按原去重/抽样方式选择并保存物理代表；请求为`ChooseFromZone(copy_current, distinct=card, discovery=True)`，固定三选项上限和完整默认查询，不接受费用、销毁未选牌等其它奖励。

初始交付沿原复制器，费用、属性与局部附魔使用其当前存放材料；成功入手后，原记录用实际新实体及`HandEntryRecord`武装同回合跟随。原已有同名牌、另一张复制、新手牌驻留或跨回合使用不代替它。原`PlayRecord`完成且保持该实体/驻留/所属回合区间，才消费一次奖励；原地图的未选项菜单不变，新模式没有第二次发现或选择。

月光指引保存的原牌库引用若仍有效，奖励通过原`MoveCard(draw=True)`进入唯一真实抽牌器。奖励先预留这个同步原根的`DrawRecord.id`，后续原抽牌、烧牌、抽到时施法和替换链结束后，沿既有完成标记闭合。新记录字段`reward_draw_id`必须对应原选中实体、卡面、来源、玩家、回合和该次使用后的抽牌；等待帧保留唯一完成责任。原牌已经离开、变面或重新进入牌库时，不改抽另一张同名牌或牌库顶，也不制造疲劳。初始复制烧毁不武装跟随，奖励时满手则由真实抽牌烧掉原牌。

`DrawGroupReward(discover_spell_copy)`只接受三个明确法术匹配槽，没有任意回调或组合参数。每槽继续由原随机匹配及`draw_one`处理；三次原根完成后才执行奖励。反应中的额外抽牌、抽到即施放后的替换叶子，不新增候选。每个实际原法术根保留一个选项，重复卡面也保留各自原物理材料；空槽不伪造选项，普通无压轴分支仍只抽牌。

为原根保存完整抽前复制材料，和既有`copy_other`共用结构校验。组结束时，仍处在原手牌驻留且卡面/实体匹配的原牌使用当时当前材料；已离开、烧毁或抽到即施放的原牌使用其完整抽前材料。普通`RequestChoice(CARD_DISCOVERY)`与`CopyCard(current)`负责真实选择、交付、满手、独立附件及发现事实；卡牌层不扫描现手牌或重建抽牌历史冒充原组。

加大音量用原`spell_conditions.finale`接受压轴条件，后来的抽牌反应不能重新核定该次付款；自动施法沿原条件快照保持非付费压轴。实际选择不追加一次抽样，原三个匹配抽取仍使用完整实际牌库与原RNG。

精确去重/权重、原牌变面后的可抽资格、反制的使用跟随、同名多次抽到的展示，以及抽前/组结束当前复制的官方窗口，都与国服校准分开；上面是明确本地契约，不宣称官网主面证明了这些时序。版本对齐和边界实测依用户要求暂缓，实际差异与下一项只在原两份台账登记。

`schema604`用于新增模式及现有跟随记录的两项字段，旧1～603需原引擎读取。没有新增游戏状态顶层账本、效果/payload类型或玩家DTO字段；既有原跟随公开摘要只展示主人已知的奖励卡面，完整原引用、draw_id、候选材料、队列和RNG保持私有。
