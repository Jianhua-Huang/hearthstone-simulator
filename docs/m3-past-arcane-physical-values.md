# 过去奥术的原物理费用、回合内双施法和结果消费者

[完整资料](../data/cards/past-arcane-physical-values-v1.json)保留十张原法术、奥术残渣、四张真实抉择子牌和三份附魔原行。26份官网双语主面覆盖十张母牌、残渣及星域相变射线的两个子牌。星辰坠落两个旧子牌接口各自双语均返回零卡，完整响应另留来源证据；这两个子牌依据原完整本地行和已核官网母牌正文实现，不声称取得其独立官网主面。执行进度与下一项仍只在[项目状态](project-status.md)和[机制清单](mechanism-backlog.md)维护。

## 两个有限公共入口

`CopyDeckSpellAtCurrentCost(player_id, current_cost, source_id)`只复制本人牌库中当前报价等于指定值的一张物理法术。先用原区域查询取得完整法术候选，再沿原报价器按每个实体过滤；同一印刷面有不同存放费用时，不能用卡牌ID集合代替物理条件。每个合格物理实体仍有一个随机权重，空匹配不消耗随机数；选中后沿原`CopyCard(mode='current')`入手、爆牌和复制材料管线，原牌库顺序与实体保持。旧`CopyMatching`继续按原印刷查询及其既有最低当前价模式工作，没有改变默认费用含义。

奥术光辉按7、8、9、10四档依次提交这个效果。每档在自己的执行时刻读取当前牌库和报价，先前获得反应可以影响后续档；该跨档窗口为明确本地政策，待国服校准。不能把费用匹配改成印刷费用，或把同名不同费用的牌一起加入候选。

`DrawMatchingTurnSpellRepeat`复用原`DrawMatchingSpellRepeat`的物理检索与`draw_one`，只改变实际授予策略：原匹配法术在抽牌开始前获得一次手动使用的双施放附件，期限为当前原全局回合。观星的查询明确为其他奥术法术，同一面物理复制各有权重。只给原被抽实体授予，已有手牌同名体不补领；自动施法与抽到时施放不使用这个手动附件。失败付款、恢复、复制/重置和到期仍沿原附件生命周期与支付证明。

旧绽放的永久全部实际CAST策略继续使用原效果类型，并保留`card_cast_repeat`附件；新观星使用已有`card_spell_repeat`类型和`expires_turn`。二者共用私有抽取函数，没有给旧效果增加字段或改变原接受策略。两种新效果加入机制签名，core765沿schema600/观察119/命令13/replay1，不增加状态字段或来源事实类型；旧机制身份不重标为新身份。

## 原健康结果与真实抉择

磷光射击将原`HealthResult.damage_dealt`交完整对应费用随从池和原有归因的`SummonFromPool`；实际零伤害查询零费档，满板容量及空档沿原召唤政策。咒术之箭在正文接受时，以本人最大法力是否至少六选定实际伤害回调；稍后的最大法力变化不回改原资格。回调抽取原实际伤害量，预防后的零伤害不产生额外抽牌或疲劳。

奥术溢爆使用原健康结果中正的实际伤害减原非负剩余生命，只有正超额才提交原奥术残渣，以原`SummonStats`设等量攻击/生命。法强只在原伤害包计算一次，后来移除法强来源不回改残渣数值；死亡、入场、满板、等待和失败回滚仍交公共执行器。零伤害、预防、转换、伤害下限等边缘继承公共健康分类，本批不据内部断言认证国服极端乘区。

星辰坠落与星域相变射线声明原真实`ChooseOneSpec`与对应子牌，目标属于分支；随机伤害分支不用手动目标，休眠分支只接受敌方随从。普通法术伤害、同时随机不同目标伤害与两回合休眠交原效果；实际兼得来源沿已有公共入口，不引入额外组合机制。兼得的分支顺序和伤害反应后目标驻留等精确窗口明确为本地政策。

## 原变形与奥秘窗口

衰变飞弹的三次有限调用各自在当前局面取活跃敌方随从，沿原零选项数的随机采样请求捕获一个`MinionReference`，再提交当前局部费用减一的`TransformMinionFromPool`。原采样属于普通效果选择，不冒充发现；后续重新取池与物理目标，休眠/地点不参与。实际变形、完整费用档候选和随机数继续由公共模块执行。

星辰排列只提交一次手牌范围的`TransformMinionsInZones(+3)`，费用档与保留值都使用原局部费用。整组的原物理引用与费用在公共接受窗捕获，后来离开原驻留者不拉回、不授予后来同ID驻留；原手牌法术、牌库和战场不参与。这个局部费用依据及后续保留窗口沿原变形契约，未以正文推断为所有全局价格条件的官方实现。

法术共鸣沿原`SecretSpec`的对手回合政策，观察实际`spell_cast_started`，核对原CAST的玩家、来源及原法术面，再沿捕获的原材料复制基础面，设费用零。原奥秘揭示、消费、隐藏、满手和原施法继续结算共用既有管线；自动/重复CAST、其他奥秘拦截顺序与原开始窗的精确关系保留本地待校准记录。

这些适配不修改[完整84项参考](../data/cards/past-arcane-local-reference-v1.json)及原成员权重，也不自动绑定TIME_857生产范围。尚未实现的发现、牌库或过去法术依赖仍须明确失败，不能按已接入子集开放整池。
