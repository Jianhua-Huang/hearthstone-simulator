# 袖珍次元：原发现选项的重复终止

[完整原行与双语官网主面](../data/cards/past-arcane-seen-offers-v1.json)用于`GDB_133`袖珍次元的独立可执行适配。没有增加标准合法根或衍生物，也没有按可执行覆盖改变完整过去奥术参考池。

`DiscoverFromPool.repeat_until_seen`默认关闭，原固定次数、额外折扣、刷新、召唤等发现保持原路径。开启时只接受本人当前职业的普通可收集法术发现：固定三选项上限、每轮立即普通入手、保留候选、真实来源。它不接受延后交付、费用、额外奖励或其它专用发现参数。

重复状态由`ContinuePoolDiscovery.selections`中的完整原始`ChoiceResult`推导。每个原菜单的所有选项都算见过，未选择的牌也算；比较的是原候选的`generation_identity`，同一生成身份的别名共享身份。另一次施法、此前手牌和其它来源的发现不共享本次记录。

原菜单提交、发现事实及所选牌交付继续使用公共发现器、创建器与原收据。最后一轮的菜单包含见过的身份时，这一轮仍可选择并交付，随后续接停止，不生成下一菜单或消费额外RNG。满手按普通生成烧牌，不提前停止；空合格池无菜单、不消耗RNG，也不制造抽牌或疲劳。最后一轮仍交付的精确官方窗口明确保留为本地政策，国服边界待验证。

恢复时验证每个原选择的玩家、来源、职业、完整有序选项、实际结果历史和单调choice id；已终止的原进度不能再接下一轮。候选完整性、生成资格和抽样沿实际绑定池查询，不以已接入卡牌取代池。原交付反应可以暂停，等待帧携带全部原收据；失败回滚、独立注册表恢复、clone、回放与自动施法复用现有执行器。

该字段进入既有类型化帧，`schema605`拒绝旧1～604；没有新增顶层状态账本、效果/payload类型或玩家DTO字段。玩家只能看到应见的当前菜单与原公开结果，内部进度、原分支、队列及RNG不投影给玩家。具体版本、实际验证与下一项只在原两份台账登记；完整TIME_857生产scope仍须全部实际依赖闭合后另行验收。
