# 过去真实施法费用观察与本回合历史消费者

本批接塔姆辛·罗姆、加兹鲁维、大法师瓦格斯三个真实主体，来自原完整过去732张名单。原十二根前审及剩余四根继续在原两份台账与下一队列维护，不裁候选或重定义整个目标。完整五个客户端原行、八个双语主站面及原附魔证据见 [数据文件](../data/cards/past-cast-cost-history-v1.json)。

费用观察继续使用原 `SpellSourceCostObserverProfile(effect_id, school)` 两字段类型，旧神圣光环声明保持原值。新增的有限形状是一个真实随从面、唯一 `spell_cast_finished` 触发器，以及暗影或全学派范围；非随从或不匹配触发器明确拒绝。原支付/自动接受时捕获完整报价，实际完成记录及其收据验证保持；不按后来改费、印刷费用、法力支付量或通知次数重建数值。注册表需要完整报价不代表此时有活跃来源，实际是否执行仍由原随从触发和生命周期判断。

塔姆辛仅认本人成功完成的暗影 CAST，原数值费用至少一时复制该次原法术面，永久费用设零。只在原 `CopyCard` 末尾追加 nullable `cast_id`，原物理操作数此时必须为空；仅允许有来源、原本人成功完成的物理法术、基础面、手牌追加、永久明确零费。执行按原 CAST 身份查询真实历史，保留原来源实体的复制关系和实际随从交付来源，再沿原复制、附魔和手牌通知管线。排队后原法术载体移动或换面不会改成别的牌；没有新 CAST 或伪造手牌出牌。其余旧 CopyCard 形状和验证保持，没有新 Effect 或载荷类型。

加兹鲁维认本人成功完成且原数值费用恰为一的 CAST，交普通 `GenerateFromPool` 从实际宿主完整 `constructed.cards` 可收集机械/all随从域生成。原候选身份、顺序、权重和资格保持，不按已有适配器删除未知牌。根效果接入不等于全部可能产物已闭合，未实现产物仍明确报错。

瓦格斯仅本人回合结束，复用原 `SpellHistoryQuery` 当前回合上下界和 `RecastFromHistory`。按每次成功物理 CAST 抽样，保留同牌多次历史权重，包含既有自动/重复/历史来源；使用当前分支与随机合法目标。无需该随从先在场见过法术，不把历史重施法伪装为付费出牌，空历史不抽样。每次实际结束主体重新接受当时历史。

上述原费用口径、成功来源资格、基础零费复制、自动/重复 CAST 与结束先后为明确本地政策，精确国服边缘仍待验证；版本和热修对齐按用户要求暂缓。恋旧风潮整源、其余专用池和原七根中的抽牌/洗入复制、伤害死亡波、消灭组记忆继续推进。
