# 过去卡牌的抉择、三次选择与法力账户

[完整源数据](../data/cards/past-choice-and-mana-v1.json)保存教师参考名单内五张法术、三种实际召唤物、七个内部选项及三个原附魔证据。固定原行共18份；完整官网目录与单卡响应核出22个双语主面。OG_195c的原行费用仍为省略，只有该身份依据两完整主面明确规范为0；不把省略值普遍默认成0。四个内部抉择选项ETC_373a/b、OG_195a/b在本次完整官网API中没有返回主面，原响应和[逐项缺口](../outputs/card-integration-20261014/k550-past-choice-and-mana/primary-child-availability-01.json)保留，完整固定原行与父卡两分支说明继续作为接线依据。

集会鼓圈与上古之神的小精灵使用既有ChooseOneSpec，保存实际分支身份与明确兼得主体。普通分支只执行自己对应的召唤或增益；兼得先让所有召唤及其反应完成，再经InvokeBehavior读取实际场面授予增益，因此新召唤的随从也受益。原有范达尔来源、支付一次、自动分支、保存和生命周期全部复用公共解释器。七个内部选项使用choice_only，零运行费用属于虚拟选项表达，不改变原源印刷费用，也不进入生成库存。

星夜露宿使用三个普通RequestChoice，每次都提供实际三个选项，允许重复选同一项。共享选择管线负责等待、重放、随机自动选择及重复施法选择记忆，三个位置分别有稳定repeat_key。本次公开Wiki API说明与完整卡面共同支持三次及重复选择，原卡没有普通抉择声明。逐次选择后执行对应主体再接受下一次的通知窗口沿本地公共队列，精确客户端窗口未校准，已在数据中明确标记；本轮不等待客户端实测。

晶体结积在原主体接受窗口按玩家实际永久水晶与mana_cap计算三次增长的溢出，随后提交公共ChangeManaCrystals与对应数量的真实晶体截击者召唤。临时法力不占永久水晶空位；增加的是空水晶，当前可用法力不因此增加。满场时召唤沿普通容量规则失败，溢出不会改回额外水晶；不另写法力或召唤结算器。

超凡之盟先提交公共DestroyAllManaCrystals，再通过延后主体捕获本人当前手牌和牌库的实际CardReference，用ModifyStoredCost设为1。只作用于这些物理对象，没有永久玩家费用光环；后来新生成的同名牌保持自己的正常价格。对手资源与卡牌不受影响，其他价格来源仍按公共报价规则结算。

五张均只增加真实原生行为与必要定义，生产过去域尚待完整候选和依赖闭合。专项为真实上层精灵教师与小学生设置独立的五成员实验目标；该测试库存不能充当通用过去池。版本对齐、正式国服认证及待验证规则边界仍分别记录，实际结果与下一项只在[项目状态](project-status.md)及[机制台账](mechanism-backlog.md)维护。
