# 三种原始梦境来源

本批把原版伊瑟拉（EX1_572）、沉睡者伊瑟拉（LEG_CS3_033）和大德鲁伊纳拉雷克斯（WC_035）接到原有五张完整梦境牌。资料见[完整记录](../data/cards/past-dream-consumers-v1.json)，实际执行与验收见[项目状态](project-status.md)。这是标准牌实际可达的过去卡牌依赖；不据此认证完整过去传说来源。

三个来源与满怀希望的树妖的完整官网中英文响应，都列出同一组五张子卡。API 子卡顺序为 217、808、340、301、489，对应 DREAM_05、04、01、02、03；完整生成配方按原 DREAM_01～05 身份声明，随机执行仍委托公共管线，不把 API 顺序误作牌名编号顺序。

- 原版伊瑟拉使用当前资料的本人结束时随机获取两张，提交两次独立、等权、可重复的完整有限名单生成。
- 沉睡者伊瑟拉的战吼用原自动选择接口产生完整五张的随机排列，直接复用莎拉达希尔的实际有序入手回调。每张各一，满手后继续正常生成并烧毁，不能先裁掉放不下的牌。
- 纳拉雷克斯进入原两回合休眠状态，只有休眠期间的本人结束声明执行，直接复用树妖实际的一张梦境获取回调。计时、苏醒与重复结束效果均由原内核负责，苏醒后不再保留休眠获取主体。

这是已有 `GenerateFromCandidates` 与自动排列的完整有限配方。它们已经可以通过标准宿主执行，不需要额外注册通用发现池、职业过滤或生成上下文。完整五张身份和单位权重保持，不按可执行程度裁池。

原五张定义及元数据保持完整：欢笑的姐妹保留扰魔，翡翠幼龙保留真实白板龙属性，伊瑟拉苏醒沿原双方角色伤害与法伤管线，梦境回到原拥有者手牌，梦魇沿原增益和施用者下次开始回合销毁附件。苏醒既有八个伊瑟拉身份排除已包含本批两个伊瑟拉，无须新增排除或重写效果。DREAM_05e 只保留原附魔证据，不伪造独立可入手卡。

重复结束和战吼、支付、区域容量、通知中断、选择恢复、RNG 回滚、回放及玩家信息投影继续由公共实现负责。小型专项夹具直接注册原五张与树妖实现；为复用有序交付回调，借用真实莎拉达希尔声明和回调，但不在该小夹具执行其腐化法术主体。完整宿主保留莎拉达希尔全部依赖。
