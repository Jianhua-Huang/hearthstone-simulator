# 事件复制、固定数字与反向跨区规则修正

[完整资料](../data/cards/past-event-fixed-copies-v1.json)保六个新根：碎枝GIL_658、蛇发女妖佐拉LOOT_516、塔达拉姆王子ICC_852、莫拉比ICC_289、影舞者索尼娅LOOT_165、伊克斯里德LOOT_329，以及六个既有修正消费者和恋旧风潮独立证据，共十三原始完整记录/二十六份双语主站面。完整732过去参考身份保持，不以这些定义存在认证正式生成资格。

[暴雪12.0完整机制说明](https://hearthstone.blizzard.com/en-gb/news/21965466)的复制章节明确区分区域方向。普通同区和正向复制保留普通附魔；BOARD→HAND、BOARD→DECK、HAND→DECK及GRAVEYARD反向复制移除普通附魔。具体卡牌明确规定的数值/费用在基础复制之后另行安装。永久固有组成等沿已有base配方处理，不能把这条规则扩大为删除固有生成身份。

因此，K723萨索瓦尔HAND/DECK保留局部增益的本地政策被本批取代：这两份采用base，BOARD继续current，三份仍绑定同一个已接受原材料。麦迪文的残影、幻觉药水、尖壳印记、凶猛的聒噪怪及代表入口亡者之牌也改用相应反向base。旧数据里的local_policies和旧绿色收据作为当时证据保留，不再用来证明修正后的行为。原始完整记录、定义、元数据、卡池身份与权重不变；ICC_091原本没有全局生成元数据，该缺席也保持。

低层CopyCard(mode=current)继续是显式操作，正向/同区消费者保持，不偷偷改动所有current调用。required_keyword只增加有限base形状：先对同一原场上驻留检查当前关键词，再创建基础复制。尖壳印记先增益并在原反应后检查当前嘲讽；入手复制不会带走刚授予的临时嘲讽或+2/+2。已离场再回来的同ID仍不匹配原引用。

碎枝与佐拉通过原友方随从引用创建base手牌复制。碎枝在第一次通知前装10/10与10费；佐拉的金色表现记录为当前不影响构筑规则的外观差异，不新造金色卡牌身份或改写原卡文。塔达拉姆复用已接凯雷塞斯的local_cost牌库口径判断无三费牌，纯目标规则在不满足条件时关闭箭头，结算主体再次核条件；原出牌实体变成原当前随从的3/3复制，复制对象战吼不重做。费用层精确国服口径与付款后条件变化窗口继续本地记录。

莫拉比只响应真实新增frozen事件；已冻结、不能冻结、英雄及自身不产生复制。友方和敌方随从都可按原接受冻结时的卡面取得一张base手牌复制，后续反应令原体离场不改已接受卡面。索尼娅读取实际友方场上DeathRecord，原来源存活时给一个base的1/1、1费手牌复制；伤害、旧临时增益和授予能力不带回，原固有印刷能力仍在。死亡归属和同批死亡后的来源资格沿现有公共窗口。

伊克斯里德只响应本人真正完成的随从出牌，排除自身入场、反制及效果召唤。以原连续场上引用找到战吼后的当前材料，再委托已有current场上复制、数量与入场，不重复战吼。原体离场/休眠/将死或磁力等未形成独立场上体时，目前按已记录的无当前场上复制政策处理；不因此删掉候选身份，也不冒称已校准该边界。
