# 过去卡池：突袭奖励、费用、治疗、法力与手牌边缘

本批五原始面为哈维利亚·墨鸦、斯卡布斯·刀油、泽瑞拉、时光巨龙诺兹多姆及流放者奥图里斯。固定37.0完整源行、十二份双语官网主面、原732参考身份及MIS_701来源证据保存在 `data/cards/past-hand-edge-cost-healing-v1.json`。没有新增具名物理衍生物、裁剪成员、改变权重或宣称正式池完成。

墨鸦复用上一批的真正完成突袭攻击查询，包括原攻击随从自然阵亡时的冻结关键词。来源仍须存活，当前友方场上随从组经普通捕获引用增加1攻击；来源本身可获增益，手牌、牌库、休眠或已经死亡的随从不在场上组内。不另记攻击或属性计数。

刀油的真实连击通过普通AddCostModifier安装-2费、两次用途、本回合到期的玩家预算，所有手牌可用牌型共享次数与零下限。零费卡也依既有消费契约占一次；英雄技能、自动CAST不作为下一张手牌消费。来源离开不会撤掉已授予的玩家预算，期限和费用的付款接受仍由普通费用解释器负责。

泽瑞拉只读取原治疗账本中本回合由本方来源实际恢复的生命，可包含敌方角色，不能把请求治疗量、过量治疗或目标属于本人误作依据。真实战吼接受时冻结一次总量，再对当时活跃敌方随从作普通同时伤害；英雄、休眠对象不在该组内，伤害是随从能力，不额外继承法术伤害。

诺兹多姆按实际施用者优先、再另一方的顺序，经两个有限原生续接重新查询当前最大法力并委托ChangeManaCrystals，设至10，新增部分为空晶。不恢复已经花掉的法力，不重写mana_cap、临时账户或过载；从超过10降低时沿用普通移除空晶及可用法力上限。显式自定义容量低于10仍服从已有配置上限。没有直接写玩家账户或另造资源执行器。

[官方原面](https://hearthstone.blizzard.com/en-us/cards/54919-nozdormu-the-timeless)明确设为10晶；[社区规则页](https://hearthstone.wiki.gg/wiki/Nozdormu_the_Timeless)的已索引Notes注明新增空晶，并标注2019-11-02的Celestalon来源。当前未取得原推文正文或确切URL，wiki直接打开403；这条采用的空晶语义及取得资料的层级已保存为本地研究记录，不当成当前国服实测。版本/热修和精确反应先后按本轮范围暂缓。

奥图里斯读取真正完成的本人PlayRecord原hand_index/hand_size，判定原左端或右端；单卡手牌只触发一次。付款移牌、抽牌或后续手牌改变不能重算原位置；不要求牌有Outcast关键词，自动CAST与召唤也不制造新的手牌出牌。原生主体明确排除来源自己的新出牌，遵循已在场监听的本地触发契约。符合后对当前敌方英雄和活跃随从使用普通同时能力伤害，仍沿原死亡、选择与回放器。

本批没有公共引擎、共享工具、Effect、载荷、状态字段或profile更改。实际验收与下一项仅在 [项目状态](project-status.md) 与 [机制台账](mechanism-backlog.md) 登记；历史内部验证不等于完整正式支持或国服规则校准。
