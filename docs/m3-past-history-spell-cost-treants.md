# 原抽牌、英雄技能伤害、施法费用与永久树人增益

[固定资料](../data/cards/past-history-spell-cost-treants-v1.json)保存克里丹 BT_196、火眼莫德雷斯 BAR_547、卡雷苟斯 DAL_609、凯尔萨斯 BT_255 和强力巨树格鲁 DRG_319 的完整原行、双语官网响应、既有树人 DRG_311t 及独立 MIS_701 来源证据。完整过去732参考和原29项树人身份分别固定，不按实现覆盖裁剪；树人身份谓词不新增生成池，也不把未知定义登记为白板。

克里丹使用既有完成抽牌记录及原手牌入手ID。真正从牌库成功抽入同一原手牌驻留、且发生在当前实际回合才进入清场分支；原付费PlayRecord保留该入手ID。初始手牌、生成、复制、旧回合抽牌和回手后的新驻留不借用旧抽取。纯目标规则在清场分支关闭箭头域，正常分支沿可用时必选的原随从目标；全场分支交普通DestroyBatch，排除原来源本体并保留既有活跃、死亡及检查点政策。同一手牌驻留变形、效果触发战吼等精确国服边缘仍按原数据口径登记待验证。

火眼读取既有hero_power_damage查询，使用实际结算时冻结的原HERO_POWER卡面、来源玩家及实际伤害单位。原技能替换、后续牌面或伤害种类不改历史；法术、随从及没有明确归属的间接伤害不能冒充英雄技能信用。达到10后只交普通随从能力DamageBatch，对当前敌方角色各造成10点伤害；不叠加法术伤害。友方目标、护甲和实际/名义量沿原健康账本，间接归属及精确国服统计边界保留。

卡雷苟斯直接声明既有first_per_turn法术设0光环，并从完整宿主constructed.cards进行按当前英雄职业筛选的法术发现。原法师卡面不固定被偷取后的发现职业，也不能用小型验证池替代宿主名单。首张仍使用原付费手牌前缀这一既有本地政策；凯尔萨斯则直接声明every_nth_per_turn=3法术设1，读取完整原实际CAST接受前缀，包含现有重复、效果、抽到施放及历史起源。两者都没有新费用预算或额外计数器，来源进入不重置玩家历史，支付后的旧报价不因来源死亡、沉默或后续施法重新计算。自动施法、反制和多费用来源的精确国服窗口继续遵守[首张](m2-first-play-turn-cost-auras.md)及[周期](m2-periodic-spell-cost-auras.md)的明确待校准政策。

格鲁安装普通、独立的持续PlayerEffectSpec，使用已有PlayerAuraSpec的controlled_minion_cards范围及完整29项原树人身份。当前受控手牌、牌库与场面等材料沿原范围参与增益，当前复制排除派生光环缓存，再由接收者的真实程序重新计算；原来源离场、沉默或转控不移走旧玩家的程序，每次实际重复战吼安装独立实例。完整谓词内仍缺定义的身份保持明确未支持，后续是否为本轮实际可达依赖须另核，不能据谓词增加独立狂野/Classic接卡门槛。既有范围中沉默后的重应用、当前控制者和储存区政策不冒充国服实测。
