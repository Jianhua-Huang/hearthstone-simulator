# 过去传说的个人施法与出牌监听

[完整资料](../data/cards/past-legendary-cast-listeners-v1.json)保存菲奥拉、艾蒂丝、比尔杜、原版周卓、萨维斯、加里维克斯、特罗格佐尔、哈尔琳、莫扎奇、纳兹亚十个原始传说面，及实际萨特、加里维克斯幸运币和石腭穴居人壮汉三个依赖。石腭穴居人壮汉是可收藏普通随从，不能伪装成不可收藏白板衍生物。三个客户端收藏父子链接、完整16原行与28官网语言面经共享准备核对。

原版周卓的0攻及幸运币的0费均仅按指定原行缺省字段和双语主站数值明确归零，原行保持。幸运币另有[完整双语主站响应](../outputs/card-integration-20261014/k686-past-legendary-cast-listeners/coin-source-observations-01.json)，牌面明确不触发加里维克斯；它仍是正常0费法术，走普通付款、临时法力、施法事实和其他合格监听。

本批沿已有[个人施法契约](m3-reactive-growth-cards.md)区分手牌CAST开始与整次物理出牌完成。通用逐次CAST不是所有“你施放”的第二次个人出牌：自动、抽到时施放、历史和额外重复不伪造新的个人手牌开始；反制保原开始事实，但没有成功完成奖励。重复法术可有两个真实CAST与一个原付款/PlayRecord。此资格及前后窗口属于原明确本地政策，不能宣称已穷尽国服实际边界。

原版周卓直接复用已验收核心版的实际`cards.trigger_source.cho`行为，完整旧定义及PoolCard被固定核验，不能逐卡复制另一个法术复制器。双方原手牌法术开始时，从原物理法术捕获`CapturedCardCopyMaterial`，通过`CopyCard(mode='base')`交给另一玩家；不把当前折扣带给复制件。加里维克斯采用同一材料与原base复制接口，但只响应对手，并向施法者给一张实际幸运币。排除只写在加里维克斯消费者中，不能全局屏蔽幸运币的施法事实。复制与固定礼物满手分别走原烧牌流程。

菲奥拉和艾蒂丝要求原本人手牌开始、目标为该来源的原物理ID和区域纪元。菲奥拉沿`GrantCapturedKeyword`先授予圣盾；艾蒂丝沿普通随机随从能力伤害造成3点，不吃法伤。目标原事实不根据后来换面或离场同名新体改写。特罗格佐尔在对手原手牌开始、法术主体前召唤实际石腭穴居人壮汉；新壮汉不能倒灌订阅已经接受的同一个开始事件，后续对手施法才沿原捕获增益接口给其+2攻击。

萨维斯读取原已完成的本人物理出牌，排除自己的原入场，包含被反制的法术出牌；普通召唤或自动施放不制造额外手牌出牌。比尔杜、莫扎奇、哈尔琳和纳兹亚匹配整次本人SPELL出牌成功完成且未被反制，复用已存在的个人完成消费者政策。比尔杜调用原主英雄技能刷新；莫扎奇调用原持续法伤授予；源沉默、回手、复制与实际当前技能继续由公共生命周期处理。

哈尔琳直接使用`RandomSplitDamage`既有`non_spell_unit_packets`配置：预算4、`MINION_ABILITY`、无新CAST。每单位目标、普通健康/死亡、随机接受、等待及后续游标都由公共分摊解释器负责，不能在卡牌层复制四次旧候选抽样或额外施法。

纳兹亚读取原`PlayRecord.cost`，因此当前本地规则按原接受的实际报价计算，折扣、0费及主体改变后来费用都不重写原数值，不把法伤或剩余法力变化当作费用。此沿[既有活化月亮井费用事实](m3-trigger-source-cards.md)政策；[官方论坛的玩家揭示讨论](https://us.forums.blizzard.com/en/hearthstone/t/it%C2%B4s-all-over-raj-naz%C2%B4jan-hunter-legendary/83375)只展示牌面，没有直接证明所有折扣、替代支付和自动施法规则。精确国服费用依据仍明确待验证，不用间接资料冒称已校准。

本批不增加公共结算器、状态字段、Effect/载荷或玩家协议。原完整732过去传说身份、顺序、角色与参考权重保持，不能据已实现子集注册生成池；MIS_701和完整萨满来源仍未绑定，YOG_522原相邻目标监听边界继续保留。全部实际验收、差异及下一项只在原项目状态/机制台账维护。
