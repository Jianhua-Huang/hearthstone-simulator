# 过去传说的具名召唤、条件亡语与治疗

本批服务于标准来源实际可达的过去传说依赖，完整资料见[版本化数据](../data/cards/past-legendary-named-bodies-v1.json)。12个根面是冷喉、莎莉、穆克拉、火车王、奥妮克希亚、砰砰大师弗拉克、砰砰博士、厨师诺米、诺萨莉、笼头、斯塔拉格与费尔根。六个新依赖保留完整客户端原行；火车王的`EX1_116t`和奥妮克希亚的`ds1_whelptoken`不是同一个身份。塔迪乌斯采用构筑版`FP1_014t`，不借用纳克萨玛斯冒险首领。香蕉和地精炸弹复用已实现的真实定义与行为。

共享prepare核22个完整原行及28个官网中英文主面；六个不可收藏衍生物没有据此宣称额外官网主面验证。七条客户端父子收藏关联完整核对，斯塔拉格和费尔根的塔迪乌斯采用完整具名依赖原行。冷喉中文客户端把嘲讽与亡语分段，官网合并显示：工具只在指定卡、中文、精确完整行哈希和唯一前缀匹配时允许这项显示转换，规则正文、数字及其他字段照常严格核对。原始行没有改写。

卡牌行为只组合公共效果。火车王把两个自身小龙召给对方；弗拉克创建四个实际地精炸弹；砰砰博士创建两个实际砰砰机器人；诺米仅在当前本人牌库为空时请求六个真实6/6元素。奥妮克希亚复用`FillBoardWithCard`保存的原始剩余容量及完整有序计划，休眠和地标占位继续由内核处理。具名召唤均带`SummonCause.capture`，普通召唤不执行战吼。笼头与塔迪乌斯亡语召唤复用已有场位助手，保原死亡槽或主动触发时载体右侧；其他战吼、填场的落位沿既有公共默认政策，精确国服边界仍待校准。

穆克拉通过两次`AddToHand`把实际香蕉给对方，并沿原信息接口让赠送者知道固定礼物。满手烧牌、实际香蕉+1/+1、持有者付款和玩家隔离仍由既有路径负责。诺萨莉为双方当前英雄各请求其最大生命值，在一个`HealBatch`中执行；使用普通效果治疗类型，护甲、过量、转换与来源倍率继续归公共健康模块。

冷喉在原亡语回调中读取执行控制者的当前手牌龙/万种族资格，对双方活跃存活普通随从提交一个3点伤害批次，排除英雄、休眠和地标。莎莉读取原死亡攻击事实或主动触发回调的来源攻击，遵循公共亡语解释器的首次捕获/重复刷新窗口，不读印刷攻击，也不把捕获窗口中尚未开始的记录当成已执行事实；伤害只作用于敌方当前普通随从。两者均使用随从技能伤害，不吃法术伤害。

斯塔拉格和费尔根通过双方实际死亡历史查询另一原始身份，不能用当前墓地或曾存在的印刷脸替代死亡事实。同批死亡的两者各自可以看到该死亡批次；先变形再死亡不会补出原身份的死亡。笼头生成实际9/9冲锋、嘲讽野猪，印刷关键词、立即攻击预算、沉默与新实体生命周期复用公共模块。

砰砰机器人以原四选一随机效果选择1～4，再从当前存活敌方角色中随机选择伤害目标。先金额后目标的RNG顺序是明确的本地政策；[首手玩家报告](https://us.forums.blizzard.com/en/hearthstone/t/inconsistent-interaction-with-boom-bot-and-arachnathid/164339)不足以证明官方采样顺序或离场后授予剧毒的所有边界，不据它改变公共离场来源规则。选择等待、失败后的RNG回滚、独立注册表恢复/clone/回放与玩家投影继续沿原解释器。

本批不修改公共引擎、状态格式或Effect类型，只增加内容版本和精确显示核验分支。原完整732参考身份、顺序、角色及本地权重保持，不能把已实现子集注册为完整过去池；MIS_701和完整萨满来源仍未绑定。执行进度、实际验收、差异及下一项只记原两份台账。
