# 过去传说变形的完整本地参考域

恋旧风潮 MIS_701 是已取得的萨满自然法术71项参考域的一员，当前正式标准卡实际能调用它，因此其过去传说生成依赖属于本轮范围。主卡的描述和属性保留固定客户端原始行；本资料不跟随主站当前热修重写固定版本。

[版本化参考资料](../data/cards/past-legendary-reference-v1.json)从完整23452行固定库，沿已使用的过去系列政策，筛选可收集、MINION、RARITY=5且原始系列在该政策中的记录。按完整源顺序保留732个不同原始卡牌ID，每项保留完整原行/SHA、独立解码元数据、原源位置、候选角色和本地参考权重1。原主卡行单独保存；不据当前原生定义有无裁剪候选。

这732项是声明谓词下完整的潜在身份域，不能直接宣称732个实际等概率生成结果。18组同英文名记录和30条原重印关系在[身份审计](../outputs/card-integration-20261014/k681-past-legendary-reference/full-reference-audit-01.json)逐项保留，不擅自删除或合并。实际生成时的身份去重/权重、泰坦/传说附属/三符文、原始牌库资格和来源排除继续使用既有独立生成政策；哪些适用于本来源还需单独核对，不能用“未实现”当排除理由。正式过去系列定义、重印和国服排除的未确认处保持本地差异，版本与边界校准按用户要求暂缓。

该数据文件尚未接到运行注册表，不增加白板定义、元数据、标准根或可抽样的部分池。后续只为真实候选及其生成、复制、回手再打等实际可达依赖补完整效果；候选仅被变形上场不表示其战吼和其他区域需求可以省略。完整域闭合后，再经标准宿主有限scope绑定实际来源。

主卡执行须复用公共物理随从批次/变形器，记录原场上接收者及连续驻留，处理双方、休眠/地标/满场、随机计划、变形后触发、终局截断、等待恢复、回滚与玩家隔离；完整采样窗和先后采用有依据规则或明确本地政策，不在卡牌层复制结算器。
