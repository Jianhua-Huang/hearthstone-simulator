## 来源及角色

完整保留十根、十三个新子卡、二十九个既有基础/升级技能及其随从、武器依赖，以及七个仅作证据的原行，共五十九行。四十八个完整双语主站卡面覆盖十根、十三新子卡和 MIS_701；旧技能族的完整响应仍引用原已审资料，不写成五十八次新卡面核对。原先没有全局 PoolCard 的十二个旧身份继续保持缺席，没有为本批补造全局生成资格。

图哈特的主站十四个 childIds 按原顺序保留，但不据此宣称穷尽十一职业升级族。四个 AT_132_SHAMAN 上下文/选项卡面只作证据，实际升级萨满技能继续使用既有四个基础图腾，包括空气之怒图腾；该历史印刷选择与正式版本对齐另行记录。

玛里苟斯的十个主站子卡中，九个是法术，一个是变形术绵羊。候选九种各权重一；绵羊作为实际变形依赖接入，不进入法术发现名单。龙卵原行空攻击和升级寒冰箭原行空费用，仅按完整双语主站卡面的明确零值规范化；其余原行、角色、数值和文本不改。

## 共享能力与原身份

`DiscoveredDeathrattleTarget` 保存原战吼和原随从引用；`GainDiscoveredDeathrattle` 只接受已真实提交的完整发现结果。授予沿原 `_grant_to` 分配普通可移除附件，保留所选卡定义、亡语行为及 `RememberedDiscovery` 证明。带原生亡语记忆的所选卡，从该印刷声明的全新初始材料开始，不能借用别的实例的成长、抽牌或发现历史。

`AbilityInstance` 只在最后追加 `deathrattle_discovered_from=None`。复制和继承保留原证明，沉默和重置使用原移除路径；删除或篡改所选身份的存档明确拒绝。没有新增 GameState 台账或第二个亡语执行器。获得亡语先于普通入手通知；满手牌时实际所选卡烧毁，已提交的授予仍保留。原受体离场或同 ID 再入场时不承接旧授予，所选卡仍按原发现流程交付。此处先后顺序是明确的本地时序政策，国服精确校准暂缓。

具名法术发现只在 `DiscoverFromPool` 最后增加默认空的 `fixed_candidates`。专用 `named.fixed.cards` 配方要求明确、唯一、完整的非收藏物理法术身份，逐一验证后才使用随机，继续调用原候选、私有选择、交付、恢复和回放流程。该配方不注册或改写普通卡池，不为正式生成池提供按可执行状态裁剪的入口。未知身份直接失败。

`ReturnToHand.recipient=None` 和 `Transform.recipient=None` 只追加原随从引用守卫，继续委托原回手或变形执行器。比费在揭示前捕获唯一的自身返回请求：自然死亡用原 `ReturnDeadMinion`，提前触发用原受保护回手或牌库移动；不生成新的基础复制，也不追随后来的同 ID 重新驻留。原 `Joust.on_result` 回调保持，新 `on_win=()` 只支持这个有限的自身返回形状。

完成攻击后的费用读取只接受原战斗连续驻留或唯一对应的自然死亡材料，费用计算仍交原局部费用层。种族使用原 `TribeState.matches_any`，保留全部种族及显式排除语义。缺失原非死亡离场材料时明确未支持，不回退为印刷费用或新驻留。

## 实际效果与边界

九种升级法术分别调用普通法术伤害、整次六点随机分配、捕获原受体的冻结/变形、当前完整法师法术池、抽四张及普通群体伤害。没有为生成子卡另写施法器。梦境之门拥有真正的抽到时施放声明，召唤当前完整龙池候选、不触发战吼，并沿原替代抽牌、疲劳和场位容量处理。

汉纳尔依据原已用奥秘的冻结职业，排除该奥秘的职业；不按当前英雄职业推断。直接设置奥秘、自动施放和对手使用不成为本人的手牌使用事件。格雷布使用原随机分支和 `GrantCapturedDeathrattle`；自然死亡排除已移除死体，提前触发可选到仍存活的自身，空池不消耗随机。

阿克蒙德必须有真正 MatchSetup 开局留下的物理初始牌库记录；Scenario 中未知的开局身份明确报错，不能按名字猜测。原初始牌与同名生成卡保持区别，已接受的当前出牌和反制出牌沿原“使用过”定义查询，实际召唤只创建印刷体、不重复战吼。此处历史类型、精确费用层、转控制权和观察者窗口仍按原模块的本地政策，未宣称国服完全一致。

选择待续做独立注册表恢复、clone、回放及失败选择原子回滚；玩家 DTO 不含内部发现证明、原生记忆或随机状态。版本/热修、待实测规则边缘与完整过去源绑定继续分别登记，不能用本批定义数量替代整池效果验收。
