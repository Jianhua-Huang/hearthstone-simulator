# 过去法师法术：原邻位、冻结与具名衍生物

[完整资料](../data/cards/past-mage-freeze-summons-v1.json)保留十五张过去法师法术、两个新衍生物和三个既有真实依赖的完整原行与中英主面。所属系列仅用于来源归档，本批推进标准来源实际可达内容，不增加标准构筑根。完整179项和原84项名单继续保留；执行与下一项仅在原两份台账维护。

## 原物理邻位与伤害批次

冰锥术、陨石术及灵魂冻结只捕获原目标所在面板前一格、本格、后一格的 active、存活普通随从。地标、休眠及特殊物件占位不会把更远的随从补为邻居。原目标接受后保存 MinionReference，后续不重新按面板搜索目标；原物理驻留变面、转移控制、离场重入沿现有严格引用政策处理。

原目标在正文执行前已经离场时，三个邻位正文直接结束，不重新寻找邻居、不产生额外自伤，已接受的付款保留。此入口由真实 PlayCard、card_committed 反应中消灭原目标的专项验证，避免在空面板查找索引导致整笔操作回滚。

冰锥术逐个提交既有 FreezeCapturedMinion，再以新 `DamageCapturedMinionGroup` 对仍有效的原成员提交一次普通 DamageBatch。陨石术直接提交同一请求，各原成员分别保留目标15/邻位4的原基础伤害。整个批次统一由共享伤害结算器捕获法强、写结果和执行死亡检查；卡牌正文不结算伤害或死亡。

新请求仅含1～3个唯一 MinionReference、等长非负整数伤害和原法术来源。构造/保存验证核完整类型、配对、分配上界、原卡面类型和来源；执行时过滤失效原引用，不跟随同名新体。队列恢复使用公共 continuation 及效果编码，无新增 Entity、Player、顶层历史、CardDefinition 或玩家DTO字段。

灵魂冻结沿既有 FreezeCapturedMinion 处理原组，冻结后对施法者英雄提交普通 SPELL 伤害，基础值为接受时捕获的原成员数。已冻结者计入；冻结预防和中间反应不重新计数。这是当前明确本地政策，成功冻结数、法强与精确国服窗口仍待验证。
