# 过去法师的四张任务与完整奖励

[完整来源包](../data/cards/past-mage-quests-v1.json)保存学习龙语DRG_323、元素盟军DRG_324、洗劫天空殿ULD_433、打开时空之门UNG_028，以及龙族使者DRG_323t、升格卷轴ULD_433p、已有时空扭曲UNG_028t的七条完整原行和十四份中英文官网主面。这些是标准过去来源的实际跨系列依赖，不新增标准组牌根；完整过去法师来源仍以原179个身份为分母。

四张任务声明普通QuestSpec和QuestStageSpec，进度只返回原AdvanceQuest或ResetQuestProgress，不直接修改任务状态。原实例、阶段、区域、完成标志、共享占位、开局保证、恢复和玩家投影继续由原任务解释器处理。

| 任务 | 实际计数依据 | 原奖励 |
| --- | --- | --- |
| 学习龙语 | 激活后本人真实法术法力支出累计8 | 原SummonByCard召唤新的6/6龙族使者 |
| 元素盟军 | 两个连续本人回合各完成至少一次元素随从出牌 | 原DrawPhysicalGroup从本人牌库检索三张法术 |
| 洗劫天空殿 | 激活后本人十次实际法术CAST | 原ReplaceHeroPower换成升格卷轴 |
| 打开时空之门 | 激活后本人八次实际CAST，原物理来源不属于起始牌库或原脸已替换 | 原AddToHand交付已有完整时空扭曲 |

学习龙语读取card_committed的完整PlayRecord和原PlayerSpellManaCostRow.mana_for；另接mana_consumed的完整ManaConsumptionRecord，核对原消费历史和来源。支付减费后的实际法力计数；生命替代支付、随从、技能、交易和锻造不计入。每个原支出身份的各单位使用独立唯一键，最多推进目标所需的八点；原事件重入不重复记账。任务自己的安装费用不回算，激活前的旧支出不回算。

元素盟军在card_played读取完成的原PlayRecord及提交时冻结种族，沿submitted_tribes应用原提交费用材料中的种族附魔。随从的后续换面不追改已提交身份，召唤不当作出牌。同一真实本人回合区间只记一个唯一键；本人回合结束时若当前区间未获信用，清空此前进度。对方回合不重置，额外本人回合是独立的真实区间。奖励的三个物理法术检索槽依次走原抽牌和容量规则，烧牌、空匹配、选择等待与反应仍归原执行器。原QUEST_REWARD_DATABASE_ID=395仅保存为原始字段，奖励本身不创建或施放该身份。

两个施法任务订阅spell_cast_started，并核对原CastRecord和事件来源/玩家。沿既有普通施法监听政策，正常CAST和被反制的手动施法尝试计数，其他失败的自动尝试不计；每个原cast id仅一次。英雄技能使用不当作法术。升格卷轴的2费原技能从完整普通生成域选择可收藏法师法术，明确固定法师职业，生成牌获得CostSpec(delta=-2)；生成资格和主任务排除仍交给公共池，未知合格成员报错，不能按已实现范围裁池。

时空之门只在实际本局OpeningState提供的原始物理套牌身份上判定来源。同名副本有新的实体身份；原物理牌是否换面沿已有face_replaced政策处理。没有真实起始牌库身份的Scenario在本人合格施法时明确拒绝，不从牌名或当前牌库猜测。已有时空扭曲的整条定义、元数据、执行行为及每玩家整局一次标记保持；奖励只是原AddToHand，由现有quest_hand_rewards自动包装，满手时保存完成事实并等待真实空位。

## 本地政策与证据边界

官网主面和固定本地原行确认卡文、数字、身份、类型和原奖励引用；细分支出通知点、连续本人回合窗口、反制信用、换面来源资格及奖励的精确反应顺序仍是本地政策。[社区高级规则](https://hearthstone.wiki.gg/wiki/Advanced_rulebook)区分反制与施法监听，并描述任务奖励的阶段关系；[社区任务说明](https://hearthstone.wiki.gg/wiki/Quest_(ability))描述可见任务、起手和满手奖励。它们不认证本项目全部国服时序。

本批只增卡牌适配，内容版本687；core787/schema611及原效果、payload、观察、命令和回放接口保持。选择等待继续保存原任务实例和原奖励帧，失败恢复原事务；内部唯一键、起始牌库材料和待交付奖励不提供给玩家。专项见[测试](../tests/test_past_mage_quests.py)，实际执行结果和下一项只维护在[项目状态](project-status.md)与[机制清单](mechanism-backlog.md)。版本/热修对齐与国服规则边缘按用户授权暂缓。
