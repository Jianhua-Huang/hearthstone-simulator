# 过去法师奥秘的死亡、复制与回合伤害消费者

[完整来源包](../data/cards/past-mage-secret-consumers-v1.json)保留AT_002轮回、DEEP_000召唤结界、DMF_107非公平游戏、ICC_082寒冰克隆的四条原行和八份完整中英文官网主面。这些是标准过去来源的实际依赖，不新增标准组牌根；完整过去名单的绑定仍独立验收。

四张牌只组合已有SecretSpec、原事实查询和公共效果，没有新增Effect/payload、内核或协议字段。原隐秘独立区域、同key去重、五容量、触发顺序、条件重检、消费后发布、选择恢复、回放和回滚均使用secrets.py。召唤结界明确声明owner回合例外，另外三张遵守opponent规则。轮回和召唤结界声明requires_board_space；无场位时保留奥秘，不先消耗再丢弃。

| 卡牌 | 实际入口和公共效果 |
| --- | --- |
| 轮回 | minion_died核原death_id、物理id、控制者、批次、回合与BOARD区域，用原DeathRecord.base_cost查询完整普通同费可收集随从域，再沿GenerateFromPool(board)召唤。 |

轮回使用原死亡基础费用，不从后来同名牌、当前墓地或最后一条死亡推测。当前选择的基础/印刷口径明确忽略局部费用附魔和只作用于手牌的光环；这是待国服核定的本地费用政策。召唤仍接受完整同费池，未知合格定义报错回滚，不能按已实现数量过滤。空匹配按普通空域处理；完整候选身份、权重和版本由公共池保留。

召唤结界只比较当前物理局部费用，不套用假想入手后的职业费用报价；休眠、地标、交互对象和其它非活跃槽位不参与。复制保留当前数值、伤害及原公共能力生命周期，不重放战吼。并列候选以物理id为独立均匀分支，候选完整保存到原随机事件；唯一候选不抽样。CopyMinion保存BoardPresenceReference及SummonCause，抽样后原驻留失效则按原公共引用政策处理。揭示反应后重新计算当前候选的窗口暂为本地政策。

非公平游戏发生在对方结束阶段，三次奖励抽牌仍在对方回合，然后原交接流程开始本人回合及正常抽牌。[官方卡文](https://hearthstone.blizzard.com/en-us/cards/61585-rigged-faire-game/)没有给出全部时序；[灰烬元素讨论](https://us.forums.blizzard.com/en/hearthstone/t/ashen-elemental-bugs/96640)的玩家记录支持此结束阶段解释，尚不作为国服官方校准结论。精确结束反应队列中的先后仍沿原引擎和奥秘顺序。

护甲吸收也属于实际伤害；后来治疗不能抹去旧记录，换英雄不能因原hero_id消失而抹去该玩家的受伤事实。只看对应玩家英雄的最终DAMAGE，友方随从受伤、被免疫防止的零伤害、直接LoseHealth和本人前一回合受伤不阻断。奥秘在对方回合中途设置也检查该回合之前的伤害。失败的对方回合不会消费奥秘，可等待以后满足；奖励抽牌导致的疲劳仍交普通抽牌/伤害流程处理。

寒冰克隆不以原随从仍活着作为条件，不把召唤或被反制的手牌当作已使用随从。原提交材料保存原卡面、固有组合顺序、永久属性/Jade等既有基础材料，不依赖后来同数字id的驻留。当前明确使用原提交的基础卡面，忽略战吼之后的附魔与变形；该原卡面/当前卡面边缘尚缺独立确证，因此作为本地政策登记，不能宣称与国服完全一致。[社区规则记录](https://hearthstone.wiki.gg/wiki/Advanced_rulebook?section=66)只提供该效果不依赖源随从存活的局部依据。满手依次按普通交付/烧牌处理，不能因手满而保留奥秘。
