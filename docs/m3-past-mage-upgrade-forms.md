# 过去法师的完整升级形态与手牌伤害

[固定完整源记录](../data/cards/past-mage-upgrade-forms-v1.json)保存4张过去法师原牌及5个非收藏形态，共9条完整原行和18份中英文主面；原始字段与原文保留。它们是标准效果实际可达的跨系列依赖，不增加标准组牌根。完整179张过去法师生产源仍须按原台账补齐，不能用这些形态或当前已实现子集裁池。[原生适配](../hs_sim/cards/past_mage_upgrade_forms.py)复用公共等级、手牌进度、锻造、随机池、目标与伤害批处理。

## 物理形态与入口

| 原牌 | 全部物理形态 | 复用能力 |
| --- | --- | --- |
| 冰风暴 BAR_305 | BAR_305 / BAR_305t / BAR_305t2 | 5/10最大水晶等级、随机冻结1/2/3个不同的活跃敌方随从 |
| 小型法术红宝石 LOOT_103 | LOOT_103 / LOOT_103t1 / LOOT_103t2 | 持有时每使用两张元素牌升一级；随机取得1/2/3张法师法术 |
| 熔火符文 TTN_477 | TTN_477 / TTN_477t1 | 2费锻造换面；基础3点伤害和一张随机法术，锻造面各两次 |
| 深呼吸 ONY_006 | ONY_006 | 执行主体时固定1加其他手牌法术数，对原目标与物理相邻活跃随从造成一批法术伤害 |

等级族使用已有ManaRankFamily；手牌和牌库按持有者最大水晶单调升级，使用当前水晶数或失去水晶不会降级。三面原始cost缺省，运行时的0费声明由全部中英文主面核定，不改写原始空值。新增族属于独立注册轴，须在通用观察器外保全原族并核验唯一新增声明。

法术石使用HandProgressSpec，事件是原card_committed，资格读取原提交面及其已接受种族附魔。仅己方元素随从的真实手牌使用推进；直接召唤、对手使用、非元素和法术不会推进。每个实际事件最多完成当前阶段，牌库形态不监听手牌进度，新取得的牌不追溯旧事件。费用政策明确采用已有法术石的clear_local：完成换面时清除本地费用附魔。该费用边界为本地政策，尚未国服校准。

法术石随机奖励通过完整普通constructed.cards域，固定查询法师职业及可收藏法术，允许重复；持有者为其他职业也不改变奖励职业。熔火符文查询同一普通域的所有职业法术。两者继续由公共生成器抽样、创建和执行手牌容量规则，不按卡牌实现程度筛选，也不会打开尚未闭合的过去法师源。

锻造使用HandActionSpec及公共upgrade_face，独立支付2费并保留同一实体；随后施放仍按3费付一次。已锻造面的完整主面明确写明伤害两次、获取法术两次。本地按两个连续的普通Damage，随后一次count=2的GenerateFromPool实现；每段各自应用法术伤害，首段消灭目标后另一段失去目标不会取消随后生成。外层为一次出牌、一次CAST；精确施法计数、两段与生成间的正式细时序仍列为本地政策，未宣称官方校准。等待、失败回滚和回放沿原解释器。

深呼吸按[公开卡面](https://hearthstone.wiki.gg/wiki/Deep_Breath)与完整本地主面核定基础1点。主体开始时捕获其他物理手牌法术数和原目标的物理相邻位置，再交给DamageCapturedMinionGroup。手牌随从不计入，当前法术自身不重复计入；地标和休眠位置会占据位置，不跨过它们寻找另一侧随从。目标与相邻随从共同进入普通法术DamageBatch，法术伤害由内核结算。捕获时点与位置边缘保留为本地政策，国服边缘验证暂缓。

## 数据核验和保护范围

红宝石前两面的原文含有@显示分隔符；完整主面仅省略该分隔符，基础面的升级说明完整保留。共享准备器只对两条精确原行摘要、显式@为空声明和中型面的原parentId进行核准。完整规则、数字、身份、费用、学派和全部响应仍执行原检查，改动源行、正文或父面会拒绝。深呼吸原@为现有动态脚本数值显示，继续使用原核验路径。

只新增原生卡牌声明、上述两条原文显示核验及内容版本；无新增效果、载荷、状态字段或公共战斗结算器。专项需覆盖全部形态的真实入口、付款、升级资格、复原/回放、失败原子性和隐藏进度；实际结果与下一项仅在[项目状态](project-status.md)及[机制清单](mechanism-backlog.md)维护。
