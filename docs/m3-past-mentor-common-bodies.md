# 过去法术的公共效果接线

[固定来源数据](../data/cards/past-mentor-common-bodies-v1.json)保存已取得教师参考范围内的六张真实法术与四个实际衍生物。完整固定原行和20份双语主面观察共同核对卡名、数值、种族、关键词和子卡身份；原图录完整响应与字节收据复用共享准备工具。奥妮克希亚雏龙、海藻爬行者和树人通过原源COLLECTION_RELATED_CARD_DATABASE_ID连接，森林的援助的终止副本另由完整主面childIds连接。

- 生命之树使用公共HealBatch对双方当前有效角色提交以各自生命上限为数值的法术治疗；治疗转换和过量治疗由原内核处理。
- 优胜劣汰使用公共BuffMinionsInZones，对本人手牌、牌库和战场的实际随从加4/+4；区域、休眠、实体引用与信息边界沿既有契约。
- 奥妮克希亚鳞片使用FillBoardWithCard接受实际空位组，召唤真实2/1突袭雏龙；没有硬编码七次召唤或另写容量/数量解释器。
- 奇迹生长先执行真实三次抽牌及其反应，再通过InvokeBehavior读取当时实际手牌数，用SummonStats设置真实植物的入场数值。满手烧毁不增加手牌数，零手牌的0生命体沿普通死亡处理。
- 塞纳里奥结界先获得8点护甲，再从宿主constructed.minions按印刷8费、可收藏随从查询并召唤；不添加职业限制或按效果实现覆盖过滤。
- 森林的援助由公共召唤解释器执行五次树人请求。双生法术与实际DAL_256ts终止副本使用HandDerivativeSpec，副本没有双生关键词；自动CAST同样走公共衍生物管线。

延后调用会丢弃原RuleContext中的CAST字段，召唤主体据原实体和玩家查询仍活动的真实CAST，并重新捕获SummonCause；不能把学生实体或免费施放的零支出当原法术来源。抽牌等待、自动施法、原生召唤及异常回滚仍由公共内核执行，无新存档字段或第二套结算器。

教师已取得的21条社区参考来自Standard/Druid视图，显示版本255130，与固定执行资料255026分开保存。本批只补其中六张的原生行为及衍生物，不安装生产环境的过去域。专项中的六成员库存使用独立且明确命名的实验目标，只用于真实上层精灵教师发现、学生教学和自动CAST入口验证；不得当作完整过去卡池。其余实际成员和后续生成依赖须接续补齐，完整候选与来源资格再单独绑定。版本对齐与规则边界暂缓，不将本地效果测试升级为官方池或国服认证。
