# 原随从战吼的伤害死亡波

[完整资料](../data/cards/past-minion-death-waves-v1.json)保留高弗雷勋爵 GIL_825 的固定客户端完整行、完整双语主站面和原过去732传说参考清单；恋旧风潮 MIS_701 只作为未绑定来源证据。本文不认证完整过去池、正式生成资格或国服规则校准。

高弗雷的真实战吼返回 `RepeatBattlecryMinionDamage`，绑定已接受且正在执行的原 `BattlecryRecord`，不伪造法术 CAST。解释器每轮捕获双方当前活跃、存活、非将死的其他随从；休眠、地标和原物理战吼载体排除。同一轮通过原 `settle_health_batch` 提交基础2点 `MINION_ABILITY` 伤害，不叠加法术伤害。护盾、免疫、转移、数值规则、吸血、剧毒和死亡均使用公共执行器。

`ContinueBattlecryDamageIfDeaths` 保存原请求、来源分配事实、完整有序目标、实际健康批次及完整伤害结果ID区间。状态/待选恢复校验真实原战吼、物理来源、完整批次、原目标顺序和原伤害种类/基础值，拒绝裁掉某个目标、借用其他批次、未来结果或已完成的战吼。原生存档仍不提供未签名外部来源认证。

普通反应、死亡、亡语和复生结算后，仅当本轮原伤害或剧毒原因对应真正的场上随从死亡时继续；反应另行造成的消灭、伤害和后来死亡不计入本轮。下一轮重新捕获当前场面，因此亡语/复生新实体可以被后续波命中。空组立即停止，无额外随机。没有人为的成功次数上限；真实无限循环仍由既有工程预算触发失败回滚，英雄终局继续由解释器停止。

已接受战吼在原载体死亡、沉默、控制变化、回手或换形后继续；每轮仍排除原物理ID，伤害来源材料由该轮公共健康器冻结。每次实际战吼重复独立运行整段正文，不把某一波当作新的战吼或重复支付。

精确伤害/死亡/亡语通知顺序、只有原波伤害死亡触发重复，以及来源变化后的继续政策均明确为本地实现，保留待国服校准。当前只新增两个有限效果，无新 GameState 账本或卡牌声明字段；原法术连续伤害契约完整保持。塔隆的实际消灭组记忆仍是下一必要依赖，其他目标域继续开放。执行证据、差异和下一项只在[项目状态](project-status.md)与[机制台账](mechanism-backlog.md)维护。
