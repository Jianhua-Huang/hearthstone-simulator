# 过去卡牌的四组具名亡语后继

[完整资料](../data/cards/past-named-death-successors-v1.json)保留大铡蟹、厨师曲奇、管理者埃克索图斯、奥及五个实际物理后继，共九个定义。另有BOT_700e、BRM_027pH和MIS_701三条原始证据，不注册；不能从同前缀或字母H推导普通生成资格或技能升级路径。共享准备核十二完整客户端行、二十个完整中英文主站面。灰烬的零攻击与英雄的零费用只按明确双语主站数据归一，原行保持。

大铡蟹按印刷磁力、回响、机械种族及 `HandRepeatSpec` 走已有手牌提交和融合管线。亡语用原有序组接受两个具名微型机器人，各自普通入场，不执行战吼；自然死亡从原槽位/+1、提前触发从原存活载体右侧/+1接受位置。原子组身份、每体数量、容量、等待与恢复仍交公共执行器。回响只在整次手牌提交生成一次临时基础副本，直接召唤不产生回响；融合后的亡语属于现有宿主附件。

厨师曲奇和曲奇的搅汤棒均有印刷吸血；亡语只调用原 `EquipWeapon` 安装确切2/3武器。旧武器退役、新武器攻击预算、英雄战斗及实际吸血治疗仍沿普通生命周期。

管理者原客户端关联指向正常技能BRM_027p；具名英雄BRM_027h自己的HERO_POWER标签与该技能相连。亡语显式调用原 `ReplaceHero`，使用8生命英雄和正常技能；技能复用原当前敌方角色查询和 `RandomDamage(..., HERO_POWER)` 造成8点伤害。保留原英雄替换对护甲、持续附件、攻击支出及额外技能的政策，罕见国服边界待验证。没有制造英雄牌战吼，也没有把pH版本编造成升级技能。

奥普通亡语在原位置召唤0/3灰烬；灰烬在实际控制者回合开始时通过原 `Transform` 变成印刷奥。它不是旧实体复活或休眠；转控、沉默、旧增益/伤害清理与再次死亡沿原生命周期。开始反应中的特殊离场重入窗口和数量扩展后的精确相对位置继续按现有本地政策记录。

本批不改变公共内核、Effect/载荷、正式卡池或来源绑定。完整过去732名单、其他专用池、版本/热修与国服规则边缘继续保留；定义存在不等于生成资格或完整目标完成。实际进度与验收只维护[项目状态](project-status.md)和[机制台账](mechanism-backlog.md)。
