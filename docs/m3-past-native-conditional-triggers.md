# 过去卡池：原出牌、攻击、召唤及弃牌消费者

五原始面为梵妮莎·范克里夫、考瓦斯·血棘、精英牛头人酋长（金属之神）、血骑士领袖莉亚德琳、萨瓦丝女王。固定37.0完整客户端行、十二份中英文官网主面、原732参考身份保存在 `data/cards/past-native-conditional-triggers-v1.json`。没有增删生成池成员或改变权重，MIS_701仍仅来源证据。

梵妮莎以本次真实连击的原PlayRecord为上界，读取对手最后一张已提交的物理手牌；跨回合保留，反制不撤销已经提交的出牌。随从采用原固有PlayedMinionCopyMaterial，其他牌型采用原FrozenPlayedFaceFact，交给普通CopyCard的base入手路径。后来增益、变形、控制或区域改变不覆盖旧面；自动CAST、召唤及技能不是手牌出牌。

考瓦斯的冲锋和吸血是实际关键词。回手触发读取本人真正完成的物理出牌及原提交时有效Outcast关键词附件，不把后来区域中的实体面当成原牌。有Outcast关键词与本次是否处于手牌边缘分别处理，文本的“使用一张流放牌”不要求激活边缘奖励。普通回手沿既有生命周期清理局部增益、重新获取手牌；沉默、满手和玩家边界仍由原内核负责。

酋长只读取真正完成的原声明攻击，不把裸CombatDamage当成攻击，也不接替已取消或替换的攻击。原combat玩家决定友方资格，来源本体仍须存活。新纯查询 `completed_minion_keywords` 只读取同一原战斗驻留的当前关键词，或唯一对应的冻结自然死亡记录；不会以同ID重新入场的实体、后来印刷卡面或默认空集替代丢失的原材料，无法证明时明确拒绝。既有攻击、伤害、死亡、费用、回溯与保存执行器均未替换，也没有新增攻击记录字段。原攻击结束时的关键词/死亡窗口沿用本地政策，国服边缘校准后置。

莉亚德琳在本人实际召唤事件后核对当前存活友方目标与来源攻击，严格低于时，向同一个捕获的MinionReference分别授予圣盾及突袭。两次效果复用GrantCapturedKeyword；第一个效果的反应若让目标离开后再入场，第二个不能冒用新驻留。相同攻击不触发，本体自己不会因自身召唤得到奖励。

萨瓦丝只接受真实原生成功弃牌的DiscardRecord；对原保留实体增加+2/+2，随后由既有弃牌回手器交付。原手牌属性及费用保留，新的真实手牌获取可以再次弃牌成长；旧弃牌材料不能冒用新获取。原手牌期限、溢出、揭示、选择恢复和事务回滚遵循已有保留弃牌契约。

本批仅为酋长增加有限纯查询，其余主体组合现有效果。完整效果、必要恢复/回放和信息边界的实际结果只在 [项目状态](project-status.md) 与 [机制台账](mechanism-backlog.md) 维护。版本/热修与国服规则边缘暂缓，数据存在和内部专项通过不表示完整正式池、732整源或全局发布验收已完成。
