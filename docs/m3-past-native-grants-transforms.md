# 过去真实授予、变形与合体消费者

本批沿完整过去传说732张原名单，接入大导师野爪、米米尔隆的头部、龙骑士塔瑞萨、腐鳃、无敌五个真实主体。原十二根前审中其余七根继续保留，见本批 `dependency-source-boundary-01.json`；没有按实现程度裁剪原候选、角色或权重。实际进度及执行证据只在原两份台账维护。

完整固定客户端记录及已取得的完整主站响应保存在 [数据文件](../data/cards/past-native-grants-transforms-v1.json)。V-07-TR-0N 是实际物理衍生随从；拟态变形、唤起兽群是两个真实抉择显示面，仅 `choice_only`，不作为可生成法术。附魔和塔瑞萨的空白 effect dummy 仅作原始证据，不注册为空白法术。两抉择面的主站查询无可用结果，完整失败响应已保留，使用固定客户端面，不冒称主站确认。

大导师野爪复用原抉择解释器。第一项按原牌库顺序捕获本人当前野兽/全种族随从的物理引用，再交普通 `BuffStoredCard`；第二项用原友方野兽谓词与 `TransformMinionIntoCopy`，复制当前材料，不触发新战吼。既有两者兼得来源按印刷顺序先牌库增益，再变形；没有新造组合机制。无有效目标及原来源自选采用原 `IF_AVAILABLE` 语义，精确国服窗口待验证。

米米尔隆的头部仅在本人回合开始检查当前友方普通活跃机械/全种族随从，至少三个时捕获全部合格实体并交一个 `DestroyBatch`，再以原来源和头部原位置普通召唤 V-07-TR-0N。死亡反应、场位、数量和满场由原内核处理。休眠排除、全部而非任选三个以及原位置是明确本地政策。衍生物的完整原文给出冲锋与超级风怒，使用既有四次攻击关键词。

塔瑞萨从本人当前手牌龙/全种族随从中按每物理实体一个权重普通随机一次，先 +3/+3，再授予实际递归亡语。为这个真实需求，只在原 `GrantDeathrattle` 末尾追加可空 `stored_card`，保留原五个位置字段及验证：仅永久、普通主体、有来源、ID一致的原 HAND `CardReference`。执行先验证原印刷随从面，再核原连续区域引用；移动或离开再重入失效。安装复用原 `_grant_to`，保存、复制、沉默、回手、死亡与能力退休继续沿原附加器生命周期。没有新 Effect、载荷或平行亡语执行器。

手牌授予通知使用新 `stored_deathrattle_granted`，加入原 owner-only 事件集合，随原玩家归属裁剪；即使对手曾见过该牌，也不公开此次手牌附加变化。通知不携带私有附件身份。增益反应中原牌离开手牌，后续旧引用不会授予新驻留；该时序是待国服校准的本地政策。

腐鳃捕获原其他友方活跃随从驻留并普通授予亡语；每次实际亡语再对当时友方活跃组普通 +1/+1。无敌两次真实主体共用普通随机增益与嘲讽，排除自己、按当前亡灵/全种族判断；复生由原内核产生一血基础新实体，不额外战吼。空候选不抽样。精确死亡、控制与复生先后保留为待验证边缘。

本批不完成恋旧风潮整源绑定，不认证正式标准合法性、完整专用池或国服校准；版本及热修对齐仍按用户要求暂缓。原十二根中的施法、抽牌/洗入复制、死亡波与记忆需求继续按真实公共契约推进。
