# 过去自然法术的基础效果依赖

`data/cards/past-nature-basic-effects-v1.json` 保存十四张原始可收集法术、五个具名衍生物及已有 CS2_013t 的二十条完整原行和原生定义 pin，并保留二十八个完整官网主面观察。原始法术是先知者沃当前德鲁伊完整八十五项名单中的必要内容；名单没有按实现进度删减。

法力组 BOT_054、BT_130、CS2_013、SCH_427 分别组合现有双方满水晶增长、本人空水晶增长、刷新和过载。生物计划对双方独立按实际容量裁增长，不制造法力过剩。野性成长和过度生长在执行时读取本人的永久 `max_mana` 与实际 `mana_cap`；达到永久上限时只交付一张原 CS2_013t，否则按普通空水晶增长，部分可增长仍不补发过剩牌。该零费法术继续使用原抽一张效果。

临时法力不能替代永久水晶触发上述过剩。暴雪在 [21.2 补丁说明](https://news.blizzard.com/en-us/article/23712592/21-2-patch-notes) 明确修复了野性成长和过度生长的这项错误；[社区法力说明](https://hearthstone.wiki.gg/wiki/Mana) 也区分已经达到永久上限与仍有有效增长。本地将这一规则推广到原引擎已有的可变上限；部分增长不补过剩是据该说明采用的本地解释，精确国服边缘仍未校准。雷霆绽放零费先刷新两点，再沿普通过载记录和下次本人开始锁两点，不新建资源账户。

LOOT_047 使用普通生命上限增益和施法者三点护甲。UNG_108 先对原友方目标加一攻一血，再在普通结算后读取该目标的当前攻击获得护甲，不使用印刷攻击。TOY_805 接受原本人牌库全部随从的物理引用，逐张交 `BuffStoredCard` 降一攻和一费；手牌、对手牌库及法术不在该原组内，原伤害、生命、费用下限、附件、驻留失效和私人通知均由旧执行器处理。额外通知下的护甲读取窗口继续作为本地时序政策登记。

EX1_161 先用原消灭与死亡流程，再由施法者对手普通抽两张。目标可以属于任一方，但抽牌者始终是施法者的对手；原亡语等待和结算继续位于这次消灭的后续效果之前。

所有具名衍生物按原父卡 `COLLECTION_RELATED_CARD_DATABASE_ID` 对应的原 dbfId 保留，不能因为外观或名称相近而合并：

| --- | --- | --- |
| BAR_533 | BAR_533t | 两只 1/2 嘲讽野兽 |
| BOT_420 | EX1_tk9 | 两个 2/2 树人 |
| EX1_571 | EX1_tk9 | 三个 2/2 树人 |

固定入场交给原 `SummonByCard` 和完整 `SummonCause`，正常数量、容量、死亡、实际交付和恢复仍由公共管线负责；手牌树人用普通两次原交付，满手照常爆牌。Arbor Up 的后续读取召唤结算后的实际本人活跃随从组，包含成功到达的新体，满场仍增益原在场随从。自然死亡的原伤害受法术伤害加成，树人身材不受该加成。

本批仅接入这些真实依赖。先知者沃的完整八十五项来源及其他尚未核对的自然范围继续使用原显式关闭政策；不能把十四张的增量或登记数量表述为完整来源已支持。固定正式版本、热修对齐和国服边缘按原目标暂缓，具体剩余项仍仅在两份原台账维护。无新公共内核、Effect、payload、状态字段或 snapshot schema。
