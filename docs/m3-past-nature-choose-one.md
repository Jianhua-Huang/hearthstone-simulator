# 十张过去自然抉择法术

`data/cards/past-nature-choose-one-v1.json` 保存十张真实根卡、二十个原始选择面、八个具名随从及六个附魔证据的四十四条完整原行，另有二十二个完整官网主面观察。AT_037t、TSC_650t、TSC_650t4 保持既有完整定义和生成元数据；新增的具名随从是 DRG_311t、CS2_231、SW_422t、TRL_254t、ULD_135at。相同外观的树人没有合并身份。

根卡使用现有 `ChooseOneSpec`、真实分支 ID 和显式 combined 分支。分支在出牌、目标和支付前选定，保留根卡的唯一出牌和施法记录；二十个 choice_only 展示面不作为普通手牌或生成元数据登记。普通选择通过 `PlayCard.branch_id`，不会在已付款之后再用一个普通 RequestChoice 冒充抉择。

水晶之力的英雄分支依据[玩家实测记录](https://linuxtest.hearthpwn.com/forums/class-discussion/druid/232587-that-fandral-crystal-power-interaction)：可以指定英雄，但伤害部分不生效。该项是社区依据，未国服校准。随从先受伤再治疗沿原死亡检查点，已死目标不能因后续治疗复活；伤害和治疗分别使用原 SPELL 类型。

召唤先于增益的合并顺序参考[社区讨论](https://eu.forums.blizzard.com/en/hearthstone/t/choose-both-effects/1822)，每张分别显式声明，不由通用层机械拼接两个分支。分支 ID、完整原面均保留；缺乏有序客户端脚本时，普通展示顺序采用根卡印刷文字的选项顺序。这些精确顺序仍是本地政策，不能据此认证官方随机序列。

普通纯召唤选项使用已有 `requires_board_space`，满场时不能手动选它；参照[抉择规则说明](https://hearthstone.wiki.gg/wiki/Choose_One)的不可用选项处理。仍有其他实际效果的合并分支不要求空位；纯召唤的划水好友合并分支仍需至少一格。混合“召唤及原随从增益”在没有既有合法随从目标时采用 IF_AVAILABLE 本地政策：召唤继续，原目标增益跳过，不事后重新选择新召唤随从。该边界继续登记待验证。

目标增益在原主体接受时捕获 `BoardPresenceReference`，沿已有 `BuffCapturedMinion` / `GrantCapturedKeyword` 执行。若先前召唤反应使原目标回手并重新入场，新驻留不接收旧增益或嘲讽。播种施肥的群体增益在召唤及其反应完成后捕获实际本人活跃随从组，因此新树人可获得加一攻；之后的逐个增益仍保持各自原驻留。数量、容量、随机、死亡、选择恢复、回放与玩家投影继续使用原公共管线。

两者兼得权限由原活动来源和原出牌/CAST 接受窗口冻结，途中范达尔等来源离场不会重选分支。手动与自动 CAST 使用相同声明，自动来源不制造第二次付款或分支卡 CAST。

十张根卡属于先知者沃的完整八十五项德鲁伊过去自然名单；本批不开放裁剪后的来源。其他未实现依赖、正式版本/热修和国服边缘仍按两份原台账推进。没有新增公共内核、Effect、payload、状态字段或 snapshot schema。
