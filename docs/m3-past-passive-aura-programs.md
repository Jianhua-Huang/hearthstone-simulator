# 真实持续提供者与永久玩家效果

本契约对应[固定完整资料](../data/cards/past-passive-aura-programs-v1.json)中的十个过去来源，以及实际灌木雏龙 `REV_314t`。两张海纳泽尔保留各自真实身份；淤泥桶 `WW_044t` 复用已有定义和使用、弃置、消灭效果。十三份完整原始行和二十六份完整双语主站响应保留，不按可执行覆盖裁剪原732张参考名单。本批不是完整标准池或国服规则认证；执行结果只在原两份台账登记。

格林达复用原友方手牌随从回响光环，实际出牌接受后由原临时入手、最低1费和回合到期管线生成复制。逐罪者凯尔萨斯复用原每三张随从的实际出牌历史。来源后来入场不会重置历史；法术和其他牌型不冒充随从计数。

暮陨者艾维娜只增加 `any_first_card` 的有限费用声明：双方分别在自己的当前回合，第一张实际从手牌使用的牌设为0费。`FirstPlayCostFact.kind=None` 仅用于此声明，查询既有完整出牌前缀，覆盖随从、法术、武器、地标和英雄牌。英雄技能及自动施法不新增手牌出牌根。既有按随从、法术、种族和实际CAST计数的分支保持；没有新增玩家计数器。

泰瑟兰使用 `friendly_outside_starting_deck` 的确切减4费、最低1费声明。`StartingDeckCostFact` 冻结实际报价的玩家、物理来源、时钟、分配界限及双方完整初始牌库实体清单。清单来自真实开局 `OpeningState`，不从卡名、当前牌库或创造者猜测。同名新复制拥有独立物理身份；纯生成报价没有物理来源和初始清单。没有开局记录的物理Scenario显式报未支持。原有 `CostContribution` 只增加末尾可空字段，实际付款、等待、恢复和回放继续共用原费用管线。紧凑历史校验将双方清单与原开局逐项比较，拒绝裁剪、改序和借用其他物理对象；不会按今天的光环重新计算已付款金额。旧七种费用双方关系的匹配表保持。

海纳泽尔两面各提供法术伤害+1，以及友方法术吸血；波普加只对印刷邪能法术提供吸血及减2费，并通过普通入手获取两张确切淤泥桶。新增的 `friendly_spells`、`friendly_fel_spells` 关键词范围只接受吸血、无附加条件的有限形状。手牌显示、实际健康包和整段随机分摊预算查询同一来源能力。实际普通伤害由原健康器计算吸血，不使用事后监听伤害再治疗；多个提供者合并一个关键词。自动施法和淤泥桶实际弃置、消灭伤害同样使用原健康来源。既有手牌附加关键词、非施法分摊及已冻结的伤害包政策保持。提供者存活与精确国服逐段窗口暂按本地健康管线记录，未冒称已校准。

托匹奥的真实战吼通过 `AddPlayerEffect` 安装永久玩家程序。程序只响应本人实际完成、主体已启动、未中断且无失败的自然CAST，沿普通 `SummonByCard` 召唤真实3/3突袭龙族雏龙，不额外施法或伪造出牌。原来源死亡、沉默或转控不转移已安装程序；多次真实战吼分别安装、普通场地容量负责溢出。召唤原因继续使用共享 `SummonCause`；来源后来特殊变形时的分类边缘保留待国服验证。

伊丽扎的真实亡语安装永久玩家攻击光环，作用于当前及将来的活跃友方场上随从。它不是依赖原随从存活的光环，也不是写入手牌或牌库的永久增益。多次实际亡语分别叠加；提前触发亡语沿既有执行器，沉默移除原亡语后不再安装。

因扎的真实战吼安装普通无限次玩家减费。适用身份来自固定完整原始源中98个正值 `OVERLOAD` 标记的物理卡面，保留全部原行、顺序和哈希，包含尚未实现效果的身份。该名单是结构条件，不能算作98张效果已实现；不另开狂野接卡范围。非目录动态合成卡面的过载身份需要实际语义调查，不能据此静默认证。原过载支付及减费叠加继续共用已有执行器。

只增加一个不可变费用事实载荷，没有新Effect、GameState账户、命令或第二套结算器。新增两项玩家程序沿原归属、附着、选择恢复和信息投影。双方玩家DTO不公开初始牌库清单或私有报价证明。原池身份、角色、顺序、权重及未知项报错政策保持；版本、热修和国服边界按本轮目标暂缓。
