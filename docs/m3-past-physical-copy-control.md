# 原选中随从的复制、沉默与控制归还

[固定资料](../data/cards/past-physical-copy-control-v1.json)保留夺心者卡什 DRG_308、星界使者塞雷西亚 BOT_555、无名者 DMF_116、纳亚克·海克森 AV_331 和腐烂的普雷莫尔 BAR_540 五个完整原根、恋旧风潮的独立来源证据及完整过去传说参考。原始行、双语官网响应、身份和角色不随实现覆盖裁剪；这些跨系列效果由标准来源实际可达，不能据所属系列排除。资料存在、内部执行和正式生成资格仍分别登记。

卡什与纳亚克在既有 `DeathrattleMemory` 末尾使用空默认的 `selected_subjects`。每项保存实际战吼ID、原来源与原目标的完整物理分配、原目标连续在场引用、捕获窗口及有限角色；卡什另保存原目标的基础复制材料。写入发生在普通控制转移通知之前，反应立即杀死纳亚克时也能够读取原选择。每次真实战吼分别捕获；没有目标是已知空结算，不能替未知材料造空白随从。

卡什保存的是原选择时的印刷基础身体及固有材料，后来目标的增益、变形、离场或死亡不改已保存配方。延后召唤使用原 `remembered_copy` 的有限 `base` 形状；实际请求必须匹配已执行的原生选中复制亡语、完整原配方及该次亡语的接收者，不能借即时 `board_copy` 放松原接受窗口。原组合部件、固有数字和普通召唤数量、容量、位置、入场与回溯继续由已有模块执行；不执行复制对象的战吼。原始记忆不因提前触发或一次实际亡语而消费；当前复制保留原记忆，基础复制、沉默及回手按原生命周期清空或退役。

纳亚克先记住目标当时的控制者，再交普通原目标抢夺；这份记录是原选择，不伪装为转控成功收据。亡语只归还原连续在场实例，不按原拥有者、当前载体控制者或后来同ID的新驻留重选。目标同一驻留中的变形和控制变化保留链接。归还复用从旧控制层移除路径提取的同一个公共分支：有空间时转移原实体，原活跃随从面对满场归还时进入普通消灭，休眠原体有空间时也可归还。休眠并且归还方满场继续保留原来的显式未支持死亡政策错误及整动作回滚，等待后续规则边界核定；不静默跳过或重选。

塞雷西亚读取真正完成的对方随从出牌，沿原入场引用查找同一物理实例，再使用原当前复制变形。本人出牌、效果召唤与被反制的出牌不触发。原对象已经离场、休眠或将死时采用本地跳过政策，不借后来同ID的新体或猜测最后可见材料。精确国服离场窗口仍待验证。

无名者使用原当前复制变形，首次变形通知前设为4/4，随后只沉默原选中对象。两端均保存原引用；变形自己的旧引用不会把沉默转向自己，反应令原目标离场后也不对其后来驻留补做沉默。原能力、数值、伤害与生命周期的重置仍交现有变形和沉默执行器。

普雷莫尔读取实际友方死亡的冻结关键词，包含真实授予的嘲讽。普通复活材料只新增有限 `remove_keywords=(Keyword.TAUNT,)`，要求原嘲讽死亡、原来源和接收者，不能混入其他关键词、设值、附加主体或额外属性授予。每个实际数量体在首次入场通知前消费局部嘲讽，保留其他印刷能力和固有身体；以后回手、沉默及外部持续光环仍遵从原公共层。持续嘲讽光环与特殊入场的精确国服边缘保持为本地待验证政策。

core848/schema666使新增原生记忆与有限请求形状具有明确保存身份。旧记忆种类和字段保持原规则，新种类不能混入成长、抽牌、消灭组或囚禁材料。完整原始战吼、配方和内部链接不进入玩家DTO。新载荷与三个有限效果由原解释器注册；没有新增命令、全局选择计数器或另写复制、控制、死亡及召唤结算器。实际执行、验收证据、已知差异和下一项只维护[项目状态](project-status.md)及[机制台账](mechanism-backlog.md)。
