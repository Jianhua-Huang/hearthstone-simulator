# 过去卡牌的物理牌库、手牌消费者

[完整资料](../data/cards/past-physical-inventory-v1.json)保留亡语者布莱克松、砰砰机甲、湮灭战车和当前郭雅夫人的四个完整卡面，另保DAL_070e与MIS_701来源证据；共享prepare核六条完整客户端行及十个完整中英文主站面。附魔证据不注册，原过去732成员、角色和来源不裁剪。

布莱克松调用原 `SummonFromZone(count=3)`，沿完整本人牌库物理库存筛选费用至多5的印刷亡语随从，每次实际入场及反应后重新查询。两处公共查询现在向已有 `matches_metadata` 提供真实印刷亡语布尔值；没有新增查询字段或平行计数器。当前采用原印刷费用/亡语政策，牌库减费、额外授予、沉默及持续费用的精确国服筛选边界仍待验证。

砰砰机甲为本人牌库中每个物理随从捕获一个完整 `stored_copy/current` 材料，保持重复实体的独立权重和原牌不动；通过原 `SummonByCard(selection='random')` 普通复制，不执行战吼。只将已有 `on_summon` 开放给DECK/current、无额外设值/创建授予的有限复制形状；其他手牌、base或混合形状仍拒绝。原 `ContinueCopiedMinion` 绑定每份实际交付及原连续驻留，召唤通知与反应结束后交 `GrantKeyword(RUSH)`。转控、休眠或离场后的续接沿已有存活接收者政策，精确国服边界独立记录。

湮灭战车从完整本人手牌中普通招募一个机械或万种族随从，不要求候选自身有亡语。它在实际原交付者的既有续接中调用 `TriggerDeathrattles`；无亡语时正常为空，有亡语则沿原接受/重复管线。来源已经死亡不取消该次请求；原数量、容量、物理材料、入场和等待仍由公共解释器执行。

郭雅夫人按固定快照的“选择一个友方随从，召唤你牌库中的它的所有复制”实现。实际战吼捕获本人牌库中相同当前卡面ID的完整物理引用，按原牌库顺序交原 `SummonStoredCard`；原目标保留，后插入的牌不追加，失效旧驻留不改选同名新实体。没有可选目标或没有复制时正常空结算。跨版本身份等价、精确顺序及中途变更仍属待国服边界。
