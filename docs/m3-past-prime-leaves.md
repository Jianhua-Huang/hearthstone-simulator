# 四个终极族的原亡语与具名生成身体

[完整资料](../data/cards/past-prime-leaves-v1.json)保留瓦丝琪、卡加斯、兹克索尔、坎雷萨德四个原根与四个实际具名终极身体，以及三条辅助证据，共11完整原行、18完整双语官网主面。父卡的 `COLLECTION_RELATED_CARD_DATABASE_ID` 必须逐一等于对应终极身体的原 dbfId；终极身体都是非收藏随从，不能因此取得普通构筑资格。原过去732名单、其余终极族和其他目标域保持。

四张父卡的实际亡语分别返回原 `shuffled` 包装的 `AddToDeck`，接收者和语义发起者使用本次亡语控制者。它们创建确切注册的终极卡面，经过普通随机插入、来源和逐张通知；不把升级解释成抽池或同名白板。提前触发、重复亡语、控制、沉默和区域处理沿公共执行器。

瓦丝琪两面都有印刷法伤1；终极面通过三次 `DrawMatchingWithCostReduction` 抽本人物理法术并各减3费。每项保留原抽牌/原手牌驻留、烧牌、抽到施放与补抽、选择续接和费用下限；无匹配法术不额外抽非目标或制造疲劳。

卡加斯两面都有突袭。终极面只读取真正完成的原攻击、原来源连续驻留及该攻击范围内的 COMBAT 伤害/剧毒致死事实，再交普通 `GainArmor(10)`。英雄目标、防御反击、非战斗消灭或后来另外造成的死亡不借用原攻击。存活来源和接受时控制者遵从既有攻击触发政策；同时死亡、控制变化的精确官方窗口继续待国服校准，不用后来实体生命反推原结果。

兹克索尔两面都有突袭；终极面返回三项有来源的普通 `CopyMinion`，绑定原连续在场引用。每项在其真实执行窗捕获当前材料，复制保留当前属性和附件，不执行新战吼。来源中途移动或离开再回来不重绑新驻留，数量与容量由原复制/召唤器处理。三次捕获与反应之间的精确官方窗口仍按这项明确本地政策记录。

坎雷萨德原体使用原 `CostAuraSpec`，令本人当前恶魔随从牌费用减1，保持连续来源、叠加、下限、沉默与转控规则。终极面以 `DeathQuery`/`Resurrect(count=3, distinct='death')` 处理一份冻结的本人恶魔死亡库存，每物理死亡一个权重，普通复活重建印刷身体，不带旧伤害/增益或重跑战吼。当前模型在同一次库存内不放回，后一次施法不消费旧墓地；精确官方放回/权重、死亡卡面种族和数量窗口未由正文单独认证，保留为待国服差异。不能因此删掉池成员或只在有三条死亡记录时才支持卡牌。

这批只增加卡牌适配器，没有改公共健康、复制、洗牌、费用、复活或解释器。未知内容继续明确报错；有资料不等于全部效果、全部生成依赖或正式标准资格已验收。进度、实际检查和下一项仅在[项目状态](project-status.md)与[机制台账](mechanism-backlog.md)维护。官方[终极随从介绍](https://news.blizzard.com/en-gb/article/23369565/ashes-of-outland-and-the-demon-hunter-are-now-live)支持具名洗入和升级关系；固定完整原行及双语卡面是本批正文依据，公告不证明未公开的内部抽样/时序规则。
