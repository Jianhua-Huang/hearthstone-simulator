# 真实过去法术的原牌招募与不同随从复活

[完整固定数据](../data/cards/past-recruit-resurrection-v1.json)保存动物保镖SCH_610、补水区VAC_948两份原行及四份完整双语官网主面。两张均来自已取得的教师参考范围；动物保镖的德鲁伊/猎人双职业保留，不另外生成标准构筑根。这里没有安装生产过去域，也不将本批有限实验库存当作完整卡池。

动物保镖以SummonFromZone提交两个原牌库招募，查询野兽且当前存储费用不超过5，实际成功的每个身体经原on_summon路径授予突袭。原牌移动到场，保留物理ID与原材料；不是抽到手里再免费打出，也不触发战吼。每次移动、额外召唤及其反应完成后才重新查询下一张，所以第一次召唤的反应可改变后续候选。满场、无候选、额外数量和跟进失效继续由原招募/召唤管线处理。

SummonFromZone新增显式cost_basis='local'，只允许带真实归因的、有费用上下界的本人牌库请求，且保持印刷攻击力筛选；默认printed与旧形状不变。RecruitBasis保留相同政策，每个完整原牌库库存成员保存当窗current_cost，包括不合格成员。原选择、随机前后状态、后续重新查询和全部支付/移动仍沿现有保存与事件证明验证；布尔费用、缺项、改换basis或与候选不符的数值均拒绝。这里的local只计算原存储卡base_cost与附魔，不把进入手牌后才适用的固有/玩家报价提前施加到牌库；与既有物理抽牌查询一致。

补水区以Resurrect(count=3, distinct='card', selection='highest_cost')提交一份真实原死亡库存。候选取死亡当时的友方控制者和实际嘲讽关键词；已经沉默掉嘲讽的不合格，后来授予嘲讽后死亡的可以合格，敌方死亡不混入。复活重建原生基础实体，不把后来授予的嘲讽自动带回来。复活的每个身体和数量跟进继续走原死亡材料/新实体分配管线。

新highest_cost政策要求真实归因和不同card身份，不能同时塞入预先截过的cost_extreme或外部death_ids。原接受窗先保留完整合格死亡；每轮在剩余库存重算最高费用，只在最高档按不同card_id选组，再在该组内选原死亡记录；选中后移除整个card_id，下一轮可以下降到较低档。唯一组/唯一记录不消耗随机，实际平局沿原RNG保存和局部复演。新死亡不进入原批次，空池和满场沿既有关闭政策。

[30.0.3官方更新说明](https://hearthstone.blizzard.com/en-us/news/24125212)中的不同随从调整与固定完整卡面一致；[公开论坛的沉默案例](https://us.forums.blizzard.com/en/hearthstone/t/endbringer-umbra-triggers-silenced-deathrattle-minions/153066)作为玩家线索保留。卡牌当前按印刷费用排序，跨Core/历史重印的不同身份按字面card_id区分；这两处比较政策及精确官方随机窗口仍未国服校准，完整数据已明确记录，本轮不等待实测或执行版本对齐。没有用社区线索认证正式完整规则。

新库存字段由core738/schema589区分，旧完整卡定义和旧生成库存不变；旧存档仍需原引擎。两张通过真实上层精灵教师发现和同一小学生自动CAST验证时使用独立实验过去域，原生实际执行不能替代未知生产域。实际验收、差异及下一项只维护于[项目状态](project-status.md)和[机制台账](mechanism-backlog.md)。
