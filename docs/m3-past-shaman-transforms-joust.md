# 萨满过去自然法术：变形与揭示比费治疗

[完整资料](../data/cards/past-shaman-transforms-joust-v1.json)保留风暴聚合器、衰变、突变、不稳定的异变、异变、始源之潮、惊爆异变和两个原始身份的治疗波，共9张牌；10条完整原行及20个官网中英文面分别核验。原0费突变只按明确证据归一缺失费用标量，不修改原行。全部萨满71项与联合174项来源保持，部分实现不能绑定为完整生成池。

## 传说池变形的有限公共入口

风暴聚合器要求从完整可收藏传说随从视图随机变形，不要求新随从与原对象同费。原TransformMinionsInZones仅支持费用档，因此增加有限cost_basis='none'声明，限定为有来源的普通场上组、完整传说随从查询、零费用偏移、不保留旧费用且无额外亡语授予。其他查询、储存区域和组合仍明确拒绝。

原prepare_transforms先捕获全部原物理引用并核定完整有序候选，再沿原TransformPoolTarget逐对象执行；不自行写随机数或变形结算器。新目标可含不同费用，原池权重保持。中途已离场的原引用跳过且不再消耗抽样随机；不把新生物补入原组、不把离场者拉回。原变形生命周期重置状态、保持场上实体身份，并不触发新面战吼、消灭或亡语。

旧printed/local费用档、保留费用、降费可用档回退、升费10费上限与原本高于10费的政策继续走原分支；新增声明不扩展这些公式。声明沿现有Effect/载荷保存，没有新增类型或额外持久状态；core820/schema640明确拒绝旧1～639存档。

## 真实消费者

衰变对原敌方活跃普通随从组执行减一费用变形；异变对友方组加一。突变与不稳定的异变只接受友方普通随从，惊爆异变接受任一普通随从并加三。始源之潮先接受敌方衰变组，再接受友方异变组，保留原公共两阶段局面政策。全部候选来自完整宿主普通池，不以本批接入牌拼池。

不稳定的异变同时声明印刷Echo标记和原HandRepeatSpec；后续同回合临时副本、原费用下限、实际支付及结束到期由既有手牌重复/生命周期负责。不能只贴关键词，也不自行创建没有期限或付款声明的副本。

两个治疗波身份各自走真实Joust请求，冻结双方牌库实际物理随从及原储存费用；严格本人较大才胜出，平局和空池遵循原明确政策。揭示不抽取或移动牌，不把对方整个牌库提供给玩家；完整原比较结果和原治疗目标进入回调，随后由普通SPELL治疗执行8或16点。待选期间不重新比较后来的牌库或费用。
