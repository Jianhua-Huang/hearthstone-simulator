## 存储武器耐久的最小桥接

`ModifyWeapon.stored_card`是末尾追加的可空原CardReference，原四个位置字段和默认装备路径保持。仅允许HAND/DECK、整数target_id与原引用ID一致、非负攻击/耐久增量；执行器要求原面确为武器并核对原玩家、区域、卡面及zone_epoch。原引用离开时沿原跳过事件，不搜索替代牌或新洗入武器。

原武器修改器继续分配普通攻击附魔、修改原物理耐久及刷新原属性/装备。隐藏存储变化使用已有owner-only `stored_card_buffed`事件与原玩家字段，不向对手发公开`weapon_changed`；装备路径仍发布原公开事件。无新事件类型、Effect、payload或GameState字段。当前复制、移区/装备、快照和回放沿原物理材料负责；不开放存储武器负耐久、死亡或丢弃材料的组合范围。

来源仅声明HAND后DECK再原装备的固定本地顺序；原武器在先前反应中离开/被替换则跳过，新到达者不卷入。新可空字段使用core835/schema653拒绝旧执行/保存身份，完整类型清单保持。
