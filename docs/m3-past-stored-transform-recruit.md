## 原物理库存的变形

拉法姆捕获原剩余手牌/牌库全部类型的物理引用，以普通完整传说随从池逐一替换。利亚姆仅捕获原牌库中局部费用恰为一的原牌，不选择手牌；材料和选择在本次主体窗口冻结。沃斯捕获原手牌法术和对手当前真实可玩职业，以 `class_mode='specified'`、职业枚举和 `include_neutral=False` 查询完整该职业法术。没有职业时明确拒绝，不默认为法师、当前己方职业或中立牌。

普瑞斯托捕获本人原牌库随从的物理引用及原攻击力、最大生命、局部费用，然后交现有 `TransformStoredFromPool`。既有完整保留数值的手牌形式仅扩展到牌库中、来源明确且目标是完整可收藏龙随从查询的有限形式。原共享变形重置旧身体与普通能力，并安装新的印刷身体、可移除的原数值和费用附件；没有第二个属性或区域执行器。队列等待后不重新读取后来的原数值，也不追随同实体 ID 的新驻留。

“原始数值”与先前局部增益的准确官方取值、局部费用与特殊固有费用、跨区域移除及外部费用光环的临界窗仍是已登记的本地政策，未声称国服精确校准。

## 费用排序和生成洗牌

`OrderDeckByCost` 验证完整唯一的本人物理牌库及每张定义，以当前局部费用分档，由高到低排列；同费用档用原 MT19937 等概率重排，单牌档和空档不消耗随机。旧位置知识沿公共信息层隐藏，最终提交复用原完整 `ReorderZone`。这次排序不记作语义洗牌，也不会为未来抽牌安装持续排序器。精确官方同费政策及特殊固有费用继续保留本地差异。

艾维娜使用完整普通传说随从查询，一次冻结十次有放回抽样，普通生成器安装每张费用为一的创建材料。`GenerateFromPool` 只新增确切传说随从、费用设一的来源明确牌库形式，其他原限制保持；不伪造攻击/生命授予以绕过旧声明门禁。十次实际插入属于原一个语义洗牌操作，随后沿原 `ShuffleDeck` 随机化当前整副物理牌库，使原来被排序的牌也重新随机。

现有随机插入组在最后整副随机化前捕获通知，精确反应窗口采用本地政策。旧语义插入来源是否同样要求整副重排，应按实际共享路径另审，不能用这张牌的最终洗牌替其他旧来源提供通过证据。容量失败、随机、创建与信息隐藏继续沿公共机制。

## 原招募与死亡历史

皮普希只有三个独立顺序请求：圣盾、突袭、嘲讽。每次读取仍在本人牌库中的完整物理候选，取出原实体，保留原材料、不战吼；已被前一个槽取走的多关键词卡不会再填后一个槽。容量与额外数量沿普通招募。当前采用公共查询的印刷关键词依据；牌库中额外授予/移除关键词及精确官方槽次序保留待验证差异，不冒称已使用当前关键词匹配。

巴萨莱弗查实际最近一个已经稳定结束的本人 `OwnerTurnRecord`，从该全局回合之后筛选本人控制者的实际场上随从死亡，初次本人区间从第一回合起算；不用奇偶推测本人回合。原冻结死亡材料中的当前亡灵身份决定资格，再把确切死亡 ID 交原归因复活请求。新身体沿普通基础复活，不承接旧增益或添加并行死亡计数。连续本人回合、重复死亡、场位和等待继续由原层负责；上个本人结束反应的归属窗口是本地边界。
