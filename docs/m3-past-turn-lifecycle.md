# 过去卡牌的回合、物理牌库及原攻击消费者

本批接入 FP1_013 克尔苏加德、VAC_340 饥饿食客哈姆、VAC_413 园林护卫者基利、VAC_446 挂机的阿凯、WW_357 老腐和老墓、SW_024 洛萨，以及实际衍生物 VAC_413t 岛栖鳄鱼。固定资料见 [完整记录](../data/cards/past-turn-lifecycle-v1.json)，准备及实际结果见 [本批验证](../outputs/card-integration-20261014/k725-past-turn-lifecycle/verification-01.json)。结果以原两份台账和最终验证收据为准；本文不预先宣称未执行检查通过。

## 来源和范围

八份完整客户端记录及十六份完整双语主站响应保留。基利两种语言的完整主站响应明确关联 `childIds: [113343]`；[官方媒体包](https://blizzard.gamespress.com/Hearthstone-Perils-in-Paradise---Press-Kit)也列出 `HUNTER_VAC_413t_enUS_IslandCrocolisk-113343_NORMAL.png`，因此使用确切的 2 费 2/3 猎人野兽岛栖鳄鱼，不根据前缀或名字替换为其他鳄鱼。阿凯原始行没有 ATK 标签，`attack` 保留为 `null`；两份完整主站响应均为 0，仅这一确切省略零值的字段归一为 0。

原 732 个过去传说身份、来源、顺序及池角色保持；MIS_701 仍只作资料证据，没有将部分实现绑定成完整来源。定义存在数不表示卡池资格、全部效果或正式标准支持。版本、热修和精确国服规则边界本轮继续后置。

## 共享执行

六个结束主体声明普通 `TriggerSpec('turn_ended', ..., EndTurnSpec(...))`，克尔苏加德为 `either`，其余为 `controller`。自然结束、重复及额外结束仍由旧解释器选择、接受和执行；主体不再用一次额外的事件玩家判断覆盖主动结束 profile 的 scope。老腐和老墓的开始效果监听真实 `turn_started`，只在实际自身控制者回合开始触发。

`turn_event_consumers.py` 的五个有限 Effect 只补充这些真实卡需要的当前查询和原攻击续接；没有新 GameState 账户、死亡记录、结算器、命令或玩家程序。存档 schema 668、内核 851 注册并验证新类型，旧格式显式拒绝。普通随机、原引用、属性、区域、尸体付款、复活、战斗和通知继续共用原层。

克尔苏加德在主体实际执行时读取当前全局回合内全部友方场上死亡事实，每次实际死亡是独立候选，不按卡名去重。原死亡顺序及完整 `death_ids` 一次冻结后交 `Resurrect(selection='first')`，每个新体用普通基础材料与数量/容量策略；接受后新反应造成的死亡不插入同一批尾部。来源本人死亡后，不从后来同 ID 新驻留重新索引一个来源；已经接受的普通复活批继续按原契约完成。

哈姆在主体执行时按敌方当前牌库中的物理随从牌均匀抽取，一个实体一份权重；空池不消耗 RNG。原 `DestroyStoredCard` 真正移除牌后才进入 +2/+2 的原来源奖励，不产生场上死亡、亡语、弃牌或尸体。来源奖励要求原控制者、卡面、epoch 和进入顺序仍对应存活场上体；原体离场或重新入场不借用奖励。

基利通过普通入手/溢出管线取得确切岛栖鳄鱼。亡语捕获当时实际控制者手中全部随从物理引用，依次授予 +2/+3，排除法术、牌库和对手牌；提前触发仍不伪造死亡。游客的原卡组构筑 profile 保持：生成或在场使用游客不临时解锁构筑权限，本批也不新增独立狂野构筑域。

阿凯在实际主体执行时查询当前其他友方活跃存活随从，按其连续场上驻留及本回合已完成的 `CharacterAttackRecord` 判断是否攻击。手动和强制战斗都计入，不用只表示主动攻击消耗的 `attacks_this_turn` 代替；前一结束主体刚完成的攻击也能被看到。新驻留重新判断；同一驻留换面或转控不抹去旧攻击事实。已选中的受益组使用原连续在场引用，后来新召唤体不插入这一组。

老腐和老墓的自身结束获得 5 尸体，自身开始先核原活体，再交 `SpendCorpsesForMinion` 的完整 5 单位门槛。不足不部分支付；成功后 `GainMaxHealth(5)` 同时增加上限及剩余生命，保留缺失生命，未伪装为治疗。付款接受后的奖励不因来源随后死亡而撤销。

洛萨先委托现有敌方随从随机选择器，再在同一处理器中委托原 `force_attack` 接受真实窗口；取得实际创建的 `CharacterAttackRecord.declaration.id` 后安装有限成长续接，不预测下一个 ID，也不在稍后取“最近一次攻击”。续接核对应 forced 窗口及原来源卡面/控制者/epoch/进入顺序；实际战斗、奥秘、目标替换、死亡和恢复全由旧执行器完成。成长沿既有克劳利使用的因果战斗/剧毒致死事实，且只奖励仍存活的原来源。普通主动攻击或外部强制攻击没有安装此奖励；空候选、取消、未击杀或来源消失都不成长。

## 保留的本地边界

阿凯把未进入战斗而取消的攻击视为没有攻击；洛萨按最终交付目标的本次战斗/剧毒致死来判断，而非任何后来效果造成的死亡。克尔苏加德的同刻排序、哈姆的精确公开窗口及复制/转控极端时序沿已有共享层的本地政策。这些可内部验证的契约不等于国服实测结论，仍需后续校准。
