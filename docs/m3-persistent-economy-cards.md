# 下一次技能、整局费用与开局法力效果

完整原始卡面与配方见[固定数据](../data/cards/persistent-economy-effects-v1.json)。本页只维护表达契约；实际进度、验证与下一项在[项目状态](project-status.md)和[机制清单](mechanism-backlog.md)。

喷灯破坏者向对手添加一次 `HERO_POWER` 类型的 `CostSpec(delta=2)`；梦缚信徒的战吼与亡语分别向原执行方添加一次 `CostSpec(set_to=0)`。两者使用 `AddCostModifier`，没有额外回合期限，也不绑定当前技能实体。来源离场、沉默或换技能不会撤销已建立修正；沉默仍移除未来亡语。一次实际技能支付消费全部匹配的有限次层，包括最终零费时；无效动作或结算异常沿公共事务回滚。多层加减/设值继续采用现有附件顺序，不另设卡牌特例；准确国服排序待校准。

洛用无到期、无有限用途的玩家 `AddCostModifier` 将 `MINION` 费用设为5。它影响当前和后续取得的随从牌，不改印刷费用、实体本地费用或其他牌型。来源死亡、沉默和换英雄不会删除玩家修正；后加的其他费用层继续走同一原报价、付款、收据与恢复流程。

伊瑟拉的 `OpeningHook('before_deal', ...)` 只从原构筑开局入口执行。它分别通过命名 `InvokeBehavior` 在实际执行时读取双方当前 `mana_cap` 并沿 `SetManaCap` 各增加5；双方原套牌中的独立来源分别执行。提高上限本身不给水晶。普通场景或之后取得、召唤、打出卡牌不会重演对战开始效果。原战吼交 `ChangeManaCrystals(player,3,filled=True)`，只给本方已充能永久水晶，服从当前上限和原账目。使用原开局/换牌、待选、随机、保存及回放，不维护第二套开局时钟。

净化祭司先以命名普通阶段定位当前本方英雄，再交无期限 `GrantHealthRule`：`HEALING / ADD / 2 / SOURCE`，`source_relation='friendly'`。筛选治疗来源的当前控制者，目标可以是任一方角色；不扩大对手的治疗。独立效果叠加，来源随从存续不再是条件，英雄替换沿原非印刷附件迁移。法术、技能、普通效果与吸血仍交共享治疗准备和实际结果层，遵守缺血钳制、转换/防护、归属和历史，不回写基础卡面或伪造额外治疗事件。

适配器仅组合既有公共请求；卡牌身份和完整卡面进入内容指纹。原内核、持久字段、保存布局和玩家命令保持原契约。其余真实费用过滤、敌方回合期间规则与持续来源归属按实际卡需求另行接入；本页不以这几张牌宣称这些整族均已完成。正式标准池、活动资格、有效热修及国服精确时序仍需对应证据。
