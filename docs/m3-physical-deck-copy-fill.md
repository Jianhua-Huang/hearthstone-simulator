# 阿莎曼的物理牌库复制填手

EDR_527阿莎曼的完整原行及严格双语主面固定在`data/cards/native-opponent-deck-fill-v1.json`：9费7/7盗贼野兽传奇，战吼以对手牌库中的卡牌复制填满本人手牌，每张费用减少3。未知数字标签4065原样保存，不据此猜执行语义。[官网卡面](https://hearthstone.blizzard.com/en-gb/cards/114527/)证明这项真实需求，不证明全部抽样和微观窗口。

`FillHandWithDeckCopies(player_id, owner_id, source_id, cost=None)`在执行时读取本人实际手牌容量与当前持牌数，接受一次有限剩余数量；打出本体已经离开手牌，进入战吼前的实际反应可以改变这一数量。没有使用全局固定10张，也不循环到永远补满。它先验证完整原物理牌库域和费用声明，再交既有`CopyMatching`逐张执行；不安装可收藏生成池，不抽走原牌，不消耗原牌库、不触发抽到时施放或疲劳。

`CopyMatching.cost`是新增的可选永久创建费用，默认None保持原请求行为；最低价选择仍比较来源持有者原报价，费用只作用于所得复制。每次实际随机选择前重查当前物理来源，每个物理位置一个权重，同名不同实体不去重；已有随机复制按可重复抽取执行。前次获取反应抽走、加入或修改源牌，可改变后面的候选及当前材料。剩余复制数量仍来自原接受窗口，容量变小沿原入手溢出烧牌，容量变大不追加新的数量。

实际复制继续调用普通`CopyCard(mode='current', cost=CostSpec(delta=-3))`。复制分配新的本人实体和附件，保留来源当前本地材料及原复制来源信用，不修改对手原实体；不复制来源玩家全局手牌报价。所得牌的永久独立减费在首次`card_created`与获取通知前安装，本人当前费用政策再按普通报价和付款执行，最低费用仍由原费用层计算。来源沉默、死亡或转控不移走已经交付的费用，已接受尾部仍归原接收者。

普通手牌允许的随从、法术、武器和地标共用这一交付路径；复制本身不使用或召唤卡牌，也不会执行被复制随从的战吼。空来源或没有剩余容量不消耗抽选RNG，没有抽牌/弃牌/场上死亡伪事件。费用声明对整个实际选取域先行核验，不通过重抽或裁候选绕开不匹配。工程数量预算沿原事务明确失败并还原支付、实体、信息和RNG。

等待保存已经交付的复制、费用与原剩余`CopyMatching`请求。恢复不重新创建第一份或重新报价原数量；后续来源查询继续使用恢复后的合法局面。来源原牌库实体ID、复制工作状态、费用配方、RNG和等待帧不返回玩家接口。接收者仅获得普通本人新手牌，其他玩家看到原入手事件和可见数量，不能据此读取复制结果或隐藏来源。

重复抽样、物理位置权重、逐次重查、当前材料保留、数量冻结及满手反应窗口沿用既有公共政策，仍需M6国服逐案校准。论坛重复结果只可作为调查线索，不当作随机权重或国服规则认证；内部测试只证明这份明确政策执行一致。正式标准合法池、完整实际可达范围和国服证据独立闭合。
