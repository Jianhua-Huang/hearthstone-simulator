## 一个抽牌执行器

`physical_draw_groups.py`只保存不可变的 slots、reward、原 draw_id、HandEntry 游标和原 HAND 引用。普通槽从牌库顶调用原 draw_one；匹配槽沿 zone_candidates、一次原RNG与 draw_one，空匹配不消耗RNG。每个槽及其全部抽牌反应完成后再推进下一个槽，不批量挪牌冒充多次抽牌。没有新增 GameState 历史、抽牌或费用账户。

`CapturePhysicalDrawGroup`沿原 DrawRecord 的 replacement_id 链寻找实际交付；成功 DrawRecord 与 reason=draw 的 HandEntry 同步追加，其有序前缀精确绑定原驻留。抽到即施放的根不是手牌选项，实际补抽的叶子可以成为该槽受益。额外触发抽牌没有进入这条替换链，不混入组后选项；先离手再抽回的实体也不会把旧驻留重绑到新驻留。

整组结束前不执行增益。奖励均返回已有 BuffStoredCard、ModifyStoredCost、MoveCard 或 RequestChoice；选择分支已经携带原引用，恢复后不重新抽牌或支付。候选列表每个匹配槽在实际执行时读取，前一槽反应能改变后续牌库、费用与种族。完整未知种族报错，不悄悄从候选删除。

各槽有一条原尝试或显式空匹配收据，index与有序收据严格一致，不能省掉普通抽牌尝试。执行及 FrameCodec 核对来源、原玩家、抽牌完成、替换链、原HandEntry前缀和不超前的驻留；这不为未签名存档提供外部来源认证。

## 保存、信息及待校准边界

新增请求和payload由 core-effects-v345 识别；schema275布局保持。旧core344即使schema相同也明确拒绝，内容注册表身份同样严格绑定。观察85、命令12、replay1保持。候选、原始开局、HandEntry游标、槽和奖励材料不进入玩家投影；选择只对选择者显示。

多种族按不共享类型排除、typeless不参与、当前牌库费用/当前有效种族、第一回合无历史、替换补抽的奖励归属、整组后奖励窗口、显式变形失去原始牌库信用及转交附魔/溢出均为已声明的本地执行政策，仍需相应国服精确证据校准。内部验证不能替代官方规则证据，固定37.0正式合法池、服务端热修和全部实际可达内容仍须另外闭合。

黑暗贿赂的转交仍遵守原MoveCard的明确限制：携带 `defining_hand_source` 的特殊手牌载体尚无支持的转交生命周期，遇到会明确报错并回滚；这是真实接卡缺口，不能由普通手牌转交验证推成整卡完整。后续接入其具体真实来源时必须补齐，不删除候选或静默跳过。

原生示例 `python -B -X utf8 -m examples.card_physical_draw_groups`使用六个真实根卡；龙鳞军备通过真实MatchSetup、换牌、苦花骑士灌注、技能加入翡翠传送门及正常抽牌验证身份，没有实验卡牌定义。该短牌库/额外复制数量是明确experimental构筑验证，现有传送门实验池不因此变成正式完整生成池。

谦恭审判的set_drawn_minion_stats奖励允许普通混合抽牌槽，整组完成后只对实际原手牌随从设定攻击/生命，费用不变。它与set_stats_cost_all保持不同操作，原匹配/替代补抽/烧毁和驻留证明不变。有限扩展及相关源见[真实消费者契约](m3-native-consumer-followups.md)，不是国服时序或完整池认证。
