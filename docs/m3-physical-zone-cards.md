# 弃牌、整批牌库销毁与召唤装备

龙鳞军备复用本页真实开局物理身份与face_replaced政策，分别匹配本人原始牌库及外来法术；同名新分配和复制不会取得原始信用，Scenario缺失原始事实明确报错。转交仍用旧MoveCard，完整范围见[抽牌组契约](m3-physical-draw-groups.md)。

本契约覆盖末日守卫、蒸汽清洁器和作战动员。固定37.0完整原行及审核配方在[卡牌数据](../data/cards/physical-zone-effects-v1.json)，行为在`hs_sim/cards/physical_zone_cards.py`。实际进度、测试、差异和下一项只在[项目状态](project-status.md)及[机制台账](mechanism-backlog.md)维护。

## 真实身份与公共效果

三张核心卡的构筑等价分别由官方目录的具名`copyOfCardId`关系与完整历史原行核对；不解释未知数字标签，也不从文字占位符猜脚本。[冻结来源](../outputs/card-integration-20261014/k30-source-evidence.json)保留原始关系，英文目录关系只能证明该目录中的身份，不能代替国服规则校准。

末日守卫声明印刷冲锋并返回`DiscardMatching(player_id, count=2, source_id=source_id)`。两次弃牌复用既有逐次随机选择，每次执行时重查当前手牌；第一张的原生弃牌主体、生成和待选可以影响第二次候选。没有两张时只处理实际存在的牌，不预抽两个固定引用，不触发场上死亡。

作战动员使用官方根DBF96916的`childIds=[1652,383]`，分别对应完整`CS2_101t`白银之手新兵和`CS2_091`圣光的正义。复用已有普通新兵定义，不创造核心别名；武器原行的`HEALTH=4`作为耐久而非随从生命。主体依次返回三个各含一个`SummonEntryMaterial`的`SummonByCard`，然后返回`EquipWeapon`。`materials`是候选集，不能用三个重复候选表示三次召唤；每次请求都携带实际`SummonCause`。数量、场地容量、等待恢复和装备替换继续由现有模块执行，满场仍可装备，换武器不刷新英雄已使用的攻击次数。

## 原始牌库信用与替换卡面

蒸汽清洁器读取开局已固定的`starting_deck_identity`，取双方全部原始物理实体ID的并集。在接受战吼主体时按玩家1、玩家2的当前牌库顺序捕获全部合格`CardReference`；每张牌即使受保护，也先验证其定义存在。没有真实开局材料的场景明确报错并回滚，不能将整个牌库猜为原始或生成。

当前内部政策保留双方开局原实体，即使它后来进入另一方牌库；新生成或复制的同名牌仍是新实体，不继承原始牌库信用。每个实体的私有布尔字段`face_replaced`记录显式替换卡面：场上`Transform`与存储区公共替换/变成复制入口都会置为真。同面替换和变回原名也不恢复信用，普通回手、区域移动、沉默和生命周期清理不抹掉该记录。

该字段属于物理接收实体，不从复制来源继承。普通复制创建新实体且保留新接收者自己的记录；将已有实体变成另一实体的复制属于替换，先使该接收者失去原信用。内在升级或换面若未经过显式替换入口，保持既有信用。这些原始牌库并集、显式替换与内在形态的区别目前有玩家第一手报告作为调查线索，尚未逐例获得国服校准，不宣称覆盖所有特殊换面例外。

## 整批销毁的接受与执行

`DestroyDeckBatch(cards, source_id=None, reveal=True)`位于已有区域模块。`cards`必须是不可变的牌库引用元组，不允许手牌引用、重复物理目标或非布尔揭示政策。执行前使用带`origin_state`的`FrameCodec`验证整份请求；超出结算预算明确报错，已过期的原引用沿既有引用政策跳过，不改抓同名牌。

执行器先将全部有效目标移动到墓地区，再按捕获顺序发布各自的原牌库销毁事件、揭示信息及原生被销毁主体。任意反应、抽牌、待选或调用方续接都不能插到两次移除之间，因此第一张的原生抽牌不会抽走本批另一个目标。反应中新加入牌库的牌不属于原批次。这里不创建场上死亡、尸体、亡语、复生或星舰贡献，也不制造弃牌、抽牌和疲劳。

原单张牌库/手牌销毁复用同一个发布助手，保留原`on_destroy`续接返回值及公开/私有政策；新批次没有为单张入口增加兼容分支。原生主体仍由既有捕获队列执行，异常事务回滚、待选保存、克隆和回放继续复用公共解释器。

## 保存与证据边界

内核执行语义为`core-effects-v335`，内容包`constructed-cn37-preview-v36`。实体新增`face_replaced`，schema271严格拒绝旧1～270及缺失/非布尔字段，不从旧存档推测变形历史。没有新增内核模块或`GameState`顶层账本；玩家观察85、命令12与replay1结构保持。玩家投影不返回原始牌库材料、替换标记、内部帧和完整历史。

字段类型、请求结构和历史一致性检查不构成未签名外部存档的来源认证。精确国服销毁顺序、变形/内在形态例外和全部实际可达池仍按M0/M6/M7闭合。

`python -B -X utf8 -m examples.card_physical_zones`通过玩家命令展示冲锋弃牌、三新兵和武器，以及真实开局、金萼幼龙灌注、技能洗入传送门再由清洁器移除。短牌库、显式法力和既有五成员实验龙池用于内部实验，不认证正式标准套牌或完整生成池。
