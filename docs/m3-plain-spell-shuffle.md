# 普通随机法术的语义洗入

宇宙具象使用现有`GenerateFromPool.shuffle_actor_id`保存真实执行者，生成完整合格池的一张普通法术后，直接把原`AddToDeck`材料交给既有`ShuffleDeckCards`。不经过手牌、不扫描后来牌库，不新增随机器、实体字段、载荷或区域处理器。空池不产生洗牌记录或随机消耗；缺少完整池、合格效果未实现或未知必要事实仍在抽选前报错，不能按可执行覆盖裁池。

无`minion_stats`时，该入口仅接受有原来源、可收集SPELL、可重复抽样、随机DECK交付；费用、临时牌、重复施法授予、召唤原因及其他额外创建形状明确拒绝。原固定属性随从洗入仍走原守卫；普通未分类随机插入的归因不变。实际交付复用既有语义操作记录、首个真实见证、发起者/接收者区分及保存核对，见[原洗牌契约](m3-semantic-deck-shuffles.md)。

宇宙具象本体为2费恶魔猎手暗影流放法术，完整固定行和双语主卡面见[固定数据](../data/cards/cosmic-manifestation-v1.json)。目标使用普通必选角色域；按原接受的流放条件，一次施法内执行一组或两组“对原目标造成2点SPELL伤害，然后随机洗入一张恶魔猎手法术”。每组独立查询及抽样，职业固定为恶魔猎手，不随当前英雄变化。沿现有版本族/来源排除政策，普通法伤、支付、反制、终局、死亡、插入反应及选择恢复交原执行器。

当前本地政策保留原角色目标；原目标已不存活时普通伤害不再生效，洗入仍可执行。它不重新挑目标或重算后来手牌位置。原生流放重复不增加施法/支付；其他真实施法重复仍由公共机制分配独立施法记录。精确国服重复目标、检查点和生成池仍未校准，不能由本文或内部测试推导整卡正式支持。

本次仅放开既有请求的一个有限形状，无字段布局变化；core418/schema337拒绝旧版本，观察89/命令12/replay1保持。玩家DTO不暴露洗牌来源、宿主完整牌库、随机状态或恢复队列。实际执行结果及下一项仅在[项目状态](project-status.md)和[机制台账](mechanism-backlog.md)维护。
