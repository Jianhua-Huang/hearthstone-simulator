# 本回合实际法术伤害计费

普通物理法术声明 `player_spell_damage_cost=PlayerSpellDamageCostSpec()`，有限 profile 为 `cost.player-spell-damage-turn-v1`。它消费[原法术实际伤害查询](m3-spell-damage-query.md)，按 payer、原全局回合、原 `SPELL`卡面及实际 `damage_dealt`减费，最低零。英雄承伤、不同派系数、施法次数、请求量或净生命损失不能替代此数值。

`spell_damage_costs.py`只负责费用输入和验证，付款、施法、伤害、死亡、区域及选择执行仍由公共内核处理。没有新玩家计数、账户、GameState/Player/Entity字段、伤害执行器、事件、动作或组合。其他固有数量/条件公式、非普通法术或未审核 profile 均拒绝。

冻结 `PlayerSpellDamageCostFact`保存原声明、payer、turn/action、实体/顺序/伤害游标、完整有序 `PlayerSpellDamageCostRow`及 quantity/before/after。每行引用原 `DamageRecord`，附原来源 `CardType`或明确无卡牌来源的 None，使不访问当前注册表的 typed 结构验证仍能重算数值；注册表验证逐行核对原来源类型，包括未计数记录。不能裁剪未命中行、改写源类型/顺序或借用未来物理身份。

该事实作为原 `IntrinsicCostStageFact.player_spell_damage`默认 None 私有叶，在本地、外部、最低费及支付货币层之前完成数量计费。物理报价、生成报价、合法动作和实际支付共用同一捕获入口。接受窗口重新读取完整原事实；已接受根只核对原前缀，允许后来合法新增伤害，旧付款不重新计价。进入新全局回合后新报价数量归零，旧历史与旧付款保持。

数量跨本回合中的获取时间，包含双方英雄与随从目标、护甲吸收及最终实际伤害。免疫、圣盾、阻止、零量、伤害转治疗及失效目标没有额外信用；普通治疗、增血或吸血治疗不重复计量。治疗转伤害按原法术来源及最终伤害计数。召唤物与英雄技能仍是自己的原来源，不向上追认法术信用。当前范围内未知正源明确拒绝，原系统疲劳和未知零源不取得卡牌信用；其他回合未知归属不阻塞当前范围，未知原卡面仍拒绝。精确国服来源和转换口径尚待校准。

JSON严格解析原行、原类型和新叶，typed frame沿已有冻结类型集合编码。独立注册表恢复、克隆、回放、等待续接与失败回滚共享原机制。完整伤害前缀、源种类及付款事实不进入玩家观察；玩家只看到允许观察的当前费用、动作和事件。内部完整性校验不提供未签名归档的外部来源认证。

[必要完整原行](../data/support/player-spell-damage-cost-basics.json)只隔离适配 `CATA_452`织法者的光辉和其原关联 `CATA_452t`碧蓝守卫：10费法师普通奥术法术，调用已有 `Summon`召唤原6费6/6龙。没有白板替代、任意生成池或生产代表包扩张。查询需求材料中的CATA_487没有因此得到适配。

新卡牌声明与私有费用叶改变定义指纹及保存结构，因此引入 `prototype-v292` / `core-effects-v291` / schema256，旧1～255明确需原引擎。观察84、命令12、replay1保持。费用层顺序、精准CN归属/窗口、正式卡池、完整阶段及其他基础机制仍分别开放。实际验证和下一项仅在[项目状态](project-status.md)及[机制清单](mechanism-backlog.md)维护。
