# 随机池随从的入场计时休眠

TIME_058渺小的振翅蝶为1费1/1中立野兽，亡语随机召唤一个印刷2费、休眠2回合的随从。本体没有休眠。完整根与两份官网主卡面在[数据包](../data/cards/pool-entry-dormancy-v1.json)。使用完整宿主可收藏随从池、任意职业，未知合格内容在随机前报错，不能改成休眠随从筛选或按可执行覆盖裁池。

`SummonFromPool.entry_dormant_turns`保存正整数计数，要求原来源、明确`SummonCause`和普通印刷材料；不与另附入场关键词组合。`PoolSummonBasis`保存同一字段，全部有序候选材料的`SummonEntryMaterial.dormant_turns`必须与原basis严格相等。原手动JSON解码、接受/完成事件、选择历史与恢复校验继续核对完整请求；独立预选批次没有这项声明，明确拒绝借用。

实际创建通过原分配器将计数传给已有`initialize_dormancy`，在首次入场通知与光环刷新前分配一个普通休眠实例。没有先召唤活跃实体再施加MakeDormant。覆盖普通原生初始计时/非永久无限期休眠是显式本地材料政策；永久休眠载体仍在完整材料检查时、任何RNG前明确报错，不裁池，不放宽已有永久休眠不变量。本轮没有为不存在的永久型实际来源创建组合开发任务。

数量额外体复用原所选材料，每个分配独立实体及休眠ID；自然亡语使用原死亡槽，活体触发使用载体右侧。控制者开始回合的原倒数、活跃性、保护、苏醒回调、原实体及入场次数均沿原休眠生命周期。等待恢复保留原选择和未完成交付，不再次抽样；异常整步回滚、克隆、独立注册表恢复、回放及玩家投影沿原管线。

只在一个已有请求和两个已有载荷各增一字段；无新effect/payload类型、状态、实体或能力字段。内核416/schema335拒旧schema，观察/命令/replay布局保持。未签名快照仍不认证来源。精确国服原生休眠优先级、入场/反应窗口及完整标准生成资格仍开放，内部方法通过不认证正式整卡支持。
