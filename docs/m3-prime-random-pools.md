# 莫戈尔格与索兰莉安的终极体随机池

[完整资料](../data/cards/prime-random-pool-v1.json)保留两个原本体、两个具名非收藏终极体和MIS_701来源证据，共五条完整固定客户端行与十个完整双语主站面。本体的 COLLECTION_RELATED_CARD_DATABASE_ID 逐一绑定确切终极体；证据不注册。原亡语通过既有 `shuffled`/`AddToDeck` 按实际控制者洗入具名新实体，普通抽牌、费用与区域生命周期保持。

莫戈尔格两面均有印刷圣盾。终极面接受四个独立的 `SummonFromPool` 请求，使用原 `constructed.minions` 的完整可收藏鱼人查询；每次普通抽选再走原数量、容量和通知管线，不触发所召唤随从的战吼。原 `SummonEntryMaterial` 已能在入场前安装圣盾，本次只让随机池入口接受严格类型的单项圣盾元组；旧嘲讽/吸血/突袭组合校验保持，圣盾与其他词条的未授权混用仍拒绝。四次来源、受益者与原因按原接受值保留，默认场末位置与逐次结算沿既有本地政策。

索兰莉安两面均有法术伤害+1。终极面接受一次五项 `CastFromPool`，每次重新查询完整 `constructed.cards` 中的可收藏法师法术，包含具有法师职业的双职业面；固定法师查询不随使用者职业变化。独立有放回抽选、自动抉择、费用豁免、失败尝试、奥秘与实际来源历史继续交原施法管线。已接受五项不要求原终极体继续在场。

core843/schema661仅在原 `CastFromPool` 尾部增加可选的严格 `AutomaticTargetPreference.ENEMY_IF_AVAILABLE`，要求真实source和随机目标政策，再交已有 `CastSpell` 与完整目标证明管线。每次施法优先合法敌方目标，敌方为空才从其他合法目标中选择；无合法必选目标按原失败尝试。没有第二套目标选择或施法执行器。旧固定五奥秘producer仍要求该新字段为None，不允许修改已绑定请求。

当前固定宿主查询包含23个鱼人和51个法师法术；资料记录完整有序成员、权重、原始行和行为来源。实际宿主模式标识沿已有 `experimental`，不声称正式国服标准资格已认证。生产查询不按实现程度裁剪，未知合格成员必须明确报错；逐成员测试驱动仅用于选择具体入口，不替换生产池。

随机四体的摆位/容量、终极体离场后的剩余施法、罕见控制与通知窗口沿上述明确本地政策；国服规则边缘及版本/热修继续暂缓。拼装候选仍遵守先前已记录的争议限制。完整过去732来源、MIS_701尚未绑定及其他开放域不因这两族完成而关闭。实际验收、已知差异和下一项只维护[项目状态](project-status.md)和[机制台账](mechanism-backlog.md)。
