# 兵主：原生符文技能与下一张法术奖励

[完整原始记录与双语主面](../data/cards/primus-native-spell-bonus-v1.json)保留兵主、三个技能描述、既有仆从和两条欧斯克参照，共七条原记录、十四个完整官网主面。技能原记录没有 COST 标签，官网两语主面明确为零；只将描述费用归一为零，原行不改。三个描述是 choice-only，不能成为手牌法术、CAST 或物理生成候选。兵主也不因此取得本轮标准构筑根资格。

[卡牌适配](../hs_sim/cards/primus_titan.py)复用三个 ActivatedAbilitySpec 和原泰坦行动。鲜血技能只选敌方随从，交 DestroyCapturedMinion；只有原目标实际被消灭，才按捕获的剩余生命给原来源增加生命、给原玩家英雄增加最大及当前生命。来源离场后自身增益不追随新体，独立英雄奖励仍由公共续接处理。

邪恶技能以两个独立 SummonByCard 请求召唤已有 TTN_737t2 仆从，保持其原定义、3/3、嘲讽和复生。每次实际入场分别处理容量、反应和死亡；不新增同名衍生物，也不以重复候选材料代替召唤次数。

自身 minion_ability_used 通知触发对应符文发现。发现查询当前宿主完整普通域中的可收藏卡及印刷符文，采用 runes_any，不按当前玩家职业过滤；法师通过鹰获得兵主也能发现对应符文牌。普通域既有三符文生成政策保留，精确专用来源例外仍待确认。未知合格候选须显式失败，不能按效果覆盖率裁池。

## 冰霜奖励的原生来源

冰霜技能使用原 PlayerEffectSpec(kind='next_spell_bonus')，下一张法术减三费并获得本次法术伤害加三。费用贡献、实际手牌接受、自动施法、反制、重复施法首次认领、显式移除及跨回合寿命继续使用[原配对程序](m3-next-spell-bonuses.md)，不另写支付或伤害执行器，也不提供常驻法术伤害。

原 AddPlayerEffect 只增加默认 None 的 ability_event 与 ability_source，分别为已有 Event 和 SourceAllocationFact。它们必须同时提供，只接受原随从 BOARD 来源，不混合健康来源、光环期限、存储法术、调查或发放集合。仅 next_spell_bonus 可以使用此来源。

材料从原技能接受时已冻结的 RuleContext 捕获，因此技能开始反应造成的死亡、变形、沉默或转控不会把已接受奖励改给新来源或新玩家。程序 id 必须等于原注册 ActivatedAbilitySpec.behavior_id，并同时核对技能 id、描述面、原来源、玩家、完整实际开始事件和分配边界。已经结束的技能不能再安装，同一实际开始事件不能重复安装。

选择恢复是后续命令，不能要求开始与安装拥有相同动作编号。校验要求原开始先于安装、动作号不倒退，并且对应实际 minion_ability_used 尚未发生；恢复后的原技能仍可完成。原战吼来源与旧安装收据形状保持，新来源使用私有完整事件、分配材料和原实例收据。等待帧中的已生成安装请求也核原来源；不认证未签名存档的外部来源。

两项私有 wire 字段采用 schema611，明确拒绝旧1～610；不增加 PlayerEffect、PlayerEffectSpec、卡面或实体字段，不增加效果或 payload 类型。玩家投影不能提供原事件 JSON、分配边界、私有收据或完整已认领材料。

## 保留范围

完整十二泰坦参考名单、身份及权重不变，艾泽里特鹰专用池和真实发掘 profile 仍分别验收。实现兵主不等于整个泰坦池或职业奖励递归依赖闭合。鲜血捕获窗口、控制变化后的后续触发归属、三符文发现资格及既有法术认领政策继续保留本地未校准边界；正式补丁和国服边界按用户授权暂缓。

实际执行、验收与下一项仅在[项目状态](project-status.md)及[机制台账](mechanism-backlog.md)维护。
