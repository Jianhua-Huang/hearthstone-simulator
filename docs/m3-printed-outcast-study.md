# 伊利达雷研习与下一张印刷流放牌

CORE_YOP_001伊利达雷研习为1费恶魔猎手法术，无印刷学派、自身没有流放。完整当前卡面、raw858明确连接的YOP_001/61939旧行及两份官网响应在[数据包](../data/cards/printed-outcast-study-v1.json)。旧行只作身份依据，没有注册占位旧牌；当前定义及池元数据的deck_identity规范为YOP_001。

发现使用已有独立OUTCAST关键词元数据与PoolQuery.keywords_all，按当前英雄加中立的可收藏池查询，牌型不限随从/法术。完整合格但未知的效果在任何RNG前明确报错；不根据Registry.cards裁池。当前英雄/来源排除等精确国服池政策仍待校准。

发现交付结束后才安装独立的、无回合期限的一次CostSpec(delta=-1)，条件为CardAbilityCondition(ability='outcast', basis='printed')。它适用于下一次匹配的正常卡牌支付，包括早已持有的牌及非手牌边缘位置；不是只改选中牌，也不要求本次流放激活。原Source本身不是流放，连续使用研习不会误消费前次优惠。烧掉发现结果或候选为空仍沿独立续接安装优惠；原反制、终局及异常解释器决定是否继续。

这个新增有限条件只读原不可变定义中的OUTCAST，拒绝current依据，避免把动态手牌位置当身份。matches_ability及matches_cost_values共同支持真实、生成和保存的费用遍历；原CostQuoteInput已有card_id/能力及完整贡献，未新增费用事实或存档字段。原战吼当前/印刷语义保留。PoolQuery.ability仍明确只接受原战吼条件；印刷流放候选使用已有keywords_all，防止把物理查询中的当前关键词误当新费用条件的印刷依据。

零下限、多个优惠叠加、匹配支付一次消费、非匹配及对手不消费、跨回合保留、反制后仍已支付/消费，均由原费用模块负责。发现与获取/价格通知中的等待、坏恢复、原接受事实重演、克隆、回放及玩家信息隔离沿原管线。Game.quote_cost仍只允许当前行动者的手牌/技能；内核纯报价与玩家DTO边界没有放宽。
