# 祖拉玛特牢房的原弃牌与后续使用

真实来源固定为37.0快照的JAIL_887、JAIL_887t2、JAIL_887t3及仅作原始证据的JAIL_887t2e。地标5费/3耐久，奖励为原5/5嘲讽，释放原8费8/8。此前已实现的5/5完整定义复用，不重复注册。完整原行、双语官网响应与原定义指纹随数据包保留；官网文字不是全部结算时序的证明。

## 原实体与公共执行

地标激活使用原手牌目标、`DiscardCard`及其成功续接；只有实际弃牌成功才请求5/5。耐久、冷却、末次离场和亡语仍由原地标与死亡模块负责。末次耐久的原死亡检查可能早于激活主体，释放的祖拉玛特不能在当时提前冻结只有前两次弃牌的列表。

`PrisonPlaybackState`放在原结束触发附件中，保存实际牢房死亡身份与本祖拉玛特已消费的弃牌 occurrence ID。原弃牌账本仍是唯一物理来源，绑定原实体及原场上zone epoch；末次移入墓地的激活主体同时核原死亡驻留。这样普通控制变更不会把同一牢房拆成不同来源，回手重放则属于新驻留。其它牢房、其它弃牌分别核对，不用全局按卡名搜索。普通当前复制沿原附件复制保留状态，回手/变形等基础重置沿既有生命周期丢弃附件。未从牢房释放的印刷祖拉玛特没有弃牌记忆。

每次实际结束主体在新局面接受完整剩余 occurrence、有序权重和随机状态，然后委托已有执行器：

- 随从使用普通按卡召唤，不触发战吼；保存原组件和青玉固有尺寸，沿公共入场、数量和容量处理。
- 法术在实际弃牌移区完成后、弃牌反应前保存完整当前材料，后续创建新物理法术并调用普通自动CAST；不搬动后来可能已改变的原墓地对象。
- 武器、地标和英雄使用原生成安装器，不伪造从手牌打出、支付、战吼或连击。

消费在执行器之前接受，每个祖拉玛特独立；容量不足、无合法目标等普通失败沿原管线处理。未知真实内容显式拒绝，不从原候选中删掉。其它结束主体、额外结束与召唤数量沿已有模块；这里不另建重复结算器。

## 保存和信息边界

原材料、候选、抽样前后状态、消费前后和唯一Finish为宿主私有事实。恢复重核实际结束执行、原牢房、完整候选和局部抽样，并核当前附件不能重置消费；挂起续接保留原解释器。公开DTO不增加私有记忆字段，私有诊断事件不进入玩家事件白名单。未签名快照内部一致性检查不能认证外部原始来源。
