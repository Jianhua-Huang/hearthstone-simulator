# 本地星灵法术完整候选域与原生费用消费者

本增量服务固定国服标准候选宿主的实际生成依赖。它不新增标准合法根，也不单独开展狂野补卡。验收结果与下一项以[项目状态](project-status.md)和[机制清单](mechanism-backlog.md)为准。

## 名单与证据

[完整资料](../data/cards/protoss-spell-domain-v1.json)保存固定本地23452条原目录中所有`collectible=true`、`type=SPELL`且印刷`PROTOSS=1`的七条完整原行：SC_750时空提速、SC_753光子炮台、SC_755建造水晶塔、SC_757幻像、SC_759护盾充能器、SC_760谐振盘、SC_761闪现。原身份、原标签、多职业和原无派系均保持。另保留SW_462炽热连击，以及真实3费3/4冲锋非收藏衍生物SC_751t狂热者。共9条执行资料、18份完整官网双语主面；SC_757e原附魔另保存完整原行作为证据，没有伪造独立可施放卡。

`constructed.protoss.spells`保留七个单位权重成员，包括谐振盘自身。`complete=true`只表示这一明确本地原标签域没有裁成员，不表示正式国服随机生成资格已确认；正式名单、重复权重和自生成禁令仍未确认。当前普通标准法术库存没有星灵法术，谐振盘必须使用此独立域，不以普通池的空结果代替奖励，也不按已实现子集缩池。

本地宿主在原46个有序池对象之后安装此域。池版本包含完整资料摘要，进入宿主库存和绑定摘要；旧池的库存、权重、顺序、查询、职业政策和标准根资格保持。原launch宿主不额外安装该池；只注册卡面不等于拥有其完整生成域，缺域继续显式失败。

## 最小公共费用范围

保留`CardAbilityCondition`既有字段与序列化，仅增加`fire_spell`和`protoss`两个正向印刷结构条件，供真实费用消费者使用。前者要求原定义为SPELL且印刷派系为FIRE；无派系是明确不匹配。后者要求原完整元数据的`factions`包含`protoss`；缺元数据或未知派系显式报错，不当作否定。两者只允许`basis=printed,present=true`，类型范围继续与`CostSpec.card_types`相交，不新建冻结ID白名单。

实体费用、原费用操作数证明和假想生成费用共用同一印刷身份判定；没有添加卡面、实体、玩家或保存字段。手动支付消耗匹配的一次折扣，读价、生成预览、非匹配卡和免费自动施法不消耗。符合条件的零费卡仍消耗一次折扣，原条件/支付证明不因之后局面变化重定价。现有战吼、流放、奥秘、法强费用条件保留各自语义，不把新条件开放给原仅支持战吼的池查询。

## 保留的规则差异

幻像当前在公共复制入场通知完成后授予双倍受伤；正式规则是否在入场通知前已带该附魔尚未校准。通知中对新体造成伤害、改变原体或移除新体等边界按公共复制后续政策执行，不据此宣称正式时序一致。卡文明确的复制后普通战斗双倍受伤、沉默移除和原体不受影响必须可执行。

光子炮台以原目标、原伤害结果与死亡原因为本地判断口径；伤害重定向、替代死亡和精确通知顺序继续待校准。派系折扣按印刷原定义，连击沿既有原施法条件，随机域采用明确单位权重。这些是可追踪本地政策，不是正式国服证据。

完整过去Mage179域与NX2_001/TIME_857原生产scope继续关闭，定义增加不等于其递归效果全部闭合。版本/热修对齐与国服规则边界依用户指示暂缓；其它专用域和未确认成员仍在原完整目标中。
