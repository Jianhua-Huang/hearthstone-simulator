# 真实卡牌的公共效果配方

真实龙牌的当前种族/赐福条件、分阶段移除和回溯伤害继续复用原管线；只为实际地标需求增加有限随机入口。候选、原死亡、恢复及待国服窗口见[契约](m3-dragon-native-effects.md)，生成资格仍独立核对。

完整来源见[九张原始卡面](../data/cards/public-effect-consumers-v1.json)，执行装配见[卡牌模块](../hs_sim/cards/public_effect_consumer_cards.py)。实际验收、已知差异与下一项仅在[项目状态](project-status.md)和[机制台账](mechanism-backlog.md)维护。本契约描述内部执行边界，不认证正式标准池或国服时序。

## 唯一公共范围扩展

`KeywordAuraSpec(Keyword.TAUNT, 'enemy_minions')` 复用原 `AbilityInstance`、当前控制者、派生贡献并集和刷新。此形状固定 `include_self=False`、无相邻、无条件及无种族或卡面过滤；其他敌方关键词和任意敌方范围仍明确拒绝。不是可消费关键词的循环重新授予。

目标来自当前对方的实际面板，沿原活跃随从筛选；地标、休眠体和非活跃占位不获得嘲讽。来源控制改变后改为新控制者的敌方；离场、沉默和休眠沿原能力生命周期移除贡献。其他固有或持续来源的嘲讽继续保留。内核没有新增状态字段或第二套光环执行器。

## 生命、复制与死亡

阿玛拉的故事是普通可收藏法术，不能因名称含“故事”推断为传说故事伙伴。它使用原属性层，设置当前及局部最大生命，不是受旧最大生命钳制的剩余生命赋值，也不是治疗；护甲、英雄实体身份及独立生命变化事实保留。原局部最大生命已高于40时仍按原设值层覆盖，持续最大生命修正的准确国服层序待校准。

暴徒双人组由原连击接受事实触发，只有实际随从出牌付款一次；普通召唤不触发连击。当前复制经过原附件、容量与召唤管线，不另执行战吼、连击或原付款。源被移除后不跟随同名新体。

末日使者之杖的原始 `HEALTH=6` 是武器耐久，不是随从生命。武器替换、耗尽和显式消灭仍交普通装备/死亡协调器；亡语执行时捕获当前有效随从，休眠和地标保持。逐个死亡、亡语等待、失败回滚与恢复沿原批处理，不写卡牌专用死亡循环。

## 原攻击、随机和物理牌序

补给官复用已完成的 `CharacterAttackRecord` 和原来源存活截面；取消、裸兼容战斗、其他角色攻击不冒充本体完成攻击。攻击互伤致死时不奖励是已有本地存活政策，仍待对应国服证据校准。

嘉沃顿的故事调用原完整八项额外效果机制，不另建随机候选；原已拥有的关键词和场上突袭准备度政策继续有效。随机、失败回滚、等待恢复和重复申请由原模块负责。

越时因果对当前实体ID做完整逆序，不复制卡牌、不洗牌、不消耗随机、不重建区域驻留或费用附件。既有 `ReorderZone` 校验完整排列及私有事件；玩家不得从全知快照读取对手牌库身份。

## 保存与证据边界

本次采用 core374/schema299，拒绝旧schema1～298。没有新增 `CardDefinition` 或其他模型字段，也没有新 effect/payload 类型；版本变化声明新增光环作用域的规则差异。玩家观察87、命令12及回放1保持。原1059完整定义和默认311定义指纹必须保持。

中英文官方卡面比对证明数据身份和文字对应，不证明全部国服层序、热修、标准资格或实际可达内容闭合。三条原附魔记录仅作来源证据，不注册为可打出的牌。活体疫病、尼珊德拉及其尚未明确的真实需求继续保留，不能借本批通过宣称它们已完成。

## 穆拉克与无穷香蕉的普通效果配方

`TIME_042`的实际战吼开始时捕获本人当前手牌的完整`CardReference`组，逐张交给普通`DiscardCard`及其反应；全部原请求结束后用`AddToHand`获取`TIME_042t`。不借用默认只弃一张的`DiscardMatching`，也不在每次反应后重新扩大整手牌的原捕获组。此前出牌提交反应已经产生的手牌属于战吼开始时的当前组；弃牌途中产生的新牌不追加入原组。普通召唤不执行战吼。

香蕉是可指定双方随从的普通一费法术，主体依次执行`Buff(+1,+1)`与`AddToHand(TIME_042t)`。实际支付、反制、原目标、重复主体、自动施法、容量/烧牌、等待恢复和回放均使用已有管线；每个接受的主体分别产生一张新的基础香蕉，原物理法术正常离手进入墓地，新牌不继承原单卡减费或临时期限。不是回响，也没有新增原实体常驻手牌的规则例外。

官方双语卡面只确认文字和命名依赖，未确认实体语义。[2026-10-12玩家一手反馈](https://us.forums.blizzard.com/en/hearthstone/t/king-maluk-infinite-banana-glitch/166764)观察到重复施法后多张香蕉入手，可支持复用生成流程的方向，但不是官方开发者裁定或国服校准。本配方的新副本、原弃牌组、反制及精确入手时序仍列为M6本地政策。`TIME_042te`只保留原始附魔证据，不注册为可执行卡。本次没有公共内核、模型字段、Effect或存档布局变更，实际进度和验证只在两份原台账登记。
