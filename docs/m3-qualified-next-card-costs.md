# 下一张指定牌的费用与本人真实开始禁疗

本页维护表达、保存和边界契约；实际进度、验证与下一项只在[项目状态](project-status.md)和[机制清单](mechanism-backlog.md)。五张真实卡的完整原行和配方见[固定数据](../data/cards/qualified-next-effects-v1.json)，实现见[卡牌适配](../hs_sim/cards/qualified_next_cards.py)。

## 费用资格复用原付款管线

`AddCostModifier`及其持久`CostModifier`增加三个有限字段：`combo_only`、`temporary_only`、`maximum_cost`。前两项及既有种族筛选分别独立使用，不为任意组合扩展接口。连击和临时筛选要求有限用途；完整价格上限只允许带种族限制、有限用途的纯生命支付转换，不参与数值变化，避免用自身改变的价格循环判断自身资格。已有随从种族筛选允许减费、固定价格及上述生命支付。

- 狐人老千：当前物理牌的有效、未消费连击能力决定结构资格，不要求这次连击已激活；新生成候选按完整印刷定义判断。减2与当回合到期、实际付款消费仍由原公共层负责。
- 洞穴专家：临时资格来自该物理手牌的`HandLifetime`，同名普通手牌不匹配。整组换手的租约不自动成为临时关键词，未取得实际临时期限的假想生成卡也不匹配。未使用减费没有额外回合期限。
- 提克迪奥斯：本回合下一张当前恶魔随从设为0。英雄免疫是原生持续关键词光环，由当前来源的沉默、控制和离场生命周期管理；战吼已经交付的减费有自己的期限。
- 速逝鱼人：下一张当前鱼人随从的完整当前价格不超过3时改为生命支付。先用全部数值层及原手牌最低费用求完整金额，再判上限，保留有序贡献和原支付/用途收据。后续减费、加税都影响资格；0费仍消费一次用途，免疫不免除生命支付。

物理报价的`CostQuoteInput`保存完整原`HandLifetime`，并校验原最低费用；手牌离开HAND后的已接受法术报价继续带原期限和下限，不借当前区域重造临时资格。匹配、生成报价、付款证明及恢复校验共用这些材料，预览不消费用途。未知卡面或种族信息仍明确报错。

当前种族依据、完整价格阈值和各数值层的精确排序是明确的本地规则政策，须以对应国服证据校准；完整原行的文字不能单独证明全部交互窗口。

## 禁疗到本人下一次真实开始

`GrantHealthRule(..., until_owner_turn_start=player_id)`只支持英雄载体，并与全局回合到期互斥。它复用`OwnerTurnExpiry`和原真实owner时钟，将期限保存在健康规则附件的`health_rule_expiry`；不新建回合账本或健康执行器。

环形山鳄鱼给当前敌方英雄安装目标侧`HEALING/PREVENT`规则，原期限绑定施放者。来源死亡不结束已交付的规则；英雄替换沿原附件复制保留原期限。其他玩家的额外回合、跳过的本人槽位不触发到期；本人紧接的额外真实开始会到期。到期在开始事件及反应接受前统一移除，治疗、防护、吸血结果、等待恢复和回滚继续走公共层。精确国服开始反应政策待校准。

## 保存、玩家接口与演示

当前格式由`serialization.SNAPSHOT_SCHEMA_VERSION`声明；新增嵌套期限和报价材料使用严格解码，旧格式需原引擎读取，不静默迁移。原观察、玩家命令和回放外层协议保持，完整期限、报价操作数和恢复帧不得进入玩家DTO。

`python -B -X utf8 -m examples.card_qualified_next`通过玩家命令演示五张适配及各稳定位置的独立恢复、clone和回放。洞穴专家场景使用一个显式标为“非正式卡牌”的临时牌生产夹具，生成真实雪人；夹具不进入生产注册表或正式池，不冒充已实现的真实生产卡。正式标准池、完整可达内容和国服官方校准仍须分别闭合。
