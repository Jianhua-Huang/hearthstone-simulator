# 任务的有限区域状态订阅

治愈荒野与征战时光之末使用两个具名、有限的状态订阅；它们复用原QuestStageSpec、QuestProgress及AdvanceQuest，没有另一套计数器、事件日志或通配回调。

## 声明与接受

`QUEST_FULL_BOARD_TURNS`对应`state:full_board_owner_turns`。普通通知提交后，原任务监听路径检查当前玩家确为任务持有者、真实本人回合记录仍开放，以及物理战场占位已达到实际Ruleset.max_board。尚未消费该本人回合ID时才保存脱离当前状态的进度回调；回调沿原AdvanceQuest以`owner_turn:<id>`去重。因此随从、地标和休眠载体使用同一场位依据，不把全局回合奇偶当本人的实际区间。

`QUEST_FULL_THEN_EMPTY_HAND`对应`state:full_then_empty_hand`，只能用于目标2的单阶段声明。原进度为0且手牌达到hand_capacity(player, rules)时接受第一步；原进度为1、已有full键且手牌为空时接受第二步。玩家独立容量和实际Ruleset默认容量均参与，不写死10。回调分别交full/empty键给原AdvanceQuest，不把此前空手倒算为第二步。

两种订阅在既有通知点检查实际区域，不依靠枚举入手、出牌、弃牌、移区或容量改变的所有来源名称。只在条件成立时分配原RuleContext快照；普通具名事件任务保留原路径。没有新增可执行的state事件，也没有对所有事件都分配进度回调。未知state策略、混合state/具名事件声明及错误手牌目标明确拒绝。

原回调保留当时已接受的条件，较早反应改变区域后不重新计算这一接受。原实例/阶段及completing保护仍由AdvanceQuest处理，移除后的旧回调不影响后来任务；奖励仍是普通AddToHand与FinishQuestStage，等待期间保留完成中的原槽位。

## 两个真实消费者

TLC_239以三个不同本人区间为目标，满场激活及下一本人开始时仍满场可按本地政策计数。奖励使用已经完整实现的TLC_239t永茂之花。

END_017以满手、随后空手为两个有序里程碑，容量修改和物理手牌转移与普通抽取/弃牌使用同一检查。奖励使用已有END_017t提克和托克。两张奖励定义逐字段固定，不重新注册，TLC_239e只保留原始附魔证据。

这些接受窗口、满场跨回合和通知反应顺序是待M6核对的本地规则，不作国服认证。正式池及全部可达内容也须独立闭合。
