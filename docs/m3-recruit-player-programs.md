# 白银之手长期数值来源与消费者

三张实际来源共用原PlayerEffectSpec、AddPlayerEffect及可叠加PlayerAuraSpec：MEND_800突袭、亡语使新兵+1攻击；MEND_801圣盾、每次自身实际shield_lost使新兵+1生命；MEND_803武器战吼使新兵+1/+1。程序属于原接受玩家，源死亡、武器替换和英雄更换不退役它；盾丢失须命中原来源，不以别人的圣盾事件或沉默移除后失去的触发补发奖励。

PlayerAuraSpec只新增scope字段。默认active_board保持原活跃场上随从含义；controlled_minion_cards必须带非空、明确卡牌ID列表，连续作用于当前控制者的HAND/DECK/PLAY/BOARD普通随从卡，包括休眠实体。星舰建造载体不在此范围。效果是原加法层的派生贡献，当前卡面、控制变化、沉默、回手与当前/基础复制沿原属性/区域生命周期；不将来源的派生缓存复制成局部永久属性。精确国服区域/转手/复制数值窗口仍待校准，内部合同不代替官方规则证明。

休眠校验仅允许与当前注册程序重新计算完全相同的贡献，普通休眠仍须零光环；不放行任意正数缓存。存储卡首次通知前，在本地创建授予后计算当前玩家贡献，再冻结观察者上下文，不插入额外健康检查点。全场重算继续沿原refresh_auras，不新增战斗、随机、支付或创建执行器。

完整原源固定九个Silver Hand Recruit身份；现有CS2_101t实际定义严格pin并复用，另外八个仅为具名谓词证据，不因此变成可执行卡。新scope允许声明尚未适配的具名成员，已登记成员必须是随从；尝试实际创建未知身份仍明确报unsupported card definition。旧active_board注册校验保持。六条MEND附魔原行分别证明来源持续说明和实体数值说明，只作证据，不计物理卡或适配。

MEND_802沿两个原生SummonByCard请求召唤新兵并授予可移除圣盾。MEND_900沿四次原生请求召唤，再沿四次普通AddToHand交付新兵；场位不足不取消后续入手，满手依原烧牌政策。所有新实体获得当前玩家数值贡献；候选列表与召唤数量是两个概念，不把重复候选传给单次选择请求。原接受、占位、额外数量、待选、失败回滚和回放继续使用原管线。上述交付先后与精确国服复合窗口保留M6。
