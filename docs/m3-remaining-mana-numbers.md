# M3：剩余法力决定原生手牌数字

开锁匠JAIL_501使用[完整固定原行及双语官网主面](../data/cards/remaining-mana-numbers-v1.json)。原始数值为1费1/1，实时战吼显示槽保留为@；官网只省略该槽，完整规则文字保持。原始答复[ClayByte](https://www.reddit.com/r/hearthstone/comments/1u1ifvd/comment/oqq89cc/)说明所有数字最低为1；该答复不证明完整国服时序或修饰层顺序。

## 原生来源与普通数值层

RemainingManaNumbersProfile声明真实原生随从。印刷能力remaining_mana_numbers及remaining_mana_card_id沿普通沉默、复制和重置生命周期，不添加GameState、Entity或CardDefinition字段。只在物理手牌中，将原生基础费用、攻击和生命同步为max(1,当前控制者剩余法力)；普通局部增益、减费、设费和支付账户继续交原执行器。

同步不分配附件、不掷骰、不发明获得属性事件。事件前规范化和普通刷新共用同一纯状态操作，查询和玩家观察不改动局面。离开手牌后保留当前材料；普通召唤使用印刷1/1，当前复制保留冻结材料，回到手牌后按真实接收者资源重新同步。沉默在移除原生能力前恢复印刷身材，费用材料仍沿普通费用政策保留；该层序属于待国服核对的本地契约。

## 实际付款与冻结战吼

正在接受的物理手牌在付款中保持原数字，其他手牌应立即反映扣费后的资源。实际pay_quote使用只包围同步付款的payment_window；实际事件与独立付款投影均向同一规范化函数传入该原来源排除。付款内没有选择等待，排除标志不会承担跨等待的语义状态；付款结果、原物理材料和完整前后状态仍由原付款证明保存和比较。原反制、支付账户、用途消费、回滚及完成流程保持共享。

普通BattlecryPayload增加可空remaining_mana_number，实际原生战吼捕获时冻结一次。手牌出牌在付款前捕获；效果触发从实际原载体材料捕获。历史重放直接携带原标量，不从后来改变的法力、身材或新载体猜测；缺少原始标量时明确拒绝。卡牌主体仅对合法敌方随从调用普通Damage；没有目标的正常可选战吼复用原空目标规则。

稳定边界检查当前手牌缓存、原付款法力基础和声明/标量匹配，恢复沿原FrameCodec与完整模型校验。玩家接口不输出内部来源字段、冻结标量或对手未知手牌。core565/schema459拒绝旧1～458；观察101、命令12、replay1保持，没有新增Effect或显式载荷类型。
