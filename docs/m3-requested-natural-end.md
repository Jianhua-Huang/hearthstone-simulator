# 真实法术请求的正常回合结束

快刀乱斩JAIL_500的[完整原行及双语主面](../data/cards/slice-and-dice-v1.json)支持5费潜行者传说法术、“再次使用在本回合中使用的所有其他牌、尽可能以敌人为目标、结束你的回合”的正文。完整官网响应与精确规则证据的界限见[来源记录](../outputs/card-integration-20261014/k271-slice-and-dice/rule-sources-01.json)；下述接受窗口及重放政策是内部契约，仍待国服校准。

卡牌只组合`WholeCardHistoryQuery`、`ReplayWholeCards`与`RequestNaturalTurnEnd`。历史查询使用原施法者本回合已经完成的真实手牌出牌，保留原有序物理次数，排除该卡面；自动施法、效果召唤和对方出牌不伪造新手牌历史。重放使用既有完整实体激活profile及`ENEMY_IF_AVAILABLE`，支持随从、法术、武器、地标和英雄的实际主体，参数、当前连击/战吼条件和选择沿已有解释器，不另写卡牌层结算器。排除所有同ID卡面、原有序资格及生成主体保留政策不冒称开发者确认。

## 为什么不能在卡牌主体里直接结束

整卡重放返回后，原法术仍有CAST、付款出牌、触发与选择的完成工作。直接执行结束阶段会让回合时钟越过这些原工作，也不能靠宿主再发送一次玩家结束动作弥补。`RequestNaturalTurnEnd(cast_id)`只为真实正在执行的原法术创建结束义务，并把`FinishNaturalTurnEnd`追加在当前解释器队列尾部；请求本身是诊断透明工作，不额外插入游戏事件或检查点。

`NaturalTurnEndRequest`保存原CAST、真实`OwnerTurnRecord.id`、接受事件游标和完成状态。原区间身份不能只用玩家ID代替，同一玩家的额外回合也是另一个区间。同一CAST幂等；不同CAST可以各有请求，第一个正常结束原区间，其余只能标为`stale`，不能再结束新回合。已经处于正常结束阶段或不再处于该施法者原回合的请求不新增义务。

尾工作检查原施法、出牌、整卡重放、死亡暂缓、选择和英雄致死屏障都已退出，队列余项只能是其他结束尾工作。随后委托原`EndTurnPhase/end_turn`，共用结束触发、解冻、期限失效、本人时钟、额外/跳过回合和正常下一回合开始。它不复制任何阶段执行器。

## 保存、恢复与终局

`GameState.natural_turn_end_requests`是一个必要的源绑定义务列表；没有新分配计数器。四种状态为`pending/applied/stale/interrupted`，严格验证原CAST、原玩家区间、事件游标、实际`turn_ended`或`game_ended`。正常完成前不允许冒称已经结束。

稳定边界核对全部待处理请求与有序尾工作一一对应，尾部不能移动到其他工作之前。付款后选择还核对原`paid_hand_choice_boundary`，保存、独立注册表恢复、clone、回放和失败选择保持同一义务。真实投降/终局沿原中断清理关闭尚未执行的请求；重放造成致死并在请求前结束时不创建虚假回合结束。无签名快照不提供外部来源认证。
