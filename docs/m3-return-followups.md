# 原随从回手与成功续接

真实CATA_201暮光主母需要把敌方随从移回拥有者手牌，EDR_523欺诈之网需要成功回手后召唤实际4/4潜行蜘蛛，CORE_DAL_720摇摆矿锄需要随机回手的同一实体获得减费。END_021次元武器匠与TIME_100沙漏侍者复用存储卡牌增益，前者还需要武器攻击力。完整原始记录和审核配方见[内容数据](../data/cards/return-hand-effects-v1.json)，实际验收及下一项只在[项目状态](project-status.md)与[机制台账](mechanism-backlog.md)维护。

## 原物理实例和真实成功

ReturnCapturedMinion保存现有MinionReference(entity_id,player_id,card_id,zone_epoch,entered_order)，执行时验证注册随从卡面与原控制者/区域/卡面/进入次序。仅原实例当前存活、active且不是惰性交互物时执行；离场再入场、变形或转控不把指令转给后来的实例。卡牌规划阶段捕获有序原对象，群体逐一回手，中间反应不能把原尾项重选为新的敌方对象。

该适配直接调用原ReturnToHand处理器，继续共享目的手牌容量、非死亡移动、印刷重置、成功入手历史与可选本地费用。to_owner=true按原拥有者交付，false按原当前控制者交付；暮光主母和摇摆矿锄分别明确声明这两种真实口径。正常成功先重置旧身材/伤害/附件，再沿原改费安装减2；没有复制实体或由卡牌自行扣费。

处理器实际使原实体进入目的HAND才接受on_success不可变Effect元组。满手失败仍由原处理器标记普通死亡，保持原控制者/owner/死亡材料，不产生成功续接；失效原实例也没有续接。成功被接受后，card_returned反应可以先执行或等待，并可以合法再次移走该牌；已接受的蜘蛛召唤继续执行。它取决于已发生的回手成功，不要求随后还在手牌中。错误选择、后续异常和整次动作回滚仍由原事务处理，恢复不再执行一次回手或重复召唤。

EDR_523的成功门槛、休眠排除、所有原窗口/满手行为仍为明确待国服校准政策，不把内部执行正确当成官方时序认证。

## 随机原候选

RandomReturnCapturedMinion保存有序不可重复的MinionReference集合与可选原CostSpec。执行时验证每张注册卡面，过滤已失效/非存活的原实例，以实体ID排序复用公共RNG选择一次；每个物理实例一个权重。空池保存原跳过通知且不消费RNG。

实际random_choice通知后，后续ReturnCapturedMinion携带选中的完整原引用与原减费。随机通知反应可暂停等待或使该目标转控/离场；续接失效时跳过，不重新抽选另一个对象。随机选择、选择帧、RNG、返回和付款沿原快照/回放体系，没有额外随机器、选择库存或新的顶层台账。摇摆矿锄明确回到当前控制者手牌，而非强制原owner，借来的友方随从使用同一政策。

## 存储武器攻击

BuffStoredCard继续使用CardReference守卫，额外允许物理HAND/DECK武器的攻击力增益；武器health必须为0，DiscardRecord仍只支持原随从材料。武器耐久不由生命字段修改。原Enchantment、费用、到期、refresh_entity与私有stored_card_buffed通知沿原路径，正常装备保留这些攻击附件。

次元武器匠捕获本人原手牌中的随从/武器，各加2攻击；其他类型排除。沙漏侍者使用已有EndTurnSpec本人自然结束能力，捕获本人原手牌随从各加1/+1，不给武器加耐久，也不在对手结束时触发。

新效果类型和武器数值资格由core-effects-v314标识；没有改旧保存字段布局，schema268、观察85/命令12/replay1及规则302保持。MinionReference复用已有注册，不重复安装同一payload类型。玩家投影不提供原引用epoch、接受续接、存储材料或付款证明；正式池、全部可达内容与国服校准继续独立处理。
