# 双回合仪式、原倒计时与真实完成事实

[完整三行和六份中英主面](../data/cards/rituals-v1.json)固定BE_005充盈仪式（3费暗影术士史诗法术）、BE_085召唤仪式（2费暗影术士普通法术）及BE_085t克拉西斯蛮兵（非收集4费3/5嘲讽）。原标签的印刷计数为2，主面保留全文而省略动态@值。原行/脚本值、完整响应及字节收据保留，仍用既有显式显示规则核对，不将空显示解释为零回合。

两根使用原`ongoing_effect_id`安装原生`PlayerEffectSpec(kind='ritual',duration=2,tick_event='turn_started')`。这次有限profile只声明两个后续己方真实开始；原开始窗口先捕获待扣实例，再发布开始反应，之后各实例按原次序扣减。对方开始和本人结束不扣次数，同一开始反应新装的实例不能借用已捕获tick。共享秘密/任务/持续效果区域的容量及原支付/CAST保持，重复卡有独立实例。

原计时器最后一次实际扣减先移除原实例、释放其位置，再在原`player_effect_expired`发布前冻结一个`RitualCompletion`。State新增私有`ritual_completions`与`next_ritual_completion_id`，记录完整最后实例（剩余1）、玩家、真实回合/owner_index、动作和原发布位置。原私有`_ritual_completion`与行逐项绑定，拒绝缺行、重复、改借实例、未来时钟及缺少原到期证明；重新计算JSON哈希不会绕过结构检查。普通移除/取消与其他种类的计时到期不算完成；空抽牌和满场不抹去真实已到期事实。`completed_rituals(state,player_id)`是纯查询，其他真实卡可据此消费，不能扫描宿主事件或以当前已无持续效果推测完成。

完成事实在到期监听者和原payload之前可查；原payload依旧调用普通物理抽牌组/减费或两次固定召唤，原数量额外体、入场反应、死亡、支付、待选和回放不重写。失败事务恢复时钟、实例、完整历史及游标，选择失败保留原待选。到期继续项通过`from_expiry`核其完整原实例。私有事实不进入玩家DTO，公开计时与到期只沿原四字段协议。

本批采用己方开始计数、先释放位置及记录完成、后到期反应/payload，抽牌减费和两原召唤沿已有窗口。印刷文本与脚本计数不证明所有时序，精确国服扣减、完成可见、触发/自然抽牌顺序及容量/放置政策仍待M6；不能把所有OBJECTIVE或计时法术归为仪式。core633/schema521拒旧1～520，原Effect/payload类型集合及动作13/观察115/replay1保持。默认仅增加两个空历史字段、core/schema及对应hash；旧玩家声明和默认指纹保持。内部一致性不是未签名保存的外部来源认证，正式池/可达域仍归M0。实际结果和下一项只在[项目状态](project-status.md)与[机制清单](mechanism-backlog.md)维护。
