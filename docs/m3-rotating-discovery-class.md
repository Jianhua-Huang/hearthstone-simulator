# 手牌战吼的可变发现职业

蔽影密探 `CATA_614` 使用原生战吼参数选择法术职业。完整来源与两个完整官方主面在 `data/cards/shadowed-informant-v1.json`：2费2/2、中立、龙；原始数据有“你的职业”和动态职业名两个完整正文。源核验工具只为固定完整原行省略分隔符和运行时职业名，保留两段正文，不截取其中一段。

`RotatingDiscoveryClassProfile` 注册一个真实随从来源，要求其声明普通手牌本人开始监听与战吼。原生 `AbilityInstance(kind='class_discovery')` 保存来源声明和职业字符串，印刷附件创建时取实际控制者英雄职业；不改印刷中立标签、英雄职业、牌库构筑资格或通用职业条件。没有新玩家/对局账户，也不把这个参数伪装成费用或关键字附件。

手牌监听复用 `HandProgressSpec` 的真实 `turn_started` 见证；只在原持有者的开始执行。`RotateDiscoveryClass` 绑定原手牌卡面、玩家、实体、区域周期、原生附件和原开始事件，并要求已接受的进度见证。同一物理附件不能重复消费同一开始。牌库、场上、对手开始或跳过机会不变更；额外真实本人开始计一次。移区或附件失活使旧继续项失效。

当前从11个普通构筑英雄职业中排除前值，均匀选一个新值；中立、梦境不进入这个随机域。完整有序域、前值、结果和MT19937前后状态保存于私有收据；恢复核原开始、局部抽样、连续值和实际载体末值。观察与合法动作不抽样，等待失败或整次动作失败沿原事务回滚。精确初值时点、是否全局/所有区域同步、本人开始窗口、排除规则和转手政策仍待国服校准，不能据本地随机政策认证官方规则。

当前复制保留原生参数，基础复制和重建取接收者实际英雄职业；沉默、变形、重置和引用失效沿原生命周期。`BattlecryPayload.discovery_class` 在普通战吼接受时冻结，与原重复次数计划、支付、间接激活及选择恢复共同保存；每次重复不重新看英雄职业或重抽参数。执行只构造已有 `DiscoverFromPool` 的指定职业、可收藏法术查询，普通发现资格、随机选项、交付和信息边界仍由原执行器负责。

玩家在可见载体上可见 `discover_class`，印刷 `classes` 仍为中立；对手手牌提前返回未知信息，不能读取后来参数。随机收据不加入玩家事件。观察协议升至102，命令12、回放1保持；内核575、schema469、实验内容preview-v400。原模型只给 `AbilityInstance` 加两项可空字段、`BattlecryPayload` 加一项可空字段，无新GameState字段或显式载荷类型。

构筑注册表本身不声明宿主完整 `constructed.cards` 池。使用完整1188候选根构造的独立预览查询确认：法师的真实候选 `TIME_859` 异化尚未实现，当前会明确报错，不从候选中删掉。其他十个普通职业在该有限候选域通过定义完整性检查，也不代表正式生成池已认证。此依赖未补前，不能称蔽影密探完整标准效果已完成。[候选域审计](../outputs/card-integration-20261014/k294-shadowed-informant/generation-domain-audit-01.json)与[来源观察](../outputs/card-integration-20261014/k294-shadowed-informant/primary-observations-01.json)分别保留。

本模块不宣称任意战吼授予、拼接或全部历史卡的可变参数已经支持；真实来源需要时按实际材料接入。收据检查不提供未签名存档来源认证。执行进度与测试结果只在[项目状态](project-status.md)和[机制台账](mechanism-backlog.md)维护；正式补丁/合法池、完整可达内容与国服校准仍各自开放。
