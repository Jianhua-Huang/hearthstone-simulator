# 世界之柱碎片：原发现未选候选的手牌交付

[完整原行与中英官网主面](../data/cards/shard-original-discovery-remainders-v1.json)来自已取得的固定本地目录与缓存。真实3费不可收藏宝藏 DEEP_999t3 发现一个元素并召唤，把另外的原候选置入手牌；来源并不增加标准构筑根，真实发掘 profile 绑定仍独立处理。

## 有限公共声明

[适配](../hs_sim/cards/shard_original_remainders.py)使用原 DiscoverFromPool、完整普通宿主域、印刷元素查询、当前职业/中立资格，以及原 SummonCause/CAST 归因。新字段 `unselected_to_hand=True` 只开放一次、三个选项、普通无附加奖励的元素随从发现并召唤。错误类型、无来源/因果、手牌目的地、额外轮数、复制、冻结、改费、重抽和其它派系查询均拒绝；不拓展任意组合。

原发现生产者保留完整候选、抽样及RNG、原菜单和选择、实际独立召唤根。该策略在选中召唤尝试及原发现通知完成后，沿原菜单顺序获取未选卡，每次仍交普通 create_hand_card，实时处理手牌容量和获取反应。不会重新查询职业或随机池，也不会把选中卡再获取一次。候选只有一张或两张时只交付实际存在的未选卡，空域不生成选项或额外消耗随机数。

选中元素召唤时不执行战吼；后来从手牌正常打出未选卡才执行它们的战吼。原未选卡保持印刷费用。选中入场失败、在入场反应后离场，或当时职业改变，都不重写已经选择的菜单。完整场时仍完成原选中尝试并交付另外候选，这是本地未校准窗口政策。

## 私有进度与恢复

原 DiscoverySummonRecord 增加 `remainder_created`，保存严格按原菜单前缀的实际 SourceAllocationFact；普通入手与满手烧牌都留实际物理身份。每次只执行一个 DeliverUnselectedDiscoveryCard，再保留精确的下一项控制，所以第一张获取引发等待时，第二张的原身份仍明确欠交。

原生产者生命周期与完整选择边界证明继续负责控制顺序、当前子召唤完成、不能删除/重复/冒充续接、完成前不能缺交。私有事件链核对每次只增加一个原身份、实际创建来源/玩家与原窗口，以及选中召唤和发现通知已发生。取得之后的合法出牌、变形或转控不改写历史事实；这些证明验证内部一致性，不能认证未签名存档的外部来源。

未选卡创建是普通语义效果检查点；控制身份只用于续接归属和保存校验，不使它成为透明诊断步骤。因此每张的获取反应先于下一张，终局可保留已实际创建的前缀并停止后续交付，真正回溯则退役原尝试并保留单调分配器。

两项私有wire扩展使 snapshot schema610 拒绝旧1～609，不静默补默认值。新有限控制仍经原公共解释器；SourceAllocationFact 和原 payload 类型复用，无 CardDefinition、Entity 或额外计数器字段。发现未选卡的普通获取不产生额外 card_discovered 通知；完整候选、RNG、进度实体和私有事件不得进入玩家DTO。
