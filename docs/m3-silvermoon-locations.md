# 银月城原地标形态与原生过量分流

TIME_810、TIME_810t1和TIME_810t2作为同一真实来源的三个必要形态接入；[内容包](../data/cards/native-silvermoon-locations-v1.json)固定三完整原行、六严格双语主面和四真实官网父子关联。三者均4费、3印刷耐久，根可收藏、后续形态不可收藏。实际验收和下一项只在原两份台账维护，不从目录接入认证正式标准池。

过去形态随机对一个敌方随从造成5伤害，再推进到现在；现在形态将5点过量分流到该随从控制者的英雄，再推进到未来；未来先取当前剩余生命最低的合格敌方随从组，再在同生命物理对象中随机抽选，不再升级。候选使用既有active/live普通随从查询，位置和相同卡面不会合并权重，潜行仍可被随机选中。没有手动指定目标入口；敌方地标/英雄不进入随从候选。

普通RequestChoice的有限零选择、一次sample_size和真实on_select保存原MinionReference及LocationFaceReference，不让玩家选择或暴露内部JSON材料。空随从池不抽RNG但继续原印刷推进。推进沿已有AdvanceLocationFace，在伤害、死亡与事件反应后检查原物理来源；保留剩余耐久、冷却、用途和入场身份，不放置新实体或重置耐久。最后一耐久的主体在原接受上下文执行，离场或死亡的原地标不再升级。

公共DamageExcessToHero新增可选`kind`，默认仍是DamageKind.SPELL并要求实际SPELL分配；有限DamageKind.EFFECT仅接受实际LOCATION分配，不能传普通随从、英雄或法术来伪造这一来源。没有制造CAST、cast_id或法伤来源，也没有第二套分配器。原SOURCE预算仅报价一次，再按原随从正剩余生命分配两包；两包分别交TARGET、免疫、圣盾、护甲、重定向、生命下限及现有原子健康批次。EFFECT不会加入Spell Damage，默认SPELL学派/倍率/转换和原结果语义保持。

同一批次中的随从和英雄包完成之后才进入死亡/监听/等待。恢复继续保存typed请求和捕获引用，未知来源/结果回调先于失效目标处理而拒绝。独立reader、clone、完整回放、选择异常回滚及后续原形态检查共享公共解释器。无需新增GameState、实体或能力字段，没有新增Effect/payload类型；请求增加字段由core443/schema361保护，旧1～360须原引擎。观察92、命令12、replay1保持。

无目标仍推进、最低生命并列抽选、最后一耐久主体、伤害后推进窗口，以及沿用的“先按生命分配、再处理承受端保护/转换”均为明确本地政策，仍需国服校准。不能将部分怪物实际承受0之后重新分配英雄余量，也不能用事后伤害结果自行猜过量。正式M0池、M6和全标准可达及阶段发布仍分别开放。
