# 万能钥匙的发现刷新

JAIL_319 沿既有 DiscoverFromPool 查询宿主完整池中的可收藏当前职业法术，最多三个不同候选。最后追加 JAIL_319t 的真实刷新控制面。该面原 cost 为空且没有 COST 标签，双语官方主面显示零，数据包显式记录显示归一化；它是 choice_only，不是额外可打出的法术，也不加入生成池。JAIL_319e 原行与当前主面效果不同，仅作为完整原始证据保留。

有限 `DiscoverFromPool.refresh_card_id` 只允许单次、三选、普通手牌交付的法术发现，不接额外赠礼、费用材料、配对抉择或其他交付变体。原公共解释器负责选择、伤害、死亡、材料化和事务。

玩家选择刷新时，完整原四项菜单及实际选择仍保存为 CardDiscoveryRecord。在原选择提交处仅接受一次 `randrange(5)`，保存在 control_roll：零命中，其余四值未命中。选择反应之后，命中则以 DamageKind.EFFECT 对发现者当前英雄造成五点普通伤害；因此沿用护甲、免疫和致死处理，不加法术伤害。伤害及其反应完成后才重新查询和抽选；对局终止不再发起菜单。保存/恢复不重新掷风险，不重新支付或产生第二次施法。

刷新收据的 is_control 为真。discovered_cards、discovered_this_turn 和冻结发现费用事实排除这些行；真实选中法术才沿原 MaterializeDiscoveredCard / DiscoveryCompletion 产生一次发现。历史前缀仍完整保留全部选择，不能删去控制收据来改变原费用接受窗。普通发现生产者默认拒绝控制结果；只有 RefreshPoolDiscovery 可要求原控制收据。

OriginalDiscoveryOffer 保留全部原选项，但仅真实牌槽拥有 OfferedCardMaterial。未选牌的材料、选项及整卡执行同样排除控制面，不能把刷新当作另一张法术。原菜单的类型、顺序、声明与选择分类在等待和历史边界重新核对。诊断收据、风险整数、内部随机状态及续接不进入玩家 DTO。

未知合格法术在抽样前报错，不能裁掉；完整空池不抽随机、不提供孤立刷新按钮。重复刷新继续使用原公共结算预算，自动施法也经过同一选择与风险提交入口。

上述风险抽样与选择反应先后、当前职业资格、自动控制选择及英雄替换/救援的精确国服窗口仍为本地政策，待 M6 校准。内部行为通过不代表 M0 正式池或所有可达内容已闭合。实际测试与接受状态只见项目状态和机制台账。
