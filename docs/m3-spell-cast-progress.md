# 实际施法接受事实与持牌升级

本契约补齐法术钻石所需的一项独立公共能力：普通手牌进度按真实物理施法推进。复用已有施法历史、手牌进度、升级和复活效果，没有新增组合规则或另一套结算器。运行身份为`prototype-v167` / `core-effects-v167`、schema162，拒绝旧1～161；观察71/命令10/replay1保持。实际执行位置只在[项目状态](project-status.md)与[机制清单](mechanism-backlog.md)维护。

## 公共接受事实

`spell_casts.note_payload`是手动及自动主体接受的共同通知入口。既有`SpellCastRecord`已写入、`payload_started=True`且没有失败时，先保留原[持牌条件](m5-held-spells.md)的原子记录，再发布内部事件`spell_cast_accepted`。hand、repeat、effect、draw、history五种实际来源共用该入口。

事件金额固定为精确整数1，源/目标/玩家与实际施法记录一致，data只有`cast_id`。反制手牌尝试、目标失败、尚未接受主体的自动来源没有该事实；已接受的空主体有事实。开始、接受、完成仍为不同阶段。接受后被终局截断可保留已经发生的接受事实，不据此声称施法完整成功。

普通注册行为不能直接发布该事件，内核要求真实接受边界标志并核对原记录。动作/快照边界逐条核对：当前每个实际接受记录恰有一条事实，未接受尝试无事实，字段准确且不重复。普通回溯保留旧尝试日志，同时恢复施法历史并可重用cast ID；校验沿真实`timeline_rewound.event_start`划定已撤销范围，旧日志只做事实形状校验，当前记录必须匹配重试后的新事实。多个重试和独立回溯窗口均沿各自原检查点处理，不能把旧日志全部加进当前进度或删掉历史。事件可以发生在后续`SelectChoice`动作中，所以行动号允许从原施法创建动作至当前动作，不能误要求一直等于创建动作。这里验证结构与对局记录一致，不提供未签名存档来源认证。

## 复用普通手牌进度

必要代表使用原有声明：

```python
HandProgressSpec(
    'event', 4, upgrade_card_id=next_form,
    event='spell_cast_accepted', condition_id='diamond.cast',
    upgrade_cost_policy='clear_local',
)
```

资格回调收到`RuleContext.cast`，示例明确要求施法玩家等于持牌控制者；可按真实origin筛选。普通进度继续沿原候选队列执行，候选物理实体/能力ID/控制者及手牌驻留必须有效。该事件的见证键使用`cast:N`，同一施法重复处理不会再次推进，不把开始和完成事件各算一遍。状态及冻结材料中的见证必须引用已接受、无失败的实际施法记录；current复制可以继承另一实体或玩家取得的见证，因此不错误要求历史施法者总等于现持有者。

每个合格cast贡献1单位。达到4时沿原`upgrade_face`换形、清除显式声明的本地费用、保留连续能力身份/见证，下一阶段从0开始；第八个cast完成第二次升级。之后每个新cast仍使用自己的真实身份。旧腐蚀、注能、数值事件、阴谋重复进度及条件型`kind='spell_cast'`保持原窗口和表达，后者仍只记录条件事实，未放宽为任意回调或授予。

持牌捕获发生在接受事件时。提交或自动开始反应中已获得且仍持有的牌可以计入；本次主体途中才获得的牌没有追溯信用，之后新的嵌套/重复cast可以计入。通用队列先处理接受事件捕获的反应，再进入原主体效果续行；既有主体回调的冻结上下文仍按原契约保留，没有为这一基础缺口改写所有回调的时序。

普通current/base复制、不重置移区暂停、重置、升级成本及原子回滚沿[手牌进度](m5-hand-progress.md)与[升级](m5-hand-upgrades.md)处理。选择可在自动接受之前、进度回调中或主体内暂停，独立注册表恢复、clone与回放保留同一接受事实。挂起`AdvanceHandProgress`必须持有实际事件数组中的原事件，不能替换序号或借用另一次记录。回溯保留多个效果结果不会虚构新cast，普通回溯恢复仍恢复原真实记录与事实。

## 必要真实代表与玩家边界

[三条完整raw/pin](../data/support/spell-cast-progress.json)固定LOOT_507、LOOT_507t及LOOT_507t2，PIN为`75aade1b3732382c3157a9be841592a3c0a88e4defd1d4ba92779453775a16be`。小型原文要求施放4个法术，中段原标签仍保留门槛4；三个主体为7费，复活2/3/4个不同友方随从。必要普通主体复用`Resurrect(distinct='card')`，不增加专用复活系统。本地完整行是此次行为依据；[官方资料库入口](https://hearthstone.blizzard.com/en-gb/cards/46307-lesser-diamond-spellstone/)可定位卡牌，但此次页面文本没有返回完整卡文，不能把链接本身当作已取得官方时序证据。

仅在隔离专项适配该三形态，生产代表64/合成3保持。来源、选择及异常用明确公共探针验证，没有给真实钻石新增主体，也不把场景当作合法混合职业牌组或全部复活材料组合认证。

接受事件不进入玩家事件白名单，cast身份和完整历史仅供可信宿主。控制者复用既有`hand_progress`摘要，对手隐藏手牌不暴露成长、见证、能力ID或全知状态；观察/命令版本无需改变。
