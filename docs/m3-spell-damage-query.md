# 原法术来源的实际伤害查询

`spell_damage_dealt(state, registry, player_id, *, turn=None, before_id=None)`读取已有[伤害历史](m3-damage-history.md)的冻结结算结果。`turn`为原全局回合，`before_id`为排他原伤害记录ID；均须为正整数，player须为1或2，bool不能充当整数。不指定回合则累计整局，不指定前缀则读取所有当前有效记录。

先沿原完整历史校验物理身份、时钟、原卡面及顺序，再在指定回合/前缀内筛选原来源控制者及印刷类型 `SPELL`，累加最终 `damage_dealt`。所有友方/敌方、英雄/随从目标都计入。护甲吸收属于伤害；请求量、净失血、施法次数、当前卡面、当前控制者、`DamageKind`标记及当前技能不能代替原事实。

免疫、圣盾、规则阻止、零量及伤害转治疗的记录贡献零。治疗转换为实际伤害时按原法术来源与最终伤害计数；吸血治疗、普通治疗、增加生命上限和生命支付不额外产生伤害信用。失效目标没有结算结果，故没有额外记录。召唤物的自身伤害依然归原随从，不追溯给召唤法术。

未知正量来源在所选回合/前缀内明确拒绝，不猜来源或静默删去；范围外未知归属不阻塞该范围。原系统疲劳与未知零量不取得卡牌信用。原卡面未知仍由完整历史校验拒绝，不因零金额或类别排除而隐去。数据校验不认证未签名存档的外部来源。

查询和原英雄技能伤害累计共享私有按来源类型求和函数；原 `hero_power_damage`签名与语义保持。来源/目标后来变形、转控、死亡、回手不会重写结果；真实回溯退役旧尝试，失败事务和等待恢复沿原记录边界。查询不消费随机、分配身份或写缓存。全知完整结果只供规则/宿主使用，玩家仍接收原允许观察的事件和当前状态。

[CATA_452与CATA_487完整本地原行](../data/support/spell-damage-query-basics.json)只证明查询需求。此增量补查询前置，不适配这两张牌，也不注册白板；CATA_452的固有费用消费者尚待补齐，CATA_487的准确首次事件窗口也不能从本查询完成推出。

没有新模型、持久字段、账本、伤害执行器、事件、动作或组合。查询入口和共用实现的效果身份为 `core-effects-v290`；`prototype-v291`、schema255、观察84/命令12/replay1及原字段布局保持。精确国服来源、转换信用与事件窗口待M6校准，正式池/全部卡牌尚未认证。实际验收和下一项仅在[项目状态](project-status.md)及[机制清单](mechanism-backlog.md)维护。
