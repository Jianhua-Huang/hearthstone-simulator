# 普通法术的原费用参数

实际执行、验证结果与下一项只在[项目状态](project-status.md)和[机制清单](mechanism-backlog.md)维护。该有限入口由BE_094漂浮教程的真实需求引入，不代表完整正式池、全部费用来源或国服交互已经认证。

## 声明与两个原窗口

普通有on_play主体的法术可注册`SpellSourceCostProfile(card_id)`，唯一支持basis为submitted_manual_or_automatic_acceptance。未知政策、非对应类型、重复身份、未知卡牌或非普通法术声明拒绝。独立只读注册表映射进入构筑指纹，空映射不改变默认代表包指纹；不安装虚构重复来源或修改法术印刷费用来取得数值。

- 手动hand及同次出牌的repeat执行复用原PlayRecord.submitted_cost.quote，包含支付前完整物理输入、局部/外部操作、数值/账户、修正及有限用途。不能在原一次性减费或增费已消费后重新报价，也不从当前法力或生命余额差推算费用。
- effect/draw/history自动施法沿既有capture_cost_input/capture_quote_fact，在原存储载体移动和目标选择之前捕获。原实体的附魔、能力及手牌下限保留，以实际施法者查询当前费用；跨玩家来源不改变卡牌所有者。自动CAST不支付、不消费所报价的有限次修正，数值可以与实际零支出不同。
- 原生自动重复的每个实际child CAST在自身接受窗重新捕获当前来源报价，记录自己的源费用及开始收据；不把parent的字段通过replace默认为新接受窗。普通同次付费手牌的repeat仍使用该次原付款报价。精确当前国服重复/费用窗口仍待M6。

这些政策区分费用和支出，也区分原付费根与新的自动CAST。实际数值计算、全部费用层、资格与账户仍由既有报价执行器完成，没有第二套价格或支付实现。

## 原记录、保存与核验

SpellCastRecord新增显式nullable source_cost，声明来源的每个实际尝试均携带完整CostQuoteFact，包括反制或无目标失败；没有声明的旧CAST只能为null。主体通过spell_source_costs.amount读取已经接受的数值，不能从一个未声明来源或非实际CAST调用得到默认0。

完整输入必须绑定原source_id、player_id、card_id和SPELL类型；使用原报价代数校验、固有历史前缀及已提交手牌报价相等检查。自动来源的原报价时钟必须与该次CAST接受一致。后来的费用修正、场面变化或选择恢复不改变旧值，也不能用另一实体或另一付款者的有效报价冒充。

spell_cast_started的私有source_cost摘要绑定完整有序原报价。手动、自动和原生child三处producer均显式写入；恢复时与原开始记录核对，即使重新计算外层状态/事件哈希也不能只改一处蒙混。该机制只保证内部完整性与保留的原事实一致，不提供未签名整份存档的外部来源认证。

严格字典与typed帧复用CostQuoteFact及原输入/事实类型；旧schema不能省略字段后静默得到null。引入时schema509拒旧1～508，core-effects-v621、构筑内容v454；观察115、命令12、replay1保持。没有新GameState、Entity、Player或CardDefinition字段、Effect、外部动作或结算队列。

## 漂浮教程的普通效果配方

来源为原1费术士暗影法术，完整原行与两双语官网主面见[固定来源包](../data/cards/source-cost-stat-spell-v1.json)。在实际主体中读取一次原费用并乘2，然后按原顺序返回：

1. 对CAST原目标执行普通Buff，同量增加攻击与生命。资格由原live_character与区域政策处理，牌层不额外要求目标仍属于原控制者或保留原卡面。
2. 用普通RandomBuffStoredMinion在实际第二请求窗，从本人手牌的合格物理随从中等权选一个，沿BuffStoredCard施加同量永久数值。重复同名实体仍是独立候选，不过滤到对手手牌或非随从。

两份增益共享同一个已经冻结的金额。后一个请求仍使用原公共队列及当时手牌；没有合格手牌时不抽随机数，原金额0时不制造零值增益或随机抽取。原目标在执行时不再符合普通Buff资格，只跳过对应场上增益，不重抽场上目标；若之后合法进入本人手牌，可以成为当时手牌请求的候选。既有原生重施沿其保留目标政策，失效的场上部分由公共Buff跳过，后段手牌仍沿原队列。第一次手动/自动目标选择时失败则沿原施法失败路径，不执行两份主体。上述精确目标、变化、通知与两区域先后窗口仍待国服校准。

原费用、局部引用和普通效果进入同一个解释器、选择等待、回滚、clone及replay；玩家观察不输出私有源报价、修正用途、附件或恢复帧。手牌增益随真实牌保存，进入场上后按原沉默/生命周期处理，不为该卡另造附魔或随机机制。

原报价基础见[费用匹配契约](m5-spell-cost-matching.md)，本入口只借用公共报价和compact校验，不引入重复匹配条件。原自动来源见[施法契约](m5-spell-casts.md)，属性和手牌请求继续沿[跨区域扩展](extensions.md)。M0正式部署/热修/资格与完整可达域、M6和完整M7仍独立开放。
