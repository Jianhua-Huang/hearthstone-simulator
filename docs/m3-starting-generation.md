# 起始卡组决定的生成资格

对应B08b-01/U31及祈求已知规则差异。补真实起始资格，复用已有候选查询、随机、发现、召唤、变形、解释器和原卡组事实；没有另造组合机制或卡牌特殊授予。当前prototype-v163/core-effects-v163，schema158严格拒旧1～157；玩家观察69、命令10、回放1保持。实际执行与下一项维护在[项目状态](project-status.md)和[机制清单](mechanism-backlog.md)。

## 规则依据与调查范围

[官方31.0公告](https://hearthstone.blizzard.com/en-us/news/24149389/31-0-patch-notes)说明：克苏恩及迦拉克隆相关卡的变形、发现和随机生成资格，取决于该玩家的起始卡组是否包含同组的卡。2019迦拉克隆介绍中的全局禁止生成说法不能继续作为当前规则。

本地调查冻结了31个经典克苏恩相关身份及33个迦拉克隆相关身份。[完整64条原始记录](../data/support/starting-generation.json)逐行保留全部字段和哈希，整体pin为`16bbb51825c490a71a0017dc7c25d995735aaf9f2a06420cc10e27becd6f94af`。调查依据包括本地实际卡文、RITUALIST/收藏关联标记、重印身份以及祈求和依赖祈求的真实卡；不仅检查裸关键词，还识别克罗斯、龙的兽群等相关来源。升级迦拉克隆身份仅是组信息，其可否进入具体池仍由原收藏性、版本池和查询限制决定。

这64条是冻结调查范围，不能冒称正式国服当前池已经完整。经典成长、破碎之劫四部件和其他同名角色分开；DMF_254不因名称相似被塞入经典仪式组。后续M0调查发现新身份须补有依据的组信息和版本，不能按可执行覆盖删去未知候选，也不能拿有数据宣称完整范围已确定。

## 不可变起始事实

`GenerationContext(target_id, mode, starting_decks=None)`新增可选的两个完整有序起始卡组，类型为两个字符串tuple组成的tuple。顺序和重复保留，不根据当前牌库、手牌、场上实体或已经调用的仪式/祈求次数反推。

- 构筑入口从两个`DeckSpec.cards`自动冻结，绑定原目标/模式及`PlayerState.original_deck`；换牌、抽牌、消耗、生成或洗入不会改写。
- 实验场景可显式声明两个原卡组事实；声明中的牌仍须由既有状态校验确认。场景未声明时保持未知，不把当前场景牌库猜成真实起始卡组。
- 纯查询遇到有条件组候选时必须有起始事实及准确的执行座位，未知则明确报错。普通候选或已被普通查询条件排除的组成员不要求无关起始事实。
- 当前卡组事实与生成上下文不符，或者构筑上下文与`MatchSetup`不符，均拒绝恢复。实验场景的自述事实与结构校验不提供未签名存档的来源认证。

`GenerationContext.to_dict/from_dict`使用明确的三字段格式；旧快照依靠schema门槛拒绝，不能静默补空卡组。这些全知原卡组和上下文不进入玩家观察。

## 公共候选路径

`resolve_candidates(..., player_id=None)`根据声明座位判断其起始卡组中是否有同组身份。克苏恩组不会解锁祈求组，另一个座位的起始牌也不能替本座位解锁。固定本地身份表、已注册经典/祈求profile身份及真实祈求关键词声明提供识别；不执行卡牌主体或把动态生成的相关牌追加成起始资格。

先保留原版本池、特殊关键词、身份/来源排除、职业、费用和其他查询规则，再检查起始资格，然后对真正符合规则的候选检查可执行适配。没有资格的组成员可以按规则排除；取得资格后若没有适配，必须明确报错，不能从池中静默消失。允许资格不绕过其余禁限，抽样权重、身份去重和随机算法继续原路径。

| 已有入口 | 起始事实与执行座位 |
| --- | --- |
| 随机生成/直接池召唤/施放池 | 原生成上下文与效果声明的player_id |
| 普通或连续发现 | 原上下文与发现声明座位，原选择收据重新核对资格 |
| 分组候选发现 | 原上下文与offer声明座位，不从选项归属猜座位 |
| 随机跨区变形 | 原上下文与冻结TransformPoolTarget.player_id；沿原变形声明 |
| 已归因召唤材料 | PoolSummonBasis冻结完整上下文；与原状态起始卡组核对 |
| 已接受冻结施放池 | 使用原冻结上下文/声明座位重算候选，不能改成后来局面 |

显式命名的必要创建/固定变形继续原效果语义；本项没有把默认随机候选限制改成所有显式创建的全局拦截器。满场、空池、费用、反应和检查点仍由原入口负责。空候选不凭空消费随机数，主体失败沿原事务回滚。

## 当前开放项

经典克苏恩的嘲讽成长已有独立基础，永久性与精确窗口待国服校准；四部件开局/组装仍未完成；全部真实来源、国服窗口、固定正式版本和完整合法可达池继续开放。仅验证公共生成资格及其必要消费者，不以64条数据、测试数或撤除组合提高完成度，也不宣布U31/H2/M0/M6/M7完成。
