# 原生持续来源与旧召唤主体的来源交接

本页维护表达与扩展契约；实际进度、证据和下一项只在[项目状态](project-status.md)及[机制清单](mechanism-backlog.md)。完整十一张原行与配方见[固定数据](../data/cards/static-provider-effects-v1.json)，声明由[适配模块](../hs_sim/cards/static_provider_cards.py)安装，不在运行时解析卡牌文字。

## 复用现有声明

普通突袭、潜行、冲锋和嘲讽复用原关键词；两张法强卡分别显式声明1及2，不把`SPELLPOWER=1`的布尔标记当作全部数值。受伤时加攻与当前控制者持武器加攻使用`StatRelationSpec`，不反复添加永久增益。两个种族来源使用原`AuraSpec`筛选当前其他友方鱼人或海盗，外部属性不复制成接收者的永久附魔。

止水湖蛇颈龙用原`cleave=True`，其最终相邻对象、主要互伤及额外包、攻击次数、死亡和待选沿[顺劈契约](m2-cleave-combat.md)。卡德加用原`SummonQuantitySpec()`，来源范围是己方实际卡牌，默认不含英雄技能；多个独立来源的乘积、接受窗口、模板、场位及恢复证明继续交原数量机制。

无私的保卫者的完整卡面是“受到的所有伤害提高一点”，使用目标侧、仅本体的`HealthRule(DAMAGE, ADD, 1)`，没有限伤到1。免疫、圣盾、沉默及伤害结算仍由公共层处理。

## 显式交接旧召唤来源

旧`Summon`没有造成召唤的卡牌身份，不能遇到卡德加就猜当前玩家、接受方或监听事件的来源。`summon_quantities.card_summon(context, player_id, card_id, position=None, stats=None)`是卡牌主体使用的适配入口，调用者必须提供实际行为上下文。

当既有数量来源门禁不适用时，返回参数相同的普通`Summon`，保留原常规路径及事件。若该请求按原门禁属于歧义召唤，则用`SummonCause.capture(context)`及完整`SummonEntryMaterial`委托已有`SummonByCard`。实际发起卡与上下文恰好正在监听的cast/power分别判断；对方数量来源不借给本方，英雄技能仍按声明类型过滤。接受后的额外召唤保留原计划，源死亡或等待恢复不重新抽选或重算已经接受的次数。

原代表、普通工具主体、条件植物和抽取后召唤复制的直接旧主体已改为显式调用这个入口；没有在解释器中自动补来源。低层入场、复生、其他已归因生产者和普通打出的随从不走该适配，避免再次倍增。直接提交缺来源的`Summon`在数量来源存在时仍报错并回滚。该入口不是任意来源或隐藏状态的自动兼容器；实际新卡生产者仍须声明自己的完整来源、复制材料及生命周期。

**标准可达性和原始来源须分别证明。** `adapt.py`植物亡语、`pools.py`旧交付和`interrupts.py`替代入场的直接请求不能仅凭静态位置认定为标准缺口。池入口已有显式归因分支，具体主体应传真实来源；未接入的配方及候选根外来源由实际标准依赖证明需要后处理。传送门的调用与历史收据契约见[标准传送门来源](m3-standard-portal-summon-source.md)。全部正式可达内容仍须闭合，不能将18处迁移或单次战吼演示当作完整卡德加支持；无来源旧请求继续拒绝。

## 零反击与数值准备

真实无私的保卫者与0攻击受击者暴露了原健康准备层的问题：原结构反击包为0，却被承受端加法变为1。现在保留结构互伤包，但`COMBAT`原始0量直接维持0，不再转换、重定向或放大为实际打击。正数战斗包保持原数值层；0基础法术仍可先得到法强，再执行承受端修正。未添加伤害执行器、保存字段或事件类型。

该零反击政策、各数值层顺序、相邻捕获、种族生命撤销以及召唤精确窗口仍需国服官方证据校准；内部回归不能代替M6。卡牌原行与一般资料不能单独证明这些交互。

## 保存和玩家边界

全部新增卡牌使用已有能力与状态布局；没有新schema字段，格式仍由`SNAPSHOT_SCHEMA_VERSION`统一声明。规则版本随行为修正更新；原注册表身份、快照、等待恢复、clone、回放、异常回滚和玩家投影继续校验实际材料。来源、条件缓存、完整数量计划及工作帧不得进入玩家DTO。

`python -B -X utf8 -m examples.card_static_providers`使用已注册真实定义和玩家合法动作，展示法强、突袭、受伤加攻、武器与种族来源、顺劈及卡德加；各稳定位置独立恢复、clone和回放。实验场景的跨职业牌及显式法力上限不认证正式套牌或卡池。标准资格、Core等价身份、国服热修及全部可达内容仍需各自闭合。
