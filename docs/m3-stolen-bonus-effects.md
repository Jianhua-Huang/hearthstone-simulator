# 原随从的额外效果偷取

紫罗兰惩戒者JAIL_101按[完整原行与双语主面](../data/cards/violet-tormentor-v1.json)接入，3费4/3中立普通随从，战吼选择敌方随从，偷取其额外效果，每项获得+1/+1。[官网卡面](https://hearthstone.blizzard.com/en-us/cards/124003-violet-punisher)支持正文；[来源记录](../outputs/card-integration-20261014/k272-violet-tormentor/rule-sources-01.json)区分卡面与精确交互证据。

`StealBonusEffects(victim, beneficiary, source_id)`使用原`MinionReference`，受益者若存在必须是不同于原目标的原来源。目标由真实战吼的敌方随从准入选择，使用`IF_AVAILABLE`，无合法目标仍能正常打出随从；魔免不阻挡战吼，潜行、休眠、友方和英雄不进入该目标域。

原效果执行时按现有`BONUS_EFFECTS`顺序读取目标当前有效的嘲讽、圣盾、魔免、吸血、剧毒、复生、突袭和风怒，每种只计一次。已经消耗的标记不计；同一关键词的多个印刷/授予附件不增加计数，受益者已经拥有该关键词不减少原偷取数量。偷取已有突袭不套用随机授予的攻击时机筛选；没有随机抽样。八项沿原机制表，R-035完整国服候选认证没有因本卡自动闭合。[官方30.2说明](https://news.blizzard.com/en-gb/article/24122902/30-2-patch-notes)仅支持潜行改为魔免及随机突袭授予的局部调整。

公共处理用原`consume_keyword`消费目标当前的本地关键词附件，全部本地移除先于反应。非额外效果的冲锋、亡语、法术伤害、普通属性和其他附件保留，不用沉默代替偷取。持续光环和条件提供者独立存在：当前有效标记可以复制给来源，原提供者不会被移除，仍可能继续给目标供应该标记。这是沿既有生命周期的明确本地政策，不能据此宣称已国服确认。

接受后的固定标记连接原`GrantCapturedKeyword`，再由一个`BuffCapturedMinion`授予合计+N/+N。原普通授予保留其各自反应窗口；目标之后离场不会让后续工作重新扫描同ID的新身体。原受益者离场则后续授予和增益失效，不向手牌或新驻留重绑。来源在已接受战吼之前离场时仍可移除原目标标记，但没有受益者奖励。连续来源、重复计数、合并一次属性奖励及精确反应窗口仍待M6。

沉默、回手、当前/基础复制、已消耗标记、恢复、回放与失败回滚沿原管线。新Effect保存中严格验证原引用和已分配边界，不添加GameState账本、模型字段或新payload；玩家投影不输出原私有引用。无签名快照不提供外部来源认证。

本契约注册1种Effect，schema445/core551，旧1～444拒绝；观察99、命令12、回放1保持。实际进度、验证结果和下一项仅维护在[项目状态](project-status.md)及[机制台账](mechanism-backlog.md)。
