# 原攻击者设生命与原生存储区域成长

本契约对应阿凯欧斯`TLC_811`与食草剑龙`TLC_827`。完整固定原行、必要附魔证据与配方见[数据包](../data/cards/stored-growth-native-effects-v1.json)，卡牌适配见[实现](../hs_sim/cards/stored_growth_native_cards.py)。实际进度、验收证据和下一项仅在[项目状态](project-status.md)及[机制台账](mechanism-backlog.md)维护。

## 原随从与共享属性层

阿凯欧斯只消费本人另一随从的实际`attack_declared`通知，核对原窗口、来源、玩家、事件序号及`CharacterAttackRecord.source_kind`。英雄攻击、对方攻击、自己攻击和单纯防守不会进入主体；强制攻击仍有同一个真实攻击声明。来源在通知捕获状态中须活跃、存活且未标记消灭。

主体保存通知截面的来源当前剩余生命值与原攻击者`MinionReference`。后续反应改变阿凯欧斯的生命或使其死亡，不重新计算已经接受的数值；这沿用既有行为调用的冻结状态政策。目标回手、重入、换控制者、换面或死亡使原随从引用失效，不将旧奖励接给同ID的新驻留。

`hs_sim.engine.sacrifice.SetCapturedMinionStats(beneficiary, attack=None, health=None, source_id=None)`先检查原引用仍指向活跃存活随从，再同步委托已有`SetStats`处理器。它不维护另一套属性算法；清伤、局部附魔、光环、沉默与事件仍由原属性层处理。请求至少设置一种属性，类型和值复用原验证。带`origin_state`的FrameCodec拒绝未知实体、未来区域修订、未来入场分配及未知来源；旧驻留可以编码，但执行时只会过期跳过。

目前的剩余生命取值截面、光环再次应用及来源在反应中离场的规则均为明确的内部政策，尚未取得逐例国服服务器校准；不能将本契约当成官方时序证据。

## 一个存储监听实例覆盖手牌与牌库

食草剑龙印刷攻击为0：固定原行的`attack=null`及缺少`ATK`标签对应已审核的零值编码，配方显式写0；不把未知卡的空字段泛化为可执行白板。

战场结束主体使用既有`TriggerSpec('turn_ended', ..., EndTurnSpec())`，对原随从交`BuffCapturedMinion(attack=1)`。手牌和牌库使用同一原生`HandProgressSpec`实例，完成回调交`BuffStoredCard(CardReference.capture(source), attack=1)`；三个区域不共享另一张物理牌的计数，也不会在战场额外执行存储监听。

`HandProgressSpec.zone`保留既有标量`Zone.HAND`、`Zone.DECK`，并仅新增严格有序的`(Zone.HAND, Zone.DECK)`。该有限配对不是任意区域集合：反序、重复、战场、字符串tuple和调用方list均拒绝。解码器将JSON中的合法二项数组还原为typed tuple。

任何包含牌库的声明仍须是普通MINION、`kind='event'`、门槛1、`repeat=True`、一个完成回调、单位进度，无升级形态、进度中回调或生命转耐久。每个物理载体仍只安装一个`AbilityInstance(kind='hand_progress')`，不新增状态字段、卡牌专属计数或结算器。

捕获按既有手牌在先、牌库在后及双方物理顺序，事件键只消费一次。条件明确要求实际结束玩家为持有者。当前状态复制保留已有成长和完成事实但获得新实例；基础复制从印刷值开始；抽牌和普通不重置移区保留成长并更新监听身份；打出后回手的重置沿已有生命周期。

前置反应在待处理进度执行前改变区域，旧能力实例候选失效，即使新区域仍属于配对范围也不重绑、不补领旧事件。成长回调已捕获的存储引用也不会命中新区域。此处沿用既有移区更新能力身份的政策；准确国服跨区触发窗口仍待校准，没有为了新卡绕过原生命周期。

## 保存、恢复与玩家信息

牌库中的成长不发布`hand_progressed`，也不提供手牌进度投影。控制者只在实际手牌中看到该配对实例的公开进度摘要；战场使用普通属性投影，对手不能取得隐藏卡面、完成事实、候选、见证、原引用或挂起工作帧。存储属性变化继续沿原私有事件通道，不扩大观察白名单。

core353/schema279保护新增请求及配对scope编码；真实旧schema278存档明确拒绝，不能据默认卡牌指纹不变宣称可恢复旧机制存档。事务、错误选择回滚到原等待边界、独立注册表恢复、clone与回放仍使用原解释器。没有新增GameState字段、观察版本、命令或回放格式。

本契约不认证完整标准卡池、完整甲龙生成池、构筑热修集合或国服官方一致性，也不注册尚未补齐实际依赖的生成源。

## 既有存储进度的射击消费者

玉莲帮捣蛋鬼复用相同的有限HAND/DECK监听，以card_played的原完成PlayRecord核对本人实际MANA支付且费用恰为2；单纯花费法力、自动施法或其他资源支付不属于这次出牌。重复单事件完成只记录原进度，正文用印刷初始1加当前来源的完成次数，不增加第二套计数或公共执行器。

原战吼BehaviorCall已保存脱离当前状态的来源快照，开始反应中的沉默/变形不会改写它接受的次数。整个次数交给既有NON_SPELL_PROFILE随机分段伤害，每发重新查询当前敌方角色，继续沿普通死亡、暂停与回放。当前物理载体可沿原TriggerBattlecry再次使用其原生成长；外来历史战吼载体和新基础整卡重放沿现有“不复制原附件”的来源政策使用已知印刷1，不查询后来原实体的成长。准确成长接受窗、历史来源及每包交付的国服细节仍须M6校准。此接入没有扩展内核、schema或观察协议。
