# 原手牌法术的持续光环

乌索尔 `EDR_259` 使用原手牌中当前费用最高的法术，转为真实衍生法术 `EDR_259e1` 并自动施放。战吼安装光环；原法术从本人回合结束时开始施放，三次结束后到期。原始衍生记录的类型是 SPELL，并非只有展示用途的附魔。

## 来源与政策

两条完整原始记录固定在[数据包](../data/cards/ursol-spell-aura-v1.json)，源为37.0.0.255026。根记录的 `TAG_SCRIPT_DATA_NUM_1=3`、衍生记录的 `TAG_SCRIPT_DATA_NUM_2=3` 及衍生正文的本人结束窗口保留；主卡两种语言的完整官网响应和核验见[来源准备](../outputs/card-integration-20261014/k255-ursol-spell-aura/prepared-02/source-review.json)。官网卡面只证明展示内容，不认证全部执行细节。

[玩家关于乌索尔与时序光环的原始报告](https://us.forums.blizzard.com/en/hearthstone/t/ursol-not-working-with-chronological-aura/166695)及回复说明先在结束时施放原法术，此时新建的结束效果不追溯加入当前队列。完整响应与指纹保存在该批输出目录。这是玩家一手报告及解释，不能视为国服正式裁定。

当前费用、并列候选抽选、唯一候选不耗随机、原牌材料的保留、五格容量和精确接受窗口为本地执行政策，仍待 M6 国服校准。没有据目录或内部测试认证正式合法池。

## 共享执行路径

- `CastHighestHandSpellAsAura` 读取当前整份本人手牌的物理法术与普通报价，不按剩余资源、手动可用性或当前目标预筛。没有法术时不做事；并列最高才抽选。
- `SpellAuraRecord` 保留原来源分配、完整候选及报价、选择前后随机状态、原牌当前复制材料和原转换事实。原手牌实体经既有存储变形生命周期换为光环，附件重置、驻留代次递增，随后由 `CastStoredSpell` 施放同一物理对象。原法术没有在战吼时施放，也没有虚构手牌出牌或支付。
- 原光环的纯 `spell_aura` 附件仅携带不可变历史索引。`SpellCastRecord` 在实际主体接受时捕获索引；历史重施和当前复制保留原材料，基础复制没有材料，不能静默执行成白板。
- `PlayerEffectSpec.stored_spell` 声明独立的本人结束光环。原 `AddPlayerEffect` 安装实例并绑定原法术和受益者；已有容量、获得顺序、结束捕获、倒计时、移除及到期执行保持统一。普通玩家程序的默认声明与注册表指纹保持。
- `CastAuraSpell` 读取捕获实例及原材料，使用普通当前复制配方创建非手牌施法实体，再交给唯一自动施法管线。目标与选择每次重算，原生法术参数和存储增益继续由既有规则读取，当前法伤继续由伤害管线处理。找不到目标也消耗本次光环时钟。

源随从死亡、沉默、回手、变形或转控不撤销已安装程序。移除光环停止未来捕获；已经接受的主体按原玩家效果契约完成。新的光环实例各自计时；在结束事件中创建的其他光环不追溯进入该事件的捕获集合。没有另造回合或施法结算器。

## 保存、核验与信息边界

`GameState.spell_aura_history` 是有序不可变事实清单。原始转换事件绑定完整记录哈希；接受顺序、分配界限、最高费用选择、随机重演、嵌套材料必须引用更早记录，均纳入状态/边界检查。该一致性证明不是未签名存档的外部来源认证。

玩家程序保存原始受益者；捕获的施法请求不能更换受益玩家。待选恢复、异常回滚、clone 与回放继续用原帧和事务。保存格式为 schema430，旧1～429明确拒绝；内核版本为535，内容身份preview-v358。外层回放1、命令12保持。

公开观察99只在此类光环中增加 `cast_card_id`，让双方看到实际被施放的法术卡面。完整手牌候选、费用清单、原物理ID、历史索引、随机状态和材料哈希均不进入玩家观察或公开事件。当前测试结果及未完成轴只在原两份台账登记。
