# 真实手牌与牌库法术的局部法伤消费者

战场轰炸手 CATA_209、大法师卡雷 CATA_458 直接复用既有 `GrantStoredSpellDamage`；不增加公共执行器、字段或版本。完整固定源、四份中英文官网完整卡面及内部政策保留在 [数据包](../data/cards/stored-spell-bonus-v1.json)。

战场轰炸手通过普通手牌目标选择绑定本人原法术；没有合格手牌法术时允许不选目标。大法师卡雷在每次实际战吼主体开始时捕获本人手牌、牌库中的原物理法术，按这两个区域的原有顺序生成有限授予请求。原引用跨等待保留；离开原驻留区间的请求不重新绑定同 ID 的新位置。对手及随后获得的牌不在这一批中。

每份 +1 是独立永久局部能力，保留原授予者身份。来源离场或沉默不撤回已经授予的独立能力；当前复制、原牌跨区、施放捕获和生命周期重置遵循 [已有物理法术法伤契约](m3-native-reborn-fire-draw.md)。实际 CAST 主体将原局部能力冻结到自己的材料，不能把它变成玩家全局法伤或转给另一张同名牌。

[真实卡专项](../tests/test_stored_spell_bonus_cards.py)覆盖合法目标/支付、本人双区域与对手边界、实际伤害、叠加、来源离场、原牌抽取、当前复制、普通召唤、真实授予暂停后的队列/回滚/独立恢复/回放和玩家信息。实际验证结果及下一项只在 [项目状态](project-status.md)、[机制执行清单](mechanism-backlog.md) 维护。

原批手牌/牌库捕获、授予反应顺序、移区后原引用失效的精确国服语义仍待校准。星体平衡 EDR_874 的两张生成法术及奖励交付仍独立核查，尚未注册；不能以这两张既有存储消费者认证生成来源或完整正式标准池。
