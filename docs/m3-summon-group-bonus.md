# 原召唤组的实际受益者与水蛭持续来源

真实需求来自丑恶的残躯`EDR_810`与填鳃暴龙`TLC_240`。前者增加友方水蛭实际结束主体的偷取量，后者在三次原召唤完成后给实际召出的鱼人各一个额外效果。完整卡面及依赖见[固定配方](../data/cards/summon-beneficiary-native-effects-v1.json)；本地执行契约和国服证据校准分别登记，实际进度与下一项只在原两份台账维护。

## 同组交付之后的有限奖励

`SummonOrderedGroup(..., bonus_effects=True)`是在原有序组上的有限声明，只表示每个成功交付获得一个普通额外效果，不引入任意奖励脚本或组合矩阵。`OrderedSummonGroupSpec`仍保存三项有序原配方及真实`SummonCause`，每项独立接受已有`SummonByCard`数量/身材计划；数量来源造成的实际额外交付也保留其原身份。原卡牌召唤、场地容量、死亡和反应继续由既有解释器负责。

全部原子项完成后，按原子项和交付次序读取`CardSummonDelivery`成功实体，以完整`MinionReference`绑定原卡面、控制者、区域世代及战场驻留。失败的尝试没有受益者；原实体离场、重新入场、变形或转控后不会以同名牌、当前场位或同ID的新驻留替代。

`OrderedGroupRecord.bonus_receipts`保存完整的已接受奖励前缀，每项`GroupBonusFact`包含原受益者、有序候选、选中关键词、结果及MT19937前后状态。没有第二个数量计数或GameState账本。每次原`FinishOrderedGroup`只推进下一项，复用`bonus_candidates`取该执行窗口当前有效候选，并通过既有`GrantCapturedKeyword`安装能力。授予与下项之间保持原反应窗；中途待选恢复不会重抽已接受结果、重复授予或丢失其余受益者。过期受益者及空候选保留跳过收据，不取随机数。

原私有接受/关闭事件与新增`ordered_group_rewarded`事件共同核对同组原请求、完整子项、单调有序奖励前缀及当前记录。当前记录还须匹配实际原交付。每项随机值可由保存的候选和RNG局部重演；这不是未签名存档的外部来源认证。选择恢复仍受原完整队列及付款边界约束。完整组、奖励前缀和随机字段只属于宿主保存，不直接进入玩家DTO。

TLC_240仍声明普通突袭和亡语，`TLC_240t`是原始2/1鱼人白板；不为衍生物伪造战吼或让其他来源召出的同名鱼人自动获奖。自然亡语从原死亡位置开始，主动触发沿当前源之后的位置政策；全部子项执行完才奖励是本地明确政策，精确国服反应/排序窗口仍待校准。

## 当前水蛭来源

丑恶的残躯战吼复用两次原归因召唤，生成已接通的`EDR_810t`。既有水蛭每次实际结束主体执行时，卡牌层纯查询同控制者战场上的存活、活跃、未消灭且未沉默的当前`EDR_810`，每个提供者增加1点；不安装永久偷取增量或增加公共健康账本。当前复制、沉默、变形、死亡和转控仍由普通实体生命周期表达。

增强后的数值仍交[原角色生命上限转移](m2-character-health-theft.md)，不是伤害或治疗；最低当前生命目标、并列、原物理引用和后一个主体重查均保持原契约。全部来源、准确超额量、动态授予和精确国服窗口并未由这两张牌的内部验证认证。

## 版本与证据边界

保存使用core351/schema278，拒绝真实旧schema277存档。仅扩展既有组请求/记录并增加奖励值模块，没有第二套区域、召唤或关键词执行器。

[官方残躯卡库](https://hearthstone.blizzard.com/en-us/cards/114301)、[官方暴龙卡库](https://hearthstone.blizzard.com/en-us/cards/117949)用于核对卡面身份；[30.2官方公告](https://hearthstone.blizzard.com/en-us/news/24122902)支持历史额外效果的魔免及突袭资格调整。当前八种候选复用[原额外效果政策](m4-bonus-effects.md)，完整当前国服候选、精确组奖励时序、来源和生命偷取边界仍需M6证据。注册两张根卡不等于全部标准可达组合或正式池已经闭合。
