# 露妮的原手牌暂存与未来归还

`TIME_EVENT_998`时光卫士露妮的完整原行和两张严格双语主面固定于`data/cards/temporal-hand-return-v1.json`。[官方卡牌库](https://hearthstone.blizzard.com/en-us/cards/121676-runi-temporal-guardian/)支持手牌中全部随从送往两回合后的未来、返回时+5/+5；准确回合时钟、开始优先级、满手顺序仍待国服校准。

## 有限入口和原物理材料

`SendHandMinionsFuture(player_id, source_id)`仅表达这张真实卡的全部当前手牌随从、两次未来真实开始和+5/+5，没有任意时长或组合参数。一次接受原完整有序组，以已有`SavedHandCard`、`hide`与`Resolution.move`移入私有SETASIDE；保留物理ID、原卡面、epoch、获取、能力、费用和附魔。非随从及后续新取得的手牌保留，不复制原牌，不生成弃牌或死亡。

`GameState.future_hands`保存模块所有的不可变`FutureHandReturn`。来源死亡或离开不撤销已接受的组。当前政策在接受的全局turn+2真正开始、普通turn_started和自然抽牌前归还；跳过的机会不算真实开始，额外回合算一次。归还先于已有临时牌库手牌到期；多个未来组按接受顺序分别提交并允许组间反应。这些优先级是明确的本地政策，不能从卡面推断为M6证据。

手牌升级/变形可以增加epoch而保留原获取；保存版本须晚于原获取版本，不能误要求两者恰好相邻。归还仍严格匹配实际保存的当前卡面和SETASIDE驻留，不借旧卡面或同名新体补位。

## 归还、通知及边界

到期只匹配原SETASIDE驻留。+5/+5调用原属性附件安装器，原完整组全部移区/增益后再通知；成功入手用原获取历史，满手沿已有setaside_overflow及原销毁/烧牌消费者，期间取得的牌先占容量。归还不执行战吼，也不生成新的随从本体。已有到期附魔按普通全局期限处理，不因暂存另开时钟。

保存布局使用schema417。FrameCodec、独立注册表恢复、clone、回放、选择异常回滚及Rewind沿原解释器；原始保存/归还收据和完整实际获取相互校验，Rewind只核有效时间线的收据。due组必须留有唯一原归还续接与开始发布，不能藏入未选分支或删掉欠付工作。终局把未归还组标为ended，原牌仍私有，不再兑现奖励。

全知保存、原组、来源材料和控制队列不进入玩家DTO；成功入手和普通烧牌继续走现有玩家信息边界。此入口仅处理真实手牌随从，不能据此宣称阿纳克洛斯场上组或完整未来机制已实现；不认证未签名存档来源。正式卡池、M6及完整标准可达仍独立，实际验证和下一项仅见[项目状态](project-status.md)与[机制台账](mechanism-backlog.md)。
