# 原返回对象与真实本人回合的时间效果

本契约说明眩晕、诅咒之链、孵化仪典和海洋咒符的有限公共表达。实际执行、验证、差异和下一项只在[项目状态](project-status.md)和[机制清单](mechanism-backlog.md)维护。

## 原物理回手和禁止使用

`ReturnToHand(..., lock_next_owner_turn=True, source_id=...)` 使用原返回执行器。在确实到达目标手牌并完成原重置后、发布返回通知前，捕获该次实际 `CardReference`，安装已有 `LockHandCard`。禁止立即生效，跨过返回方下一真实回合开始，至再一次开始解除；额外回合计数，跳过的回合机会不计数。禁止是手动出牌门禁，不是假造费用，也不阻止效果召唤。

`to_owner=True` 根据实际原拥有者决定接收方，不能改用当前控制者。同名的其他手牌不受影响；满手沿原死亡检查点处理，不添加虚假手牌标记。返回、转手、复制和再次入场沿已有重置/当前复制契约；不在反应后按名字重新查找。罕见的“敌方控制、原拥有者为施法方”场景中，标记对当前回合的作用仍是待国服核实的本地政策。

## 原控制者结束时归还

`ChangeControl(..., until_previous_controller_turn_end=True, cannot_attack_this_turn=True, source_id=...)` 是真实诅咒之链所需的有限入口。与原 `until_end_of_turn` 二选一。成功转控时，在同一物理随从安装独立归还标记，保存实际前控制者及其 `OwnerTurnExpiry` 结束期限。当前回合的攻击禁止复用已有 `GrantAttackPolicy`，与控制标记共同安装后才捕获通知。转控失败不授予攻击禁止。

归还绑定原玩家的真实结束，不按全局回合号加一，不随此后转控改换时钟。归还前的额外己方回合不会提前归还；当前全局回合攻击禁止仍正常失效。原结束反应及其选择完成后，现有稳定清理循环移除到期标记并调用原 `restore_removed_control`，保留冻结重绑、光环和死亡检查点。

沉默/手动移除立即走原归还路径；变形和回手重置取消旧标记；当前复制不复制物理归还义务；死亡不重新取得该随从。普通归还方满场仍按原消灭政策处理。重叠临时控制来源及休眠载体向满场归还仍明确拒绝，属于实际未完成交互，不能据单卡已注册宣称完整支持。手动出牌目标还通过现有玩家 DTO 规则检查真实战场容量；反应后失去空位则沿既有失败路径。

新的 `Enchantment.control_return_expiry` 仅允许原结束时钟，须与原返回玩家一致，且与全局 `expires_turn` 互斥。完整字段、原创建区间、未来/错误玩家/错误边界和到期边界校验共同用于恢复；死亡冻结材料也校验原时钟。没有新的 GameState 字段或玩家命令。

## 下一本人回合结束和开始

孵化仪典声明 `PlayerEffectSpec(kind='objective', duration=2, tick_event='turn_ended', next_turn_end=True)`，仍通过原持续法术安装器、容量门禁、独立实例及倒计时执行。

`next_turn_end` 是有限的“下个本人回合结束”计时政策。普通本人回合中安装时须经过当前结束及下次结束，初始剩余二；对方回合或已捕获的本人结束反应中安装时，初始剩余一。结束事件先捕获原计时实例，反应中新实例不扣减该次已捕获边界。没有第二回合调度器。到期复用 `BuffMinionsInZones` 的场上范围，在实际执行窗捕获当前活跃友方随从的原引用并增益；不回溯施法时的随从名单。

海洋咒符使用原 `kind='sigil', duration=1, tick_event='turn_started'`，到期请求原归因召唤执行器，保留数量来源、占位失败和实际入场规则。仅接通官网明确关联的 `CATA_528t` 纳迦畸体：3费3/3、纳迦、嘲讽。原卡面代理后缀由官网完整渲染卡面消解，不发明额外可执行代理。`DINO_405e` 仅作原始附魔证据，属性奖励使用已有公共附魔。

持续实例仍独立于来源存活、控制和英雄替换；同名实例独立，公开占位及容量沿原玩家效果规则。玩家观察只提供现有持续效果和合法操作，不暴露内部归还时钟、手牌禁止材料、帧或随机状态。原 schema 289 存档需旧引擎；本能力使用 core365/schema290。
