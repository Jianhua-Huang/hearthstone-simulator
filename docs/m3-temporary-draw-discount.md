# 锐目侦察兵的原抽牌与本回合减费

EDR_950锐目侦察兵是3费2/3随从，战吼抽一张牌，在本回合中其费用减少1。完整原行、EDR_950e期限证据与严格双语主面保存在`data/cards/temporary-draw-discount-v1.json`；e不额外注册为可执行卡。

## 固定源与动态展示

本地原文保留两段完整规则，用`@`分隔，并在第二段斜体中使用`{5}`展示牌名。官网完整响应保留两段规则，但省略这两个展示标记。源核对只对EDR_950及固定完整原行哈希开放`{'@':'','{5}':''}`，其余文字、数字、身份、类型及印刷属性继续逐项严格比对。初次严格拒绝记录保留；没有改动原始记录或官网缓存来制造匹配。

该处理只解释来源展示，不从占位符推导额外窥视牌库权限。准确客户端动态牌名的可见时机仍需国服证据；玩家视图不因此取得全知牌库或其他私密内容。

## 原物理交付与期限

`spell_sequences.DrawWithTemporaryCostReduction`在既有`DrawWithCostReduction`上增加一个必需的当前全局回合期限，复用原`draw_discount`。旧永久减费请求及匹配抽牌请求的字段、调用和默认行为保持。新请求执行时核对期限确实是当前回合，不接受过去或未来的“本回合”请求。

实际抽牌仍调用原`draw_one`。只有该次记录的hand交付会捕获`CardReference`，原抽牌反应完成后用普通`ModifyStoredCost`减费并传入期限；不搜索最新手牌、同名卡或后续额外抽牌。原卡离开再返回、转交或变更驻留后，原引用失效。费用零下限、实际支付、全局期限退役及移动后仍在原时钟到期均沿既有费用和区域机制。

burn、fatigue和cast没有本次手牌减费；抽到时施放的替补抽牌不继承原请求的奖励。这些行为保留原永久抽牌减费政策，不另建抽牌、施法、费用或期限执行器。

## 恢复与证据边界

新增一个效果类型，没有修改旧效果形状、模型或保存布局。抽牌反应中的真正等待、独立注册表恢复、克隆、回放、异常回滚及玩家信息隔离继续沿公共协议。

具体国服抽牌、反应与减费的相对窗口，以及动态牌名展示，仍待M6；本地内部验证不认证正式补丁、合法/生成池或全部标准可达内容。实际版本、测试、进展和下一项只在[项目状态](project-status.md)及[机制台账](mechanism-backlog.md)维护。
