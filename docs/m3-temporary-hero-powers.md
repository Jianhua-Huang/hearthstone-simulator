# 临时英雄技能与原实体恢复

萨弗拉斯的故事使用`TemporaryHeroPowerProfile`登记原法术及两次/一次两张明确技能面。两面必须是同费用、同普通使用上限的活跃原生技能；没有任意阶段脚本、额外槽替换或基础技能推断。

`SwapTemporaryHeroPower`通过原`install_hero_power`安装流程，仅把旧主槽技能的退休区域改为SETASIDE。旧实体的费用附魔、能力、使用上限、卡面及其他物理材料保留，不复制或重建。新增GameState.temporary_power_returns保存每个临时实体、原保留实体的ID/区域epoch/安装顺序、来源profile及第一笔实际使用ID；无原技能时明确保存空原项。普通额外技能槽独立保留。

保留区只允许被完整原恢复绑定引用的HERO_POWER，不开放任意英雄技能进入普通卡牌区域。每个保留物只属于一个外层交换，链必须同控制者、无环且驻留精确；直接拼装、普通替换得到的无恢复材料临时面明确拒绝，不作为永久8伤白板。

每次完整成功的manual激活结束后，在完成通知之前推进一次；触发主体不消耗次数，主体重复也只对应一次实际使用。第一用在同一物理临时实体上切换剩余次数面，重装原印刷主体而保留非印刷授予、费用、使用上限和本回合已用次数，不刷新可用次数。历史只允许注册的首面到末面变化，并须有该实体真实成功使用记录；转换依据一次扫描生成，不逐行重扫历史。

第二用恢复原物理实体并沿普通新安装政策将uses_this_turn置0，保留原上限及局部材料；没有原项则移除主槽。确切刷新/完成事件先后仍是待M6国服校准的本地政策。普通新技能、英雄替换或移除会取消整个返回链并退役保留物，不能在旧使用完成时覆盖新槽。

重复施放支持嵌套：先返回前一个临时技能的剩余状态，再返回更深原项。旧技能在伤害反应中被新交换保留时，其完成仍能推进隐藏原实体；若该隐藏临时技能已耗尽，只把更深原项接给外层返回，不改写当前主槽。取消按迭代链处理，不随嵌套深度递归调用。

8点伤害仍是原RandomDamage/HERO_POWER。原技能开始接受保留原主体，实际取敌通过普通续行读取当前角色，包含开始反应新增的敌人；支付、使用、法强分类、主体重复、死亡、终局中断、回滚和回放仍走共同执行器。公共观察仅显示当前已安装技能，保留材料、返回绑定和全知历史不给玩家。
