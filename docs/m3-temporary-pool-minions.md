# 从发现或随机池获得临时随从牌

血瓣群系TLC_449是1费、2次使用的地标，原生使用效果发现1费临时随从牌；坑道恐怪TLC_469是3费4/3野兽，原生亡语随机获得两张2费临时随从牌。完整原行和四张中英官网卡面独立固定，不能把地标误作法术，也不能把费用修正到期解释为临时卡销毁。

`DiscoverFromPool`与`GenerateFromPool`各增加`temporary_until_turn`。真实主体以当时全局回合号捕获期限；请求执行及等待帧恢复均要求保留原当前回合。有限声明只允许具有原来源、可收藏随从、普通替换抽取和手牌交付，不混入费用修正、固定属性、特殊礼物、复制召唤等未接通形状。普通发现包装器不支持临时交付时明确拒绝，未知合格候选仍在各自请求取随机数前报错。

普通资格、完整选项、选择恢复和整批抽选保持原管线；选中结果直接转为已有`CreateTemporaryCard`。原执行器在真实新实体首次创建/获取/烧牌通知前安装`HandLifetime`，负责容量、实体身份、费用底线、回合到期及玩家隔离。两张随机结果依原生成请求先完整抽选，再逐个实际交付；等待或反应不会重新抽样。场上原随从、旧同名手牌和临时新手牌保持独立身份。

血瓣群系采用当前英雄职业加中立的普通发现资格；坑道恐怪随机获取任意职业的2费随从。临时卡采用现有全局回合末清理政策，在对手回合生成时也于该回合到期；已打出的临时随从沿原生命周期保留场上实体。精确国服资格、获取通知和结束清理窗口仍待校准，没有认证正式标准池或完整可达内容。
