# 地母塞拉赞恩：逐学派的下一次施法

BE_337原完整记录和双语官网主面固定在[data/cards/therazane-v1.json](../data/cards/therazane-v1.json)。适配保留6费5/5萨满传说元素及战吼；七个实际学派各授予一个独立的一次性玩家效果。无学派法术不消费，受益玩家之外的施法不消费；来源随后死亡、沉默或转控不会撤回已授予的效果。

## 现有次数系统中的有限范围

`AddSpellRepeatModifier(..., automatic=True)`扩展原玩家次数预算，旧默认False仍只作用于手牌出牌。本次True只接受总次数2、class_mode=any、一个实际学派、一次用途、明确来源且无到期、费用或场面来源条件。不能据此声称支持任意自动施法预算。`SpellRepeatModifier.automatic`随严格类型化材料保存，不能将授予伪装成手牌法术附件，也不会被复制牌继承。

每次实际战吼安装七个独立附件身份。同一学派的多份已存在预算全部消费一次，次数按原系统取最大值；双施法重合仍总共两次。原随从战吼执行器负责是否发生额外战吼，本牌不自行遍历或乘算主体。

## 接受与消费

手动出牌继续使用原提交窗口、完整SpellSubmissionReceipt和SpellPolicyReceipt。付款失败不消费，真正提交后即消费，反制不退还；重复子施法不再消费，新安装的预算留给下一次原始施法。旧手动政策和较晚的场上重复光环窗口不变。

效果施法、抽到时施放和历史重施仍交给原自动CAST执行器。原接受窗捕获当前受益玩家、原施法实体、全部适用卡牌附件、逐学派预算和原生提供者。CardCastRepeatPlan新增完整player_modifiers及modifier_hero_class；CardCastRepeatProof保存原State及规则，恢复时重算原贡献库存。成功接受目标后才原子消费匹配的一次性预算，接入原RepeatAutomaticSpell，产生一个真正的native_repeat子CAST；不是重复调用裸效果函数，不额外打出、支付、抽牌或补抽。

当前本地政策：无有效自动目标的失败尝试不消费；施法正文随后失效或终局不退还已接受消费。自动重复子CAST不重新接受玩家预算，正文或开始反应中新安装的预算不会被该子CAST消费。目标、选择、死亡、法术完成、来源费用和结算帧继续复用原执行链。原生提供者、物理牌属性与玩家预算重合时只保留原总两次计划。

以上逐学派重合、自动失败、反制消费、目标重用和精确窗口仍待国服M6校准；完整原文本不单独证明这些交互。

## 保存、历史与玩家边界

添加事件私有保存完整原预算材料`_spell_modifier_material`，自动消费私有绑定`_automatic_cast_id`；原手动消费继续绑定play_id。边界验证将完整有效事件与真正的手牌收据、自动接受计划核对，拒绝跨来源重复消费、遗漏匹配学派、遗失未用学派、篡改原材料、借用其他附件和无消费见证。主动移除仍是明确的原移除事件；本有限范围不允许自动到期。回溯使用公共effective_events分支，不能用已退休分支的添加/消费替代当前分支。

挂起的原完整贡献、来源、分配上界和原始规则均通过原FrameCodec保存；独立注册表JSON恢复、clone和回放保留同一事实。未结束动作异常回滚整个事务；待选失败回到原待选边界，已经接受的消费保持。

私有材料、贡献ID、原State、消费对应关系和结算帧不进入玩家观察或日志。现有公开次数及学派结构保持，动作13、观察115、replay1不变。core638/schema526拒旧1～525；内容版本v470。没有新增Effect或payload类型，也没有新的State账户。

实际测试范围、结果、已知差异和下一项只在[项目状态](project-status.md)与[机制清单](mechanism-backlog.md)记录；本契约不认证M0正式部署/合法池、完整可达域、M6国服行为或M7发布。
