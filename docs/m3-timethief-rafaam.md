# 时空大盗拉法姆与原生拉法姆费用

本批接通TIME_005主卡、TIME_005t7巨人和原奇闻构筑声明，复用`simple_followup_p70_cards.py`已实现的八张伴生牌及绵羊。九个已有完整定义和行为不替换。完整来源、实际结果与下一项仅在[项目状态](project-status.md)及[机制台账](mechanism-backlog.md)维护。

## 构筑成员与效果族分别声明

[数据包](../data/cards/timethief-rafaam-v1.json)固定十一条完整客户端记录及二十二份双语官网完整响应。构筑成员使用官网明确的`bundledCardIds`，不是所有`childIds`：一张主卡、九张不同伴生牌加三十张自选牌，共四十张。原`FabledSpec`和`DeckSizeRule`处理名额、容量、职业、副本、不可收藏资格、展开和真实开局；`DeckSpec`仍需提交完整四十张物理牌表，不在开局临时填充或随机替换九张牌。

绵羊不在这九个伴生名额内，但完整冻结库中十一条`3928=1`记录包含它。原P70效果族已据此涵盖绵羊，本批保持其抽牌、增益、持有条件、减费和非拉法姆排除语义。构筑的十张成员与效果筛选的十一张身份不能互相代替，也不通过名字、ID前缀或种族猜测旧系列拉法姆的资格。

## 主卡与巨人

主卡保持10费10/10，战吼在原实际执行窗口读取本玩家的冻结物理出牌历史；九个不同原伴生身份均已出现时，返回普通`Destroy`作用于敌方英雄。只计实际付费手牌提交记录，使用零费或其它支付资源仍是使用；复制体重新正常打出可以贡献其身份。召唤、普通自动入场、敌方出牌和重复使用同一身份不能代替其它尚缺身份。消灭、英雄致死替代与终局仍由原内核处理，不用伤害绕过护甲或另写胜负结算。

巨人保持8费8/8突袭，使用有限`cost.player-played-rafaam-v1`。它共用既有`PlayerPlayedClassCostSpec/Fact`的完整冻结出牌前缀，只改变实际身份筛选：每次本玩家使用已核定效果族中的牌减一，重复使用也分别计数，绵羊属于此费用筛选。召唤和敌方历史不计；后来变形、控制和获取不重写原使用身份。当前自己尚未提交时不计入自己的付款，完成原提交后才影响后续报价。零下限、本地费用、鱼人拉法姆的下一张减费、外部支付层和一次性消费仍走原费用管线。

没有新增对局计数器、模型字段或效果类型。完整价格事实保存全部原付费卡面、选中记录、数量与原价/结果，由原序列化及前缀校验承接；待选、恢复、回放和重算哈希后的裁改检查共用既有契约。该有限费用声明只允许实际巨人，并要求完整原奇闻包和40张声明存在。

## 复用与证据边界

小小拉法姆的战吼/亡语仍抽取原牌库物理牌；绿色拉法姆不增益自身；探险者从原牌库发现并获取原实体；大酋长先获得五护甲再重读实际手牌条件；夺心者沿原当前复制与容量；灾异和大法师沿原伤害批和捕获变形；鱼人沿原一次性指定身份减费。主卡和巨人接入后，这些旧消费者的原完整族过滤自然包含新定义。

[官方34.2.2说明](https://hearthstone.blizzard.com/en-us/news/24250382/34-2-2-patch-notes)支持小小同时有战吼/亡语、绿色不影响自己及大酋长读取手牌的修订。[历史本人报告](https://us.forums.blizzard.com/en/hearthstone/t/timethief-rafaam-wrong-work/159051)及后续讨论区分重复使用和不同原伴生身份，但不是当前国服完整校准。

本地采用`rafaam-family-v1`，主卡完成条件要求九个明确原伴生，巨人费用沿十一身份效果族和原提交历史。绵羊能否代替某个主卡完成身份、计数和反制/战吼的精确窗口仍待M6国服；本批没有把数据标签或历史讨论当作已穷尽的官方运行规则。普通生成仍遵守原奇闻硬排除和完整宿主池，不因注册这些定义认证M0正式合法或生成池。内核604、快照498；观察114、命令12、回放schema1保持。
