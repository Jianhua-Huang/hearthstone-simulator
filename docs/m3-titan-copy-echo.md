# 阿曼苏尔与 V-07-TR-0N：原目标与完整重复主体

[完整原记录](../data/cards/titan-copy-echo-v1.json)保存两张泰坦及六个技能描述，八原行、十六个完整双语主面。描述费用只按官网两语零值归一，原 COST 缺省不改；choice-only 不能成为物理法术或生成候选。两根是标准实际调用依赖，不新增标准构筑资格；完整十二泰坦参考仍保持、不按效果覆盖裁池。

[卡牌适配](../hs_sim/cards/titan_copy_echo.py)组合既有公共效果，不增加内核字段、机制类型或协议。三技能各一次，只消耗原泰坦行动，不付额外法力、不创建 CAST。

## 阿曼苏尔

复制技能以已有玩家可见目标规则排除当前具有 TITAN 的随从，允许其他友方或敌方随从；复制及原+2/+2入场授予沿 CopyMinion/CreatedMinionGrant，不重新执行战吼。满场保留原复制失败政策，仍完成本次技能及后续被动。

移除技能使用 RequestChoice 的原 BOARD 目标契约，按当前可选敌方数量选择至多两个不同原物理驻留。原完整选项、目标事实、Noggenfogger 替换、部分执行及等待恢复交给既有解释器；选择后以一个 RemoveFromGame 批次移除原引用，不触发死亡、亡语或复生，不在卡牌回调直接改区域。

六费技能按完整普通域的印刷六费随从候选随机召唤，以现有原入场关键词政策赋予嘲讽/吸血。三技能实际完成通知后，只对原来源自身使用技能触发可收藏传说随从发现，任意职业及中立均走完整普通域，不按当前玩家职业过滤。普通生成排除泰坦等既有政策保持，精确专用例外和入场中间窗口仍未当前国服校准。

## V-07-TR-0N

每次原生技能先执行自身完整主体，再以普通续接读取当前其他友方活跃随从，通过 ChooseRandomEffects 选择一个接收者并执行同一完整主体。不是只重复增益：火炮各加2/1并分别造成四点随机敌方能力伤害；动力各加1/2并各抽一张；防御各加三生命并获得扰魔。没有其他友方随从时不产生重复主体或额外选择 RNG；重复不消费接收者行动、不执行第二个泰坦技能或发送第二次技能完成通知。

炮击使用接收随从本身为伤害来源，其自身剧毒、吸血能够生效。这来自[暴雪工程师的历史完整问答](https://us.forums.blizzard.com/en/hearthstone/t/dev-talk%E2%80%94totally-titans-all-about-the-new-keyword/109540)，不把文本中的“重复”错误实现成仍由原泰坦造成两次伤害。能力伤害继续使用 MINION_ABILITY，不受法术伤害放大；随机敌方目标在各次炮击实际正文查询后交原执行器，独立抽样。

接收者增益保存原 MinionReference，主体来源采用该接收随从。当前本地政策为原完整主体后再从新局面选择接收者；整次已接受重复续接可在原来源随后死亡时继续，增益不追随失效原驻留。精确选择窗口、少量来源日志与源离场边界仍记录待校准，没有把这些内部政策冒称官方当前规则。

## 验收边界

随机分支及原目标选择的通知、等待、恢复、RNG、原付款/行动回滚、克隆、独立注册表回放与玩家信息沿原管线。未知合格发现成员须显式失败并回滚，不能裁候选或作为白板。完整宿主实际六项技能与所有候选定义闭合另行验证；拥有展示面或注册数不替代行为。
