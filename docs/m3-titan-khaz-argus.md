# 艾泽里特鹰的泰坦参考与两张原生泰坦

[完整20原行与40官网双语主面](../data/cards/titan-reference-khaz-argus-v1.json)保留固定原目录的12个可收藏TITAN标签身份，不按已实现程度删候选。六项技能的原记录没有费用标签，完整官网主面明确显示0；仅按来源逐项声明描述费用0，原行仍保留缺省值。它们是 choice-only 展示卡，不能作为物理手牌、可施放法术或随机生成候选。

艾泽里特鹰明确要求随机获取一张泰坦并设1费；原文及完整主面不能证明精确成员、权重和禁用。这里保留12成员、各权重1的本地未绑定参考，不升级为当前国服正式池。[官方工程师泰坦说明](https://us.forums.blizzard.com/en/hearthstone/t/dev-talk%E2%80%94totally-titans-all-about-the-new-keyword/109540)说明三项一次性主动技能、技能不是法术、强制战斗不另消耗普通行动，以及普通随机生成/进化对泰坦的排除。专用来源例外与普通生成资格必须分开；本增量不修改普通生成池或开放发掘profile。

## 卡兹格罗斯

[原生适配](../hs_sim/cards/titan_khaz_argus.py)将三个真实技能交原 ActivatedAbilitySpec：泰坦锻造自身加2/2并实际抽取一把武器；升温回火自身永久加5攻、英雄本回合加5攻；烈焰之心自身加5生命、英雄加5护甲。技能消耗原泰坦行动及对应能力，不付法力、不算施放描述法术。

原 minion_ability_used 通知后，对仍存活的原来源授予本回合免疫，再读取当前敌方随从，交公共随机强制战斗。空敌场仍获得免疫而不抽样；强制战斗不增加第二次普通行动消耗。技能主体、抽牌/获取反应、结束通知与强制攻击复用原解释器；来源在已接受技能中离场后，驻留增益不追随新体，实际抽牌等独立效果仍继续。免疫授予后的精确反应窗口仍为待校准本地政策。

## 阿古斯

三个真实技能复用普通执行器：按完整宿主普通域发现当前职业/中立的可收藏亡语随从并永久减3费；对主体捕获的当前手牌随从逐张按原 CardReference 永久减2费；四次独立具名召唤已有的TTN_862t4晶石元素。元素原定义、2/2、嘲讽及印刷种族保留，不重复实现或创建新衍生物身份。四次实际入场各处理当前容量与反应，不把四个同名材料塞进单次随机候选当次数。

两条印刷 KeywordAuraSpec 增加有限目标值 friendly_minions_left_of_source 与 friendly_minions_right_of_source，分别只允许突袭和吸血。来源必须是普通非合成随从；不允许独立授予、包含自身、仅相邻、条件、种族/身份过滤等其它形状。原字段、旧最左/最右及其他关键词光环政策保持。

接收者按当前物理BOARD顺序相对于来源的左右侧选择，再交原活跃角色与自身排除筛选；跨过地标位置仍覆盖该侧其他随从，地标不获得关键词。控制、沉默、回手、复制及场位变化由同一刷新器重新贡献，不向接收者永久写入授予附件。不同阿古斯分别贡献，当前复制继续保留真实泰坦已消耗技能。

## 保留范围

军队使用既有普通具名召唤的放置政策；精确相对来源的放置位置、发现资格及少量反应窗口继续记录待校准，不要求新增困难随机实验。12张泰坦的完整名单、已实现效果和艾泽里特鹰生产绑定分开验收；其余成员和能力不会因有数据或展示描述而被当作可执行。

来源、实际执行、验证和下一项仅在[项目状态](project-status.md)与[机制清单](mechanism-backlog.md)登记。版本对齐和国服规则边界依用户要求暂缓，本地未知仍须显式报错。
