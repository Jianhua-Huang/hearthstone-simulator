# 高戈奈斯与阿米图斯：复用原数值、抽牌与持续规则

[完整原行与主面](../data/cards/titan-value-effects-v1.json)保存两张泰坦及六个技能描述，共八原行、十六个双语官网主面。六描述无原 COST，只依据两语主面声明描述费用零；保持 choice-only，不成为物理法术、手牌或生成候选。两张泰坦也不因此进入标准构筑根，完整十二泰坦参考继续未绑定。

[原生适配](../hs_sim/cards/titan_values.py)只组合已有公共能力，不新增内核字段、执行器、效果类型、payload 或版本协议。内容包推进，core781/schema611保持。三技能仍各一次，消费原泰坦行动，没有法力支付或 CAST。

## 高戈奈斯

首张法术减三费直接使用 CostAuraSpec 的 first_per_turn 与普通费用减值。来源必须仍贡献原持续光环；依据既有实际手牌接受历史判断本回合的第一张法术，不另建计数器，不在来源入场、回手或重新出现时重置原玩家资格。沉默、转控、离场和正常回合刷新继续走原光环及支付管线。自动施法与极少数特殊接受窗口保留原本地政策，未认证当前国服裁定。

狂海怒涛先交 DamageBatch 对所有敌方角色造成三点 MINION_ABILITY 伤害，再以普通续接重新读取当前友方角色并交 HealBatch 治疗六点；不是法术伤害。天空之王对另一个友方或敌方随从造成二十点能力伤害，不能选择自身或英雄。

沙加恩之怒复用 DrawMatching，匹配已有完整固定目录中全部九十八个正印刷 OVERLOAD 身份，保留原物理牌、获取与烧牌管线；无匹配跳过，不伪造疲劳，也不为抽牌创建副本。物理检索没有 collectible 过滤，不把既有生成来源的可收藏限制移植到牌库检索。九十八原始事实文件保持完整针脚，这不表示新增九十八张可生成卡或认证其独立效果覆盖。

## 阿米图斯

嘲讽与 HealthRule 的入伤 CAP2 是印刷声明。接收者为当前友方随从，包括来源自身，排除英雄和敌方；每个伤害包分别限制。原同时伤害批次冻结贡献规则，因此来源在同批致死，不会反向改写其他原包的上限；后续新伤害重新读取当前来源。

增援直接复用两个随从检索槽及 DrawGroupReward('set_stats_cost_all',2)。原两次物理抽牌完成后，仅对仍符合原交付的手牌设攻、生命和费用为二；原抽牌观察、空检索、满手烧牌、离场引用与真实付款保持。强化对其他友方随从加二攻二生命，来源自身排除。平静对原敌方随从逐个使用现有 SetStats 设二攻二生命，并清除原累计伤害；精确跨属性光环/死亡的窗口仍属本地待校准边界。

## 验收辅助与保留范围

共享 tools/card_batch.py 的 observe_local_host 只读取实际宿主完整结构，不创建或推进 Game；check_local_host_preservation 比较完整旧定义、元数据、有序池对象、权重/排除/complete、标准资格、族、原生捐赠及源 scope。相同 pool id 在不同目标域的对象保持独立，不能先压成按 id 的字典。多层宿主的目标标识必须保持各自角色及一对一映射，实际版本摘要变更逐项记录；源查询和实际完整库存摘要继续核对。结构保全不能替代卡牌行为测试，也不认证未签名外部存档。

没有因此开放艾泽里特鹰完整泰坦池、真实发掘 profile 或 WW_009。正式版本对齐、三符文/其他专用资格及规则边界依用户授权暂缓；完整目标、实际验收和下一项仍只在[项目状态](project-status.md)及[机制台账](mechanism-backlog.md)维护。
