# 变形后的原随从召回

升腾CATA_567使用[完整固定源](../data/cards/ascendance-originals-v1.json)：4费萨满史诗自然法术；CATA_567e只保留为完整附魔证据，不注册成可使用卡牌。新适配组合原费用层、整批变形和复制召唤，没有卡牌私设结算器。

## 接受与授予

`TransformMinionsInZones.deathrattle_behavior_id`是可空的有限入口，只接受有真实来源的普通战场批次，不混入存储区域或保留费用覆盖。原目标、位置顺序、印刷费用加1的档位和完整生成候选仍由原变形模块捕获；未知合格定义明确失败，不从池中删除。空档位保持原随从，不耗随机数、不安装召回亡语。

接受整批时，为每个原目标捕获现有`remembered_copy`完整当前局部材料，再装入`GrantDeathrattle.deathrattle_memory`。该可空字段仅接受带材料的copy_summon永久记忆，不能用于任意原生成长、抽牌、弃牌或囚禁记忆授予。原生声明、真实继承和这一有限授予分别核验；原NativeDeathrattleSpec类型仅复用其已知复制载荷形状，没有新增全局状态。

原`TransformPoolTarget`和`TransformCapturedMinion`保存原目标与完整授予，核对两者物理身份一致。执行仍先检查原目标是否存在；发生离场、换面或转控时按原引用规则跳过，不将亡语授予新身体。真正变形在重置、原属性清理后调用公共附件安装，在首次transformed通知和普通入场前已有完整记忆；随后发布授予通知。随机、巨型、印刷休眠、存活与位置继续共用原流程。

## 亡语与生命周期

实际亡语只读取已接受的DeathrattleCapture中的记忆，再交`SummonByCard`和原复制入场器。在自然死亡位置或活体旁边交付，不执行原随从战吼。印刷新身体已有的亡语和新增召回亡语是独立附件；沉默、再次变形、回手重置移除授予，当前复制保留，基础复制不保留。重复施放保存有限的嵌套旧材料，原时间期限不会在延迟召回时重启，见[原复制材料契约](m3-frozen-deathrattle-copy.md)。

严格记忆校验覆盖活动身体、原死亡、嵌套复制与待选变形请求；FrameCodec同时验证单独排队的带材料GrantDeathrattle，不能借恢复注入未来材料。异常回滚、选择继续、快照、clone、回放和玩家隔离沿原解释器。core543/schema438拒绝旧1～437；观察99、命令12、replay1保持，没有新Effect类型或GameState字段。

## 证据和未确认项

官方[36.6.1热修](https://us.forums.blizzard.com/en/hearthstone/t/3661-hotfix-patch/165846)修复与休眠随从交互后单位失效；[36.2公告](https://hearthstone.blizzard.com/en-us/news/24290432/36-2-patch-notes)修复受伤的时流扰动者经升腾后遗留永久法术伤害。两份完整HTTP响应及SHA已归档；内部覆盖休眠原体、休眠目的体与真实END_022的动态法术伤害，不模拟已修复的失效状态。

公告和卡面没有证明所有增益、伤害、当前/基础复制及回手细节。当前采用整批接受时冻结完整局部当前材料、印刷费用升级和原时钟策略，完整数值与生命周期均是显式本地政策待M6，不冒充国服确认；正式合法/生成池和全部实际可达内容仍开放。实际进度、测试结果和下一项只在[项目状态](project-status.md)及[机制台账](mechanism-backlog.md)维护。
