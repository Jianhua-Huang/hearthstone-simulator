# 亡灵原生效果与实际英雄生命条件

本批五张原生卡的[完整来源包](../data/cards/undead-native-v1.json)保留冻结37.0原行、原行哈希、实际依赖完整定义及独立视觉证据。两种语言的官方卡库观察与国服职业系列开放公告分别归档；卡面相同不证明精确时序或完整标准合法池。实际执行、验收结果、差异和下一项仅在[项目状态](project-status.md)与[机制台账](mechanism-backlog.md)维护。

## 原生声明

- 暗影升腾者CORE_ICC_210声明既有`turn_ended`与`EndTurnSpec`。执行时用原`InvokeBehavior`读取当前场面，只列另一个存活、活跃的友方普通随从；以物理实体为权重，随机一次后用普通属性层给予+1/+1。保留ICC_210组牌身份；旧版原行仅作别名证据。
- 累叠食尸鬼JAIL_440监听自身正数实际`damage_dealt`，不另加“受到伤害并存活”条件。两个归因于原触发的`SummonByCard`请求复用数量、空位、死亡及后续结算。官网固定子卡为已有HERO_11bpt，完整定义保持原冲锋及本人回合结束死亡，不注册同名白板。JAIL_440e只保留为独立证据，不凭视觉附魔推导额外行为。
- 绝望鬼灵JAIL_942用原嘲讽与`AttackPolicySpec('cannot_attack')`，同时保留亡灵、德莱尼两种族。沉默、控制、攻击限额与强制攻击沿原生命周期；强制攻击绕过自愿攻击限制是既有公共政策，仍须国服校准。
- 生命撕裂者TIME_614用原生战吼及敌方场上随从`IF_AVAILABLE`目标域。目标资格与实际主体都读取同一真实英雄生命变化账本，检查原玩家与当前全局回合；不使用当前损血量、单纯受伤、累计本人回合次数或宿主日志代替。
- 游荡之魂CAP_803用原复生与亡语。按原亡语控制方对当前本人英雄请求3点`EFFECT`治疗；仅原提交`HealthResult.overheal`为正时，通过`InvokeHealthResult`在当前局面选一个随机敌方角色，造成相等的`MINION_ABILITY`伤害。实际治疗倍率、转换、防止、重定向、伤害与死亡仍由原处理器执行；不以请求量减当前缺血量重算过量，不增加法术伤害。

## 最小公共能力

`RandomBuff`保存不可变、无重复的物理候选ID及普通属性量。处理时筛选仍存活、活跃的场上随从，按原随机机制选择一次，再产生普通`Buff`。空池记录跳过且不消耗随机数；不新增玩家选择、效果回调或属性执行器。卡牌在紧接的主体执行窗生成候选，沿既有随机伤害的候选与通知政策。保存编码复用公开Effect的有限类型清单，失败回滚沿原事务恢复属性、事件与随机状态。

`HeroHealthChangedTargetProfile`是注册表内的有限原生声明：只允许已有敌方场上随从目标域的普通随从战吼。注册表校验、只读查询、冻结和指纹覆盖声明；未使用时不改变旧默认注册表指纹。不增加CardDefinition、State、Entity或玩家DTO字段，也不注册可以读取全知状态的玩家目标回调。`targeting.effective_target_spec`在既有第一张复制法术规则之后应用该声明，供合法动作、提交及自动目标共同调用。

`changed_this_turn`只读`hero_health_change_history`中原玩家、原全局回合对应的实际剩余生命变化。对手回合间接触发同样按该全局回合判断，不错误使用仅累计本人回合的血肉巨人查询。护甲单独变化、护甲承伤、没有实际恢复的治疗均不产生资格；先受伤后恢复到原值仍保留真实变化。英雄替换、支付、赋值及恢复仍由原[英雄生命事实](m3-hero-health-changes.md)入口记录。

原手动目标在支付前判定，实际战吼主体在其执行窗重新检查；没有提交目标时不在后续凭空生成一个选择。重复、间接与历史战吼仍复用原生产者，不增加本卡私有战吼解释器。原目标离场、转手、重入与主体条件在既有消费者窗口处理。

## 证据边界

[国服职业系列公告](https://hs.blizzard.cn/news/24293282/)明确“艾泽拉斯头号通缉”于北京时间2026年8月26日凌晨1点开放，早于本轮37.0目标；[36.4公告](https://hs.blizzard.cn/news/24293283/)说明获得方式。CAP卡不能仅因前缀或MINI_SET标签被当作尚未开放，也不能据本次窄范围公告认证全部正式池。

原生结束顺序、致死受伤通知与空位、条件接受窗、治疗后反应与过量伤害顺序及特殊英雄处理保留为M6待国服校准政策；当前内部行为契约不声称已获官方时序证明。完整亡灵、鲜血或其他随机生成池仍须各自闭合，不能只筛已注册卡开放。
