# 亡灵资源、原抽取对象与原生法术参数

真实抽牌条件只读原两次物理抽牌，来源奖励绑定原连续驻留；按实际消灭奖励保存原目标与死亡原因，继续委托普通死亡、抽牌和法力执行器。有限请求及待国服边界见[五费随从契约](m3-five-cost-native.md)。

[完整原行与固定龙息](../data/cards/undead-resource-native-v1.json)描述五张真实原生卡及一个固定衍生物。两种语言的官方卡库观察保留动态数字占位的差别，不将缺失展示数字当作实际效果金额。实际执行、测试、差异与下一项只维护在[项目状态](project-status.md)和[机制台账](mechanism-backlog.md)。

## 原生效果

- 多彩龙巢母CATA_469保留突袭、龙与亡灵。仅响应自身真实`attack_declared`，以原行为上下文的攻击力调用`RefreshMana`。没有增加最大法力水晶，也不按伤害数值回费；资源上限、锁定与攻击结算沿原内核。
- 艾森娜EDR_430在实际战吼主体窗口查询本局`DeathRecord`中原控制方相同的随从死亡，至少20个才发出20点`MINION_ABILITY`的`SplitDamage`。每个单位沿原机制重选当前敌方角色；此前获取时点不重置死亡事实，消灭/复生的真实死亡与回手、变形等非死亡移除不同。
- 恐惧迅猛龙TLC_432保留亡灵、野兽和原生延系profile。只抽一个原物理牌库对象：当前有亡语、当前牌库费用不高于3的随从。延系仅将实际到达且仍在原手牌驻留的对象设为0费；下一个延系翻倍仍只抽一次，重复费用部分。移交、离手、爆牌和抽牌替换由原抽牌组接收事实处理，不按同名或最终手牌扫描补奖励。
- 黑翼实验品CATA_464保留龙与亡灵，实际亡语生成固定2费龙息CATA_464t。其基础伤害来自该次真实亡语主体的攻击力，不是法术伤害附魔或卡面占位1。自然死亡用原`DeathRecord.attack`，主动/存储亡语沿已有首次接受与额外执行上下文政策。
- 时空封冻者TIME_617是可移除的原生持续来源，只阻止正常回合开始抽牌。法术、战吼、主动抽牌仍正常执行；没有将整回合、所有抽牌或后续玩家永久关闭。休眠、死亡、沉默、换面、复制及控制使用原来源生命周期。

## 原抽牌组的有限扩展

`DrawGroupSlot.max_current_cost`与`current_deathrattle`是明确的物理牌库过滤条件。费用使用原`local_cost`；亡语使用当前未消费能力的结构事实。普通顶牌抽取不能附带这些过滤，亡语过滤要求随从域。没有把印刷费用当当前费用，也不先筛出几种卡名。

`DrawGroupReward('set_cost_all', value, repetitions)`在组完成后对原实际手牌接收对象调用原`ModifyStoredCost(CostSpec(set_to=value))`。本卡value为0，允许原延系的1或2次费用部分；没有改变抽牌次数、抽牌顺序、支付方法或原接收引用的时效。

## 原生基础伤害值

`DeathrattleRecord.source_attack`在主体实际开始时写入一次。自然亡语取不可变死亡记录，首次主动主体取其原接受上下文，额外执行取既有新局面上下文；记录不修改攻击力，也不是新计数器。未开始时为None，实际开始后必须为非负精确整数；原前缀已写入值不可变，原自然死亡值须匹配`DeathRecord`。记录与完成、异常回滚、恢复、回溯共用原历史。

`SpellBaseDamageValue`只保存原法术面、非负基础量和该次实际亡语ID。普通`AbilityInstance`增加两个互斥有限字段：可移除原生抽牌来源声明，以及原生法术基础值。法术值是单一纯附件，须匹配已注册父亡语、实际原载体和原执行攻击事实；不能混入其他能力或重复安装。0是有效的已绑定值。

`CreateDeathrattleSpell`只解析实际执行记录，再委托原`create_hand_card`。参数在原创建/入手事件之前安装，容量、爆牌、生成来源、手牌身份与事件均由原助手负责。原当前卡复制重分配附件身份并保留值；物理洗入和再抽回保留同一值。

实际CAST通过`SpellCastRecord.native_spell_value`冻结完整原物理附件，正文用其基础量产生普通SPELL伤害。法强、倍增、转换、目标、死亡与法术重复均使用原管线；未开始或失败CAST不能冒领值，反制不执行主体。原施法历史重施为新实体安装原冻结值；整卡历史执行则只从明确选中的原出牌ID、其已捕获CAST或仍有原材料的反制来源恢复参数。不能根据同名最新法术或当前源攻击推断。

没有可恢复原参数的派生来源仍明确不支持；尤其不会以raw脚本占位1补白板。历史来源被换面且没有已捕获CAST时的额外原材料，以及保留回溯携带已退休历史来源的完整政策，仍需实际来源证据后补齐，不能以正常当前复制/历史路径通过宣称所有参数继承均已完成。

玩家投影仅对已可见法术面增加`base_damage`数值，绝不输出原亡语ID、完整附件、上下文或状态；对手未知手牌不因此暴露参数。无参数的直接拼装龙息在玩家操作入口明确不支持。新增持久字段和可见字段均有独立schema/view版本，旧存档必须使用其原引擎。

## 正常回合抽牌

`TurnDrawSuppressionProfile`安装可复制、可沉默移除的印刷来源。`BeginTurnEvents`在原开始事件和倒计时之后排入`DrawAtTurnStart`，实际轮到它时读取当前活跃存活来源；无来源就交给原`Draw`。源在开始反应或等待选择中离场后，正常抽牌可以恢复；来源存在时不提出这次Draw，空牌库也不会因此疲劳。

不改变OwnerTurn、回合排程、开始时钟或其他Draw，初始对局与正常轮转共享原入口。内部来源诊断事件不自动输出给玩家。

当前攻击操作数、首次/额外亡语取值、延系条件、重放参数与开始反应/正常抽牌先后仍属于M6本地政策，须国服校准；当前卡面和内部测试不关闭正式M0、完整随机池或全部派生继承政策。


## 蚀解软泥怪与骸骨的双数值材料

`SpellStatGrantValue`保存原法术面、非负攻击增益、正生命增益和原物理消灭原因；独立`spell_stat_value`附件与旧伤害值互斥。两种值共享原生法术登记、原CAST捕获、当前复制和历史重施入口，旧亡语伤害值仍须核对原实际亡语攻击事实。不能将属性值当成法伤，也不能将未绑定骸骨默认为0/0。

`DestroyMinionForStatSpell`只接受原另一个友方存活随从，在实际执行普通Destroy前冻结当前攻击和剩余生命；原引用失效不奖励。后续请求保留原双数值和完整DeathCause，由普通解释器先结算死亡及反应，再委托原create_hand_card；原来源死亡不撤销已接受奖励，已有延后死亡窗口不插入额外检查点。值须保留真实原消灭原因，当前复制重分配附件身份而保留参数，普通基础复制不伪造参数；实际骸骨施法只产生普通Buff。

玩家可见法术面仅增加`stat_bonus={attack,health}`，不输出原因、原引用、附件或私有上下文。保存schema405拒旧1～404，观察95；命令12与回放1保持。冻结当前剩余生命、死亡反应后交付及精确国服交互仍为待M6校准的本地政策；结构化值和自洽原因不提供未签名存档的来源认证。既有完整池与全部派生继承限制继续适用。
