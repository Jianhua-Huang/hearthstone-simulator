# 临时出牌任务与邪能地窟裂隙

TLC_446、奖励法术TLC_446t与裂隙物体TLC_446t1使用[固定完整数据](../data/cards/underfel-rift-v1.json)。三种实际邪能野兽沿用原完整定义，逐项核对定义PIN，不重新注册或替换。TLC_446e保留为原始证据，没有给无独立主体的附魔制造可使用卡牌。

## 原临时出牌资格

任务声明普通QuestSpec及六次card_played进度。只读本人原完成PlayRecord，核对原物理来源、玩家及完成状态，再读取`submitted_cost.quote.quote_input.hand_lifetime`。该事实来自原接受的手牌报价，不扫描后来实体、卡名或诊断日志，不新增任务计数器。

临时随从、武器和法术沿同一资格；实体离手或战吼中变形不会改写已接受资格。普通牌、自动施法、对方出牌与临时牌自然消失没有这项原物理临时出牌事实。任务起效前的使用不追溯补算，任务自身安装和计数时点仍用原任务契约。当前“使用”沿原完成出牌语义，反制不抹去已完成的物理使用；精确国服窗口仍待M6。

达到六次后由原AdvanceQuest、完成帧及普通AddToHand交付一张五费奖励。奖励不是临时牌；满手、等待、异常回滚、任务占位及完成移除继续由既有执行器负责。

## 安装与投牌

奖励法术使用InstallInteractable安装真实0/1惰性物体，没有虚假的随从召唤。本人以原UseInteractable动作投入一张当前手牌，原交互物管线负责一次性消费、实际本人区间、私有移除与公开牌面；这项投入不当作使用、施放、弃牌或死亡，不执行投入牌主体。

主体使用两份SummonFromCandidates，每份明确列出全部三种邪能野兽，携带从原物体捕获的SummonCause。每次执行先核验完整候选，再沿当前容量、普通召唤数量计划、随机与入场；保留一次实际投牌和两次独立召唤请求。缺失候选明确失败，不从池中删牌。等待后不重复投入、消费或抽选已经完成的第一项。

本次不改变[既有交互物契约](m4-interactables.md)：物体占用场位、满场安装失败、可立即激活、按每个物理物体每个实际本人区间使用一次。位置、容量、揭示及精确优先级仍是待M6政策，不能从卡面推定全部已与国服一致。

## 裂隙的传说特征

[官方34.0.2公告](https://hearthstone.blizzard.com/en-gb/news/24247520/34-0-2-patch-notes)确认六次任务与五费奖励；[35.6公告](https://hearthstone.blizzard.com/en-us/news/24276665/35-6-patch-notes)明确修复裂隙在场时「麦迪文的胜利」未正确减费的问题。完整HTTP响应与SHA见[来源记录](../outputs/card-integration-20261014/k267-underfel-rift/rule-sources-01.json)。

原裂隙有ELITE=1，没有RARITY标签，官网非收藏牌也未提供rarityId。通用解析器对这种缺省仍保持原Rarity.NONE政策；本卡在固定数据的metadata_overrides中显式声明运行时Rarity.LEGENDARY，使既有“控制传说牌”查询识别物体。该声明依据原标记与上述明确规则，不补造官网制作稀有度、不改XML或API响应，也不把其他未核对的非收藏牌一并提升为传说。

原物体攻击值缺省仅按两个完整主面的0作逐卡声明，原行不改写。数据存在、规则声明与国服完整支持分别登记。
