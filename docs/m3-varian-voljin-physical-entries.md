# 瓦里安与沃金的原物理对象

[完整两原行、四官网主面和定义pin](../data/cards/varian-voljin-dependencies-v1.json)对应AT_072瓦里安·乌瑞恩（10费7/7）及BAR_080暗影猎手沃金（5费3/6）。两者都是WON_113实际列出的传说依赖，原父面及十二个childIds引用已保留的[来源文件](../data/cards/legacy-champion-dependencies-v1.json)。本契约不增加标准构筑根、不改变任何专用池成员；执行进度与实际验收仍仅在原两份台账登记。

## 瓦里安的三个原槽

原卡战吼建立三个顺序执行的RecruitTopMinionOrDraw，每槽保留原SummonCause，执行时重新读取本人当前牌库顶部。随从且实际场位未满时，直接交已有SummonStoredCard，移动原实体并沿公共召唤展开；不先入手，不额外制造抽入手记录或执行战吼。其他类型、满场或空库交普通Draw一次，继续复用爆牌、疲劳、抽到时施放及其补抽。补抽属于自己的原生产者，不把其随从重新算作瓦里安的直接召唤。

场位读取结算器实际Ruleset.max_board；不在卡牌层写死七格，也不增加回调对规则对象的私有读取。每个直接入场在原接受窗单独捕获数量计划，第一体仍是牌库原对象，额外体仍用原不可变材料。原槽之间的正常反应可改变下一张顶牌、空位或来源状态，剩余已排定原槽不会因瓦里安离场而改成新的战吼。

此路线依据固定卡面及[社区整理的卡牌澄清](https://www.hearthpwn.com/cards/22342-warian-wrynn)、[开发者答复转录](https://www.hearthpwn.com/forums/hearthstone-general/general-discussion/56166-card-mechanics-interactions-clarifications)和[社区规则手册](https://hearthstone.wiki.gg/wiki/Advanced_rulebook)。资料说明满手仍可直接召唤、满场改入手、顺序入场及不触发直接入场随从的战吼；原三条CM_Whirthun链接本次返回403，未声称读到原始官方正文。固定37国服的细微通知窗口仍未校准。

## 沃金的原目标与当前控制者手牌

原目标由普通IF_AVAILABLE战吼目标规则选择，范围为双方可选随从，排除本次出牌来源；没有目标时仍可正常出牌。效果接受时捕获原MinionReference与原造成来源，SwapWithControllerHand只从该目标当前控制者的手牌选取随从。实体原始owner不改；将卡面“拥有者手牌”解释为当前controller手牌是明确本地政策，已被窃取目标的精确国服语义仍待校准。

同名物理手牌各占一个等权位置。无可用手牌随从、原目标已过期或离场时不交换、不抽样。随机选中及原第一移动沿既有交换/召唤接受窗提交，不拆成两个可被反应打断的回手、召唤动作。原目标移出腾出的场位和原手牌移出腾出的手牌位置均可使用，满场/满手不会把合法交换误判为失败。

新SummonStoredCard与RecruitEntryMaterial仅增加受限swap_with_controller_hand布尔，必须附原交换目标、正确手牌归属、原造成来源及普通无额外授予的手牌材料。False仍走原报警机“自身与对手手牌”验证；True不能借用旧来源自身关系，历史、待选、解码均保留这个原模式，不能按恢复后的局面重新推断。原目标返回时重置主动增益、伤害和费用层，原手牌保留当前材料；控制者与原始owner各按原物理移动政策处理。

两实体完成分配后才发布回手、获取及入场通知。回手获取记录使用真正的原造成来源；原报警机来源恰是被返回的本体，因此其既有记录语义保持。数量倍率仅第一次返回目标，后续体创建不可变额外实体并逐次检查容量。恢复、异常回滚、随机状态和玩家隔离继续复用[原物理交换契约](m3-physical-hand-minion-swap.md)及公共解释器。

## 保存与边界

两种新增Effect只表示真实卡牌所需的有限入口，没有新增顶层GameState或独立调度器。core811/schema631，旧1～630存档拒绝；旧Effect和payload类型保留，原RecruitEntryMaterial载荷严格增加模式字段。普通物理召唤、旧对手手牌交换与新控制者手牌交换均须覆盖恢复和回放，带错误模式、玩家、原驻留或非布尔声明的保存不能借用另一来源。

社区依据、本地owner解释、数量来源与精确通知窗口的差异保留，不冒称国服全机制校准。WON_113父卡及其两个选择面、托奇完整法师来源仍须后续明确绑定；取得并实现这两个依赖不代表专用池目标已完成。
