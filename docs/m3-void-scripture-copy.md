# 虚空经文：原发现交付后的条件复制施法

YOG_507 使用普通当前职业法术发现。完整原始记录、官网中英文主面和完整过去法师参考名单固定在 `data/cards/void-scripture-v1.json`；这不是正式卡池完成声明。

`DiscoverFromPool.cast_affordable_copy` 只接受一轮、三个选项、普通手牌交付的当前职业可收藏法术发现，不接受其他授予、目的地、折扣或重复参数。选中时增加一个有限的 `CastAffordableDiscoveredSpell` 续接，绑定完整原选择、真实父 CAST 和原接受事件。普通发现先完成实际入手或烧毁及通知；随后才读取剩余法力与完整费用报价。报价不付款，也不消费下一次法术费用修正。

原发现卡仍在原手牌连续驻留且卡面相同时，使用完整当前法术材料和物理报价。满手烧毁、离手、重新入手或换面时，采用原选中的印刷法术及完整生成报价，不借其他同名体。此损失政策与非魔法值支付法术仍按数值比较剩余法力的政策尚未国服校准。

满足费用条件后，复制直接建立为独立普通法术实体，通过既有当前存储材料复制器和 `spell_casts.automatic` 执行；不暂时插入手牌或牌库。复制不再付款，原发现手牌保留。目标复用 `ENEMY_IF_AVAILABLE`：有合法敌方目标时只选敌方，否则退回既有合法目标域；无目标法术正常执行，自动发现使用原随机选择政策。

原接受和完成证明仅进入私有事件。恢复时验证原菜单、选择、交付、父 CAST 接受窗、唯一待执行续接和实际自动 CAST；不提供未签名存档的来源认证。普通等待、事务/RNG 回滚、回放和终局仍由公共解释器管理。

[官方 28.0 修复记录](https://hearthstone.blizzard.com/en-us/news/24008693)明确要求被选中并立即施放的奥秘不会因此暴露。普通信息投影继续隐藏秘密 CAST 与选择，私有条件复制证明不得进入玩家 DTO。准确国服交付时序、原卡损失/变形及替代支付边界继续登记为本地待验证政策。
