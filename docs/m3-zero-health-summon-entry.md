# 非负生命的入场材料

`SummonStats.health` 接受非负整数，继续拒绝负数、布尔、浮点和没有任何覆盖项的声明。零值和正值共用既有材料、编码及 `apply_summon_stats`，没有新的召唤、死亡或复制执行器。

固定属性在首个入场通知之前安装，指定生命仍清除原伤害，再按普通层序刷新光环。局部0/0可以因既有光环成为存活随从；没有光环时由原死亡检查点、召唤历史、死亡原因和残骸执行正常死亡，不能用额外 `Destroy` 代替。成功入场后死亡仍是一次成功召唤；满场则沿原容量入口失败，不分配替代实体。普通召唤、具名召唤、复制和复活继续共用原固定属性材料。

JAIL_511孤守晶塔的实际使用主体捕获本人当前手牌数量一次，将真实JAIL_511t的入场材料设为该数值；不把地标计入手牌，也不在入场反应或数量额外体中重新计数。费用、耐久、冷却及满场使用资格沿原原生地标入口；精确国服使用门禁另行校准。

攻击续接使用既有 `SummonEntryMaterial.on_summon`、`original_named_reference` 和 `AttackRandomEnemyMinion`，无需扩展原仅限法术的固定召唤攻击profile。每次实际交付绑定原实体与战场驻留；离场重入、死亡、休眠或转控使该受益体无效时跳过，不改找同名随从。完整敌方候选在原攻击执行时查询，实际随机、强制战斗和死亡仍由公共内核负责；空候选或失效攻击者不抽选。原来源退役不反向撤销已接受的交付和绑定。

完整原主卡及衍生物各有双语官网主卡面，JAIL_511e仅保留完整raw证据；不能依据孤立附魔描述授予主卡没有印刷的免疫。入场反应与攻击的精确接受窗口、额外体及光环政策继承现有内部契约，仍待M6国服校准，不以纯代码通过认证正式支持。

保存版本拒绝旧版，避免旧读取器把合法零材料当作非法输入。实际版本、范围、执行结果和下一项仅在两份原台账维护。
