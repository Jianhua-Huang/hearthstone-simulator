# 僵尸兽首选部件的原生消费者

本文约定已有原生正文成为合成部件时的执行身份；候选资格仍由[独立参考](m3-zombeast-local-reference.md)记录，不以适配数量推断正式池。完整原始数据见[固定批次](../data/cards/zombeast-native-first-consumers-v1.json)，注册入口为[原生适配模块](../hs_sim/cards/zombeast_native_first_consumers.py)。实际验收和下一项只在原两份台账维护。

## 完整声明和原子登记

六个首选部件为 BE_044、CORE_LOE_039、EDR_014、END_013、JAIL_EVENT_100、TLC_102。批次保留六根及 JAIL_EVENT_100t 的七份完整原行、十二个双语官网根主面、原定义摘要与构筑身份；未增加独立定义或标准合法根。注册先核所有原定义、元数据、数值和可捐赠声明，再统一登记六个能力。任一原声明不符，整批不登记。

蛙生原始发现 profile 的完整名字/种族域、黑暗之赐版本和全部十个配方也进入固定摘要；不得只核一个行为名或在部件层重建候选。独立角色参考的完整规范摘要必须匹配，六个身份确在首选参考之内。适配模块不注册 crafted.zombeast.first 或 crafted.zombeast.second，也不改变普通生成资格和现有拼装限制。

## 相关边界

未适配的合格候选必须保留在库存，并在真实入口显式失败/回滚；不能因尚未适配而从池中删除。缺失原发现 profile、原定义或原依赖也必须在注册前失败。独立候选、来源共池、权重以及历史次件例外的未确认项仍见原参考；两个角色域未绑定时没有隐式退回普通池。

专项使用完整本地宿主和明确单候选的两角色夹具，通过真实付费驯兽师制造并使用合成体；嵌套发现/拼装使用宿主原库存。标准任务的实际减三费、原抽牌和攻击内的等待、原来源离场及晚交付失败用于验证真实依赖，没有穷举任意组合。专项见[测试模块](../tests/test_zombeast_native_first_consumers.py)。
