# 围攻城门与原生僵尸兽奖励

`TLC_EVENT_400`沿普通`sidequest`安装、计数、完成和移除。[官方33.6公告](https://news.blizzard.com/en-gb/article/24232759/33-6-patch-notes)明确它是普通抽取的支线任务；完整中英主面要求使用三张亡灵或野兽，再制造减3费的僵尸兽。进度读取真正完成出牌的原`PlayRecord`，用已有`submitted_minion_types`核支付前冻结的当前种族；双种族与All各计一次，对方出牌、非匹配类型和普通召唤不计。精确国服进度窗口仍待M6。

任务完成条件与合成部件角色分别声明。奖励通过已有`CraftMinion`选择两个野兽部件，不把任务中的“亡灵或野兽”误解释成两个不同部件角色。`ICC_828t`原模板是猎人职业的亡灵野兽，两个原生正文槽由完整配方承载；全中英主面省略两个动态槽并显示0费1/1，原本地完整行仍保留。仅其完整原行SHA和明确的两槽/印刷0费声明可通过资料比较，没有放宽其他卡文。

`crafted.zombeast.first`与`crafted.zombeast.second`必须由宿主按目标版本/模式声明完整。两类资格和权重独立于可执行部件适配，不能据已实现野兽、当前职业或卡文行数推断正式池。原生效果、费用、身材合并沿[自定义卡面](m3-crafted-minion-faces.md)，[官方雷克萨介绍](https://hearthstone.blizzard.com/en-gb/news/20888401/null)支持两个原野兽的费用/身材/正文合成。当前仅审四个既有真实部件用于执行验证；它们不是正式候选白名单，也不认证具体原系列身份。

原`CraftMinion`只增加可选`max_part_cost`，默认None保持维克多原预算。围攻城门本地有限配置为每个部件印刷费用至多5、合计至多10；固定减3使用原`discount_amount`，当没有`discount_tribe`时无条件生效。维克多仍读取原接受窗口的持龙条件，原选项标题保持。部件上限先于执行定义查询，所有费用内合格内容在抽样前必须可执行且已审捐赠；不能裁去未知候选。减费作用于最终普通入手的当前费用，不改变配方印刷费用、不放宽部件预算，最低费用沿公共费用层。

两次选择、完整候选/选项/RNG证明、原来源/玩家、排队保全、异常回滚、恢复、回放、最终满手燃烧和玩家隔离复用已有制造管线。任务奖励等待期间保留原完成续接，最后沿普通任务结束移除槽位；不先分配两个部件实体。原生战吼、亡语和关键词由合成卡面的普通生命周期执行，不在卡牌层复制结算器。部件角色重叠不会在两个独立选择之间强行去重；实际正式重叠资格、每部件5费边界、权重、当前种族窗口及国服规则仍待M0/M6。
