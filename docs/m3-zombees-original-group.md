# 僵尸蜂群的原随从与实际召唤组

[完整原行与官网主面](../data/cards/zombees-secret-v1.json)保存NX2_013、实际衍生物NX2_013t和两语言主面。它是过去奥秘参考域依赖，不增加标准组牌根。尸蜂是一费1/1野兽/亡灵；种族读取既有CARDRACE与2534附加种族映射，不丢弃原始未知节点或另造衍生物身份。

## 原使用与目标

在对手实际card_played之后检查成功手动随从入场，读取原PlayRecord及MinionPlayEntry。战吼已经完成，原连续驻留仍须活跃存活；反制、失败、磁力合并、离场或休眠不揭示。原本人使用、自动CAST和效果召唤不构造另一次对手随从手牌使用。满场由既有奥秘requires_board_space门禁保留来源。

有限SummonAttackProfile新增opponent_played_minion政策，只适用于原对手card_played奥秘，不能借普通法术主体或自动最低生命目标规则。原RuleContext没有活动CAST，来源必须是已揭示的物理奥秘；原事件、玩家、完整手牌记录和原入场驻留绑定。战吼选择可能推进动作编号，故原提交动作≤实际card_played事件动作≤奥秘接受上下文动作，同一真实play_id与回合必须保持，不能把这些合法时钟强行相等。实际执行及带事件的FrameCodec恢复重核有效历史中原事件存在，并有同来源/玩家/接受动作的后续secret_revealed。回溯沿既有effective_events，未签名存档不提供来源真实性认证。

同一驻留的变形或转控保留原“攻击它”对象；真正离场及同ID新驻留不重绑，后来同名新体也不代替目标。明确any_minions战斗关系继续由已有ForceAttack执行，不开放普通玩家攻击友方或随机选择另一个敌人。

## 真实交付和普通战斗

先交四个原SummonByCard请求，再使用同一个AttackSummonedGroup连接器。请求、来源、数量、容量和完成状态由original_summon_groups.ordered_recipients核对，只有实际成功的原交付参加攻击；既有同名体及其他来源的嵌套召唤不加入。数量来源的实际额外交付属于原组，失败请求也须保留。

每个成员以实际入场驻留交给ForceAttack，沿原声明、拦截、战斗伤害、死亡和恢复。提前杀死目标后其余尸蜂留场，攻击不转向英雄或新对象；法伤不增加战斗伤害，没有额外冲锋、突袭或再次执行战吼。

本地采用既有紧急手术/树群政策：四次召唤及反应先完成，再执行攻击。只有一个空位就只交付一个，后续战斗空位不追补失败请求。揭示后的离场已接受请求继续完成；不同转控关系、数量与精细召唤/攻击时序仍属于待国服校准的本地政策，卡牌文字不能独自证明线上完全一致。原[符文召唤组](m3-blood-rune-native.md)及其他两类普通活动法术profile保持。
