# 永久不可交互场上载体

本契约复用[一般休眠](m4-dormancy.md)的生命周期、普通效果资格和休眠期间触发。实现与规则证据分开；实际验证和下一项仅在[项目状态](project-status.md)与[机制清单](mechanism-backlog.md)维护。

## 真实依据与适用范围

[官方虚空传送门](https://hearthstone.blizzard.com/en-us/cards/41942-nether-portal/)称其生成的传送门为永久传送门。本地完整原行保留5费奖励法术 `UNG_829t1`、永久场上载体 `UNG_829t2`、3/2虚空小鬼 `UNG_829t3`；载体卡文声明己方回合结束召唤两个小鬼。必要实验通过原 `Summon` 和具有控制者回合范围的 `dormant_triggers` 完成这条路径，没有新增召唤或结束回合执行器。

[七条完整原行](../data/support/permanent-board-carriers-basics.json)另保留火刃传送门、萨格拉斯的扭曲虚空和纯净龙巢；这些三张主体没有在本实验注册。`UNTOUCHABLE`的120条本地引用混有条件休眠、永久载体和其他模式，不能由标签直接批量声明永久休眠，也不能从不可收藏推断不属于构筑可达物。永久传送门没有因此获得印刷休眠关键词或两回合倒计时。

## 声明与生命周期

- `CardDefinition.permanent_dormancy: bool = False`：显式原生永久状态。启用时必须是普通随从，`dormant_turns=None`且没有`on_awaken`。布尔值严格校验。
- `DormancyState.permanent: bool = False`：沿原入场初始化保存声明。永久实例没有倒计时；不能把正数回合与永久标志同时安装。
- 原`entity.active`继续控制攻击、普通目标、伤害、消灭、沉默、普通移区、光环和一般场上能力。载体占用一个原场位，普通死亡检查跳过它；休眠专属触发仍能运行。
- 原`AwakenMinion`对永久实例复用过期目标跳过行为，不清除状态、不发布唤醒事件。原`AdvanceDormancy`和自然回合计时对没有倒计时的状态不做推进。普通条件休眠仍可显式唤醒，定时休眠仍按原规则计时。
- 保存时检查场上永久卡面必有永久实例，实例标志必须与当前注册卡面一致。删掉状态、改成条件休眠、添加倒计时或把永久标志挪给普通卡面会被拒绝；这是存档一致性验证，不是未签名存档来源认证。

永久声明只在原场上生命周期初始化处读取，不新增可沉默附件、实体币种或其他缓存。默认`False`从普通和模块卡面指纹中省略，未使用新声明的注册表保持旧身份；显式永久声明参与指纹。

## 执行与信息边界

己方自然结束回合沿原`EndTurnSpec()`接受完整主体，再顺序执行两次原召唤；逐次检查场位，一空位只成功一次，满场保留原载体。对方回合结束不接受这个主体。永久载体原物理身份和生命周期不随回合重建；路径不需要随机抽样。

选择、队列、事务、独立注册表恢复、克隆和回放沿现有公共层。必要测试观察者只用于在两次真实小鬼召唤之间暂停；它不是新增真实卡适配或新组合机制。诊断选项中的未知声明仍必须在保存前拒绝，选择后的诊断失败则完整回滚。

双方看到原公开卡面和既有`dormancy.remaining_turns=null`状态，内部实例ID、开始回合、永久标志和队列不进入玩家观察。没有增加玩家字段或命令，载体的隐藏属性标签也没有被解释为新的战斗属性。

## 尚未确证的边界

这是独立公共生命周期的内部契约，精确国服规则和时序尚未校准；实验未验证所有奖励法术的出牌资格，也没有给完整正式卡池背书。不能把“永久”解释为所有特殊移除方式都无效。清空/放逐等不经过普通死亡的路径需按真实来源单独核对，不能调用普通`Destroy`假冒。

原[非死亡移除](m3-nondeath-removal.md)已能退役明确捕获的永久物理随从：清除场上休眠/presence并进入SETASIDE，后续回合不再运行其场上主体。这是公共原语的接受能力；正常指定目标资格与具体全体来源的候选范围分别维护，不能据此宣称所有移除法术或雷诺版本都能处理传送门。

萨格拉斯与其原传送门的绑定及升级属于该真实来源的独立需求：[27.4官方修复](https://hearthstone.blizzard.com/en-us/news/23999071/27-4-patch-notes)明确涉及复制后误关联原传送门。本契约没有实现或推广这些绑定、升级和其他奖励主体。条件休眠、全部不可交互来源、M0正式池、M6校准和M7批量接卡继续由台账登记。

实现见[生命周期初始化](../hs_sim/engine/lifecycle.py)、[唤醒限制](../hs_sim/engine/dormancy.py)、[状态与验证](../hs_sim/engine/model.py)、[声明与指纹](../hs_sim/engine/registry.py)；必要验证见[永久载体专项](../tests/test_permanent_board_carriers_basics.py)。
