# 玩家整局种族关键词光环

玩家持续效果可以在来源离场后继续提供关键词。声明位于原 `model.py`，贡献进入原 `keyword_auras.py`，仍使用普通突袭、攻击次数和生命周期。实际执行与验收只在[项目状态](project-status.md)和[机制清单](mechanism-backlog.md)维护；本页描述公共契约，不代表国服校准或整族支持。

```python
PlayerEffectSpec(
    'boom.mech.rush', 'BOT_238',
    keyword_auras=(PlayerKeywordAuraSpec(Keyword.RUSH, ('mech',)),),
)
```

`PlayerEffectSpec.keyword_auras` 默认空元组，原有数值光环、法伤、触发和倒计时不变。新增不可变 `PlayerKeywordAuraSpec` 当前仅接受 `Keyword.RUSH` 和非空、唯一的种族字符串元组；声明只能装在整局 `persistent` 效果。没有新增效果指令、结算器、状态缓存、实体字段、事件、外部动作或任意条件表达式；定时、其他关键词及特殊授予按具体真实需求后置。原生随从的 `KeywordAuraSpec` 与授予入口没有扩展。

安装和移除使用原 `AddPlayerEffect` / `RemovePlayerEffect`，实例身份、公开说明、重复实例和所属玩家都沿[原玩家效果](m4-player-effects.md)。来源被替换、变形或离场不撤销实例；普通随从沉默也不能删除玩家效果。相同突袭贡献取并集，移除一个实例保留其他实例或固有突袭，不返还攻击次数。

每次原光环刷新，在实例所属玩家的当前战场筛选活跃随从。通过原 `has_any_tribe(..., basis='current')` 判定当前种族；双种族任一匹配，`all` 及明确排除沿既有查询，未知完整种族明确报错。没有按已适配卡牌枚举全部机械。英雄、武器、地标、休眠、建造中物体、手牌、牌库及墓地不获得该战场贡献。

受益者沉默保留外部突袭，沉默移除种族修改后重新判定资格。变形和转控按当前卡面、当前种族及接收方玩家效果重算。普通当前/基础复制不把外部突袭烘焙进永久附件；复制体在实际目的方场面重新受益。回手、存储复制、死亡清除战场贡献，再出牌、召唤和唤醒沿原刷新点恢复。新增随从只能沿原突袭规则攻击随从，不能因此攻击英雄；已消费的机会不会恢复。

选择、异常回滚、恢复、克隆、回放和派生值校验复用现有解释器及完整状态验证。玩家观察仍只有原公开效果的 `effect_key/card_id/effect_kind/remaining_turns` 和场上关键词，不公开内部实例 ID、隐藏来源、私有区域、工作帧或 RNG。读取观察和合法操作不会推进效果。

注册表指纹包含新玩家声明。旧玩家效果的序列化声明多一个默认空 `keyword_auras` 叶；无玩家效果的定义和指纹保持。快照状态没有新增字段，但机制版本和 schema 随解释语义升级，不接受旧引擎存档隐式迁移。

“科学狂人”砰砰博士 `BOT_238` 的[完整本地原始记录](../data/support/player-keyword-aura-basics.json)明确要求“本局对战剩余时间内，你的所有机械拥有突袭”。隔离验证只接必要战吼和普通英雄替换；使用既有 `warrior.power` 夹具技能，未适配真实红色按钮及五种动力装置，不能宣称整张英雄卡已完成。生产代表包和正式池没有新增该卡。[官方卡页](https://hearthstone.blizzard.com/en-gb/cards/48146-dr-boom-mad-genius/)本轮可提取内容只有导航，不能把它当作已读取完整正文的证据。

当前种族依据、休眠/死亡显示、沉默、转控及安装发布的精确窗口是明确的内部政策，仍待 M6 国服校准。完整玩家关键词族、真实英雄包、正式合法/可达池和批量接卡继续开放；本项不展开机制组合矩阵。

## 当前关键词条件的整局光环

真实消费者[巢穴女王沙卡尔](../hs_sim/cards/broodqueen_shakar_card.py)复用原`DeathQuery`读取本回合、死亡时由本人控制的实际场上随从死亡记录，至少5次才沿`AddPlayerEffect`安装独立整局程序。不新增死亡计数器，不以当前尸体或事件通知次数代替原事实；程序不附着于战吼来源，仍沿原独立实例和公开玩家效果生命周期。

新增`PlayerKeywordConditionAuraSpec(keyword=Keyword.CHARGE, required_keyword=Keyword.RUSH)`，目前仅接受这一真实的有限条件，不开放任意谓词、相反方向或条件循环。`PlayerEffectSpec.keyword_auras`接受旧种族声明或新条件声明，仍仅允许`persistent`。原`PlayerKeywordAuraSpec`两字段布局、只授予种族突袭的限制及全部旧玩家声明保持，无默认字段迁移。

原光环刷新先完整计算普通玩家/随从贡献，再从当前活跃场上随从的本地附件、当前自身条件和这次新计算的外部贡献判断是否有突袭。冲锋贡献进入原`aura_keywords`集合；不读取上一次的有效关键词缓存作条件，不把外部冲锋复制为永久附件。当前唯一条件从突袭到冲锋，无循环，一次刷新即可处理外部突袭的出现与消失。`lifecycle.local_keywords`仅抽出原附件/武器与有限次/手牌进度/受伤自身标记的并集，原`refresh_entity`继续与各类光环/条件集合合并，其他关键词语义保持。

来源死亡/沉默/回手/转控不撤销程序；受益者失去当前突袭、转到无此程序的玩家、变形成无突袭材料或进入非活跃区域时，冲锋贡献重新计算。保留原突袭时沉默不能删除外部冲锋；已有本地冲锋和重复玩家实例各自独立。普通当前/基础复制、回手、休眠/唤醒及源移除仍使用原管线；不返还已用攻击次数，也不重建攻击或支付执行器。

完整原行保留三种初始/就绪/无进度显示，官网只呈现初始5。源核验工具仅对[完整原源包](../data/cards/broodqueen-shakar-v1.json)中精确原行SHA及显式`{'{0}':'5'}`启用初始显示比较；所有规则主体、元数据与另外两个原始状态仍保全，未知tag1724不猜名，不推广成通用截断或数值放宽。

死亡门槛和光环贡献沿上述本地接受/刷新、原沉默/转控/复制与攻击政策，精确国服窗口仍待M6。core630/schema518拒旧1～517，命令/观察/replay协议及原注册效果/载荷名字列表保持；新增有限模型声明，没有新State字段、随机或执行指令。实际验证和下一项仍只在原两份台账维护。
