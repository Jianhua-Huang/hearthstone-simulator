# 攻击变形与次回合死亡奥秘

固定完整原卡面和有限审核配方见[内容数据](../data/cards/reactive-secret-effects-v1.json)。卡牌只声明原SecretSpec条件和公共效果；隐藏、消费、窗口、等待及玩家投影继续使用[公共奥秘解释器](m4-secrets.md)。实际进度、验收证据、差异与下一项只在[项目状态](project-status.md)和[机制台账](mechanism-backlog.md)登记。

## 秘法误导

JAIL_315使用原`m4.minion_attack`检查当前有效的敌方随从攻击。英雄攻击不触发；攻击者已离场、死亡、变友方或其他奥秘已使攻击失效时，原实时检查阻止消费。奥秘成立后，从原接受上下文捕获MinionReference，返回原TransformCapturedMinion，目的为完整DBF796绵羊CS2_tk1，1费1/1野兽，无额外主体。

普通变形保留原物理BOARD驻留、已使用攻击次数及原攻击窗口，清除原身材、关键词、附魔和亡语；攻击继续按变形后的当前属性结算。不能先将攻击者移出场再创建另一只羊，也不能把免疫当作自动变形防护。揭示反应使原引用失效时跳过原已接受变形，不重新绑定后来卡面或回手再入场的实体。

[2026-08-13一手报告](https://us.forums.blizzard.com/en/hearthstone/t/mystic-misdirection-works-on-immune-minions/164586)描述免疫随从攻击时仍被变形，属于社区证据。[36.4官方修复](https://hearthstone.blizzard.com/en-us/news/24293283/364-patch-notes)说明曾修复此奥秘取消瓦丝琪女男爵攻击的问题；该句不是全部变形替换优先级证明。瓦丝琪具体替换行为仍按实际可达依赖另接，不以本批认证。

## 失时往生

TIME_620判断的是随从被打出的下一全局回合死亡，与奥秘部署回合无绑定。当前明确的内部口径为实际物理手牌打出：从原minion_died的death_id读取完整不可变DeathRecord，核对原实体、死亡控制者、批次和当前回合；死亡时须为友方普通BOARD随从。

从原play_history读取同一物理实体最新出牌，要求MINION、完成且实际入场、未反制、`play.turn+1 == death.turn`。再将最新successful_summon_history入场与该手牌出牌的turn/action及HAND→PLAY→BOARD原zone_epoch关联；普通召唤、复制、复生、后来从存储区重新召唤的同一实体，不借用更早的出牌资格。原持续驻留中的变形和转控不伪造新入场，因此保留该原出牌关系；这些详细口径仍待国服校准。

默认对手回合及当前召唤空间检查复用SecretSpec。成立后从已接受上下文保存原death_id、原死亡位置和SummonCause，返回ResurrectMinion；公共召唤数量政策、入场、随机、等待、事务及历史继续共享。重新创建死亡卡面及其印刷能力，不恢复普通增益、伤害、沉默，不重新执行战吼。不能按当前同名随从、最后死亡记录或最后场位猜原对象。

## 复活材料与已有入场路径

resurrection_summons原带来源归因的材料不再借用“普通空白召唤候选”限制，改为验证实际死亡卡面的完整MINION定义、不可作为主体的choice-only排除及完整星舰组件。巨型、磁力、星舰组件等印刷随从使用已有创建和enter_minion；星舰主体带原DeathRecord.components重建，组件须为已注册的非星舰MINION。没有第二复活执行器、假召唤、额外战吼或新启动星舰。

这个修正让真实失时往生能够处理已打出的当前巨型随从，带来源的复活与已有无归因原路径使用一致的印刷材料。数量加成仍分别创建新实体；巨型附肢仍由原入场流程展开，不把附肢当作另一次手牌打出。

core-effects-v316保护资格与材料语义，原schema268及所有既有保存字段布局保持。观察85/命令12/replay1、历史代表工厂保持；恢复校验、等待、异常回滚、clone、回放和玩家信息沿原公共解释器，全知死亡/入场关联不进入玩家DTO。
