# M5-13d-02j-01：特定法术重复附件与使用捕获

2026-09-25。内核 `prototype-v90` / `core-effects-v90`，snapshot schema87，玩家观察51；代表包50、动作7、外层replay1保持。旧schema1～86明确拒绝。**R-133是内部原型契约，未通过国服校准。** 本页落实[前置审计](m5-card-spell-repeat-audit.md)中的第一项，不宣称发现交付和来源适配已经完成。

## 公共接口与归属

`GrantCardSpellRepeat(card: CardReference, casts=2, source_id=None, expires_turn=None)`给捕获的手牌或牌库法术添加独立附件；casts为总施放次数，至少2，expires_turn为可选全局回合截止值。`RemoveCardSpellRepeat(card, ability_id, source_id=None)`移除目标牌上的指定附件，缺失附件不产生效果，不能借此移除其他种类能力。

复用 `AbilityInstance` 身份、来源、期限、复制与移除框架，新增 `kind='card_spell_repeat'`，使用现有 `SpellRepeatSpec(casts, class_mode='any')`表达次数。该类型只允许法术载体、未消费的可移除动态授予，不允许磁力、条件职业筛选或伪装为印刷能力。本批不新增印刷法术自身次数声明。

`CardReference`校验实体、控制者、卡身份、区域和zone_epoch。执行前目标离区、转移或换形使引用失效，按既有存储区契约跳过，不能操作后来进入同位置的牌；非施法牌、未知来源、已过期期限或非法次数明确失败并回滚。

附件属于这一张物理牌，来源沉默、死亡或转控不撤销。先打别的法术不消费附件；两张同名牌互不影响。附件没有玩家级剩余用途，牌的每次合法手牌使用都读取其自身尚存在的属性。

## 捕获与已有次数合并

`play_history.prepare_play`在支付及移动前冻结 `PlayRecord.card_spell_repeats`，保存独立附件的不可变快照。提交反应中的到期或后续授予不修改该出牌事实。不合法操作及未提交成功的支付沿用事务回滚。

`spell_repeats.execution_count`合并三个贡献：本牌的冻结次数、已有玩家政策的提交收据、目标/反制窗口关闭时仍有效的场上光环。按现有重复契约取总次数最大值，不相加或连乘；匹配的玩家有限政策依旧消费，不能因为本牌也有重复而留给下一张。

重复仍只支付一次、产生一次手牌出牌，每遍物理施法分别记录cast。分支缓存、独立选择、死亡延后、终局中断和结算上限复用既有框架。反制保留冻结事实但不开始重复；提交中终局可以有捕获而没有施法或重复批次；主体中致死按原终局契约中断剩余遍数。

本项来源文字为“被使用时”，所以只作用于手牌使用。自动生成、实际存储牌代施放、抽到时施放均不使用此附件；即使自动施放的实体保留附件，也不产生伪手牌出牌。历史重施创建原印刷载荷，不继承旧实体附件。此来源范围属于R-133待校准政策，不表示所有“施放两次”文字都共用该规则。

## 生命周期

| 操作 | 处理 |
| --- | --- |
| 普通手牌/牌库移动、洗回重抽、物理转移给对手 | 保留同一附件，随物理牌转移 |
| 显式reset移动、基础复制、全量基础重建 | 清除动态附件 |
| 显式当前复制 | 继承次数与绝对期限，分配新附件身份 |
| 手牌同类型升级形态 | 按既有升级契约保留动态授予，重装印刷声明 |
| 回响临时副本、双生法术衍生牌 | 重新创建声明卡面，不继承原附件；原牌重复不会给副本递归授予 |
| 来源沉默/离场 | 不影响附件；现有Silence仅作用场上随从，不拓宽为手牌法术沉默 |
| 回合截止 | 复用附件期限清理，手牌、牌库及已离开区域均清理 |
| 普通回溯 | 恢复提交前原牌及附件，再提交一次 |
| 保留多结果 | 共享捕获和物理施法次数，不为每个结果再乘一次次数 |

不同复制或特殊变形的正式继承规则仍需来源证据。这里使用明确的公共操作语义，不推断所有卡牌文字中的“复制”都等于mode=current。

## 保存、信息与验证

PlayRecord内的附件元组由现有类型化能力编解码器恢复；挂起的授予/移除指令通过允许列表恢复。校验类型、唯一有序身份、法术载体、引用来源、期限、next_attachment_id边界、同一身份前后内容与实际载体一致，以及已接受出牌的重复批次不得丢失本牌贡献。附件已到期/移除时仍可保留过去的捕获事实；不要求历史附件继续存活。

玩家自己手牌中的法术公开 `card_spell_repeats=[{casts, expires_turn}]`。内部附件ID、来源ID、冻结收据和结算帧不进入玩家观察。授予/移除事件只给拥有者且目标已知时显示次数；牌库不因授予而暴露追踪句柄。对手即使记得该牌身份，也看不到后续隐藏修改；配对状态验证对手观察、修订值和日志一致。
