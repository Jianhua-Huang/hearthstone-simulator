# M5-13d-02g-01：独立连击主体与可恢复激活

2026-09-25，暂定契约 R-127。内核 `prototype-v85` / `core-effects-v85`，snapshot schema 82，代表包 `representative-m5-v47`；观察46、命令7、回放外层1保持。本批建立独立主体和执行记录，重复次数与有限次消费留给02g-02。机制整体仍为partial，没有当前国服一致性认证。

## 声明与条件

`CardDefinition.combo`声明条件成立时执行的行为，与普通`on_play`及`battlecry`分别安装能力。当前支持带`Keyword.COMBO`的实体随从、武器与英雄牌；普通法术的连击数值分支沿用施法主体。法术、技能、地标、choice-only及抉择混合声明不能使用这个新字段；未注册行为明确拒绝。

`PlayRecord.combo`仍取决于提交前本回合己方出牌计数。已承诺但被反制的手牌计入；技能、普通召唤、复制和交易不虚构出牌。`PlayRecord.combos`保存提交时声明，表明这张牌带有什么能力，不证明实际触发。实际连击由独立`combo_history`记录；首张牌、整次反制、入场失败、磁力合体均不激活。

同一接受的主体中，顺序是普通出牌行为、完整战吼批次、连击主体。普通效果只执行原定遍数，铜须和玩家战吼政策只作用于战吼。各连击使用原手动目标与冻结条件；开始时不重新计数来把首张牌变成连击。各主体共享现有出牌目标域，尚不表达同一张牌的两个独立手选目标。这是实验组合顺序，待R-127校准。

军情七处特工`EX1_134`、艾德温`EX1_613`已从`on_play`中的条件分支迁入明确声明。刺骨`EX1_124`保持单个法术主体内的条件数值选择，避免将基础伤害和强化伤害误拆为两次效果。没有新增真实卡、缩减生成池或扩大正式支持声明；仍为282记录/283定义。

## 捕获、生命周期与时序

`ComboPayload(ability_id, behavior_id, card_id)`冻结具体附件及其声明卡。`ComboRecord`记录实际载体/玩家、原打出卡、手牌出牌ID、目标、时间、保留回溯关联、结果遍数及完成/终局中断状态。声明来源与载体身份分别保存，不通过当前卡面猜测过去的能力。

普通随从在反制窗口通过、物理入场后捕获能力；入场事件的反应执行前，队列已持有接受的连击。因此其后沉默、死亡、回手、变形或转控不会改写这次主体、原玩家或原目标。武器装备、英雄替换之后走相同主体入口。巨型先处理附肢，并在延后的主体入口复核原实体、区域、形态、入场身份和控制者；捕获前死亡/转控使后续主体取消，捕获前沉默清除连击能力。这个差异来自现有巨型入口，不声称已校准为国服规则。

`BeginCombo`建立实际记录并发出`combo_started`，之后执行捕获的行为；结束标记完成记录并发出`combo_finished`。开始监听先于主体效果执行，而主体上下文已捕获。事件提供内部`combo_id`及`play_id`，`RuleContext.combo`/`play`提供相应不可变事实。目标失效时由公共效果处理跳过，不自动重新选目标。

沉默清除被动声明，复制分配新附件身份，回手重打重新安装印刷能力；这些操作自身不触发连击。已开始的效果不因能力消失而取消。终局将已开始未结束的记录标为中断；尚未开始的队列不会生成虚假记录。异常在统一事务边界回滚状态、付款、RNG、事件和历史。

## 回溯、恢复与信息边界

普通回溯重试恢复检查点并重新执行动作，撤销前一尝试的连击记录。保留结果时，`RewindOutcomeRecord.combos`冻结接受的能力集合，每个结果经普通连击入口产生记录，以`outcome_id`和`iteration`区分。条件继续取原始出牌事实；即使多结果之间变形，也不重新捕获另一套连击。只支付、打出一次。这一结果遍数不等于连击重复次数，后续必须独立建模。

选择可以发生在连击开始前、开始监听、主体内部及完成监听。快照保存捕获上下文、声明和历史、待执行开始/结束标记及保留结果，检查类型、来源/玩家、时间、唯一键、记录关联和关闭次序。旧schema1～81明确拒绝，不默认补字段。散列用于损坏检测，不保证任意重写整个文件后的真实性。

`activated_combos(state, player_id, completed=None, turn=None, before_id=None)`仅供可信宿主查询。completed指主体结束，空效果或目标失效后也可能结束，不保证场面有变化。玩家观察、命令及过滤日志不公开连击内部历史、附件ID、行为名和开始/结束诊断事件。
