# M5-13d-02g-03b：鲨鱼之灵、幸运彗星与必要连击组合

2026-09-25。代表包 `representative-m5-v48`；内核87、schema84、观察48、命令7保持。本批是已有公共机制的来源组合验收，规则边界记为 **R-130**，不宣称正式卡池或国服一致性。

## 必要适配与范围

- `TRL_092` 鲨鱼之灵：冻结资料为4费0/3亡灵。声明印刷潜行及一次控制者回合开始期限，同时组合独立战吼和连击次数光环，两者均明确限定随从。潜行不靠战吼追加；普通召唤也有期限。失去潜行不取消重复光环。它没有连击主体，文字中的连击引用不能让它成为连击发现候选。
- `GDB_873` 幸运彗星：先通过现有发现协议选择并交付连击随从，待交付及其反应结算后，再授予玩家一次 `trigger='play'` 的连击重复政策。政策无回合截止；下一张提交的、有连击声明的随从消费一次，不限定发现所得实体。来源离场不移除玩家政策。
- `EX1_131` 迪菲亚头目及 `EX1_131t` 迪菲亚强盗：补充召唤型连击测试。冻结头目为2费3/2，衍生物为1费2/1不可收藏随从；不得沿用记忆中的旧头目数值。主体组合普通 `Summon`，每遍按实际剩余场位执行。

合计新增四条记录，样本286条、定义287个（含合成测试英雄）、十四个choice-only。全部仍为partial / internally_tested，正式合法性未知。

次数机制沿用[连击重复](m5-combo-repeats.md)和[临时关键词](m5-timed-keywords.md)：鲨鱼/铜须/彗星来源取适用次数最大值，不乘成四遍；所有匹配的有限政策各消费一次。首张未触发连击的随从、被反制的随从仍消费play政策；普通随从、连击法术及连击武器不消费彗星的随从政策。战吼和连击身份与出牌次数保持独立。

当前重复调度以手牌出牌为入口；间接/历史战吼、自动施法等其他来源没有因接入这两张牌而扩大到完整范围。实体自身的多次伤害/召唤也不是次数光环。具体来源窗口、叠加、跨职业发现、被反制/未触发时的消费，均须国服证据校准。

## 顺序、恢复和信息边界

发现选择挂起时尚未授予政策。交付产生的反应先于授予；空候选无选择但继续授予，满手烧毁选中牌也继续授予，交付反应导致终局则不执行之后授予。选择后反应报错恢复到同一个待选状态，保留先前已支付的施法动作，未产生错误次数。

施法重复产生独立发现与独立政策；回溯保留结果不再为同一次匹配多扣用途。政策投影沿用受控玩家事实；发现仅对选择者公开，固定资料、原始候选、附件与来源身份不进入对手观察。

38项[专项](../tests/test_m5_combo_sources.py)覆盖实际来源、缺失候选严格拒绝、私有选择、同回合/跨回合政策、未触发/反制、武器与法术排除、空池/烧牌/终局、交付顺序与失败恢复、法术重复、回溯、光环生命周期、重复召唤满场及固定数据校验。完整回归结果见[项目状态](project-status.md)。
