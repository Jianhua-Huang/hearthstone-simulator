# 13d-02c-02 前置审计：秘密选择与载体反制

这是v76时的前置审计，保留当时缺口；v77已实现下述公共能力，当前契约与证据见[秘密载体反制](m5-counter-policies.md)。原审计如下。原始根卡及卡文见[固定来源摘录](../outputs/m5-13d-02c-counter-candidates.json)，目标仍为国服构筑规则。审计时TSC_032与相关选项尚未加入代表包；v77已加入。

当前可复用：RequestChoice及玩家私有选项/选择事件、统一附件ID与复制/沉默/到期生命周期、MinionReference和能力实例守卫、CounterCard以及随从minion_counter_check窗口、法术card_committed窗口。反制的目标是尚未接受主体的整次手动出牌。

当前不能直接复用的语义：普通ChooseOne把分支写在公开动作内，不适用于奥卡尼的秘密选择。普通奥秘占用独立区域且来源离场保留，不适用于随从载体。limited_triggers.capture先检查条件，check只复查载体并直接消费次数，没有在消费时再次检查窗口是否已被其他来源反制；公开投影和limited_trigger_used也没有私有分支的表达。不能通过藏行为名称或给已有计数填特殊值绕过这些问题。

实现时需要一份类型化、可序列化的隐藏策略声明/实例，明确选择结果、匹配类型、次数、来源实例、所属玩家和观察策略。结算检查必须针对当前窗口实时匹配，在仍可反制时原子消费，并让后续来源看到已反制结果；被沉默、离场、重装或失去有效身份的载体不能消耗旧策略。秘密选项用已有私有RequestChoice，选择后的策略及历史则需要专门的受控投影。

验收覆盖：秘密选择中途恢复、错误选择回滚；重复战吼及独立能力的结果合并；同类型/不同类型多来源与异议/法术反制竞争；来源死亡、沉默、休眠/唤醒、转控、变形、回手重打、复制；牌面及策略的玩家知识不会因转控或复制意外泄漏/丢失；已反制窗口不能再次消费；嵌套选择、终局、普通/保留回溯和完整回放。为每个能力实例保留明确来源，不能依赖卡名或一次可变回调闭包。

官方25.4公告能证明两个反制来源不能在同一随从上重复消耗，不能证明重复奥卡尼战吼应当叠加还是覆盖，亦不能证明转控/复制后的隐藏知识。这些需要单独证据或明确暂定契约；官方卡牌库页面本次只返回动态壳，不能作为完整规则内容引用。集中客户端校准仍在M6。
