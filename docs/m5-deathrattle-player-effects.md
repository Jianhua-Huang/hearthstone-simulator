# M5-13d-02k-03：玩家亡语次数与期限

2026-09-25。内核`prototype-v94` / `core-effects-v94`、快照schema91、代表包54；观察51、命令7、replay1保持。**R-138为原型政策，尚未完成国服校准。** 本批扩展已有公共玩家持续效果，没有另建期限、容量或结算系统。

## 公共声明与来源

`PlayerEffectSpec.deathrattle_repeats`声明不可变的`DeathrattleRepeatSpec`元组。永久效果以及有期限的objective/sigil均可贡献；同一实例允许多项有明确载体范围的声明。加入、移除、原来源实体离场以及公开剩余回合沿用`PlayerEffect`契约。

`DeathrattlePlayerContributor`保存所属玩家、完整接受时实例、规格下标与规格。原实例ID加规格下标标识贡献位置，与场上能力ID共同排序；同一效果的两个实例不会合并成一个身份。来源实体死亡、沉默、变形、回手或转控不撤销玩家已取得的效果。次数与场上来源取最大设值，保留所有适用贡献者；不能把两个“两次”相乘或当成额外一次相加。

自然和主动入口共享原有计划接受点。接受后效果被移除或到期，不改写余下重复；新一次触发重新捕获当前有效实例。亡语中新建或更强的玩家效果只影响后续新计划。原有每能力排列、首次与额外回调窗口、死亡/复生检查点保持k-02契约，见[场上重复计划](m5-deathrattle-repeats.md)。

## 期限与容量

复用已有owner回合开始/结束时钟，在边界反应前捕获实例和期望余量，反应后守卫扣减。边界期间新增或替换的实例不会误扣；边界期间移除的旧实例不会被复活。暂停选择时保存同一守卫，恢复后只扣一次。

雪落墓地采用三次所属玩家回合结束（含施放回合），回合结束触发先执行，然后扣减/到期。到期先移除实例，再执行可选到期载荷，所以到期载荷不会继续使用已移除的次数贡献。对手结束回合不扣减己方实例。该窗口复用R-047/R-048并列入R-138；官方“持续3回合”文字不足以认证精确排列。

持续效果占用既有ongoing容量及其与奥秘共享容量限制；永久效果沿用不占ongoing容量的契约。满区手动出牌在支付前拒绝，效果式加入失败不会产生幽灵贡献。反制雪落墓地仍支付费用但不安装玩家效果。

## 存档与边界

schema91区分场上能力来源与玩家实例来源；旧schema1～90明确拒绝。恢复核对类型、唯一有序位置、实例/来源引用、所属玩家、创建时间、计时范围、规格下标与注册表声明及最终次数。历史来源允许已被移除或其余量已经减少；不能要求它仍在当前生效列表中。尚未执行的挂起上下文继续核对接受时完整来源。

普通回溯恢复政策与批次；保留结果式回溯建立独立新批次。终局保留未执行位置；重复中抛错原子回滚。玩家DTO继续只公开已有持续效果信息，不暴露完整次数计划、规格下标或内部历史。注册表指纹包含新声明，观察版本无需变化。
