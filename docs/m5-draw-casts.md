# 抽到时施放与可恢复抽取链

M5-10c 公共子集，`prototype-v75` / `core-effects-v75`，snapshot schema 74，玩家视图 `player-view-v44`。代表内容包仍为 `representative-m5-v38`，未增加真实卡牌。入口见 [draw_casts.py](../hs_sim/engine/draw_casts.py)，验证见 [60 项专项](../tests/test_m5_draw_casts.py)。本页描述内部契约；国服精确语义登记 **R-089**。

## 声明与来源

```python
CardDefinition(..., keywords=(Keyword.CASTS_WHEN_DRAWN,),
    cast_when_drawn=CastWhenDrawnSpec(
        replacement=True, after_draw='blood.after_draw', choices='random'))
```

关键词和声明必须配对，限可进入手牌的法术；未知回调在注册冻结时拒绝。`after_draw` 是补抽链完成后的可选行为，`replacement=False` 提供无需补抽的显式扩展策略。动态裸授予关键词不创建行为声明。

普通 `Draw`、`DrawMatching` 和 `MoveCard(draw=True)` 共用 `draw_one`。定向抽牌只限制该次抽取，替代补抽使用当前牌库顶；过期物理引用跳过且不伪造一次抽牌尝试。`Draw` 新增可选 `source_id`，补抽来源则为触发施法的原实体。

普通移牌、生成、复制、起手发牌和换牌不触发本机制，也不记录抽取；第一回合及正常回合开始的 `Draw` 使用本机制。手动打出、`CastSpell`、`CastStoredSpell` 不会因为法术带此声明就自动补抽或调用抽后行为。

交易也转交抽取续接：已交换的物理牌先回到牌库，选出的另一张牌共用抽取流程；其补抽可再次抽到刚交易的牌。交易提交事件及专属回调上下文仍在交换时捕获，回调实际执行等待补抽链结束；终局会停止该回调。这个捕获窗口沿用原交易契约，需与 R-089 一并校准。

## 实体、历史与结算阶段

每次真实抽取尝试建立不可变 `DrawRecord`，区分 `hand`、`burned`、`cast`、`fatigue`，记录玩家、回合、动作、来源、原卡、父子补抽关系及对应施法 ID。宿主可调用 `drawn_cards` 按玩家、结果、回合或完成状态查询；它不是玩家观察接口。

有空手牌位时，带有效声明的抽到法术从牌库直接迁移至墓地，保留原物理实体和所有者，不先进入手牌。发出抽牌事件后，以独立 `SpellCastRecord(origin='draw')` 执行其效果。不会支付费用、增加 `PlayRecord`、产生手牌获取记录或回响副本；已有法伤、伤害防止和双生法术衍生流程继续生效。具体卡牌若有额外来源政策，仍需扩展契约。

一次抽到施法的阶段依次是：等待施法、施法、等待补抽、补抽链、抽后行为、结束。补抽又抽到此类法术时递归建立记录，但实际执行使用有预算的效果队列；不依赖不可保存的递归调用栈。多次 `Draw(count=N)` 逐次完成各自整条链，再处理下一个原始请求。

本原型先结算最内层抽后行为，再向外结束。例如连续抽到多张堕落之血式测试牌时，先完成伤害及全部补抽/疲劳，再依次洗入各自复制；这与在施法效果末尾立刻洗牌不同。卡文证明需要抽后窗口，但此精确顺序仍待 R-089 校准。

满手时直接烧掉该牌，不施法也不补抽；效果执行后手牌才满，则后续补抽按普通烧牌处理。空库每次实际尝试产生疲劳，强制目标不存在造成施法失效时仍补抽。致命伤害或疲劳会中断未完成记录并停止后续工作，不继续执行抽后洗牌。这些均是明确的原型策略，不等于最新国服认证。

## 选择、恢复与信息

`RuleContext.draw` 提供抽取上下文，抽后回调同时获得已完成的 `cast`。法术自身及其抽后回调沿用 `choices='random'` 或 `'player'`；其他来源的独立触发选择不继承该策略。玩家选择可以在抽取触发、施法效果、嵌套补抽及抽后回调中挂起。

五类内部续接标记可序列化。恢复时校验阶段、未完成标记顺序、父子补抽双向关系、抽取与施法的双向关联，以及施法完成先于补抽。选择恢复、克隆与动作回放保留同一链。效果异常和预算耗尽沿用事务回滚，包含牌库、历史、RNG 和玩家知识。

玩家只获得现有事件的受限投影。普通抽到施法的实际卡名公开，自动部署的奥秘仍仅拥有者可见；牌库其他内容、内部 draw/cast ID、完整历史和未选选项不导出。公共视图语义改变，因此版本升至 v29；动作协议仍为 v6。

## 证据与验收

[官方 12.2 更新说明](https://hearthstone.blizzard.com/en-gb/news/22546493)确立“抽到时施放”关键词及已有卡牌例子。冻结数据中的 `DAL_582t` 地狱犬传送门、`SCH_307t` 灵魂残片、`TRL_541t` 堕落之血及三种 `TTN_450t` 疫病用于确定需求；堕落之血另要求抽牌后洗入复制。这些证据不证明当前国服全部窗口，也不表示已适配这些整张卡。

60 项专项覆盖普通/定向/显式/交易抽取、满手/疲劳、多层补抽与抽后回调、独立嵌套抽牌、开局/换牌/回合、随机/玩家选择、受限玩家入口、双生/回响隔离、奥秘隐私、终局/预算/回滚及损坏快照拒绝。原有 45 项交易/锻造测试另已通过。全量结果见 [项目状态](project-status.md)。
