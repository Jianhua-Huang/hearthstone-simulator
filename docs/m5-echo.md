# M5-09a：回响与临时手牌

本批补齐印刷回响、无关键词的“本回合可重复使用”声明，以及可复用的临时手牌生命周期。验证使用合成定义，没有扩大真实卡牌适配包。入口为 [temporary_cards.py](../hs_sim/engine/temporary_cards.py)，[40 项专项测试](../tests/test_m5_echo.py) 与现有机制组合验证；当前实测回归见 [项目状态](project-status.md)。

## 公共声明和效果

```python
CardDefinition('echo_spell', '回响测试', CardType.SPELL,
    keywords=(Keyword.ECHO,), hand_repeat=HandRepeatSpec(), on_play='effect')

# 无关键词的本回合重复；不自动套用回响副本的 1 费下限。
CardDefinition('repeat_spell', '重复测试', CardType.SPELL,
    hand_repeat=HandRepeatSpec(echo=False), on_play='effect')

# 任意可入手实体的显式临时生成，可放入挂起选择的后续效果。
CreateTemporaryCard(player_id, card_id, expires_turn,
                    minimum_cost=0, source_id=None)
```

`HandRepeatSpec` 目前仅支持实体随从和法术的印刷声明。Echo 标记必须与声明一致；孤立关键词、非实体选项和不支持的卡牌类型明确报错。动态回响/手牌光环及捕获存储卡授予已接入 [手牌能力契约](m5-hand-keywords.md)。普通 `GrantKeyword(ECHO)` 仍禁止，以避免绕过存储区域引用规则。

出牌时先捕获重复资格。支付并提交原牌后生成一张基础定义副本，保持独立实体 ID，来源指向原牌；不继承原牌增益、减费、沉默或其他实例附件。生成到手后，共享手牌获取历史和裂变检查。直接召唤不执行这一步，法术效果重复也不额外生成回响副本。磁力提交仍只生成一次副本，Echo 不转移为宿主的持续能力。

## 生命周期与费用

临时属性保存在不可变 `HandLifetime(source_id, created_turn, expires_turn, minimum_cost)` 中，属于实体状态，纳入严格快照和挂起上下文校验。它与增益附件的到期分开，避免把“移除附魔”和“移除手牌”混为一谈。

| 情况 | 当前公共契约 |
| --- | --- |
| 原牌未打出 | 没有临时期限，也不强加副本的费用下限 |
| 回响生成的副本 | 本回合结束时到期；最终费用下限为 1 |
| 无 Echo 关键词的重复副本 | 同样本回合到期；默认费用下限为 0 |
| 临时牌仍在手中到期 | 移入墓地并发出拥有者私有 `card_expired`；不算弃牌、死亡或尸体收益 |
| 临时牌已在场上/墓地/牌库到期 | 清除临时记录及其费用下限，不消灭该实体 |
| 当前复制 | 复制原截止回合，不延长有效期 |
| 基础复制/显式重置 | 不继承临时记录；正常打出后是否再次生成，由新实例的声明决定 |
| 换手、手牌升级 | 保留截止回合；不是因控制者变化而重新计时 |
| 裂变拆分/重组 | 复用裂变继承策略保留临时记录，不借变换绕过期限 |
| 回手/变形 | 沿用公共重置语义；重置实体清除旧临时记录 |

费用下限最后应用于权威报价，即所有本地费用附魔、玩家修正和光环处理之后。不能把它作为一个普通减费附件插入序列，否则后续设为 0 的效果会绕过下限。拥有者观察、合法操作和支付共用报价；手牌主动操作的独立费用不因此改变。

拥有者手牌观察额外提供 `temporary` 的截止回合与费用下限，不提供内部来源 ID。对手仍只看到允许追踪的卡背/已知身份和数量变化；私有到期事件不发给对手。当前玩家视图为 `player-view-v44`。

到期清理沿用回合结束后的稳定化流程：结束回合反应先执行，再清理临时牌和附件；清理反应新生成的本回合临时牌也须在进入下一回合前处理。工程结算预算限制自生成无限链，失败不伪装为正常结束或平局。

## 官方依据与 R-084

官方关键词说明支持：回响打出后返还副本，副本不保留原牌属性增益，未用副本在回合结束时从手中消失。[回响说明](https://news.blizzard.com/en-us/article/21658543/the-witchwood-s-newest-keywords)

2019 年 12 月更新规定回响副本不能低于 1 费。这支持副本单独的最终费用下限，不能据此给未打出的原牌一并加下限。[官方更新说明](https://hearthstone.blizzard.com/en-us/news/23239986)

**R-084 原型假设：** 本批选择在支付/提交后、目标反制与主体效果之前生成副本。因此被反制仍生成；打出时的卡面和资格一经捕获，不受随后变形影响。`card_committed` 的冻结反应上下文仍是该事件发出时的状态。具体反制、抉择、磁力、终局窗口与国服结果未校准。

回合结束反应后的清理顺序、当前复制保留期限、洗入牌库后到期只清标记、跨玩家移动以及与裂变继承的互动也属于 R-084。替代支付的最终数值沿用该下限，其特殊官方语义仍待核对。基础定义与这些选择不能混作同一证据等级。
