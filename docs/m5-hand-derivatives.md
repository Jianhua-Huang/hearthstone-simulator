# M5-09b/c：双生法术、微缩与巨化

本批用同一套公共声明表达三类打出后衍生形态，使用合成卡验证，没有扩大真实卡牌包。实现见 [hand_derivatives.py](../hs_sim/engine/hand_derivatives.py)，[44 项专项测试](../tests/test_m5_hand_derivatives.py)；完整回归与当前版本见 [项目状态](project-status.md)。

## 声明与独立身份

```python
CardDefinition('root', '微缩测试', CardType.MINION,
    cost=3, attack=3, health=3, keywords=(Keyword.MINIATURIZE,),
    hand_derivatives=(HandDerivativeSpec(Keyword.MINIATURIZE, 'mini'),))
CardDefinition('mini', '微型测试', CardType.MINION,
    cost=1, attack=1, health=1, keywords=(Keyword.MINI,))
```

双生法术使用 `Keyword.TWINSPELL`，衍生定义不再带双生法术；微缩和巨化使用 `MINIATURIZE` / `GIGANTIFY`，分别指向带 `MINI` 的 1 费 1/1 和带 `GIGANTIC` 的 8 费 8/8 定义。两种随从能力可以并存，按声明顺序生成。每个实体有自己的 ID、卡牌定义和来源 ID，不能把微型当作原牌临时加一个属性减益。

冻结数据中 `DAL_177` / `DAL_177ts` 分别具有和不具有 `TWINSPELL`，`TOY_307` / `TOY_307t` 分别具有 `MINIATURIZE` / `MINI`；`MIS_025` 同时带微缩和巨化，关联两个衍生记录。这些关系用于核查模型，没有注册为本批可执行真实卡。完整数据指纹见 [目标清单](../data/targets/local-2026-09-23.json)。卡牌 ID 显式声明，不猜测后缀。

注册冻结时验证：声明不可变、同种能力不重复，关键词与声明一致，原牌和子形态均是同类型可入手实体；子形态必须不同 ID 且不再拥有上述三种生成能力。双生副本保留印刷费用，微型/巨型满足印刷费用和身材。无声明的动态关键词不能用 `GrantKeyword` 注入，磁力也不将这些入场能力或形态标记转移给宿主。

## 当前执行与生命周期

出牌准备时把仍有效的衍生声明捕获到 `PlayRecord`，支付和移动之后使用该记录。后续原实体死亡、沉默、变形、回手或转控不会改写已经捕获的卡牌身份和原打出者。该新增记录进入 snapshot schema 74，旧 1～71 快照明确拒绝；外层 replay schema 1 与 player-view-v44 不变。

| 情况 | 当前内部契约 |
| --- | --- |
| 双生法术正常施放 | 主体效果及其选择结束后生成终结形态，然后完成本次效果迭代/打出 |
| 双生法术被反制 | 没有主体效果执行，不生成副本 |
| 已支持的法术效果重复 | 每次成功执行的效果迭代各生成一张；费用和出牌历史仍只记一次 |
| 微缩/巨化从手中打出 | 完成打出及其反应后生成；直接召唤不生成 |
| 磁力打出 | 保留原打出者的衍生资格；宿主不获得该生成能力 |
| 原牌实例增益/减费 | 不转移；新实体按终结形态的独立定义初始化 |
| 常驻费用光环/玩家减费 | 正常作用于生成后的卡，微型可以被减到 0 费 |
| 原牌是临时手牌 | 生成的终结形态默认永久，不继承期限；回响另行生成的原形副本仍会到期 |
| 满手牌 | 按普通容量烧掉新实体；双能力按声明顺序分别检查容量 |
| 终结形态再次打出/基础复制 | 保留子形态身份，不恢复已去掉的生成关键词 |
| 裂变子形态 | 获取后进入普通裂变稳定化流程 |
| 结算中对局已结束 | 后续衍生效果沿用终局截断，不继续生成 |

选择可以停在生成之前、生成触发之后或重复效果之间；保存、恢复、克隆和动作回放必须与连续执行一致。失败回滚包括实体、手牌、来源记录和随机状态。玩家入口使用既有出牌命令；拥有者按普通手牌查看子形态，对手不获得内部来源、子卡 ID 或隐藏手牌。
