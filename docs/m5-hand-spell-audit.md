# M5-13d-02i：持牌期间施法条件前置审计

2026-09-25。必要来源为冻结记录TSC_071双弓积骇纳迦，完整文字见[来源资料](../outputs/m5-13d-02h-spell-policy-candidates.json)。它需要“本牌在手中时施放过法术”条件，再授予下一法术重复；后半部分已由[玩家法术政策](m5-spell-modifiers.md)支持。本页只审计前半部分，不宣称该牌已经适配或国服规则已校准。

## 当前源码证据

- `hand_history.enter_hand`为每次成功获取分配新的HandEntryRecord，记录实体、控制者、卡身份、回合、action、zone_epoch、来源区和原因。实体保存最近hand_entry_id。开局手牌早于第一回合；烧毁未进入手牌不产生成功驻留。
- `play_history.prepare_play`将本次使用的hand_entry_id和获取回合冻结到PlayRecord，因此回手重打应使用新的驻留，不能靠实体ID累加终生条件。
- `spell_casts`独立记录hand、repeat、effect、draw、history五种施放来源。`cast_spells(successful=True)`表示已经完整执行且没有失败，不等同于“曾开始施放”；反制也有失败记录。
- 手牌进入历史尚无施法游标，施法历史尚无“当时哪些牌在手中”的事实。两个历史的action可以相同：同一个动作可以先获取牌再自动施法，也可能正在施法才获取牌。仅按回合/action大小、最终仍在手牌或当前cast.completed筛选，都不能可靠重建先后。
- 已有 `HandProgressSpec(kind='event')` 可按手牌捕获候选，记录不可变事件见证，并通过公共回调完成进度；腐蚀/注能只是其特化用法。**实施前先评估复用这条能力及生命周期**，不要预设必须新增一套历史系统。当前手动法术完成只沿用card_played，自动来源另发spell_cast_finished；若以事件进度实现持牌施法事实，需要明确统一的施法窗口与去重身份，并验证现有复制/区域迁移是否符合该来源，不能把两个事件简单相加。

## 下一实现必须先固定的语义

1. **驻留身份**：采用本次成功进入手牌的身份；单纯相同实体或相同卡ID不能代表同一次持有。实际出牌使用冻结PlayRecord引用，不能在战吼执行时读取可能已经被其他效果改写的最新指针。
2. **施法窗口**：明确在开始、主体接受还是完成时判定持有，以及失败/被反制/中途终局是否计入。正在施放的法术将此牌加入手牌、此后又嵌套自动施法，是必须分开验证的正反例。
3. **来源与归属**：明确手动、重复、生成、抽到与历史施放的资格；查询玩家与手牌当时控制者匹配。不能把R-131只匹配手牌使用的政策范围直接复制到“施放过”条件。
4. **生命期**：回手/重新获得、手牌转移、当前复制/基础复制、手中变形分别决定重置或继承。需要保存事实或游标证明，不能在卡牌回调中挂布尔闭包。
5. **间接来源**：战吼重演/手牌外直接触发可能没有这次主体的普通手牌驻留；先给出明确来源政策或明确拒绝，不能无声取其他实体的历史。
6. **恢复与信息**：条件事实进入全知保存及严格校验，普通回溯恢复原事实，保留结果不能重复计入同一个已发生施法；不得通过对手隐藏手牌条件泄露获取身份或施法关联。

满足这些条件后，用真实纳迦与现有有限次数政策组合；没有必要同时接大量效果重复的卡。JAIL_123特定卡授予、TIME_064混合触发次数、动态/种族范围等保留独立任务；正式卡池和国服校准仍不在此处闭环。
