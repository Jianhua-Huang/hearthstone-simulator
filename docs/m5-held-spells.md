# M5-13d-02i：持牌期间施法条件

2026-09-25。内核 `prototype-v89` / `core-effects-v89`，snapshot schema86、观察50、代表包50；动作7、外层replay1保持。旧schema1～85明确拒绝。**R-132是内部契约，国服精确时序尚未校准。** 本页承接[前置审计](m5-hand-spell-audit.md)与[玩家法术次数政策](m5-spell-modifiers.md)。

## 公共表达与事实窗口

复用 `HandProgressSpec(kind='spell_cast', goal=1, condition_id='always')` 与现有手牌能力实例。它仅积累条件事实：不支持升级形态、回调、循环或生命转耐久；这些行为继续使用原有腐蚀、注能及通用事件进度。规则行为通过 `held_spell_condition(context)` 查询，无需在每张卡里维护布尔闭包或扫描最终事件日志。

在一次物理法术的主体接受执行时，先为施法者当时仍在手中的相关卡记录 `cast:N` 见证，再运行法术效果。先评估所有资格，再原子写入全部进度，最后发出原有 `hand_progressed` 事件。因此第一个进度反应能看到同窗口其他牌更新后的事实；进度达到目标后不继续增长。可选筛选器收到带真实 `RuleContext.cast` 的独立状态上下文，必须返回bool。

- 手动、重复、效果生成、抽到时施放、历史重施五种来源默认均可积累条件；只匹配施法者的手牌。
- 被反制的手牌法术、自动施法目标失败不积累。已接受的空效果法术会积累；接受后发生终局仍保留事实。
- 本次法术执行途中才获得的牌不追溯计入本次施法；之后的嵌套施法或第二遍物理施法可以计入。
- 提交反应、自动施法开始反应中获得的牌，若到主体接受时仍在手中，会计入。这是明确的暂定窗口，不能用action级时间比较代替。
- 法术重复的每次物理cast各计一次；保留回溯结果的多个效果结果不虚构新cast。普通回溯恢复原状态，尝试次数不累计到最终事实。

“在手中时施放过”与“下一张法术重复”使用不同来源资格。官方[23.0.3历史补丁](https://hearthstone.blizzard.com/en-us/news/23797160)于2022-04-26将双弓/风潮的重复限定为手牌使用，排除其他牌代施放及抽到时施放。这支持R-131的来源范围，**不证明R-132持牌条件的全部来源、接受窗口或当前国服部署**。

## 生命周期与冻结判定

| 操作 | 条件状态 |
| --- | --- |
| 初次进入手牌 | 新能力、零进度 |
| 实体转移到另一方手牌、离手后重抽、场上回手 | 新驻留重置，不能沿实体ID继承上次持有 |
| 正常使用，HAND进入PLAY或BOARD | 续接已有事实，出牌前冻结 |
| 显式当前复制 | 复制已经获得的条件，包括跨玩家复制；能力身份独立 |
| 基础复制、普通召唤 | 使用新印刷状态，零进度 |
| 手牌升级形态 | 安装新形态声明，重置该条件 |
| 沉默 | 沿用现有能力移除契约，不修改已经冻结的旧出牌事实 |

`hand_history.enter_hand`仅重置此类条件，不改变旧腐蚀/注能的生命周期。显式当前复制在建立新实体后复制附件，因而有意继承原条件，而普通移动到手牌执行重置。该区别仍待国服复制证据校准。

每个 `PlayRecord.held_spells` 保存不可变 `HeldSpellProgress(spec, cast_ids, before_cast_id)`。None表示提交时无此声明；有声明但不满足时保存空见证，不混为未记录。`before_cast_id`冻结提交前的历史上界，之后回手、复制、变形或施法不能重写原判定。

普通手牌战吼读取原PlayRecord；手牌历史战吼和战吼历史链追溯原始冻结出牌。直接效果激活读取真实载体已保存的条件，普通召唤的载体不自动满足。**效果来源战吼再被历史重演时，目前没有冻结的持牌判定，明确报错并回滚**；不能借用执行者、当前同名牌或更晚的手牌记录。将这种间接来源补齐仍属于M5，不能宣称所有战吼来源已覆盖。

## 保存、恢复与信息

能力见证及冻结事实进入schema86。恢复校验严格字段、规范类型、整数与唯一顺序、见证上界、对应施法已经接受且无失败、与出牌时间先后的关系，以及计数/完成/消费字段一致性。当前复制可以引用另一玩家取得的原条件，因此不错误要求所有继承见证均由现持有者施放。这里校验结构一致性，不声称能够从最终状态逆推所有复制过程的真实性。

条件在发现暂停前已经成立，恢复选择不会再次计数。动作失败回滚整个动作；选择失败回到原暂停点，保留此前已成功提交的事实。原始对局、克隆、JSON恢复及动作回放应一致。

持有者通过原有手牌 `hand_progress` 查看kind、value、goal、completions、completed。对手的隐藏手牌不含该信息；cast IDs、进度见证键、冻结PlayRecord与内部声明不进入任何玩家观察。状态快照仍只供可信宿主。
