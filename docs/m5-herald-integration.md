# M5-07c：兆示代表链路收尾

本批关闭既定普通手动来源的代表组合验收，未宣称兆示整族、全部特殊来源或官方规则校准完成。[新增组合测试](../tests/test_m5_herald_integration.py) 共 12 项，结果见 [项目状态](project-status.md)。没有增加真实卡牌数量。

## 已验证组合

- 六职业强化、巨型主体的两片独立附肢，以及替换英雄职业后仍保留的玩家计数。
- 重复兆示法术只支付一次，每次效果单独推进兆示；满场仍计数，但不伪造士兵或生成奖励。
- 重复伤害与生命费用共享奥妮克希亚替换；反制保留已支付事实，取消法术效果；替换来源在重复施法中死亡后，下一次伤害重新判断资格。
- 两次挂起选择之间的生命增长能保存恢复；艾萨拉英雄风怒、武器耐久与奥妮克希亚战斗生命替换共同结算。
- 生命费用支付后替换成死亡之翼并进入灾变选择；重复链后段失败时，费用、增长、计数、RNG 和实体一并回滚。
- 古加尔的替代牺牲与星舰贡献相隔离，不把被牌库卡替代的死亡错误登记为己方组件贡献。

## 保留缺口与责任阶段

| 缺口 | 阶段与原因 |
| --- | --- |
| 自动/抽到时/特殊重复施法，重复战吼与非手动来源 | **M5**：公共施放来源和调度还缺实现；不能因普通出牌通过而标记完成 |
| 直接设定生命、减少上限与生命损失替换的特例 | **M5**：需要新增或明确公共语义；`LoseHealth` 不能自动替代所有设值操作 |
| 全部职业/种族元数据、正式构筑与生成池 | **M0**：模式和国服目标池证据未完整；实验候选不能充当完整池 |
| R-069～R-082 的精确窗口与边界 | **M6**：当前已编码的假设要与国服逐事件结果核对；内部回放一致不代替官方校准 |
| 其余具体卡族和已能表达的牌 | **M7**：机制组合适配和逐卡验收；发现新公共缺口时返回 M5 |

以上归档允许主线推进到裂变及后续公共机制，但不删除任何缺口。机制族在机器台账中继续是 `partial / internally_tested`。
