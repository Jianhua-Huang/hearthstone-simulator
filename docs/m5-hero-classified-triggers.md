## 声明与职责

当前安装在 `Zone.HERO` 的 `CardType.HERO` 可声明普通 `TriggerSpec(..., end_turn=EndTurnSpec(...))`，也可声明或通过 `GrantLimitedTrigger` 获得不带关键词的 `LimitedTriggerSpec`。有限能力可监听普通事件，或由自己的 `end_turn` 分类进入结束能力管线。动态普通分类结束能力使用现有 `GrantTrigger`，不另建英雄解释器。

`limited_triggers.supports_carrier` 统一注册、附件恢复和动态授予的载体资格：

| 声明 | 允许载体 |
| --- | --- |
| 通用有限次数，`keyword=None` | 随从、武器、英雄 |
| 法术迸发 | 随从、武器 |
| 暴怒 | 随从 |

通用有限触发不取得法术迸发资格。英雄上的法术迸发、暴怒声明及授予明确拒绝；法术迸发原施法候选、存档载体检查和暴怒存活规则保持。地标、英雄技能和法术也没有因本次扩展获得通用有限次数权限。

## 接受窗口、次数与替换

自然结束、显式效果激活、真实事件的 phase 激活均复用[分类结束模块](m5-end-turns.md)和[激活模块](m5-end-turn-activations.md)。各主体有独立附件身份、条件和重复计划；`all` 重复范围可匹配英雄主体，`minion` 范围不会匹配。重复来源本身仍只能由现有随从声明，本次没有把英雄变成重复来源。

自然窗口仍只发布一次真实结束事件并推进一次所属回合时钟。主动激活不制造自然回合事件，phase 必须绑定允许的真实原因。条件在接受窗判断且必须返回 bool；失败不消耗有限次数。各次额外执行保持原主体和计划，但沿原契约读取新局面。

普通主体已接受的回调按既有普通来源规则继续执行。英雄在此前反应中被替换，不会把原主体改绑到新英雄，也不会自动撤销原普通回调。有限主体的首次执行先核对原实体仍活跃、未被消灭、生命大于零，且控制者、入场顺序、能力身份及原能力状态一致；替换发生在消费前时，原有限主体的整段重复跳过。

消费守卫通过后只扣一次用途，再发布 `limited_trigger_used`。该反应或主体自身随后替换英雄，已接受主体及其额外执行仍沿原上下文继续结算，不重复消费，不借用新英雄上的能力。嵌套激活是独立接受窗口；原能力耗尽或原状态已被另一根消费时不能重用旧守卫。

英雄替换沿[既有 R-038](m4-heroes-history.md)：可继承的动态能力分配新附件 ID，并保留剩余次数、消费与到期状态；旧英雄的印刷能力不作为动态能力继承，目标英雄自己的印刷能力重新安装。旧英雄进入墓地后不能重新订阅。手动英雄牌、生成安装和四种已有物理历史重演入口均复用该安装生命周期，付款、技能替换和完成记录仍由原模块负责。这里没有裁定所有真实英雄卡的专属继承例外。

## 结构候选与随机入口

`EndTurnSelector.carrier_kinds` 可显式包含 `hero`，与 `minion`、`weapon`、`location`、`hero_power`、`player_effect` 并列。原调用者列出的五种范围不会自动扩展；需要英雄的调用者必须声明英雄范围。`owner` 与 `selected` 使用实际当前物理实体身份，被替换的旧实体 ID 不会匹配新英雄。

[公共候选与随机模块](m5-end-turn-producers.md)沿注册 profile 声明 current/printed/active、消费、presence、存活与休眠政策。候选查询只读结构，不执行主体条件；一个物理英雄只有一个随机权重，多个分类主体不会增加该英雄权重。`live_only` 对英雄检查正生命和未被消灭。随机选择与原主体/完整计划同窗接受，额外执行不重新抽选；空池保留空根且不消耗 RNG。

## 恢复、事务与玩家信息

附件、消费守卫、原主体、完整批次与 Finish 证明沿现有可序列化类型保存。等待选择、独立注册表恢复、克隆、动作回放、嵌套、终局中断和异常回滚使用公共解释器；卡牌行为不直接拼接私有控制步骤。失败回滚付款、次数、随机状态和历史。旧宿主版本或重算哈希后改写原消费、裁掉 Finish 等损坏状态仍拒绝。

本载体权限批次未增字段，历史schema139由v143签名绑定，旧v142标签不能赋予新权限。此后的[玩家合并抉择](m5-player-choose-both.md)新增玩家政策、原接受历史与生成分支证明字段；当前prototype-v145/core-effects-v145/schema140，旧1～139需原引擎。观察59、命令9、replay1及代表64/合成3保持。

玩家端沿已有 `limited_triggers` 只看到公开英雄的关键词与剩余次数，不看到附件 ID、行为/条件 ID、接受证明、候选或 RNG。全知快照仍只供宿主。只使用少量测试声明验证公共能力，不新增正式卡适配；其他自动来源、抉择剩余组合、U14/U64/U65整轴、H2完整阶段、M0正式池与版本、M6国服校准和后置M7继续保留。
