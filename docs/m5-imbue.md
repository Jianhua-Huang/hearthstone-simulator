# M5-12c-01：灌注累计与英雄技能成长

原批次是灌注的公共基础，整类仍为 partial。引入时运行时 `prototype-v75` / `core-effects-v75`，snapshot schema 74、`representative-m5-v38`、`player-view-v44`；旧 1～71 快照拒绝，玩家命令 v6、外层 replay 1 保持。[58 项专项](../tests/test_m5_imbue.py)内部通过，全量结果见 [项目状态](project-status.md)。

## 公共声明和状态

`ImbueProfile` 用不可变、带版本的 `ImbueClass` 声明显式覆盖全部十一职业。八职业映射到技能 ID；恶魔猎手、术士、战士声明为无灌注技能。不存在的技能适配和“该职业无技能”是不同情况：前者明确报错并事务回滚，不能通过过滤注册表把缺失实现变成无效果。未知英雄职业同样报错。

`Imbue(player_id, source_id, count, profile_id)` 在公共结算器内执行。每次使用按执行时的玩家职业重新解析技能，追加带来源、职业、旧/新技能实体、历史序号、回合、动作和 profile 版本的 `ImbueRecord`。历史属于玩家，来源离场、沉默、变形、转控，以及英雄/技能替换都不删除既有成长；亡语按实际执行者继续走同一接口。

`imbue_count` 区分请求次数和实际成长次数；`imbue_value(base=1, step=1)` 根据实际成长计算效果参数，第一次为 base，此后每次加 step，不修改技能费用。本批德鲁伊/法师代表均以 1 为初值。无技能职业保留无效果记录，但不为后来换职业贡献成长；此跨职业政策明确为 **R-100 暂定**。同一玩家不能中途切换 profile；声明及版本进入注册表指纹。

零次调用不分配历史或技能、不查询 profile，但仍校验参数和来源。过大次数受结算预算限制。多次灌注逐次进入反应/死亡检查，前一轮改变职业会影响后一轮，终局停止剩余轮次。数量不是出牌次数：重复效果、主动亡语、自动施法各自实际执行时才记一次。

## 技能实体与时序

| 当前情况 | 本批行为 | 保留边界 |
| --- | --- | --- |
| 无技能，或技能 ID 与映射不同 | 创建新技能实体，原技能进入墓地 | 新技能实例的使用次数重置；玩家本回合总使用次数保留 |
| 已经是该灌注技能 | 保留同一物理实体，仅追加玩家历史 | 次数、费用修正、次数上限和附件保留；成长不刷新技能 |
| 技能被替换后再灌注 | 恢复当前职业映射的技能，读取既有玩家成长 | 旧技能实例不复用；无逆向推测的缓存等级 |
| 换英雄/职业 | 历史保留，下一次按当前职业解析 | `keep_hero_class` 沿用既有英雄牌契约；不是按英雄外观猜职业 |

替换时先完成技能安装和历史追加，再发出 `hero_power_replaced` 与 `imbued`，保证观察替换事件的反应看到一致的成长状态；之后恢复正常反应窗口。无效职业发出 `imbue_no_effect`。技能使用在效果捕获时读取强度，使用开始事件后的新灌注不追溯改变已捕获效果。这些使用次数、跨职业和捕获窗口仍须 M6 校准。

`SplitDamage` 增加严格的效果/英雄技能/随从能力伤害来源参数，保留原逐点重新选择目标的行为。法师技能以英雄技能伤害执行，不获取普通法术伤害加成；法术/攻击/疲劳来源不能误用该接口。

## 恢复、回溯与玩家接口

类型化历史、profile 指纹、来源/技能身份和单调序号均参与快照校验。嵌套选择、多个来源、跨回合、错误回滚、克隆和动作回放覆盖同一状态。已实现的手牌回溯可撤销一次尝试产生的灌注历史和新技能；重试获得新的实体 ID，保留结果只保留一次成长。英雄技能自身的回溯与结果保留已由 [M5-12c-02b](m5-power-rewind.md) 接入。

玩家观察增加公开的 `imbue: {count, level}`，日志只显示公共成长数值，不投影内部历史、profile 或旧技能诊断字段。宿主全知快照不能直接交给玩家。`python -m examples.imbue_growth` 通过玩家命令完成德鲁伊/法师独立成长，8 动作、38 事件，中途恢复及完整回放一致；见 [示例](../examples/imbue_growth.py)。

## 证据与 R-100

[国服上线说明](https://hs.blizzard.cn/new/24189539/index.html)说明最初六职业首次替换、以后技能文本数值增长；[官方 FAQ](https://hearthstone.blizzard.com/en-us/expansions-adventures/into-the-emerald-dream)说明非灌注职业无效果。[永恒回响国服公告](https://hs.blizzard.cn/news/24245105/)扩充潜行者和死亡骑士，旧六职业说明不能直接当当前完整范围。[35.4 国服修正](https://hs.blizzard.cn/news/24266874/)涉及死亡之翼之后潜行者灌注误选死亡骑士技能，支持保留当前职业这项依赖。

**R-100 待校准：** 首次数值与未灌注时直接取得技能、无效请求与后续换职业的计数关系、跨技能保留、替换与同实体成长的使用次数、费用/附件继承、技能开始时的参数捕获、灌注反应/死亡窗口、魔像卡面及属性继承。58 项测试证明本批契约自洽，不是国服一致率。
