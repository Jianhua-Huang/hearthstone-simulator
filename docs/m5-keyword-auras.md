## 声明与来源

`CardDefinition.keyword_auras` 接受 `KeywordAuraSpec` 元组，每个声明安装为独立 `AbilityInstance(kind='keyword_aura')`，有附件 ID、来源、印刷/授予标记、到期及沉默策略。`GrantKeywordAura(holder_id, spec, source_id, expires_turn)` 向活跃场上随从授予同类能力；不直接修改受益实体的关键词。

```python
KeywordAuraSpec(Keyword.WINDFURY)  # 来源控制者的当前英雄
KeywordAuraSpec(Keyword.RUSH, 'friendly_minions')
KeywordAuraSpec(Keyword.TAUNT, 'friendly_minions', include_self=True)
KeywordAuraSpec(Keyword.WINDFURY, 'friendly_minions', adjacent_only=True)
```

当前来源仅为活跃场上随从。目标可为当前友方英雄或友方随从；随从默认排除来源，支持显式包含自身或物理相邻范围，相邻不能同时包含自身。地标、休眠及建造中星舰不受益，选取相邻槽位时不跳过这些占位。当前不提供敌方范围、任意条件过滤、武器/英雄/玩家长期效果来源。

支持八种已有连续语义的关键词：风怒、嘲讽、冲锋、突袭、吸血、剧毒、免疫、魔免。嘲讽、冲锋和突袭只允许随从范围。圣盾、潜行、复生等带消费状态的关键词以及泰坦、法术迸发等专门机制显式拒绝；它们不能靠每次重算重新授予来实现。

## 重算与生命周期

- 来源能力是真值，`Entity.aura_keywords` 是派生集合；有效关键词为自身能力、武器贡献与光环贡献的并集。多来源不重复叠加布尔关键词，移除一项不会清除其他来源。
- 每个既有光环检查点从全部来源重新计算；受益者不创建永久附件。光环字段与最终关键词均参与稳定边界检查，伪造或陈旧缓存不能恢复。
- 来源沉默、消灭、回手、变形、休眠或到期撤销相应贡献。来源转控后按新控制者定位受益者；复制来源具有独立附件身份。授予能力可在已沉默的实体上生效，再次沉默仍移除。
- 沉默受益者只移除其自身附件，场外来源提供的光环仍生效。复制受益者不把外部光环变为固有能力；新实体重新按场景计算受益范围。
- 英雄替换后光环指向当前英雄，新英雄保留既有替换契约中的攻击次数/冻结状态；墓地旧英雄的派生光环被清空。
- 复用当前死亡批次策略：当批死亡记录保留最后有效光环，整批移出后撤销；不新增死亡检查点。这是原型时序契约，尚待国服实测。

## 风怒与艾萨拉

风怒将每回合攻击额度设为二；获取、失去、重新获取以及来源叠加均不改变 `attacks_this_turn`。第一次攻击后获得风怒可再攻击一次，失去后可能立即没有剩余攻击；已经攻击两次的英雄重新获得风怒也不能进行第三次攻击。冻结、攻击力、嘲讽、武器耐久与既有合法性检查继续生效。

艾萨拉按冻结本地记录为 8 费 8/8 纳迦，声明巨型双附肢与友方英雄风怒光环。CATA_151t/CATA_151t1 继续使用已有兆示捕获等级与本回合英雄攻击增益。主体沉默不撤销附肢已产生的增益；兆示强化不增加风怒的攻击额度，满场无法生成附肢也不阻止主体光环。

官方萨尔介绍明确描述武器风怒允许一回合攻击两次，仅用于核实基础规则；艾萨拉精确数据来自锁定本地记录，官方卡牌库索引也已找到，但页面未提供可读的完整规则文字，不能据此宣称国服交互通过验证。[官方风怒说明](https://hearthstone.blizzard.com/en-us/news/13023803)；[艾萨拉官方卡牌库](https://hearthstone.blizzard.com/en-us/cards/124116-azshara-ocean-lord)。
