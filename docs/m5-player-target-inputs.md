# 玩家可见目标条件与原输入

公共接口位于 `hs_sim/engine/player_target_inputs.py`。它让真实手牌的普通根、战吼和连击共用可恢复的玩家条件。实际执行、验收结果和下一项仅在[项目状态](project-status.md)及[机制清单](mechanism-backlog.md)维护。本接口是内部构筑机制契约，尚未国服校准。

## 注册与输入

```python
from hs_sim.engine import PlayerTargetRuleSpec

def affordable_health(ctx):
    own = ctx.observation['players'][ctx.player_id - 1]
    return ctx.target is not None and ctx.target['health'] <= own['mana']

registry.register_player_target_rule(
    PlayerTargetRuleSpec('affordable_health', 'v1'), affordable_health,
)
```

声明卡牌或独立主体时通过 `target_rule='affordable_health'`引用，同时明确目标域。规格标识和语义版本进入注册表指纹；修改处理函数语义时必须更新版本。注册处理函数是可信纯函数，只读取 `PlayerRuleContext` 的观察、来源和目标副本，返回严格bool。它不能读取全知GameState、调用引擎RNG或在闭包中捕获外部对局。该接口不是Python沙箱。

普通 `register_target_rule(..., visibility='player')` 保持既有普通操作用途；独立付费主体需要上述显式原输入注册，不能借普通可见性声明取得新来源权限。全知自定义条件仍不获该路径授权。

## 两个窗口

付款前原窗口只捕获一次完整公开观察及物理引用映射。普通根和每个物理主体仍各自捕获自己的完整有序候选、激活条件和已选目标；回调逐次获得独立副本。该观察包含玩家已能看到的资源、费用、当前属性和公开计数，不包含完整内部历史或暗牌属性。

战吼、连击实际执行时按既有 `skip_unavailable`政策使用当前观察复查原目标。付款后法力变化或前一主体改变目标，会影响此时的资格，不会重写原候选。当前来源在可见位置时使用完整当前DTO；已离开可见位置的来源使用现有自动效果的有限公开来源描述，条件必须处理相应字段可用性，不能假定每个区域都有手牌费用字段。

真实回溯每次尝试捕获新的当前观察、卡面和接受窗；初始观察从真实回溯保存的Information取得，保留一次原根，不递归嵌入前一次完整局面。保留原目标选择，仍只产生一次净支付。此政策不授权生成/间接来源自行选目标。

## 保存与检查

`PaidTargetObservation`只保存规范JSON和不可变物理引用绑定；没有将完整GameState或旧递归历史嵌进普通记录。原观察进入目标原输入摘要。恢复检查观察版本、原席位/回合、完整可见槽位、自己的手牌/战场顺序、原身份与属性/种族、原法力水晶及此前出牌计数，再由同一版本纯函数重算完整原候选。

完整付款证明另从真实付款前GameState重建同一投影，检查资源、护甲、费用及其他原公开字段。该重建保留原已知身份与可见句柄，不重新取得当前玩家知识；观察事件仅保留计数，校验不会发布虚构事件。等待恢复、clone、回放及重试共用此检查。

关闭后的紧凑记录保留已接受观察和可重建物理事实，不从当前局面推算原资源。上述检查证明内部一致性；不能认证任意未签名存档的外部来源，也不能从后续当前资源独立证实过去的全部公开输入。需要外部来源认证时应由可信宿主提供签名或原动作回放。

## 信息与范围

物理映射、完整原观察、来源JSON和证明只供可信宿主与恢复器。玩家端仅得到当前可见候选句柄；对方手牌即使记住卡名，也没有后续隐藏属性。盲选对方手牌必须覆盖所有允许手牌类型，先拒绝会依赖隐藏类型的目标域；条件只见背面或已知身份DTO。牌库/墓地等来源继续需要独立揭示与选择契约。

开发格式为prototype-v140/core-effects-v140/schema137，旧schema1～136需原引擎，明确拒绝补缺；观察58、命令9和外层replay1保持。未使用玩家原输入注册的内置目标不额外保存观察。

[间接战吼](m5-indirect-body-targets.md)已连接自己的原输入。未公开内部历史的全知自定义条件、其他执行来源的原授权/目标选择/RNG窗口，以及完整U14生命周期组合、正式池和国服官方证据继续按各自契约补齐。本模块不宣称任意条件、所有来源或整个机制族已完成。


[生成整牌消费者](m5-generated-body-targets.md)已经连接显式原输入：实际执行者可与当前回合玩家不同，由生成激活/owner-turn证明校验。原观察值的结构接受该席位，不产生付费能力；付费消费继续要求active viewer，生成消费者显式使用自身原窗口。原候选与实际调用时的当前资格分别处理。
