# 回溯次数卡面与生命周期

原始 M5-11b 批次公共子集，`prototype-v75` / `core-effects-v75`、snapshot schema 74、player-view-v44、representative-m5-v38；动作 v6、回放外层 1。实现沿用 [回溯检查点](m5-rewind.md)，新增 [45 项内部测试](../tests/test_m5_rewind_forms.py)。精确国服规则仍待 R-091/R-092，整族 partial。

## 声明与身份

`RewindSpec(retries=2, next_card_id="remaining_one")` 表示本次打出最多重试两次，第一次重试切为 `remaining_one`。下一形态必须声明一次重试并指向无回溯的终结形态。注册冻结时检查整条链存在、严格减一、以无回溯形态结束；拒绝循环、截断及形态间身材、费用、行为、职业或其他能力差异。卡名、ID、回溯标记与收藏/构筑身份可不同。

不带 `next_card_id` 的声明保持原有“每次手动打出预算”，不能据此宣称持久次数卡面。链本身不限定最多三次，具体卡牌的有效次数由版本数据决定。

重试先恢复支付前检查点，再将**同一实体**的卡面切到对应剩余次数；原实例数值、增益、能力附件及消耗、伤害和手牌获取信息均保留。仅更新 `card_id`、区域引用修订，并在终结形态撤下回溯标记。随后正常打出并使用该形态的历史身份。此操作不复用会重建基础属性的通用升级或变形。

| 交互 | 原型行为 |
| --- | --- |
| 保留结果 | 保存当前已消耗次数的卡面 |
| 回手/洗入/转控 | 保持当前卡面；再次手动打出按该卡面预算执行 |
| 基础/当前复制、死亡历史复活、复生 | 使用当前卡面作为来源，按既有各自生命周期处理附件和数值 |
| 沉默 | 移除能力，不把身份退回初始卡面；回手重置后仍只有剩余卡面的预算 |
| 变形 | 替换为目标定义；已捕获的本次回溯会话仍可恢复原出牌检查点 |
| 自动施法、历史重施 | 执行记录的卡面，不开启新的手动回溯或消耗形态 |

## 支付、历史与玩家接口

**R-092 暂定政策**：一次已接受的手动出牌绑定检查点的原支付报价。重试恢复后仍按原卡与原状态计算费用，原卡 ID 专属减费/替代支付最终只净消耗一次；只匹配新卡面 ID 的优惠不在这次重试中突然生效。以后再次手动打出时正常按当前卡面报价。官方说明尚不能证明这些精确支付边界。

游戏内出牌/施法/死亡历史记录实际执行的当前卡面；宿主动作日志保留最初 `PlayCard` 和后续选择，回放推导每次形态。`rewind_face_changed` 在撤销标记后公开新卡面，沿用已有实体句柄；该控制事件不捕获卡牌触发。旧区域引用失效，私有选择句柄继续使用已有防复用边界。嵌套发现和结果选择均可保存恢复、克隆和重算回放，加载检查已执行卡面与尝试次数一致。

## 两张必要验证代表

- `TIME_000` 半稳定的传送门：回溯随机生成随从，生成牌带减三费；撤销旧生成实体后使用继续推进的 RNG 产生新实体。
- `TIME_EVENT_999` 时间之沙：初次发现任意职业法术，回溯后通过 `rewind_attempt` 改用当前职业法术；旧发现所得牌随分支撤销。

两者只使用显式不完整实验池，缺少生成上下文时报错，不能把实验候选数量/概率当作正式池。真实台账为 260 条/261 个注册定义，十二个 choice-only 描述；没有批量扩卡。

## 证据与后续

[官方开发者说明](https://hearthstone.blizzard.com/en-us/news/24241327/across-the-timeways-community-events)确认回溯会重新加载整个游戏状态，但未给出精确支付、终局或触发顺序。

冻结原文中 `TIME_038/t1/t2/t3` 分别为三/二/一/零次，正次数形态的 `REWIND` 标签均为 1，不能把标签值当次数。[国服 34.0 补丁](https://hs.blizzard.cn/news/24243857/)已把钟表先生从三次改为两次。**C-005** 保留有效数据覆盖、后续修订和卡面映射核实；不修改原始哈希，也不注册已知存在冲突的当前卡牌实现。公共链使用合成定义验证。

**M5-11c 保留多种结果**已通过 55 项专项，使用独立累计效果进度和一次激活计数，见 [保留结果与来源离场契约](m5-rewind-outcomes.md)。历史组合验收保留；当前只推进独立基础机制，不拓展组合或特殊授予，执行位置见 [项目状态](project-status.md)。英雄技能回溯已有独立入口，见[技能回溯契约](m5-power-rewind.md)；特殊动态回溯授予/来源按实际卡牌需求后置，正式池与卡面版本确认留 M0/M7，国服精确规则留 M6。完整回归结果见 [项目状态](project-status.md)。
