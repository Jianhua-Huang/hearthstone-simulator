# M5-08：裂变的公共手牌机制

**2026-10-09当前范围：**普通抉择/兼得、预选和真实历史继承保留；抉择与磁力/裂变/同一静态长期载体及独立印刷战吼/连击、根分支定价均已撤下。下方旧增量和费用/裂变组合补充仅保留历史记录，不是现行接口或必做依赖。当前扩展方式见[抉择契约](m5-choose-one.md)及[扩展指南](extensions.md)。

本页记录原有普通法术的公共原型基础契约，使用合成定义验证，没有增加真实卡牌适配。入口为 [shatter.py](../hs_sim/engine/shatter.py)，验证为 [36 项专项测试](../tests/test_m5_shatter.py)。实际完整回归结果见 [项目状态](project-status.md)。 抉择及配方转换实验已撤除，见[历史撤除说明](m5-shatter-choose-roots.md)。

## 声明与身份

```python
CardDefinition('root', '组合牌', CardType.SPELL,
    keywords=(Keyword.SHATTER,), shatter=ShatterSpec('left', 'right'),
    on_play='combined_behavior')
# left、right 各自是独立法术定义，带 Keyword.SHATTERED 和自己的 on_play。
```

根牌与两种碎片都是独立实体。注册时必须给出两个不同、可解析、仅属于此族的普通法术碎片；缺失父牌、递归碎片、共用碎片、非实体选项和当前未支持的奥秘/任务/持续法术/手牌进度组合明确拒绝。根牌与两片的效果仍通过普通行为组合，不在结算器中判断卡牌 ID。

重组得到新的根牌实体，并消耗其印刷 Shatter 能力。消耗状态已经属于可保存的能力实例，无需额外全局配对字典或不可恢复闭包。卡族声明进入注册表指纹；原批次快照版本为 50，玩家观察为 `player-view-v44`，现行版本见[项目状态](project-status.md)。

## 公共流程

- 成功进入手牌的未消耗根牌拆成两片，左片放手牌最左、右片放最右。抽到、生成、普通移动与基础复制共用此入口。入手前已满手则烧掉根牌，不拆分。
- 任意相邻的同族互补碎片重组，原有两片离开手牌，新根牌放在这两个位置的左侧。单独打出碎片只执行该片行为和正常支付；组合牌只支付一次，执行声明的组合行为。
- 每个效果处理器完成后、光环/死亡与事件反应调度之前检查手牌，直到无变化；因此打出、弃掉或移动中间牌，或重排手牌，均可触发重组。每次拆分/重组消耗统一结算预算，失败全部回滚。
- 原根牌/两片移入墓地，记录来源实体，但不制造死亡、弃牌、尸体或星舰贡献。成功产生的手牌实体登记获取历史，原因分别是 `shatter` 与 `recombine`。旧 `CardReference` 随离手失效，后续效果不会把旧片段拉回。
- 场景初始化先构建完整手牌，再统一处理；这些实体的获取回合为 0。正式对局中，起手牌保持原实体供换牌选择，换牌和开局钩子完成后、首回合开始事件之前处理，获取回合同样为 0；之后的首回合抽牌为回合 1。

拆分、重组使用拥有者私有事件 `card_shattered`、`cards_recombined`，玩家接口不透出诊断载荷中的内部实体 ID。对手能看到手牌数量与卡背变化；烧牌继续按既有规则公开被烧卡面。全知快照和诊断事件仍只供可信宿主使用。

## 生命周期和费用

| 情况 | 当前明确契约 |
| --- | --- |
| 拆分 | 两片使用各自印刷属性/行为；分别复制根牌附魔和非印刷授予能力，分配新附件 ID，保留原来源与期限 |
| 重组 | 使用根牌印刷行为；保留声明的左片的附魔和非印刷能力，不叠加共同减费；左右物理位置颠倒不改变取值来源 |
| 当前复制组合牌 | 保留 Shatter 已消耗状态，不再次拆分 |
| 基础复制/显式重置组合牌 | 恢复印刷 Shatter，成功入手后再次拆分 |
| 组合牌移入牌库再抽回 | 未要求重置则保留已消耗状态 |
| 临时减费到期 | 两片及组合牌保留原期限，沿用公共到期清理 |
| 沉默、变形和转控 | 普通法术不进入现有随从沉默/变形/转控入口；手牌跨玩家移动仍由公共区域操作处理，不凭同名跨玩家配对 |

## 官方依据与 R-083 待校准项

国服上线公告确认入手拆分、两端摆放、碎片可独立使用以及相邻重组后具有合并效果。[国服官方说明](https://hs.blizzard.cn/news/24250357/)

公告没有定义以下细节，本批全部标记 **R-083 原型假设**，不能视为官方认证：

1. 每个效果后的检查窗口；一次处理器内的多次获取，以及与抽牌/生成反应、反制、死亡和终局的精确顺序。
2. 只有一个手牌空位时先保留左片、烧掉右片；空手入手后可立即重组。
3. 不同原始副本的同族碎片能够配对；物理逆序也能重组；多组候选按玩家/手牌顺序处理。
4. 两片复制根牌附魔；重组以声明的左片为继承来源，忽略右片独立修改。包括独立减费、设值、授予能力和可见身份的官方细节。
5. 换牌阶段暂不拆分，所有开局钩子结束后拆分；当前复制/重置/移入牌库的保留语义，以及变换造成的获取历史如何被其他牌识别。

自动施法已在 [独立施法契约](m5-spell-casts.md) 接入且不经过手牌，不触发入手裂变；[抽到时施放](m5-draw-casts.md) 也直接使用原实体施法、不产生手牌获取；特殊来源和重复组合按后续真实卡需求处理，不作为当前基础阶段门槛。真实五个卡族及特殊组合效果没有在此批接入，归 M7 适配；适配时发现新公共依赖须回到 M5。正式池归 M0，窗口证据与国服实测归 M6。

36 项测试覆盖上述已实现契约，包括选择中断后的保存恢复、动作回放、失败回滚、预算、严格快照、玩家命令和私有信息；这些验证证明实现自洽，不证明 R-083 等同国服结果。
