## 出牌与施法的区别

`PlayRecord` 继续只记录手动从手牌打出。新增 `SpellCastRecord` 与 `GameState.cast_history`，每次法术效果执行各有一条记录，原始手动执行标记 `hand`，同一出牌的后续遍标记 `repeat`，由效果施放标记 `effect`。记录物理法术实体、卡牌身份、控制玩家、发起效果的实体、回合/动作、目标、来源区域、条件、选择策略、执行阶段和结果。

反制的手动法术产生失败尝试记录；没有合法目标的自动法术也留下失败记录。成功表示效果队列正常执行完毕，不表示一定造成伤害、奥秘一定部署成功或对局继续；终局截断尚未结束的施法时标记 `interrupted`。这些区别允许后续卡牌明确选择“尝试”“成功”“玩家打出”或“效果执行”，不能把整个列表长度当作所有卡文要求的施法次数。

`cast_spells(state, player_id, origin=None, successful=None, turn=None, before_id=None)` 是规则/宿主查询接口，默认返回所有尝试。它不向玩家接口导出全知历史。

## 自动施法入口

```python
CastSpell(player_id, card_id, source_id=None, target_id=None,
          targeting='random', choices='random')
CastStoredSpell(card: CardReference, player_id, source_id=None,
                target_id=None, targeting='random', choices='random')
```

`CastSpell` 新建基础法术实体；`CastStoredSpell` 使用带区域版本校验的手牌/牌库实体，保持原实体及所有者，迁移至施法玩家墓地。过期引用明确跳过，类型错误或未知卡牌原子回滚。跨玩家来源改变控制者，不改变所有者。自动施法不支付费用，不抽牌、不产生疲劳，不增加出牌记录，不生成回响副本，不进入普通出牌反制/法术迸发/腐蚀窗口，也不套用手动法术重复光环。

自动法术使用自己的独立实体作为伤害等效果来源，所以已有法伤、派系与伤害修正可继续使用。奥秘、任务和长期玩家效果走各自的公共激活流程，保留容量/唯一键检查；双生法术属于效果完成后的衍生物，自动施法也生成其终结形态。已经构造的自动实体不先进入手牌，因此不会错误触发裂变入手或手牌获取。

## 目标与条件

- `random` 在当前符合声明的目标中均匀抽取，仍执行类型、区域、友敌、排除自身及卡牌谓词。没有目标时，强制目标法术失效；可选/有则必选声明允许无目标执行。存在候选时随机策略选一个目标，不随机选择放弃目标。
- 自动选择绕过手动指定目标的潜行、魔免和免疫选择保护；免疫伤害防止仍在伤害结算中生效。休眠、死亡和非活跃实体不成为目标。这是 R-088 的待校准规则，不是国服实测结论。
- `explicit` 使用效果指定的目标；不合法或缺少强制目标时失效，不偷偷换一个目标。目标随后离场时由各公共效果处理过期目标，不重新抽样。
- `RuleContext.cast` 是施法记录；`RuleContext.play` 在自动施法时保持 `None`。公共 `spell_conditions` 优先返回施法条件，普通随从等仍读取出牌条件。
- 手动及重复施法沿用原出牌冻结条件；自动施法按当前已提交出牌历史计算连击、按当前法力上限计算法力渴求，流放/快枪手/压轴为 false。不会伪造手牌位置或支付。此策略及来源例外需 R-088 校准。

## 选择、挂起与公开信息

自动法术自己的 `RequestChoice` 默认自动随机选择，遵守采样和最小/最大数量；数量范围不是固定值时先等概率选数量，再等概率选子集，并保持选项原顺序执行。回调与多级分支仍能获得同一施法上下文。独立触发来源或对手的选择不继承施法者的随机策略。`choices='player'` 提供明确的挂起扩展路径，使用原有选择动作恢复。

`ResolveAutomaticSpell` 与 `FinishSpellCast` 都是可序列化效果，`payload_started` 区分尚未执行与已执行阶段。挂起边界检查开始/结束标记、嵌套次序与记录一致，防止重复执行或丢失结束标记。手动重复效果也逐遍留下记录，支付和出牌仍只有一次。结算预算、异常回滚、RNG、存档、克隆和回放使用现有公共设施。

玩家日志只新增 `spell_cast_started`、`spell_cast_finished`、`spell_cast_failed` 的受限投影。普通实际施放的法术身份公开，自动部署的奥秘仍保持隐藏。内部 cast ID、发起者内部 ID、未选目标/选项、完整历史与区域候选不直接导出；自动选择诊断事件保持内部。
