## 能力声明与身份

`CardDefinition.spell_repeats` 接受 `SpellRepeatSpec` 元组，每项安装为有独立附件 ID 的 `AbilityInstance(kind='spell_repeat')`。`SpellRepeatSpec(casts=2, class_mode='other')` 表示友方其他职业法术执行两遍，`class_mode='any'` 支持不筛选职业的公共扩展；`casts` 是总遍数，不是额外次数。多个匹配声明取最大值，不连乘、不相加。

来源限于活跃场上随从，按当前控制者作用。沉默、死亡、回手、休眠、变形、转控、复制和到期沿用公共附件生命周期。`GrantSpellRepeatAura(target_id, spec, source_id=None, expires_turn=None)` 支持动态授予；再次沉默可移除，当前复制保留附件并分配新身份，基础复制与回手重打重新安装印刷声明。

“其他职业”使用当前英雄职业与法术印刷职业集合：中立牌不匹配，包含当前职业的双职业牌不匹配。缺少职业元数据明确报错并回滚，不能把未知职业当成其他职业。已经开始执行的遍数不随来源离场、沉默或新增来源改变。

希奈丝特拉按冻结记录为 6 费 5/5 龙、巨型+2，左右附肢继续使用已实现的跨职业实验法术池与兆示折扣。主体只声明上述公共能力；没有卡名专用结算器。附肢没有空位时主体能力仍生效；完整生成池和模式合法性未认证。

## 一次出牌、多遍效果

1. 沿用一次支付、一次出牌历史、一次反制检查和一次目标替换窗口。被反制时不进入重复执行。
2. 在反制/目标窗口关闭后，从当前来源捕获总遍数、最终目标 ID 和法术行为 ID。普通只执行一次的法术沿用原有路径。
3. 每遍重新建立只读 `RuleContext`，因此后续遍可读取此前效果改变的场面、手牌和法伤，并重新使用 RNG；`context.play` 仍是同一份冻结出牌条件，不重新支付或重算连击、流放、压轴、快枪手。
4. 同一目标 ID 沿用到后续遍。回手等导致目标不在公共效果允许区域时，目标部分按既有过期策略处理，独立抽牌等部分仍可执行。不能把第二遍简化为“再选一个合法目标”。
5. 普通反应继续在效果间执行；随从死亡移出、亡语和复生延迟至整个重复阶段结束。复用 `death_deferrals`，可与星舰发射嵌套。英雄死亡继续使用现有立即终局契约，丢弃剩余工作并标记中断。
6. 最后仅一次 `FinishPlay` / `card_played`，继续既有法术迸发与腐蚀流程。法术中途新召唤的法术迸发来源不会消费本次法术；已捕获来源在重复效果结束后仍须符合生效条件。

奥秘、任务及长期玩家效果也通过公共激活流程执行：第二遍奥秘/任务重新检查唯一键与容量，允许创建时使用新实体，不能把原有活跃实体再移动一次；同名奥秘/主任务因此不能直接叠放。允许叠加的长期效果每遍创建独立实例。

## 抉择、发现与保存

`RequestChoice.repeat_key` 是显式选择策略，默认 `None`：发现和普通交互每遍独立请求选择。需要沿用第一次选项的效果内选择可设置稳定键，并传入当前法术 `source_id`。滋养现用支付前的动作 `branch_id`，两遍从冻结记录读取同一分支，不再使用 `repeat_key`。

```python
RequestChoice(
    context.player_id,
    (ChoiceOption('draw', '抽牌', (Draw(context.player_id),)),),
    source_id=context.source_id,
    repeat_key='my-payload-choice',
)
```

缓存的是选项 ID，而不是第一次生成的效果列表；后续遍仍重新构造分支效果。键只关联正在执行的同一法术与玩家；其他触发来源的选择不会继承。带键的请求不能随机抽样选项身份，候选改变导致缓存选项失效时明确报错回滚。出牌前抉择与效果内选项缓存分开；公共入口、自动策略和R-112见[抉择契约](m5-choose-one.md)。

`GameState.spell_repeats` 保存不可变 `SpellRepeatRecord`，包括所关联的 `play_id`、最终目标、总遍数、行为 ID、完成进度、中断标志与 `SpellChoiceMemo`。开始/完成遍、关闭重复阶段均为可序列化指令。保存时核对记录与帧中标记的数量、顺序、出牌完成位置和死亡延迟深度；它们不能藏在闭包或全局变量中。

记录属于全知状态。玩家 DTO 不公开重复记录、行为 ID、选择缓存键或结算队列；用户通过现有选择句柄提交操作。异常沿用事务边界：未挂起时回滚整次出牌，已挂起时回滚本次选择，恢复到此前成功提交的等待状态。
