# M5-13d-02g-03a：临时关键词与回合期限

2026-09-25。内核 `prototype-v87` / `core-effects-v87`、snapshot schema 84、玩家观察48；代表包47保持。本文保留原内部实验契约 **R-129**，不确认国服边界。2026-10-09新版计时改用真实自身区间，见[独立回合契约](m3-turn-scheduling.md)。来源范围见[连击来源审计](m5-combo-sources-audit.md)，实际验收结果见[项目状态](project-status.md)。

## 声明与运行状态

`TimedKeywordSpec(keyword, boundary='turn_started', player='controller', occurrences=1)` 为印刷或授予的战斗关键词限定期限。支持潜行、嘲讽、圣盾、冲锋、突袭、风怒、免疫、剧毒、吸血、复生、魔免；目前载体限定随从。带主体或跨区协议的连击、泰坦、回响等不能作为裸临时标记使用。

印刷定义同时声明 `keywords=(Keyword.STEALTH,)` 与 `timed_keywords=(TimedKeywordSpec(Keyword.STEALTH),)`；每个期限必须唯一对应一个印刷关键词。普通 `GrantKeyword` 增加可选 `duration`，要求匹配同一关键词，不能与旧 `expires_turn` 同用。旧全局回合结束期限保持原语义，未改为按控制者计时。

每个能力附件保存原声明和可空的 `KeywordExpiry(player_id, created_turn, owner_turn_index, boundary, created_owner_turn_id)`。未入场的印刷牌保留未计时声明；真正安装到场上时绑定玩家、原创建区间及自身回合到期序号。运行中不从文本猜测期限，也不随控制者重新推算。

- `turn_started`：跳过已经开始的当前回合，取指定玩家下一次开始；额外次数每次增加一个该玩家实际自身开始，不依赖双方交替。
- `turn_ended`：指定玩家若正在行动，当前结束计为第一次，否则取其下一次结束。结束反应中新授予的同回合到期关键词也进入稳定清理。
- `player='controller'/'opponent'` 在首次安装时解析一次；同一标记的后续转控不改变已绑定玩家。
- 当前引擎已按真实自身区间计算和验证期限；额外回合计数，跳过机会不计数。旧按全局奇偶计算的存档需原引擎，新schema152明确拒绝。

## 时序

开始新回合时先切换行动玩家、更新法力及回合计数，再原子移除该玩家已到期的全部关键词。随后捕获 `attachments_expired` 反应。新 `BeginTurnEvents` 延续点使这些反应完整结算后，才捕获普通 `turn_started`、休眠/玩家计时和抽牌工作。到期反应可以暂停选择；若导致终局，不继续发出回合开始或抽牌。

到期反应重新授予“下次开始”期限时，当前开始已经过去，因此得到新的后续期限。结束期限在普通结束反应之后移除，沿用 `ExpireTurn` 的稳定清理循环；循环预算耗尽仍回滚，不转成游戏平局。

到期使用现有内部 `attachments_expired`，逐实体报告被移除附件。所有匹配实体先同时移除，再捕获反应；不让一个监听看见另一只尚未移除的到期标记。冻结的死亡历史和先前规则上下文保持不变。

## 生命周期

| 来源/操作 | 本批契约 |
| --- | --- |
| 手牌/牌库印刷实体 | 未计时；换回合不消耗印刷期限 |
| 手牌打出、普通/跨区召唤 | 入场反应前首次绑定期限，不能靠战吼或on_play补装 |
| 当前场上复制 | 复制能力消费状态及原期限、原绑定玩家；附件ID独立，不续期 |
| 原始复制、变形、复生、复活 | 安装印刷定义并重新计时；复生自己的消费规则保持 |
| 当前手牌副本/从手牌复制到场上 | 隐藏区副本仍未计时，首次入场绑定接收方 |
| 弹回/洗牌重置 | 丢弃旧实例期限，重新安装未计时印刷声明；再次入场才重新绑定 |
| 转控 | 保留原期限，不重置；这项具体国服语义待M6验证 |
| 沉默 | 与对应能力一起移除；转为其他定义不会留下旧期限 |
| 攻击/随从能力伤害/圣盾消耗 | 既有提前消费规则生效，期限不会让已消费关键词复原 |
| 休眠 | 标记不参与普通作用，但计时继续；唤醒不重装已过期标记 |
| 磁力 | 可转移的未计时印刷标记在宿主安装时绑定，保留磁力分组与移除规则 |
| 星舰 | 建造体保留未计时声明，发射前不消耗；发射激活时绑定。重造/历史发射继续走印刷安装路径 |
| 死亡/移出场外 | 已绑定实例仍按时清理；不可变死亡记录保留当时证据 |

相同关键词可以由多个不同期限或永久来源提供；过期只移除对应附件，其他来源继续有效。期限失效不影响同一随从的战吼/连击重复光环。

## 恢复与信息

原schema84按固定玩家和全局期限校验，是历史格式。当前schema152保存实际自身序号及创建区间，校验原区间、次数、边界、未来创建、漏绑定及已过期实例，不再推算全局奇偶；严格拒旧1～151。挂起帧中的 `GrantKeyword.duration` 同样使用类型白名单恢复。

原观察48曾公开全局期限。当前观察65在原本可见实体的 `keyword_durations` 中公开关键词、开始/结束边界、玩家和owner_turn_index；不暴露来源、附件ID、创建区间ID或内部期限对象。对手未知手牌仍是牌背。已消费标记不出现在当前期限列表。全知快照/回放仍不能给玩家接口。
