## 两项固定实测的共用准备

双方使用术士好友对战。A表示最初持有目标随从的人，与先后手无关。只用正常出牌，双方不攻击英雄，不加入持续召唤、任务或其他改变观察窗口的效果。

关键牌：诅咒之链、森金持盾卫士、王室图书管理员、恶魔监禁。每个实际场景只需各一张对应关键牌；参考牌组放两张方便抽到。缺关键牌就先跳过，不为测试合成。

双方可用同一套参考30张牌组：15种牌各2张。其余12种为森金持盾卫士、奖品商贩、巫医、精灵弓箭手、欢快的同伴、日怒保卫者、血帆袭击者、荆棘帮暴徒、寒光先知、硬壳甲虫、吵吵机器人、荆棘谷猛虎，另加诅咒之链、王室图书管理员、恶魔监禁。

已静态核对30张、职业、固定标准候选身份和牌组码往返，未在当前国服实际导入。先以客户端能保存的标准牌组为准，填充牌可换自己已有的普通标准随从。准备时控制手牌，避免烧掉关键牌；进入观察窗口后，不再使用会抽牌、增益、伤害或召唤的填充效果。

## T6：双链后立即沉默

所需：A有森金、诅咒之链、图书管理员；B有诅咒之链。A在最后一次操作前至少有6点法力，两边空位充足。

1. A打出森金，不攻击，结束。
2. B用诅咒之链夺走这只森金，结束。
3. A下一回合用另一张诅咒之链夺回**同一只**森金。不要先结束回合；立即打出图书管理员，战吼沉默它。
4. 记录沉默后森金立即在哪边、是否仍有嘲讽；A结束后再记录，B空过并结束后再记录。

整个窗口不攻击目标、不造成伤害、不回手、变形或第三次偷取。当前本地结果写在上表，实测按真实情况填写，不预设答案。

## T7：休眠向满场归还

所需：B有诅咒之链、恶魔监禁及至少4点法力。A有森金、六只可填场的普通随从，以及手中的另一只填场随从。

1. 准备阶段A先铺六只无持续效果、无亡语的随从。参考牌组可用血帆袭击者×2、荆棘帮暴徒×2、寒光先知×2。A手中留森金和猛虎，B场上留足空位。
2. A打森金成为第七只，结束。B先用链夺走森金，再对它使用恶魔监禁，确认实际进入休眠，然后结束。
3. A此时六只随从，打出猛虎补到七格；B侧森金仍在休眠。先留下双方完整场面，再由A点击结束。
4. 连续记录到全部结算停止、B回合开始，观察森金是否移动、死亡、消失、短暂出现或继续休眠。随后B不做其他操作，结束，再记录一次。

目标必须为**非恶魔森金**。监禁对友方恶魔会改为加属性，无法构成这个场景。六只准备随从的身材不重要，人数和不存在持续效果/亡语更重要。

本地对照：休眠向有空位的一侧可以归还；普通活体向满场归还走消灭；休眠且满场目前明确报错并回滚。限制与回滚已内部验证，未据此实现或确认正式服本项处理。
